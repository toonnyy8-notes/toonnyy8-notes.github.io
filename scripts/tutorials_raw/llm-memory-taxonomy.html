    LLM 的記憶：一張三軸分類地圖

    這篇綜述以表示、更新動態、持續性三個軸，整理注意力快取、遞迴狀態、測試時更新的參數、查表記憶與 MoE。

    Sining Zhoubian、Dan Zhang、Evgeny Kharlamov、Jie Tang（2026）〈Memory for Large Language Models〉

    01 · 記憶指什麼

    記憶在這裡指模型內部保存、並影響後續輸出的資訊，例如：注意力為每個讀過的 token 留下的 key–value 向量；遞迴模型讀完前文後帶到下一步的一組數值；推論時還會被改動的參數；以及可以用索引直接查的表格。

    02 · 三個問題

    三個問題決定一個機制的位置：它有沒有獨立的讀寫介面？推論時會不會被更新？能影響計算多久？

    03 · 兩個例子

    TitansEOnL 在推論時以梯度更新一個記憶模組；EngramEOffL 把記憶存在以雜湊定址的槽中。兩者都被歸為顯式長期記憶：前者線上更新，後者離線（訓練期）更新。

    三軸標記依序表示 表示／更新／持續：實心＝顯式（E）、線上（On）、長期（L）；空心＝隱式（I）、離線（Off）、短期（S）。

    01 · 範圍

    本文的記憶是模型層級的機制

    作者觀察到，記憶正從「計算的副產品」變成一個明確的架構設計維度（§I）。Titans 與 TTT-E2E 在部署時更新參數；Engram 把記憶儲存與稠密計算分開；Nested Learning 讓訓練與推論的界線變得模糊；MoE 依輸入只啟用一部分參數，構成一種條件記憶。條件記憶指只有被路由器選中時才參與計算的參數，例如 MoE 的專家。

    注意力快取、遞迴序列狀態、測試時調適、檢索模組與條件參數路由過去多被分開研究，但作者認為它們都在回答同一組問題：存什麼、何時與如何更新、如何與前向計算互動、保留多久、儲存粒度為何（§I）。缺少統一的框架時，方法之間難以比較，系統層級的權衡也難以分析。

    本文的範圍因此限定為模型層級的記憶：只納入實例化於模型架構或其推論期動態之中的機制（§II）。依賴外部協作或工程流程的代理層級記憶與提示層級記憶被排除；外部 RAG 流程也被排除，因為它依賴架構外的文件庫、向量資料庫與協作流程，而本文討論的查表記憶把持久儲存嵌在模型結構中（§IV-B f）。預訓練後固定的靜態參數（例如 attention 或 MLP 權重）即使編碼了知識，原則上也不討論，焦點是會隨時間演變、或主動儲存與檢索資訊的機制（§II-A c）。MoE 是例外：它的專家也是訓練後固定的參數，作者卻把它放在顯式參數化記憶與查表記憶之間的中間位置（§IV-C），理由見 08。

    對話紀錄、使用者檔案、工具輸出與資料庫等，只有在其儲存、存取或更新機制實例化於模型架構內、或與架構緊密耦合時才納入（§II-D）。作者也強調，這套分類「不是僵硬的分類，而是揭示共同結構的概念框架」（§II 開頭）。下表摘錄 Table III：既有綜述多以代理、認知類比或生命週期組織，本文的視角是架構。

    02 · 三個軸

    三個軸分別回答存什麼、何時更新、保留多久

    作者用三個大致正交的軸描述每個記憶機制（§II）。表示軸（representation）分隱式與顯式，回答「存什麼、如何存取」；更新動態軸（update dynamics）分離線與線上，回答「何時、如何更新」；持續性軸（persistence）分短期與長期，回答「資訊能影響計算多久」。

    軸的順序：§I 的貢獻列表寫成「表示、持續性、更新動態」，摘要、§II 與 §VII 寫成「表示、更新動態、持續性」。本頁採用 §II 的順序。

    表示軸：有沒有獨立的讀寫介面

    隱式記憶把資訊當作前向計算的副產品儲存，與模型內部動態緊密耦合；它沒有顯式的讀、寫或查表介面，只能經由計算圖存取。例子是 RNN、線性注意力與 SSM 的演化狀態，以及 Transformer 的 KV 快取。這裡的「狀態」指模型讀完前文後留下、並帶到下一步的數值，例如 RNN 的隱藏向量。顯式記憶是獨立的儲存元件，具有明確的存取語意，通常支援顯式的定址、檢索與更新，而且這些操作不能化約為標準的前向計算或離線反向傳播（§II-A）。

    區分隱式與顯式的判準是有無獨立且可控的儲存／檢索介面。KV 快取雖然實體化為顯式的張量，但它的存取語意由架構固定，沒有獨立定址或更新控制，因此仍是暫時的計算狀態，屬於隱式。反過來，顯式不限於非參數結構：附加的參數模組只要被設計並作為記憶運作、具有清楚的讀寫語意與可控的更新策略，就是顯式，與是否為參數形式無關（§II-A）。§IV 開頭再補充一點：顯式記憶的定義性質是自主性（autonomy），也就是儲存的資訊獨立於當下的計算圖存在，能以不同於標準前向傳播的機制更新、存取或維護。

    更新動態軸：推論時會不會更新

    離線記憶只在訓練期更新，通常以梯度最佳化，推論時固定，例如端到端訓練的記憶層與 MoE。線上記憶在推論期也能更新，頻率可以是每個 token、每個片段或每個批次，更新規則也可以不同於標準反向傳播（§II-B）。只看「何時」並不夠，下一節的更新規則補上「如何」。

    持續性軸：有效視野，而非儲存大小

    持續性指儲存的資訊能繼續影響計算的有效時間範圍，簡稱有效視野：過去的資訊還能影響目前輸出的距離。它不只取決於狀態是否實體保留，也取決於儲存粒度與壓縮率（§II-C）。短期記憶細粒度，通常受限於局部視窗、片段或一次推論；長期記憶在延伸的上下文、某些情況下跨會話保留資訊或其影響，不一定需要大型的未壓縮儲存。

    持續性取決於儲存粒度與壓縮率。KV 快取以高保真、低壓縮的方式保存每個 token 的狀態，儲存隨 token 數成長，難以無限擴展，有效視野因而受視窗大小、快取預算、淘汰策略或會話邊界限制，被歸為短期。遞迴狀態的大小固定，可以靠大幅壓縮維持較長的有效視野，因此可能被歸為長期；§II-C 的用詞是「may」，不是保證。長期記憶的特徵是延伸的有效視野，而非儲存大小本身。06 的 C3 會把這兩種情形畫成曲線。

    作者指出三個軸在概念上大致正交（§II-C c）：顯式記憶可以離線或線上，線上記憶依更新與淘汰策略可以短期或長期。

    檢查理解

    三個軸是什麼？各問什麼？

    表示（隱式／顯式）：存什麼、如何存取；更新動態（離線／線上）：何時、如何更新；持續性（短期／長期）：資訊能影響計算多久（§II）。

    KV 快取已是實體張量，為何仍算隱式？什麼讓參數模組算顯式？

    判準是有無獨立且可控的儲存／檢索介面；KV 快取的存取語意由架構固定、無獨立定址或更新控制；參數模組若被設計並作為記憶運作、具清楚讀寫語意與可控更新策略即為顯式，與是否為參數形式無關（§II-A）。

    為什麼儲存隨 token 數成長的 KV 快取被歸為短期，而大小固定的遞迴狀態反而可能被歸為長期？

    持續性取決於儲存粒度與壓縮率：KV 快取高保真低壓縮，儲存隨 token 數成長，因而受視窗與快取預算限制；遞迴狀態大小固定，可以靠壓縮維持較長的有效視野（§II-C 用「may」，不是保證）。

    04 · 注意力

    注意力是內容定址的短期隱式記憶

    作者把自注意力描述為「可微、內容定址的暫時工作記憶」（§III-A a）。內容定址指讀取時不靠位置編號，而是比較 query 與每個 key 的相似度。

    以記憶的語言描述，KV 快取的寫入是每個新 token 以附加一筆 key–value 條目的方式隱式更新快取；讀取由即時計算的注意力權重完成（§III-A a）。StreamingLLM 使用滑動視窗注意力，再保留少量 attention sink token，不需重新訓練就能在無界串流上穩定生成；從記憶觀點看，它是一種隱式淘汰策略：滑動視窗持續覆寫多數過去狀態，少數 attention sink token 被保留下來錨定注意力（§III-A c）。

    注意力記憶的容量直接綁定上下文視窗。MLA（DeepSeek-V2）把 key 與 value 共同壓縮成潛向量，改變 KV 記憶的粒度與效率，但不改變其隱式語意（§III-A b）。延長上下文也不一定轉化為有效利用：長上下文模型常無法利用名目上的容量。HyperMLP 把自迴歸注意力改寫成輸入條件的兩層 MLP，隱藏寬度隨序列長度成長，仍屬隱式（§III-A d）。

    §III-B 提出一個統一的觀點：稀疏、選擇與局部–全域結構，都是對線上記憶系統加上准入、存取與保留的控制。固定稀疏（Sparse Transformer、BigBird、Longformer）決定每一步可以存取哪些條目，不增加容量，只重塑存取路徑。MoBA 把 KV 切成區塊，把每個 query 路由到少數相關區塊；NSA 結合壓縮的區塊摘要、選擇性保留的細粒度區塊與局部視窗；兩者屬於自適應存取控制。選擇性注意力（Selective Attention）是隱式的准入控制。RATTENTION 分析滑動視窗大小與保留的全域 token 數之間的權衡，顯示少量精選的全域記憶就能大幅改善效能。作者的結論是：注意力式記憶常常不是靠存更多，而是靠控制資訊如何被准入、存取與保留（§III-B e）。

    檢查理解

    KV 快取如何「寫入」與「讀取」？StreamingLLM 在記憶觀點下是什麼？

    每個新 token 以附加條目寫入，讀取由即時計算的注意力權重完成；StreamingLLM 是隱式淘汰策略：滑動視窗持續覆寫多數過去狀態，保留少量 attention sink token 錨定注意力（§III-A a、c）。

    05 · 遞迴狀態

    遞迴序列記憶把歷史壓進固定大小的狀態

    先備知識：向量、內積、外積、正交

    向量是一列數字，例如 $k=(1,0)$。兩個向量的內積 $k^\top q$ 是對應元素相乘再相加；內積為 0 時稱兩者正交，例如 $(1,0)$ 與 $(0,1)$。範數 $\|x\|=\sqrt{x^\top x}$ 是向量的長度，$\|k\|=1$ 稱為單位向量。

    外積 $vk^\top$ 是一個矩陣：第 $i$ 列第 $j$ 欄的元素是 $v_ik_j$。例：$v=(0.6,0.8)$、$k=(1,0)$ 時，$vk^\top=\begin{pmatrix}0.6&0\\0.8&0\end{pmatrix}$。矩陣乘上向量 $(vk^\top)q=v\,(k^\top q)$，也就是「$v$ 乘上 $k$ 與 $q$ 的內積」。

    先看一個 2 維的例子

    令狀態 $S$ 是一個 $2\times2$ 矩陣，起始為 0。寫入一對 key–value 的方法是把外積 $vk^\top$ 加進 $S$；以 key $k$ 讀取的方法是計算 $Sk$。

    第一次寫入 $k_1=(1,0)$、$v_1=(0.6,0.8)$：$S=v_1k_1^\top=\begin{pmatrix}0.6&0\\0.8&0\end{pmatrix}$，讀出 $Sk_1=(0.6,0.8)=v_1$。第二次寫入與 $k_1$ 正交的 $k_2=(0,1)$、$v_2=(1,0)$：$S=\begin{pmatrix}0.6&1\\0.8&0\end{pmatrix}$，讀 $Sk_1$ 仍是 $v_1$，因為 $k_2^\top k_1=0$。第三次寫入與 $k_1$ 不正交的 $k_3=(0.707,0.707)$：讀 $Sk_1$ 會多出 $0.707\,v_3$。這個多出來的部分稱為串擾：讀某個 key 時混進其他 key 的值。2 維空間最多只能放 2 個互相正交的 key。

    遞迴序列記憶做的就是這件事：把歷史壓縮進一個與前向計算耦合、大小固定的潛狀態（§III-C）。經典的 RNN 與 LSTM、線性注意力遞迴與狀態空間模型（SSM）都屬此類。

    從線性注意力到 delta rule

    線性注意力把注意力核化並利用矩陣乘法的結合律，把因果注意力寫成以線性時間更新的遞迴狀態；GLA 對矩陣值狀態加入資料相依的衰減；Mamba 與 Mamba-2 引入選擇性更新與 SSD 形式；Gated Delta Networks（GDN）以輸入條件的 delta rule 做內容感知的保留（§III-C b）。Fig. 3 把兩類遞迴寫成：

    SSM 的式子中，$h_t$ 是狀態，$A_t$ 是狀態轉移，$B_t$ 把輸入寫進狀態，$C_t$ 負責讀出；本頁的元件只使用第一條式子，不展開 SSM。圖中 $q_t$ 以虛線連到記憶方塊，表示讀取。本頁推導讀出寫成 $o_t=S_tq_t$，以某個 key 查詢時為 $S_tk_i$；論文圖中沒有寫出讀出式。

    Fig. 3 的線性注意力狀態更新式是 $S_t=\alpha_tS_{t-1}-\beta_tS_{t-1}k_tk_t^\top+\gamma_tv_tk_t^\top$，狀態大小為 $d_v\times d_k$。本頁推導三項各有作用：$\alpha_tS_{t-1}$ 讓整個狀態以比例 $\alpha_t$ 保留，$\alpha_t<1$ 即衰減（遺忘）；$-\beta_tS_{t-1}k_tk_t^\top$ 擦除狀態在 $k_t$ 方向上原本存的值；$+\gamma_tv_tk_t^\top$ 把新值 $v_t$ 綁到 $k_t$ 上寫入。係數與文獻的對應為：線性注意力取 $\alpha=1,\beta=0,\gamma=1$，即純加法寫入；delta rule 取 $\alpha=1,\beta=\gamma$。這些對應是本頁依 §III-C 的描述與原論文的標準形式整理，論文沒有逐一寫出。

    衰減式（GLA 類）對應 $\beta=0$、$\alpha<1$，這是兩層簡化：原方法的衰減是資料相依的，而且 GLA 的衰減是逐通道（對角矩陣），本頁用一個常數純量 $\alpha$ 代替。Mamba 本身對應 Fig. 3 的第二條式子，本頁不把它寫成第一條式子的某組係數。Gated delta（GDN）的原式是 $S_t=\alpha_t(S_{t-1}-b_tS_{t-1}k_tk_t^\top)+b_tv_tk_t^\top$，展開後對應 $\alpha=\alpha_t$、$\beta=\alpha_tb_t$、$\gamma=b_t$。

    覆寫與串擾

    本頁推導同一個單位 key 寫入兩次時，兩種規則讀出的結果不同。若 $\|k_t\|=1$ 且 $\alpha=\beta=\gamma=1$，寫入後 $S_tk_t=S_{t-1}k_t-S_{t-1}k_t(k_t^\top k_t)+v_t(k_t^\top k_t)=v_t$：delta rule 讀出新值，舊值被完全取代，這稱為覆寫（新值取代同一個 key 的舊值）。純加法寫入則讀出 $S_{t-1}k_t+v_t$，也就是舊值＋新值。一般而言，$T$ 筆加法寫入後以 $k_i$ 讀取，得到 $S_Tk_i=v_i(k_i^\top k_i)+\sum_{j\ne i}v_j(k_j^\top k_i)$。只有所有鍵互相正交時，交叉項 $\sum_{j\ne i}v_j(k_j^\top k_i)$ 才為 0，而 $d_k$ 維空間中最多只有 $d_k$ 個互相正交的鍵；隨機單位鍵在 $T>1$ 時就會互相干擾。

    本頁推導隨機單位鍵時，每個交叉項的 $(k_j^\top k_i)^2$ 期望為 $1/d_k$。下方元件把串擾定義為 $e_i=\|r_i-c_iv_i\|$，扣掉了落在 $v_i$ 方向的分量，粗估其均方根約為 $\sqrt{(T-1)(d-1)}/d$。以 20 個 seed 平均：$d=8,T=16$ 為 1.264（粗估 1.281）；$d=32,T=16$ 為 0.672（粗估 0.674）。即使 $T<d$（$d=32,T=16$），平均串擾仍有 0.674。這是 Table II「壓縮損失與狀態干擾」與 §III-D a「記憶跨度與表示保真度的權衡」的最小例子。

    • Gated DeltaNet-2 分離 key 側的擦除與 value 側的寫入。
    • Kaczmarz Linear Attention 把寫入視為 key 正規化的投影步。
    • Kalman Linear Attention 與 Gated KalmaNet 以濾波或線上回歸，依估計品質調節更新。
    • RWKV-7 以向量值的狀態閘與上下文內學習率推廣 delta rule。
    • KDA（Kimi Linear 的遞迴核心）引入逐通道的對角衰減。
    • DeltaProduct 組合多個 Householder 更新；Comba 用純量加低秩轉移與閉迴路回饋。
    • Mamba-3 改進離散化並加入複數值更新與 MIMO 形式，狀態大小仍固定。

    檢查理解

    寫出線性注意力的狀態更新式與狀態大小；線性注意力與 delta rule 各對應哪組係數？

    $S_t=\alpha_tS_{t-1}-\beta_tS_{t-1}k_tk_t^\top+\gamma_tv_tk_t^\top$，大小 $d_v\times d_k$；線性注意力 $\alpha=1,\beta=0,\gamma=1$；delta rule $\alpha=1,\beta=\gamma$（Fig. 3；係數對應為本頁推導）。

    同一個單位 key 寫入兩次時，加法與 delta rule（$\alpha=1,\beta=\gamma=1$）各讀出什麼？什麼條件下加法寫入才完全沒有串擾？

    加法讀出舊值＋新值，delta rule 讀出新值（$\|k\|=1$ 且 $\alpha=1,\beta=\gamma=1$ 時 $S_tk_t=v_t$）；只有所有鍵互相正交時交叉項 $\sum_{j\ne i}v_j(k_j^\top k_i)$ 才為 0，而 $d_k$ 維中最多 $d_k$ 個互相正交的鍵；隨機鍵在 $T>1$ 時就會互相干擾（本頁推導）。

    06 · 隱式的限制

    隱式記憶受容量、讀寫語意與持續性限制

    §III-D 列出隱式記憶的三個限制。第一，容量有界且難以控制（a）：注意力模型的容量隨上下文視窗與 KV 快取大小而定，受平方或線性時間複雜度與硬體限制，長上下文模型常無法有效利用名目長度；狀態式模型原則上可處理無界序列，但壓縮進固定大小的狀態，產生記憶跨度與表示保真度的權衡。第二，缺乏可調適的讀寫語意（b）：資訊只依計算圖（注意力權重或狀態轉移）儲存與取回。第三，跨脈絡持續性有限（c）：內容常綁在少數前向傳遞或一次推論會話上，計算結束即丟棄；快取狀態快照或多狀態混合主要改善同一延伸序列內的保留，而非跨會話的持久。

    作者認為這三點「劃定了僅靠計算耦合記憶能達到的邊界」，並由此引出把儲存與內部計算分開的顯式記憶（§III-D d）。下方的 C3 只示範第一點：比較各種機制每層需要保存的數值個數如何隨序列長度 $L$ 成長。

    檢查理解

    §III-D 的三個限制是什麼？

    容量有界且難以控制；缺乏可調適的讀寫語意；跨脈絡持續性有限（§III-D a–c）。

    為什麼儲存隨 token 數成長的 KV 快取被歸為短期，而大小固定的遞迴狀態反而可能被歸為長期？

    持續性取決於儲存粒度與壓縮率：KV 快取高保真低壓縮，儲存隨 token 數成長，因而受視窗與快取預算限制；遞迴狀態大小固定，可以靠壓縮維持較長的有效視野（§II-C 用「may」，不是保證）。

    09 · 時間尺度與風險

    多時間尺度更新與顯式記憶的六項風險

    記憶參數在結構上與骨幹分開，更新排程不必與訓練步或推論步一致，因此不同的參數子集可以用不同的頻率演化（§IV-D）。Titans 與 TTT-E2E 是短時間尺度的例子：持久參數在一次推論中逐 token 演化（a）。Nested Learning 以階層化的更新頻率形成由快到慢的連續譜（b）；慢–快參數分解則回到 fast/slow weights（c）。這裡有一個穩定性–可塑性的權衡（d）：更新頻繁增加適應力，但容易過擬合暫態訊號；更新慢保持穩定，但反應遲鈍。作者的結論是：時間控制對顯式記憶與結構持久性同樣核心。

    10 · 混合與評測

    混合架構、記憶管理與評測

    混合架構（§V-A）把不同的記憶基底組合起來。Samba 交錯 Mamba 式的選擇性 SSM 層與滑動視窗注意力（a）；LightTransfer 把預訓練 Transformer 中的「lazy」層換成串流元件；Priming 把混合化當作從預訓練 Transformer 到混合 SSM 的知識轉移。OLMo Hybrid、Kimi Linear、Hymba、Falcon-H1 等固定串列或混合頭的模型，以靜態選擇分配高保真的注意力路徑；[80] 指出全注意力層放在哪裡，是召回–效率權衡的核心決定因素。

    AMOR 與 HAM 則以訊號決定何時使用昂貴的記憶（§V-A b）。AMOR 在遞迴骨幹上附加事後的注意力精修塊，閘控的是是否執行注意力精修，依據是正規化輸出熵：只對熵高的位置啟用。HAM 讓遞迴記憶處理每個 token，閘控的是token 是否准入 KV 快取：稀疏的 KV 快取只存遞迴狀態難以預測的 token，快取成長由門檻或學習的路由器控制。作者的歸納是，固定混合是排程或結構式的分配，AMOR 與 HAM 則依不確定性或預測誤差更新可存取的記憶集合。

    12 · 開放問題

    開放問題與延伸閱讀

    §VI 列出六個方向。

    1. 統一的記憶理論：在狀態轉移的觀點下，以保留保真度、干擾穩健性與資訊壓縮效率刻畫容量，並形式化穩定性–可塑性。
    2. 持續與終身的參數記憶：讓參數化記憶跨任務、跨會話累積而不破壞已學知識。
    3. 穩健且可解釋的更新規則：逐一對應 Table II 的五種規則風險，例如驚奇度、熵或預測誤差能否忠實反映未來的相關性，准入與淘汰的不可逆問題；目標是可診斷、必要時可逆。
    4. 自適應的記憶分配與控制：由靜態組合走向學習的控制器。
    5. 硬體–演算法協同設計：記憶的存取模式要配合硬體。
    6. 有原則的多維度評測：儲存容量、檢索保真度、時間持續性、抗干擾與計算效率，以及控制干擾注入、記憶衰減量測、更新一致性分析等壓力測試。

    §VII 的結論是沒有單一的記憶範式能滿足所有需求：token 層級的注意力以可擴展性換取高保真召回；遞迴序列記憶提供壓縮的長視野，但有干擾；顯式記憶增強時間持續性，但帶來更新穩定與定址的複雜度。因此 LLM 的設計正轉向自適應協調這些互補基底的混合架構。
