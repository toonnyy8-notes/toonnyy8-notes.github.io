只用梯度，也能把取樣做到極準

poly(1/δ)→polylog(1/δ)

擴散模型只學得到 score。這篇論文提出 FORS，用一連串「擲硬幣」取代密度計算，讓只靠 score 的取樣器第一次在精度上做到指數級的改進。以下用可以操作的圖，一步步拆開它。

直接玩 FORS 閱讀論文
TL;DR · 01

瓶頸在每一步不精確

DDPM 每步用一個高斯近似真正的反向轉移，誤差一路累積，步數至少要 Ω(1/δ)。只要每步能精確取樣，步數就只剩對數級。

TL;DR · 02

用梯度擲出指數機率的硬幣

拒絕取樣需要密度值。FORS 用路徑積分做出無偏估計，再用 Poisson 化的 Taylor 級數擲硬幣，全程只查詢梯度。

TL;DR · 03

一個工具，兩個領域

同一個子程序也是對數凹取樣中 proximal sampler 的 RGO。這是第一個只用梯度、對一般對數凹分佈達到 polylog(1/δ) 的方法。

01 · 問題

問題出在每一步的高斯近似

擴散模型把雜訊一步步變回資料。每一步該做的事，是從一個確定的分佈抽樣。

前向過程把資料 X0 逐步加噪成 XT；反向時，給定 Xt+1 = x′，下一步的正確分佈由 Bayes 法則決定：

ρt(x | x′)  ∝  pt(x) · exp(−‖x − αt−1x′‖² / 2ηt)資料在雜訊水準 t 的密度，乘上一個以 α⁻¹x′ 為中心的高斯窗。論文稱這種形式為 Gaussian tilt。

DDPM 把 log pt 做一階展開，用單一高斯 N(α−1x′ + η st, ηI) 取代它。步長小時近似很好；步長一大，真正的 kernel 可能變成多峰，高斯就蓋不住。這個每步誤差會累積，Jiao、Zhou 與 Li（2025）證明 DDPM 因此無法擺脫多項式依賴。

下圖讓你直接看到這件事。拖動 x̄ 或加大步長 η，比較真實 kernel、DDPM 的高斯，以及稍後會介紹的 FORS 輸出。

02 · 分水嶺

高精度一直綁在「能不能算密度」上

要精確修正每一步，傳統做法是 accept–reject。它需要的資訊，正好是擴散模型沒有的。

取樣演算法能用的資訊分兩種。零階 oracle 回傳 f(x)，也就是 log 密度（到常數）；一階 oracle 回傳 ∇f(x)，也就是 score。

有零階資訊時，Metropolis–Hastings 或拒絕取樣能把離散化偏差完全篩掉，誤差只剩混合不足的部分，而那部分隨步數指數下降，所以是 polylog(1/δ)。只有梯度時，主流方法都是離散化一個 SDE，偏差只能靠縮小步長壓下去，所以是 poly(1/δ)。擴散模型訓練時只學 score，自然落在右下角。

03 · FORS

用梯度擲出一枚 ew 機率的硬幣

核心技巧來自應用機率裡的 Bernoulli factory。先看最簡單的一維版本。

想在 [0, 1] 上從 p ∝ e−f 取樣，而且只能查詢 f′。拒絕取樣要以機率 c·e−f(x) 接受，但我們不知道 f(x)。論文的觀察分三步：

1

值變成梯度的期望

微積分基本定理給出 f(x) 的無偏估計，每個樣本只花一次梯度查詢。

f(x) = Ey∼U[0,x][ x·f′(y) ]
2

把指數 Poisson 化

取 J ∼ Poisson(2B)，指數函數的 Taylor 級數會變成一個乘積的期望。

eE W = eB · E[ ∏j≤J (B+Wj)/2B ]
3

每個因子擲一次硬幣

依序以機率 (B+Wj)/2B 擲硬幣，全部成功才接受。任何一枚失敗就提早拒絕。

a(x) = ew(x) − B
04 · 高維

高維時，截斷的代價有多大

硬幣機要求 W 落在 [−B, B]。高維裡 W 可能很大，所以要截斷；問題是截斷的偏差能不能小到可以忽略。

回到 Gaussian tilt ν ∝ exp(−f(x) − ‖x − x0‖²/2η)。論文選 proposal 為一階展開得到的高斯 q = N(x0 − η∇f(x+), ηI)，其中 x+ 近似 proximal point。兩者的對數比恰好是 Taylor 餘項，可以寫成路徑積分，沿路徑抽一個點就得到一個無偏的 W。

截斷到 [−B, B] 會改變目標，但偏差只來自 |W| > B 的尾端事件。論文的關鍵不等式把誤差上界寫成高斯 proposal 下截斷超額量的指數矩；只要 W 的尺度遠小於 1，尾機率就是指數小，步長只需要縮小 log(1/δ) 倍。

路徑怎麼選決定了 W 的尺度。直線路徑上 |W| ≈ β‖x − x+‖² ∼ βηd；論文改用帶隨機端點的 sin/cos 路徑，因為 ara′r + brb′r = 0，路徑上的點與它的速度互相獨立，W 變成零均值的高斯內積，尺度降到 βη√d。

γz,r(x) = ar x + (1 − ar) x̂ + br z,   ar = sin(πr/2),  br = cos(πr/2),  z ∼ N(0, ηI)W = ⟨γ̇, ∇f(x₊) − ∇f(γ)⟩，r ∼ U[0,1]。式 (9)–(10)。
05 · 擴散

串成擴散取樣器：誤差隨步數怎麼降

把 DDPM 的每一步換成一次 FORS 呼叫。每步誤差指數小，總誤差只是相加，不再隨步長放大。

Algorithm 2 很短：從 XT ∼ N(0, σT²I) 開始，每一步呼叫 FORS 從 backward kernel 抽出 Xt。KL 鏈式法則把總誤差拆成三項：初始化誤差、每步截斷誤差的總和、以及加權的 score 誤差 Σ ηt ε²t。

步長的條件是 ηt ≲ σt²/G，G ≈ (d + log(1/δ))·log(d/δ)。這等於要求訊噪比每步只放大 1 + 1/G 倍，所以雜訊水準呈幾何間隔，從 σ0² ≍ δ²/(d + M2²) 走到接近純雜訊只要 T ≈ G·log(κ/δ) 步。

理論說 FORS 的誤差隨步數指數下降，DDPM 只能多項式下降。下面是一個可以精確計算的小實驗：在一維網格上逐步傳播整個 Markov 鏈的密度，量測最終輸出和真實分佈的 TV 距離。

06 · 結果

三種擴散取樣器，只換 proposal 與估計量

同一個 FORS 骨架，配上不同的 proposal，對應不同強度的假設。誤差以 bounded Lipschitz 距離衡量。

Theorem 4.1 · 簡單版

只假設有限二階動差

O(d log²(M/δ) + log³(M/δ))
proposal
N(x̄, ηI)，不含 score
score 誤差
L²，Capx = O(1)
步長
σ²/η ≫ d·log + log²

W 約為 N(0, η‖s‖²)。Tweedie 恆等式加上高斯卷積保證 ‖s‖² ∼ d/σ²，對任何資料都成立。先前最佳是 Õ(d/δ)。

Theorem 4.4 · DDPM 版

非均勻 Lipschitz score

O(√(dL) log3/2 + L log²)

N(x̄ + η s(x̄), ηI)
score 誤差
L²，Capx = O(√(d/L))
假設
‖∇s⋆‖ ≤ L/σ² 以高機率成立

∇s⋆ 就是後驗共變異，所以 Lipschitz 天然是高機率性質；無條件時 L = O(d + log(1/δ))，高斯混合時 L = O(log)。sin/cos 路徑消掉 η·tr(H) 偏差。

資料有內在維度 d⋆

N(x̄ + η̄ s(x̄), η̄I)，1/η̄ = 1/η + 1/σ²

稍強的 L²，Capx = O(d/d⋆)

把 −‖x‖²/2σ² 吸收進 proposal，剩下的 Hessian 是半正定的後驗共變異，trace 由覆蓋數控制在 d⋆/σ²。

相較所有先前結果，對 1/δ 的依賴是指數級的改進。論文腳註提到 arXiv 版本之後又有改進：最小假設下做到 Õ(d⋆·log³)，Frobenius 範數版本的非均勻 Lipschitz 下做到 Õ(L·polylog)。這裡依 ICML 版本陳述。

07 · 對數凹

順手解決對數凹取樣

Proximal sampler 每一步需要的 RGO，正好也是一個 Gaussian tilt。

Proximal sampler（Lee、Shen、Tian 2021）在增廣分佈 π(x, y) ∝ exp(−f(x) − ‖x − y‖²/2η) 上做 Gibbs 取樣：先抽 y ∼ N(x, ηI)，再從 exp(−f(x) − ‖x − y‖²/2η) 抽 x。後者稱為 restricted Gaussian oracle（RGO）。外層迴圈的收斂已有成熟理論；過去實作 RGO 都需要函數值。FORS 讓它只需要梯度。

假設（f 光滑）保證一階查詢數（期望）
Log-Sobolev 不等式χ² ≤ ε²Õ(κ(d1/2log3/2(R/ε²) + log²(R/ε²)))，κ = CLSIβ
Poincaré 不等式χ² ≤ ε²Õ(κ(d1/2log1/2(1/ε) + log(1/ε))·log(χ²/ε²))
對數凹KL ≤ ε²Õ(β d1/2 W2²(μ0, μ)/ε²)；配合 KLS 進展可得一般對數凹的高精度保證

這些速率和 Fan、Yuan、Chen（2023）相同，差別是不需要函數值。論文為簡化起見假設可取得精確的 proximal point；當 η ≤ 1/(2β) 時那是一個強凸最佳化問題，誤差分析可比照 Altschuler & Chewi（2024）。

08 · 脈絡

四條研究線，在這篇論文匯合

經典取樣、對數凹理論、精確模擬、擴散模型理論，原本各自發展了幾十年。

匯合點可以拆成四步：把擴散的一步看成 RGO（主線 2）；用 Bernoulli factory 與路徑積分實作 RGO（主線 3）；沿用擴散理論的早停、二階動差、內在維度與非均勻 Lipschitz 等假設語言，讓結果能逐項比較（主線 4）；最後把同一個子程序放回 proximal sampler，回饋對數凹取樣。

09 · 展望

還沒解決的事，以及怎麼讀下去

這是一篇理論論文。它把 1/δ 的依賴推到接近最佳，維度依賴與實務成本仍然開放。

01

維度依賴的缺口

有界支撐時上界是 Õ(d)，Xun & Price（2026）的下界是 Ω̃(√d)，中間差了至多 √d。

02

ODE 取樣器的高精度保證

DDIM 一類的確定性取樣器實務上步數更少，但還沒有 polylog(1/δ) 的保證。

03

實務成本

每步需要 Poisson 數量的 score 查詢，理論步長條件也可能保守。作者把 FORS 定位為原則性的 accept–reject 校正器，尚無大規模影像實驗。

04

score 誤差的結構

後續工作顯示梯度雜訊為次指數尾時仍可高精度，只有有界變異數時有 Θ(1/δ) 下界。神經網路 score 落在哪一邊還不清楚。
