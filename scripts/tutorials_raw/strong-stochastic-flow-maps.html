    02Flow map

    與其一步步解，不如直接記住答案

    Flow 與擴散模型的取樣，本質上是解一條微分方程：

    dxtdt=vt(xt),Φs,t(xs)=xs+∫stvr(xr) dr\frac{dx_t}{dt}=v_t(x_t),\qquad \Phi_{s,t}(x_s)=x_s+\int_s^t v_r(x_r)\,dr

    數值解法每一步只看當下的速度，步數一少誤差就累積。Flow map 換個做法：讓網路直接學解映射 Φs,t\Phi_{s,t}，輸入起點與兩個時間，輸出終點。它被兩個性質完全刻畫：

    ∂tΦs,t(x)∣t=s=vs(x),Φu,t∘Φs,u=Φs,t\partial_t\Phi_{s,t}(x)\big|_{t=s}=v_s(x),\qquad \Phi_{u,t}\circ\Phi_{s,u}=\Phi_{s,t}切線條件 · 半群條件

    切線條件說，跳一小步時它就是原本的速度場。半群條件說，先跳到 uu 再跳到 tt，等於直接跳到 tt。訓練通常分兩部分：在對角線 s=ts=t 上匹配速度，在 s≠ts\neq t 處用半群或導數條件自蒸餾。Consistency model、Shortcut、MeanFlow 與 Decoupled MeanFlow 都是這個框架的變形。

    flag

    留下的問題：ODE 沒有隨機性。推論期的獎勵對齊、序列蒙地卡羅，以及需要多樣性的分子構形取樣，都需要一個隨機的少步取樣器。

    03隨機化

    弱解只要分佈對，強解要路徑對

    擴散模型也能寫成一條與 probability flow ODE 有相同邊際分佈的 SDE：

    dXt=f(t,Xt) dt+g(t) dWtdX_t=f(t,X_t)\,dt+g(t)\,dW_t

    其中 WtW_t 是布朗運動。要把 flow map 推廣到 SDE，有兩種做法。

    弱隨機 flow map（GLASS、Diamond Map、Meta Flow Map）學的是轉移核 pt∣sp_{t\mid s}。每次呼叫都抽一份新的雜訊，抽出的分佈正確，但和任何一條特定的雜訊路徑都沒有關係。

    強隨機 flow map 學的是 Itô map，布朗路徑本身成為輸入：

    Ψs,t: (Xs, W[s,t]) ⟼ Xt\Psi_{s,t}:\ \big(X_s,\ W_{[s,t]}\big)\ \longmapsto\ X_t

    給定同一條路徑，答案就是確定的，所以一步、兩步、十六步都必須落在同一點。回到開頭的圖切換成「弱解」，就能看到差別：弱解每次換步數，終點都會變，有時還會掉進另一個井。

    弱隨機 flow map強隨機 flow map
    學的是轉移核 pt∣s(⋅∣Xs)p_{t\mid s}(\cdot\mid X_s)Itô map Ψs,t\Psi_{s,t}
    輸入起點與一份獨立雜訊起點與這段布朗路徑
    收斂意義分佈收斂逐路徑收斂
    換步數結果改變結果不變
    路徑上的量無法估計可以估計

    為什麼需要強解？只有強解能計算沿路徑累積的量。iSSFM 示範的 Feynman–Kac 校正就是例子：粒子的權重是沿它自己軌跡的積分，粒子必須真的走過那條路徑，權重才有意義。

    04路徑表示

    把一條布朗路徑，壓成幾個數字

    網路無法直接吃一條連續路徑，需要有限維的表示。只給增量 Wt−WsW_t-W_s 不夠，因為雜訊在區間內部怎麼擺動，會改變漂移累積的結果。SSFM 採用 Foster、Lyons 與 Oberhauser（2020）的多項式展開：用 shifted Legendre 多項式當權重，對雜訊做加權加總。

    Is,t(n)=∫stP~n ⁣(u−st−s) dWu ∼ N ⁣(0, t−s2n+1)I^{(n)}_{s,t}=\int_s^t \tilde P_n\!\Big(\frac{u-s}{t-s}\Big)\,dW_u\ \sim\ \mathcal N\!\Big(0,\ \frac{t-s}{2n+1}\Big)

    這組係數有三個性質，剛好撐起整個方法：

    • 獨立且服從常態。可以直接精確取樣，不必模擬整條路徑。變異數隨階數以 1/(2n+1)1/(2n+1) 遞減，所以少數幾個係數就涵蓋大部分資訊。
    • 重建路徑會收斂。用前 NN 個係數重建的多項式路徑，在 rough path（α-Hölder）意義下收斂到布朗運動，而且端點永遠精確。
    • 可以拼接。兩段子區間的係數，經封閉形式的 Chen 關係就能拼成整段的係數。下一章的半群自蒸餾靠的就是這一點。
    Ws,v(N)=∑n=0N−12n+1t−s Is,t(n)∫svP~n ⁣(r−st−s)drW^{(N)}_{s,v}=\sum_{n=0}^{N-1}\frac{2n+1}{t-s}\,I^{(n)}_{s,t}\int_s^v \tilde P_n\!\Big(\frac{r-s}{t-s}\Big)dr用 N 個係數重建的多項式路徑

    05SSFM

    四步論證，一個損失函數

    SSFM 把 flow map 寫成 Euler–Maruyama 一步的樣子，只是係數由網路產生，而且網路看得到路徑係數 Is,t={Is,t(n)}n<N\mathcal I_{s,t}=\{I^{(n)}_{s,t}\}_{n<N}：

    Ψs,tθ=Xs+(t−s) fs,tθ(Xs,Is,t)+gs,tθ(Is,t) (Wt−Ws)\Psi^\theta_{s,t}=X_s+(t-s)\,f^\theta_{s,t}\big(X_s,\mathcal I_{s,t}\big)+g^\theta_{s,t}\big(\mathcal I_{s,t}\big)\,(W_t-W_s)

    fs,tθf^\theta_{s,t} 可以理解成區間內「平均的漂移」，gs,tθg^\theta_{s,t} 是「平均的擴散」。漂移網路必須看路徑係數，因為雜訊在區間內的擺動會改變漂移累積的結果；擴散網路刻意不看狀態 XsX_s，這是加性雜訊結構的要求。整個理論可以拆成四步，點開看每一步：

    1切線條件Lemma 3.1expand_more

    Itô map 在 s→ts\to t 時退化成 SDE 本身。這是把網路和 SDE 連起來的唯一接點。

    lim⁡s→tdΨs,t=f(t,Xt) dt+g(t) dWt\lim_{s\to t} d\Psi_{s,t}=f(t,X_t)\,dt+g(t)\,dW_t
    2參數化Proposition 3.2expand_more

    上面的 Euler–Maruyama 形式滿足切線條件，若且唯若對角線上的係數等於 SDE 係數。所以對角線可以直接拿 SDE 係數來監督。

    ft,t(x)=f(t,x),gt,t=g(t)f_{t,t}(x)=f(t,x),\qquad g_{t,t}=g(t)
    3半群條件Proposition 3.3expand_more

    再加上半群條件，這個映射就是 Itô map。證明把區間切細，讓和式收斂成 Riemann 積分與 Itô 積分，最後用強解唯一性收尾。注意兩段吃的是同一條路徑的兩半。

    Ψs,t(Xs,W[s,t])=Ψu,t(Ψs,u(Xs,W[s,u]), W[u,t])\Psi_{s,t}(X_s,W_{[s,t]})=\Psi_{u,t}\big(\Psi_{s,u}(X_s,W_{[s,u]}),\,W_{[u,t]}\big)
    4唯一的極小點Theorem 3.5expand_more

    兩個條件各寫成一個非負損失。Itô map 讓兩者同時為零；反過來，任何讓兩者為零的映射都滿足上面兩個命題，所以就是 Itô map。

    LSD=E∥f−f^t,t∥2+∥g−g^t,t∥2⏟Lf,g+E∥Ψ^s,t−Ψ^u,t∘Ψ^s,u∥2⏟LD\mathcal L_{SD}=\underbrace{\mathbb E\big\|f-\hat f_{t,t}\big\|^2+\big\|g-\hat g_{t,t}\big\|^2}_{\mathcal L_{f,g}}+\underbrace{\mathbb E\big\|\hat\Psi_{s,t}-\hat\Psi_{u,t}\circ\hat\Psi_{s,u}\big\|^2}_{\mathcal L_D}

    半群損失要求「一大步」和「兩個半步」看到同一條路徑。大步需要整段的係數 Is,tI_{s,t}，兩個半步各需要 Is,uI_{s,u} 與 Iu,tI_{u,t}。Chen 關係保證前者可以由後者精確算出：

    Is,t(n)=∑m=0ncn,m(Is,u(m)+(−1)n+m Iu,t(m))I^{(n)}_{s,t}=\sum_{m=0}^{n}c_{n,m}\Big(I^{(m)}_{s,u}+(-1)^{n+m}\,I^{(m)}_{u,t}\Big)中點 u 的 Chen 關係

    06訓練

    不必模擬，也不需要老師

    每個訓練批次拆成兩份。75% 做匹配：讓網路模仿真實 SDE 走一小步。剩下 25% 做蒸餾：讓兩個半步教一大步。

    X^t=Xs+f(s,Xs)(t−s)+g(s)(Wt−Ws),Lmatch=∥Ψs,tθ−X^t∥2t−s\hat X_t=X_s+f(s,X_s)(t-s)+g(s)(W_t-W_s),\qquad \mathcal L_{\text{match}}=\frac{\|\Psi^\theta_{s,t}-\hat X_t\|^2}{t-s}
    Ldistill=∥Ψs,tθ−sg(Ψu,tθˉ∘Ψs,uθˉ)∥2t−s,u=s+t2\mathcal L_{\text{distill}}=\frac{\big\|\Psi^\theta_{s,t}-\mathrm{sg}\big(\Psi^{\bar\theta}_{u,t}\circ\Psi^{\bar\theta}_{s,u}\big)\big\|^2}{t-s},\qquad u=\tfrac{s+t}{2}

    擴散模型的真實漂移需要 score。給定資料點與加入的雜訊 ϵ\epsilon，條件 score 有解析解 −ϵ/σt-\epsilon/\sigma_t。損失是 L²，網路最後會收斂到真正的邊際漂移，和 denoising score matching 是同一個論證。所以整個訓練不必模擬軌跡，也不需要預訓練的教師。

    07成績

    影像與分子

    CIFAR-10 上，SSFM 在每個步數都勝過弱隨機 flow map，也和確定性 flow map 打成平手。分子系統上的差距更大：Alanine dipeptide 只用 2 次網路評估，自由能面的誤差就比擴散模型低兩個數量級，100 步即可追平擴散模型的 1000 步。

    flag

    留下的問題：SSFM 只用半群損失，而確定性 flow map 領域表現最好的是對時間微分的 MeanFlow 類損失。另外它只能從零訓練，影像只做到 64×64。

    08iSSFM

    三個原則，把它推上 ImageNet

    iSSFM（Blasingame 等，2026 年 10 月）找出 SSFM 卡住的地方：布朗路徑處處不可微，導數型損失用不了；損失也沒有逼網路真正用上高階係數。作者整理成三條原則。

    PRINCIPLE 1

    路徑表示要光滑、高階、可拼接

    沿用 Legendre 係數，並把 Chen 關係推廣到任意切分點，再給出多項式路徑的封閉形式導數。實驗中全域 Karhunen–Loève 展開明顯較差。

    任意切分 Chen封閉導數
    PRINCIPLE 2

    損失要逼網路用上整條路徑

    把 SDE 換成由多項式路徑驅動的隨機 ODE（Wong–Zakai），導數存在，iMF 類損失就能用，而且向量場依賴全部係數。

    Wong–ZakaiiMF
    PRINCIPLE 3

    參數化要對齊預訓練模型

    用指數提升消去線性項，隨機項改成封閉形式的鞅，對角線直接匹配教師速度，再用 Decoupled MeanFlow 架構加 LoRA 微調。

    Exponential liftDMF

    為什麼 Doss–Sussmann 行不通

    一個漂亮的想法是減掉雜訊項：令 Z=X−MZ=X-M，其中 M=∫g dWM=\int g\,dW，得到一條可微的隨機 ODE，再套用確定性 flow map 的導數損失。作者證明這條路會失敗。Eulerian 條件在起點評估向量場，而起點處的雜訊增量是零，所以最優解完全不看路徑係數；Lagrangian 條件最多只用到增量 I(0)I^{(0)}。玩具實驗中，這類模型的誤差對 N 完全是平的。

    Wong–Zakai：換一條光滑的路徑

    改把布朗路徑換成它的多項式近似。多項式可以微分，SDE 就變成一條普通 ODE：

    dXr(N)dr=br(Xr(N))+νr W˙r(N,s,t)\frac{dX^{(N)}_r}{dr}=b_r\big(X^{(N)}_r\big)+\nu_r\,\dot W^{(N,s,t)}_r

    向量場裡的 W˙(N)\dot W^{(N)} 依賴全部 N 個係數，而且在起點也不為零，所以導數型損失會逼網路用上整條路徑。N 趨近無窮時，解收斂回原本的 SDE。對時間微分時，區間端點一動係數就跟著變，作者把多項式路徑固定、用一次 forward-mode JVP 同時處理這兩件事。

    對齊預訓練模型

    Flow matching 模型對應的 SDE 有一個線性項 α˙tαtXt\tfrac{\dot\alpha_t}{\alpha_t}X_t，在線性排程下靠近雜訊端會發散，讓蒸餾變得困難。乘上積分因子 αt\alpha_t 就能把它消掉：

    d[αtXt]=2αt ut(Xt) dt+αtνt dWtd[\alpha_tX_t]=2\alpha_t\,u_t(X_t)\,dt+\alpha_t\nu_t\,dW_t

    隨機項 Mα=∫αν dWM^\alpha=\int\alpha\nu\,dW 是一個被積函數確定的鞅。依 Dambis–Dubins–Schwarz 定理，它是時間變換後的布朗運動，所以直接在這個「鞅時鐘」上建構 Legendre 係數，隨機項就有封閉形式，不需要再學擴散網路。flow map 變成：

    Ψs,tθ(x)=αsαt x+2As,tαt us,tθ(x;Is,t)+Mtα−Msααt,As,t=∫stαr dr\Psi^\theta_{s,t}(x)=\frac{\alpha_s}{\alpha_t}\,x+\frac{2A_{s,t}}{\alpha_t}\,u^\theta_{s,t}\big(x;\mathcal I_{s,t}\big)+\frac{M^\alpha_t-M^\alpha_s}{\alpha_t},\qquad A_{s,t}=\int_s^t\alpha_r\,dr

    對起點套用 Eulerian 條件，雜訊項在兩邊互相抵消，得到 improved MeanFlow 形式的回歸：目標是確定性的教師速度，路徑資訊只透過 material derivative DsD_s 進入。

    2αs us,tθ−2As,t sg(Dsus,tθ) ⟶ 2αs sg(usteacher)2\alpha_s\,u^\theta_{s,t}-2A_{s,t}\,\mathrm{sg}\big(D_s u^\theta_{s,t}\big)\ \longrightarrow\ 2\alpha_s\,\mathrm{sg}\big(u^{\text{teacher}}_s\big)WZ-iMF 損失

    架構沿用 Decoupled MeanFlow：前 20 個 DiT 區塊看 ss，後 8 個看 tt。路徑係數乘上 (t−s)(t-s) 閘門後以殘差注入，所以初始化時對角線就精確等於預訓練模型。

    強一致性實驗顯示兩種訓練方式都具有強解性質：步數增加時，結果都會收斂到自己 32 步的解。不過半群損失訓練的模型路徑一致性較好，WZ-iMF 的生成品質較好，目前還無法兩者兼得。

    09待解問題

    還沒解決的事

    乘性雜訊

    狀態相依的擴散係數會讓 Itô map 不再連續，需要 rough path 理論的 Itô–Lyons map。兩篇論文都只處理加性雜訊。

    品質與一致性的取捨

    WZ-iMF 指標最好，半群損失路徑最一致。有沒有一個損失能同時做到？

    有限 N 的代價

    大步只看得到 N 個係數，兩個半步看到的資訊比較多，所以蒸餾損失不會降到零。N 是需要調整的超參數。

    路徑式應用

    Feynman–Kac 校正、獎勵對齊與長時間分子動力學都需要強解，目前只有初步示範。
