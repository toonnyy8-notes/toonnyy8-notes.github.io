No. 119 Latent On-Policy Self-Distillation（LOPD）
    No. 119 · 互動教學 · arXiv 2608.13040 · 2026

    LOPD：讓自蒸餾老師的特權脈絡可以訓練

    這篇論文從過去的成功解題紀錄找出相似的幾筆，轉成一串數字放進老師的輸入，並用最後的成績限制老師不要變得和學生一樣。

    Guibin Zhang、Jiayang Lyu、Ran Sun、Xinlei Yu、Haoyu Zhao、Qibing Ren、Shuicheng Yan（2026）〈Latent On-Policy Self-Distillation〉

    01 · 自蒸餾

    自蒸餾（self-distillation）：同一個語言模型扮演兩個角色（這是 OPSD 的做法；LOPD 的老師權重是凍結的，見 06）。學生只看任務，自己寫出回答；老師多看一段額外資訊，在學生寫出的每個位置給出「下一個詞是什麼」的機率，學生學著讓自己的機率接近老師。詳見 03。

    02 · 可訓練的額外資訊

    LOPD 讓這段額外資訊可以訓練：從過去成功的解題紀錄中找出 3 筆最相似的，轉成 96 組數字（向量，不是文字）放進老師的輸入。老師的權重在訓練中不更新，只有產生這些數字的模組與學生在學。詳見 05、06。

    03 · 結果與強度

    論文報告：在工具使用與程式生成共 10 組比較中，每組評測題目的彙總分數都是 LOPD 最高；但程式題的差距多半只有 1–3 題，且論文沒有多次重複訓練的差異範圍。詳見 12。

    01 · 下一個 token

    語言模型在每個位置輸出下一個 token 的分布

    語言模型把文字切成 token（詞或詞的片段），所有可能的 token 組成詞表 $\mathcal V$。給定前面的文字，模型對詞表中每個 token $v$ 輸出一個未正規化的分數 $z_v$，稱為 logit。softmax 把 logit 轉成機率：$p(v)=e^{z_v}/\sum_{u\in\mathcal V}e^{z_u}$，所有機率相加為 1。$\log p(v)$ 稱為該 token 的 log 機率，機率越小越負。

    生成文字時，模型依這個分布抽出下一個 token，接到前文後再預測下一個，如此反覆。溫度、top-k、top-p 是改變抽取方式的設定（例如 top-k 只在機率最高的 k 個 token 中抽）；本論文的設定值列在 15。

    02 · 軌跡與獎勵

    多輪代理人的一條軌跡只在結尾得到一個獎勵

    論文研究的是多輪代理人（agent）：收到任務 $x$ 後，與環境（例如一組可呼叫的工具 API）來回互動。第 $t$ 輪時，代理人看到的狀態 $s_t=(x,o_{\le t},a_{\lt t})$ 包含任務、到目前為止的觀察 $o_{\le t}$ 與之前的動作 $a_{\lt t}$（§3.1）。這一輪的動作 $a_t=(a_{t,1},\dots,a_{t,L_t})$ 是一串 token，長度 $L_t$；$a_{t,n}$ 是第 $n$ 個 token，$a_{t,\lt n}$ 是它之前的前綴（prefix）。所有輪次串起來是一條軌跡 $\tau$，共 $|\tau|$ 輪。

    軌跡結束後，驗證器給一個結果獎勵 $r(\tau)\in[0,1]$：工具類資料集 EnvScaler 給完成子任務的比例，程式類資料集 TACO 全部測試通過給 1、否則 0（App. B.2）。只用這個數字訓練模型的做法稱為 RLVR（reinforcement learning with verifiable rewards）：一條可能有上千個 token 的軌跡只得到一個數，哪些 token 該負責並不清楚。論文的 RLVR 基線是 GRPO：同一題取 G 條軌跡，以每條獎勵相對於組內平均的高低加權更新（App. B.1，G = 4）。

    $a_{t,n}$、$a_{t,\lt n}$、$L_t$；第 $t$ 輪第 $n$ 個 token、它之前的前綴、該輪動作長度
    $\tau$、$r(\tau)$；軌跡、結果獎勵（0 到 1）

    03 · OPSD

    OPSD 讓同一個模型帶著特權脈絡當老師

    知識蒸餾讓學生模型學習老師模型在每個 token 上的機率分布，而不只學一個正確答案；每個 token 都有訊號，比 RLVR 的單一獎勵密集。On-policy 指監督發生在學生自己取樣出的軌跡上；off-policy 指學生模仿別人寫好的軌跡。前者讓訓練時看到的狀態與推論時一致（§1）。

    比較兩個分布用 KL divergence：$D_{KL}(p\|q)=\sum_v p(v)\log\frac{p(v)}{q(v)}\ge0$，兩分布相同時為 0。它不對稱。學生分布寫作 $p^S$、老師分布寫作 $p^T$ 時，reverse KL $D_{KL}(p^S\|p^T)$ 對「學生機率高、老師機率低」的 token 懲罰較重；forward KL $D_{KL}(p^T\|p^S)$ 對「老師機率高、學生機率低」的 token 懲罰較重。stop-gradient $\mathrm{sg}[\cdot]$ 表示前向照常計算，反向傳播時不讓梯度穿過。

    On-policy 自蒸餾（OPSD）的老師不是另一個更大的模型，而是同一個模型（OPSD 的情形；LOPD 的老師不同，見 06）多看一段特權脈絡（privileged context）$c$：學生推論時看不到的資訊。學生 $\pi^S_\theta$（參數 $\theta$）取樣軌跡：

    $$a_t\sim\pi^S_\theta(\cdot\mid s_t),\qquad \tau=(s_1,a_1,\dots,s_{|\tau|},a_{|\tau|})\sim\pi^S_\theta(\cdot\mid x)$$
    Eq. 1

    既有方法以設計者寫死的規則 $\Phi_{fix}$ 從經驗來源 $E$（答案、推理軌跡、回饋、示範或檢索到的軌跡）產生脈絡，老師就是同一模型（OPSD 的情形；LOPD 的老師不同，見 06）看著這段脈絡：

    $$c_{fix}=\Phi_{fix}(x,E),\qquad \pi^T_\theta(\cdot\mid s_t,c_{fix})=\pi_\theta(\cdot\mid[s_t;c_{fix}])$$
    Eq. 2

    損失在學生走過的每個前綴上比較兩者，$D$ 為某個 token 層級的 divergence：

    $$\begin{aligned}\mathcal L_{OPSD}(\theta)=\mathbb E_{\tau\sim\pi^S_\theta}\Big[\textstyle\sum_{t=1}^{|\tau|}\sum_{n=1}^{L_t}D\big(&\mathrm{sg}[\pi^T_\theta(\cdot\mid s_t,c_{fix},a_{t,\lt n})]\\&\big\|\,\pi^S_\theta(\cdot\mid s_t,a_{t,\lt n})\big)\Big]\end{aligned}$$
    Eq. 3

    論文比較的基線各自代表一種 $c_{fix}$（§4.1、App. B.1）。它們也各自保留原論文的 KL 方向與老師形式，所以 §4.1「只差在特權脈絡與蒸餾損失」並不是只差一項。

    OPSD 的結構可以這樣總結：學生 $\pi^S_\theta$ 只看狀態 $s_t=(x,o_{\le t},a_{\lt t})$，並自己取樣軌跡；老師是同一個模型（OPSD 的情形；LOPD 的老師不同，見 06）多看特權脈絡 $c_{fix}=\Phi_{fix}(x,E)$，這段脈絡可能是答案、軌跡、回饋或技能，由設計者的固定規則產生；老師在學生走過的每個 prefix $(t,n)$ 給出下一 token 分布，損失是兩者的 token 層級 divergence，老師一側 stop-gradient（Eq. 2–3）。推論時只用學生，不給脈絡。

    檢查理解

    OPSD 的老師與學生各看到什麼？監督在哪些狀態上計算？推論時用誰？

    04 · 蒸餾損失

    蒸餾損失只比較老師的前 M 名與合併後的尾部

    LOPD 的老師也看一段脈絡 $c$，它的構造在 05–06 說明；這裡先把老師寫成 $\pi^T(\cdot\mid s_t,c,a_{t,\lt n})$。在第 $t$ 輪、第 $n$ 個 token 的前綴上，學生與老師的下一 token 分布是

    $$p^S_{t,n}=\pi^S_\theta(\cdot\mid s_t,a_{t,\lt n}),\qquad p^T_{t,n}=\pi^T(\cdot\mid s_t,c,a_{t,\lt n})$$
    Eq. 8

    完整詞表有十萬個以上的 token，逐一比較太貴。論文取老師機率最高的 $M$ 個 token 為支撐集 $\mathcal V^M_{t,n}$，其餘合併成一個尾部事件 $\perp$；學生也用同一個支撐集（Eq. 9）：

    $$\tilde p_{t,n}(v)=\begin{cases}p_{t,n}(v), & v\in\mathcal V^M_{t,n}\\ 1-\sum_{u\in\mathcal V^M_{t,n}}p_{t,n}(u), & v=\perp\end{cases}$$
    Eq. 9

    蒸餾損失在學生自己的軌跡上，對有監督的動作 token 取平均；$\omega_{t,n}\in\{0,1\}$ 是標記「這個 token 要監督」的遮罩，$\mathcal D$ 是任務分布：

    $$\begin{aligned}\mathcal L_{distill}(\theta,\phi)=\;&\mathbb E_{x\sim\mathcal D}\,\mathbb E_{\tau\sim\pi^S_\theta(\cdot\mid x)}\\&\Big[\frac{\sum_{t,n}\omega_{t,n}D_{KL}(\tilde p^S_{t,n}\|\tilde p^T_{t,n})}{\sum_{t,n}\omega_{t,n}}\Big]\end{aligned}$$
    Eq. 10

    學生寫在前面，是 reverse KL；作者的理由是「so that the student concentrates on teacher-supported behavior」（§3.3）。預設 $M=20$（§4.1）。取樣時的 top-k 也是 20（Table 4），但那是生成時的設定，與蒸餾的截斷是兩回事。$\phi$ 是產生脈絡的模組的參數，下一章定義。

    合併尾部有一個後果 本頁推導：把尾部多個 token 合併成一項，只會丟失可區分的資訊，KL 不會因此變大（log-sum 不等式）。所以截斷後的 KL 不大於完整 KL，$M$ 越大、分得越細，截斷 KL 不會變小。學生在尾部內如何分配機率完全不影響損失，只有尾部總量受監督。下面的 C1 用 8 個 token 演示。

    05 · Composer

    Composer 從檢索到的經驗產生 96 個連續向量

    LOPD 把固定規則 $\Phi_{fix}$ 換成有參數的 $\Phi_\phi$，稱為 composer，輸出一串連續向量 token $\langle e_i\rangle$，以 ⊕ 表示串接：

    $$c_\phi=\Phi_\phi(x,E)=\langle e_1\rangle\oplus\langle e_2\rangle\oplus\cdots\oplus\langle e_K\rangle$$
    Eq. 4

    Eq. 4 照原文只寫 $K$ 個 token，並稱 $K$ 為「每筆經驗的 token 數」；下面的 Eq. 7 則有 $J\cdot K$ 個。此處 $K$ 為單筆軌跡的向量數；串接後共 $J\cdot K=96$（Eq. 7）；$J$ 即 $n_{ret}$。兩式不一致，實作以 Eq. 7 為準。OPSD 的不對稱保留：老師看 $c_\phi$，學生只看 $s_t$。

    經驗庫與檢索（§3.2、App. A.3）。經驗庫只存訓練集上的成功 rollout（工具類超過 reward 門檻、程式類通過全部測試），每筆是任務描述加上省略冗長觀察的「動作—結果」紀錄。檢索器 Qwen3-Embedding-8B 把文字轉成 4,096 維的單位向量：文件端編碼「任務＋軌跡」，查詢端只編碼任務。兩個單位向量的內積稱為 cosine 相似度，越大越相似；以 FAISS 精確搜尋取最高的 $J$ 筆，記為 $E=\{m_j\}_{j=1}^J$（Eq. 15–16）。預設 $J=3$；附錄與 §4.3 把同一個量寫成 $n_{ret}$。

    編碼。LoRA 是一種微調方式：凍結原本的權重矩陣，只訓練加在旁邊的一個低秩增量。encoder $\mathrm{Enc}_\psi$ 是凍結的 backbone 加上 LoRA（rank 8、α = 16，套在每個 block 的七個線性投影上，App. A.1），參數記為 $\psi$。它把「當前任務＋第 $j$ 筆經驗」編成 $T_j$ 個 $d$ 維隱藏向量（Eq. 5）。

    $$\begin{aligned}H_j&=\mathrm{Enc}_\psi(x,m_j)\in\mathbb R^{T_j\times d}\\E_j&=\mathrm{Comp}_\chi(H_j;Q_\chi)=[\langle e_{j,1}\rangle,\dots,\langle e_{j,K}\rangle]\in\mathbb R^{K\times d}\end{aligned}$$
    Eq. 5、6

    壓縮。cross-attention：每個 query 向量對一組 key/value 向量，依相似度取 value 的加權平均。QFormer 式壓縮器用固定數量 $K$ 個可學習的 query $Q_\chi$ 對變長的 $H_j$ 做 cross-attention，所以不論經驗多長，輸出都是 $K$ 個向量。論文的壓縮器有 8 層、各層共用參數，FFN 倍率 4，參數記為 $\chi$；composer 的全部可訓練參數是 $\phi=(\psi,\chi)$。

    串接。$J$ 筆經驗各 $K$ 個向量串成老師的脈絡。這裡的 $\bar\theta$ 是訓練開始前的 base 模型權重，訓練中不更新：

    $$\begin{aligned}c_\phi(x,E)&=\textstyle\bigoplus_{j=1}^{J}\big(\langle e_{j,1}\rangle\oplus\cdots\oplus\langle e_{j,K}\rangle\big)\\\pi^T_{\bar\theta,\phi}(\cdot\mid s,c_\phi)&=\pi_{\bar\theta}(\cdot\mid[s;c_\phi])\end{aligned}$$
    Eq. 7

    $$\mathcal L_{init}(\phi)=-\mathbb E_{(x,y^\star)\sim D_{exp},\,E=\mathrm{Ret}(x)}\big[\log\pi_{\bar\theta}(y^\star\mid s,c_\phi(x,E))\big]$$

    07 · 退化

    只最小化蒸餾損失時，老師分布可以移向學生來降低損失

    因為梯度會穿過老師回到 composer，composer 有兩種方式降低 $\mathcal L_{distill}$：讓學生變好，或讓老師變得像學生。作者寫：「an unconstrained composer can instead minimize Equation (10) by moving $p^T$ toward $p^S$, yielding uninformative latent context without improving the student」（§3.3）。論文稱這種結果為退化（collapse）。

    以下用一個理想化模型說明這句話 本頁推導：只看一個前綴、完整詞表；學生 logits $z$、老師 logits $u$ 可以自由移動，$p=\mathrm{softmax}(z)$、$q=\mathrm{softmax}(u)$，$\mathrm{KL}=\sum_v p_v\log(p_v/q_v)$。對兩組 logits 的偏微分是

    $$\frac{\partial\,\mathrm{KL}}{\partial u_k}=q_k-p_k,\qquad \frac{\partial\,\mathrm{KL}}{\partial z_k}=p_k\big[(\log p_k-\log q_k)-\mathrm{KL}\big]$$
    本頁推導

    對 $u$ 做梯度下降，每一步都讓 $q$ 往 $p$ 移動，最小值在 $q=p$。在此理想化模型中，損失梯度本身不含「脈絡是否帶有資訊」的訊號；真實系統中梯度還要經過 $\partial u/\partial\phi$（96 個向量與凍結網路），學生也同時移向老師，損失也是 top-M 版本。下面的 C3-lite 只讓老師移動、學生固定。

    08 · Privileged margin

    Privileged margin 以結果獎勵加權老師在取樣 token 上的優勢

    作者用兩種方式防止退化：一是 06 的冷啟動，讓 composer 一開始就有資訊；二是把結果獎勵接進來（§3.3）。對每個有監督的 token，定義老師相對學生的 privilege：

    $$\delta_{t,n}(\phi)=\log\pi^T_{\bar\theta,\phi}(a_{t,n}\mid s_t,c_\phi,a_{t,\lt n})-\mathrm{sg}\big[\log\pi^S_\theta(a_{t,n}\mid s_t,a_{t,\lt n})\big]$$
    Eq. 11

    $a_{t,n}$ 是學生實際取樣到的 token；學生那一項加了 stop-gradient，所以 δ 只訓練 composer。兩個 log 機率在 forward 時都已算好，只需取出對應的值。把結果獎勵換成 $A(\tau)=2r(\tau)-1\in[-1,1]$（獎勵 0.5 對應 0），再對軌跡上的 δ 加權平均：

    $$\begin{aligned}\Delta(\phi)&=\mathbb E_\tau\Big[\frac{\sum_{t,n}\omega_{t,n}A(\tau)\,\delta_{t,n}(\phi)}{\sum_{t,n}\omega_{t,n}}\Big],\\A(\tau)&=2r(\tau)-1\in[-1,1]\end{aligned}$$
    Eq. 12

    Eq. 12 是逐軌跡比值再取期望；Alg. 1 第 12 行則寫「masked tokens 上的加權平均」，batch 內怎麼聚合沒有說清楚。成功軌跡（$A>0$）上老師給學生的 token 較高機率會使 Δ 增加，失敗軌跡上則使 Δ 減少。

    為了看清 Δ 何時為正，先定義一個量 本頁推導：$Q(a)$ 是「在這個前綴選了 token $a$ 之後，整條軌跡 $A$ 的平均值」，$\bar Q=\sum_a p^S(a)Q(a)$ 是它在學生分布下的平均。若動作恰好從 δ 中的學生分布 $p^S$ 取樣，δ 的期望可以逐步寫出：

    $$\mathbb E_{a\sim p^S}[\delta]=\sum_a p^S(a)\big(\log p^T(a)-\log p^S(a)\big)=-\sum_a p^S(a)\log\frac{p^S(a)}{p^T(a)}=-D_{KL}(p^S\|p^T)\le0$$
    本頁推導

    這是期望值；單一批次的取樣平均可以為正。論文取樣用溫度 0.7、top-p 0.95、top-k 20（Table 4），計算 $p^S$ 時的溫度沒有說明，所以這個等式在論文設定下不一定成立。同樣的方法把一個前綴對 Δ 分子的期望貢獻拆成兩項：

    $$c=\sum_a p^S(a)Q(a)\log\frac{p^T(a)}{p^S(a)}=-\bar Q\,D_{KL}(p^S\|p^T)+\sum_a p^S(a)\big(Q(a)-\bar Q\big)\log\frac{p^T(a)}{p^S(a)}$$
    本頁推導

    第一項在 $\bar Q>0$（平均獎勵過半）時是負的，與 margin 作對；在 $\bar Q<0$ 時是正的，反而獎勵老師與學生的差距。第二項（共變項）才表示「老師在導向較高獎勵的 token 上給更高機率」。作為參考量：Table 3 的測試集平均獎勵換成 $2r-1$，未訓練模型是 $2(0.486)-1=-0.028$，LOPD 學生是 $2(0.637)-1=0.274$；這是測試集代理值，不是訓練 rollout 的 $\bar Q$，而 EnvScaler 的 $r$ 是完成子任務比例，不是成功率。

    09 · 對偶更新

    對偶變數 β 在 Δ 低於 m 時加大懲罰

    LOPD 要求 Δ 至少達到一個門檻 $m$（margin）。這是一個受限最佳化問題：在約束 $g(\phi)=m-\Delta(\phi)\le0$ 下最小化損失。標準做法是加上一個對偶變數 $\beta\ge0$，把約束乘上 β 加進目標，稱為 Lagrangian；β 由「約束違反多少」決定：違反時 β 增加、使懲罰變重；滿足時 β 減少，但不低於 0（$[\cdot]_+$ 表示負值截成 0，稱為投影）。約束有餘裕時 β 會降到 0、懲罰消失，這個性質稱為互補鬆弛。完整目標是

    $$\begin{aligned}\min_{\theta,\phi}\max_{\beta\ge0}\ &\mathcal L_{distill}(\theta,\phi)+\beta\big(m-\Delta(\phi)\big)\\&+\lambda\big\|c_\phi-\mathrm{sg}[c_{\phi_0}]\big\|_2^2\end{aligned}$$
    Eq. 13

    最後一項是 anchor：懲罰 latent 脈絡偏離冷啟動時的 $c_{\phi_0}$，權重 $\lambda$；$c_{\phi_0}$ 每個任務先快取，不需要額外 forward。預設 $m=0.05$（§4.1）、$\lambda=0.2$、對偶步長 $\eta_\beta=0.5$、composer 學習率 $10^{-5}$（Table 4）。Alg. 1 的流程如下。

    本頁推導 β 項對 φ 的梯度是 $-\beta\nabla_\phi\Delta=-\beta\,\mathbb E[A\,\nabla_\phi\log\pi^T(a_{t,n}\mid\cdot)]$（遮罩平均）。這與強化學習中 REINFORCE 的梯度形式相同（本頁只用到它的形式：以樣本的 log 機率梯度乘上獎勵），樣本來自學生而不是老師，沒有重要性權重。β 的變化很慢：Δ 停在 0 時每步只增加 $0.5\times0.05=0.025$。若每 32 rollouts（App. B.1）做一次對偶更新（本頁推論，論文未寫明），Fig. 4 的 1,600 rollouts 是 50 步，Δ 一直為 0 時 β = 1.25；這是 Δ = 0 的情形，不是上限，Δ 為負時每步增加 $0.5(m-\Delta)>0.025$。

    對偶更新可以這樣總結：Eq. 13 為 $\min_{\theta,\phi}\max_{\beta\ge0}\mathcal L_{distill}+\beta(m-\Delta)+\lambda\|c_\phi-\mathrm{sg}[c_{\phi_0}]\|^2$；β 初值 0，$\beta\leftarrow[\beta+\eta_\beta(m-\Delta)]_+$；$m=0.05$、$\eta_\beta=0.5$、$\lambda=0.2$（§4.1、Table 4）。Δ<m 時 β 增加，Δ>m 時 β 降到 0 為止。本頁推導 β 項對 φ 的梯度是以學生樣本、無重要性權重的 REINFORCE 形式 $-\beta\mathbb E[A\nabla_\phi\log\pi^T(a_{t,n})]$；Δ 停在 0 時 β 每步只增加 0.025。

    檢查理解

    常見錯誤

    1. 把老師當成與學生同權重。LOPD 的老師是凍結的 θ̄ 加 latent 脈絡。
    2. 對老師加 stop-gradient。Eq. 10 不加，否則 composer 收不到蒸餾梯度。
    3. 用學生的前 M 名當支撐集。Eq. 9 用老師的前 M 名。
    4. 把蒸餾的 M = 20 與取樣的 top-k = 20 混為一談。
    5. 用 in-place 賦值替換佔位 embedding。須用 torch.cat，autograd 才追得到。
    6. 老師主 forward 忘了關掉 encoder LoRA。
    7. 以為 m = 0 等於「沒有約束」。照 Eq. 13 字面仍有 Δ ≥ 0，但退化點 Δ = 0 滿足它，所以 m = 0 擋不住退化；論文沒有說明 m = 0 的實作是關掉 β 還是把 m 設 0。

    研究脈絡

    LOPD 接在幾條脈絡之後。DAgger（2010）提出在學生自己走到的狀態上向老師求監督；知識蒸餾（2015）讓學生學老師的完整分布；context distillation（2022）讓同一個模型把「看過額外脈絡時的行為」蒸餾回不看脈絡的自己；MiniLLM（2023）把 on-policy 蒸餾用在大型語言模型。GRPO（2024）是只用結果獎勵的基線。連續 latent token 的形式來自 latent 推理（Coconut，2024）與 latent 記憶（MemGen，2025）。2026 年的 OPSD 家族（OPSD、SDFT、SDPO、Skill-SD）各自指定一種特權脈絡；RLCSD 指出特權脈絡造成的風格偏移。每張卡片連到對應的研究筆記。
