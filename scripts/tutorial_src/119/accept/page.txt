 LOPD：讓自蒸餾老師的特權脈絡可以訓練

 這篇論文從過去的成功解題紀錄找出相似的幾筆，轉成一串數字放進老師的輸入，並用最後的成績限制老師不要變得和學生一樣。

 Guibin Zhang、Jiayang Lyu、Ran Sun、Xinlei Yu、Haoyu Zhao、Qibing Ren、Shuicheng Yan（2026）〈Latent On-Policy Self-Distillation〉

 01 · 自蒸餾自蒸餾（self-distillation）：同一個語言模型扮演兩個角色（這是 OPSD 的做法；LOPD 的老師權重是凍結的，見 06）。學生只看任務，自己寫出回答；老師多看一段額外資訊，在學生寫出的每個位置給出「下一個詞是什麼」的機率，學生學著讓自己的機率接近老師。詳見 03。

 02 · 可訓練的額外資訊LOPD 讓這段額外資訊可以訓練：從過去成功的解題紀錄中找出 3 筆最相似的，轉成 96 組數字（向量，不是文字）放進老師的輸入。老師的權重在訓練中不更新，只有產生這些數字的模組與學生在學。詳見 05、06。

 03 · 結果與強度論文報告：在工具使用與程式生成共 10 組比較中，每組評測題目的彙總分數都是 LOPD 最高；但程式題的差距多半只有 1–3 題，且論文沒有多次重複訓練的差異範圍。詳見 12。

 01 · 下一個 token

 語言模型在每個位置輸出下一個 token 的分布

 語言模型把文字切成 token（詞或詞的片段），所有可能的 token 組成詞表 V $\mathcal V$ 。給定前面的文字，模型對詞表中每個 token v $v$ 輸出一個未正規化的分數 zv $z_v$ ​，稱為 logit。softmax 把 logit 轉成機率：p(v)=ezv/∑u∈Vezu $p(v)=e^{z_v}/\sum_{u\in\mathcal V}e^{z_u}$ ​/∑u∈V​ezu​，所有機率相加為 1。log⁡p(v) $\log p(v)$ 稱為該 token 的 log 機率，機率越小越負。

 生成文字時，模型依這個分布抽出下一個 token，接到前文後再預測下一個，如此反覆。溫度、top-k、top-p 是改變抽取方式的設定（例如 top-k 只在機率最高的 k 個 token 中抽）；本論文的設定值列在 15。

 02 · 軌跡與獎勵

 多輪代理人的一條軌跡只在結尾得到一個獎勵

 論文研究的是多輪代理人（agent）：收到任務 x $x$ 後，與環境（例如一組可呼叫的工具 API）來回互動。第 t $t$ 輪時，代理人看到的狀態 st=(x,o≤t,a<t) $s_t=(x,o_{\le t},a_{\lt t})$ ​=(x,o≤t​,a<t​) 包含任務、到目前為止的觀察 o≤t $o_{\le t}$ ​ 與之前的動作 a<t $a_{\lt t}$ ​（§3.1）。這一輪的動作 at=(at,1,…,at,Lt) $a_t=(a_{t,1},\dots,a_{t,L_t})$ ​=(at,1​,…,at,Lt​​) 是一串 token，長度 Lt $L_t$ ​；at,n $a_{t,n}$ ​ 是第 n $n$ 個 token，at,<n $a_{t,\lt n}$ ​ 是它之前的前綴（prefix）。所有輪次串起來是一條軌跡 τ $\tau$ ，共 ∣τ∣ $|\tau|$ 輪。

 軌跡結束後，驗證器給一個結果獎勵 r(τ)∈[0,1] $r(\tau)\in[0,1]$ ：工具類資料集 EnvScaler 給完成子任務的比例，程式類資料集 TACO 全部測試通過給 1、否則 0（App. B.2）。只用這個數字訓練模型的做法稱為 RLVR（reinforcement learning with verifiable rewards）：一條可能有上千個 token 的軌跡只得到一個數，哪些 token 該負責並不清楚。論文的 RLVR 基線是 GRPO：同一題取 G 條軌跡，以每條獎勵相對於組內平均的高低加權更新（App. B.1，G = 4）。

 03 · OPSD

 OPSD 讓同一個模型帶著特權脈絡當老師

 知識蒸餾讓學生模型學習老師模型在每個 token 上的機率分布，而不只學一個正確答案；每個 token 都有訊號，比 RLVR 的單一獎勵密集。On-policy 指監督發生在學生自己取樣出的軌跡上；off-policy 指學生模仿別人寫好的軌跡。前者讓訓練時看到的狀態與推論時一致（§1）。

 把老師當成與學生同權重。LOPD 的老師是凍結的 θ̄ 加 latent 脈絡。

 16 · 研究脈絡

 研究脈絡

 LOPD 接在幾條脈絡之後。DAgger（2010）提出在學生自己走到的狀態上向老師求監督；知識蒸餾（2015）讓學生學老師的完整分布；context distillation（2022）讓同一個模型把「看過額外脈絡時的行為」蒸餾回不看脈絡的自己；MiniLLM（2023）把 on-policy 蒸餾用在大型語言模型。GRPO（2024）是只用結果獎勵的基線。連續 latent token 的形式來自 latent 推理（Coconut，2024）與 latent 記憶（MemGen，2025）。2026 年的 OPSD 家族（OPSD、SDFT、SDPO、Skill-SD）各自指定一種特權脈絡；RLCSD 指出特權脈絡造成的風格偏移。每張卡片連到對應的研究筆記。
