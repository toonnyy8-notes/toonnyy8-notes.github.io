# 119 設計審查（教學法＋可建置性）

1. **P0** 靜態圖／SVG 縮放。6.4「圖寬＝容器寬，圖上文字 12–13px 不縮放」，但 6.2 的 `figHero/figOPSD/figSlots/figAblation` 沒有寫重畫機制。viewBox 縮放會讓 390px 文字低於 12px。修正：各 fig 函式接收容器寬度，以 ResizeObserver（debounce）重畫；斷點版面（hero 上下堆疊、F2 的 3×32 細格）寫成明確分支。

2. **P0** 公式響應式。「Eq. 3、10、12、13 在 <600px 用 aligned 拆兩行」沒說明怎麼切換。KaTeX 渲染後無法用 CSS 換行，且 `\tag` 與 aligned 並用有限制。修正：這四式一律寫成 aligned 兩行版（不分斷點），`\tag` 放在 aligned 外層；`.katex-display` 加 `tabindex=0` 與 `role=group`、`aria-label`，鍵盤才能捲動。

3. **P1** S7 過密。600–700 字內要教 min-max、Lagrangian、投影梯度、互補鬆弛、Alg. 1、REINFORCE 形式、q* 不動點、C3、LO7、LO8。對象只有基礎機率與神經網路背景。修正：拆成 07 對偶更新（Eq. 13、Alg. 1、LO7）與 08 理想化不動點（q*、C3、LO8）；REINFORCE 只在符號表標明「本頁僅用其梯度形式」，或刪除。

4. **P1** S6 難度陡升。S5 只有 250–350 字就接 Q(a)、Q̄、共變項分解。Q(a)=E[A|prefix,a] 沒有直觀定義，C2 卻用手動滑桿 r̄(a) 取代。修正：先以一句話說明「Q(a)＝選了 token a 之後的平均 A」，在 C2 前補一行 E[δ]=Σp(log q−log p)=−KL 的逐步推導。「log-sum 不等式」（S3）只列名稱、沒有教，應補一句直觀說明或改述為「合併只會丟失資訊」。

5. **P1** C2 滑桿語意不實。「老師保留多少脈絡資訊 s」實際是 logit 在 log p 與 log q0 之間的線性內插，並不是資訊量，也不是論文的機制，違反字面原則。修正：改為「老師位置 s（0＝等於學生，1＝q₀）」，並在假設列寫明內插式。

6. **P1** S4 過密且字數預算矛盾。550–650 字要容納檢索、LoRA、QFormer、cross-attention（初學者未必學過）、Eq. 5–7、17–18、冷啟動、凍結老師，還要放 LO2、LO3 兩段約 450 字的參考答案。字數目標不可能達成。修正：拆成 04a（檢索與 composer）與 04b（注入、冷啟動、凍結老師）；補 cross-attention 一句定義（query 向 key/value 取加權平均）。LO 長度不計入「長度」欄，或把各章字數改為實際值。

7. **P1** S1 一章塞入 logit、softmax、log 機率、取樣參數三種、7 個軌跡符號、RLVR、GRPO，只有 350–450 字。修正：拆兩節，或把取樣（溫度、top-k、top-p）縮成一句並移到 S12 的設定表。符號表也要折疊到每章末，不要整張置於開頭。

8. **P1** Hero 先用未教過的詞。事實卡 2、3 與 hero 圖標籤使用「連續向量」「reverse KL」「凍結」，但 S1–S4 才教。修正：hero 圖標籤改寫成「老師與學生的分布差異（詳見 03）」；卡片內每個詞附括號定義，或延後到對應章節。

9. **P1** C3 的步驟 ① 概念屬於 S5，卻放在 S7，造成 S5（LO5）只有論述沒有互動。修正：在 S5 放 C3 的精簡版（只有 β=0，一個滑桿「檢視第幾步」），S7 再展開 ②③；或至少在 S5 結尾連結到 C3 ①。

10. **P1** C3 的數值穩定性只靠下限 −30。更新式 u−=g，g 含 β(pQ−qQ̄)，等效步長為 η(1+βQ)。固定 β≤1 時 Q≤0.6 沒問題，但對偶模式 β 在 B 預設可增長到 15（m=0.2 時 60），若日後新增 Q>0 且接近常數的預設，會超過穩定上限 2 並振盪（jitter）。修正：把 b 限制在 [0, 5]（並在讀數標註「上限 5 為本頁保護」），或在規格中記錄穩定條件 η(1+βQ_max)<2，selfTest 加一條斷言。β 縱軸 max(1,maxβ) 在 B（β=15）會壓扁其他曲線，改用 min(max, 5) 並加「超出」標記。

11. **P1** C4 的信賴區間易被誤讀成顯著性檢驗。「基線分數落在區間之內」暗示「無差異」，但兩者在同一批題目上配對評測，真實配對檢定的檢力更高。修正：該行文字改為「單次評測的取樣雜訊範圍；配對差異需要逐題結果，論文未提供」，並在內文先教 SE（一句：N 題、答對率 p̂ 時 SE=√(p̂(1−p̂)/N)）。±1.96 在首次出現前要說明。

12. **P2** 減少動態的規格缺失。6.4 與第 4 節只提「取消 transition」，但 C1–C3 長條與 SVG 更新是否有動畫沒寫。修正：明寫「圖版更新一律無動畫」，或指定 `@media (prefers-reduced-motion)` 下禁用的 transition 清單。

13. **P2** 讀數格式。「截斷 − 完整」在 M=7、8 時為 −0.0000 或 −2e-17，會顯示「-0.0000」。修正：顯示前 `v = Math.abs(v)<5e-5 ? 0 : v`，並以 `toFixed` 後去除 −0。

14. **P2** 用語偏比喻或口語。「尋峰」「涵蓋」（forward／reverse KL 說明）、「尾部桶」（bucket）、「（q 的）拉向學生」（S5）。修正：改為「reverse KL 對學生機率高、老師機率低的 token 懲罰較重」等字面描述；「桶」改「合併後的尾部項」。

15. **P2** 無障礙與裝置。每個 SVG 圖有 `aria-label`，但 C1–C3 的 4–6 個長條讀數沒有 table 或 `<dl>` 等價物，螢幕閱讀器只聽到 debounce 後的一句摘要。修正：圖版下方的讀數框用 `<dl>`／`<table>` 保留完整數值，SVG 設 `role=img` 並與讀數 `aria-describedby` 關聯。核取框、`select`、`details summary` 的觸控區也要列入 ≥44px。
