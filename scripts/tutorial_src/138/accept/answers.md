# GPPO 頁面驗收答案（Goldfish 測試）

**LO1** 答：E_μ[r] = Σ_a μ·(π/μ) = Σ_a π = 1，前提是 μ>0 的地方涵蓋 π>0 的地方。用舊資料可行，因為 E_μ[rA] = E_π[A]，用 μ 抽的樣本乘上 r 就能估計 π 下的期望（頁上 3 token 算例：E_μ[rA] = 0.3 = E_π[A]）。
- 段落：「所以用 μ 抽的樣本乘上 r」
- 信心：high

**LO2** 答：兩項是（1）收益項 1/(1−γ)·L_μ(π)，即代理目標；（2）懲罰項 4ξγ/(1−γ)²·D_TV^max(π‖μ)²，隨 TV 距離的平方增加。
- 段落：「右邊是收益項」
- 信心：high

**LO3** 答：D_TV = ½E_μ|r−1|（Eq. 4），所以 |r−1| 是 2D_TV 的單樣本 MC 估計（忽略常數）。剪裁 r∈[1−ε,1+ε] 等於要求每個樣本 |r−1|≤ε。頁面明說這是「重新詮釋，不是定理」。論文據此指出兩個缺陷：TV 的生成函數二階導數為 0 且對稱；PPO 只限制單樣本估計值，不限制定義 TV 的期望。
- 段落：「是 2DTV 的單樣本 Monte Carlo」
- 信心：high

**LO4** 答：Â>0 時，梯度為 0 的情況是 r>1+ε（此時選到剪裁項）；Â<0 時是 r<1−ε。即正優勢 token 只受上界影響，負優勢 token 只受下界影響。
- 段落：「這時梯度為 0」
- 信心：high（頁面標註為本頁推導）

**LO5** 答：一階泰勒展開後 f'(1)E_μ[r−1] = 0，只剩二次項 D_f ≈ f''(1)/2 · E_μ[(r−1)²]，所以 f''(1)>0 的平滑散度在 r≈1 只差比例常數 f''(1)/2。單一樣本的 f(r) 不一樣：它仍含 f'(1)(r−1) 項，例如 KL 的 −log r 在 r>1 時為負。
- 段落：「單一樣本的 f(r) 仍含」
- 信心：high

**LO6** 答：C_f^Vajda := inf_{0<V≤1} L_f(V)/V²，使 D_TV² ≤ D_f / C_f^Vajda（Eq. 6–7）。其中 L_f(V) = inf_{β∈[0,1−V]} [β f(1+V/β) + (1−β) f(1−V/(1−β))]（Eq. 5）。四個 f 的值（頁面以格點計算，論文未給數值）：TV 1、χ² 4、KL 2、Hellinger 1。
- 段落：「TV 1、χ² 4、KL 2、Hellinger 1」
- 信心：定義 high；數值 medium-high（是頁面自己的計算）

**LO7** 答：前提是 C_f^Vajda > 0。懲罰項為 4ξγ/(C_f(1−γ)²)·D_f^max，對 D_f^max 是一次方（TV 是平方）。它不保證 Eq. 11 單調改進：保證只屬於 Eq. 8 與 Eq. 9 的限制式問題；Eq. 11 是逐樣本硬剪裁，沒有定理支持，所以不保證演算法單調改進。
- 段落：「沒有定理，所以不保證演算法單調改進」
- 信心：high

**LO8** 答：固定 r_min = 0.8，令 δ = f(0.8)，上界由 f(r_max) = δ 決定。校準後四個 MC 區間：TV [0.8, 1.2]、χ² [0.8, 1.2]、Hellinger [0.8, 1.2223]、KL |log r| [0.8, 1.25]（KL 的 |log r| 讀法是頁面推定，論文 δ_KL ≈ 0.22）。只有 11 個不同演算法，因為 TV–MC 與 χ²–MC 在任何 r_min 下都是 [r_min, 2−r_min]，完全相同（Table 1 兩列數字也相同）。
- 段落：「TV–MC 與 χ²–MC 區間相同」
- 信心：區間 high；KL 數值 medium

**LO9** 答：Atomic 的期望是 E_μ[μf(r)] = Σ_a μ²f(r) ≠ D_f，所以不是無偏估計（Binary 也不是）。App. B 只證明二階動差的逐動作貢獻 v_Atom = μ²·v_MC ≤ v_MC（Eq. 58–59），沒有偏差分析。頁面的玩具例（λ = 0.3、χ²）：E[Atomic] = 0.01268，真實 D_f = 0.08360。
- 段落：「只證明二階動差的逐動作貢獻」
- 信心：high

**LO10** 答：DAPO = (KL, MC)，區間 [e^{−δ}, e^{δ}] = [0.8, 1.25]（本頁校準）。DPPO = (TV, Binary)，論文式為 1±δ/μ（以 TV 計）；本頁以 TV2 計校準為 1±δ/(2μ) = 1±0.1/µ，µ = 0.1 時為 [0*, 2.0]。RIPO = (χ², Atomic)，區間 1±√(δ/μ)，µ = 0.1 時為 [0.3675, 1.6325]。
- 段落：「RIPO 為 (χ², Atomic)」
- 信心：DAPO、RIPO high；DPPO medium（取決於 TV 的 ½ 寫法）

**LO11** 答：可行上限是 r ≤ 1/μ（因為 π ≤ 1）。假設把 dual clip [0.5, 10] 疊加上去，KL–Atomic 的上界 e^{δ/μ} 超過 10 的條件是 δ = 0.2231 時 μ < 0.0969，δ = 0.22 時 μ < 0.0955。頁面說明這是假設性疊加，論文沒寫組合方式。
- 段落：「δ = 0.2231 時 µ < 0.0969」
- 信心：算式 high（ln10 的推導）；組合方式本身未知

**LO12** 答：KL–Atomic 數學 41.5 對 GRPO 27.7，相對 +49.82%（+13.8 分）；程式 59.7 對 52.4，相對 +13.93%（+7.3 分）。「所有 Atomic/Binary 格都勝過 GMPO」不成立：χ²–Binary 數學 34.8 < GMPO 35.1；TV–Binary 程式 53.8 < GMPO 54.4。不確定性：論文每格只有一個數字，沒有 seed 數、標準差或信賴區間；Avg@8 是同一模型評測 8 次，不是 8 次獨立訓練。
- 段落：「沒有報告 seed 數、標準差或信賴區間」
- 信心：high

## 初學者可能卡住的地方
1. μ 同時是「舊策略」的符號，也是區間公式裡的機率值；E_μ[·] 是期望，初學者容易混淆。
2. TV 的 ½ 造成兩倍差：同一個 δ = 0.2，用 ½|r−1| 得 [0.6, 1.4]，用 |r−1| 得 [0.8, 1.2]。頁面選後者是推定。
3. Eq. 3 的 min 方向：正負 Â 各對應哪一側被剪裁，容易記反。
4. C_f^Vajda 與 L_f(V) 是 inf 優化，頁面只給結果，沒有計算步驟，初學者無法自己算出 β 或 C_f。
5. 4 × 3 格子表欄位錯位（RIPO 標籤落在 Binary 欄附近），而且 dual clip 疊加是假設，很難分辨哪個區間是論文本身、哪個是推定。
