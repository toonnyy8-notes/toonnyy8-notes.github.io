# 顧問筆記：Bellman Policy Optimization（arXiv 2609.15987v1）

對象：教學設計者（不是讀者）。來源：`src/paper.txt` 全文，含附錄 A.1、A.2、B、C。
標記規則：沒有標記的數字與式子都直接出自論文；〔顧問推導〕是我自己算的或推的，論文沒有寫。
名稱一律照論文拼法：DAPO-Math-17k、GRPO-ClipHigher、GSPO、CISPO、DPPO、Qwen3-30B-A3B-Base、Qwen3-4B-Base。不要「修正」成別的拼法。

一句話定位：論文有兩個部分，強度差很多。
(a) 理論：PMD 的逐狀態更新可以改寫成一個只需要「終端獎勵 R 與起始值 V^µ(x)」的軌跡級平方殘差目標 (18)，並且兩者的最佳解相同（定理 1，嚴格證明）。
(b) 實作：對 (18) 做四步近似後得到損失 (14)，它和 GRPO 的 (5) 只差一處：重要性比率 r = π/µ 換成 min(sg(ω), C)，ω = (1+ϵ−µ)/(1+ϵ−π)。這四步近似沒有任何誤差界，定理 1 不涵蓋 (14)。

## 2. 必須講對的 5 個推導

### 推導 A：PMD 閉式解與 log Z = KL(µ‖π⁺)（式 12、17、20–22）

條件：單一狀態 s，η > 0，µ(·|s) 是機率分佈，A^µ 滿足式 (10)。

1. 問題 (16)：max_π Σ_y π(y)A(y) − (1/η) Σ_y π(y) log(π(y)/µ(y))，約束 Σ_y π(y) = 1。
2. 〔顧問推導〕拉格朗日：對 π(y) 微分得 A(y) − (1/η)(log(π(y)/µ(y)) + 1) − λ = 0，所以 π(y) ∝ µ(y) exp(ηA(y))。目標對 π 嚴格凹，所以解唯一。論文只給結果 (12)，沒寫這兩行。
3. 取對數得 (20)：log π⁺(y_t|s_t) − log µ(y_t|s_t) − ηA^µ(s_t,y_t) + log Z_µ(s_t) = 0。
4. 兩邊對 y_t ∼ µ(·|s_t) 取期望：E_µ[log π⁺ − log µ] = −KL(µ‖π⁺)；E_µ[A^µ] = 0（式 10）；log Z 不依賴 y_t。所以 log Z_µ(s_t) = KL(µ(·|s_t)‖π⁺(·|s_t))，即 (21)。
5. 代回得 (22)：log π⁺ − log µ − ηA^µ + KL(µ‖π⁺) = 0。

必須講清楚的兩點：
- 方向。PMD 的懲罰項是 KL(π‖µ)，殘差裡出現的是 KL(µ‖π)（論文在 §3.2 稱它為 full reverse KL）。兩者不是同一個量，方向相反是推導的結果，不是筆誤。
- 為什麼用 A 不用 Q。用 Q 時解相同，但 E_µ[Q^µ] = V^µ(s_t) ≠ 0，第 4 行會多一項 ηV^µ(s_t)，中間狀態的值就消不掉。〔顧問推導〕
- 〔顧問推導〕一致性檢查：由 Jensen，log E_µ[exp(ηA)] ≥ E_µ[ηA] = 0，和 KL ≥ 0 相符。

### 推導 B：望遠鏡與殘差為零（式 23、24、19）

條件：確定性轉移、中間獎勵為零、無折扣、V^µ(s_{|y|+1}) = R(x,y)。任何一項不成立，(23) 就不成立。

1. (8) 代入 (9)：A^µ(s_t,y_t) = V^µ(s_{t+1}) − V^µ(s_t)。
2. 加總：Σ_{t=1}^{|y|} A^µ(s_t,y_t) = V^µ(s_{|y|+1}) − V^µ(s_1) = R(x,y) − V^µ(x)。
3. (22) 對 t 加總並代入：Σ_t [log π⁺(y_t|s_t) − log µ(y_t|s_t) + KL(µ(·|s_t)‖π⁺(·|s_t))] = η(R(x,y) − V^µ(x))。
4. 即 δ(x,y;π⁺,µ) = 0，其中
   δ(x,y;π,µ) = η(R(x,y) − V^µ(x)) − Σ_{t=1}^{|y|} [log(π(y_t|s_t)/µ(y_t|s_t)) + KL(µ(·|s_t)‖π(·|s_t))]（式 19）。

注意：(24) 是「對每一條 µ 會產生的軌跡」成立，不是只在期望上成立。這是平方殘差目標能取到 0 的原因。
另外 δ(x,y;µ,µ) = η(R(x,y) − V^µ(x))（§3.2 Step 1 用到），因為 π=µ 時對數比與 KL 都是 0。

### 推導 C：必要性（附錄 A.1）

條件：π̂⁺ ∈ Π_µ；ϕ(x) > 0；T_max 有限；目標值有限（所以在可達狀態上 KL(µ‖π̂⁺) < ∞，即 µ 對 π̂⁺ 絕對連續）。

1. 定義 d_π(s,a) = ηA^µ(s,a) − [log π(a|s) − log µ(a|s) + KL(µ(·|s)‖π(·|s))]。則 δ(x,y;π,µ) = Σ_t d_π(s_t,y_t)（式 30）。
2. 最小值是 0（π⁺ 達到，且目標非負）。所以最佳解滿足 δ(x,Y;π̂⁺,µ) = 0，P_µ(·|x)-幾乎必然（式 31）。
3. 對任何 π：Σ_a µ(a|s) d_π(s,a) = η·0 − (−KL(µ‖π)) − KL(µ‖π) = 0。這一步只用式 (10) 和 KL 的定義，和 π 是不是最佳解無關。
4. 設 τ = inf{t ≥ 1 : Y_t = EOS} ∧ T_max，D_t = I{t≤τ} d_{π̂⁺}(S_t,Y_t)，M_n = Σ_{t≤n} D_t。由第 3 行 E[D_t | F_{t−1}] = 0，{M_n} 是鞅。
5. M_{T_max} = δ = 0 幾乎必然，所以 M_n = E[M_{T_max} | F_n] = 0，D_t = M_t − M_{t−1} = 0。
6. 可達狀態 s 與 a ∈ supp µ(·|s) 的事件機率為正，所以 d_{π̂⁺}(s,a) = 0。
7. 和 d_{π⁺}(s,a) = 0 相減：log(π̂⁺(a|s)/π⁺(a|s)) = KL(µ‖π⁺) − KL(µ‖π̂⁺)，右邊不依賴 a。所以 π̂⁺(a|s) = c(s) π⁺(a|s)。
8. 兩者都在 Π_µ 內，在 supp µ(·|s) 外為零，歸一化給 c(s) = 1。

給初學者的替代講法〔顧問推導〕：鞅差兩兩不相關，所以 E[M_{T_max}²] = Σ_t E[D_t²]。左邊是 0，右邊每一項非負，所以每個 E[D_t²] = 0。這比條件期望的寫法好懂，結論相同（有限詞表、有限長度、各量有限時平方可積）。直覺是：一串「平均為零的意外」加起來永遠剛好是零，只可能每一個意外本身都是零。

〔顧問推導〕Π_µ 這個限制不能省：若把 π 在 supp µ 上整體乘以 c < 1、把剩下的質量放到 supp µ 之外，log π 多出 log c，KL(µ‖π) 少掉 log c，d_π 不變，殘差仍為零。所以離開 Π_µ 就有其他零殘差解。實驗用 temperature 1.0、top-p = 1.0、關閉 top-k（附錄 B），softmax 下 µ 是全支撐，這個限制在實驗裡不起作用。

### 推導 D：線性化與 Â（式 25、26）

條件：這是近似，不是等式。

1. L_i(π) = ϕ(x) δ(x,y^i;π,µ)²/(2η)。∇L_i = ϕ(x) (δ/η) ∇δ。
2. ∇δ = −Σ_t ∇[log π(y_t^i|s_t^i) + KL(µ(·|s_t^i)‖π(·|s_t^i))]（µ 固定，η(R−V^µ) 與 log µ 無梯度）。得 (25) 第一行。
3. 線性化：把係數 δ(x,y^i;π,µ)/η 換成它在 π=µ 的值 R(x,y^i) − V^µ(x)。得 (25) 第二行。
4. V^µ(x) 換成 mean{R(x,y^j)}_{j=1}^G（論文稱為不偏估計）；ϕ(x) 取 1/√Var_{y∼P_µ(·|x)}(R(x,y))，再換成 1/std{R(x,y^i)}_{i=1}^G。兩者相乘就是式 (2) 的 Â^i，得 (26)。

必須說明的後果〔顧問推導〕：
- η 從此消失。(14) 裡沒有 η，實驗設定裡也沒有 η。PMD 的「步長」在實作中沒有對應的旋鈕。
- 第 3 行丟掉了 δ 對 π 的依賴。原本 δ 會隨 π 接近 π⁺ 而趨近 0，梯度自動變小；線性化後係數固定，更新不會自己停在 π⁺。所以定理 1 的固定點性質不會傳到 (14)，真正限制步幅的是遮罩 M 與上限 C。
- 在 π=µ 時，∇KL(µ‖π) = −Σ_y µ(y)∇log π(y) = 0，ω = 1，所以每個 rollout batch 的第一次更新就是帶基線的 REINFORCE，和 GRPO 的第一次更新相同。BPO 與 GRPO 的差別只在同一批資料的後續更新（主實驗每批 8 次更新）以及 rollout 引擎與訓練引擎的數值差異上才出現。
- 完整 KL 項的作用〔顧問推導〕：對 softmax logits z，∇_z log π(y) = e_y − π，∇_z KL(µ‖π) = π − µ，兩者相加得 e_y − µ，與當前 π 無關。也就是說 (26) 的方向是「把取樣到的 token 往上推，按 µ 的比例把其他 token 往下拉」。

### 推導 E：二元 KL 恆等式與 ω（式 13、27、28、15；附錄 A.2）

條件：(27) 對二元 KL 是精確等式；把完整 KL 換成二元 KL 才是近似。二元 KL 是完整 KL 的下界：0 ≤ D^bin_KL ≤ D_KL（§2.6，引自 [8]）。

1. 記 p = π(y|s)，q = µ(y|s)。D^bin_KL(µ‖π; y) = q log(q/p) + (1−q) log((1−q)/(1−p))。
2. ∇D^bin_KL = −q ∇log p + ((1−q)/(1−p)) ∇p。
3. 用 ∇p = p ∇log p：∇[log p + D^bin_KL] = (1−q)∇log p + ((1−q)p/(1−p)) ∇log p = ((1−q)/(1−p)) ∇log p。
4. 代入 (26) 得 (28)：∇L_{i,t} ≈ −Â^i ((1−µ)/(1−π)) ∇log π(y_t^i|s_t^i)。
5. π → 1 時係數發散，所以分子分母各加 ϵ：ω_t^i = (1+ϵ−µ(y_t^i|x,y_{<t}^i)) / (1+ϵ−π(y_t^i|x,y_{<t}^i))（式 15）。這一步論文只說是為了數值穩定，沒有推導。
6. 再乘遮罩 M_t^i（式 6 的規則，ω 取代 r）並把 ω 截到 C，得 (14)：L^BPO = −Â^i M_t^i min(sg(ω_t^i), C) log π(y_t^i|x,y_{<t}^i)。

教學時要給的數字〔顧問推導，ϵ = 0.1〕：

| µ(y) = q | π(y) = p | r = p/q | (1−q)/(1−p) | ω (ϵ=0.1) |
|---|---|---|---|---|
| 0.5 | 0.6 | 1.2 | 1.25 | 1.2 |
| 0.01 | 0.02 | 2.0 | 1.0102 | 1.0093 |
| 0.98 | 0.99 | 1.0102 | 2.0 | 1.0909 |
| 0.5 | 0.9 | 1.8 | 5.0 | 3.0 |
| 0 | 1 | 無限大 | 無限大 | 11.0 |
| 1 | 0 | 0 | 0 | 0.0909 |

讀法〔顧問推導〕：
- π=µ 時 r = ω = 1。p > q 時兩者都大於 1，方向一致。
- r 對低機率 token 敏感（0.01→0.02 就是 2 倍），ω 對高機率 token 敏感（0.98→0.99，未平滑時是 2 倍）。這是兩種權重最主要的行為差異，論文本身沒有討論。
- ϵ = 0.1 時 ω 的範圍是 [0.1/1.1, 1.1/0.1] = [0.0909, 11]。
- ω > C = 3 需要 p > (2.2+q)/3，只有 q < 0.8 時才可能發生。
- 二元近似保留了「取樣 token 的 logit 梯度分量 = 1−q」，但其他 token 的分量從 −µ(v) 變成 −(1−q)π(v)/(1−p)，即按 π 而不是按 µ 的比例分配。

## 3. 常見誤讀、不一致、未說明之處

### 3.1 看起來對、但論文沒有證明的說法

1. 「BPO 被證明等價於 PMD」。被證明的是目標 (18)，條件是：精確的 V^µ(x)、對 P_µ 的完整期望、每個 token 的完整詞表 KL、取到精確最小值。實際訓練的損失 (14) 經過線性化、組估計、二元 KL、平滑、遮罩、截斷，沒有任何等價或誤差界。摘要寫的是 "We prove that it has the same unique optimal solution"，其中 it 指 reformulation，不是 BPO loss。
2. 「唯一解」。唯一性的意思是：在 Π_µ 內、在 µ 可達的狀態上、以完成分佈 P(·|x) 相同來計。不可達狀態上 π 可以任意。
3. 「BPO 用 Bellman 方程訓練」。(14) 的計算裡沒有任何 Bellman 備份或值估計。Bellman 方程只在推導 (23) 時用了一次。
4. 「critic-free 是 BPO 的新特性」。GRPO 本來就是 critic-free（§2.3 原文）。BPO 的主張是：從 PMD 出發、不用 critic 也能得到同一個最佳解。
5. 「ω 是另一種重要性比率」。ω 的分子是 µ、分母是 π，和 r = π/µ 的位置相反；它來自 ∇[log π + 二元 KL] 的恆等式 (27)，不是重要性取樣修正。論文稱它 mismatch-correction weight。
6. 「(18) 很便宜」。(19) 每個 token 需要完整詞表的 KL(µ‖π)，即需要 rollout 策略的整個分佈。(14) 只需要取樣 token 的 µ 機率，成本和 GRPO 相同。〔顧問推導〕
7. 「BPO 用 KL 懲罰」。附錄 B：no KL penalty，entropy bonus 係數為 0。KL 只出現在推導裡，化成了 ω。
8. 「BPO 比基線高 3.1–11.0 點」是峰值檢查點的比較：每個方法各自取三個基準平均最高的檢查點（平手取較早者），而挑選用的就是報告成績的同一組 AIME 題目。每十個訓練步評估一次，所以是從約 40 個帶雜訊的評估點取最大值〔顧問推導：400/10〕。沒有報告種子數、誤差線或顯著性檢定。
9. 「最強的基線是 CISPO」只對峰值成立（47.4%）。訓練結束時最強的基線是 DPPO（45.5%，BPO 是 49.4%）。其他三個基線在第 400 步的數值論文沒有給。
10. 「BPO 對超參數不敏感」的證據來自另一個模型：Qwen3-4B-Base、每批 128 個提示 × 16 個回應 = 2048 個回應、4 個 minibatch、最大長度 8192、1000 個訓練步。那裡的準確率約 25%，不能和主實驗的 50.5% 放在同一張圖比較。
11. 主實驗的預設值 ϵ = 0.1、C = 3.0 在消融裡都不是最高：ϵ = 0.05 得 25.8%（ϵ = 0.1 是 25.4%），C = 4.0 得 25.8%（C = 3.0 是 25.4%）。差距 0.4 個百分點，單次訓練下無法判斷是否有意義〔顧問推導：判斷部分〕。ϵ = 0.3 掉到 24.1%，仍比 GRPO-ClipHigher 的 20.5% 高 3.6 點。
12. 「BPO 在三個基準都最高」成立（57.4 / 41.0 / 53.0），但各基準的最強基線不同：AIME24 與 AIME25 是 DPPO（55.8、39.2），AIME26 是 CISPO（50.4）。對各自最強基線的差距是 1.6 / 1.8 / 2.6 點〔顧問推導〕。

## 4. 哪些可以在瀏覽器裡現場示範

### 可以（封閉式或極小計算）

1. **單一狀態的 PMD**。滑桿：η、3–5 個 token 的 µ 與 A（強制 Σµ·A = 0）。顯示 π⁺ ∝ µ·exp(ηA)，並即時顯示 log Z 與 KL(µ‖π⁺) 兩個數字相等。η → 0 時 π⁺ → µ。
2. **兩步二元樹，驗證 δ = 0**。〔顧問推導，已用程式驗算〕詞表 {a,b}，長度 2，µ 處處 0.5，R(aa) = 1，其餘 0，η = 1：
   - V^µ(x) = 0.25，V^µ(a) = 0.5，V^µ(b) = 0。
   - A^µ：起點 a: +0.25、b: −0.25；狀態 a 之後 a: +0.5、b: −0.5；狀態 b 之後皆 0。
   - π⁺(a|x) = 0.6225，log Z = KL = 0.03093；π⁺(a|a) = 0.7311，log Z = KL = 0.12011；π⁺(·|b) = (0.5, 0.5)，log Z = KL = 0。
   - π = π⁺：四條軌跡的 δ 全是 0，L = 0。
   - π = µ：δ = (0.75, −0.25, −0.25, −0.25)，L = 0.09375（ϕ = 1）。
   - π(a|x) = 0.7、π(a|a) = 0.6、π(·|b) = 0.5：δ = (0.12362, −0.47092, 0.17365, 0.17365)，L = 0.03717。

## 5. 先備知識（教學順序）

1. 機率分佈、期望、取樣；對數與 exp；softmax。
2. 語言模型逐 token 生成：π(y_t | x, y_{<t})，一條回應的機率是各步機率的乘積（§2.2 的 P_π）。
3. 強化學習的基本物件：狀態、動作、獎勵、策略；這裡狀態 = 提示 + 已生成的前綴，動作 = 下一個 token，轉移是確定性的，只有終端獎勵。
4. RLVR：驗證器給整條回應一個分數；目標 J(π)（式 1）。
5. rollout 策略 µ 與當前策略 π 的區別，以及兩者為何會不同（同一批資料多次更新、兩個引擎的數值差異；§2.3）。
6. 策略梯度的 log-derivative 形式 ∇log π，基線的概念；stop-gradient（sg）。
7. GRPO：組內標準化優勢（式 2）、重要性比率（式 4）、PPO 式截斷與等價的遮罩寫法（式 3、5、6）。
8. 值函數 V、Q、優勢 A 與 Bellman 方程；在終端獎勵設定下 Q(s_t,y_t) = V(s_{t+1})（式 7–10）。
9. KL 散度：定義、非負、不對稱（KL(π‖µ) 與 KL(µ‖π) 不同）；二元 KL 與它是完整 KL 下界（§2.6）。
10. 帶約束的最佳化與「指數傾斜」解：PMD（式 11、12）、配分函數 Z、步長 η 的角色。
11. 望遠鏡求和。
12. （只在講必要性時需要）條件期望、鞅的直覺：「每一步的期望增量為零」。可用 §2 推導 C 的變異數講法避開測度論。
13. 讀實驗需要：Pass@1 與 Avg@32 的意思（每題取 32 個回應，平均正確率，再對題目平均）、峰值檢查點與終值的差別、百分點與百分比的差別。
