05 · 軌跡殘差

三個代數步驟把 PMD 改寫成軌跡殘差

步驟 1：消去配分函數

把式 (17) 取對數，得到每個狀態、每個 token 都成立的最佳性條件（式 20）：$\log\pi^+(y_t\mid s_t)-\log\mu(y_t\mid s_t)-\eta A^\mu(s_t,y_t)+\log Z_\mu(s_t)=0$。兩邊對 $y_t\sim\mu(\cdot\mid s_t)$ 取期望：$\mathbb E_\mu[\log\pi^+-\log\mu]=-D_{\mathrm{KL}}(\mu\|\pi^+)$；由式 (10)，$\mathbb E_\mu[A^\mu]=0$；$\log Z_\mu$ 與 $y_t$ 無關。所以

$$\log Z_\mu(s_t)=D_{\mathrm{KL}}\big(\mu(\cdot\mid s_t)\,\|\,\pi^+(\cdot\mid s_t)\big)$$
式 (21)

代回得 $\log\pi^+-\log\mu-\eta A^\mu+D_{\mathrm{KL}}(\mu\|\pi^+)=0$（式 22），式中不再有 $Z$。注意方向：PMD 的懲罰是 $D_{\mathrm{KL}}(\pi\|\mu)$，這裡出現的是 $D_{\mathrm{KL}}(\mu\|\pi^+)$（論文 §3.2 稱為 full reverse KL）。兩者是不同的量：PMD 懲罰的是 $D_{\mathrm{KL}}(\pi\|\mu)$，殘差裡的是 $D_{\mathrm{KL}}(\mu\|\pi^+)$；方向相反是推導的結果，不是筆誤。

這一步必須用 $A$ 而不是 $Q$ 本頁推導：若用 $Q$，$\mathbb E_\mu[Q^\mu]=V^\mu(s_t)\neq0$，得到 $\log Z_Q=D_{\mathrm{KL}}(\mu\|\pi^+)+\eta V^\mu(s_t)$，中間狀態的價值留在式子裡消不掉（W1 的最後一列讀數）。一致性檢查 本頁推導：Jensen 不等式給 $\log\mathbb E_\mu[e^{\eta A}]\ge\eta\,\mathbb E_\mu[A]=0$，與 KL ≥ 0 相符。

步驟 2：逐項相消（telescoping sum）

由第 03 章，$A^\mu(s_t,y_t)=V^\mu(s_{t+1})-V^\mu(s_t)$。沿一條回應相加，中間項兩兩相消，只剩終點與起點：

$$\sum_{t=1}^{\lvert y\rvert}A^\mu(s_t,y_t)=V^\mu(s_{\lvert y\rvert+1})-V^\mu(s_1)=R(x,y)-V^\mu(x)$$
式 (23)

這一步需要確定性轉移、中間獎勵為零、沒有折扣三個條件；任何一項不成立，式 (23) 就不成立。

步驟 3：殘差與目標

把式 (22) 沿軌跡加總並代入式 (23)，對 $\mu$ 可能產生的每一條軌跡都得到 $\delta(x,y;\pi^+,\mu)=0$（式 24），其中軌跡殘差定義為

$$\delta(x,y;\pi,\mu)=\eta\big(R(x,y)-V^\mu(x)\big)-\sum_{t=1}^{\lvert y\rvert}\Big[\log\frac{\pi(y_t\mid s_t)}{\mu(y_t\mid s_t)}+D_{\mathrm{KL}}\big(\mu(\cdot\mid s_t)\,\|\,\pi(\cdot\mid s_t)\big)\Big]$$
式 (19)

作者給每個提示一個固定正權重 $\phi(x)$，把殘差平方在 rollout 分佈下的期望當作目標：

$$\min_{\pi\in\Pi_\mu}\ L(\pi)=\mathbb E_{x\sim\mathcal D,\;y\sim P_\mu(\cdot\mid x)}\Big[\phi(x)\,\frac{\delta(x,y;\pi,\mu)^2}{2\eta}\Big]$$
式 (18)

(18) 只需要驗證器給的終端獎勵 $R(x,y)$ 與起始值 $V^\mu(x)=\mathbb E_{y\sim P_\mu}[R]$，後者可以從 rollout 估計；不需要任何中間狀態的價值（§3.1）。因為式 (24) 對每一條軌跡成立（不只在平均上），平方殘差能取到 0，$\pi^+$ 是 (18) 的一個最佳解。另外，$\pi=\mu$ 時對數比與 KL 都是 0，所以 $\delta(x,y;\mu,\mu)=\eta(R(x,y)-V^\mu(x))$。(18) 並不便宜 本頁推導：每個 token 都需要整個詞表上的 $D_{\mathrm{KL}}(\mu\|\pi)$，即 rollout 策略的完整分佈。

softmax 對 logit 的梯度

後面幾章要用到這個基本結果 本頁推導。LLM 以 logit 向量 $z$ 經 softmax 給出 $\pi=\mathrm{softmax}(z)$，$\log\pi(y)=z_y-\log\sum_ve^{z_v}$。對 $z_v$ 微分得 $\partial\log\pi(y)/\partial z_v=\mathbb 1\{v=y\}-\pi_v$，寫成向量是 $\nabla_z\log\pi(y)=e_y-\pi$，$e_y$ 是第 $y$ 個分量為 1、其餘為 0 的 one-hot 向量。3 個 token 的例子 示範值：$z=(1,0,-1)$ 時 $\pi=(0.6652,0.2447,0.0900)$；取樣到 t1 時 $e_y-\pi=(0.3348,-0.2447,-0.0900)$：取樣的 token 被往上推，其他 token 按 $\pi$ 的比例往下拉。同理 $\nabla_zD_{\mathrm{KL}}(\mu\|\pi)=\pi-\mu$；取 $\mu=(0.5,0.3,0.2)$ 時為 $(0.1652,-0.0553,-0.1100)$。兩者相加 $e_y-\mu=(0.5,-0.3,-0.2)$，與目前的 $\pi$ 無關。

由此得到殘差的 logit 形式 本頁推導：若 $\pi(\cdot\mid s)=\mathrm{softmax}(z)$、$\mu(\cdot\mid s)=\mathrm{softmax}(z^\mu)$，則 $\log\pi(y)-\log\mu(y)+D_{\mathrm{KL}}(\mu\|\pi)=(e_y-\mu)\cdot(z-z^\mu)$，log-sum-exp 相消。所以在「每個狀態各自一組 logit」的表格式參數下，$\delta$ 是 logit 的仿射函數，(18) 是最小平方問題。下面的 W2、W3 都用這個形式計算。

案例 I 示範值：詞表只有 a、b，回應恰為 2 個 token，$\mu$ 處處 0.5，只有 aa 的獎勵為 1、其餘為 0，$\eta=1$、$\phi=1$。此時 $V^\mu(x)=0.25$、$V^\mu(a)=0.5$、$V^\mu(b)=0$，$\pi^+=(0.62246,0.73106,0.5)$（依序為 $\pi(a\mid x)$、$\pi(a\mid a)$、$\pi(a\mid b)$）。$\pi=\mu$ 時四條軌跡 aa、ab、ba、bb 的 δ = (0.75, −0.25, −0.25, −0.25)，L = 0.09375；$\pi=\pi^+$ 時 δ 全為 0，L = 0。

06 · 定理 1

定理 1 證明殘差目標與 PMD 有相同的唯一解

定理 1（§3.1）：令 $\phi$ 為任意正權重。(18) 有唯一最佳解，且等於 PMD 解 $\pi^+$。「唯一」與「相等」的意思是：任何解 (18) 的策略 $\hat\pi^+\in\Pi_\mu$，對每個提示 $x$ 都有 $P_{\hat\pi^+}(\cdot\mid x)=P_{\pi^+}(\cdot\mid x)$，即在 $\Pi_\mu$ 內、$\mu$ 可達的狀態上、以完成分佈相同來計。不可達的狀態上 $\pi$ 可以任意。

最佳化範圍：(18) 的 min 取在整個 $\Pi_\mu$ 上，也就是每個狀態各自任意選一個分佈的表格式策略，不受神經網路參數化限制；而且是相對一個固定 $\mu$ 的單一步 PMD。定理 1 沒有保證參數化的 LLM 能表示或到達這個最佳解。

充分性：由式 (24)，而且式 (17) 保持 $\mu$ 的支撐（$\mu$ 為 0 處 $\pi^+$ 也為 0），所以 $\pi^+\in\Pi_\mu$ 取到目標值 0；目標非負，最小值就是 0。

必要性：反過來，任何最佳解都必須等於 $\pi^+$。本頁用變異數的講法說明 本頁推導的講法，結論與 App. A.1 相同，只需要條件期望。

  1. 定義 token 殘差 $d_\pi(s,a)=\eta A^\mu(s,a)-\big[\log\pi(a\mid s)-\log\mu(a\mid s)+D_{\mathrm{KL}}(\mu\|\pi)\big]$，則 $\delta=\sum_td_\pi(s_t,y_t)$（式 30）。記 $D_t=d_\pi(S_t,Y_t)$；回應已結束時 $D_t=0$。
  2. 對任何 $\pi$，每個狀態上 $\sum_a\mu(a\mid s)d_\pi(s,a)=\eta\cdot0+D_{\mathrm{KL}}(\mu\|\pi)-D_{\mathrm{KL}}(\mu\|\pi)=0$。這只用到式 (10) 與 KL 的定義，與 $\pi$ 是不是最佳解無關。
  3. 交叉項為零：$s<t$ 時，$D_s$ 在第 $t$ 步之前就已決定，所以 $\mathbb E[D_sD_t]=\mathbb E\big[D_s\,\mathbb E[D_t\mid S_t]\big]=0$。因此 $\mathbb E_\mu[\delta^2]=\sum_t\mathbb E_\mu[D_t^2]$（詞表與長度有限、各量有限時成立）。
  4. 最小值是 0 且 $\phi>0$，所以最佳解使 $\mathbb E_\mu[\delta^2]=0$（式 31），於是每個 $\mathbb E_\mu[D_t^2]=0$：對每個 $\mu$ 可達的狀態 $s$ 與 $\mu(a\mid s)>0$ 的 $a$，$d_{\hat\pi^+}(s,a)=0$。
  5. 與 $d_{\pi^+}(s,a)=0$ 相減：$\log\frac{\hat\pi^+(a\mid s)}{\pi^+(a\mid s)}=D_{\mathrm{KL}}(\mu\|\pi^+)-D_{\mathrm{KL}}(\mu\|\hat\pi^+)$，右邊與 $a$ 無關，所以 $\hat\pi^+=c(s)\,\pi^+$。兩者都在 $\Pi_\mu$ 內（$\mu$ 的支撐外為 0）並加總為 1，所以 $c(s)=1$。

直覺上：每一步的殘差在 $\mu$ 下平均為零，而且彼此不相關；它們的總和平方的期望等於各自平方的期望之和。總和要對每條軌跡都是 0，只可能每一步的殘差本身都是 0。論文 App. A.1 用鞅（martingale）表述第 3–4 步：部分和每步的期望增量為 0、終值為 0，所以每個部分和都是 0。

$\Pi_\mu$ 這個限制不能省 本頁推導：把 $\pi$ 在 $\mu$ 的支撐上整體乘以 $c<1$，剩下的機率放到支撐外，$\log\pi$ 多出 $\log c$，$D_{\mathrm{KL}}(\mu\|\pi)$ 少掉 $\log c$，$d_\pi$ 不變，殘差仍為 0。實驗以 temperature 1.0、top-p 1.0、無 top-k 取樣（App. B），理論上 softmax 的 $\mu$ 全支撐，這個限制應不起作用 本頁推導，論文未討論；但 rollout 引擎的低精度（例如 bf16）可能讓極小機率下溢為 0，所以只能說「理論上」。

08 · 二元 KL 與 ω

二元 KL 把梯度權重變成互補機率的比值

式 (26) 的完整 KL 需要整個詞表的 logit，計算成本高（§2.6）。論文改用 [8] 的二元 KL：對取樣到的 token $y$，把詞表分成 $\{y\}$ 與其餘全部兩類，只比較這兩類的機率。記 $p=\pi(y\mid s)$、$q=\mu(y\mid s)$：

$$D^{\text{bin}}_{\mathrm{KL}}(\mu\|\pi;y)=q\log\frac qp+(1-q)\log\frac{1-q}{1-p},\qquad 0\le D^{\text{bin}}_{\mathrm{KL}}\le D_{\mathrm{KL}}$$
式 (13)、§2.6

（§2.6 以 $\pi\|\mu$ 的方向定義式 13；§3.2 與 App. A.2 用的是這裡的 $\mu\|\pi$ 方向。）二元 KL 是完整 KL 的下界。App. A.2 證明一個精確的恆等式：$\nabla D^{\text{bin}}=-q\nabla\log p+\frac{1-q}{1-p}\nabla p$，再用 $\nabla p=p\nabla\log p$，

$$\nabla\big[\log p+D^{\text{bin}}_{\mathrm{KL}}(\mu\|\pi;y)\big]=(1-q)\nabla\log p+\frac{(1-q)p}{1-p}\nabla\log p=\frac{1-\mu(y\mid s)}{1-\pi(y\mid s)}\nabla\log\pi(y\mid s)$$
式 (27)(28)

恆等式 (27) 是精確等式；把完整 KL 換成二元 KL 才是近似。換掉之後梯度只剩取樣 token 的 $\nabla\log\pi$，乘上「1 減舊機率」對「1 減新機率」的比 $\frac{1-\mu}{1-\pi}$（式 28）。在 logit 上 本頁推導：這個近似保留取樣 token 的分量 $1-q$，但其他 token 的分量從 $-\mu_v$ 變成 $-(1-q)\pi_v/(1-p)$，按 $\pi$ 而不是按 $\mu$ 的比例分配。若 $\pi$ 與 $\mu$ 只在取樣 token 的機率上不同（其他 token 按比例縮放），兩者完全相同，二元 KL 也等於完整 KL；詞表只有兩個 token 時恆相同，所以 W2、W3 的二元樹看不到這一步的差異。
