09 · 實驗

實驗中 BPO 的峰值平均準確率為 50.5%

設定（§4.1、App. B）：模型 Qwen3-30B-A3B-Base，訓練資料 DAPO-Math-17k 的英文子集。每個 rollout batch 有 256 個提示、每個提示 16 條回應，共 4096 條，分成 8 個 512 條的 minibatch；一個訓練步 = 一個 rollout batch 加 8 次更新，訓練 400 步 = 3200 次更新。最大回應長度 16384 token。所有方法都使用 rollout-router replay（R3），只改 policy loss。BPO 用 ϵ = 0.1、C = 3.0。比較對象是 GRPO-ClipHigher、GSPO、CISPO、DPPO。

10 · 實作

實作設定與常見錯誤

App. B 列出所有方法共用的設定。BPO 專屬的只有 ϵ = 0.1 與 C = 3.0；沒有 KL 懲罰，entropy bonus 係數為 0，損失以 seq-mean-token-mean 聚合（每條回應先對 token 取平均，再對回應取平均），最佳化器為 AdamW、固定學習率 1e−6。

依式 (14)(15)(6) 改寫成 PyTorch 風格的虛擬碼如下（本頁改寫，不是論文提供的程式碼）：

# logp, logp_old: [B, T] 取樣 token 的 log π 與 log μ；adv: [B]；mask_pad: [B, T]
p, q   = logp.exp(), logp_old.exp()
omega  = ((1 + eps - q) / (1 + eps - p)).detach()            # 式 (15)，sg
M      = ~(((adv > 0)[:, None] & (omega > 1 + eps_high)) |
           ((adv < 0)[:, None] & (omega < 1 - eps_low)))      # 式 (6)；BPO 的 eps_low/high 論文未給
loss_t = -adv[:, None] * M * omega.clamp(max=C) * logp        # 式 (14)
loss   = ((loss_t * mask_pad).sum(1) / mask_pad.sum(1)).mean()  # seq-mean-token-mean（App. B）

論文沒有給的設定有三項：BPO 的遮罩門檻 ϵ_low／ϵ_high、組內獎勵全相同（std = 0）時的處理、std 是母體還是樣本標準差。常見錯誤：

  1. 把 (14) 說成「被證明等價於 PMD」：被證明的是 (18)；(14) 經過四步近似，沒有誤差界。
  2. 把 ϵ_low = 0.2、ϵ_high = 0.28 當成 BPO 的論文設定：論文只給 GRPO-ClipHigher 的 [0.8, 1.28]，BPO 的遮罩門檻未公開；App. B 只說除 policy loss 外設定相同。實作時可以自選，但不應當作論文值。
  3. 混用平滑常數 ϵ 與遮罩門檻 ϵ_low／ϵ_high；混用軌跡殘差 δ 與 DPPO 的門檻 δ = 0.1。
  4. 以為 BPO 加了 KL 懲罰：App. B 沒有 KL 懲罰；KL 只在推導中出現，最後化成了 ω。
  5. 對 ω 傳梯度：(14) 用 sg(ω)，梯度只經過 log π。遮罩也要用 ω 判斷，不是用 r。
  6. 組內獎勵全相同（std = 0）沒有處理：論文未說明；常見做法（例如令 Â = 0 或加小常數）不是論文的設定。
  7. 忽略 seq-mean-token-mean 本頁推導：推導中 (18) 的梯度是對 token 求和，實作對每條回應先取 token 平均，等於多乘 1/|y|，論文沒有討論。
  8. 遮罩與上限的交互 本頁推導：若 1 + ϵ_high < C，Â > 0 且 ω > 1 + ϵ_high 的 token 已被遮罩，C 只對 Â < 0 且 ω > C 的 token 起作用。這依賴未公開的 ϵ_high，只能當作條件句。
檢查理解

BPO 的 ϵ、C、KL 懲罰、損失聚合？論文沒有給哪些設定？

ϵ = 0.1、C = 3.0、無 KL 懲罰、seq-mean-token-mean、AdamW 1e−6（App. B）；未給 BPO 的 ϵ_low／ϵ_high、std = 0 的處理、std 為母體或樣本。

11 · 研究脈絡

研究脈絡

BPO 位在三條脈絡的交會處。第一條是 PPO → GRPO → DAPO（ClipHigher）、GSPO、CISPO、DPPO：critic-free 的 RLVR 方法與它們的截斷規則，也是本文的比較對象；DPPO 的論文同時提供了二元 KL。第二條是 Policy Mirror Descent：以 KL 懲罰的逐狀態更新，給出 μ·exp(ηA) 的閉式解。第三條是 DPO、From r to Q* 與 VIMPO：用策略的機率比重新參數化獎勵與價值。VinePPO 指出學到的價值網路在推理任務上不準，是本文避免 critic 的動機之一。每張卡片連到對應的研究筆記。
