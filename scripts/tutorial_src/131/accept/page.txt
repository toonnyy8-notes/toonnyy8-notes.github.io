 Bellman Policy Optimization：把 PMD 改寫成只需終端獎勵的目標

 這篇論文證明一個只用終端獎勵與起始值的平方殘差目標，與 Policy Mirror Descent 有相同的最佳解；實際訓練用的損失則是它的四步近似。

 Zhuoqing Song、Haotian Xu、Xikun Zhang、Lidong Bing（2026）〈Bellman Policy Optimization〉

 01 · PMD 的要求PMD 在每個狀態要求：新策略 = 舊策略 × exp(η × 每個 token 的好壞程度) 再歸一化（好壞程度稱為 advantage，第 03 章定義）。直接實作需要每個中間狀態的 advantage。

 02 · 只剩最終獎勵只有終端獎勵時，一條回應上所有 token 的好壞程度相加，等於「最終獎勵 − 起始期望獎勵」。作者用這個關係寫出一個只需要最終獎勵的目標，並證明它的最佳解與 PMD 相同。

 03 · 實際損失是近似實際訓練的損失是這個目標的四步近似。與 GRPO 相比改了兩處：每個 token 的權重由「新舊機率比」換成「1 減舊機率」對「1 減新機率」的比（分子分母各加一個小平滑常數，再設上限；精確式見第 08 章），截斷規則也改用這個新權重判斷。近似沒有誤差界；論文報告的峰值 AIME 平均為 50.5%。

 advantage組內中心化並除以 std（同 GRPO）

 損失聚合seq-mean-token-mean

 基線GRPO-ClipHigher [0.8, 1.28]；CISPO 權重上限 3.0；DPPO binary TV 門檻 δ = 0.1（符號衝突：這個 δ 不是第 05 章的軌跡殘差 δ $\delta$ ；同理，平滑常數 ϵ $\epsilon$ 與遮罩門檻 ϵlow,ϵhigh $\epsilon_{\text{low}},\epsilon_{\text{high}}$ ​,ϵhigh​ 也是不同的量）；GSPO [1 − 3×10⁻³, 1 + 5×10⁻³]

 依式 (14)(15)(6) 改寫成 PyTorch 風格的虛擬碼如下（本頁改寫，不是論文提供的程式碼）：

 # logp, logp_old: [B, T] 取樣 token 的 log π 與 log μ；adv: [B]；mask_pad: [B, T]
p, q = logp.exp(), logp_old.exp()
omega = ((1 + eps - q) / (1 + eps - p)).detach() # 式 (15)，sg
M = ~(((adv > 0)[:, None] & (omega > 1 + eps_high)) |
 ((adv < 0)[:, None] & (omega < 1 - eps_low))) # 式 (6)；BPO 的 eps_low/high 論文未給
loss_t = -adv[:, None] * M * omega.clamp(max=C) * logp # 式 (14)
loss = ((loss_t * mask_pad).sum(1) / mask_pad.sum(1)).mean() # seq-mean-token-mean（App. B）

 論文沒有給的設定有三項：BPO 的遮罩門檻 ϵ_low／ϵ_high、組內獎勵全相同（std = 0）時的處理、std 是母體還是樣本標準差。常見錯誤：

 把 (14) 說成「被證明等價於 PMD」：被證明的是 (18)；(14) 經過四步近似，沒有誤差界。

 把 ϵ_low = 0.2、ϵ_high = 0.28 當成 BPO 的論文設定：論文只給 GRPO-ClipHigher 的 [0.8, 1.28]，BPO 的遮罩門檻未公開；App. B 只說除 policy loss 外設定相同。實作時可以自選，但不應當作論文值。

 混用平滑常數 ϵ 與遮罩門檻 ϵ_low／ϵ_high；混用軌跡殘差 δ 與 DPPO 的門檻 δ = 0.1。

 以為 BPO 加了 KL 懲罰：App. B 沒有 KL 懲罰；KL 只在推導中出現，最後化成了 ω。

 對 ω 傳梯度：(14) 用 sg(ω)，梯度只經過 log π。遮罩也要用 ω 判斷，不是用 r。

 組內獎勵全相同（std = 0）沒有處理：論文未說明；常見做法（例如令 Â = 0 或加小常數）不是論文的設定。

 忽略 seq-mean-token-mean 本頁推導：推導中 (18) 的梯度是對 token 求和，實作對每條回應先取 token 平均，等於多乘 1/|y|，論文沒有討論。

 遮罩與上限的交互 本頁推導：若 1 + ϵ_high < C，Â > 0 且 ω > 1 + ϵ_high 的 token 已被遮罩，C 只對 Â < 0 且 ω > C 的 token 起作用。這依賴未公開的 ϵ_high，只能當作條件句。

 11 · 研究脈絡

 研究脈絡

 BPO 位在三條脈絡的交會處。第一條是 PPO → GRPO → DAPO（ClipHigher）、GSPO、CISPO、DPPO：critic-free 的 RLVR 方法與它們的截斷規則，也是本文的比較對象；DPPO 的論文同時提供了二元 KL。第二條是 Policy Mirror Descent：以 KL 懲罰的逐狀態更新，給出 μ·exp(ηA) 的閉式解。第三條是 DPO、From r to Q* 與 VIMPO：用策略的機率比重新參數化獎勵與價值。VinePPO 指出學到的價值網路在推理任務上不準，是本文避免 critic 的動機之一。每張卡片連到對應的研究筆記。
