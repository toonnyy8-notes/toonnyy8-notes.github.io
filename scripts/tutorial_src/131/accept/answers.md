## LO1
- 答：狀態 s_t = (x, y_<t)，s_1 = x；動作是下一個 token y_t；轉移確定，s_{t+1} = (x, y_≤t)；中間步驟獎勵為 0，回應結束時給終端獎勵 R(x,y)，|R| ≤ 1。
- 目標：J(π) = E_{x~D, y~P_π(·|x)}[R(x,y)]，即期望終端獎勵（式 1）。
- 出處：「中間步驟沒有獎勵；回應結束時，確定性驗證器給出終端獎勵」
- 信心：high

## LO2
- 答：Â^i = (R^i − mean{R^j}) / std{R^j}，同一回應的所有 token 共用；r_t^i = π(y_t^i|s_t^i) / μ(y_t^i|s_t^i)（式 2、4）。
- 遮罩 M_t^i = 0 若 (Â^i > 0 且 r > 1+ϵ_high) 或 (Â^i < 0 且 r < 1−ϵ_low)，其餘為 1（式 6）。
- 等價：∇(sg(r) log π) = r∇log π = ∇r，未截斷時 (5) 與 (3) 梯度相同；(3) 取到截斷分支時 clip(·) 梯度為 0，對應 M = 0。頁面標為本頁推導，論文未直接給。
- 出處：「所以未截斷時兩者梯度相同」
- 信心：high

## LO3
- 答：Q^μ(s_t,y_t) = V^μ(s_{t+1})（式 8，因中間獎勵為 0、轉移確定）。
- A^μ(s_t,y_t) = V^μ(s_{t+1}) − V^μ(s_t)（式 9 取 π = μ）。
- Σ_y μ(y|s) A^μ(s,y) = 0（式 10，advantage 在 μ 下平均為零）。
- 出處：「選了 yt 就一定到 st+1」
- 信心：high

## LO4
- 答：(16) 是取 f = A^μ 的問題，唯一解為 π⁺(y_t|s_t) = μ(y_t|s_t) exp(η A^μ(s_t,y_t)) / Z_μ(s_t)，其中 Z_μ(s_t) = E_{y'~μ}[exp(η A^μ(s_t,y'))]（式 12、17）。用 Q^μ 取代 A^μ 得到同一解。
- η → 0 時 π⁺ → μ，即不更新；η 越大，機率越集中到 advantage 最大的 token。
- 出處：「→μ（不更新）」
- 信心：high

## LO5
- 答：log Z_μ(s_t) = D_KL(μ(·|s_t) ‖ π⁺(·|s_t))（式 21）。
- 用的性質：對 (17) 取 log 得式 (20)，再對 y_t ~ μ 取期望；用 E_μ[A^μ] = 0（式 10），且 log Z 與 y_t 無關。
- 若改用 Q^μ：E_μ[Q^μ] = V^μ(s_t) ≠ 0，得 log Z_Q = D_KL(μ‖π⁺) + η V^μ(s_t)，中間狀態的價值消不掉。
- 出處：「中間狀態的價值留在式子裡消不掉」
- 信心：high

## LO6
- 答：Σ_{t=1}^{|y|} A^μ(s_t,y_t) = R(x,y) − V^μ(x)（式 23，telescoping；需確定性轉移、中間獎勵為 0、無折扣）。
- δ(x,y;π⁺,μ) = 0（式 24，對每條軌跡成立）；δ(x,y;μ,μ) = η(R(x,y) − V^μ(x))，因為 π = μ 時對數比與 KL 都是 0。
- 出處：「π=μ 時對數比與 KL 都是 0」
- 信心：high

## LO7
- 「唯一」的意義：任何解 π̂⁺ ∈ Π_μ 對每個提示 x 都有 P_{π̂⁺}(·|x) = P_{π⁺}(·|x)，即完成分佈相同；只在 μ 可達的狀態上比較，不可達狀態的 π 可以任意。範圍是整個表格式 Π_μ、相對固定 μ 的單步 PMD，不保證 LLM 參數化能到達。
- 必要性關鍵步驟：(a) 定義 token 殘差 d_π(s,a)，δ = Σ_t d_π(s_t,y_t)（式 30）；(b) 交叉項為零，E_μ[δ²] = Σ_t E_μ[D_t²]；(c) 最小值為 0 且 φ > 0，故每個 E_μ[D_t²] = 0，d_π̂⁺ = 0；(d) 與 d_π⁺ = 0 相減得 π̂⁺ = c(s) π⁺，兩者皆歸一化，故 c(s) = 1。
- 出處：「交叉項為零：s<t 時」
- 信心：high

## LO8
- 涵蓋嗎：不涵蓋。定理 1 只涵蓋精確目標 (18)；(14) 是四步近似，沒有誤差界。
- 四步：(1) 線性化（式 25）：把 δ/η 換成 π = μ 時的值 R − V^μ(x)；(2) 組內估計（式 26）：V^μ(x) ≈ mean{R^j}，φ(x) ≈ 1/std{R^j}，合起來得 Â^i；(3) 簡化 KL：完整 KL 換成二元 KL（取樣 token 對其餘），並加平滑常數 ϵ；(4) 遮罩與上限：乘截斷遮罩 M，並把權重截到 C。
- 線性化丟掉：δ 對 π 的依賴。原本 π 接近 π⁺ 時 δ → 0、梯度自動變小；線性化後係數固定，η 也從梯度中消失。
- 出處：「原本 π 接近 π⁺ 時 δ → 0」
- 信心：high

## LO9
- 答：∇[log π + 二元 KL] = (1 − μ(y|s)) / (1 − π(y|s)) · ∇log π(y|s)（式 27–28）。這是精確恆等式；把完整 KL 換成二元 KL 才是近似。
- ω 的來源：取上式的係數 (1−μ)/(1−π)，為數值穩定加平滑 ϵ，得 ω = (1+ϵ−μ)/(1+ϵ−π)（式 15）。ω 不是重要性取樣修正，分子是 μ，r 的分子是 π，方向相反。
- π = μ 時：∇D_KL(μ‖π) = 0，ω = r = 1，BPO 第一次更新與 GRPO 相同（帶基線的 REINFORCE）；差異只在同批資料的後續更新與引擎數值差異。
- 出處：「第一次更新等於 GRPO」
- 信心：high

## 初學者可能卡住的地方
1. 三種「ϵ」：平滑常數 ϵ（式 15）、遮罩門檻 ϵ_low／ϵ_high，以及 DPPO 的 δ = 0.1 與軌跡殘差 δ 同字。頁面有符號表，但讀到式子時容易混。
2. 「V」兩義：詞表 𝒱 與價值 V^π；Q、A、V 又各帶 π 或 μ 下標。
3. KL 方向：PMD 的懲罰是 D_KL(π‖μ)，推導後卻出現 D_KL(μ‖π⁺)。頁面說明這是推導結果，不是筆誤，但新手會以為寫錯。
4. 精確與近似混在一起：恆等式 (27) 是精確的，把完整 KL 換成二元 KL 才是近似；ω 與 r 的分子分母位置相反。
5. 示範值當成論文設定：0.2／0.28 是頁面的示範遮罩；公式 (2) 在 std = 0 時是 0/0，論文沒有說明處理方式。
