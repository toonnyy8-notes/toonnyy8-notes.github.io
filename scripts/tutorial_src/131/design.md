## 1. 介紹（步驟 6-1）

### 1.1 一段話總結

RLVR（reinforcement learning with verifiable rewards）用驗證器替 LLM 的整條回應打分數再做強化學習。主流方法 GRPO 不訓練價值模型（critic-free），用組內標準化的獎勵當 advantage，所有 token 共用。Policy Mirror Descent（PMD）是另一條理論路線：在每個狀態上最大化「advantage 期望 − KL 懲罰」，閉式解是 μ·exp(ηA)/Z，但需要每個中間狀態的 advantage 與配分函數 Z。本文在「確定性轉移 + 只有終端獎勵」的設定下做三件事：(1) 對 PMD 最佳性條件取期望，把 log Z 換成 KL(μ‖π⁺)（式 21）；(2) 用 Bellman 方程把 token advantage 寫成相鄰狀態價值之差，沿回應相加只剩 R(x,y) − V^μ(x)（式 23）；(3) 得到每條軌跡都為零的殘差 δ（式 24），以其平方的期望作為目標 (18)。定理 1 證明 (18) 與 PMD (16) 在 μ 可達的狀態上有相同的唯一最佳解。接著作者以線性化、組內估計、二元 KL、平滑／遮罩／上限四步近似，得到損失 (14)。它與 GRPO 的 (5) 有兩處不同：(i) 權重 sg(r)（r = π/μ）換成 min(sg(ω), C)，ω = (1+ϵ−μ)/(1+ϵ−π)；(ii) 遮罩 M 的判斷量由 r 換成 ω（§3，式 14 之後）。BPO 的遮罩門檻 ϵ_low／ϵ_high 論文沒有給。在 Qwen3-30B-A3B-Base、DAPO-Math-17k 上，BPO 的峰值 AIME24–26 平均 Avg@32 為 50.5%，比 GRPO-ClipHigher、GSPO、CISPO、DPPO 高 11.0、7.0、3.1、4.1 個百分點（§4.2、Table 1）。

### 1.2 研究動機（§1）

1. GRPO 類方法廣泛使用，但 policy optimization 的選擇明顯影響推理表現與穩定性（§1 引 [4, 7–11]）。
2. PMD 用 action value 加散度懲罰更新策略，直接用在語言生成需要中間狀態的價值估計；常見做法是另訓價值模型，增加記憶體與計算（[1]），且學到的價值在推理任務上可能不準（[22] VinePPO）。
3. 目標：找一個 PMD 的改寫，**不訓練價值模型**也能得到同一個策略更新。

### 1.3 貢獻（§1 條列，照原文）

1. critic-free、軌跡級的 PMD 改寫（式 18–19），不需估計中間狀態的 value 或 advantage；證明它與原 PMD 在 rollout 策略可達的狀態上有相同的唯一最佳解（定理 1、App. A.1）。
2. 由此改寫經組內估計與梯度近似導出實用損失 (14)；以「互補 token 機率的平滑比值」ω 取代 GRPO 的重要性比率。
3. 實驗：50.5% 峰值平均，勝過四個基線 3.1–11.0 個百分點。

#### 步驟 1：RLVR 是回合式 MDP（§2.2，式 1）

狀態 $s_t=(x,y_{<t})$，動作是下一個 token $y_t\sim\pi(\cdot\mid s_t)$，轉移是確定性的（接上 token），回應在 EOS 或 $T_{\max}$ 結束，只有終端獎勵 $R(x,y)$。目標
$$J(\pi)=\mathbb E_{x\sim\mathcal D,\,y\sim P_\pi(\cdot\mid x)}[R(x,y)].\tag{1}$$

#### 步驟 2：GRPO 與 μ ≠ π（§2.3，式 2–6）

- rollout 由 $\mu$ 產生、在 $\pi$ 上最佳化；兩者不同的原因：同一批 rollout 之後的多次更新，以及 rollout 引擎與訓練引擎的數值差異（[8, 27–30]）。
- $\hat A^i=\dfrac{R^i-\mathrm{mean}\{R^j\}_{j=1}^G}{\mathrm{std}\{R^j\}_{j=1}^G}$（式 2）；同一回應的所有 token 共用。
- $L^{\text{GRPO}}_{i,t}=-\min\{r_t^i\hat A^i,\ \mathrm{clip}(r_t^i,1-\epsilon_{\text{low}},1+\epsilon_{\text{high}})\hat A^i\}$（式 3），$r_t^i=\pi(y_t^i\mid s_t^i)/\mu(y_t^i\mid s_t^i)$（式 4）。
- 梯度相同的寫法：$\tilde L^{\text{GRPO}}_{i,t}=-\hat A^iM_t^i\,\mathrm{sg}(r_t^i)\log\pi(y_t^i\mid s_t^i)$（式 5），$M_t^i=0$ 若 $\hat A^i>0$ 且 $r>1+\epsilon_{\text{high}}$，或 $\hat A^i<0$ 且 $r<1-\epsilon_{\text{low}}$；否則 1（式 6）。
- 〔本頁推導〕(5) 與 (3) 梯度相同的理由：$\nabla(\mathrm{sg}(r)\log\pi)=r\nabla\log\pi=\nabla r$；被截斷的分支梯度為 0，正好對應 $M=0$。
- 組內例子〔本頁推導〕：$G=16$、0/1 獎勵、4 條正確〔示範值：「4 條正確」與 0/1 獎勵都是本頁所選；論文只說 $\lvert R\rvert\le1$〕：mean 0.25；若 std 取母體標準差 0.4330，正確回應 $\hat A=1.7321$、錯誤 $-0.5774$；若取樣本標準差 0.4472，則 1.6771、−0.5590。**論文沒有說明 std 用哪一種**，頁面兩者並列。

#### 步驟 3：終端獎勵下的 Bellman 方程（§2.4，式 7–10）

$V^\pi(s_t)=\mathbb E_{z\sim P_\pi(\cdot\mid s_t)}[R(x,(y_{<t},z))]$（式 7）；中間獎勵為零、轉移確定，所以 $Q^\pi(s_t,y_t)=V^\pi(s_{t+1})$（式 8）；$A^\pi=Q^\pi-V^\pi$（式 9）；$\sum_{y_t}\pi(y_t\mid s_t)A^\pi(s_t,y_t)=0$（式 10）；終端條件 $V^\pi(s_{\lvert y\rvert+1})=R(x,y)$。$V^\pi(x)$ 是提示 $x$ 的期望獎勵。

#### 步驟 4：PMD 與閉式解（§2.5 式 11–12；§3 式 16–17）

$$\max_{\pi(\cdot\mid s)}\ \mathbb E_{y\sim\pi}[f(s,y)]-\tfrac1\eta D_{\mathrm{KL}}(\pi(\cdot\mid s)\,\|\,\mu(\cdot\mid s))\tag{11}$$
唯一解 $\pi^+_{\mu,f}(y\mid s)=\mu(y\mid s)\exp(\eta f(s,y))/Z_{\mu,f}(s)$，$Z=\mathbb E_{y'\sim\mu}[\exp(\eta f(s,y'))]$（式 12）。取 $f=A^\mu$ 得 (16)(17)。

- 用 $A^\mu$ 與用 $Q^\mu$ 解相同，因為 $Q^\mu=A^\mu+V^\mu(s_t)$ 且 $V^\mu(s_t)$ 不依賴動作（§3 原文）。
- 〔本頁推導〕拉格朗日：對 $\pi(y)$ 微分得 $f(y)-\frac1\eta(\log\frac{\pi(y)}{\mu(y)}+1)-\lambda=0$，故 $\pi\propto\mu e^{\eta f}$；目標對 $\pi$ 嚴格凹，解唯一。論文只給結果。
- 〔本頁推導〕$\eta\to0$ 時 $\pi^+\to\mu$；$\eta$ 越大越偏向 advantage 大的 token。最佳值 $=\frac1\eta\log Z$（W1 讀數驗證）。

#### 步驟 5：消去 Z（§3.1 Step 1，式 20–22）

取對數：$\log\pi^+-\log\mu-\eta A^\mu+\log Z_\mu=0$（式 20）。對 $y_t\sim\mu$ 取期望，用式 (10)（$\mathbb E_\mu[A^\mu]=0$）：
$$\log Z_\mu(s_t)=D_{\mathrm{KL}}(\mu(\cdot\mid s_t)\,\|\,\pi^+(\cdot\mid s_t))\tag{21}$$
代回得 $\log\pi^+-\log\mu-\eta A^\mu+D_{\mathrm{KL}}(\mu\|\pi^+)=0$（式 22）。
- **方向**：PMD 懲罰是 $\mathrm{KL}(\pi\|\mu)$，殘差中出現的是 $\mathrm{KL}(\mu\|\pi)$（§3.2 稱 full reverse KL）。方向相反是推導結果，不是筆誤。
- 〔本頁推導〕**為什麼用 A 不用 Q**：用 $Q$ 時 $\mathbb E_\mu[Q^\mu]=V^\mu(s_t)\neq0$，得 $\log Z_Q=\mathrm{KL}(\mu\|\pi^+)+\eta V^\mu(s_t)$，中間狀態的價值留在式中消不掉。
- 〔本頁推導〕一致性：Jensen 給 $\log\mathbb E_\mu[e^{\eta A}]\ge\eta\mathbb E_\mu[A]=0$，與 KL ≥ 0 相符。

#### 步驟 6：逐項相消（telescoping sum，§3.1 Step 2，式 23）

式 (8) 代入 (9)：$A^\mu(s_t,y_t)=V^\mu(s_{t+1})-V^\mu(s_t)$。沿軌跡相加：
$$\sum_{t=1}^{\lvert y\rvert}A^\mu(s_t,y_t)=V^\mu(s_{\lvert y\rvert+1})-V^\mu(s_1)=R(x,y)-V^\mu(x).\tag{23}$$
條件：確定性轉移、中間獎勵為零、無折扣；任何一項不成立 (23) 就不成立。

#### 步驟 7：殘差與目標（§3.1 Step 3，式 18、19、24）

(22) 沿軌跡加總並代入 (23)：$\delta(x,y;\pi^+,\mu)=0$（式 24），其中
$$\delta(x,y;\pi,\mu)=\eta\big(R(x,y)-V^\mu(x)\big)-\sum_{t=1}^{\lvert y\rvert}\Big[\log\frac{\pi(y_t\mid s_t)}{\mu(y_t\mid s_t)}+D_{\mathrm{KL}}(\mu(\cdot\mid s_t)\|\pi(\cdot\mid s_t))\Big].\tag{19}$$
$$\min_{\pi\in\Pi_\mu}L(\pi)=\mathbb E_{x\sim\mathcal D,\,y\sim P_\mu(\cdot\mid x)}\Big[\phi(x)\frac{\delta(x,y;\pi,\mu)^2}{2\eta}\Big].\tag{18}$$
- (24) 對**每一條** μ 會產生的軌跡成立，不只在期望上成立；所以平方殘差能取到 0。
- (18) 只需終端獎勵 $R$ 與起始值 $V^\mu(x)$，後者可用 rollout 估計（§3.1）。
- $\delta(x,y;\mu,\mu)=\eta(R-V^\mu(x))$（π = μ 時對數比與 KL 都為 0；§3.2 Step 1 用到）。
- 〔本頁推導〕(18) 並不便宜：(19) 每個 token 需要整個詞表的 $\mathrm{KL}(\mu\|\pi)$，即 rollout 策略的完整分佈。
- 〔本頁推導〕**先備：softmax 對 logit 的梯度（頁面在 logit 形式之前教）**。$\pi=\mathrm{softmax}(z)$，$\log\pi(y)=z_y-\log\sum_ve^{z_v}$，所以 $\partial\log\pi(y)/\partial z_v=\mathbb 1\{v=y\}-\pi_v$，寫成向量 $\nabla_z\log\pi(y)=e_y-\pi$（$e_y$ 是第 y 個分量為 1 的 one-hot 向量）。3 token 例子〔示範值〕：$z=(1,0,-1)$ ⇒ $\pi=(0.6652,0.2447,0.0900)$；取樣 t1 時 $e_y-\pi=(0.3348,-0.2447,-0.0900)$：取樣 token 往上推、其他 token 按 π 的比例往下拉。同理 $\nabla_z\mathrm{KL}(\mu\|\pi)=\pi-\mu$；μ = (0.5, 0.3, 0.2) 時為 (0.1652, −0.0553, −0.1100)，兩者相加 $e_y-\mu=(0.5,-0.3,-0.2)$，與 π 無關（`check.py` 以有限差分交叉核對，頁面只用解析式）。
- 〔本頁推導〕**logit 形式**：若 $\pi(\cdot\mid s)=\mathrm{softmax}(z)$、$\mu(\cdot\mid s)=\mathrm{softmax}(z^\mu)$，則 $\log\pi(y)-\log\mu(y)+\mathrm{KL}(\mu\|\pi)=(e_y-\mu)\cdot(z-z^\mu)$，log-sum-exp 相消。所以在表格式（每個狀態各自一組 logit）參數下，δ 是 logit 的仿射函數、(18) 是最小平方問題。W2、W3 用此式計算（數值穩定，$\pi\to0,1$ 也不會出現 log 0）。
- 頁面 S5 內文（不只在 W2 讀數）列出案例 I〔示範值：μ 處處 0.5、R(aa) = 1 其餘 0、η = 1〕：V(x) = 0.25、π⁺ = (0.62246, 0.73106, 0.5)；π = μ 時 δ = (0.75, −0.25, −0.25, −0.25)、L = 0.09375；π = π⁺ 時 δ 全為 0、L = 0。

#### 步驟 8：定理 1（§3.1；App. A.1，式 30–31）

敘述：$\phi$ 為任意正權重；(18) 有唯一最佳解 $\hat\pi^+=\pi^+$，「唯一」與「相等」的意思是：任何解 (18) 的 $\hat\pi^+\in\Pi_\mu$ 對每個提示 $x$ 都有 $P_{\hat\pi^+}(\cdot\mid x)=P_{\pi^+}(\cdot\mid x)$。
- 充分性：由 (24)，且 (17) 保持 μ 的支撐，所以 $\pi^+\in\Pi_\mu$ 取到目標值 0；目標非負，最小值為 0。
- 必要性：頁面主線用**變異數講法**〔本頁推導，與 App. A.1 的結論相同〕，只需要條件期望；鞅只在一句註記中出現。
  1. token 殘差 $d_\pi(s,a)=\eta A^\mu(s,a)-[\log\pi(a\mid s)-\log\mu(a\mid s)+\mathrm{KL}(\mu\|\pi)]$，$\delta=\sum_td_\pi(s_t,y_t)$（式 30）。記 $D_t=d_\pi(S_t,Y_t)$（回應已結束則 $D_t=0$）。
  2. 對**任何** π，在每個狀態上 $\sum_a\mu(a\mid s)d_\pi(s,a)=\eta\cdot0+\mathrm{KL}(\mu\|\pi)-\mathrm{KL}(\mu\|\pi)=0$（只用式 10 與 KL 定義；論文 §3.1 Proof sketch 的同一式）。
  3. 交叉項為零：$s<t$ 時 $D_s$ 在看到第 t 步之前就已決定，所以 $\mathbb E[D_sD_t]=\mathbb E\big[D_s\,\mathbb E[D_t\mid S_t]\big]=0$。因此 $\mathbb E_{\mu}[\delta^2]=\sum_t\mathbb E_\mu[D_t^2]$（詞表與長度有限、各量有限時成立）。
  4. 最小值為 0 且 $\phi>0$ ⇒ 最佳解使 $\mathbb E_\mu[\delta^2]=0$（式 31）⇒ 每個 $\mathbb E_\mu[D_t^2]=0$ ⇒ 對每個 μ 可達的狀態 s 與 $a\in\mathrm{supp}\,\mu(\cdot\mid s)$（事件機率為正），$d_{\hat\pi^+}(s,a)=0$。目標值有限也保證可達狀態上 $\mathrm{KL}(\mu\|\hat\pi^+)<\infty$，各量有限。
  5. 與 $d_{\pi^+}=0$ 相減：$\log(\hat\pi^+/\pi^+)=\mathrm{KL}(\mu\|\pi^+)-\mathrm{KL}(\mu\|\hat\pi^+)$，右邊與 $a$ 無關 ⇒ $\hat\pi^+=c(s)\pi^+$；兩者在 $\Pi_\mu$ 內（支撐外為 0）、歸一化 ⇒ $c(s)=1$。
  - 註記（頁面一句話）：論文 App. A.1 用鞅表述第 3–4 步：部分和 $M_n=\sum_{t\le n}D_t$ 每步期望增量為 0，終值 $M_{T_{\max}}=\delta=0$ 幾乎必然，故每個部分和都為 0。
- W2b 用數字顯示第 2、3 步對任何 π 都成立。

#### 步驟 10：二元 KL 恆等式與 ω（App. A.2，式 13、15、27）

記 $p=\pi(y\mid s)$、$q=\mu(y\mid s)$。$D^{\text{bin}}_{\mathrm{KL}}(\mu\|\pi;y)=q\log\frac qp+(1-q)\log\frac{1-q}{1-p}$；$\nabla D^{\text{bin}}=-q\nabla\log p+\frac{1-q}{1-p}\nabla p$；用 $\nabla p=p\nabla\log p$：$\nabla[\log p+D^{\text{bin}}]=(1-q)\nabla\log p+\frac{(1-q)p}{1-p}\nabla\log p=\frac{1-q}{1-p}\nabla\log p$。π → 1 時發散，分子分母各加 ϵ：
$$\omega_t^i=\frac{1+\epsilon-\mu(y_t^i\mid x,y_{<t}^i)}{1+\epsilon-\pi(y_t^i\mid x,y_{<t}^i)}.\tag{15}$$
- 二元 KL 是完整 KL 的下界：$0\le D^{\text{bin}}_{\mathrm{KL}}\le D_{\mathrm{KL}}$（§2.6 引 [8]）。式 (13) 在 §2.6 寫成 $D^{\text{bin}}(\pi\|\mu;y)$，§3.2 用的是 $D^{\text{bin}}(\mu\|\pi;y)$（App. A.2）；頁面只寫後者並註明方向。
- ω 的分子是 μ、分母是 π，與 r = π/μ 位置相反；它來自 ∇[log π + 二元 KL]，不是重要性取樣修正。論文稱 mismatch-correction weight。
- 〔本頁推導〕數字（ϵ = 0.1）：(q, p) = (0.5, 0.6)：r 1.2、未平滑 1.25、ω 1.2；(0.01, 0.02)：r 2.0、ω 1.0093；(0.98, 0.99)：r 1.0102、未平滑 2.0、ω 1.0909；(0.5, 0.9)：r 1.8、未平滑 5.0、ω 3.0；(0, 1)：r、未平滑皆無限大，ω 11.0；(1, 0)：r 0、ω 0.0909。ω 的範圍 $[\epsilon/(1+\epsilon),(1+\epsilon)/\epsilon]=[0.0909,11]$。
- 〔本頁推導〕讀法：p > q 時 r 與 ω 都大於 1，方向一致；r 對低機率 token 敏感；未平滑比值 (1−q)/(1−p) 對高機率 token 敏感（0.98 → 0.99 就是 2 倍），ϵ 平滑後這個敏感度大幅減弱（ϵ = 0.1 時 ω = 1.0909），且 ω 被限制在 [ϵ/(1+ϵ), (1+ϵ)/ϵ]。論文沒有討論這個差異。ϵ = 0.1、C = 3 時 ω > C 需要 $p>(2.2+q)/3$，只在 q < 0.8 可能發生。
- 〔本頁推導〕二元近似保留取樣 token 的 logit 分量 $1-q$，但其他 token 的分量從 $-\mu_v$ 變成 $-(1-q)\pi_v/(1-p)$（按 π 而非 μ 的比例）。若 π 與 μ 只在取樣 token 的機率上不同（其他 token 按比例縮放），兩者完全相同，且二元 KL = 完整 KL；詞表只有兩個 token 時恆相同（W2、W3 的二元樹因此無法顯示這一步的差異）。

### W1 · 單一狀態的 PMD：π⁺、log Z 與 KL（S4）

- **概念**：式 (17)；η 的角色；log Z = KL(μ‖π⁺)（式 21，S5 會用到，這裡先以數字出現並標「S5 說明為什麼」）；用 Q 時 log Z 多 ηV〔本頁推導〕。
- **輸入**：
  - μ 預設組（分段按鈕）：「偏斜 (0.4, 0.3, 0.2, 0.1)」（預設）、「均勻 (0.25 × 4)」、「集中 (0.85, 0.05, 0.05, 0.05)」〔示範值〕。

- **計算**：$V=\sum\mu_kQ_k$，$A_k=Q_k-V$；$\ell_k=\log\mu_k+\eta A_k$，$\log Z=\mathrm{lse}(\ell)$（先減最大值），$\pi^+_k=\exp(\ell_k-\log Z)$；$\mathrm{KL}(\mu\|\pi^+)=\sum\mu_k(\log\mu_k-\log\pi^+_k)$ 用 $\log\pi^+_k=\ell_k-\log Z$ 直接算（不對 π⁺ 取 log，避免 π⁺ 極小時下溢）；$\mathrm{KL}(\pi^+\|\mu)$ 同理；$\mathbb E_{\pi^+}[A]$；最佳值 $\mathbb E_{\pi^+}[A]-\mathrm{KL}(\pi^+\|\mu)/\eta$（η = 0 時顯示「—」）；$\log Z_Q=\log Z+\eta V$。
- **防護**：η = 0 ⇒ π⁺ = μ、log Z = 0；μ 預設組全為正，不會 log 0；KL 讀數顯示前若 |值| < 5e−13 顯示 0.0000（避免「−0.0000」）。

- **預期觀察**：η = 0 時 π⁺ = μ；η 增大時質量移向 A 最大的 token（預設 t4）；log Z 與 KL(μ‖π⁺) 恆相等；KL(π⁺‖μ) ≠ KL(μ‖π⁺)；最佳值 = (1/η) log Z；改用 Q 時 log Z 多 ηV。

### W2 · 二元樹：逐項相消、殘差與定理 1（W2a 在 S5，W2b 在 S6）

模型（頁面寫出）：詞表 {a, b}，每條回應恰為 2 個 token（不提早 EOS），狀態 x、a、b，葉節點 aa、ab、ba、bb。ϕ = 1、單一提示。

- **共用輸入**（W2a 圖版內）：μ(a|x)、μ(a|a)、μ(a|b) ∈ [0.05, 0.95]，步長 0.01，預設 0.5；R(葉) 各用分段按鈕 {−1, 0, 1}，預設 R(aa) = 1、其餘 0；η ∈ [0.1, 4]，步長 0.1，預設 1；π 的控制項改在 **logit 空間**：三個滑桿 $\theta_s=\mathrm{logit}\,\pi(a|s)\in[-12,12]$，步長 0.01，預設 θ^μ；滑桿旁同時顯示 π(a|s) = σ(θ_s)（四位小數）。範圍理由〔本頁推導〕：$\lvert\theta^\mu\rvert\le\mathrm{logit}(0.95)=2.94$，$\lvert\theta^+-\theta^\mu\rvert=\eta\lvert A(s,a)-A(s,b)\rvert\le4\cdot2=8$，故 π⁺ 的 logit 必在 [−10.95, 10.95] 內，滑桿位置與狀態永遠一致。按鈕：「π = μ」、「π = π⁺」、「範例 (0.7, 0.6, 0.5)」〔示範值〕（設 θ = logit 值）。μ、R、η 的預設〔示範值〕。
- **計算**（全部封閉式）：$V^\mu(a)=\mu(a|a)R(aa)+(1-\mu(a|a))R(ab)$，$V^\mu(b)$ 同理，$V^\mu(x)=\mu(a|x)V^\mu(a)+(1-\mu(a|x))V^\mu(b)$；$A^\mu(x,a)=V^\mu(a)-V^\mu(x)$ 等，$A^\mu(a,a)=R(aa)-V^\mu(a)$ 等；π⁺(a|s) 用兩項 lse；$P_\mu(y)$；token 殘差用 logit 形式 $d_\pi(s,y)=\eta A^\mu(s,y)-(\mathbb 1\{y=a\}-\mu(a|s))(\theta_s-\theta^\mu_s)$，$\theta=\mathrm{logit}$；$\delta(y)=d_\pi(x,y_1)+d_\pi(y_1,y_2)$；$L=\sum_yP_\mu(y)\delta(y)^2/(2\eta)$；$J(\pi)=\sum_yP_\pi(y)R(y)$。

### W4 · logit 空間的梯度方向：完整 KL、二元 KL、BPO、GRPO（S8）

- **輸入**：μ 固定 (0.4, 0.3, 0.2, 0.1)（與 W1 預設相同，logit $z^\mu=\log\mu$）；μ 與 Δ 預設〔示範值〕；π 的 logit 偏移 Δ₁…Δ₄ ∈ [−3, 3]，步長 0.05，預設 **(0, 1, 0, 0)**（讓二元與完整版不同）；取樣 token y（分段按鈕 t1–t4，預設 t1）；ϵ（與 W5 共用，預設 0.1）；按鈕「π = μ」「只改 y 的 logit」（設 Δ = 1·e_y）；顯示勾選：完整 KL、二元 KL、BPO（ω）、GRPO（r），預設前三者（REINFORCE 勾選已刪除：π = μ 時它與其他向量相同，S5 的 3 token 例子已教 $e_y-\pi$）。

### W5 · 純量比較：r、未平滑比值、ω、上限與遮罩（S8）

- **驗收**：見 5.5。
- **預期觀察**：p = q 時 r = ω = 1；低機率區 r 變化劇烈而 ω 接近 1；高機率區未平滑比值變化劇烈，ϵ 平滑後大幅減弱（ϵ = 0 時最明顯）；ω 被限制在 [ϵ/(1+ϵ), (1+ϵ)/ϵ]；ϵ 越大 ω 越平。
