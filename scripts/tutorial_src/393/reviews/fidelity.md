Conditioning on w_s says z_t is not a function of z_s alone; it does not disprove a z-chain. Page states it as proven. My MC (K=3, alpha~ = 0.9/0.6/0.3, Gaussian chain (37), 2M runs, x fixed): P(z_t=z_s | z_s=x)=0.591, | z_s≠x = 0.454, USDM (38) gives 0.611 for both; Markov test P(z_u=z_t | z_t≠x) = 0.511 if z_s=z_t, 0.480 otherwise. So the conclusion holds, but by a different argument. Fix: tag the z_s-conditioned MC as 〔本頁推導〕, say A.3's argument is conditional on w_s, soften to the paper's "不一定"; W3's TV 0.1018 is a w_s-conditional gap, label it so.
