## 2. 必須講對的推導

### D1. argmax 邊際與 T（A.1；式 (10)(11)）
條件：x_k = 1；ε ~ N(0, I_K)；w = α̃x + σ̃ε。
- w_k ~ N(α̃, σ̃²)，w_{i≠k} ~ N(0, σ̃²)，彼此獨立。(24)(25)
- Z = max_{i≠k} w_i，P(Z < l) = Φ(l/σ̃)^{K−1}。(27)
- P(argmax = k) = ∫ Φ^{K−1}(l/σ̃) · (1/σ̃) φ((l−α̃)/σ̃) dl；令 l̃ = l/σ̃：
  **P_k = ∫ φ(l̃ − α̃/σ̃) Φ^{K−1}(l̃) dl̃**。(28)
- 其餘 K−1 個索引對稱，各為 β_t = (1 − P_k)/(K−1)。(30)
- 向量形式：Cat(β_t 1 + (1−Kβ_t) x)。(32) 令 α_t = 1 − Kβ_t 得
  **T(α̃) = K/(K−1) · [ ∫ φ(z − α̃/√(1−α̃²)) Φ^{K−1}(z) dz − 1/K ]**。(11)(34)
- 檢查〔顧問推導〕：α̃=0 時積分 = 1/K → T=0；α̃→1 時積分 → 1 → T=1。T 只依賴訊雜比 α̃/σ̃ 與 K。
- K=2 封閉式〔顧問推導〕：T = 2Φ(α̃/(√2 σ̃)) − 1 = erf(α̃/(2σ̃))。數值驗證 α̃=0.6：兩邊皆 0.40412。
- 注意：φ 必須是 exp(−z²/2)/√(2π)。正文 (11) 下方與 A.1 Part 3 印成 exp(−z²)/√(2π)，是筆誤（A.3 寫對了）。

### D2. 邊際的 ODE（A.2；式 (12)(33)(36)）
p_t = β_t 1 + (1−Kβ_t) x。關鍵一行：[11ᵀ − K I] p_t = 1 − K p_t = (1 − Kβ_t)(1 − Kx)。
- dp_t/dt = β_t′(1 − Kx) = β_t′/(1−Kβ_t) · [11ᵀ − K I] p_t。(33)
- 代入 α_t = 1 − Kβ_t（β_t′ = −α_t′/K）：**dp_t/dt = −α_t′/(Kα_t) · [11ᵀ − K I] p_t**。(36)，即 (12)（α_t = T(α̃_t)）。
- **符號不一致**：背景式 (3) 印成 Q_t = +α_t′/(Kα_t)[11ᵀ − K I]，少一個負號；(12) 與 (36) 有負號。〔顧問推導〕直接對 (1) 微分可得負號版才對（α_t′<0，非對角速率 −α_t′/(Kα_t) > 0）。教學請用 (12)/(36)。
- 這步的邏輯地位：論文宣稱「邊際 (35) + ODE (36)」是 USDM 的「unique signatures」。其實 (36) 是 (35) 的直接推論，不是獨立條件。

### D3. 軌跡不對偶（A.3；式 (39)(40)）
- 高斯轉移：w_t | w_s ~ N(α̃_{t|s} w_s, (1−α̃_{t|s}²)I)，α̃_{t|s} = α̃_t/α̃_s。(37)
- 離散轉移：z_t | z_s ~ Cat(α_{t|s} z_s + (1−α_{t|s})1/K)。(38) → 所有「非 z_s」的索引機率相等。
- 推前：P(argmax = i) = ∫ ∏_{j≠i} Φ((l − α̃_{t|s}(w_s)_j)/√(1−α̃_{t|s}²)) · (1/√(1−α̃_{t|s}²)) φ((l − α̃_{t|s}(w_s)_i)/√(1−α̃_{t|s}²)) dl。(39)
- 非最大的那些索引機率相等 ⇔ (w_s)_i 全相等，機率為零 → (40) 不等。
- 結論用語要精確：對偶是「每個時刻的（條件）邊際」相等，以及因此 NELBO 的期望可改用高斯潛變數計算 (19)；不是「把高斯軌跡逐點取 argmax 就得到 USDM 軌跡」。

### D4. Rao-Blackwellized NELBO (17) 是 (49) 的逐點恆等式（A.6）
定義：x̄ = Kα_t x + (1−α_t)1，x̄_θ = Kα_t x_θ + (1−α_t)1，i = z_t 的索引，m = x 的索引，κ_t = (1−α_t)/(Kα_t+1−α_t)。
x̄ 只有兩種值：x̄_m = Kα_t+1−α_t，x̄_{j≠m} = 1−α_t，所以 x̄_j/x̄_i ∈ {1, κ_t, 1/κ_t}。
把 (49) 的 Σ_j (x̄_j/x̄_i) log[(x̄_θ)_i x̄_j / ((x̄_θ)_j x̄_i)] 拆成兩個和：
- z_t = x（i=m）：比值在 j≠m 為 κ_t。Σ_j(x̄_j/x̄_i)log(x̄_j/x̄_i) = (K−1)κ_t log κ_t；另一和 = κ_t Σ_j log((x̄_θ)_i/(x̄_θ)_j)。
- z_t ≠ x（i≠m）：比值在 j=m 為 1/κ_t、其餘為 1。Σ_j(x̄_j/x̄_i)log(x̄_j/x̄_i) = −(1/κ_t) log κ_t；另一和 = Σ_j log((x̄_θ)_i/(x̄_θ)_j) + (1/κ_t − 1) log((x̄_θ)_i/(x̄_θ)_m)，且 1/κ_t − 1 = Kα_t/(1−α_t)。
合起來即 (17)：
f_Duo = −α_t′/(Kα_t) · [ K/x̄_i − K/(x̄_θ)_i − (κ_t 1_{z=x} + 1_{z≠x}) Σ_j log((x̄_θ)_i/(x̄_θ)_j) − K α_t/(1−α_t) log((x̄_θ)_i/(x̄_θ)_m) 1_{z≠x} − ((K−1)κ_t 1_{z=x} − (1/κ_t) 1_{z≠x}) log κ_t ]
〔顧問推導〕我用隨機 x_θ（K=7, α=0.37）數值驗證兩種情況下 (49) 與 (17) 相等到 1e-15。
**重要**：A.6 展示的是對固定 (z_t, x) 的代數恆等，沒有任何期望被解析積掉。「Rao-Blackwellization」與「降低變異」的說法在推導中找不到對應步驟；論文自己也報告兩式評估得到同一 PPL 33.7。Table 3 的 1.7 PPL 差距的機制論文沒有解釋。教學時可說「省記憶體、不必建 one-hot x̄ 的等價改寫」，不要自行替它補上變異數下降的理由。

### D5. USDM 後驗 (4) 與 DDT 的「只翻一次」
- (4) 驗證〔顧問推導〕：q(z_s|z_t,x) ∝ q(z_t|z_s) q(z_s|x) = [α_{t|s} z_t + (1−α_{t|s})/K] ⊙ [α_s x + (1−α_s)/K]，乘 K 展開四項：Kα_t z_t⊙x + (α_{t|s}−α_t) z_t + (α_s−α_t) x + (1−α_{t|s})(1−α_s)1/K；分母 K·q(z_t|x) = Kα_t⟨z_t,x⟩ + 1 − α_t。與 (4) 一致。
- DDT (22)：z_t = argmax(α̃_t x + σ̃_t ε)，x 與 ε 全程固定。〔顧問推導〕非 k 的座標都是 σ̃_t ε_i，其最大者永遠是 j* = argmax_{i≠k} ε_i，所以 z_t ∈ {k, j*}；z_t = k ⇔ α̃_t/σ̃_t > ε_{j*} − ε_k =: Δ。α̃_t/σ̃_t 隨 t 單調，故每個 token 至多翻一次，翻轉點在 α̃ = Δ/√(1+Δ²)（Δ ≤ 0 時始終為 k）。這就是 A.7 說的「只能取兩個值、類似 MDM 的 carry-over」。
- 「確定性」指的是給定 (x, ε) 後 t ↦ z_t 是確定函數。它是以資料為條件的直線內插（最優 denoiser 假設，(57)–(59)），不是模型自己的 PF-ODE；教師網路沒有被用來解 ODE。

## 3. 常見誤讀、內部不一致、未交代處

### 3a. 看起來對但論文沒有證明的說法
1. 「離散擴散 = 高斯擴散取 argmax」：只在邊際成立（D3）。正文自己在 (12) 後與 A.3 否定了軌跡版。
2. 「Thm 3.2 證明 Duo 的 ELBO 比高斯擴散緊」（Fig. 1 圖說這樣寫）：定理比較的是兩個**邊際概似**（不是 ELBO），而且對象是 Thm 3.1 構造出來、共用同一個高斯空間 denoiser 的取樣器配對 (14)。實際訓練的 Duo 是直接用 (6)/(17) 訓練離散 denoiser，並不是該構造。定理只當動機。
3. 〔顧問推導〕Thm 3.2 的證明把 q_data（one-hot 上的 pmf）與 p̄^θ_data（R^K 上的密度）放進同一個 Σ_x q log(q/p̄)；pmf 與密度的對數不可直接比，嚴格說 KL(q_data‖p̄) 在這設定下不是有限量。請當作示意性論證，不要對初學者說成嚴格定理。
4. 「課程學習讓訓練快 2×」：依據是 510K 步時 PPL 35.2，比訓練 1M 步的 UDLM（36.7）好約 1.5。但 Duo 與 UDLM 還差一個損失改寫 (17)；同表 Duo w/o CL 在 1M 步是 35.0，比 35.2 還低。所以 2× 是相對 UDLM，不是相對自己的無課程版本。
5. 「取樣快兩個數量級」：ancestral 是 1024→16 步（64×，Gen PPL 75.24 對 77.69，entropy 5.53 對 5.55）；要 Greedy-Tail 才是 1024→8（128×，69.58，但 entropy 5.30 對 5.55，多樣性下降）。
6. 「Duo 在 3/7 個 zero-shot 資料集勝過 AR」：正確（Lambada 49.78<51.28、Pubmed 44.48<49.01、Arxiv 40.39<41.73），但 MDLM 與 SEDD Absorb 在同樣三個資料集上也勝過 AR；且擴散模型的數字是上界。Duo 對 MDLM 只贏 1/7（PTB），對 SEDD Absorb 贏 4/7。
7. 「與 absorbing diffusion 差距縮到 2 PPL 以下」：Table 1 三欄差距為 29.9−27.0 = 2.9（LM1B 無 packing）、33.7−31.8 = 1.9（LM1B）、25.2−23.2 = 2.0（OWT）。只有一欄嚴格小於 2。
8. 「蒸餾後 Duo 全面勝過蒸餾 MDLM」：只在低步數。Table 7 Round 5 ancestral：T=8 為 111.88 對 193.05，T=16 為 75.24 對 89.17，T=32 為 61.31 對 62.29（幾乎平手），T≥64 起 MDLM+SDTT 較好（T=64：55.83 對 47.04；T=1024：50.55 對 36.89）。結論 §7 也承認 USDM 的 perplexity 仍落後 MDM。
9. 「DCD 是把 consistency distillation 搬到離散」：沒有用教師解 ODE，也沒有 (9) 的 λ(t)、d；實際是「同一條 (x,ε) 內插軌跡上相鄰兩點的輸出分布 KL 對齊 + 逐輪加倍步長」，結構上更接近 SDTT/progressive distillation。
10. 「課程 = 模型一路在連續潛變數上訓練」：τ = 0.001 只用於前 500K 步，後 500K 步 τ = 0（純離散）；評估一律用離散 NELBO (18)，α_t = 1 − t。
11. Duo w/o CL（35.0）已勝過 UDLM（36.7）；論文在 §7.1 建議無法調參時就不要用課程。

## 4. 哪些能在瀏覽器即時示範

可以（封閉式或小型蒙地卡羅，全在前端）：
1. **T(α̃) 曲線**：(11) 是一維積分，梯形法數千點即可；用 exp((K−1)·log Φ(z)) 避免下溢。滑桿調 K（2 → 50257）看曲線如何被擠到 α̃≈1 附近。對照點〔顧問推導〕：K=30522 時 T(0.85)=0.008、T(0.95)=0.15、T(0.97)=0.45、T(0.985)=0.94；K=2 時 T = erf(α̃/(2σ̃))。注意 3b 的 Fig. 6 問題。
2. **邊際對偶 (10)**：小 K（如 5），抽 w = α̃x + σ̃ε 取 argmax，直方圖對比 Cat(T x + (1−T)/K)。〔顧問推導〕K=5、α̃=0.6、10⁶ 樣本：得 0.4119 / 0.147，理論 0.4124 / 0.1469。
3. **軌跡不對偶 (40)**：K=3，固定兩個 argmax 相同但數值不同的 w_s，蒙地卡羅 w_t 的 argmax 分布，顯示兩者不同，且「非最大」的兩類機率不相等。
4. **ODE (12)**：用數值差分 dT/dα̃ 驗證 dp/dt = −T′/(K T)[11ᵀ − KI]p。
5. **DDT 軌跡 (22)**：固定 (x, ε)，拖動 t 看每個 token 只在 {x, argmax ε} 間翻一次；翻轉點 α̃ = Δ/√(1+Δ²)（D5）。可與 USDM ancestral 的多次改寫、MDM 的一次揭露並排（對應 Fig. 5）。
6. **f 與 f_Duo 恆等**（D4）：小 K、隨機 x_θ，兩式逐點相等。
7. **softmax(w/τ)**（(20)）：調 τ 看輸入由軟到硬；τ=0.001 時幾乎就是 one-hot。
8. **後驗 (4) 與 ancestral 取樣**：小 K 上用「神諭 x_θ = x」或任意固定 x_θ 走一遍反向鏈，展示 token 可被多次修正。
9. **data-processing 直覺**（Thm 3.2 的精神）：兩個小維高斯的 KL 與其 argmax 推前分布的 KL 比較。只能當直覺，不能當作定理本身的驗證（見 3a-3）。

## 5. 初學者先備知識（教學順序）

1. one-hot 向量、類別分布 Cat(π)、機率單體；argmax 把 R^K 映到 one-hot。
2. 高斯分布的 pdf φ 與 cdf Φ；獨立變數最大值的 cdf 是各 cdf 相乘。
3. 推前分布（pushforward）：把隨機變數經函數映射後的分布。
4. 前向擴散的「邊際」寫法：高斯 N(α̃x, (1−α̃²)I) 與離散 Cat(αx + (1−α)π)；訊雜比。
5. 離散擴散兩種先驗：遮罩（MDM，揭露後不再變）與均勻（USDM，可反覆改寫＝自我修正）。
6. 連續時間 Markov 鏈、速率矩陣 Q、邊際的線性 ODE dq/dt = Qq（只需到能讀 (2)(12) 的程度）。
7. Markov 性質與「邊際相同不代表過程相同」。
8. 貝氏後驗 q(z_s|z_t, x)、以 x_θ 取代 x 的反向過程、ancestral sampling。
9. KL 散度、ELBO/NELBO、perplexity 是 NELBO 的指數；擴散模型報的是上界。
10. data-processing inequality（處理後的分布不會更容易區分）。
11. 梯度估計的偏差與變異；softmax 溫度作為 argmax 的鬆弛（Gumbel-softmax 的同一想法）。
12. PF-ODE/DDIM 的確定性取樣（概念即可）、知識蒸餾與 consistency/progressive distillation 的「少步學多步」。
13. 評估指標：Gen PPL（GPT-2 Large 評分，越低越好）與 average sequence entropy（論文用語；多樣性，太低表示退化）；兩者要一起看。
