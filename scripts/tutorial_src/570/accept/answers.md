# 570 Goldfish 驗收答案（僅依 page.txt）

**LO1** 答：一般 RL 是線上的，邊與環境互動邊收集資料、更新策略；離線 RL 只從一個大小固定的資料集學習，不能再與環境互動。好處：不承擔與環境互動的成本與風險，可用既有紀錄（如人類操作者資料），在機器人、醫療等收集昂貴或有風險的應用特別有用。
引文：「只從一個大小固定」｜信心：high

**LO2** 答：外插誤差。策略評估時，對資料集中沒有的狀態–動作對估計不準；最大化估計值的策略更新會選到這些被高估的分布外（OOD）動作，因此表現差。與行為策略差異夠大的策略很難用此資料評估。
引文：「最大化估計值的策略更新又會選到這些被高估的分布外」｜信心：high

**LO3** 答：actor 最大化 π = argmax_π E_{(s,a)~D}[Q(s,π(s))]（Eq. 1），使 critic 對策略所選動作的值變大。TD3 三個設計（頁面標為「論文外背景」）：
1. clipped double-Q：y = r + γ·min_{j=1,2} Q′_j(s′, ã)，取較小值以抑制高估；
2. 目標策略平滑：ã = clip(π′(s′) + clip(ξ, −0.5, 0.5), −1, 1)，ξ ~ N(0, 0.2²)；
3. 延遲更新：每 2 次 critic 更新，做 1 次 actor 與目標網路更新。
引文：「使 critic 對策略所選動作給出的值變大」｜信心：high

**LO4** 答：
- CQL：修改架構（3 層）、actor 學習率 3e-5、預訓練 actor 40e3 步（只用模仿學習）、移除 SAC 熵項、評估時從策略取 10 個動作取最大者。
- Fisher-BRC：修改架構（3 層）、每筆轉移加常數獎勵 5、移除 SAC 熵項。
拿掉後：Fig. 1 顯示兩方法在許多任務上大幅退步。作者只能假設這些修改是針對 D4RL 評估資料集調整的，兩篇論文都沒有提到訓練／驗證切分。
引文：「拿掉這些實作調整後，兩個方法在許多任務上大幅退步」｜信心：medium（Table 1 排版錯亂，以正文為準）

**LO5** 答：Eq. 3：π = argmax_π E_{(s,a)~D}[λQ(s,π(s)) − (π(s) − a)²]。新增的 −(π(s)−a)² 是行為複製（BC）項，λ 控制正則強度。λ→0：只剩 BC 項，得純 BC（π→ā，資料動作平均）；λ→∞：BC 項可忽略，回到 TD3 的 Eq. 1。
引文：「時只剩 BC 項，得到純 BC」｜信心：high

**LO6** 答（C1 玩具，seed 7，常數為推定，單一狀態一步）：
- 只最大化 Q̂：a = 1.000，Q̂ = 7.185，真實 q = 4.029。
- 純 BC（資料平均）：a = −0.268，真實 q = 4.296。
- TD3+BC（α = 2.5）：a = 0.381，真實 q = 4.834，同時勝過兩者。
效益不單調：α = 2 時真實值 4.99；α = 3 時 4.25，已低於純 BC；α ≥ 3.4 時策略停在動作上界 1。
引文：「效益隨 α 不單調」｜信心：high（數字為玩具示意值）

**LO7** 答：Eq. 5：λ = α / ((1/N)·Σᵢ|Q(sᵢ, aᵢ)|)，α = 2.5，平均取在 mini-batch 上，λ 不微分（只用來縮放損失）。除以平均|Q|的理由：RL 與模仿的平衡對 Q 的尺度很敏感，且除以 |Q| 的平均也使 ∇ₐQ 的尺度在任務間一致，相當於學習率正規化。玩具例：平均|Q̂| = 4.397，λ = 2.5/4.397 = 0.5686。背景（論文外）：官方程式碼用 Q(s, π(s))，與 Eq. 5 不同。
引文：「平均在 mini-batch 上估計，而不是整個資料集」｜信心：high

**LO8** 答：
- 獎勵乘正數 c：理想化下（critic 恰好學到 cQ）最佳策略不變，因 λ 除以 c 使 λQ 不變；實際網路只近似不變。玩具中 c 任意時 π* 皆為 0.381。
- Q 加常數 b：會改變，因平均|Q| 改變使 λ 改變。玩具中 b = +4 時 π* 變為 −0.036；b = −2 時 π* 停在 1。多步任務中，獎勵加 b 約使 Q 加 b/(1−γ)（γ = 0.99 時約 100b）。
引文：「論文本身沒有宣稱不變性」｜信心：high

**LO9** 答：Eq. 4：sᵢ ← (sᵢ − μᵢ)/(σᵢ + ε)，ε = 10⁻³，μᵢ、σᵢ 為資料集上第 i 個特徵的平均與標準差。適合離線因為資料集固定，統計量只需算一次。不用的地方：AntMaze 中正規化有害，因此不使用（App. C.1）。
引文：「資料集固定，統計量只需算一次」｜信心：high

引文：「Total 的 ± 等於 15 列 ± 的總和」｜信心：high

**初學者可能卡住的 5 點**
1. Eq. 3 方向：λ 大 = RL 項強、λ 小 = BC 項強，容易搞反。
2. Eq. 5 與官方程式碼不同（Q(sᵢ,aᵢ) 對比 Q(s, π(s))），且 λ 不微分，頁面未說明 λ 是否應參與反向傳播以外的計算。
3. 玩具數字依 seed 與推定常數而變；「真實值」是玩具的 q(a) 而非 Q̂，且 α = 2 比 2.5 的真實值高，容易誤以為 2.5 最佳。
4. Table 1 與 Table 3 的文字欄位錯位，CQL／Fisher-BRC 的調整難以對應到欄位。
5. Eq. 1 寫的是對資料集 D 取期望，頁面未說明 TD3 原版取樣的回放資料與這裡的 D 有何差別。
