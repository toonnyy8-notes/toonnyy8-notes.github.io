## 1. 論證鏈（9 步）

**步驟 1｜預測目標是可換的，但換了會改變回歸問題（§1、§3）**
- 假設：線性路徑（式 1）、平方誤差。
- 內容：ε、x、u 在給定 (z_t, t) 時資訊等價；ε 預測還原 û = (ε̂ − z_t)/α，x 預測還原 û = (z_t − x̂)/σ。x 預測在低雜訊（σ→0）時誤差被放大 1/σ。
- 沒有證明的部分：「目標選擇強烈影響品質」是引用前人（Karras 2022、Salimans & Ho 2022）。

**步驟 2｜線性目標族每個方向只有一個自由度（附錄 A.1 前兩段）**
- 假設：網路輸出可吸收任意可逆線性變換；平方誤差下最優預測同樣線性變換（E[cy|z] = cE[y|z]）。
- 證明：y = φx + ψε 可正規化為 φ = −1，只剩 w = −ψ/φ。矩陣版：y = Kx + Lε，K 可逆時乘 T = −K⁻¹ 得 u_W = Wε − x，W = −K⁻¹L。
- 例外：K 奇異（純 ε 預測）不在正規形內，只能當 w→∞ 極限。
- 論文自己加的但書：正規化不改變可表示的函數集合，但「可能改變損失幾何與最佳化」。

**步驟 3｜定義目標與閉式還原（式 3–5、8–10）**
- u_W := Wε − x，W = B diag(w_1..w_D) Bᵀ，w_i ≥ 0（式 3、4）。
- 還原：û = (αW + σI)⁻¹((I − W) z_t + û_W)；特徵基底下 û_i = ((1−w_i) z_{t,i} + û_{W,i})/(α w_i + σ)（式 5）。
- 式 10 對任何使 αW+σI 可逆的 W 成立，不需要對稱。

**步驟 4｜為何限制為 PSD（附錄 A.1 末段）**
- 還原在時刻 t 失效 ⇔ −t/(1−t) 是 W 的特徵值；t 掃過 (0,1) 時這個量掃過整條負實軸。例：W = −I 在 t = 1/2 奇異。
- 加上對稱（特徵值全實數、可正交對角化）⇒ W ⪰ 0。w_i = 0 只在 t = 0 奇異，取樣器不會算 t = 0。
- 注意：PSD 是「設計選擇」而非唯一可行族；論文明說一般實矩陣代數上可行但不實用。

**步驟 5｜損失算在還原後的速度上（§4 Training objective、式 6、11、12）**
- L(θ, w) = E‖û − u‖²，不是 ‖û_W − u_W‖²。
- 方向 i 的損失：E_i(w_i; t) = E[(û_{W,i} − u_{W,i})² | t] / (α w_i + σ)²（式 6）。
- 式 11：最優目標預測 u*_{W,i} = (α w_i + σ) u*_i − (1 − w_i) z_{t,i}，還原後恆為 u*_i ⇒ 最小可達損失與 w 無關。
- 式 12：損失 = 超額誤差/(αw_i+σ)² + 不可約誤差；只有前者與 w 有關。
- 含意：w 的梯度完全來自網路的「不完美」；理想網路下 w 沒有被決定。

**步驟 6｜凍結誤差模型 ⇒ 單一時刻的偏好權重（式 13–19、式 7）**
- 假設：(a) û_{W,i} ≈ w_i ε̂_i − x̂_i；(b) e_n = ε̂ − ε*、e_x = x̂ − x* 的二階統計量 A、Γ、C 在收斂附近不隨 w 變（frozen-error）；(c) 交叉項 Γ 可忽略。
- 結論：w_i*(t) = (Γσ + αC)/(Aσ + αΓ)（式 18）；Γ≈0 時 w_i*(t) ≈ (α/σ)·C_i(t)/A_i(t)（式 19 = 正文式 7）。

**步驟 7｜時間依賴抵銷 ⇒ 一組權重就夠（式 20–23）**
- 假設（充分條件，非推導結果）：A_i(t) = α q_i(t) Ā_i，C_i(t) = σ q_i(t) C̄_i，Γ = 0。
- 結論：每個內部時刻的最小點都是 w_i* = C̄_i/Ā_i，所以也是任何時間分佈下時間平均損失的最小點。
- 實驗支持：四個時間桶各學一組權重，曲線幾乎重合；FID 4.92（共用）對 4.96（隨時間），160 epochs（§6.1.2；圖 5 標明 JiT-B/16）。

**步驟 8｜近線性頻譜律 w_i ≈ cλ_i（式 24；附錄 A.3 圖 8）**
- 再加兩個假設：Ā_i ≈ Ā（雜訊各向同性）；C̄_i ∝ λ_i（各方向相對誤差相近）。⇒ w_i* ∝ λ_i。
- 常數 c 理論不預測（論文明說，取決於誤差結構、時間取樣器、最佳化）。
- 經驗檢驗（A.3，600-epoch AnisoFlow-H/16、凍結 PCA 基底、兩個輔助線性讀出頭）：Ā^eff ∝ λ^−0.09，C̄^eff ∝ λ^1.00，比值 ∝ λ^1.09，學到的權重指數 1.07；(C̄^eff/Ā^eff)/w_i 中位數約 0.97；t≈0.25–0.80 五個 bin 內 α/σ 變化 11.7×，估計的偏好權重中位數只變 1.19×。

**步驟 9｜基底怎麼學、為何會靠近 PCA（§4、附錄 A.4–A.5）**
- 式 39：基底相關損失 L_B = Σ_i b_iᵀ M_i b_i + const，M_i = E_t[(S_t − 2 w_i H_t)/(α w_i + σ)²]，r := sg(û_W) + x，S_t = E[rrᵀ|t]，H_t = ½E[rεᵀ + εrᵀ|t]。給定網路輸出與權重時為精確式。
- 假設 1（M_i 兩兩可交換）下命題 2：最優 B = B⋆ Π diag(s)（Birkhoff–von Neumann）；任何有相異特徵值的 Σγ_i M_i 的特徵向量都給出共同基底。實作取均勻平均 G（式 40–41），B ← eigvecs(G)。
- 網路輸出為零時 r = x，G ∝ E[xxᵀ] ⇒ 第一次更新就得到（單一 minibatch 的、帶雜訊的）PCA 基底。
- 線性模型（A.5）：最優線性預測器 Φ*_t(W) = (σW − αΣ)Σ_{z,t}⁻¹（式 43），還原後的速度預測 (σI − αΣ)Σ_{z,t}⁻¹ 與 W 無關（式 44）⇒ 線性模型「不識別權重也不識別基底」；PCA 對齊是 spectral update 這個迭代的性質，不是損失的性質。W 與 Σ 可交換時為不動點；局部穩定條件 |ρ_jk| < 1（式 48–49）。
- 範圍聲明（論文自述）：不證全域收斂，不證網路＋權重＋EMA 聯合動態的穩定性。

**實驗結論（§6）**：ImageNet 256 JiT-H/16：FID 1.90 → 1.55（表 1，600 epochs）；T2I 512：除 GenEval 外皆小幅改善（表 3）；latent（SiT-XL/2-REPA、RAEv2）與預設目標持平（表 4）；8-bit 推論的 patch seam 僅有定性圖（圖 1b、6b）。

## 2. 必須講對的推導（5 個）

### D1. 速度還原（式 8–10）
條件：α + σ = 1（線性 rectified-flow 排程）。別的排程此式不直接成立。
```
(1−w) z_t + u_W = (1−w)(αx + σε) + wε − x
  x 係數：(1−w)α − 1 = −(σ + αw)        （用 α − 1 = −σ）
  ε 係數：(1−w)σ + w = σ + w(1−σ) = σ + αw
= (αw + σ)(ε − x) = (αw + σ) u
⇒ u = ((1−w) z_t + u_W)/(αw + σ)
```
代入檢查：w=0 ⇒ u = (z_t − x)/σ（x 預測，û_W = −x̂）；w=1 ⇒ u = u_W（速度預測）；w→∞ ⇒ u → (ε − z_t)/α（ε 預測）。
矩陣版同理：(I−W) z_t + u_W = (αW + σI) u。可逆 ⇔ −σ/α = −t/(1−t) 不是 W 的特徵值。

〔顧問推導〕等價讀法（教學上很有用）：若把 û_W 寫成 w ε̂ − x̂，
```
û = [αw · (ε̂ − z_t)/α + σ · (z_t − x̂)/σ] / (αw + σ)
```
即「ε 路線的速度估計」與「x 路線的速度估計」的凸組合，權重為 αw/(αw+σ) 與 σ/(αw+σ)。w 就是在調這兩條路線的混合比例。

### D2. 損失分解與「w 不改變最小損失」（式 6、11、12）
- 誤差傳遞：û_i − u_i = (û_{W,i} − u_{W,i})/(αw_i + σ)。直接由 D1（z_t 項相消）。⇒ 式 6。
- 式 11：對 u_W = (αw+σ)u − (1−w) z_t 取 E[·|z_t,t]，z_t 是條件內的已知量 ⇒ u*_W = (αw+σ)u* − (1−w) z_t；還原回去恰為 u*。
- 式 12：û_W − u_W = (û_W − u*_W) + (u*_W − u_W)，第二項 = −(αw+σ)(u − u*)。交叉項因條件期望正交性為 0（û_W − u*_W 是 z_t 的函數）。除以 (αw+σ)² 後第二項變成 E[(u − u*)²|t]，與 w 無關。
- 條件：平方誤差；û_W 是 (z_t, t) 的函數。

### D3. 單一時刻的偏好權重（式 13–19）
凍結誤差下 f(w) = (A w² − 2Γ w + C)/(αw + σ)²。
```
f'(w) = [(2Aw − 2Γ)(αw+σ) − 2α(Aw² − 2Γw + C)] / (αw+σ)³
      = 2[ w(Aσ + αΓ) − (Γσ + αC) ] / (αw+σ)³          （Aαw² 項相消）   （式 17）
f'(w)=0 ⇒ w*(t) = (Γσ + αC)/(Aσ + αΓ)                                   （式 18）
Γ=0   ⇒ w*(t) = (α/σ)·C/A                                              （式 19 / 式 7）
```
條件：Aσ + αΓ > 0 且 Γσ + αC > 0 才是 w ≥ 0 上的內部最小；Γ=0、A>0、C>0、t∈(0,1) 時為唯一最小點（分子在 w* 由負轉正）。
直覺：資料難估（C 大）⇒ 多放雜訊；雜訊難估（A 大）⇒ 少放雜訊。

〔顧問推導〕最小值本身（Γ=0）：f(w*) = AC/(α²C + σ²A)，即 1/f* = α²/A + σ²/C。這是兩個獨立估計的「逆變異數加權」：ε 路線的速度誤差變異數為 A/α²，x 路線為 C/σ²，最佳混合比 (α²/A):(σ²/C) 令其等於 D1 的 αw:σ 即得 w* = αC/(σA)。對照：w=0 得 C/σ²，w→∞ 得 A/α²，兩者都 ≥ f*。此讀法依賴 Γ=0（兩誤差不相關）。

### D4. 時間抵銷（式 20–23）與零技能反例（式 25–26）
代入 A = α q Ā，C = σ q C̄，Γ=0：
```
f'(w) = 2[wAσ − αC]/(αw+σ)³ = 2ασ q(t) Ā (w − C̄/Ā)/(αw+σ)³               （式 21–22）
```
符號只由 (w − C̄/Ā) 決定 ⇒ 所有 q>0 的時刻共用最小點 w* = C̄/Ā（式 23）⇒ 也是任意內部時間分佈下時間平均損失的最小點（需期望損失有限；q>0 的集合有正機率則唯一）。
反例（零技能，û_W = 0）：損失 = E_t[(w² + λ)/(αw+σ)²]（式 25），相當於 A=1、C=λ 不隨 t 變，逐時刻最小 w*(t) = (α/σ)λ（式 26）— 沒有抵銷，偏好的常數權重取決於時間分佈。
兩個「∝ λ」不要混：零技能是 w*(t) = (α/σ)λ（隨時間、係數已知）；訓練後網路是 w* = C̄/Ā ≈ cλ（不隨時間、c 未知，H/16 實測 0.15）。
與 EDM 的關係（式 27–30）：z̃ = x + s ε，s = σ/α；c_skip,i = λ_i/(λ_i + s²)；x − c_skip z̃ = (1−c_skip)(x − w ε)，w = c_skip s/(1−c_skip) = λ/s = (α/σ)λ。只成立於 t<1（α>0），且是「把 EDM 的純量資料變異數換成每方向 λ_i」的延伸，不是 EDM 原式。

### D5. Spectral update（式 39–41）與 A.3 的有效誤差（式 31–36）
(a) 基底損失：û_i − u_i = (b_iᵀ r − w_i b_iᵀ ε)/(αw_i + σ)，r = sg(û_W) + x。平方取期望：
```
b_iᵀ E[rrᵀ] b_i − 2w_i b_iᵀ E[rεᵀ] b_i + w_i² b_iᵀ E[εεᵀ] b_i
```
第三項 = w_i²（E[εεᵀ]=I、‖b_i‖=1）與 b_i 無關，丟掉；第二項對稱化成 H_t。⇒ 式 39。
每個 b_i 被不同的 M_i 計分 ⇒ 一般不是特徵值問題；需假設 1（可交換）。命題 2 證明要點：B = B⋆Ω，L_B = Σ_{ij} κ_ij Ω_ji²，[Ω_ji²] 雙隨機，線性函數在雙隨機集合的最小值落在排列矩陣。
G = (1/D)Σ M_i = E[a_t rrᵀ − b_t(rεᵀ + εrᵀ)]，a_t = (1/D)Σ_j 1/(αw_j+σ)²，b_t = (1/D)Σ_j w_j/(αw_j+σ)²。
初始化：û_W = 0 ⇒ r = x，E[xεᵀ]=0 ⇒ G = E[a_t]·E[xxᵀ]。「x 置中」時才等於共變異數。
注意：實作的 rank 配對（特徵值升冪、w_i 綁 rank i）是啟發式（Remark 3），不保證解命題 2 的指派問題；G 有重根時特徵向量不唯一。

(b) A.3 有效誤差：量到的是對樣本的殘差 r_n = ε̂ − ε、r_x = x̂ − x，不是對條件均值的誤差。用 ε − ε* = −(α/σ)(x − x*)（式 33，來自 z_t 固定）與正交性：
```
a = A + (α²/σ²)F,   b = C + F,   g = Γ − (α/σ)F          （式 34，F = E[(x − x*)²|t]）
A^eff = a + (α/σ) g = A + (α/σ)Γ
C^eff = b + (σ/α) g = C + (σ/α)Γ                        （式 35，F 精確相消）
(α/σ)·C^eff/A^eff = (αC + σΓ)/(σA + αΓ) = 式 18        （式 36，不需假設 Γ=0）
```
條件：ε̂、x̂ 是 (z_t, t) 的函數；仍在凍結誤差模型內。

## 3. 常見誤讀、內部不一致、未交代處

### 3.1 看起來對但論文沒有證明的說法
1. 「理論預測 w ∝ λ」。實際上線性律來自兩個額外假設（Ā_i ≈ Ā、C̄_i ∝ λ_i），等於把結論放進假設；真正的支持是 A.3 的事後量測（指數 1.00 與 −0.09）。常數 c 理論完全不給（Limitations 也承認）。
2. 「一組權重夠用是推導出來的」。式 20 是「充分條件」的假設；證據是圖 5 與圖 8c，且圖 8c 只涵蓋 t≈0.25–0.80 的「可靠 bin」，兩端未驗證。
3. 「A.3 直接量到了 A_i、C_i」。論文自己說這是 consistency check：單一輸出頭無法唯一拆成 ε̂ 與 x̂，用的是凍結網路上另外擬合的兩個線性讀出頭（30K 訓練圖做加權 ridge、另 30K 評估）；60 個方向只留 18 個（重建誤差 <5%、還原速度 MSE 增加 <1%），λ 範圍 0.205–171；放寬到 10–20% 時為 45–51 個方向。用的是凍結 PCA 基底的 checkpoint（表 1 的 1.63 那個），不是 1.55 的最佳模型。
4. 「w_i ≈ 0.15λ_i 對全部 768 個方向成立」。圖 3a 是裁掉變異數 <0.015 的版本；未裁版（圖 9）顯示約在第 256 個方向（patch embedding 瓶頸維度）之後明顯偏離。A.3 的 18 個方向也都在 λ ≥ 0.205。
5. 「AnisoFlow 普遍優於固定目標」。latent 空間持平：SiT-XL/2-REPA 1.44 對 1.44（JiT FID 1.41→1.40），RAEv2 1.05 對 1.05（0.98→0.96）；權重曲線平很多，論文明說近線性假設不直接適用。
6. 「目標完全可學（fully learnable）」。實際族：線性、PSD、每個 patch 共用、跨時間共用的 W。且實作 w_i = exp(η_i) 為嚴格正（B.1），正文寫的是「非負」；w=0（純 x 預測，表 1 的 JiT「Frozen (zeros)」）只能逼近不能取到。
7. 「AnisoFlow 是 x 與 u 之間的內插」。c=0.15 時 λ > 1/0.15 ≈ 6.7 的方向 w > 1〔顧問推導〕，比速度預測放更多雜訊（偏向 ε 預測）；圖 3a 的權重約從 10⁻³ 到 10¹ 以上。
8. 「量化穩定性有數字佐證」。只有圖 1b、6b 的定性比較（同 prompt、同 seed，W8A8，只量化 transformer 線性層的權重與 activation）；沒有任何量化後的指標，也沒說明校正方式或 INT8/FP8/blockwise FP8 的具體設定。「為何誤差表現為 patch 接縫」也只有 1/σ 放大的定性解釋。
9. 「well-conditioned」是相對的。〔顧問推導〕t→0 時分母 → w_i，低變異方向 w_i ~10⁻²–10⁻³ 仍有很大放大倍率；推論時另有分母下限 σ_min = 4×10⁻²（B.1，基線與 AnisoFlow 都用），最大放大 25×。x 預測之所以較差是因為「所有」方向分母都是 σ。
10. 「圖 1a 是表 3 那個模型的輸出」。不是：圖 1 的一百萬像素樣本來自額外的 1MP 階段＋SFT 階段（Z-Image Turbo 合成圖微調），沒有定量評估，也沒有對應基線（B.3、表 6）。
11. 「損失不變」。形式上仍是速度空間 FM 損失，但換成 û_W 的語言後等於每方向乘上 1/(αw_i+σ)² 的權重（式 6）〔後半句為顧問的改述〕。網路學的函數變了，損失幾何也變了。
12. 「PCA 基底是損失的最優解」。A.5 明說線性模型下損失與 W 無關；PCA 對齊是 spectral update 迭代的性質。非線性網路下只有經驗觀察（圖 3b，高變異方向對齊最強，低變異方向較散）。

### 3.2 數字與表格的不一致／需小心處

### 3.3 未交代或交代不足
- ImageNet 訓練超參數全部指向 JiT 論文表 9；時間分佈只在 A.3 順帶提到「training logit-normal」。
- 「PCA init + spectral update」的實際意義：G 初始化為 I、每步 B ← eigvecs(G)，所以 B 的 PCA 初始值在第一步就被單一 minibatch 的特徵向量取代〔顧問推導，依 A.4.2 末段與 B.1〕；真正留下的主要是 w_i = 0.15λ_i 的初始權重。PCA-init 版本是否另外初始化 G 未說明。
- G 的特徵值排序與 λ 排序是否一致、訓練中 rank 交叉多常發生，未報告。
- A.4.2 說 G ∝ E[xxᵀ]「對置中資料即共變異數」；PCA 是對「去均值的 patch」算的（B.2），但網路看到的 patch 是否去均值未說明。
- T2I 的 512 階段基底凍結、只學權重（表 6）；256 階段 1M iterations、512 階段 250K。
- Stiefel Adam 是 Euclidean 度量下的投影–搬運法，非平行搬運；二階動量是每個基底一個純量。
- 跨方向耦合（圖 10，JiT-B/16、32 個自由方向）：高變異方向不受背景影響，最低變異方向較敏感 — 逐方向分析只是近似。

## 4. 哪些可以在瀏覽器即時示範

### 可以（閉式或小型數值）
1. **還原恆等式（D1）**：滑桿 t、w，隨機抽純量 x、ε，顯示 ((1−w)z + u_W)/(αw+σ) 恆等於 ε − x。附 w=0 / 1 / 大值三個特例。
2. **誤差放大倍率 1/(αw+σ)**：對 t 畫曲線，比較 w=0（1/t 發散）、w=1（恆為 1）、w=0.15λ 的幾條；可加上 σ_min = 0.04 的截斷線（最大 25×）。這是式 5/6 的直接圖示，不是量化實驗的重現。
3. **單一時刻最佳權重（D3）**：滑桿 A、C、Γ、t，畫 f(w) = (Aw² − 2Γw + C)/(αw+σ)²，標出式 18 的 w*，並標 w=0 的值 C/σ² 與 w→∞ 的極限 A/α²。可加顯示 〔顧問推導〕 的 f* = 1/(α²/A + σ²/C)（須標註為補充）。
4. **時間抵銷（D4）**：選 q(t)，設 A = αqĀ、C = σqC̄，畫數個 t 的 f(w)，最小點全落在 C̄/Ā；切到零技能（A=1、C=λ）則最小點隨 t 滑動為 (α/σ)λ，時間平均的最佳常數隨時間分佈改變（數值積分；勿用含 t=0 的均勻分佈配 w=0，λ/t² 發散）。
5. **高斯玩具的「w 不變性」（式 11、43–44 的純量版）**：x_i ~ N(0, λ)，最優線性預測 Φ* = (σw − αλ)/(α²λ + σ²)，還原後係數 (σ − αλ)/(α²λ + σ²) 與 w 無關。拖 w，目標預測線在動、還原後的速度線不動。
6. **EDM 對應（式 27–30）**：輸入 λ、t，算 c_skip、w = (α/σ)λ，數值驗證式 29 兩邊相等。
7. **Spectral update 第一步 = PCA**：2D 相關高斯點雲，r = x，G = E[a_t]·Σ̂，特徵向量即主軸；可顯示 minibatch 小時的抖動（對應「noisy PCA」）。
8. **目標族示意（圖 2b）**：條狀圖切換 w_i = 0 / 1 / 常數 / 二值 / 0.15λ_i。λ 譜需自行合成（論文沒給數值），要標明是示意。

### 不可以或只能示意
- **w ∝ λ 的「湧現」**：線性／高斯最優預測器下損失與 w 無關（A.5 明說），所以沒有誤差模型就學不出任何 w；手動設 C̄ ∝ λ 再得到 w ∝ λ 是循環論證。要真的重現需訓練有容量限制的非線性網路（JiT 等級），瀏覽器不可行。可做的只是「給定假設 ⇒ 結果」的計算，須如此標示。
- **FID 1.90→1.55、表 1–4 全部數字**：需完整訓練與 50K 取樣評估。
- **圖 8 的誤差指數（−0.09 / 1.00 / 1.09 / 1.07）與 1.19× vs 11.7×**：依賴訓練好的 H/16 checkpoint 與輔助讀出頭。11.7× 可由 α/σ 在 t=0.25（=3）與 t=0.80（=0.25）粗略對上（12×）〔顧問核算；bin 中心論文只說「約」〕。
- **8-bit 量化的 patch seam**：需要真實量化網路；玩具只能示範「同樣大小的目標誤差經 1/(αw+σ) 放大後差多少」，不能宣稱重現圖 6b。
- **基底局部穩定性 ρ_jk（式 48–49）**：2D 可硬算，但需對 t 積分且對初學者資訊量低；不建議。
- **Stiefel Adam vs spectral 的 FID 差異、跨方向耦合（圖 10）、輸入瓶頸效應（圖 9）**：皆為大模型訓練現象。

## 5. 先備知識（教學順序）

1. 向量、內積、正交基底；在基底下取座標（b_iᵀ x）。
2. 期望值、變異數、共變異數矩陣；獨立高斯雜訊 N(0, I) 在任何正交基底下仍各向同性。
3. 條件期望是平方誤差下的最佳預測；殘差與任何 z 的函數正交（D2、式 34 都靠這一條）。
4. Flow matching 基礎：z_t = (1−t)x + tε、速度 u = ε − x、損失式 2、由 t=1 積分到 t=0 取樣。
5. 三種傳統目標（ε / x / u）與彼此的線性換算；1/σ、1/α 的誤差放大。
6. Patchify：一個 token = 16×16×3 = 768 維；W 作用在單一 patch 上、所有位置共用（影像層級為 I_N ⊗ W）。
7. 特徵分解、對稱矩陣、PSD；PCA = 共變異數的特徵分解，λ_i 是方向 i 的資料變異數；自然影像 patch 的 λ 跨數個數量級。
8. 單變數有理函數求極值（商的微分）— D3 只需要這個。
9. log-log 圖上斜率 = 冪次；「近線性」在此指冪次約 1（實測 1.07–1.09）。
10. （進階、可略）正交矩陣流形與 Stiefel 最佳化、雙隨機矩陣與 Birkhoff–von Neumann、EMA、特徵向量微擾。
11. （應用段需要）FID／pFID 與評估協定差異、classifier-free guidance、8-bit 量化（W8A8）的基本概念。
