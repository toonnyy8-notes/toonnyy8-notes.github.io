## 1. 介紹（步驟 6-1）

### 1.1 一段話總結

遮罩擴散語言模型（masked diffusion model, MDM；本論文稱 dLLM）從全部是遮罩符號 [M] 的序列開始，每一步由模型對所有位置輸出 token 分布，再由一個「取樣策略」決定這一步要解開（unmask）哪些位置。現行最好的做法是信心度啟發式規則，例如 Fast-dLLM 解開所有信心度超過門檻 λ 的位置；但這類規則要手動調參，且在不分區塊的完整擴散（full diffusion）設定下表現會低於隨機解遮罩（Fig. 1）。本文把取樣寫成馬可夫決策過程（MDP）：凍結的 dLLM 是環境，一個約 300K 參數的單層 transformer 是策略，輸入各位置的信心度、遮罩向量與步數，對每個位置輸出 Bernoulli 解遮罩機率（Sec. 3.1–3.2）。策略以 GRPO 訓練，獎勵是「答對與否 × 速度懲罰」的乘積（Eq. 3.1）。在 LLaDA-8B-Instruct 上，學到的策略在半自回歸（semi-AR，BL = 32）設定下與 Fast-dLLM 相當，在完整擴散（BL = L = 256）下優於所有啟發式規則（Sec. 4.1–4.2）。

### 1.2 研究動機（Sec. 1、Sec. 2.2）

1. MDM 每一步可以平行產生多個 token，理論上比自回歸（AR）模型快；Fast-dLLM 的信心度門檻是開源 dLLM 追上 AR 推論效率的關鍵（Sec. 1）。
2. 啟發式規則的缺點：要手動選信心度量與門檻 λ；高度依賴 semi-AR 區塊生成（區塊長度 BL 又是一個超參數）；在完整擴散設定下，信心度規則可能低於隨機解遮罩，且增加 NFE 不再改善（Fig. 1）。
3. 作者認為這些限制來自「啟發式規則是序列決策問題的手工解」：該以什麼順序解遮罩，才能在正確性與效率之間取得平衡（Sec. 1）。因此改用強化學習直接學取樣策略。與 d1 等 RL 後訓練不同，本文不改 dLLM 本身，只訓練獨立的小型策略網路（Sec. 1、Sec. 5）。

### 1.3 貢獻（Sec. 1）

1. 把 dLLM 取樣形式化為 MDP（Sec. 3.1），提出輕量策略設計（Sec. 3.2），以 GRPO 訓練（Sec. 3.3）。
2. 學到的策略在 semi-AR 下與 Fast-dLLM 相當（Sec. 4.1），並改善啟發式規則在 semi-AR 以外的問題（Sec. 4.2）。
3. 研究策略在模型、資料領域、生成長度之間的遷移（Sec. 4.3），以及穩定 RL 訓練與策略設計的消融（Sec. 4.4）；並顯示策略的解遮罩行為與信心度規則在性質上不同（App. C）。

### 1.5 從作者的角度逐步拆解

每一步說明：作者要回答什麼、做了什麼、得到什麼、下一步為什麼需要它。

#### 步驟 1：MDM 怎麼訓練、怎麼生成（Sec. 2.1）

- 前向過程（Sec. 2.1 無編號式）：每個 token 獨立地以機率 $t$ 變成 $M$，以機率 $1-t$ 保持原樣：$p_t(x_t^k\mid x_0)=1-t$（若 $x_t^k=x_0^k$）、$t$（若 $x_t^k=M$）、其他為 0。
- 訓練目標（Eq. 2.1，ELBO）：$\mathcal L(\theta)=\mathbb E_{t\sim U[0,1],x_0,x_t}\big[\tfrac1t\sum_k\mathbb 1[x_t^k=M]\log p_\theta(x_0^k\mid x_t)\big]$，只在被遮住的位置計算對數似然並乘 $1/t$。
- 生成（Eq. 2.2）：$y_T=(M,\dots,M)$；每一步 dLLM 輸出所有位置的 $p_t^k$，取樣策略選出 $U_t\subseteq\mathcal M_t$；$U_t$ 內的位置抽樣 $y\sim p_t^k$，其他位置不變。
- 生成速度以 NFE（network function evaluations）計，等於取樣步數；每一步是一次 dLLM 前向計算（Fig. 1 說明文字）。標準 MDM 每步在隨機位置解開固定數量的 token（Sec. 1）。
- 下一步的理由：Eq. 2.2 把「選哪些位置」留給取樣策略，這是全文要學的對象。

#### 步驟 2：現行啟發式規則與其失效（Sec. 2.2、Fig. 1、App. C.3）

- 高信心 top-K（Chang et al., 2022，MaskGIT）：$U_t^K=\arg\max_{I\subseteq\mathcal M_t,|I|=K}\sum_{k\in I}c_t^k$。
- Fast-dLLM 門檻（Wu et al., 2025）：$U_t^\lambda=\{k\in\mathcal M_t\mid c_t^k>\lambda\}$，每步解開的數量可變。
- semi-AR：一次只對一個長度 $BL$ 的連續區塊解遮罩，區塊依序由左到右。
- 失效（Fig. 1，數字取自 App. J Table 2、Table 4，LLaDA、GSM8K、L = 256）：semi-AR（BL = 32）時 Fast-dLLM 最高 79.7%（82.2 NFE）；完整擴散（BL = 256）時 Fast-dLLM 最高只有 38.7%（32.1 NFE），256 NFE 時 33.6%，而隨機解遮罩在 256 NFE 有 51.6%。高信心 top-K 在 32 NFE 達 43.6% 後下降到 256 NFE 的 33.6%。
- 現象與原因（App. C.3）：Fast-dLLM 在完整擴散下「often generates tokens in a 'reverse' order」，Fig. 7 說明文字寫「somewhat reverse」，即常呈現右到左的生成順序（Fig. 7、Fig. 26）。作者推測（原文「likely stems from」）原因是 LLaDA 的 SFT 沒有把填充 token（padding）排除在損失之外，模型對填充 token 過擬合、信心度偏高，信心度規則因此常先解開序列尾端的填充 token。
- 下一步的理由：手工規則沒有機制辨認並略過填充 token 偏高的信心度，作者改為學習規則。

#### 步驟 3：把取樣寫成 MDP（Sec. 3.1）

- 時間倒數 $t=T,T-1,\dots,1$，與 Sec. 2.1 生成的記號一致。
- 狀態 $(x,y_t)$；初始 $y_T$ 全遮罩。動作 $u_t\in\{0,1\}^L$，$u_t\sim\pi_\phi(\cdot\mid y_t)$。轉移 $y_{t-1}\sim P(y_{t-1}\mid y_t,u_t;\tau)$ 就是 Eq. 2.2，$U_t^\pi=\{k\in\mathcal M_t\mid u_t^k=1\}$。
- 獎勵 $R(y,y_t)$ 只在 $\hat T=\max\{t\in[T]\mid y_t^k\ne M\ \forall k\}$ 給出；要同時鼓勵正確（$y_{\hat T}$ 接近 $y$）與效率（步數 $T-\hat T$ 少）。
- 目標（Sec. 3.1 無編號式）：$\max_\phi\mathbb E\big[\sum_{t=1}^TR(y,y_t)\big]$。
- 重點：dLLM 是**環境**，不是策略，參數完全不變（Fig. 2：dLLM 凍結、約 7–8B 參數；策略約 300K 參數）。

#### 步驟 4：輕量策略的設計（Sec. 3.2、App. A、App. H、App. I）

- 輸入只用信心度 $c_t$（加上遮罩向量 $m_t$ 與步數 $t$），不看 token 本身：$b_t=f_\phi(c_t,m_t,t)\in\mathbb R^L$。理由：信心度在每一步本來就算好、不增加計算；啟發式規則也只用信心度；改用 dLLM 隱藏狀態需要大得多的策略且沒有穩定改善（Sec. 3.2、Sec. 4.4）。
- 架構（Sec. 4.1、App. H Table 1、App. I）：單層 transformer，adaptive layer norm（AdaLN）做條件；注意力層用 RoPE；hidden 128、feedforward 512、2 個 head、時間嵌入維度 128；總參數約 300K，不到 dLLM 的 0.01%（Sec. 3.2）。〔本頁推導〕以 LLaDA-8B 為例：300K / 8B = 0.00375%（Dream-7B 為 0.0043%）；論文只寫「< 0.01%」，頁面以「LLaDA 的示例」標示。AdaLN（adaptive layer norm）：以步數 $t$ 的嵌入產生 layer norm 的縮放與平移，讓同一組權重隨步數改變行為；RoPE（rotary position embedding）：在注意力中編碼位置，使網路知道各信心度在序列中的位置（頁面架構表各用一句說明用途，不展開）。App. I 的資料流（依圖的排列推定）：$c$（形狀 $(L,k)$，k 為 top-k 信心度數量，主實驗為 1）經線性投影，$m$ 經嵌入，兩者相加；$t$ 經正弦嵌入與 MLP 作為 AdaLN 條件；Attn+RoPE、MLP 各接殘差；最後 LN 與線性投影得到 $(L,)$ 的 logit。
- Bernoulli 似然（Sec. 3.2）：$u_t^k\sim\mathrm{Ber}(s_t^k)$，$s_t^k=\sigma(b_t^k)$；$\pi_\phi(u_t)=\prod_k(s_t^k)^{u_t^k}(1-s_t^k)^{1-u_t^k}$，閉式可算，不需近似（對比 dLLM 後訓練需要近似似然，Zhao et al. 2025a）。已解開的位置不計入似然（Sec. 3.3），Alg. 1 第 16 行把它們的 $u$ 設為 0。
- 策略溫度（Sec. 3.2）：生成時 $s_t^k=\sigma(b_t^k/\tau_\pi)$；$\tau_\pi$ 越小，機率越接近 0 或 1。實驗用 $\tau_\pi=0.5$（BL = 32）、$\tau_\pi=1$（BL = 256）（Fig. 4 說明、Fig. 16）。
- 全為 0 時的 fallback（Sec. 3.2、Alg. 1 第 17–18 行）：若 $u_t=0$，解開 $s_t^k$ 最大的位置（作者寫「similar to Fast-dLLM」）。**只在測試時使用**；訓練時強制解遮罩容易造成 reward hacking。訓練時若 $T$ 步內沒解完就終止，帶著剩下的遮罩評分；這類樣本得到很低或零獎勵（論文原文「low or no reward」，指正確性分數 $r$），策略很快學會不留遮罩。頁面的玩具模型把未完成樣本統一定義為 $r=0$、用滿 $T$ 步（步驟 7「未完成樣本」規則）。
- 替代方案 DPLS（App. E）：以 Plackett–Luce 模型加上固定效用 $b_{\mathrm{STOP}}=0$ 的 STOP token，依 softmax$(b_t/\tau_\pi)$ 逐一抽取不放回，抽到 STOP 即停；保證每步至少解開一個位置。消融顯示與 Bernoulli 表現相近（Fig. 9c），作者因簡單而採用 Bernoulli。頁面把 DPLS 放在 S12 的附註，不在 S5 展開。
- 下一步的理由：有了閉式的 $\pi_\phi(u_t)$，就能直接用策略梯度法訓練。

#### 步驟 5：GRPO 訓練（Sec. 3.3、App. H）

- 背景（研究筆記 `rl-post-training-dllm-grpo`）：GRPO（Shao et al., 2024，DeepSeekMath，2402.03300）是 PPO（Schulman et al., 2017，1707.06347）的變體，以組內平均獎勵代替價值網路。策略梯度的三句說明（頁面 S6 照用）：「優勢為正的動作，更新後機率提高；為負則降低。」「$\rho$ 是新舊策略對同一個動作給出的機率比。」「截斷限制單次更新可以把 $\rho$ 推離 1 多遠。」
- 對每個提示 $x$ 抽 $G$ 條軌跡（$G=8$，Table 1）。dLLM 溫度固定 $\tau=0$（貪婪解碼），所以同組樣本的差異**只來自解遮罩動作**。
- 優勢：$A_t^g=R(y,y_{\hat T_g}^g)-\frac1G\sum_{i=1}^GR(y,y_{\hat T_i}^i)$，不除以標準差（依 Zhao et al., 2025a 的建議）。最後一步的獎勵傳給該軌跡的所有步驟，同一條軌跡的每一步優勢相同。
- 目標（Sec. 3.3 無編號式）：
  $$J(\phi)=\mathbb E\Big[\frac1G\sum_{g=1}^G\frac1{T-\hat T_g}\sum_{t=\hat T_g}^{T}\min\big(\rho_t^gA_t^g,\ \mathrm{clip}(\rho_t^g,1-\epsilon,1+\epsilon)A_t^g\big)\Big],\quad\rho_t^g=\frac{\pi_\phi(u_t^g)}{\pi_{\phi_{\mathrm{old}}}(u_t^g)}$$
  求和範圍與正規化照原文抄錄：$t=\hat T_g..T$ 共 $T-\hat T_g+1$ 項，正規化因子是 $T-\hat T_g$（差一，見 R4）。頁面照原式顯示並加註「照原文；項數為 $T-\hat T_g+1$」，元件不使用此式，也不自行改寫。
  $\pi_{\phi_{\mathrm{old}}}$ 是產生 rollout 的舊策略；比值與截斷用來穩定 off-policy 更新。策略從頭訓練，所以移除 KL 正則項（Table 1：$\beta_{\mathrm{KL}}=0$）。$\epsilon=0.5$（expert steering 時 0.2）。
- 〔本頁推導〕Bernoulli 策略的比值可在對數空間逐位置相加：$\log\rho_t^g=\sum_{k\in\mathcal M_t}\big[u^k\log\frac{s^k}{s^k_{\mathrm{old}}}+(1-u^k)\log\frac{1-s^k}{1-s^k_{\mathrm{old}}}\big]$。
- 〔本頁推導〕這是標準 PPO 截斷的性質：只在截斷項是 min 的取值側時（$A>0$ 且 $\rho>1+\epsilon$，或 $A<0$ 且 $\rho<1-\epsilon$），目標對 $\rho$ 是常數，梯度為 0。其他區域目標等於 $\rho A$，包括 $A>0,\rho<1-\epsilon$ 與 $A<0,\rho>1+\epsilon$ 兩區（截斷不生效，`check.py` 的 $f(\rho)$ 輸出可見）。C3a 的截斷圖畫這一點。
- 下一步的理由：GRPO 只看組內相對獎勵，所以獎勵怎麼組合正確與速度，直接決定哪些樣本被強化。

#### 步驟 6：乘法獎勵（Eq. 3.1、Sec. 4.4）

$$R(y,y_t)=\begin{cases}r(y,y_t)\cdot\big(1-\frac{T-t}{T}\big)^\alpha,& t=\hat T\\0,&\text{otherwise}\end{cases}\tag{Eq. 3.1}$$

- Eq. 3.1 的「0, otherwise」指 $t\ne\hat T$ 的非終止步（獎勵只在最後一步給一次），不是「未完成樣本得 0」；未完成樣本的處理見步驟 7。
- $r$ 是任務的正確性分數。Eq. 3.1 的說明以二元獎勵為例（「e.g., a binary reward」）；實作用 d1（Zhao et al., 2025a）的獎勵（Table 1），論文沒有寫出 d1 獎勵的組成（例如是否含格式分）。$\alpha\ge0$ 控制正確率與速度的權衡；$\alpha$ 越大，策略越快（Fig. 3）。
- 〔本頁推導〕在 $t=\hat T$ 時 $1-\frac{T-\hat T}{T}=\hat T/T$，即「剩下的步數預算比例」，所以 $R=r\,(\hat T/T)^\alpha$。依 Sec. 3.1 的定義 $\hat T\in[T]$，即 $\hat T\ge1$，所以字面上速度因子至少是 $(1/T)^\alpha$，不會恰為 0。推定：若以 $\hat T=0$ 表示用滿 $T$ 步（Alg. 1 以迴圈變數 $\hat T\leftarrow t$ 結束，沒有說明 $t=0$ 的情況），速度因子為 0（$\alpha>0$）；$\alpha=0$ 時取 $0^0=1$，獎勵只看正確性。
- 加法版本 $r-\alpha\frac{T-\hat T}{T}$（Graves, 2016 的形式）會 reward hacking：訓練初期一組樣本常常全錯，這時較快的錯誤樣本仍得到正優勢（Sec. 3.3）。Fig. 9b：加法獎勵訓練出一次解開全部位置的策略，步數收斂到最小值。
- 〔本頁推導，前提：$r$ 為二元〕若 $r\in\{0,1\}$（論文例示；Table 1 的 d1 獎勵細節論文未列），乘法獎勵下錯誤樣本 $R=0\le\bar R$，所以錯誤樣本的優勢 $-\bar R\le0$，等號只在整組獎勵都是 0 時成立；正優勢只可能給答對的樣本（與 Sec. 4.4「assigning a positive advantage only if the generation is correct」一致）。若 d1 獎勵對錯誤答案也給正分（例如格式分），錯誤樣本仍可能得到正優勢，此結論不成立。答對但很慢的樣本仍可能得到負優勢（C3b 預設 P2 的第 4 列）。

#### 步驟 7：玩具 MDP——α 如何決定最佳速度（〔本頁推導〕，頁面 S8、C4）

論文沒有這一步；頁面加入它，讓讀者在可以精確計算的模型中看到 Eq. 3.1 的作用。設定（全部是玩具設定）：

- $L$ 個位置，$T=L$（與 App. C 的 $L=T=256$ 同比例）。策略只有一個參數 $s$：每一步每個仍被遮住的位置獨立以機率 $s$ 解開（忽略信心度）。
- 正確率模型：答案正確的機率 $=p_0\prod_{\text{步}}\gamma^{\max(j-1,0)}$，$j$ 是該步同時解開的數量；即每多一個同時解開的 token，正確機率乘上 $\gamma$。這個模型只用來表達「平行解開越多越容易錯」，不是論文的模型。
- 訓練模式（無 fallback，同論文）：$j=0$ 的步驟浪費掉。**未完成樣本規則**（〔本頁推導〕，兩種獎勵共用）：$T$ 步內沒解完 → $r=0$ 且步數記為 $N=T$（即步驟 6 的推定 $\hat T=0$）。代入後乘法 $R^{\times}=0\cdot(1-T/T)^\alpha=0$，加法 $R^{+}=0-\alpha\cdot T/T=-\alpha$。理由：未完成樣本確實用滿了 $T$ 步；若加法改給 0，未完成樣本（0）會勝過已解完的錯誤樣本（$-\alpha N/T<0$），變成鼓勵留下遮罩，與論文「策略很快學會不留遮罩」相反。測試模式（有 fallback）：$j=0$ 時改為解開 1 個。
- 期望值以 $(\text{步數},\text{剩餘遮罩數})$ 的動態規劃精確計算（4.4 節）。
- 結果（$L=T=16,\gamma=0.9,p_0=0.8$，第 5 節）：乘法獎勵的最佳 $s^*$ 隨 $\alpha$ 增加：$\alpha=0,0.3,1,3,10$ 分別為 0.290、0.375、0.720、1.000、1.000；加法獎勵在 $\alpha\ge0.3$ 時 $s^*=1$（一步解開全部），與 Fig. 9b「收斂到一步解開全部」的方向相同。這是玩具模型的期望獎勵最佳值，不是 GRPO 的訓練過程；論文對加法獎勵失敗的解釋是步驟 6 的優勢符號機制，頁面兩者分開陳述。
- 乘法獎勵在玩具中同樣會在 α 夠大時達到 $s^*=1$（$L=16,\gamma=0.9$ 時 α ≥ 3；$L=8$ 或 $\gamma=0.95$ 時 α ≥ 1）：α 大到一定程度後，最佳值停在上限 $s=1$。頁面明寫兩點：(1) 玩具只算期望獎勵的最佳值，不說明 GRPO 訓練是否穩定；(2) 論文對乘法獎勵的主張只是它避開「整組答錯時較快錯誤樣本得到正優勢」的機制，不是「乘法獎勵永遠不會收斂到一步解開全部」。

#### 步驟 8：semi-AR 實驗（Sec. 4.1、Fig. 3–6、App. B.5–B.6、App. J）

- 設定：環境 LLaDA-8B-Instruct（Dream-7B-Instruct 見 App. B.4）。五個策略 $\alpha\in\{10,3,1,0.3,0\}$，以 BL = 32 在 GSM8K + MATH 訓練集混合資料上訓練一個 epoch（約 15,000 筆）。每個 $\alpha$ 兩個訓練 seed，依最終訓練損失選一個；測試平均三個 seed。基準：隨機與 top-K 用 $K\in\{8,16,32,64,128,256\}$，Fast-dLLM 用 $\lambda\in\{0.1,0.2,\dots,1.0\}$；全部 $\tau=0$。
- 結果：策略優於隨機與 top-K，與 Fast-dLLM 相當；在中高 NFE 沒有超越 Fast-dLLM，作者推測該規則在 semi-AR 下接近最佳。$\alpha=10$ 訓練較不穩定，但成功時在約 10 NFE 優於 Fast-dLLM（Table 2：策略 10.3 NFE 35.2%，Fast-dLLM 10.6 NFE 17.5%）；作者歸因於策略在最後一個區塊產生數字答案時放慢（Fig. 5b、App. C.2：約 38% 對約 18%）。
- 可控性：改變訓練時的 $\alpha$ 不能平滑地走遍 Pareto 前緣；$\alpha=3$ 的行為與 $\alpha=1$ 幾乎相同；更密的網格 $\{10,9,\dots,1,0.3,0\}$ 中 $\alpha\ge4$ 收斂到接近 $\alpha=3$ 或 $\alpha=10$ 的策略，沒有中間值（App. B.5、Fig. 14）。
- 測試時控制（Fig. 6）：仿照 Chen et al. (2025a) 把機率改為 $u_t^k\sim\mathrm{Ber}(\min\{1,\beta s_t^k\})$；$\beta>1$ 每步解開更多、$\beta<1$ 更少。以 $\alpha=1$ 的策略改變 $\beta$，NFE 與正確率沿 Pareto 前緣連續變化；MATH-500 約 25 NFE 時策略 20%、Fast-dLLM 10%。$\tau_\pi$ 也能小幅調整（Fig. 16：$\tau_\pi\in\{1.5,1.0,0.5\}$；semi-AR 以 0.5 最佳，完整擴散以 1 最佳）。
- 行為差異（App. C.1，設定 BL32-slow：BL = 32，Fast-dLLM λ = 0.9 對策略 α = 0.3，兩者總 NFE 與正確率幾乎相同；N = 100 個 GSM8K 測試樣本，$L=T=256$）：在這個設定下，策略同時解開相鄰 token 的比例約 20%，Fast-dLLM 約 65%（Fig. 24）；Fast-dLLM 第一個區塊約 17 NFE、逐漸降到最後區塊約 4 NFE，策略每區塊約 10 NFE（Fig. 5a）。頁面引用這些數字時一律寫出 BL32-slow 設定，不寫成一般結論。

#### 步驟 9：完整擴散與 expert steering（Sec. 4.2、App. F、App. C.3）

- 以 BL = L = 256 訓練與測試，其餘不變。所有方法都比 semi-AR 差，但策略下降最少：GSM8K 約 12 NFE 時約 50%，啟發式規則（不論是否 semi-AR）≤ 30%（Sec. 4.2）；Table 4：策略 13.0 NFE 48.3%。
- 但理論上 BL = L 的策略可以自己學出 semi-AR，實際上在中高 NFE 仍不如 BL = 32 的策略，作者認為策略離最佳還很遠，原因可能是探索不足（Sec. 4.2）。
- App. F 的論證：若 AR 順序明顯最好，從隨機初始化的策略抽到純 AR 軌跡的機率約 $1/L!\approx0$。〔本頁推導，粗略量級〕$\log_{10}(256!)\approx506.93$，即約 $10^{-507}$；$L=8$ 時為 $1/40320$。這個數只把「一種 AR 排列」與 $L!$ 種排列相比，忽略每步可解開多個 token 的動作空間，頁面寫成「粗略量級」。
- Expert steering：訓練時把策略換成混合分布 $\pi_\phi^{\mathrm{ES}}=\frac{G}{G+E}\pi_\phi+\frac{E}{G+E}\sum_e\delta_e$（App. F），每組抽 $G+E$ 個樣本；計算似然比時要用 $\pi_\phi^{\mathrm{ES}}$，否則專家樣本在 $\pi_\phi$ 下似然約為 0 會造成不穩定。實作用一個專家：Fast-dLLM（λ = 0.9、BL = 32），每組固定一個（$E=1$）。策略比專家差時，專家樣本傾向得到正優勢，策略的更新方向偏向專家樣本；策略比專家好時專家樣本得到負優勢，策略的正確率仍可高於專家。
- 結果：高 NFE 時接近 semi-AR 的最佳正確率（GSM8K 約 80%、MATH 約 35%，Sec. 4.2 的參考值）；Table 4 GSM8K 77.2%（70.5 NFE），Table 5 MATH 31.4%（86.7 NFE）。ES 的結果點不連續：Table 4 的 ES 列為 15.7 NFE 50.6%、20.6 NFE 51.9%，下一點直接是 70.5 NFE 77.2%（之後 72.4／76.7、87.9／75.1），20.6 到 70.5 NFE 之間沒有點；Table 5 同樣從 23.1 NFE 19.8% 跳到 86.7 NFE 31.4%。頁面的 Table 4/5 摘錄表列出全部 ES 列並在文字指出這段缺口，不寫成平滑前緣。代價是訓練明顯不穩定，多個 $\alpha$ 收斂到幾乎相同的策略。行為：Fast-dLLM 常呈現右到左；不用 ES 的策略接近隨機順序（作者解讀為策略不依賴填充 token 偏高的信心度）；用 ES 的策略由左到右（Fig. 7、App. C.3）。Spearman 相關：Fast-dLLM 對策略 0.26 ± 0.21，對 ES 策略 −0.24 ± 0.51。

#### 步驟 10：遷移性與設計消融（Sec. 4.3–4.4、App. B.7–B.10）

- 模型遷移 LLaDA → Dream：多數策略接近 Fast-dLLM，與直接在 Dream 上訓練的策略相近；例外是 $\alpha=10$，退回 Fast-dLLM 水準，作者認為陡峭獎勵使它過擬合 LLaDA 的信心度模式（Fig. 8a）。策略只看信心度、不看 token 嵌入，所以能跨模型。
- 領域遷移 數學 → 程式（HumanEval、MBPP）：沒有完全遷移，HumanEval 尤其明顯；改用 KodCode-RL-10K 訓練的策略縮小 HumanEval 差距、改善 MBPP 低 NFE（Fig. 8b–c）。
- 長度遷移 L = 256 → 512：基準方法進一步變差，策略表現與之前相近（Fig. 8d、Fig. 18）。transformer 可接受不同長度輸入，MLP 不行。
- 非貪婪解碼（$\tau=0.8$，Fast-dLLM λ = 0.6 對策略 $\alpha=1,\tau_\pi=0.5$，BL = 32）：策略的 pass@k 較高且差距隨 k 擴大（Sec. 4.3：跨資料集平均 k = 1 時 +0.98%、k = 32 時 +2.56%）；多數決與 ORM 選答也較好（Fig. 19）。非貪婪時信心度定義為抽到的 token 的機率（Sec. 4.3 註 2）。
- 消融（Sec. 4.4、Fig. 9、Fig. 20）：乘法 vs 加法（步驟 6）；Bernoulli vs DPLS 表現相近，DPLS 對 $\alpha$ 的可控性略好；只用最大信心度略優於 top-50 信心度；隱藏狀態策略（約 300M 參數）較差且訓練較不穩定；測試時把 $t$ 或 $m_t$ 歸零都會降低正確率，移除 $m_t$ 下降較多（GSM8K 只歸零 $t$ 例外），NFE 變化最多 1.2（基準 GSM8K 75.1% / 45.8 NFE；MATH-500 34.0% / 58.4 NFE）。這些數字取自 Fig. 20 的說明文字與 Sec. 4.4；各長條的其他數值只出現在圖中，頁面不引用。
- 相關工作（Sec. 5；研究筆記 `learned-unmasking-concurrent-work`、`confidence-thresholding-heuristics`）：Hong et al.（2025b，2510.05725）同樣以 GRPO 學解遮罩策略，但每步解開固定數量，本文以 Bernoulli 讓數量可變；DiFFPO（Zhao et al., 2025b）同時學自適應門檻並更新基礎模型；Bansal & Sanghavi（2509.22738）與 Bao et al.（2509.25188）以蒸餾而非 RL 訓練小型模組，作者預期它們承襲啟發式規則在非 semi-AR 設定的困難；Azangulov et al.（2510.21961）建模 token 相依性；Kim et al.（2025a，2502.06768）與 Ben-Hamu et al. 的規則出現在 Fig. 11 的額外基準比較。頁面 S11 末尾以一段文字列出，只寫論文 Sec. 5 的描述。

常見錯誤（頁面 S12 逐條列出）：
1. 混淆兩個 $t$：Sec. 2.1 訓練時 $t\in[0,1]$ 是遮罩率；生成與 MDP 中 $t=T,\dots,1$ 是倒數的步數。App. C、D 的圖又把時間軸改成正向。
2. NFE = 步數 $T-\hat T$；推定：若以 $\hat T=0$ 表示用滿 $T$ 步，乘法獎勵的速度因子為 0（〔本頁推導〕；Sec. 3.1 字面上 $\hat T\ge1$，因子至少 $(1/T)^\alpha$）。訓練時的 $T$ 論文未明寫；App. C 的分析用 $L=T=256$。
3. fallback 只用在測試；訓練時不強制解遮罩，未解完就終止並評分。玩具模型中未完成樣本 $r=0$、步數 $N=T$：乘法得 0，加法得 $-\alpha$（不是 0）；Eq. 3.1 的「0, otherwise」指非終止步，不是未完成樣本。
4. GRPO rollout 時 dLLM 用 $\tau=0$；隨機性只來自策略的 Bernoulli 抽樣。
5. 已解開的位置不計入似然；優勢不除以標準差；不加 KL。
6. 加法獎勵的訓練收斂到一步解開全部（Fig. 9b）；用乘法獎勵。
7. 改 $\alpha$ 不保證平滑的速度—正確率權衡；測試時用 $\beta$ 或 $\tau_\pi$ 調整。
8. Expert steering 的似然比必須用混合分布 $\pi_\phi^{\mathrm{ES}}$。
9. 只用每個位置的最大信心度作輸入；top-50 或隱藏狀態沒有幫助。

### 1.7 限制（Sec. 6）

每個 $\alpha$ 要訓練一個策略，成本高且不一定給出夠細的控制；測試時介入（$\beta$、$\tau_\pi$）有希望但尚無定論。未來方向：擴大多領域訓練資料、學習重新遮罩（remask）已解開的 token、推廣到多模態遮罩擴散模型。

### C1 · 前向加遮罩與逐步生成（S1）

- **教的概念**：前向過程每個位置獨立以機率 $t$ 被遮住；生成時每步解開一部分位置，NFE = 步數（LO1）。
- **操作**：分段按鈕「前向（訓練）」／「生成」。
  - 前向：滑桿 $t\in[0,1]$，步長 0.01，預設 0.5；「重新抽樣」（seed 加 1，初始 7）。
  - 生成：chip $K\in\{1,2,3,4,8,16\}$（預設 4）；按鈕「下一步」「自動播放／暫停」「重設」。
- **計算**：
  - 前向：`u = 16 個 mulberry32(seed) 均勻數`，位置 $k$ 被遮住 ⇔ $u_k<t$（同一組 $u$ 隨 $t$ 單調變化，拖動時不跳動）。讀數：遮住數、期望 $tL$、ELBO 權重 $1/t$（$t<0.01$ 顯示「—」，並註明 $t=0$ 時沒有遮住的位置，該項為 0）。
  - 生成：PRNG `mulberry32(seed+1)`；每步把仍遮住的位置升冪排序，做部分 Fisher–Yates：for $i<n=\min(K,|\mathcal M|)$：$j=i+\lfloor r()\cdot(|\mathcal M|-i)\rfloor$，交換；取前 $n$ 個。這是「標準 MDM 隨機位置、固定數量」的取樣（Sec. 1）；玩具中解開的位置直接顯示正確 token（相當於 $\tau=0$ 且模型完全正確，頁面註明）。讀數：NFE（步數）、本步解開位置、剩餘遮住數；完成時顯示 NFE $=\lceil L/K\rceil$。
- **顯示**：token 列（16 格，[M] 格斜線紋＋文字「M」；本步剛解開的格加粗外框與「新」小標）。前向模式下方加一行「訓練時只在 [M] 位置計算 $\log p_\theta$，再乘 $1/t$（Eq. 2.1）」。
- **觀察**：$t$ 越大遮住越多，期望 $tL$；$K$ 越大 NFE 越少（16/K 向上取整）。生成順序與「這個 token 好不好猜」無關——這是 S2 啟發式規則要改進的地方。
- **無障礙**：token 列 `role="list"`，每格 `aria-label`（「位置 3，遮住」／「位置 3，10」）；自動播放受 `prefers-reduced-motion` 影響時改為按一次直接完成。自動播放期間讀數只更新畫面、不寫入 live region；按暫停或生成完成時一次公告（「已暫停，第 n 步，剩 m 個遮住」／「完成，共 n 次 NFE」）。

### C2 · 解遮罩規則比較：隨機 K、top-K、門檻（S2）

- **教的概念**：同一個信心度向量下，三種啟發式規則選出的 $U_t$；情境 B 中信心度規則先選尾端填充 token（LO2、LO3）。
- **輸入**：
  - 情境（分段）：
    - 「A · 一般區塊」：token 為 4.0 的玩具答案；$c=[0.62,0.55,0.48,0.41,0.93,0.36,0.30,0.88,0.27,0.95,0.33,0.71,0.85,0.22,0.58,0.64]$。
    - 「B · 尾端填充 token」：token 為 `["Total",":","$","750","×","10","=","$","7500",".","<EOS>","<EoT>","<EoT>","<EoT>","<EoT>","<EoT>"]`；$c=[0.58,0.51,0.44,0.39,0.90,0.34,0.29,0.84,0.25,0.92,0.97,0.995,0.995,0.995,0.995,0.995]$（模仿 App. C.3 的現象；token 與數值都是玩具設定）。
  - 點 token 格可切換「已解開／遮住」（預設全部遮住），規則只作用在遮住的位置。
  - 規則（分段）：隨機 K／top-K／門檻 λ（Fast-dLLM）。
  - $K$：1–16，預設 4。$\lambda$：0.05–1.00，步長 0.01，預設 0.90。勾選「空集合時 fallback」（預設開）。「重新抽樣」（seed 加 1，初始 7；只影響隨機 K）。
- **計算**（$\mathcal M$ = 遮住位置）：
  - 隨機 K：Fisher–Yates（同 C1）選 $\min(K,|\mathcal M|)$ 個；每個位置被選機率 $\min(K,|\mathcal M|)/|\mathcal M|$。
  - top-K：依 $(-c_k,k)$ 排序取前 $\min(K,|\mathcal M|)$ 個（同值取較小索引）。
  - 門檻：$U=\{k\in\mathcal M:c_k>\lambda\}$（嚴格大於）。若為空集合：勾選開啟時解開 $c$ 最大的一個（同值取較小索引；推定：論文說策略的 fallback「similar to Fast-dLLM」）；勾選關閉時 $U=\varnothing$、$|U|=0$，讀數註明「本步沒有解開任何位置」。

- **數值保護**：$|\mathcal M|=0$ 時顯示「全部已解開」並停用規則。
- **顯示**：token 列上方畫信心度長條（高度 ∝ $c$），λ 為水平虛線（只在門檻規則顯示）。被選位置：粗外框 + 格上「✓」。下方讀數表（JetBrains Mono）。

### C2B · Bernoulli 策略：τ_π、β 與 fallback（S5）

- **教的概念**：Bernoulli 策略的期望解開數、全為 0 的機率、似然；$\tau_\pi$ 與 $\beta$ 的作用；fallback 只在測試（LO6）。
- **輸入**：情境 A／B（同 C2，token 與 $c$ 相同）；點 token 格切換已解開／遮住；$\tau_\pi$：0.25–2.00，步長 0.05，預設 1.00（附 chip 0.5／1／1.5）；$\beta$：{0.25, 0.5, 0.75, 1, 1.5, 2, 3, 4}，預設 1；勾選「測試時 fallback」（預設開）；「重新抽樣」（seed 加 1，初始 7）。C2B 與 C2 各自持有狀態，只共用情境常數與繪圖函式。
- **計算**：示意 logit $b_k=8(c_k-0.7)$（**玩具設定，不是論文訓練出的網路**；頁面明寫真實策略是 transformer，輸入整個 $c_t,m_t,t$）；$s_k=\min\{1,\beta\,\mathrm{sigmoid}(b_k/\tau_\pi)\}$；$u_k=[r()<s_k]$，$k\in\mathcal M$。
  - fallback：若抽樣的 $u$ 全為 0 且勾選開啟，解開 $s$ 最大的位置（同值取較小索引）；勾選關閉時 $U=\varnothing$、$|U|=0$。
  - 讀數：$\mathbb E|U|=\sum_{k\in\mathcal M}s_k+P_0\cdot\mathbb 1[\text{fallback 開}]$，$P_0=\prod_{k\in\mathcal M}(1-s_k)$；本次的 $|U|$（含 fallback）；$\log\pi(u)=\sum_{k\in\mathcal M}[u_k\log s_k+(1-u_k)\log(1-s_k)]$，**一律以抽樣出的 $u$（fallback 前）計算**，旁註「fallback 只在測試使用，不計入似然」；右鄰比例（同 C2）。
- **數值保護**：$s_k=1$ 時 $u_k$ 必為 1，$(1-u)\log(1-s)$ 項跳過（避免 $0\cdot(-\infty)$）；用 `Math.log1p(-s)`；任一 $s_k=1$ 時 $P_0$ 直接為 0；$|\mathcal M|=0$ 時顯示「全部已解開」；$b/\tau_\pi$ 最小為 $-5.6/0.25=-22.4$，$s\ge1.9\times10^{-10}$，$\log s$ 有限。

- **觀察**：降低 $\tau_\pi$ 使 $s$ 更接近 0 或 1；$\beta<1$ 減少每步解開數、提高 $P_0$；$\beta>1$ 使部分 $s$ 截到 1。
- **無障礙**：同 C2。

### C4 · 玩具 MDP：α 與獎勵形式決定最佳解遮罩速度（S8）

- **教的概念**：乘法獎勵的 α 增大時最佳速度往快的方向移動，α 大到一定程度後停在上限 $s=1$；加法獎勵在 α ≥ 0.3 時最佳值就是一步解開全部；訓練（無 fallback）與測試（有 fallback）的差異（LO8、LO9；〔本頁推導〕）。
- **輸入**：預設只露出兩個控制：α chip {0, 0.3, 1, 3, 10}（預設 1）與目前策略 $s\in[0.005,1]$ 步長 0.005（預設 0.5）。其餘收進 `<details>`（summary「進階設定」，預設收合）：$L\in\{8,16,32\}$（預設 16，$T=L$）；$\gamma\in[0.80,1.00]$ 步長 0.01（預設 0.90）；$p_0\in[0.30,1.00]$ 步長 0.05（預設 0.80）；獎勵形式 乘法／加法（預設乘法）。
- **計算**（精確動態規劃，與 `c4_toy_mdp.py` 相同）：
  ```
  mass[L]=1, corr[L]=1；for n in 0..T-1:
    for m in 1..L, j in 0..m:  p = C(m,j) s^j (1-s)^(m-j)
      j==0: train → 留在 m（浪費一步）；test → jj=1
      g = γ^(jj-1)；若 m-jj==0：Pfin[n+1]+=mass[m]p，Cfin[n+1]+=corr[m]p g；否則轉到 m-jj
  P_unf = 剩餘 mass 總和（train 才可能 > 0；test 恆為 0）
  E[R×] = p0 Σ_N Cfin[N](1-N/T)^α；E[R+] = Σ_N (p0 Cfin[N] − α(N/T)Pfin[N]) − α P_unf
  # 未完成樣本：r=0、N=T → R×=0（不出現在 E[R×]）、R+=−α（上式最後一項）；不得改成 0
  acc = p0 Σ Cfin；NFE = Σ N Pfin[N] + T P_unf
  ```
  $C(m,j)$ 預先算成表（$L\le32$，最大 $C(32,16)\approx6.0\times10^8$，double 精確）。$s$ 網格 0.005–1.000（200 點）；最佳 $s^*$ 為**訓練模式**期望獎勵最大的網格點；同值判定用 $|\Delta|<10^{-12}$，同值取最小 $s$（`c4_toy_mdp.py` 已改為同一規則，輸出不變）。快取：`Pfin, Cfin, P_unf` 只依 $(L,\gamma,\text{mode},s)$，鍵 `${L}|${γ}|${mode}`；$p_0$、α、獎勵形式只在最後彙總時使用。
- **數值保護**：$s=1$ 時 `Math.pow(0,0)=1` 使 $j=m$ 機率為 1；跳過 $p=0$ 的項；selfTest 檢查 $\sum$Pfin + P_unf $=1$（誤差 1e-12）。
- **顯示**：
  - 左圖「訓練模式期望獎勵 vs s」：y 軸範圍取目前五條曲線的最小值與最大值，上下各加 5% 邊界（加法獎勵為負值時同樣適用；min = max 時 ±0.05）；目前 α 的曲線（粗實線）＋其他四個 α（細線，線型各異、直接標籤），$s^*$ 以 `--accent` 實心點與垂直虛線標示；目前 $s$ 以細垂直線標示。
  - 右圖「測試模式的 NFE–正確率」：所有 $s$ 網格點連成曲線（玩具策略族的前緣）；五個 α 在訓練模式下的最佳點（乘法：實心圓；加法：空心方形），目前 $s$ 為十字標記。
  - 讀數：目前 $s$ 的訓練期望獎勵、未完成機率（旁附註「未完成：乘法得 0，加法得 −α」）；測試 NFE、正確率；目前設定的 $s^*$。
  - 圖下四行說明：「此模型忽略信心度、用單一參數 $s$，正確率模型 $\gamma$ 是玩具設定。」「α 大到一定程度後，最佳值停在上限 $s=1$（一步解開全部），所以 α = 3 與 α = 10 的 $s^*$ 相同；這與論文 App. B.5 的『α 不平滑』是不同的現象。」「論文對加法獎勵失敗的解釋是優勢符號（C3b）；這裡顯示的是期望獎勵最佳值，兩者方向一致但不是同一件事。」「玩具只算期望獎勵的最佳值，不說明 GRPO 訓練是否穩定；乘法獎勵在大 α 時的 $s^*=1$ 也是玩具的期望最佳值，論文只主張乘法獎勵避開了整組答錯時的正優勢機制。」
- **觀察**（預設）：乘法 $s^*$ 隨 α 增加（0.290 → 0.375 → 0.720 → 1 → 1），α ≥ 3 時停在上限；加法在 α ≥ 0.3 時 $s^*=1$；α = 0 的訓練最佳值不在 $s\to0$，因為步數上限 $T=L$ 下浪費步會導致未完成（$P_{\mathrm{unf}}=0.0647$）。
