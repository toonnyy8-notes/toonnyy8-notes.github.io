 Flow Map Language Models：用連續去噪一步生成文字

 把 token 寫成 one-hot 向量、在連續空間學 flow，再蒸餾成 flow map，一次網路計算生成整段文字。

 Chanhyuk Lee、Jaehoon Yoo、Manan Agarwal、Sheel Shah、Jerry Huang、Aditi Raghunathan、Seunghoon Hong、Nicholas M. Boffi、Jinwoo Kim（KAIST、CMU，2026）〈Flow Map Language Models: One-step Language Modeling via Continuous Denoising〉

 01 · 問題離散擴散語言模型每步平行產生多個 token，但各 token 是獨立抽樣的；步數一少，就會拼出資料中不存在的組合。

 02 · 做法本文把每個 token 寫成 one-hot 向量，在連續空間中讓噪聲沿確定的路徑流向資料；網路只需要預測每個位置的 token 機率。

 03 · 結果蒸餾後的模型只做一次網路計算就生成整段文字。以 GPT-2 Large 計算的生成困惑度（越低越好）在 LM1B 上是 119.34；同樣只算一次的離散擴散基線在 LM1B 上最好是 292.94（Table 13）。

 01 · 離散擴散

 離散擴散一次更新多個 token，步數少時會產生不存在的組合

 語言模型把一段文字表示成 token 序列 y=(y1,…,yL) $y=(y^1,\dots,y^L)$ ,…,yL)：每個 token yl $y^l$ 取自詞表 V $V$ ，詞表大小記為 ∣V∣ $|V|$ ，L $L$ 是序列長度。自回歸模型把聯合機率拆成條件機率的乘積：

 p(y)=p(y1) p(y2∣y1)⋯p(yL∣y<L) $p(y)=p(y^1)\,p(y^2\mid y^1)\cdots p(y^L\mid y^{<L})$ )p(y2∣y1)⋯p(yL∣y<L)
Eq. 1

 取樣時必須逐個 token 進行，生成 L $L$ 個 token 需要 L $L$ 次網路計算，這是自回歸模型的序列瓶頸。

 離散擴散（discrete diffusion）先把整段序列逐步破壞，再學習把它還原。以 masked diffusion 為例，破壞的方式是遮罩：把 token 換成一個「隱藏」符號；揭露一個位置，就是在那裡填回一個詞。生成時在時間格點 0=t0<t1<⋯<tN=1 $0=t_0<t_1<\dots<t_N=1$ ​<t1​<⋯<tN​=1 上做 ancestral sampling：每一步從上一步的結果 ys $y_s$ ​ 出發，依模型給的轉移機率 pt∣s(yt∣ys) $p_{t\mid s}(y_t\mid y_s)$ ​(yt​∣ys​) 抽出下一步的狀態 yt $y_t$ ​。每一步可以同時改變很多位置，所以步數 N $N$ 可以遠小於 L $L$ 。

 問題在於 pt∣s $p_{t\mid s}$ ​ 定義在 VL $V^L$ 上，可能的輸出有 ∣V∣L $|V|^L$ 種，網路無法直接輸出這個分布。實際做法是把它近似成逐 token 條件機率的乘積：

 p~t∣s(yt∣ys):=pt∣s1(yt1∣ys)⋯pt∣sL(ytL∣ys) $\tilde p_{t\mid s}(y_t\mid y_s):=p^1_{t\mid s}(y^1_t\mid y_s)\cdots p^L_{t\mid s}(y^L_t\mid y_s)$ ​t∣s​(yt​∣ys​):=pt∣s1​(yt1​∣ys​)⋯pt∣sL​(ytL​∣ys​)
Eq. 2

 每個因子 pt∣sl(ytl∣ys) $p^l_{t\mid s}(y^l_t\mid y_s)$ l​(ytl​∣ys​) 是「給定 ys $y_s$ ​、對其他位置邊際化之後，第 l $l$ 個 token 的條件機率」。把 pt∣s $p_{t\mid s}$ ​ 近似成這個乘積，等於假設去噪後的各個 token 在給定 ys $y_s$ ​ 下條件獨立。這個假設只在 t→s $t\to s$ 的極限成立：相鄰兩步的時間差趨近 0 時，一步只改變極少數 token，兩個相關的 token 幾乎不會在同一步被決定。步數少時，每一步要同時決定很多 token，乘積近似忽略了 token 之間的相關，產生因子化誤差（factorization error）。作者強調這個誤差來自近似本身，改善模型品質也無法消除（Sec. 2）。

 論文用一個玩具說明（Fig. 3）：資料只有 new york 與 san diego 兩句，各占一半。一步取樣時，兩個位置各自依邊際機率獨立抽樣，四種組合各 25%，其中 new diego 與 san york 合計 50% 是資料中不存在的無效組合；連續 flow 在多步與少步時都只產生有效資料。這正是上面那個假設的失效：Eq. 2 的條件獨立只在 t→s $t\to s$ 極限成立，一步取樣時 s=0 $s=0$ 、t=1 $t=1$ 相距最遠，兩個位置在同一步被決定，假設不成立。Fig. 3 沒有說明它使用哪一種離散模型與排程。下圖用本頁自選的設定，看步數增加時無效組合如何減少。

 最佳 denoiser 是逐 token 後驗，所以輸出層用 softmax

 為什麼不直接回歸速度？速度目標 x1−x0 $x_1-x_0$ ​−x0​ 含有高斯噪聲 x0 $x_0$ ​，繼承了噪聲的 full-rank 結構。已知當 ∣V∣ $|V|$ 遠大於網路內部特徵維度 d $d$ 時，回歸這種目標會欠擬合 [40]（Li & He，Back to Basics，arXiv 2511.13720）。論文把這個現象稱為 rank bottleneck（秩瓶頸，Sec. 5 的 Table 18 討論）。具體地說本頁對 [40] 的說明：網路最後一層把 d $d$ 維內部特徵線性映射到 ∣V∣ $|V|$ 維輸出，所以每個位置能輸出的向量最多只張成 d $d$ 維子空間（秩 ≤d $\le d$ ）。速度目標中的噪聲在全部 ∣V∣ $|V|$ 個方向都有分量，d≪∣V∣ $d\ll|V|$ 時大部分方向網路表示不出來，只能欠擬合。denoiser 的目標是後驗機率向量，不帶這份噪聲，沒有這個問題。論文本身只寫 full-rank 與欠擬合，「秩 ≤d $\le d$ 」是本頁的白話說明。

 實驗證據是 Table 18 的消融（LM1B，FLM 1024 步）：直接回歸速度的 Velocity + MSE，Gen. PPL 是 3801.36，沒有收斂；改學 denoiser、以 softmax 輸出並用交叉熵訓練的 Denoiser + softmax + CE，Gen. PPL 是 96.91。Gen. PPL 是用 GPT-2 Large 評估生成文字的困惑度，越低越好（第 10 節說明）。
