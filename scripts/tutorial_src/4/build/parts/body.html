    Flow Map Language Models：用連續去噪一步生成文字

    把 token 寫成 one-hot 向量、在連續空間學 flow，再蒸餾成 flow map，一次網路計算生成整段文字。

    Chanhyuk Lee、Jaehoon Yoo、Manan Agarwal、Sheel Shah、Jerry Huang、Aditi Raghunathan、Seunghoon Hong、Nicholas M. Boffi、Jinwoo Kim（KAIST、CMU，2026）〈Flow Map Language Models: One-step Language Modeling via Continuous Denoising〉

    01 · 問題

    離散擴散語言模型每步平行產生多個 token，但各 token 是獨立抽樣的；步數一少，就會拼出資料中不存在的組合。

    02 · 做法

    本文把每個 token 寫成 one-hot 向量，在連續空間中讓噪聲沿確定的路徑流向資料；網路只需要預測每個位置的 token 機率。

    03 · 結果

    蒸餾後的模型只做一次網路計算就生成整段文字。以 GPT-2 Large 計算的生成困惑度（越低越好）在 LM1B 上是 119.34；同樣只算一次的離散擴散基線在 LM1B 上最好是 292.94（Table 13）。

    01 · 離散擴散

    離散擴散一次更新多個 token，步數少時會產生不存在的組合

    語言模型把一段文字表示成 token 序列 $y=(y^1,\dots,y^L)$：每個 token $y^l$ 取自詞表 $V$，詞表大小記為 $|V|$，$L$ 是序列長度。自回歸模型把聯合機率拆成條件機率的乘積：

    $$p(y)=p(y^1)\,p(y^2\mid y^1)\cdots p(y^L\mid y^{<L})$$
    Eq. 1

    取樣時必須逐個 token 進行，生成 $L$ 個 token 需要 $L$ 次網路計算，這是自回歸模型的序列瓶頸。

    離散擴散（discrete diffusion）先把整段序列逐步破壞，再學習把它還原。以 masked diffusion 為例，破壞的方式是遮罩：把 token 換成一個「隱藏」符號；揭露一個位置，就是在那裡填回一個詞。生成時在時間格點 $0=t_0<t_1<\dots<t_N=1$ 上做 ancestral sampling：每一步從上一步的結果 $y_s$ 出發，依模型給的轉移機率 $p_{t\mid s}(y_t\mid y_s)$ 抽出下一步的狀態 $y_t$。每一步可以同時改變很多位置，所以步數 $N$ 可以遠小於 $L$。

    問題在於 $p_{t\mid s}$ 定義在 $V^L$ 上，可能的輸出有 $|V|^L$ 種，網路無法直接輸出這個分布。實際做法是把它近似成逐 token 條件機率的乘積：

    $$\tilde p_{t\mid s}(y_t\mid y_s):=p^1_{t\mid s}(y^1_t\mid y_s)\cdots p^L_{t\mid s}(y^L_t\mid y_s)$$
    Eq. 2

    每個因子 $p^l_{t\mid s}(y^l_t\mid y_s)$ 是「給定 $y_s$、對其他位置邊際化之後，第 $l$ 個 token 的條件機率」。把 $p_{t\mid s}$ 近似成這個乘積，等於假設去噪後的各個 token 在給定 $y_s$ 下條件獨立。這個假設只在 $t\to s$ 的極限成立：相鄰兩步的時間差趨近 0 時，一步只改變極少數 token，兩個相關的 token 幾乎不會在同一步被決定。步數少時，每一步要同時決定很多 token，乘積近似忽略了 token 之間的相關，產生因子化誤差（factorization error）。作者強調這個誤差來自近似本身，改善模型品質也無法消除（Sec. 2）。

    論文用一個玩具說明（Fig. 3）：資料只有 new york 與 san diego 兩句，各占一半。一步取樣時，兩個位置各自依邊際機率獨立抽樣，四種組合各 25%，其中 new diego 與 san york 合計 50% 是資料中不存在的無效組合；連續 flow 在多步與少步時都只產生有效資料。這正是上面那個假設的失效：Eq. 2 的條件獨立只在 $t\to s$ 極限成立，一步取樣時 $s=0$、$t=1$ 相距最遠，兩個位置在同一步被決定，假設不成立。Fig. 3 沒有說明它使用哪一種離散模型與排程。下圖用本頁自選的設定，看步數增加時無效組合如何減少。

    02 · one-hot 與 flow

    把 token 寫成 one-hot 向量，在歐氏空間做 flow matching

    本文改走連續路線。第一步是把離散的 token 寫成連續向量（Sec. 3.1）。資料 $x_1=f(y)$：$f$ 把每個 token 換成 $|V|$ 維 one-hot 向量（該詞的位置是 1，其餘是 0），整段序列成為 $L\times|V|$ 的矩陣；$g$ 對每個位置取 argmax，把矩陣解碼回 token：

    $$f:y\mapsto\big(\mathrm{onehot}(y^1),\dots,\mathrm{onehot}(y^L)\big)^\top,\qquad g:x\mapsto\big(\mathrm{argmax}(x^1),\dots,\mathrm{argmax}(x^L)\big)$$
    Eq. 3–4

    $g(f(y))=y$，這個表示無損，不需要另外訓練 embedding，也不需要正則化。作者指出學習得到的 embedding 需要小心正則化以免崩塌或發散，預訓練 embedding 對 flow 也未必最佳（Sec. 3.1）。

    機率 simplex $\Delta^{|V|-1}$ 是分量非負、總和為 1 的 $|V|$ 維向量的集合，也就是 $|V|$ 個詞上所有機率分布的集合。one-hot 向量是 simplex 的頂點。下圖畫出 $|V|=3$ 時的 simplex。

    本文的狀態不限制在 simplex 上：它在無約束的歐氏空間 $\mathbb R^{L\times|V|}$ 中移動，不投影到 simplex，這一點與 simplex diffusion 不同。

    接著在這個空間做 flow matching（Sec. 3.2）。取噪聲 $x_0\sim\mathcal N(0,I)$ 與資料 $x_1=f(y)$，定義 interpolant：

    $$I_t=(1-t)\,x_0+t\,x_1,\qquad t\in[0,1]$$
    Eq. 5

    本文的時間方向是 $t=0$ 為純噪聲、$t=1$ 為資料，與 DDPM 的慣例相反。生成時求解 ODE $\dot x_t=b_t(x_t)$（Eq. 6），從 $x_0$ 走到 $x_1$。速度場 $b_t$ 定義成條件期望：$\mathbb E[x_1-x_0\mid I_t=x]$ 是所有會經過點 $x$ 的 $(x_0,x_1)$ 配對，其 $x_1-x_0$ 的平均，也就是站在 $x$ 時對速度的最佳猜測。

    $$b_t(x)=\mathbb E\big[\dot I_t\mid I_t=x\big]=\mathbb E\big[x_1-x_0\mid I_t=x\big]$$
    Eq. 7

    $b_t$ 可以用 MSE 回歸學習，$t$ 均勻取樣：

    $$\mathcal L(\hat b)=\int_0^1\mathbb E\,\big|\hat b_t(I_t)-(x_1-x_0)\big|^2\,dt$$
    Eq. 8

    生成時在格點上數值積分 Eq. 6。最簡單的是 Euler 法：$x_{t_{n+1}}=x_{t_n}+(t_{n+1}-t_n)\,b_{t_n}(x_{t_n})$，每一步假設速度在步長內不變。步長越大，這個假設越不準，誤差越大。

    03 · denoiser

    最佳 denoiser 是逐 token 後驗，所以輸出層用 softmax

    本文不讓網路直接學速度，而是學 denoiser $D_t$：給定含噪狀態 $x$，預測資料 $x_1$ 的條件期望。速度可以寫成 denoiser 的函數：

    $$D_t(x):=\mathbb E[x_1\mid I_t=x],\qquad b_t(x)=\frac{D_t(x)-x}{1-t}$$
    Eq. 9
    推導：由 interpolant 得到 Eq. 9（App. C.2，Eq. 74–76）

    對 $I_t=(1-t)x_0+tx_1$ 兩邊取條件期望 $\mathbb E[\cdot\mid I_t=x]$，左邊就是 $x$：$x=(1-t)\,\mathbb E[x_0\mid I_t=x]+t\,D_t(x)$。解出 $\mathbb E[x_0\mid I_t=x]=\big(x-tD_t(x)\big)/(1-t)$，代入 $b_t=D_t-\mathbb E[x_0\mid I_t=x]$，得 $b_t(x)=\big(D_t(x)-x\big)/(1-t)$。

    所以 $b_t(x)=\mathbb E[x_1-x_0\mid I_t=x]=(D_t(x)-x)/(1-t)$（Eq. 7、9）：學到 denoiser 就能算出速度。反過來寫成 $D_t(x)=x+(1-t)\,b_t(x)$（Eq. 77）：denoiser 是從 $x$ 用速度 $b_t$ 走一個步長 $1-t$ 的 Euler 步。第 06 節會用到這個關係。

    為什麼不直接回歸速度？速度目標 $x_1-x_0$ 含有高斯噪聲 $x_0$，繼承了噪聲的 full-rank 結構。已知當 $|V|$ 遠大於網路內部特徵維度 $d$ 時，回歸這種目標會欠擬合 [40]（Li & He，Back to Basics，arXiv 2511.13720）。論文把這個現象稱為 rank bottleneck（秩瓶頸，Sec. 5 的 Table 18 討論）。具體地說本頁對 [40] 的說明：網路最後一層把 $d$ 維內部特徵線性映射到 $|V|$ 維輸出，所以每個位置能輸出的向量最多只張成 $d$ 維子空間（秩 $\le d$）。速度目標中的噪聲在全部 $|V|$ 個方向都有分量，$d\ll|V|$ 時大部分方向網路表示不出來，只能欠擬合。denoiser 的目標是後驗機率向量，不帶這份噪聲，沒有這個問題。論文本身只寫 full-rank 與欠擬合，「秩 $\le d$」是本頁的白話說明。

    實驗證據是 Table 18 的消融（LM1B，FLM 1024 步）：直接回歸速度的 Velocity + MSE，Gen. PPL 是 3801.36，沒有收斂；改學 denoiser、以 softmax 輸出並用交叉熵訓練的 Denoiser + softmax + CE，Gen. PPL 是 96.91。Gen. PPL 是用 GPT-2 Large 評估生成文字的困惑度，越低越好（第 10 節說明）。

    denoiser 在 one-hot 資料上有明確的意義。記 $p^l_{1\mid t}(\cdot\mid I_t=x)$ 為：看到整個序列的含噪狀態 $x$ 之後，第 $l$ 個位置的真 token 是各個詞的機率。這稱為第 $l$ 個位置的 token 後驗。

    Lemma 3.1：$D_t(x)^l=p^l_{1\mid t}(\cdot\mid I_t=x)\in\Delta^{|V|-1}$（Eq. 11）。證明只用到一件事：$x_1^l$ 只取 one-hot 值 $e_1,\dots,e_{|V|}$。條件期望是這些值的加權平均，權重就是後驗機率（Eq. 40–41）：

    $$\mathbb E\big[x_1^l\mid I_t=x\big]=\sum_{i=1}^{|V|}e_i\;p^l_{1\mid t}\big(x_1^l=e_i\mid I_t=x\big)$$
    Eq. 40–41

    右邊的第 $i$ 個分量就是第 $i$ 個詞的後驗機率，所以最佳 denoiser 每個位置的輸出都是後驗機率向量，落在 simplex 上。因此輸出層可以用逐 token softmax，把假設空間限制在有效的離散分布上，並用交叉熵訓練（Prop. 3.2）：

    $$\mathcal L_{CE}(\hat D)=\int_0^1\mathbb E\Big[-\sum_{l=1}^L\log\hat D_t(I_t)^l\cdot x_1^l\Big]\,dt$$
    Eq. 12

    這個模型稱為 FLM（flow language model）。交叉熵可以分解：對任意分布 $p,q$，$\mathbb E_p[-\log q]=H(p)+\mathrm{KL}(p\,\|\,q)$（Eq. 42），所以

    $$\mathcal L_{CE}(\hat D)=\int_0^1\mathbb E\big[H(x_1\mid I_t)\big]dt+\int_0^1\mathbb E\Big[\sum_{l}\mathrm{KL}\big(p^l_{1\mid t}\,\big\|\,\hat p^l_{1\mid t}\big)\Big]dt$$
    Eq. 45

    第一項是不可約的條件熵，與 $\hat D$ 無關；第二項是逐 token KL。KL ≥ 0，且等號成立若且唯若兩個分布相等，所以交叉熵的唯一最小值是真 denoiser。

    檢查理解

    $b_t$ 與 $D_t$ 的關係？為何不直接回歸速度？

    $b_t(x)=\mathbb E[x_1-x_0\mid I_t=x]=(D_t(x)-x)/(1-t)$（Eq. 7、9）；速度目標 $x_1-x_0$ 帶有高斯噪聲的 full-rank 結構，$|V|$ 遠大於網路內部維度 $d$ 時欠擬合；Table 18：Velocity + MSE 3801.36，Denoiser + softmax + CE 96.91。

    為何最佳 denoiser 在 simplex 上？用什麼目標訓練？為何其唯一最小值是真 denoiser？

    $x_1^l$ 只取 one-hot 值 $e_i$，條件期望 $\sum_ie_i\,p(x_1^l=e_i\mid I_t=x)$ 就是後驗機率向量（Eq. 40–41）；所以用逐 token softmax、以交叉熵 Eq. 12 訓練；交叉熵 = 不可約條件熵 + 逐 token KL（Eq. 45），KL ≥ 0 且等號 iff 相等。

    04 · 同一個後驗

    交叉熵訓練與離散擴散用的是同一個後驗，用途不同

    Prop. 3.2 還給出一個誤差界：交叉熵的超額風險小，則在 $t=1-\xi$ 時生成分布與真分布的距離也小（Eq. 13）。

    Eq. 13 的內容與證明鏈（App. C.1.2）

    記超額風險 $\Delta_D(\hat D)=\mathcal L_{CE}(\hat D)-\mathcal L_{CE}(D)$。若 $\Delta_D(\hat D)\le\epsilon$，對任意 $\xi\in(0,1)$，$W_2^2(\hat p_{1-\xi},p_{1-\xi})\le C\epsilon$，$W_2$ 是 2-Wasserstein 距離。比較在 $1-\xi$ 而不是 1，是為了避開 Eq. 9 的 $(1-t)^{-1}$ 奇異點。

    證明鏈：Pinsker 不等式（Eq. 52）給出 $\int\mathbb E|\hat D-D|^2\le2\Delta_D$（Eq. 50）；由 Eq. 9 得 $\int_0^{1-\xi}\mathbb E|\hat b-b|^2\le2\xi^{-2}\Delta_D$（Eq. 53）；再用 Gronwall 不等式（Eq. 64）得 $W_2\le C_D(\xi)\sqrt{\Delta_D}$，$C_D(\xi)=\sqrt{2(1-\xi)}\,e^{L_{\hat b}(1-\xi)}/\xi$（Eq. 65）。假設：$b,\hat b$ Lipschitz（C.1）、二階動差有界（C.2）、輸出在 simplex 內部（C.3）。

    本頁推導Eq. 13 的 $C=C_D(\xi)^2$。$\xi\to0$ 時這個上界以 $\xi^{-2}$ 發散；發散的只是上界，不代表真誤差發散，所以這是定性的保證。

    連續法與離散法學同一個後驗，差別在怎麼用它

    兩者學的都是逐 token 後驗 $p^l_{1\mid t}$，離散擴散也常用逐 token 交叉熵訓練。離散法用它做 ancestral sampling：下一步的狀態要從聯合分布抽樣，只能逐 token 獨立抽樣，因此產生因子化誤差。連續法只用它計算速度（Eq. 11 + Eq. 9）：速度是條件期望，對 $x_1$ 線性，所以逐 token 的邊際機率就足以給出精確的 $b_t$，不需要聯合分布。

    那麼連續法裡 token 之間的相關從哪裡進來？論文（Sec. 3.2）只說連續法不需要因子化近似。本頁的回答是兩件事本頁推導：第一，網路對每個位置的後驗都條件在整個序列的 $I_t$ 上，寫作 $p^l_{1\mid t}(\cdot\mid I_t=x)$；第二，確定性 flow 讓各位置耦合演化。初始噪聲 $x_0$ 只提供隨機性。網路輸出同樣是逐 token softmax，差別在用途，而不是有沒有逐 token 分解。第 06 節的 C1b 用一個樣本展示這點。

    05 · 時間重參數化

    時間重參數化把訓練與取樣集中在 token 被決定的時間窗

    訓練時 $t$ 該怎麼取樣？作者以解碼錯誤率衡量 flow 在每個時刻決定 token 的進度（Sec. 4）。這個指標沿用自 Duo [19] 與 CANDI [20]；本文的新做法是把它轉成時間重參數化。

    解碼錯誤率 $P_e(t)$ 是時間 $t$ 的狀態 $x_t$ 經 $g$ 解碼之後，與資料 $x_1$ 的 token 不同的比例（對 $L$ 個位置平均）。端點是 $P_e(0)=1-1/|V|$（純噪聲時 argmax 隨機落在 $|V|$ 個詞之一）與 $P_e(1)=0$。重參數化時間 $\tau(t)$ 是到時間 $t$ 為止已完成的解碼進度：

    Eq. 24–25

    06 · flow map

    flow map 從時間 s 的狀態直接算出時間 t 的狀態

    積分 ODE 需要很多次網路計算。flow map 直接學 ODE 的解算子（Sec. 3.3）：$X_{s,t}$ 把時間 $s$ 的狀態映到時間 $t$ 的狀態，可以寫成以平均速度 $v_{s,t}$ 走的一步：

    $$X_{s,t}(x_s)=x_t,\qquad X_{s,t}(x)=x+(t-s)\,v_{s,t}(x)$$
    Eq. 14–15

    flow map 由三個條件刻畫：

    $$X_{s,s}(x)=x,\qquad \lim_{s\to t}\partial_tX_{s,t}(x)=b_t(x),\qquad X_{u,t}\big(X_{s,u}(x)\big)=X_{s,t}(x)$$
    Eq. 16

    第一個是邊界條件；第二個說 $s\to t$ 時 flow map 的時間導數還原速度場；第三個是半群條件：先從 $s$ 走到 $u$、再從 $u$ 走到 $t$，等於直接從 $s$ 走到 $t$。一步取樣是 $\hat x_1=X_{0,1}(x_0)$；多步取樣 $\hat x_{t_{i+1}}=X_{t_i,t_{i+1}}(\hat x_{t_i})$ 對任意格點都精確，實務上步數多通常較好。

    半群條件也可以換成兩種微分刻畫：Lagrangian（Eq. 29，沿軌跡的時間導數）與 Eulerian（Eq. 30，速度的空間導數），對應 MeanFlow、Lagrangian self-distillation 等需要 JVP 的方法。本文主線用半群條件，與 progressive distillation、shortcut models 相關。用平方誤差蒸餾時（Eq. 17），離對角項（$s\ne t$）強制半群，對角項讓 $v_{t,t}$ 逼近教師速度 $\hat b_t$，邊界條件由 Eq. 15 自動滿足；把 $\hat b_t$ 換成 $\dot I_t$，就得到不需教師的直接訓練。

    flow map 與 denoiser 不同。由 Eq. 77，$D_t(x)=x+(1-t)\,b_t(x)$ 只是用速度走一個步長 $1-t$ 的 Euler 步；它是後驗平均，資料有多個模態時會把它們平均掉（App. C.2），所以不是一步 flow map。在 new york／san diego 玩具中，Euler 一步的結果等於兩個模態的平均；精確 flow map 一步就到資料，多步合成的結果與一步相同。

    07 · two-time denoiser

    two-time denoiser 把 flow map 放回 simplex 上

    flow map $X_{s,t}$ 的輸出不在 simplex 上，不能直接用 softmax 與交叉熵學。作者定義 two-time denoiser：

    $$\delta_{s,t}(x):=x+(1-s)\,v_{s,t}(x)$$
    Eq. 18

    它是從 $x$ 以平均速度 $v_{s,t}$ 走步長 $1-s$ 的一步；輸入是時間 $s$ 的狀態。Prop. 3.3 給出四個性質：

    1. (i) 還原 flow map：$X_{s,t}(x)=\frac{1-t}{1-s}\,x+\frac{t-s}{1-s}\,\delta_{s,t}(x)$（Eq. 19）。把 $v_{s,t}=(\delta_{s,t}-x)/(1-s)$ 代入 Eq. 15 即得。
    2. (ii) 在 simplex 上：$\delta_{s,t}(x)^l\in\Delta^{|V|-1}$（Eq. 20）。
    3. (iii) 對角線是 denoiser：$\delta_{s,s}=D_s$（Eq. 21）。
    4. (iv) 半群：$\delta_{s,t}(x)=\gamma\,\delta_{s,u}(x)+(1-\gamma)\,\delta_{u,t}\big(X_{s,u}(x)\big)$，$\gamma=\frac{(1-t)(u-s)}{(1-u)(t-s)}\in[0,1]$（Eq. 22）。

    (ii) 的理由是 $\delta_{s,t}$ 可以寫成沿軌跡 denoiser 的積分：

    $$\delta_{s,t}(x)=\frac{(1-s)(1-t)}{t-s}\int_s^t\frac{D_\tau\big(X_{s,\tau}(x)\big)}{(1-\tau)^2}\,d\tau$$
    Eq. 82

    權重 $\frac{(1-s)(1-t)}{(t-s)(1-\tau)^2}$ 非負，且在 $[s,t]$ 上積分為 1（Eq. 83），所以 $\delta_{s,t}$ 是沿軌跡 denoiser 的加權平均，即凸組合。每個 $D_\tau$ 都在 simplex 上，它們的凸組合也在 simplex 上。相對地，$X_{s,t}$ 含噪聲項 $\frac{1-t}{1-s}x$，所以離開 simplex。這讓 flow map 也能用 softmax 參數化、以 KL 或交叉熵學習（Fig. 4）。性質 (ii) 對真 flow map 與真 denoiser 成立；學到的 $\hat\delta$ 在 simplex 上是因為 softmax 參數化。

    推導：Eq. 82–83 與半群權重 γ（App. C.3–C.4）

    Eq. 82。沿軌跡 $x_\tau=X_{s,\tau}(x)$，由 Eq. 9 得 $\dot x_\tau=(D_\tau-x_\tau)/(1-\tau)$（Eq. 79）。兩邊乘積分因子 $1/(1-\tau)$：$\frac{d}{d\tau}\frac{x_\tau}{1-\tau}=\frac{D_\tau}{(1-\tau)^2}$（Eq. 80）。從 $s$ 積到 $t$：$\frac{X_{s,t}}{1-t}-\frac{x}{1-s}=\int_s^t\frac{D_\tau}{(1-\tau)^2}d\tau$（Eq. 81）。與 (i) 比對，即得 Eq. 82。權重的積分 $\frac{(1-s)(1-t)}{t-s}\big[\frac1{1-t}-\frac1{1-s}\big]=1$（Eq. 83）。

    γ。兩邊都用 (i) 展開：$X_{s,t}(x)=X_{u,t}(X_{s,u}(x))$ 的右邊是 $\frac{1-t}{1-u}X_{s,u}+\frac{t-u}{1-u}\delta_{u,t}(X_{s,u})$，再把 $X_{s,u}$ 展開（Eq. 94–96）。$x$ 的係數兩邊都是 $\frac{1-t}{1-s}$，消去後乘 $(1-s)/(t-s)$，得 $\delta_{s,t}=\frac{(1-t)(u-s)}{(1-u)(t-s)}\delta_{s,u}+\frac{(t-u)(1-s)}{(1-u)(t-s)}\delta_{u,t}(X_{s,u})$（Eq. 97）。兩個係數的和是 1，因為 $(1-t)(u-s)+(t-u)(1-s)=(t-s)(1-u)$（Eq. 98）。

    中點 $u=(s+t)/2$ 時 $\gamma=(1-t)/(2-s-t)$（Prop. C.9）。本頁推導$t=1$ 時 Eq. 19 給出 $X_{s,1}=\delta_{s,1}$；真資料是 one-hot，所以真 $\delta_{0,1}(x_0)$ 幾乎必然是 simplex 的頂點，一步生成是對輸出取 argmax（Alg. 8 回傳 $g(x_{t_N})$），不是從 softmax 抽樣。$t=1$ 時 $\gamma=0$，半群教師完全來自 $\delta_{u,1}(X_{s,u})$。

      08 · 蒸餾

      以 KL 半群目標把 FLM 蒸餾成 FMLM

      有了 $\delta_{s,t}$，就可以用 KL 目標學 flow map（Prop. 3.4）。蒸餾後的模型稱為 FMLM（flow map language model）：

      $$\begin{aligned}\mathcal L_{KL}(\delta)={}&\mathbb E_{t,s,u}\,\mathbb E\Big[\sum_l\mathrm{KL}\big(\bar\delta^l_{s,t}\,\big\|\,\delta^l_{s,t}(I_s)\big)\Big]\\&+\mathbb E_t\,\mathbb E\Big[\sum_l\mathrm{KL}\big(D^l_t(I_t)\,\big\|\,\delta^l_{t,t}(I_t)\big)\Big],\\ \bar\delta_{s,t}:={}&\mathrm{sg}\big(\gamma\,\delta_{s,u}(I_s)+(1-\gamma)\,\delta_{u,t}(X_{s,u}(I_s))\big)\end{aligned}$$
      Eq. 23

      離對角項讓 $\delta_{s,t}(I_s)$ 逼近停止梯度（sg）的半群教師 $\bar\delta_{s,t}=\mathrm{sg}(\gamma\delta_{s,u}+(1-\gamma)\delta_{u,t}(X_{s,u}))$，也就是 Prop. 3.3 (iv) 的右邊；對角項讓 $\delta_{t,t}$ 逼近 denoiser。實作把 $D_t$ 換成凍結的預訓練 FLM $\hat D_t$，所以這是蒸餾。$(s,u,t)$ 的分布需在 $\{0\le s\le u\le t\le1\}$ 上 full support。作者證明在教師精確時唯一的最小值是真 $\delta$（App. C.5 的證明是簡短的 sketch，不是收斂保證）。

      用 KL 而不用交叉熵，是因為 KL 的最小值為 0，可以直接量測重建品質；兩者只差常數，學習動態相同（Sec. 3.3）。Alg. 7 寫成交叉熵形式。把對角項的 $D_t$ 換成 one-hot $x_1$，就得到 Eq. 12 的交叉熵，成為不需教師的直接訓練（self-distillation，Eq. 104）。

      09 · 離散沒有 flow map

      離散狀態空間沒有樣本層級的 flow map

      離散擴散能不能也學 flow map？先定義 pushforward：對映射 $f:S\to S$ 與 $S$ 上的分布 $\mu$，$f_\#\mu$ 是把每個點 $x$ 上的機率整塊搬到 $f(x)$ 後得到的分布。確定性的樣本層級 flow map 做的事，就是把初始分布 pushforward 成目標分布。下圖在只有 4 個狀態的集合上列舉所有確定性映射。

      C4

      確定性映射能推出哪些分布

      選擇初始分布 μ，拖動目標值 ν(y₀)：數線上的實心點是 256 個映射能推出的所有 ν(y₀)。

      μ 在 4 個狀態上的機率

      可達的 ν(y₀)

      • 目標

      對照：連續空間中，高斯經單調映射可以推出任何一維連續分布（文字對照，本圖不計算）。

      S = {y₀, y₁, y₂, y₃}。列舉全部 4⁴ = 256 個 f : S → S，對每個 f 計算 ν = f#μ（四捨五入到 1e−10 後去重）。

      確定性映射只能整塊搬移機率，不能把一個點的機率拆開：

      $$\nu(y)=\sum_{x\in f^{-1}(y)}\mu(x)$$
      Eq. 70

      每個 $\nu(y)$ 都是 $\mu$ 值的子集和。圖中 A 的可達值是 0, 0.1, …, 1.0，0.05 不可達；B 只有 0、0.25、0.5、0.75、1；C 只有 0 與 1，對應 masked diffusion 從全遮罩出發的情形。

      Prop. 3.5：設 $S$ 是有限集合且 $|S|\ge2$（$|S|=1$ 時唯一的分布就是 $\mu$ 本身）。對 $S$ 上任意分布 $\mu$，存在分布 $\nu$ 無法寫成任何確定性映射 $f:S\to S$ 的 $f_\#\mu$。證明：由 Eq. 70，$\nu$ 的每個正值至少是最小正質量 $\mu_{\min}:=\min\{\mu(x)\mid\mu(x)>0\}$；取一個 $\nu(y_0)=\mu_{\min}/2$ 的分布，它就不可達。套用到離散擴散時取 $S=V^L$、$\mu=p_0$。

      離散擴散的隨機過程是 CTMC（連續時間馬可夫鏈：離散狀態之間依速率跳躍的隨機過程）。它的分布滿足 master equation $\dot p_t=Q_tp_t$，這是描述 CTMC 分布隨時間變化的線性 ODE，$Q_t\in\mathbb R^{|V|^L\times|V|^L}$。所以分布層級的確定性演化與 flow map 存在，但這個矩陣無法計算或表示，只能用因子化近似；樣本層級則由 Prop. 3.5，一般不存在確定性的 flow map。連續 flow 有樣本層級的 flow map，可以學習並計算。

      Prop. 3.5 沒有說的事

      它沒有說真實資料分布不可達，也沒有量化近似誤差。本頁推導若 $\mu$ 在 $S$ 上均勻，可達的 $\nu$ 是機率皆為 $1/|S|$ 整數倍的分布，$|S|=|V|^L$ 時可以近似得任意細；若 $\mu$ 是 masked diffusion 全遮罩的點質量，$f_\#\mu$ 只能是點質量。實務上的障礙是第 01 節的因子化。

      檢查理解

      命題說什麼？證明關鍵？它沒有說什麼？

      $S$ 有限時，對任意 $\mu$ 存在 $\nu$ 無法寫成確定性映射的 $f_\#\mu$；需 $|S|\ge2$；$\nu(y)$ 是 $\mu$ 值的子集和（Eq. 70），正值至少是最小正質量 $\mu_{\min}=\min\{\mu(x)\mid\mu(x)>0\}$，取 $\nu(y_0)=\mu_{\min}/2$ 即不可達；它沒有說真實資料分布不可達，也沒有量化誤差。

      常見錯誤

      1. 時間方向弄反。本文 $t=0$ 是噪聲、$t=1$ 是資料。
      2. 一步生成從 softmax 抽樣。Alg. 8 是確定性合成後取 argmax（$g$）。
      3. 把 $\delta_{s,t}$ 當成 $x_t$ 處的 denoiser 或終點預測。它的輸入是 $x_s$，是 $s$ 到 $t$ 沿軌跡 denoiser 的加權平均（Eq. 82），只有 $s=t$ 時等於 $D_s$。
      4. 把 denoiser 當成一步 flow map。$D_t$ 是步長 $1-t$ 的 Euler 步、後驗平均（Eq. 77）。
      5. $\gamma$ 用 $t$ 空間的中點公式。中點取在 $\tau$ 空間，$\gamma$ 必須用一般式。
      6. 在 $t\to1$ 直接用 Eq. 9 換算速度。$(1-t)^{-1}$ 奇異；Alg. 6 只在 $t_n<1$ 評估 denoiser。
      7. 省略邊界取樣。一步 Gen. PPL 變成 142.61，entropy 3.81（Table 18）。
      8. 只看 Gen. PPL。Simplex 85.07 但 entropy 3.76；Duo+Di4C 292.94 但 3.79。
      9. 以為 $\tau(t)$ 是學出來的。它是預先算好的查表加 spline。
      10. 取樣器的出入。App. E 寫 FLM 用 Euler、FMLM 用 Kim et al. [91] 的「γ-sampling」（γ 值未給，與半群的 γ 同符號不同義）；App. G 又稱兩者為 deterministic sampling，與 Alg. 6、8 一致。論文引用 [91, 92] 取最佳 γ 值，但沒有說明 γ-sampling 與 Alg. 8 的關係。本頁以 Alg. 8 為準；一步時兩者沒有差別。
      12 · 研究脈絡

      研究脈絡（由 notes/timeline.json 提供）

      自回歸生成的序列瓶頸推動了平行解碼（非自回歸翻譯）與離散擴散（D3PM、SEDD、MDLM、Duo）；少步取樣時的品質下降（SDTT）指向因子化誤差。另一條路是連續 embedding 擴散（Diffusion-LM、CDCD）；Analog Bits 是類似 one-hot 的連續表示先例。flow matching 提供確定性的 ODE 框架，Li 與 He 的 Back to Basics（arXiv 2511.13720）說明為何要改學 denoiser 而不是速度。flow map 一線從 consistency models 到 flow map matching、self-distillation 與 MeanFlow，處理少步生成。本文把 one-hot 表示、交叉熵 denoiser 與 two-time denoiser 接在一起，$P_e$ 指標沿用自 Duo 與 CANDI。Analog Bits 與 Back to Basics 不在時間線中。每張卡片連到對應的研究筆記。

      13 · 限制與延伸

      限制與延伸閱讀

      one-hot 表示每一步都要對完整的 $|V|\times d$ embedding 矩陣求值與反向傳播，比只更新相關 embedding 的 embedding diffusion 多約 30% 的時間與記憶體（Sec. 6）；App. F 另寫比 MDLM 多 15–20% 記憶體但 wall-clock 較快（Table 32 算得 1.16–1.24 倍），兩處數字不同。作者建議以稀疏梯度或結構化表示改善，並看好把一步生成用於 RL finetuning 的 rollout。
