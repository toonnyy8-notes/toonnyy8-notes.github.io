## 1. 介紹（步驟 6-1）

### 1.1 一段話總結

以可驗證獎勵做強化學習（RLVR，reinforcement learning with verifiable rewards）的做法是：模型解題，程式檢查答案，答對就給獎勵。這種方法只能從模型「偶爾答對」的題目學到東西。如果模型對一題取樣 128 次全部答錯（作者把這類題目的集合稱為 fail@128），訓練幾乎沒有訊號。本文要回答的問題是：模型能不能為自己做不出的題目，產生一批合成練習題，讓自己之後能在原本的難題上進步？作者稱這類題目為「墊腳石」（stepping stones）；本頁的字面定義是：難度介於學生目前會解的題目與目標難題之間的合成題。

作者提出 **SOAR**（Self-Optimization via Asymmetric RL）。同一個預訓練模型複製成兩份：**老師**出題，題目與答案都由老師寫；**學生**用這些題目做 10 步 RL。老師得到的獎勵是學生訓練後，在一批真實難題上的**貪婪解碼正確率進步量**（Sec. 3.2）。這個問題寫成數學是雙層最佳化（Eq. 1），作者用兩層 RLOO 實作，因此不需要穿過內層訓練做反向傳播。老師從頭到尾沒有看過難題。

主要結果（Llama-3.2-3B-Instruct）：在 fail@128 MATH 測試集上，以「晉升題目（PQ）＋fail@128 訓練集」從頭訓練的新學生，pass@32 為 18.9 ± 5.3%；只用 fail@128 訓練集訓練（Hard-Only）為 9.6 ± 2.6%（Table 4）。HARP 上是 12.3 ± 2.0% 對 8.2 ± 1.0%（Table 5）。以「學生進步量」為獎勵的老師，比以可學習性（learnability）為獎勵的老師穩定，題目多樣性也較高（Table 1）。PQ 中只有 32.8% 的題目答案完全正確（Table 7），作者據此認為，題目是否適切比答案是否正確更重要。

### 1.2 研究動機（Sec. 1、Sec. 2）

1. RLVR 的限制：模型完全不會的題目得不到正向獎勵，訓練停滯。
2. 課程學習（curriculum learning，把題目由易到難排序來訓練）有效，但需要人工設計，也需要整理好的中間資料集。
3. 近期「不用資料」的 LLM 自我對弈系統，例如 Absolute Zero、R-Zero、LSP、SeRL、SQLM（App. A.2），用內在獎勵或代理獎勵（多數決、可學習性、獎勵模型偏好、梯度大小）訓練出題者。作者引用文獻指出，這類目標容易漂移到退化或學不會的題目，容易發生獎勵駭客（reward hacking：模型提高訓練獎勵，卻沒有完成真正的任務），長時間訓練還可能突然崩潰。
4. 作者的假設：預訓練模型看過大量簡單題目，即使解不出某題微積分，也可能寫得出相關的連鎖律練習題（Sec. 1）。

### 1.3 貢獻（Sec. 1）

1. 教與解分離：產生有效合成題目的能力，和解題能力是兩回事。基礎模型本來就能偶爾產生好題目，meta-RL 讓它更常產生（作者稱為「銳化」，sharpening；本頁的字面定義是：提高原本機率很低的有效輸出的機率）。
2. SOAR 的概念驗證。摘要寫：MATH 上 pass@1 為 4 倍、pass@32 為 2 倍；HARP 上 pass@1 為 2 倍、pass@32 為 1.5 倍。合成題目也能轉移到沒有拿來最佳化的資料集。
3. 以真實表現為依據的獎勵（grounded reward）比內在獎勵穩定，也不會讓題目多樣性崩塌。
4. 題目結構與難度校準，比答案正確更重要。
- 實驗規模：超過 600 次執行。
- 〔本頁推導〕用 Table 4–5 的 PQ 列計算相對 Hard-Only 的倍數，並用 delta 法（一階誤差傳遞）估計倍數的標準差：MATH pass@1 為 PQ 1.7 ± 1.0 對 Hard-Only 0.5 ± 0.1，1.7/0.5 = 3.40 ± 2.11，pass@32 為 1.97；HARP pass@1 為 0.7 ± 0.3 對 0.4 ± 0.1，1.75 ± 0.87，pass@32 為 1.50。摘要的「4×」無法由 PQ 列得出（R4）。pass@1 的倍數受雜訊主導，頁面只要引用倍數，就同時附上這個標準差。

#### 步驟 1：定義失敗區（Sec. 3 開頭、Sec. 4.1、App. B.5）

- 設定：困難資料集 $D$ 上，$\pi_\theta$ 的成功率是 0/128。直接在 $D_{train}$ 上做 RL（REINFORCE、GRPO、RLOO 等），因為正向獎勵太少，可能沒有進步。作者把這個失敗區當成測試平台。
- fail@128 篩選：每題用學生提示詞取樣 128 個解答，token 上限 1024，溫度 1.0，只保留 0/128 的題目。作者說 128 是「實用但嚴格」的門檻：在這個門檻下，直接訓練只有邊際改善。
- 切分：隨機 50/50。作者的理由是：基礎通過率很低，需要較大的測試集，才能把進步和隨機變異分開。
- Table 2（題數大幅減少是因為只保留 0/128 的題目，例如 MATH 5000 題中只有 359 + 360 = 719 題留下）：MATH 5000 題 → 訓練 359 題／測試 360 題；HARP 4768 → 714／714；OlympiadBench 674 → 158／158。
- MATH 的特殊處理：模型在官方 MATH 訓練集與測試集的零樣本正確率分別是 60% 與 37%，作者懷疑模型看過訓練題，所以只從官方 5000 題**測試集**取題，再做篩選與切分。
- 〔本頁推導〕0/128 不等於「永遠答不對」。如果單次答對的機率是 $p$，128 次全錯的機率是 $(1-p)^{128}$。$p=0.002$ 是依 Table 4 基礎模型 pass@1 = 0.3% 選的〔示範值〕；這個 $p$ 下，題目通過篩選的機率是 0.774，pass@32 是 $1-(1-p)^{32}=0.062$。論文自己對「基礎模型推論的 pass@k 不為 0」的解釋是：推論用的隨機種子和篩選時不同（Sec. 5.1）。頁面並列兩者，不宣稱表格支持單題 $p$ 的模型。

#### 步驟 2：稀疏獎勵為什麼讓 RLOO 沒有訊號（Eq. 4、App. B.3）

- 策略梯度（§1b 的字面說明）：每個解答的 log 機率梯度 $\nabla\ln\pi(z)$ 指出「怎麼調參數才能讓這個解答更常出現」。乘上優勢 $A$ 後，比平均好的解答變得更常出現，比平均差的變得更少出現。
- RLOO（REINFORCE Leave-One-Out，Ahmadian et al., 2024）：同一題取樣一組解答，第 $i$ 個的優勢是
  $$A(z_i)=R(z_i)-\frac1{G-1}\sum_{j\ne i}R(z_j)\tag{Eq. 4，群組大小改記為 G}$$
  更新方向是 $\sum_iA(z_i)\nabla\ln\pi(z_i)$。
- 〔本頁推導〕等價寫法 $A(z_i)=\frac{G}{G-1}(R(z_i)-\bar R)$，因此 $\sum_iA(z_i)=0$。
- 學生的實際獎勵（App. B.3，用 Math-Verify 比對答案，數字照原文印刷）：有 `\boxed{}` 且答案正確給 120.0；有 boxed、答案錯但標準答案出現在 $y_{ans}$ 中給 20.0；有 boxed、答案錯且不含標準答案給 10.0；其他給 0.0。所以實際上「全錯」的群組，獎勵通常仍有 0、10、20 的差別，梯度不為 0。這類格式分級獎勵只能教格式，不能教對答案。
- 〔本頁推導，二元獎勵理想化〕論文在 Sec. 1、Sec. 4.1 稱這個情形為「稀疏的二元獎勵」。如果獎勵只有對（1）與錯（0）兩種，全錯的群組優勢全為 0，梯度為 0；群組內同時有對有錯的機率是 $1-(1-p)^G-p^G$。$G=32$、$p=0.002$ 時這個機率是 0.062，也就是約 94% 的題目在一次取樣中不提供「答對方向」的梯度。這個 94% 是二元模型下的數字。

#### 步驟 3：把出題寫成雙層最佳化（Sec. 3.1，Eq. 1）

$$\max_\phi\ \mathbb E_{\mathcal X\sim\pi_\phi^T}\Big[R\big(\pi^S_{\theta'(\mathcal X)},\,D_{train}\big)\Big]\quad\text{s.t.}\quad\theta'(\mathcal X)=\text{RL-update}(\theta,\mathcal X)\tag{Eq. 1}$$

- 內層：學生在 $\mathcal X$ 上做 RL，得到 $\theta'(\mathcal X)$。外層：老師要讓更新後的學生在 $D_{train}$ 上的表現 $R$ 最大。
- 先例：meta-learning（MAML、Reptile）、超參數學習、資料集蒸餾（dataset distillation：外層最佳化一個小資料集，讓內層訓練在目標上表現好；作者說這部分啟發了本文）。這類方法一般要展開內層的多步訓練，做「穿過梯度下降的反向傳播」（BPTT），步數多時算不動（Sec. 2、App. A.3）。
- 作者的做法是巢狀 meta-RL：外層用 RLOO 訓練老師，內層用 RLVR（也是 RLOO）訓練學生，學生的進步量是給老師的黑箱獎勵。策略梯度只需要獎勵值，不需要對內層求導（App. A.3：「the first instance of a 'double meta-RL loop'」）。
- 不假設能自動驗證題目或答案。作者認為，只獎勵「讓學生在真題上進步」的題目，可以把出題綁在真實的學習進度上，也隱含地懲罰退化題目與獎勵駭客（Sec. 3.1）。頁面以「作者認為」標示這段。

#### 步驟 4：外層迴圈：老師的獎勵（Sec. 3.2）

- 每個外層步取樣 $g\cdot n$ 個輸出，分成 $g$ 個資料集，每個 $n$ 題。每個輸出解析成 $(q_i,a_i)$，格式不符就重抽（App. B.2）。
- 抽 $Q_R\sim D_{train}$（64 題），對每個 $\mathcal X_d$ 訓練學生固定步數，資料集獎勵是
  $$R(\mathcal X_d)=\mathrm{Acc}\big(\pi^S_{\theta'_d}(Q_R)\big)-\mathrm{Acc}\big(\pi^S_\theta(Q_R)\big)$$
  Acc 用貪婪解碼（App. B.7：為了降低學生獎勵的雜訊）。〔本頁推導〕在 64 題上，單一學生的 Acc 差一定是 1/64 ≈ 0.0156 的整數倍，比 τ = 0.01 還大。
- 減去基準正確率，是為了讓不同外層步的獎勵可以互相比較，晉升機制需要這一點（Sec. 3.2）。
- 每個資料集平行訓練 $r=4$ 個學生，取 $R_d=\frac1r\sum_jR_{d,j}$。$\mathcal X_d$ 中每個輸出都拿到 $R_d$。
- 老師提示詞（App. B.1）每一步都相同：列出允許的主題（Algebra、Counting and Probability、Geometry、Intermediate Algebra、Number Theory、Prealgebra、Precalculus）與格式 `<question>…</question><answer>\boxed{…}</answer>`，要求原創、至少 2–3 步推理、只出一題。**不給範例題**：作者在初步實驗中觀察到，給範例題時多樣性大幅下降，老師常直接照抄範例。

#### 步驟 5：學生晉升與完整演算法（Sec. 3.3、Alg. 1、App. B.3、B.7）

- 內層：學生在 $\mathcal X_d$ 上用 RLOO 訓練 10 步（batch size 8）；每次內層結束，學生**回到基準策略**。App. B.7 寫：基準學生被更新（晉升）之後，內層訓練稍微延長，多 5 步；論文沒有說明是每次晉升都再加 5 步，還是只在第一次晉升後由 10 步改為 15 步。頁面寫成「晉升後內層改為 15 步（論文未說明是否隨晉升次數累加）」。
- **晉升**（promotion，字面意思是「更換基準學生」）：老師獎勵的 3 步移動平均超過 $\tau=0.01$ 時，把基準學生換成「在最佳資料集上訓練過的那個學生」，之後的獎勵都相對新基準計算。

#### 步驟 6（選讀）：重抽格式錯誤的輸出不會使 RLOO 更新有偏（App. B.2，Prop. 1，Eq. 2–7）

- 過濾條件：題目與答案的開閉標籤都有；有 boxed；boxed 內容能被符號數學驗證器解析。不符合就重抽，直到湊滿 $g\cdot n$ 題。
- 問題：重抽等於從截斷分布 $\pi(z)=\pi_0(z)\mathbb 1_{z\in S_{acc}}/\pi_0(S_{acc})$（Eq. 2）取樣，但能求梯度的只有 $\pi_0$（模型本身）。
- Prop. 1 的前提：$\pi_0(S_{acc})>0$；$R(z)$ 是 $z$ 的獎勵函數。結論：對 $\pi$ 取樣得到的任意 $g$ 元組，
  $$\sum_iA(z_i)\nabla\ln\pi(z_i)=\sum_iA(z_i)\nabla\ln\pi_0(z_i)\tag{Eq. 3}$$
  證明：$z\in S_{acc}$ 時，$\ln\pi(z)=\ln\pi_0(z)-\ln\pi_0(S_{acc})$，多出的項是 $-(\sum_iA(z_i))\nabla\ln\pi_0(S_{acc})$（Eq. 5–6）。RLOO 的優勢總和為 0，所以這一項消失（Eq. 7）。論文明寫：這對單純的 REINFORCE 不成立。
- 在 SOAR 中，同一資料集的所有輸出共用 $R_d$；證明只需要群組內優勢總和為 0，因此仍然成立。用哪一組計算基準，見步驟 5 的本頁約定。
- 實證：拒絕取樣比格式獎勵、比先抽題目再抽答案都好（App. B.2）；多輪出題的消融也比較差（D.3）。
- 〔本頁推導〕令 $\pi_0=\mathrm{softmax}(\theta)$。$\nabla_{\theta}\ln\pi_0(z)=e_z-\pi_0$（$e_z$ 是第 $z$ 個分量為 1 的單位向量；這正是交叉熵損失梯度的負號），$\nabla_\theta\ln\pi_0(S_{acc})=\pi_c-\pi_0$。因此左式減右式等於 $(\sum_iA_i)(\pi_0-\pi_c)$。在被拒絕的輸出 $j\notin S_{acc}$ 上，$\pi_c(j)=0$，左式為 0，右式為 $-(\sum_iA_i)\pi_0(j)$：$\sum A>0$ 時壓低這些輸出，$\sum A<0$ 時抬高。C2 即時計算這些值，check.py 以有限差分確認 L、Q 確實是對 $\theta_j$ 的梯度分量。

#### 步驟 7：評估方式（Sec. 4.3、App. B.6、B.8）

- 評估時間點：MATH 取第 200 步、HARP 取第 170 步，也就是老師獎勵開始趨平或下降的位置。
- **PS**（Promoted Student）：在有多次晉升的執行中，取驗證表現最好的晉升學生（以 $D_{train}$ 貪婪正確率判斷），直接在測試集上推論。最多 4 次晉升，所以 PS 訓練過 128、192 或 256 題。
- **PQ**（Promotion Questions）：步驟 5 的 $D_{best}$。評估時用標準 RLOO 從頭訓練一個新的基礎學生，資料是 PQ＋fail@128 訓練集。目的是把「題目的價值」與「某一條幸運的學生訓練軌跡」分開。
- 合成題與真題的混合方式（App. B.6）：**課程訓練**＝先用合成題訓練 64 步，再換成真題；**混合訓練**＝全程混在一起。依基準方法 Base-T 的表現選擇：MATH 用課程訓練（Fig. 7），HARP 與 OlympiadBench 用混合訓練（課程訓練在這兩者出現早期突升後驟降，Fig. 8）。
- 基準：**Hard-Only**（直接訓練 fail@128 訓練集，群組大小 $G=32$；MATH 另跑 $G=128$，取樣量是 4 倍）；**Intrinsic-T**（流程與超參數相同，老師獎勵換成可學習性，取樣 128 題訓練新學生）；**SeRL**（以 fail@128 訓練集為種子、自我演化課程的方法）；**MATH train (Full)**（完整 MATH 訓練集 6750 題＋fail@128 訓練集，論文稱為上界參考）。
- 指標：fail@128 測試集上的 pass@k，$k\in\{1,4,8,16,32\}$，每題取 32 個樣本；報告 6–12 個種子的平均與標準差。
- 細節（頁面收進 `<details>`）：新學生最多訓練 1500 步；把訓練獎勵做 25 步置中移動平均，取正規化斜率首次低於最大值 15% 的步數，測試表現取之後 200 步的平均；OlympiadBench 固定取第 50 步。種子：MATH、HARP 各訓練 4 個老師；Intrinsic-T 與無晉升版各 3 個；Hard-Only ≥ 6 個；PQ ≥ 6 個；PS 3 個推論種子；老師取樣實驗 ≥ 8 個。

#### 步驟 8：結果一：合成題目讓學生在 fail@128 測試集上進步（Sec. 5.1，Table 4–6）

- MATH（Table 4，pass@32）：Hard-Only 9.6 ± 2.6；PQ 18.9 ± 5.3；PS 18.1 ± 2.4；Grounded-T 19.1 ± 3.7；Intrinsic-T 14.1 ± 7.5；SeRL（step 100）12.4 ± 1.0；Hard-Only（$G=128$）12.4 ± 7.4；MATH train (Full) 22.0 ± 2.4；HARP train (128) 23.0 ± 3.9。
- 內文的差距（Sec. 5.1）：PS 比 Hard-Only 高 +8.5%（MATH）、+3.6%（HARP）pass@32；PQ 高 +9.3%（MATH）、+4.2%（HARP）。這些是**百分點**（18.9 − 9.6 = 9.3）。〔本頁推導〕HARP 由 Table 5 算出 12.3 − 8.2 = 4.1（R4）。百分點差距隨 k 變大；倍數反而變小（MATH PQ：3.40 → 1.97）。
- $G=128$ 的 Hard-Only 只高 2.8 個百分點；Hard-Only 從 1500 步延長到 6500 步（HARP）也沒有進步（Fig. 10）。
- MATH 上，PQ 在合成題階段（64 步）結束、換成真題後仍持續進步（Fig. 9）；作者解讀為合成題讓真難題變得可學。
- OOD 轉移（Table 6，OlympiadBench pass@32）：Hard-Only 6.9；PQ (MATH) 10.6；PQ (HARP) 12.0；Intrinsic-T 9.1。作者推測 HARP 與 Olympiad 有較多共同結構。
- 與真實題目比較（Sec. 5.1）：PQ-MATH 回收 MATH train (Full) 收益的 75%，PQ-HARP 回收 50%。〔本頁推導〕回收比例＝(PQ − Hard-Only)/(MATH train (Full) − Hard-Only)，分母兩者都用 MATH train (Full)：MATH 為 (18.9 − 9.6)/(22.0 − 9.6) = 0.75；HARP 為 (12.3 − 8.2)/(16.2 − 8.2) = 0.51。MATH train (Full) 不是最大值：Table 4 中 HARP train (128) 為 23.0，Table 6 中 MATH train (128) 為 14.6 > 13.1。
- **教與解分離**：用訓練後的老師直接解 fail@128 測試題，pass@32 為 8.3（MATH，基礎模型 7.5）與 6.8（HARP，基礎 6.4），沒有改善。作者據此認為出題能力與解題能力大致獨立。

#### 步驟 9：結果二：以真實進步為獎勵的老師較穩定（Sec. 5.2，App. B.4，Table 1）

- 三種老師：Grounded-T（SOAR 訓練的老師）、Intrinsic-T（可學習性獎勵）、Base-T（未訓練的基礎模型）。各取樣 128 題，訓練 2–3 個新學生；Grounded-T 每個資料集 4 個種子，Intrinsic-T 3 個種子。
- 可學習性獎勵（App. B.4）：對 $\mathcal X_d$ 每題取 32 個學生解答，得到平均成功率 $\bar s_i$：
  $$u_i=\begin{cases}0,&\bar s_i=0\\1-\bar s_i,&\text{otherwise}\end{cases}\tag{Eq. 8，論文記為 }r_i$$
  $R_d=\frac1n\sum_iu_i$。$\bar s_i>0$ 時，$u_i$ 隨 $\bar s_i$ 單調下降；只有「0 次答對」會被截成 0。這個獎勵只看題目對學生的難度，和 $D_{train}$ 無關。
- 〔本頁推導〕設學生對某道合成題的單次成功率為 $s$（與步驟 1 的 $p$ 不同：$p$ 是難題，$s$ 是合成題），32 次取樣獨立，則 $\mathbb E[u]=(1-s)-(1-s)^{32}$，在 $s^*=1-32^{-1/31}\approx0.106$ 時最大（0.866）。峰值完全來自 32 次取樣與「0 次答對給 0」的截斷。F1 用獨立的座標軸呈現。
- 銳化：Grounded-T 的學生曲線落在 Base-T 各次執行的上緣，MATH 上變異較小（Fig. 5 左）。作者的解讀是：Base-T 也有成功的執行，所以好題目本來就潛藏在基礎模型中，meta-RL 讓老師更穩定地產生好題目。OlympiadBench 上兩者重疊較多。
- 內在獎勵的脆弱：不同種子的 Grounded-T 訓練出的學生軌跡很接近；Intrinsic-T 平均較差、變異較大，三個種子中有一個在所有資料集上崩潰，學生幾乎沒有進步（Fig. 5 右、Fig. 14）。
- 多樣性（Table 1，Vendi Score，用 Qwen3-8B 的嵌入，以 bootstrap 標準化到 128 題、重複 100 次）：Base-T 34.91（σ 1.74）；Grounded-T (HARP) 34.66（1.74）；Grounded-T (MATH) 31.99（1.54）；PQ 28.33（1.55）；Intrinsic-T 10.82（1.01）。論文的說明是「有效的獨特語意概念數」。Sec. 5.2 內文寫 PQ 為 31.75（R4）。
- 〔外部定義〕Vendi Score（Friedman & Dieng, 2023）是 $\exp(-\sum_i\lambda_i\ln\lambda_i)$，$\lambda_i$ 是相似度矩陣 $K/n$ 的特徵值。〔本頁推導〕$n$ 題完全相同時為 1，兩兩正交時為 $n$。
- App. E（Fig. 20）：Intrinsic-T 的獎勵平滑上升，同時老師輸出的多樣性（嵌入的平均成對餘弦距離）下降；Grounded-T 全程保持原模型的多樣性。

### C2 · RLOO 優勢與拒絕取樣（Prop. 1，§6 選讀）

- **教的概念**：Eq. 4 的優勢總和為 0；因此對截斷分布 $\pi$ 和對 $\pi_0$ 計算的梯度相同；REINFORCE 不成立；獎勵全相同時更新為 0（LO7）。
- **第一行假設**：「玩具：老師只有 6 種可能的輸出 z = 1…6，π₀ = softmax(θ)；θ、獎勵與樣本都是示範值。圖中的長條是更新方向對 θ₁…θ₆ 各分量的梯度（e_z − π，也就是交叉熵梯度的負號）。」
- **固定值〔示範值〕**：$\theta=(1.0,0.5,0.0,-0.5,0.8,0.2)$，$S_{acc}=\{1,2,3,4\}$，$z=(1,2,2,4)$，$R=(0.020,-0.010,0.000,0.030)$。
- **預設露出的控制項**：分段按鈕「優勢：RLOO／REINFORCE（A = R）」；按鈕「全部獎勵設為 0」；按鈕「獎勵全部變號」（用來看 ΣA < 0 的情形）。
- **收進 `<details>`「自訂」的控制項**：6 個勾選框「格式正確」（勾選的輸出構成接受集合 $S_{acc}$，未勾選的就是被拒絕、會被重抽的輸出；標籤文字寫明這一點）（至少保留 1 個）；4 列樣本（下拉選單「輸出 z」只列 $S_{acc}$ 中的輸出，勾選改變時自動改成 $S_{acc}$ 中編號最小者；滑桿「獎勵 R」，−0.04 到 0.04，步長 0.001）。
- **計算**：$\pi_0=\mathrm{softmax}(\theta)$（先減最大值）；$\pi_c$；RLOO $A_i=R_i-\frac13\sum_{j\ne i}R_j$，或 $A_i=R_i$；左式 $L_j=\sum_iA_i(\mathbb 1[z_i=j]-\pi_c(j))$；右式 $Q_j=\sum_iA_i(\mathbb 1[z_i=j]-\pi_0(j))$；差 $(\sum A)(\pi_0-\pi_c)$。
- **顯示**：上排是 $\pi_0$（淺色）與 $\pi_c$（實色；$S_{acc}$ 外為 0，加 `currentColor` 斜線圖樣）的長條，讀數「接受率 π₀(S)」「平均需抽 1/π₀(S) 次」。中排是 $A_i$ 與 ΣA。下排是成對長條：「對 π 的梯度 L」實心、「對 π₀ 的梯度 Q」空心框線，零線上方表示「提高 θ_j」，下方表示「降低 θ_j」。結論列：$\max|L-Q|<10^{-12}$ 時顯示「兩式相同」，否則顯示差值。另一行由目前的 $S_{acc}$ 與 ΣA 即時產生：「被拒絕的輸出 {j ∉ S_acc 的編號清單} 在 Q 中的分量是 −(ΣA)π₀(j)」，接著 ΣA > 1e-12 時寫「ΣA > 0，這些輸出被壓低」，ΣA < −1e-12 時寫「ΣA < 0，這些輸出被抬高」，|ΣA| ≤ 1e-12 時寫「ΣA = 0，沒有偏差」；$S_{acc}$ 包含全部 6 個輸出時改寫「目前沒有被拒絕的輸出」。
- **預設輸出**：$\pi_0=(0.2886,0.1750,0.1062,0.0644,0.2362,0.1297)$；$\pi_0(S)=0.6341$；平均抽 1.577 次；RLOO：$A=(0.01333,-0.02667,-0.01333,0.02667)$，ΣA = 0，$L=Q=(0.01333,-0.04,0,0.02667,0,0)$。REINFORCE：ΣA = +0.04，$L=(0.00180,-0.02104,-0.00670,0.02594,0,0)$，$Q=(0.00846,-0.01700,-0.00425,0.02742,-0.00945,-0.00519)$，最大差 0.00945。獎勵變號後（REINFORCE）：$Q_5=+0.00945$、$Q_6=+0.00519$。
- **讀者應觀察到**：RLOO 下兩式永遠相同；REINFORCE 的右式在每個被拒絕的輸出 $j\notin S_{acc}$ 上多出 $-(\Sigma A)\pi_0(j)$，ΣA > 0 時壓低、ΣA < 0 時抬高（預設 $S_{acc}$ 下就是輸出 5、6）；獎勵全部為 0 時，兩種方法的更新都是 0。

**C3a 單步計算**
- **教的概念**：Alg. 1 第 13–25 行的算術（LO5、LO6）。
- **第一行**：「每格輸入一個學生在 64 道獎勵題上的淨增答對題數 c（獎勵 R = c/64）。數值是示範值；論文沒有提供單步數據。老師優勢的分組方式是本頁約定。」
- **輸入**：4×4 整數格（列為資料集 d = 1…4，欄為學生 j = 1…4），`<input type="number" inputmode="numeric" min="-64" max="64" step="1">`。預設〔示範值〕：d=1：1, 2, 0, 1；d=2：−1, 0, 1, −1；d=3：0, 1, −1, 0；d=4：2, 1, 3, 0。前兩步的步平均（預設 0.010、0.014）；τ（預設 0.01）；按鈕「還原示範值」。
- **計算**：$R_{d,j}=c/64$；$R_d$ 為列平均；步平均；移動平均＝(前兩步＋本步)/3；晉升條件為移動平均 > τ；$d^*$ 為 $R_d$ 最大者（同值取最小 d）；$j^*$ 為排序後第 2 小（同值取較小 j）；$A_d=R_d-\frac13\sum_{l\ne d}R_l$〔本頁約定〕。非整數或超出範圍：設 `aria-invalid="true"`，以 `aria-describedby` 連到文字訊息「請輸入 −64 到 64 的整數」，該格以 0 計算。
- **顯示**：每列右側顯示 $R_d$；下方步驟清單對應 Alg. 1 的行號；結果列以文字＋圖示標示「晉升：資料集 4、學生 2；D_best 增加 64 題」或「不晉升：學生回到基準」，同時以 `--accent` 外框標出選中的格子；老師優勢以正負長條呈現並附 ΣA。
- **預設輸出**：$R_d=(0.015625,-0.003906,0,0.023438)$；步平均 0.008789；移動平均 0.010930 → 晉升；$d^*=4$，$j^*=2$（c = 1）；$A=(0.009115,-0.016927,-0.011719,0.019531)$，ΣA = 0。
- **讀者應觀察到**：本步的平均（0.0088）低於 τ，但前兩步把移動平均拉過門檻；把前兩步改成 0.002、0.006，移動平均變成 0.005596，不晉升。

**C3b 雜訊與門檻**
- **教的概念**：〔本頁推導〕平均多個學生與取移動平均，各能減少哪一部分「沒有真正進步卻晉升」的情形。
- **第一行假設**：「假設每個學生的獎勵 = 真實進步 μ + 本步共同雜訊（標準差 σ_c，因為同一步的學生共用 64 道獎勵題與同一個基準）+ 個別雜訊（標準差 σ），各步之間獨立。實際獎勵是 1/64 的整數倍，這裡以常態近似。論文沒有報告 σ、σ_c；預設值是示範值。σ_c = 0 時算出的機率是下界。」
- **輸入**：滑桿 μ ∈ [−0.01, 0.02]（步長 0.001，預設 0）；σ ∈ [0.005, 0.06]（預設 0.02）；σ_c ∈ [0, 0.02]（步長 0.001，預設 0.005）；分段 r ∈ {1, 2, 4, 8}（預設 4）；分段窗口 m ∈ {1, 3}（預設 3）；τ = 0.01、g = 4 固定顯示。
- **計算**：$\sigma_{MA}=\sqrt{(\sigma_c^2+\sigma^2/(gr))/m}$；$P=\tfrac12\,\mathrm{erfcc}\big((\tau-\mu)/(\sigma_{MA}\sqrt2)\big)$；第 3 到第 200 步（198 步）的期望晉升判斷次數 $198P$（期望值的線性性不需要步間獨立）。$P<10^{-12}$ 時顯示「< 1e-12」。erfcc 程式碼：

  ```js
  function erfcc(x){ // Numerical Recipes; fractional error < 1.2e-7
    const z=Math.abs(x), t=1/(1+0.5*z);
    const r=t*Math.exp(-z*z-1.26551223+t*(1.00002368+t*(0.37409196+t*(0.09678418+
      t*(-0.18628806+t*(0.27886807+t*(-1.13520398+t*(1.48851587+t*(-0.82215223+t*0.17087277)))))))));
    return x>=0 ? r : 2-r;
  }
  ```
- **顯示**：移動平均分布的常態密度曲線，τ 右側塗色面積即 P；讀數「每步誤晉升機率」「200 步中的期望次數」；小表列出 (r, m) = (1,1)、(4,1)、(1,3)、(4,3) 在目前 μ、σ、σ_c 下的 P，外加一列「σ_c = 0（下界）」。
- **預設輸出**（σ_c = 0.005）：(4,3) P = 7.153e-3，期望 1.42；σ_c = 0 時 (4,3) P = 2.660e-4（期望 0.053）、(1,1) P = 0.1587（31.4）。σ_c = 0.01 時 (4,3) P = 0.0607（12.0）。μ = 0.01 時 P = 0.5。
- **讀者應觀察到（在此假設下）**：增加 r 只能壓低個別雜訊；共同雜訊只能靠窗口 m 平均。所以論文設定的誤晉升機率取決於 σ_c，而論文沒有報告這個量。
