# 405 驗收答案（只依頁面文字）

**LO1**
答：x_t 由真實影像加噪得到：x_t = √ᾱ_t·x_0 + √(1−ᾱ_t)·ε，ε~N(0,I)（Eq. 4）。網路 ε_θ(x_t,t) 回歸的目標是噪聲 ε，損失為 L2（Eq. 5）。
段落：「所以 xt 由真實影像 x0 加噪得到」
信心：high

**LO2**
答：訓練時網路輸入 x_t 由真值 x_0 加噪算出；取樣時輸入 x̂_t 是網路前一步的預測，誤差沿取樣鏈累積（曝光偏差）。DDPM-IP 只改訓練輸入（改用 y_t），推論仍用原本的 Alg. 2。
段落：「取樣時的輸入來自模型自己的預測」
信心：high

**LO3**
答：Tab. 1 協定：由真實 x_0 用 Eq. 4 算 x_t，再從 x_t（不是隨機 x_T）執行 t 步反向（Alg. 2），以 FID 比較 q(x_0) 與 q(x̂_0)。資料為 ImageNet 32×32 的 ADM，每組 5 萬樣本。ADM 的 FID 隨反向步數增加：t=100 為 0.983、300 為 1.808、500 為 2.587、700 為 3.105、1,000 為 3.544。
段落：「ADM 的 FID 由 100 步 0.983 增加到 1,000 步 3.544」
信心：high

**LO4**

段落：「xt 已遺失部分 x0 的資訊」
信心：high

**LO5**

**LO7**
答：題目在 "$q(y_t" 處被截斷，無法確定完整問句，以下依頁面回答 q(y_t | x_0)。y_t = x_t + √(1−ᾱ_t)γξ 是兩個獨立高斯的線性組合，故 q(y_t|x_0) = N(y_t; √ᾱ_t·x_0, (1−ᾱ_t)(1+γ²)·I)（Eq. 7）。等價的標準 DDPM 形式為 y_t = √ᾱ_t·x_0 + √(1−ᾱ_t)√(1+γ²)·ε'（Eq. 8）。

**LO8**
答：兩者輸入相同（都是 y_t），目標不同：DDPM-IP 的目標是 ε，DDPM-y 的目標是 ε' = (ε+γξ)/√(1+γ²)（頁面推導）。DDPM-IP 較好：CIFAR10 在 1,000 步 FID 為 IP 2.76、DDPM 2.99、DDPM-y 3.25；80 步為 IP 2.93、DDPM 3.63、DDPM-y 4.24。Tab. 7 中每個測試步數 IP 都最好。DDPM-y 還比 DDPM 差，所以效果不是來自換噪聲變異數。
段落：「DDPM-y 比 DDPM 還差」
信心：high

**LO9**
答：作者用 Alg. 1 訓練的 ADM 估計預測誤差 e_t = x̂_0 − x_0 的標準差 ν_t，頁面讀出平均約 0.20（ImageNet 32）與 0.19（CIFAR10）。最直接的做法是令 γ_t = ν_t，但這需要兩階段訓練（先訓練基準模型估計 ν_t，再從頭訓練），成本高，所以改用常數 γ，在 [0, 0.2] 上網格搜尋得 0.1。作者承認常數「很可能不是最佳」。

**LO10**

段落：「斜率不能解釋 IP 的效果」
信心：high

## 初學者可能卡住的 5 處

1. **hat 符號**：訓練的 x_t（真值）與取樣的 x̂_t（預測）不同，x_0 與 x̂_0 也不同。
2. **σ_t 的記號**：Eq. 3 把它當變異數，Alg. 2 卻乘 σ_t·z。頁面判讀為變異數是 β̃_t，Alg. 2 應乘其平方根。
3. **三種噪聲 ε、ξ、ε'**：DDPM-IP 的目標是 ε（不含 ξ），DDPM-y 的目標是 ε'。γ 作用在 x_t 空間，ν_t 定義在 x_0 空間，單位不同，不能直接比大小。
4. **玩具與論文數字混淆**：C1–C3 的數字來自頁面自己的一維高斯玩具與固定比例誤差 ρ，不是論文結果。Tab. 1 與 Tab. 6 量的也不是同一件事。
5. **同名設定不同**：CelebA 的 ADM-IP 在 900 步得 FID 1.27，與 Tab. 4 的 200 步得 1.53 是不同設定。步數縮減用 respacing（重算 β），不是跳過某些步。
