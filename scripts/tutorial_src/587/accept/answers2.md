# LO13 答案

**LO13**：在 W3 中，固定 ε = 0.2 為何很少找到稀有的好動作？RIC 的增益能歸因於「形狀」嗎？

**回答**

第一部分（固定 ε 為何很少找到 B）：B 被取樣到後，比值一超過 1.2（即 1+ε）梯度就變成 0，因此每次迭代 B 的機率只能小幅上升，策略先集中到 A。頁面預設參數下，第 200 次迭代找到 B 的比例為 GRPO 0.015、DAPO 0.100、RIC 0.370、不 clip 0.395。

第二部分（RIC 的增益能否歸因於「形狀」）：不能。頁面明說這個增益不能歸因於「範圍隨機率改變的形狀」，依據是不 clip 的對照（0.395）與 RIC（0.370）相近；把 DAPO 的 ε_high 調到 1.0（下界保持 0.2）則達到 0.505。在這個玩具中大更新沒有代價，所以它只能示範「上界太小會阻礙發現稀有的好動作」，不能說明為什麼需要 trust region。第 12 節補充：預設 δ = 0.05 時 RIC 的上界處處比 ε = 0.2 大，實驗中的增益不能只歸因於「限制高機率 token」；論文也沒有「固定 ε 調大」或「不 clip」的對照。

**passage**：
- 第一部分：「B 被取樣到後比值一超過 1.2 梯度就變成 0」
- 第二部分：「這個增益不能歸因於「範圍隨機率改變的形狀」」；「預設 δ = 0.05 時 RIC 的上界處處比 ε = 0.2 大」

**confidence**：high（機制與數字直接出自頁面；「不能歸因於形狀」是頁面明確結論）

**頁面的 W3 是本頁自設的示意模型，不是論文的實驗或結果。**

**初學者可能卡住的地方**

1. RIC 上界公式：中文敘述寫「1+0.05/0.01=1+5≈3.24」，但 LaTeX 公式是 1+√(0.05/0.01)=1+√5≈3.24。照中文算會得到 6，應以根號版本為準。
2. 「不 clip」與「ε_high 調到 1.0」：頁面未解釋「不 clip」等同於不限制比值；「ε_high = 1.0」即上界 1+1.0 = 2.0，頁面沒有直接說明。
3. 「找到 B」的定義：頁面在任務描述中定義為第 200 次迭代時 B 的機率超過 0.5，但沒有在 W3 結果段落重申，讀者可能以為是取樣到 B 即算找到。
4. 玩具模型與論文的關係：頁面說明 Fig. 1(b) 的「熵穩定在中等範圍」無法在此重現，初學者容易把 W3 的數字當成論文結果。
5. trust region：頁面只在結論句中使用「trust region」一詞，且只在研究脈絡卡片中簡短提及（TRPO 以 KL 約束定義 trust region），沒有解釋它為何是必要的，讀者難以理解「不能說明為什麼需要 trust region」的意義。
