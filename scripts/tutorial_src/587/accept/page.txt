 RIPO：讓 PPO 的比值範圍隨舊機率改變

 PPO-Clip 對每個 token 用相同的比值範圍。以 KL 散度的近似衡量，這使低機率 token 能變動的距離上限較小、高機率 token 較大。RIPO 讓範圍隨舊機率改變。

 01 · PPO-Clip

 PPO-Clip 限制重要性比值

 用強化學習（reinforcement learning，RL）訓練大型語言模型時，模型逐字產生回答。每一步的「狀態」s $s$ 是題目加上已產生的前綴，「動作」a $a$ 是下一個 token。策略 πθ(a∣s) $\pi_\theta(a|s)$ ​(a∣s) 是模型給下一個 token 的機率，θ $\theta$ 是模型參數。

 一次訓練迭代先用目前的模型產生一批回答，產生回答的這份模型稱為行為策略（behavior policy）πθold $\pi_{\theta_{old}}$ ​​，簡寫 πold $\pi_{old}$ ​。之後用同一批回答把參數更新好幾次，更新中的模型記為 πθ $\pi_\theta$ ​。兩者對同一個 token 的機率之比稱為重要性比值（importance ratio）：

 rs,a(θ)=πθ(a∣s)πθold(a∣s) $r_{s,a}(\theta)=\frac{\pi_\theta(a|s)}{\pi_{\theta_{old}}(a|s)}$ ​(θ)=πθold​​(a∣s)πθ​(a∣s)​
Sec. 2.2

 每個 token 另有一個優勢（advantage）估計 A^ $\hat A$ ：A^>0 $\hat A>0$ >0 表示這個回答比平均好，訓練會推高該 token 的機率；A^<0 $\hat A\lt 0$ <0 則壓低它。PPO（Proximal Policy Optimization）的目標是

 JPPO(θ)=E[min⁡(r(θ)A^, clip(r(θ),1−ϵ,1+ϵ)A^)] $J_{PPO}(\theta)=\mathbb E\big[\min\big(r(\theta)\hat A,\ \mathrm{clip}(r(\theta),1-\epsilon,1+\epsilon)\hat A\big)\big]$ ​(θ)=E[min(r(θ)A^, clip(r(θ),1−ϵ,1+ϵ)A^)]
Sec. 2.2

 clip 把 r $r$ 限制在 (1−ϵ,1+ϵ) $(1-\epsilon,1+\epsilon)$ ，等價於 ∣r−1∣<ϵ $|r-1|\lt\epsilon$ ；常用 ϵ=0.2 $\epsilon=0.2$ 。它的實際作用是：A^>0 $\hat A>0$ >0 且 r>1+ϵ $r>1+\epsilon$ 時，min 取到常數 (1+ϵ)A^ $(1+\epsilon)\hat A$ ，這個 token 的梯度為 0，不再被推高；A^<0 $\hat A\lt0$ <0 且 r<1−ϵ $r\lt1-\epsilon$ 時同樣梯度為 0，不再被壓低。clip 不是把 πθ $\pi_\theta$ ​ 硬性截斷：參數由所有 token 共享，多次更新仍可能讓比值超出範圍，但超出後該 token 不再提供推動它的梯度。

 這個限制的目的，是讓每次更新後的新策略不要離舊策略太遠。「每次更新允許新舊策略相差的最大距離」稱為 trust region。本論文要問的是：用「比值偏離 1 多少」來代表這個距離，是否恰當。

 02 · 探索崩潰

 同一個比值範圍對低機率 token 的增量很小

 論文以 ϵ=0.2 $\epsilon=0.2$ 舉例（Sec. 3.1）。對 A^>0 $\hat A>0$ >0 的 token，原本機率 πold=0.8 $\pi_{old}=0.8$ ​=0.8 的動作，論文所說的「maximum possible updated probability」為 0.96，增加 0.16；原本機率 0.01 的動作只到 0.012，增加 0.002。精確地說，這是「繼續推高這個 token 的梯度停止之處」：比值超過 1.2 後，這個 token 不再被推高。所以一個稀有但有價值的 token 即使被取樣到一次，在這次迭代中也只能升一點。

 DAPO（Yu et al., 2025）把上下界分開，範圍改成 (1−ϵlow,1+ϵhigh) $(1-\epsilon_{low},1+\epsilon_{high})$ ​,1+ϵhigh​)，並把 ϵhigh $\epsilon_{high}$ ​ 由 0.2 提高到 0.28（稱為 Clip-Higher）。結果 0.01 的上限變成 0.0128，只多 0.0008；0.8 的上限則由 0.96 變成 1（0.8×1.28=1.024 $0.8\times1.28=1.024$ ，被機率上限 1 截斷）。作者認為這反而加劇行為多樣性的下降。

 探索崩潰（exploration collapse）指策略在訓練中迅速集中到少數高機率的動作，稀有但重要的動作不再被取樣、也不再被探索，回答變得幾乎一樣。作者的結論是：PPO 式的 clip 不分一個動作是否已被大量利用，一律以相同比值截斷。下一節說明作者如何把這歸因於距離的量法。

 KL 散度的二次近似以舊機率加權

 PPO-Clip 隱含歐氏距離

 PPO-Clip 約束 ∣r−1∣<ϵ $|r-1|\lt\epsilon$ ，等於用下式衡量新舊策略的差異：

 05 · RIC

 RIC 讓每個 token 的距離上限相同

 10 · Score Centering

 RIPO 與 Score Centering 處理不同的問題

 同批的 Score Centering（Marek 與 Ryabinin，arXiv 2609.20807）也處理 off-policy LLM RL 中的比值，但問題不同。RIPO 假設 πold $\pi_{old}$ ​ 就是實際取樣的策略，修改的是 clip 上下界的形狀；Score Centering 處理推論引擎（sampler q $q$ ）與訓練引擎（trainer p $p$ ）機率不一致的情形，從每個 score 減去 sampler 下的期望 score，是一個加法修正。下表中 Score Centering 的描述出自該論文 §4。兩篇論文都沒有組合實驗。
