08 · 查表與 MoE

查表記憶與 MoE 以不同方式稀疏存取

kNN-LM 在預訓練模型旁加上一個 context–target 配對的持久資料庫；這個資料庫不屬於標準的前向計算圖，跨推論呼叫存在，並以獨立的最近鄰機制查詢，因此比 KV 快取更明確地屬於顯式記憶（§IV-B a）。Memorizing Transformers 與 LongMem 雖有顯式的索引與檢索，但存的主要仍是模型計算的中間狀態，被視為顯式資料庫記憶與隱式活化記憶之間的邊界類別，不列入 Table I（§IV-B b）。

Engram 是可擴展的條件記憶：資訊存在稀疏啟用的槽中，以結構化雜湊檢索；它不以完整注意力重算歷史，而是依當前隱藏狀態做選擇性查表；記憶槽是推論結束後不會自動丟棄的持久元件（§IV-B c）。

09 · 時間尺度與風險

多時間尺度更新與顯式記憶的六項風險

記憶參數在結構上與骨幹分開，更新排程不必與訓練步或推論步一致，因此不同的參數子集可以用不同的頻率演化（§IV-D）。Titans 與 TTT-E2E 是短時間尺度的例子：持久參數在一次推論中逐 token 演化（a）。Nested Learning 以階層化的更新頻率形成由快到慢的連續譜（b）；慢–快參數分解則回到 fast/slow weights（c）。這裡有一個穩定性–可塑性的權衡（d）：更新頻繁增加適應力，但容易過擬合暫態訊號；更新慢保持穩定，但反應遲鈍。作者的結論是：時間控制對顯式記憶與結構持久性同樣核心。

§IV-E 列出顯式記憶的六項風險：

§IV-E a

容量成長與擴展

查表系統可隨新條目無界成長，需要索引、修剪與壓縮。

§IV-E b

干擾與記憶漂移

測試時的快速調適可能破壞已學表示；查表中過時或冗餘的條目會讓檢索產生偏差。

§IV-E c

最佳化與收斂

驚奇度學習規則或輔助損失，未必有預訓練那樣的最佳化保證。

§IV-E d

跨回合一致性

何時重置記憶、如何分離長短期儲存，問題類似持續學習。

§IV-E e

架構複雜度與可解釋性

額外的記憶模組讓系統更難分析與除錯。

§IV-E f

參數穩定的幾何限制

Lie 群上的正交低秩調適與 Muon-OGD 降低跨任務干擾；作者認為更新規則的幾何可能與儲存形式同樣重要。

10 · 混合與評測

混合架構、記憶管理與評測

混合架構（§V-A）把不同的記憶基底組合起來。Samba 交錯 Mamba 式的選擇性 SSM 層與滑動視窗注意力（a）；LightTransfer 把預訓練 Transformer 中的「lazy」層換成串流元件；Priming 把混合化當作從預訓練 Transformer 到混合 SSM 的知識轉移。OLMo Hybrid、Kimi Linear、Hymba、Falcon-H1 等固定串列或混合頭的模型，以靜態選擇分配高保真的注意力路徑；[80] 指出全注意力層放在哪裡，是召回–效率權衡的核心決定因素。

AMOR 與 HAM 則以訊號決定何時使用昂貴的記憶（§V-A b）。AMOR 在遞迴骨幹上附加事後的注意力精修塊，閘控的是是否執行注意力精修，依據是正規化輸出熵：只對熵高的位置啟用。HAM 讓遞迴記憶處理每個 token，閘控的是token 是否准入 KV 快取：稀疏的 KV 快取只存遞迴狀態難以預測的 token，快取成長由門檻或學習的路由器控制。作者的歸納是，固定混合是排程或結構式的分配，AMOR 與 HAM 則依不確定性或預測誤差更新可存取的記憶集合。

12 · 開放問題

開放問題與延伸閱讀

§VI 列出六個方向。

  1. 統一的記憶理論：在狀態轉移的觀點下，以保留保真度、干擾穩健性與資訊壓縮效率刻畫容量，並形式化穩定性–可塑性。
  2. 持續與終身的參數記憶：讓參數化記憶跨任務、跨會話累積而不破壞已學知識。
  3. 穩健且可解釋的更新規則：逐一對應 Table II 的五種規則風險，例如驚奇度、熵或預測誤差能否忠實反映未來的相關性，准入與淘汰的不可逆問題；目標是可診斷、必要時可逆。
  4. 自適應的記憶分配與控制：由靜態組合走向學習的控制器。
  5. 硬體–演算法協同設計：記憶的存取模式要配合硬體。
  6. 有原則的多維度評測：儲存容量、檢索保真度、時間持續性、抗干擾與計算效率，以及控制干擾注入、記憶衰減量測、更新一致性分析等壓力測試。

§VII 的結論是沒有單一的記憶範式能滿足所有需求：token 層級的注意力以可擴展性換取高保真召回；遞迴序列記憶提供壓縮的長視野，但有干擾；顯式記憶增強時間持續性，但帶來更新穩定與定址的複雜度。因此 LLM 的設計正轉向自適應協調這些互補基底的混合架構。
