05 · 遞迴狀態

遞迴序列記憶把歷史壓進固定大小的狀態

先備知識：向量、內積、外積、正交

向量是一列數字，例如 $k=(1,0)$。兩個向量的內積 $k^\top q$ 是對應元素相乘再相加；內積為 0 時稱兩者正交，例如 $(1,0)$ 與 $(0,1)$。範數 $\|x\|=\sqrt{x^\top x}$ 是向量的長度，$\|k\|=1$ 稱為單位向量。

外積 $vk^\top$ 是一個矩陣：第 $i$ 列第 $j$ 欄的元素是 $v_ik_j$。例：$v=(0.6,0.8)$、$k=(1,0)$ 時，$vk^\top=\begin{pmatrix}0.6&0\\0.8&0\end{pmatrix}$。矩陣乘上向量 $(vk^\top)q=v\,(k^\top q)$，也就是「$v$ 乘上 $k$ 與 $q$ 的內積」。

先看一個 2 維的例子

令狀態 $S$ 是一個 $2\times2$ 矩陣，起始為 0。寫入一對 key–value 的方法是把外積 $vk^\top$ 加進 $S$；以 key $k$ 讀取的方法是計算 $Sk$。

第一次寫入 $k_1=(1,0)$、$v_1=(0.6,0.8)$：$S=v_1k_1^\top=\begin{pmatrix}0.6&0\\0.8&0\end{pmatrix}$，讀出 $Sk_1=(0.6,0.8)=v_1$。第二次寫入與 $k_1$ 正交的 $k_2=(0,1)$、$v_2=(1,0)$：$S=\begin{pmatrix}0.6&1\\0.8&0\end{pmatrix}$，讀 $Sk_1$ 仍是 $v_1$，因為 $k_2^\top k_1=0$。第三次寫入與 $k_1$ 不正交的 $k_3=(0.707,0.707)$：讀 $Sk_1$ 會多出 $0.707\,v_3$。這個多出來的部分稱為串擾：讀某個 key 時混進其他 key 的值。2 維空間最多只能放 2 個互相正交的 key。

遞迴序列記憶做的就是這件事：把歷史壓縮進一個與前向計算耦合、大小固定的潛狀態（§III-C）。經典的 RNN 與 LSTM、線性注意力遞迴與狀態空間模型（SSM）都屬此類。

從線性注意力到 delta rule

線性注意力把注意力核化並利用矩陣乘法的結合律，把因果注意力寫成以線性時間更新的遞迴狀態；GLA 對矩陣值狀態加入資料相依的衰減；Mamba 與 Mamba-2 引入選擇性更新與 SSD 形式；Gated Delta Networks（GDN）以輸入條件的 delta rule 做內容感知的保留（§III-C b）。Fig. 3 把兩類遞迴寫成：

$$S_t=\alpha_tS_{t-1}-\beta_tS_{t-1}k_tk_t^\top+\gamma_tv_tk_t^\top,\qquad \text{Memory Size}=d_v\times d_k$$
Fig. 3，線性注意力
$$h_t=A_th_{t-1}+B_tx_t,\qquad \text{Memory Size}=d\times N$$
Fig. 3，SSM

SSM 的式子中，$h_t$ 是狀態，$A_t$ 是狀態轉移，$B_t$ 把輸入寫進狀態，$C_t$ 負責讀出；本頁的元件只使用第一條式子，不展開 SSM。圖中 $q_t$ 以虛線連到記憶方塊，表示讀取。本頁推導讀出寫成 $o_t=S_tq_t$，以某個 key 查詢時為 $S_tk_i$；論文圖中沒有寫出讀出式。

Fig. 3 的線性注意力狀態更新式是 $S_t=\alpha_tS_{t-1}-\beta_tS_{t-1}k_tk_t^\top+\gamma_tv_tk_t^\top$，狀態大小為 $d_v\times d_k$。本頁推導三項各有作用：$\alpha_tS_{t-1}$ 讓整個狀態以比例 $\alpha_t$ 保留，$\alpha_t<1$ 即衰減（遺忘）；$-\beta_tS_{t-1}k_tk_t^\top$ 擦除狀態在 $k_t$ 方向上原本存的值；$+\gamma_tv_tk_t^\top$ 把新值 $v_t$ 綁到 $k_t$ 上寫入。係數與文獻的對應為：線性注意力取 $\alpha=1,\beta=0,\gamma=1$，即純加法寫入；delta rule 取 $\alpha=1,\beta=\gamma$。這些對應是本頁依 §III-C 的描述與原論文的標準形式整理，論文沒有逐一寫出。

衰減式（GLA 類）對應 $\beta=0$、$\alpha<1$，這是兩層簡化：原方法的衰減是資料相依的，而且 GLA 的衰減是逐通道（對角矩陣），本頁用一個常數純量 $\alpha$ 代替。Mamba 本身對應 Fig. 3 的第二條式子，本頁不把它寫成第一條式子的某組係數。Gated delta（GDN）的原式是 $S_t=\alpha_t(S_{t-1}-b_tS_{t-1}k_tk_t^\top)+b_tv_tk_t^\top$，展開後對應 $\alpha=\alpha_t$、$\beta=\alpha_tb_t$、$\gamma=b_t$。

覆寫與串擾

本頁推導同一個單位 key 寫入兩次時，兩種規則讀出的結果不同。若 $\|k_t\|=1$ 且 $\alpha=\beta=\gamma=1$，寫入後 $S_tk_t=S_{t-1}k_t-S_{t-1}k_t(k_t^\top k_t)+v_t(k_t^\top k_t)=v_t$：delta rule 讀出新值，舊值被完全取代，這稱為覆寫（新值取代同一個 key 的舊值）。純加法寫入則讀出 $S_{t-1}k_t+v_t$，也就是舊值＋新值。一般而言，$T$ 筆加法寫入後以 $k_i$ 讀取，得到 $S_Tk_i=v_i(k_i^\top k_i)+\sum_{j\ne i}v_j(k_j^\top k_i)$。只有所有鍵互相正交時，交叉項 $\sum_{j\ne i}v_j(k_j^\top k_i)$ 才為 0，而 $d_k$ 維空間中最多只有 $d_k$ 個互相正交的鍵；隨機單位鍵在 $T>1$ 時就會互相干擾。

本頁推導隨機單位鍵時，每個交叉項的 $(k_j^\top k_i)^2$ 期望為 $1/d_k$。下方元件把串擾定義為 $e_i=\|r_i-c_iv_i\|$，扣掉了落在 $v_i$ 方向的分量，粗估其均方根約為 $\sqrt{(T-1)(d-1)}/d$。以 20 個 seed 平均：$d=8,T=16$ 為 1.264（粗估 1.281）；$d=32,T=16$ 為 0.672（粗估 0.674）。即使 $T<d$（$d=32,T=16$），平均串擾仍有 0.674。這是 Table II「壓縮損失與狀態干擾」與 §III-D a「記憶跨度與表示保真度的權衡」的最小例子。

其他變體（§III-C c–h）

  • Gated DeltaNet-2 分離 key 側的擦除與 value 側的寫入。
  • Kaczmarz Linear Attention 把寫入視為 key 正規化的投影步。
  • Kalman Linear Attention 與 Gated KalmaNet 以濾波或線上回歸，依估計品質調節更新。
  • RWKV-7 以向量值的狀態閘與上下文內學習率推廣 delta rule。
  • KDA（Kimi Linear 的遞迴核心）引入逐通道的對角衰減。
  • DeltaProduct 組合多個 Householder 更新；Comba 用純量加低秩轉移與閉迴路回饋。
  • Mamba-3 改進離散化並加入複數值更新與 MIMO 形式，狀態大小仍固定。
  • Log-Linear Attention 以 Fenwick tree 階層取代單一固定狀態，狀態數隨長度對數成長，介於常數狀態與逐 token KV 之間。
  • RetNet、Jamba、MoM 為遞迴–注意力混合或多狀態路由。
  • Next-Latent Prediction 以預測未來潛狀態的目標塑造隱藏表示，是離線、目標誘導的機制，不是新的測試時寫入規則。

作者的歸納是：多數遞迴序列記憶屬於狀態轉移更新，差別在每個 token 如何改變並分配壓縮的狀態（§III-C h）。

可以觀察四件事。第一，正交鍵且 $T\le d$ 時，線性注意力與 delta rule 的每一筆都是 $c_i=1,e_i=0$；衰減時 $c_i=\alpha^{T-i}$，$d=T=8,\alpha=0.9$ 的第 1 筆為 0.478。第二，隨機鍵時即使 $T<d$ 也有串擾；預設 $d=8,T=16$ 的線性注意力平均 $e$ 為 1.054。delta rule 的最後一筆恆為 $c_T=1,e_T=0$：本頁推導$\|k_T\|=1$ 時 $S_Tk_T=(\alpha-\beta)S_{T-1}k_T+\gamma v_T$，所以只要 $\alpha=\beta$ 且 $\gamma=1$ 就讀回 $v_T$，Delta rule (1, 1, 1) 與 Gated delta (0.9, 0.9, 1) 都滿足。第三，正交鍵、$d=8$、$T=9$ 時，第 9 步重用第 1 筆的 key，加法讀出 $v_1+v_9$，delta rule 讀出 $v_9$。第四，$d$ 加大時，同樣的 $T$ 下串擾變小：狀態大小 $d_v\times d_k$ 就是容量。

檢查理解

寫出線性注意力的狀態更新式與狀態大小；線性注意力與 delta rule 各對應哪組係數？

$S_t=\alpha_tS_{t-1}-\beta_tS_{t-1}k_tk_t^\top+\gamma_tv_tk_t^\top$，大小 $d_v\times d_k$；線性注意力 $\alpha=1,\beta=0,\gamma=1$；delta rule $\alpha=1,\beta=\gamma$（Fig. 3；係數對應為本頁推導）。

同一個單位 key 寫入兩次時，加法與 delta rule（$\alpha=1,\beta=\gamma=1$）各讀出什麼？什麼條件下加法寫入才完全沒有串擾？

加法讀出舊值＋新值，delta rule 讀出新值（$\|k\|=1$ 且 $\alpha=1,\beta=\gamma=1$ 時 $S_tk_t=v_t$）；只有所有鍵互相正交時交叉項 $\sum_{j\ne i}v_j(k_j^\top k_i)$ 才為 0，而 $d_k$ 維中最多 $d_k$ 個互相正交的鍵；隨機鍵在 $T>1$ 時就會互相干擾（本頁推導）。

06 · 隱式的限制

隱式記憶受容量、讀寫語意與持續性限制

§III-D 列出隱式記憶的三個限制。第一，容量有界且難以控制（a）：注意力模型的容量隨上下文視窗與 KV 快取大小而定，受平方或線性時間複雜度與硬體限制，長上下文模型常無法有效利用名目長度；狀態式模型原則上可處理無界序列，但壓縮進固定大小的狀態，產生記憶跨度與表示保真度的權衡。第二，缺乏可調適的讀寫語意（b）：資訊只依計算圖（注意力權重或狀態轉移）儲存與取回。第三，跨脈絡持續性有限（c）：內容常綁在少數前向傳遞或一次推論會話上，計算結束即丟棄；快取狀態快照或多狀態混合主要改善同一延伸序列內的保留，而非跨會話的持久。

作者認為這三點「劃定了僅靠計算耦合記憶能達到的邊界」，並由此引出把儲存與內部計算分開的顯式記憶（§III-D d）。下方的 C3 只示範第一點：比較各種機制每層需要保存的數值個數如何隨序列長度 $L$ 成長。

拖動序列長度 L。完整 KV 隨 L 線性成長，滑動視窗封頂，遞迴狀態固定；讀數表是主要的資訊來源。

滑動視窗 W
機制目前大小（浮點數）相對完整 KV可精確存取的過去 token

本頁示例設定（論文沒有數字）：頭數 nₕ = 8、每頭維度 dₕ = 128（dₖ = dᵥ = dₕ）、MLA 潛向量維度 d_c = 512（不含位置編碼分量）、SSM 狀態維度 N = 16、模型寬 d = nₕdₕ = 1024、StreamingLLM 的 sink 數 s = 4。只算每層要保存的浮點數個數，不算位元組與參數。公式：完整 KV 2Lnₕdₕ；視窗＋sink 2·min(L, W+s)·nₕdₕ；MLA L·d_c；線性狀態 nₕdₖdᵥ；SSM d·N；Log-Linear nₕdₖdᵥ·(⌊log₂L⌋+1)（本頁推導：以 Fenwick tree 前綴分解的層數上界估計狀態個數）；HAM nₕdₖdᵥ + 2⌈ρL⌉nₕdₕ（本頁推導：依 §V-A b 的最簡模型）。

$L=32768$ 時，完整 KV 為 67,108,864 個數，是線性狀態 131,072 的 512 倍；$L$ 超過 $W+s$ 之後，滑動視窗封頂於 8,396,800。遞迴狀態與 SSM 不隨 $L$ 改變，但讀數表的「可精確存取」欄隨之變成「靠壓縮」。這把曲線連回 §II-C：KV 快取的有效視野等於它能存下的 token 數，儲存隨 token 數成長；遞迴狀態大小固定，有效視野靠壓縮維持，代價是 C2 的串擾。HAM 的斜率與完整 KV 相同，但乘上准入比例 $\rho$。SSM 比線性狀態小 8 倍，完全來自本頁選的 $N=16$ 對 $d_h=128$，不是 SSM 的固有優勢。

檢查理解

§III-D 的三個限制是什麼？

容量有界且難以控制；缺乏可調適的讀寫語意；跨脈絡持續性有限（§III-D a–c）。

為什麼儲存隨 token 數成長的 KV 快取被歸為短期，而大小固定的遞迴狀態反而可能被歸為長期？

持續性取決於儲存粒度與壓縮率：KV 快取高保真低壓縮，儲存隨 token 數成長，因而受視窗與快取預算限制；遞迴狀態大小固定，可以靠壓縮維持較長的有效視野（§II-C 用「may」，不是保證）。
