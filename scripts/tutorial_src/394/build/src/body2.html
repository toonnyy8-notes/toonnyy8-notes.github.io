06 · 玩具問題

玩具問題：校正步讓更多步數繼續降低錯誤率

W3 用一個人為設定的小問題顯示校正步的作用。資料只有一個長度 32 的序列（8 種真實 token）；去噪器對每個位置輸出「正確 token 機率 $1-\varepsilon$，其餘 7 個 token 平分 $\varepsilon$」，錯誤率 $\varepsilon=\varepsilon_{\max}-(\varepsilon_{\max}-0.02)\,c$ 隨目前與目標相同的位置比例 $c$ 線性下降（[MASK] 位置算作不相同）；schedule 取 $\alpha_t=1-t$ 推定。這些都是本頁的假設，不是論文的模型。

在本頁 toy 的預設設定下（$\varepsilon_{\max}=0.5$），toy 假設去噪器錯誤率隨正確位置比例下降。MDM 的 ancestral sampler 增加步數幾乎沒有改善：早期以高錯誤率解開的 token 不再更新，錯誤率停在約 0.33–0.38。Ψ-sampler 的校正步以機率 $(1-\kappa_t)(1-\alpha_s)$ 把 token 變回 [MASK]，之後由錯誤率較低的去噪器重新預測；步數越多，校正次數越多，window schedule（$\kappa=0.9$、$t\in[0.1,0.6]$）的錯誤率由 8 步的 0.367 降到 512 步的 0.195。步數少時兩者相同，因為校正次數太少。這是 toy 假設下的結果，toy 的 $T$ 不對應論文的 NFE：真實的 MDLM 在步數低於序列長度時仍會改善（Table 13，$p=0.9$ 時 70.34 到 37.91），toy 從 $T=8$ 就持平，是 $\varepsilon_{\max}$ 選擇的結果；把 $\varepsilon_{\max}$ 調低，ancestral 的錯誤率也跟著下降。

07 · 語言實驗

語言實驗：p = 0.9 與 rescale 下 Gen. PPL 在 1024 步後仍下降

指標：Gen. PPL（generative perplexity）是以 GPT-2 Large 計算生成文字的 perplexity，越低代表越像自然文字；但重複的文字也會壓低 Gen. PPL，所以同時報告 unigram entropy，即單一樣本內 token 頻率分佈的熵，作為多樣性的代理（越低越重複）。nucleus sampling 的參數 $p$ 表示每一步只從累積機率達到 $p$ 的最高機率 token 中抽樣；$p=1$ 表示不截斷。

設定（§5.1.1、Suppl. C.1.1）：使用既有的 MDLM（MDM）與 Duo（USDM）checkpoint，資料 OpenWebText，序列長度 $L=1024$，訓練 1M 步、batch 512；取樣時 logits 轉成 64-bit。論文作圖時選擇 unigram entropy 與 ancestral 最接近的 κ schedule（Suppl. D.1.2）。下表摘自 Table 13（log-linear 步長、未蒸餾模型；括號內為 unigram entropy）。

檢查理解

OWT、nucleus $p=0.9$、log-linear、4096 步的 Duo：ancestral 與 rescale η = 0.05 的 Gen. PPL（熵）？持續下降需要什麼條件？

34.75 (5.35) → 19.21 (5.17)；需要 $p=0.9$ 與 rescale；$p=1.0$ 時 Duo rescale η = 0.02 只到 63.70，MDLM cap η = 0.005 由 110.75 變差到 131.85；32 步無增益。

08 · 影像實驗

影像實驗：CIFAR-10 FID 改善依賴 κ 與時間窗

設定（§5.1.2、Suppl. C.1.2）：35M 參數的 U-Net（Table 3 寫 35.8M），CIFAR-10 每個像素值當作 256 類的 token，訓練 1.5M 步、batch 128。訓練時以 10% 機率丟掉類別標籤（class dropout 0.1），供 classifier-free guidance（CFG）使用；Table 6、11 的 CFG 強度為 1，依式 (10) 這等於純條件取樣 本頁推導。Table 6 的 ancestral 結果最後一步取 greedy（機率最大的值）。FID（Fréchet Inception Distance）以 50k 個樣本對訓練集計算，越低越好；IS（Inception Score）越高越好。cosine 與 log-linear 是兩種 noise schedule 的形式，論文沒有給公式。CIFAR 的 Ψ 實驗不用 nucleus。

結果（Suppl. D.1.1）：ReMDM 把 MDLM 由 24.73 降到 23.71（4096 步）；Ψ-sampler 在 log-linear 取樣下把 23.71 降到 20.71。CIFAR-10 Duo 的 FID 改善：Duo（訓練 log-linear、取樣 cosine、4096 步）由 ancestral 的 25.63 降到 15.05；MDLM 降到 17.86，但論文寫的起點 24.73 是 log-linear 取樣的 ancestral，同條件（cosine 取樣）的 ancestral 基準是 23.93（Table 7），所以同條件的 MDLM 基準為 23.93 而非 24.73。兩個限制。第一，Fig. 1 右是逐步數挑最佳超參數的包絡（Table 9 caption）：4096 步的 15.05 來自 $t_{\text{on}}=0.5$，同樣 $\kappa=0.95$ 但 $t_{\text{on}}=0.6$ 時 1024 步是 16.70、4096 步是 18.99。第二，選錯 κ 比 ancestral 差：$\kappa=0.5$、$[0.4,0.6]$ 由 256 步的 20.77 惡化到 4096 步的 105.75；Suppl. D.1 原文是「With a poor choice of κt, Ψ-samplers can underperform ancestral sampling」。此外，Duo ancestral 加 $p=0.9$ 已有 22.41（Table 7），而 Ψ 的比較不用 nucleus。最佳 IS（9.50）與最佳 FID 來自不同設定（Table 10）。

作者的推薦（§5.1.2）：Duo++ 用 cosine schedule、$\kappa_t=0.95$、$t_{\text{on}}\in\{0.5,0.6\}$、$t_{\text{off}}=0.1$；MDLM 用 $\kappa_t=0.99$、$t_{\text{on}}=1.0$、$t_{\text{off}}=0.1$；$\kappa_t$ 只在 $[t_{\text{off}},t_{\text{on}}]$ 內小於 1，其餘步驟為 1。

檢查理解

CIFAR-10 Duo 的 FID 改善？兩個限制？

Duo（訓練 log-lin、取樣 cosine、4096 步）25.63 → 15.05；Fig. 1 右是逐步數挑最佳超參數的包絡；選錯 $\kappa$ 比 ancestral 差（$\kappa=0.5$、$[0.4,0.6]$ 在 4096 步 105.75）；同條件 MDLM 基準為 23.93 而非 24.73。
