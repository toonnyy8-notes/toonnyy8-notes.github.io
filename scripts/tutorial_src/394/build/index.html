    Ψ-Samplers：讓離散擴散在取樣時重新抽樣已產生的 token

    這篇論文提出一種取樣方法：每一步以可調的小機率重新抽樣已產生的 token，不需重新訓練模型。

    Justin Deschenaux、Caglar Gulcehre、Subham Sekhar Sahoo（2026）〈The Diffusion Duality, Chapter II: Ψ-Samplers〉

    01 · 一次寫定的 token

    離散擴散模型把一段文字的每個 token 逐步換成雜訊，再由神經網路一步步還原。若雜訊是一個特殊的「遮罩」符號，模型還原出某個 token 後就不再改動它。

    02 · 重新抽樣

    本文的取樣方法在每一步，以一個可調的小機率重新抽樣已經還原的 token，讓後續步驟有機會改正錯誤；這個方法不需要重新訓練模型。

    03 · 影像結果

    在 CIFAR-10 影像生成上，以 FID（一種越低越好的影像品質分數）衡量，作者把 token 換成隨機 token 的模型 Duo 由 25.63 降到 15.05；每個步數各自挑選最佳設定。

    示意（不是實驗結果）：實心＝正確 token，斜線＝錯誤 token，虛線空格＝遮罩。

    01 · 離散擴散

    離散擴散把 token 換成 [MASK] 或隨機 token

    文字由 token 組成，詞彙表有 $K$ 個類別。一個 token 寫成 one-hot 向量 $x\in\{0,1\}^K$：只有該類別那一格是 1。所有長度 $K$、非負、總和為 1 的向量構成 simplex；simplex 上的向量 $v$ 決定一個類別分佈 $\mathrm{Cat}(\cdot;v)$，抽到第 $i$ 類的機率是 $v_i$。本頁還會用到兩個運算：$a\odot b$ 是逐元素乘積，$\langle a,b\rangle$ 是內積。一段文字有 $L$ 個位置，位置索引寫成 $\ell$；每個位置獨立處理，所以下文多半只寫一個位置。

    離散擴散的前向過程把乾淨 token $x$ 逐步換成雜訊。時間 $t$ 從 0（乾淨）走到 1（純雜訊），時刻 $t$ 的狀態 $z_t$ 也是 one-hot。論文採用的前向邊際是 $z_t\sim q_t(\cdot|x)=\mathrm{Cat}(\cdot;\alpha_t x+(1-\alpha_t)\pi)$（式 1），其中 noise schedule $\alpha_t$ 在 $[0,1]$ 內隨 $t$ 遞減、$\alpha_1=0$，$\pi$ 是先驗分佈。字面意義是：以機率 $\alpha_t$ 保留原 token，否則從 $\pi$ 抽一個。兩種常用先驗：masked diffusion（MDM）用 $\pi=m$，$m$ 是特殊 [MASK] 符號的 one-hot，[MASK] 也算詞彙中的一類；uniform-state diffusion（USDM）用 $\pi=\mathbf 1/K$，即換成均勻隨機的 token。本頁把較早時刻 $s\lt t$ 的邊際寫成 $q_s(\cdot|x)$。

    式 (1) 只規定每個時刻各自的分佈（邊際），沒有規定不同時刻之間如何相關（聯合分佈）。論文 §3 的出發點是：同一組邊際可以對應許多種聯合分佈。後面的 Ψ-posterior 就是在這個自由度裡選了一種。

    $$z_t\sim q_t(\cdot|x)=\mathrm{Cat}\big(\cdot;\ \alpha_t x+(1-\alpha_t)\pi\big),\qquad \pi=m\ (\text{MDM}),\quad \pi=\mathbf 1/K\ (\text{USDM})$$

    02 · Ancestral sampler

    Ancestral sampler 依 posterior 逐步還原

    生成時要從 $z_1\sim\pi$ 往回走到 $z_0$。把 $[0,1]$ 切成 $T$ 步，$t(i)=i/T$，每一步從時刻 $t$ 走到較早的 $s=t-1/T$。如果知道乾淨 token $x$，這一步該用的分佈是反向 posterior $q_{s|t}(\cdot|z_t,x)$：已知 $z_t$ 與 $x$ 時 $z_s$ 的分佈。它由 Bayes 公式得到。本頁把兩種先驗寫成同一個式子 本頁推導：

    $$q_{s|t}(\cdot|z_t,x)\ \propto\ \big(\alpha_{t|s}\,z_t+(1-\alpha_{t|s})\langle\pi,z_t\rangle\mathbf 1\big)\odot\big(\alpha_s x+(1-\alpha_s)\pi\big),\qquad \alpha_{t|s}=\alpha_t/\alpha_s$$
    由式 (2)(3)

    第一個括號是「從每一個可能的 $z_s$ 走到觀察到的 $z_t$ 的機率」，第二個括號是 $q_s(\cdot|x)$；兩者逐元素相乘再正規化。依據：本頁以 $K=3,4,6$ 數值比對，這個式子與論文的式 (2)、(3) 相差小於 $10^{-12}$；$\alpha_{t|s}=\alpha_t/\alpha_s$ 論文沒有定義，依 Duo 的慣例。

    MDM 的情形（式 2）：$z_t=m$ 時，$z_s$ 以機率 $\frac{\alpha_s-\alpha_t}{1-\alpha_t}$ 解開成 $x$，否則留在 [MASK]；$z_t\ne m$ 時 $z_s$ 的分佈是 $\mathrm{Cat}(x)$，也就是已解開的 token 不再更新。USDM 的情形（式 3，原式在下方）允許 token 改成任何值，因此可以修正先前的錯誤，這是 USDM 在少步生成表現好的原因之一（§2.1.2）。

    ancestral sampler 如何由 posterior 得到：生成時沒有 $x$，於是訓練一個去噪器 $x_\theta(z_t,t)$，輸出 simplex 上的機率向量，代表對乾淨 token 的猜測；把 $q_{s|t}$ 裡的 $x$ 換成 $x_\theta(z_t,t)$ 就得到 ancestral sampler $p^\theta_{s|t}=\prod_\ell q_{s|t}(\cdot|z_t^\ell,x^\ell=x_\theta^\ell(z_t,t))$（§2.1.1）。每一步呼叫一次去噪器，所以去噪器呼叫次數 NFE 等於步數。在 MDM 下，式 (2) 中 $z_t\ne m$ 時為 $\mathrm{Cat}(x)$，已解開的 token 不再更新：一旦解錯就無法回頭；USDM 的式 (3) 則允許 token 改成任何值。上面的式子對 $x$ 是線性的，所以 $x$ 換成機率向量 $x_\theta$ 仍是合法的 Bayes 更新。

    式 (3) 原式（USDM）
    $$q_{s|t}=\mathrm{Cat}\Big(\tfrac{K\alpha_t z_t\odot x+(\alpha_{t|s}-\alpha_t)z_t+(\alpha_s-\alpha_t)x+(1-\alpha_{t|s})(1-\alpha_s)\mathbf 1/K}{K\alpha_t\langle z_t,x\rangle+1-\alpha_t}\Big)$$
    式 (3)

    檢查理解

    ancestral sampler 如何由 posterior 得到？式 (2) 中 $z_t\ne m$ 時 $z_s$ 的分佈？

    把 $q_{s|t}$ 的 $x$ 換成 $x_\theta(z_t,t)$，每步呼叫一次去噪器（NFE＝步數）；$z_t\ne m$ 時為 $\mathrm{Cat}(x)$，已解開的 token 不再更新；USDM 的 (3) 允許改成任何值。

    03 · Ψ-posterior

    Ψ-posterior 是兩個分佈的凸組合，邊際不變

    Ψ-posterior（式 11）把反向 posterior 與前向邊際以係數 $\kappa_t\in[0,1]$ 混合：

    $$\Psi_{s|t}(\cdot|x,z_t)=\kappa_t\,q_{s|t}(\cdot|z_t,x)+(1-\kappa_t)\,q_s(\cdot|x),\qquad \Psi_1=\mathrm{Cat}(\pi)$$
    式 (11)

    式 (11) 由兩項組成：第一項 $\kappa_t q_{s|t}(\cdot|z_t,x)$ 依賴目前狀態 $z_t$，第二項 $(1-\kappa_t)q_s(\cdot|x)$ 不依賴 $z_t$。$\kappa_t=1$ 時就是標準 posterior；$\kappa_t=0$ 時每一步丟棄 $z_t$，直接從 $q_s(\cdot|x)$ 重抽。$\kappa_t$ 越小，$z_s=z_t$（token 沒有被改動）的機率越低：均勻先驗、$K=4$、$\alpha_t=0.3$、$\alpha_s=0.6$ 時，$\kappa$ 為 1、0.5、0 的保留率依序是 0.625、0.505、0.385，而 $z_s$ 的邊際始終不變（下方 W1 的「保留率」讀數）。作者稱這種組合為 superposition posterior。

    為何任何 $\kappa_t$ 都保持 $q_s$：論文以對 $t$ 向下的歸納證明（Suppl. A.2）。基底 $\Psi_1=\mathrm{Cat}(\pi)=q_1$。假設 $z_t$ 的邊際已經是 $q_t(\cdot|x)$，則 $z_s$ 的邊際是

    $$\begin{aligned}\Psi_s(z_s|x)&=\sum_{\tilde z_t}q_t(\tilde z_t|x)\big[\kappa_t q_{s|t}(z_s|x,\tilde z_t)+(1-\kappa_t)q_s(z_s|x)\big]\\&=\kappa_t\,q_s(z_s|x)+(1-\kappa_t)\,q_s(z_s|x)\sum_{\tilde z_t}q_t(\tilde z_t|x)=q_s(z_s|x)\end{aligned}$$
    式 (16)

    第一項加總後等於 $q_s$，因為 $q_{s|t}$ 是真 posterior；第二項不依賴 $\tilde z_t$，可以提到加總外，而 $\sum q_t=1$。兩項以 $q_t$ 加權後都等於 $q_s$，凸組合仍是 $q_s$。這個證明需要四個條件：(i) 用真 $x$；(ii) $q_{s|t}$ 是與式 (1) 相容的真 posterior；(iii) 第二項不依賴 $z_t$；(iv) $\kappa_t$ 不依賴 $z_t$，否則 $\kappa_t$ 不能提到加總外。下方 W1 的開關讓 $z_t=x$ 的那一列用 $\kappa=0.5$、其他列用 1，邊際與 $q_s$ 的最大差變成 0.0525 本頁推導。因此邊際保持只對用真 $x$ 的真 posterior (11) 成立；取樣時換成去噪器 $x_\theta$ 後（04 節的式 12），條件 (i) 不成立，不再保證邊際，論文也沒有給這種情形的誤差界。

    代數上 $\kappa_t$ 超出 $[0,1]$ 時等式仍成立，但 $\Psi$ 可能出現負的分量，不是合法分佈 本頁推導。由 Bayes 公式反推的前向過程 $\Psi(z_t|z_s,x)$ 一般同時依賴 $z_s$ 與 $x$，所以不是 Markov 過程（§3）。

    04 · Ψ-sampler

    Ψ-sampler 以去噪器輸出代替乾淨資料

    取樣時沒有 $x$。式 (12) 替換了兩處（作者用 "we choose to replace"，Suppl. A.1）：$q_{s|t}$ 裡的 $x$ 換成 $x_\theta(z_t,t)$；$q_s(\cdot|x)=\mathrm{Cat}(\alpha_s x+(1-\alpha_s)\pi)$ 裡的 $x$ 換成 $q_{0|t}(\cdot|z_t,x_\theta)$，即 $s=0$ 時的 posterior，代表由 $z_t$ 與 $x_\theta$ 推測的乾淨 token 分佈。MDM 時 $q_{0|t}=x_\theta$（Suppl. A.1 末句；這依賴 MDLM 的 carry-over 參數化：已解開位置的 $x_\theta$ 就是 $z_t$ 本身）。USDM 的 $q_{0|t}$ 論文沒有寫出；由 02 節的式子取 $\alpha_s=1$ 得 $q_{0|t}\propto x_\theta\odot(\alpha_t z_t+(1-\alpha_t)\mathbf 1/K)$ 本頁推導。

    $$\Psi^\theta_{s|t}(\cdot|z_t)=\underbrace{\kappa_t\,q_{s|t}(\cdot|z_t,x_\theta)}_{\text{預測步}}+\underbrace{(1-\kappa_t)\big[\alpha_s\,q_{0|t}(\cdot|z_t,x_\theta)+(1-\alpha_s)\pi\big]}_{\text{校正步}}$$
    式 (12)

    $\kappa_t=1$ 還原 ancestral sampler。作者把第一項稱為預測步（predictor），第二項稱為校正步（corrector），類比 Gaussian 擴散的 predictor-corrector 取樣（Song et al., 2021）；校正步注入雜訊，讓先前的預測可以被修改（§3、Fig. 2）。03 節的邊際保證只對真 posterior (11) 成立：§3 末句「converge to the correct distribution given sufficient samples」是對 (11) 的敘述，論文沒有給 (12) 的誤差界。

    作者認為效果的關鍵是 offset 項 $(1-\kappa_t)(1-\alpha_s)\pi$（§3 Intuitive Explanation）。在 MDM，這一項把機率放在 [MASK] 上：已解開 token 以 $(1-\kappa_t)(1-\alpha_s)$ 的機率變回 [MASK]，之後重新解開，這稱為重新遮罩（remask）。在 USDM，每個 token 至少得到 $(1-\kappa_t)(1-\alpha_s)/K$ 的機率，即使去噪器給正確 token 零機率，它仍可能出現 本頁推導。W2 的預設情形（USDM、去噪器給 A 零機率、$\kappa=0.5$）中，下一步抽到 A 的機率由 0.0352（$\kappa=1$）升到 0.0676。

    05 · 與 ReMDM 的關係

    在 mask 先驗下，ReMDM 是 Ψ-sampler 的特例

    ReMDM（Wang et al., 2025）是 MDM 的 remasking 取樣器，以 remask 機率 $\sigma_t$ 參數化（式 21）：$z_t\ne m$ 時 $z_s\sim\mathrm{Cat}((1-\sigma_t)x+\sigma_t m)$；$z_t=m$ 時 $z_s\sim\mathrm{Cat}\big(\frac{\alpha_s-(1-\sigma_t)\alpha_t}{1-\alpha_t}x+\frac{1-\alpha_s-\sigma_t\alpha_t}{1-\alpha_t}m\big)$；$0\le\sigma_t\le\sigma_t^{\max}=\min\{1,(1-\alpha_s)/\alpha_t\}$。Ψ 等於 ReMDM 時 $\kappa_t$ 與 $\sigma_t$ 的關係是 $\kappa_t=1-\sigma_t/(1-\alpha_s)$（Suppl. A.4）：π = m 時把 Ψ 展開，代入這個 $\kappa_t$ 即得式 (21)。論文只比對了第一列；第二列 $x$ 的係數 $\frac{\alpha_s-\alpha_t}{1-\alpha_t}+\frac{\sigma_t}{1-\alpha_s}\cdot\frac{\alpha_t(1-\alpha_s)}{1-\alpha_t}=\frac{\alpha_s-(1-\sigma_t)\alpha_t}{1-\alpha_t}$，同樣一致 本頁推導。ReMDM 又涵蓋 Campbell et al. (2022) 的 FB 與 Gat et al. (2024) 的 DFM 校正器，所以 Ψ 也涵蓋它們。

    何時 $\kappa_t\lt0$：$\kappa_t\in[0,1]$ 等價於 $\sigma_t\le1-\alpha_s$，但 $\sigma_t^{\max}\ge1-\alpha_s$；當 $\sigma_t>1-\alpha_s$ 時 $\kappa_t\lt0$，超出 §3 宣告的 $\kappa_t\in[0,1]$（在 MDM 下分佈仍合法）本頁推導。因此「Ψ 涵蓋 ReMDM」嚴格成立的條件是 $\sigma_t\le1-\alpha_s$。ReMDM 有三種 $\sigma_t$ schedule（Suppl. A.5）：cap $\sigma_t=\min(\eta,\sigma_t^{\max})$（式 27）、rescale $\sigma_t=\eta\,\sigma_t^{\max}$（式 28）、loop（在 $[t_{\text{off}},t_{\text{on}}]$ 內固定 $\alpha_t$ 並用常數 $\sigma_t=\eta$）。以 $\alpha_t=1-t$、128 步換算：cap 在最後幾步（$s\lt\eta$）得到 $\kappa_t\lt0$，$\eta=0.05$ 時最小值 −0.0579；rescale 的 $\kappa_t$ 約在 $[1-2\eta,1-\eta]$ 之間，不會為負（$\alpha_t\ge1-\alpha_s$ 時 $\kappa=1-\eta/\alpha_t$，否則 $\kappa=1-\eta/(1-\alpha_s)$）本頁推導。loop 的 $\kappa$ 為常數 $1-\eta/(1-\alpha_{\text{on}})$。

    論文對 Duo（USDM）使用「κt schedules matching ReMDM」（Table 13），本頁的讀法是：把上面的 $\kappa_t(\alpha_t,\alpha_s,\eta)$ 直接套到均勻先驗 推定。$\sigma^{\max}$ 作為合法上界的意義只屬於 MDM；USDM 的合法條件是 $\kappa_t\in[0,1]$，rescale 滿足，cap 不一定滿足，論文沒有說明 USDM 如何處理負 $\kappa$。

    06 · 玩具問題

    玩具問題：校正步讓更多步數繼續降低錯誤率

    W3 用一個人為設定的小問題顯示校正步的作用。資料只有一個長度 32 的序列（8 種真實 token）；去噪器對每個位置輸出「正確 token 機率 $1-\varepsilon$，其餘 7 個 token 平分 $\varepsilon$」，錯誤率 $\varepsilon=\varepsilon_{\max}-(\varepsilon_{\max}-0.02)\,c$ 隨目前與目標相同的位置比例 $c$ 線性下降（[MASK] 位置算作不相同）；schedule 取 $\alpha_t=1-t$ 推定。這些都是本頁的假設，不是論文的模型。

    在本頁 toy 的預設設定下（$\varepsilon_{\max}=0.5$），toy 假設去噪器錯誤率隨正確位置比例下降。MDM 的 ancestral sampler 增加步數幾乎沒有改善：早期以高錯誤率解開的 token 不再更新，錯誤率停在約 0.33–0.38。Ψ-sampler 的校正步以機率 $(1-\kappa_t)(1-\alpha_s)$ 把 token 變回 [MASK]，之後由錯誤率較低的去噪器重新預測；步數越多，校正次數越多，window schedule（$\kappa=0.9$、$t\in[0.1,0.6]$）的錯誤率由 8 步的 0.367 降到 512 步的 0.195。步數少時兩者相同，因為校正次數太少。這是 toy 假設下的結果，toy 的 $T$ 不對應論文的 NFE：真實的 MDLM 在步數低於序列長度時仍會改善（Table 13，$p=0.9$ 時 70.34 到 37.91），toy 從 $T=8$ 就持平，是 $\varepsilon_{\max}$ 選擇的結果；把 $\varepsilon_{\max}$ 調低，ancestral 的錯誤率也跟著下降。

    語言實驗：p = 0.9 與 rescale 下 Gen. PPL 在 1024 步後仍下降

    09 · Duo 的課程學習

    Duo 的課程學習需要 K 維 softmax

    本節起是論文的第二個貢獻，與前面的取樣器互不依賴。Duo（Sahoo et al., 2025a）指出 USDM 可以由連續的 Gaussian 擴散得到：對 one-hot 向量 $x$ 加 Gaussian 雜訊，得到 latent $w_t\sim\mathcal N(\tilde\alpha_t x,\tilde\sigma_t^2 I_K)$，其中 $\tilde\alpha_t$ 是 Gaussian 側的 schedule，$\tilde\sigma_t=\sqrt{1-\tilde\alpha_t^2}$。取 argmax（最大座標的 one-hot）後，$z_t=\arg\max(w_t)$ 的邊際正好是式 (1) 的 uniform 形式，對應的 $\alpha_t=\mathcal T(\tilde\alpha_t)$（式 6、7）；$\mathcal T$ 是把 Gaussian 側 schedule 換算成離散側的函式。

    Duo 的課程學習在前 50% 訓練步把送進 transformer 的 argmax 換成 $\mathrm{softmax}(w_t/\tau)$（式 9）。softmax 的溫度 $\tau$ 越小，輸出越接近 argmax 的 one-hot；$\tau\to0$ 時兩者相同。輸入 embedding 變成 $V^\top y$，即以 softmax 權重 $y$ 對所有 $K$ 個 embedding 做加權和，而不是查一列表格。這要求每個位置在每個訓練步具現一個 $K$ 維向量；現代 LLM 的詞彙 $K>100{,}000$（§4），記憶體不可行。

    作者的觀察：Duo 用的溫度是 $\tau=10^{-3}$，此時 softmax 幾乎只有少數幾項非零，所以只用 $k\ll K$ 個 embedding（式 13）就能近似加權和。本頁以 $K=50257$（GPT-2 詞彙）、$\tilde\alpha_t=0.34$、$k=3$ 重複抽樣 400 次，最大權重超過 0.99 的比例是 0.9725（W4a）。剩下的問題是如何不具現 $K$ 維向量就找到最大的 $k$ 個值（10 節），以及如何估計 softmax 的分母（11 節）。$\mathcal T$ 本身原本靠預先計算 100k 個點（GPT-2 詞彙最多兩小時），論文改用約 150 項的級數（式 49、55）並再以 9 次多項式擬合（Suppl. B.3）。

    10 · Top-k 抽樣

    Order statistics 直接抽出最大的 k 個值

    逆轉換抽樣：若 $U\sim U[0,1]$、$F$ 是某個分佈的 CDF，則 $F^{-1}(U)$ 服從該分佈（式 29）。高斯的 CDF 寫成 $\Phi$，$\Phi^{-1}$ 單調遞增，所以均勻變數的大小順序在轉換後保持不變。

    如何不具現 $K$ 維向量抽最大的 $k$ 個值：$w_t$ 中乾淨 token 的座標 $o$ 均值是 $\tilde\alpha_t$，與其他座標不同，所以另外單獨抽 $\tilde w\sim\mathcal N(\tilde\alpha_t,\tilde\sigma_t^2)$；其餘 $N=K-1$ 個座標 i.i.d. $\mathcal N(0,\tilde\sigma_t^2)$。$N$ 個 i.i.d. $U[0,1]$ 的最大值的 CDF 是 $u^N$（式 30），所以 $U^{(1)}=V^{1/N}$（$V\sim U[0,1]$）直接抽出最大值；給定 $U^{(i)}$，下一個 $U^{(i+1)}$ 是 $N-i$ 個 $U[0,U^{(i)}]$ 的最大值（Prop. B.4、式 38）。再乘 $\tilde\sigma_t\Phi^{-1}$，就得到第 $i$ 大的零均值值 $\mathcal K_i$。Algo. 1 在 log 空間計算：$R_\ell=\log U_\ell/\ell$、$P_\ell=\sum_{m=\ell}^{N}R_m$、$V_\ell=e^{P_\ell}$。接著比較 $\tilde w$：$\tilde w\lt\mathcal K_k$ 為 case 1（乾淨 token 不在前 $k$ 名）；否則為 case 2，把 $\tilde w$ 插在第 $r+1$ 名（$r$ 是大於 $\tilde w$ 的 $\mathcal K_j$ 個數），丟掉 $\mathcal K_k$。論文以 Floyd 演算法抽索引（Algo. 2：依序無放回抽 $k$ 個整數，抽到重複就改用目前範圍的最大值，不需要洗牌整個 $K$ 元素的陣列），本頁元件只示範數值。

    哪些步驟是近似：值與索引在分佈上精確 本頁推導，W4a 的「重複 400 次」可與暴力排序比較（$K\le10^4$ 時）。只保留 $k$ 個 embedding（式 13）與 $\tilde Z$（下一節）是近似。

    11 · Normalizer

    以截斷高斯的期望值近似未抽樣項

    softmax 的權重是 $\lambda_i=e^{\mathcal K_i/\tau}/Z$，分母 $Z$ 是全部 $K$ 項 $e^{w_j/\tau}$ 的和。未抽樣的零均值座標都小於門檻 $c$（前 $k$ 名中最小的值），所以每一項的分佈是截斷高斯：$X\sim\mathcal N(0,\tilde\sigma_t^2)$ 限制在 $X\lt c$。論文以條件期望 $\mu=\mathbb E[e^{X/\tau}\mid X\lt c]$ 代替每一項（式 40）。把指數併入高斯密度並配方，得到

    $$\log\mu=\frac{\tilde\sigma_t^2}{2\tau^2}-\log\Phi\Big(\frac{c}{\tilde\sigma_t}\Big)+\log\Phi\Big(\frac{c-\tilde\sigma_t^2/\tau}{\tilde\sigma_t}\Big)$$
    式 (44)

    case 1、2 的 $\tilde Z$ 各含幾個未抽樣項：case 1（乾淨 token 不在前 $k$ 名）有 $K-k-1$ 個，另加乾淨 token 的 $e^{\tilde w/\tau}$，$\tilde Z=\sum_{i\le k}e^{\mathcal K_i/\tau}+e^{\tilde w/\tau}+(K-k-1)\mu$（式 41，$c=\mathcal K_k$）；case 2 有 $K-k$ 個，$\tilde Z=\sum_{i\le k}e^{\mathcal K_i/\tau}+(K-k)\mu$（式 42）。case 2 的門檻是插入後的第 $k$ 名，也就是插入前的 $\mathcal K_{k-1}$；已知被丟掉的值是舊的 $\mathcal K_k$，以 $\mathcal K_{k-1}$ 為門檻較寬鬆，是作者的設計選擇。式 (14) 後的文字寫「δ = 1 if $\tilde w\in\mathcal K$ (case 2)」，與式 (41)(42) 和 Algo. 3 相反；本頁以後兩者為準。式 (43) 把 $\mu$ 寫成 $\log\mathbb E[e^X]$（少了 $/\tau$），自洽的讀法是式 (44) 右邊為 $\log\mathbb E[e^{X/\tau}]$。

    數值上必須在 log 空間計算：$\tau=10^{-3}$、$\tilde\sigma_t\approx0.94$ 時 $\tilde\sigma_t^2/2\tau^2\approx4.4\times10^5$，與 $\log\Phi(\cdot)\approx-4.4\times10^5$ 相消，直接取指數會溢位。$\tau$ 越大，只取前 $k$ 項的誤差越大：W4b 中 $\tau\ge0.3$ 時 $Z_{\text{top}}/Z$ 低於 0.31，加入尾項期望值的 $\tilde Z$ 則在真值的 0.96–1.07 倍之間；$\tau=0.05$ 時 $\tilde Z$ 可高估到 1.27 倍，因為尾項用的是期望值，不是逐次的精確值。權重和 $\sum\lambda_i$ 隨 $\tau$ 增大而遠小於 1，說明只保留 $k$ 項本身也是近似。

    14 · 限制與延伸

    限制、NELBO 與延伸閱讀

    限制：論文沒有給可取樣的式 (12) 的收斂保證或誤差界；$\kappa_t$ 需要逐任務調整，選錯會比 ancestral 差（Suppl. D.1）；語言實驗的增益伴隨 unigram entropy 下降，影像實驗的超參數直接在 FID 上挑選；USDM 的 likelihood 仍不如 MDM（Table 2）。
