# 568 design.md 審查：教學法與建置可行性

1. **P1 未教先用的前置概念。** 「表格式設定」（Hero 卡 2、S3）、「不動點」、熵 $\mathcal H$、KL、softmax、Lagrangian（S7）、$D_{\mathrm{TV}}$（S8）、折扣狀態分佈 $d^\pi$ 與經驗 MDP $\hat M$（S9）、重要性取樣（S10、LO11）、off-policy／actor-critic／twin-Q／SAC／QR-DQN 都沒有出現在任何「先定義」的位置。讀者只會機率與神經網路。修正：S1 加 tabular 與不動點各一句；S7 開頭用 3 句定義熵、KL、softmax；S8、S9、S10 第一次出現時各補一行定義，或標「可略過」。
2. **P1 符號 ρ 三重撞名。** 「ρ(a|s) KL 先驗」(S7)、「$\rho_a=\pi_a/\pi_{\beta,a}$」(C1、C2 計算)、「$\rho(s)$ 初始狀態分佈」(Eq. 5)。α 與論文 $\alpha(s,a)$ 撞名已記錄，但 ρ 沒有。修正：程式與讀數表中的比值改名為 `ratio` 或 $w_a$。
3. **P1 S3 提前使用取樣誤差符號。** 大綱 S3 含 Thm. 3.1，原式有 $C_{r,T,\delta}$ 與 $\lvert\mathcal D\rvert$，符號表卻寫 S6 才首次出現。修正：S3 只陳述 $\hat{\mathcal B}^\pi=\mathcal B^\pi$ 的版本，完整式留到 S6。
4. **P1 S8 難度陡增且無元件。** 「4 [S8]：Thm. 3.3（TV、soft-optimal、LHS／RHS）＋Thm. 3.4＋Fig. 2 描述」400–500 字，是全頁最抽象的一節。S9（Cauchy–Schwarz、$J(\pi,\hat M)$、ζ）亦同。LO9、LO10 沒有互動元件。修正：S8 拆為 3.3 與 3.4 兩小節；3.4 直接用 C4 的讀數作例；S9 補一個一維數值例（ζ 兩項各取一個數字）。
5. **P1 S4 過密。** 一節同時教 LO3、LO4、LO5：Eq. 2、Eq. 13、Eq. 14、$D_{\mathrm{CQL}}$ 恆等式、0.64、Thm. 3.2、ν-CQL，只給 500–600 字。S7 同樣塞進 Eq. 3、KL、Lagrangian、Eq. 4、soft-max 不等式、CQL(ρ)、資料平均不變、C4。修正：S4 拆成「Eq. 13 與 C1」與「$D_{\mathrm{CQL}}\ge0$、Thm. 3.2、ν」兩節；S7 拆成 CQL(R)／CQL(H) 與 CQL(ρ)／C4。
6. **P1 C3 的 π = π̂β 按鈕與計數取整不一致。** 「按鈕『π = π̂β』（把 π 權重設成與 $\pi_\beta$ 相同）」，但 $\hat\pi_\beta$ 由 $n_a=\max(1,\mathrm{round}(N\pi_\beta))$ 得出；驗收表自己有反例（權重 (1,1,98)、N=10 得 $n=(1,1,10)$，$\hat D=0.188$，總數 12 ≠ N）。小 N 時按下按鈕 $\hat D\neq0$，觀察 (4) 失敗。修正：按鈕改設成 $n_a$ 的比例，並把「N」改稱「目標筆數」，讀數另列實際總筆數。
7. **P1 C3 軸範圍未定義，α_δ 會出界。** 左圖橫軸 α ∈ [0,1]，但 σ = 2、N = 10 時 $\alpha_{0.01}\approx1.5$，交點在圖外。右圖縱軸 $\alpha_\delta$ 範圍沒寫，$\hat D$ 很小（例如 1e-6）時 $\alpha_\delta$ 爆大。修正：右圖縱軸自動取 log 範圍並設上下限、超出以釘邊與數值標示（同 C1 做法）；左圖滑桿的 α 上限與軸一致，並在 $\alpha_\delta>1$ 時加註。
8. **P1 C2 的觀察 (5) 在圖上看不到。** 「k = 1：−0.0063 對 0」在縱軸量級約 6 的折線圖上不可見。γ = 0.95 時 k = 100 的值 8.5316 與不動點 8.5902 的差 0.06，但「右端標不動點值」會讓讀者以為已收斂。縱軸範圍也沒寫（γ 到 0.95 時 V 超過 15）。修正：加第二張「與真實值的差」的小圖或讀數列，縱軸依 γ 動態取範圍，右端同時標 k = 100 值與不動點值。
9. **P1 中、寬圖在 390px 的版面沒有規格。** C2「左：狀態圖／中：分組橫條／右：折線」、C3「左圖／右圖」、C4 三層圖只有桌機描述。只有 Alg. 1 與 Thm. 3.1／3.2／Eq. 6 寫了窄版處理；Eq. 2、Eq. 3、Eq. 4（含 min-max 與多個期望）沒寫。修正：< 768px 一律單欄堆疊，每圖 viewBox 固定寬高比；讀數表加 `overflow-x:auto` 且該容器 `tabindex="0"`；`.katex-display` 同樣加 `tabindex="0"` 與 `role="group"`，讓鍵盤能橫捲。
10. **P1 輸入過多。** C1 有 7 個滑桿、C2 有 8 個，初學者無法判斷動哪一個。修正：預設只露出 α 與 π；其餘收進「進階設定」並附預設組按鈕（如 C4）。
11. **P1 Unicode 動態文字的字型風險。** 規格要求「V̂ − V = −0.80」「Q̂₁」「$\chi^2$」用組合字元與下標數字。組合抑揚符（U+0302）加 V、Q 在 Newsreader／JetBrains Mono 常無對應字形，會退回其他字型且字距錯亂；螢幕閱讀器也會唸成零散字元。修正：改用 `<span class="hat">` 加 CSS 上標或 SVG `<tspan>`，或寫成 `V^` 加 `aria-label`。
12. **P2 標題與用語。** 「07 · 讓被壓低的分佈追隨 Q」有擬人化（分佈「追隨」），改為「07 · 以 Q 的 softmax 作為被壓低的分佈：CQL(H) 與 CQL(ρ)」。Hero 標題「讓離線強化學習低估而不是高估」是對比口號，改為「保守 Q 學習：壓低離線資料外動作的 Q 值」。事實卡 3「2–5 倍」屬宣傳語氣，且論文只寫「經常」；改成「在混合資料集 12／18 列最高」並附 Table 1 連結。
13. **P2 常見錯誤第 7 條放錯章。** 「混比表格」要先看過表格才讀得懂，放在 S10 時 Table 1–7 尚未出現。移到 S11。
14. **P2 數值與暗色模式。** C4 快取鍵 `${pb}|${alpha}` 用浮點字串（0.15000000000000002 類）；改用整數步數。C2 的 Eq. 1「斜線填色」要用 SVG `pattern`，暗色模式需另設描線色 token，規格只新增兩個 token。C1 軸超出範圍時「釘在邊界」，但箭頭終點與實際值不同，需在箭頭上標「截斷」記號。
15. **P2 元件與學習目標對應。** LO2、LO5、LO8、LO10、LO11、LO12 沒有元件；LO11 的 τ 與 α 關係（τ 小 → α 大，最反直覺）最需要一個小元件或至少一張數值表。時間線（S12）不對應任何 LO，可標為選讀。
