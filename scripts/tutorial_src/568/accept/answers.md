# 568 Goldfish 驗收作答（僅依 page.txt）

**LO1**：OOD 動作被高估。Bellman 目標的 a′ 取自學到的策略，但 Q 只在資料動作上訓練；策略偏向 Q 被錯誤高估的 OOD 動作，離線無法試做修正。Q 的訓練沒有 state distribution shift，但策略測試時可能有。
- 段落：「Bellman backup 不查詢資料外狀態的 Q 值」
- 信心：high

**LO2**：每輪解為 Q̂^{k+1}=B̂^π Q̂^k − α μ/π̂β。不動點 Q̂^π=(I−γP^π)^{-1}[r−α μ/π̂β]=Q^π−α(I−γP^π)^{-1}μ/π̂β ≤ Q^π。每步減去非負量，且 (I−γP^π)^{-1} 元素非負，所以不動點逐點變小。前提：表格式、B̂=B、supp μ ⊂ supp π̂β、π̂β>0 對所有 a。
- 段落：「每一步少一點，不動點就少一點」
- 信心：high

**LO3**：Eq. 2 的逐格解為 Q̂^{k+1}=B^π Q̂^k − α[μ/π_β − 1]（表格式、無取樣誤差）。μ<π_β 的動作被抬高 α(1−μ/π_β)；μ>π_β 的被壓低。抬高的是「資料中常見、但 μ 選得少」的動作。C1 教學例（r=(1.0,0.6,0.8)、資料比例 (0.5,0.3,0.2)、π=(0.1,0.2,0.7)、μ=π、α=0.5）：a1 抬高 0.4、a2 抬高 0.1667、a3 壓低 1.25。Eq. 1 則三者皆壓低（−0.1、−0.3333、−1.75）。
- 段落：「Eq. 2 的結果不再是逐點下界」
- 信心：high（數字為頁面的自訂例子）

**LO4**：D_CQL(s)=Σ_a π(π/π_β − 1)=Σ_a (π−π_β)²/π_β + Σ_a π_β(π/π_β − 1)，第二項為 0（兩者和皆為 1），故 D_CQL(s) ≥ 0，等號若且唯若 π=π_β。數例 π_β=(0.5,0.5)、π=(0.9,0.1)：期望懲罰 0.9×0.8 − 0.1×0.8 = 0.64，平方式 0.16/0.5+0.16/0.5 = 0.64，兩者一致。頁面另指此量即卡方散度 χ²(π‖π_β)=Σπ²/π_β−1（本頁推導，論文未用此名稱）。
- 段落：「等號若且唯若 π=πβ」
- 信心：high

**LO5**：頁面（App. D.2，本頁推導）：把抬高項換成任意 ν 後，在表格式、μ=π、最壞情況的 π 下解 max_ν min_π Σ π(π−ν)/π_β。內層最佳 π*=½ν+½π_β，代回懲罰為 −¼χ²(ν‖π_β)。只有 ν=π_β 時懲罰非負。ν≠π_β 時存在使懲罰為負的 π，下界失效。頁面強調這只是「最壞 π」意義下的必要性，不是對每個固定 π 都必要。
- 段落：「只有 ν=πβ 使懲罰非負」
- 信心：medium

**LO6**：差 α/(1−γ)（每個狀態）。推導：μ=π 時 Eq. 1 每步期望懲罰 α·E_π[π/π_β]=α(D_CQL+1)，Eq. 2 為 α·D_CQL，每步恰差 α。因 (I−γP^π)^{-1}1 = 1/(1−γ)，累積後差 α/(1−γ)。C2 數值（α=0.1、γ=0.9）：Eq. 1 − Eq. 2 = −1.0000，與 −α/(1−γ) 相符。前提：無取樣誤差、μ=π。頁面說論文只寫「we explicitly subtract 1」。
- 段落：「每一步恰好差常數 α」
- 信心：high

**LO7**：有取樣誤差時，保證 V̂^π ≤ V^π 的門檻為 α > [C_{r,T,δ}R_max/(1−γ)]·max_{s} (1/√|D(s)|)·[Σ_a π(a|s)(π/π̂β−1)]^{-1}。門檻正比於 1/√|D|（資料越多所需 α 越小，無限資料時極小 α 即可）；也正比於 1/D_CQL。評估 π=π̂β 時 D_CQL=0，門檻無限大，任何 α 都無法保證行為策略本身的下界。另外，有取樣誤差時 μ 必須在每個動作都 >0。
- 數字（頁面的 C3 教學模型，非定理）：N=100、σ=1、α=0.2 時 P(V̂>V)=0.02344；δ=0.05 時 α_δ=0.16553；N=1000 時 α_δ=0.05235（約 1/√10）；σ 加倍則 α_δ 加倍。
- 段落：「門檻正比於 1/√|D|」
- 信心：high（公式）；medium（C3 只是教學模型）

**LO8**：max_μ{E_μ[Q]+H(μ)} = log Σ_a exp Q(s,a)，最佳解 μ* ∝ exp Q（Q 的 softmax）。推導用 Lagrangian：f(x)−log μ(x)−1+λ=0，代回得 log Z，Z=Σ exp f。此值介於 max_a Q 與 max_a Q + log|A| 之間，是 max 的平滑版（soft-maximum）。
- 段落：「最佳的 μ 是 Q 的 softmax」
- 信心：high

**LO9**：Thm. 3.3 要求：D_TV(π̂^{k+1}, π_{Q̂^k}) ≤ ε，且 E_{π_Q}[π_Q/π̂β − 1] ≥ max_{a: π̂β>0}(π_Q/π̂β)·ε。頁面說明 α 大時 ε 要更小。實作上，作者以此為依據把策略學習率設為 3e-5（Q 為 3e-4 或 1e-4，見 Sec. 4）。但實作的 SAC 策略是高斯分佈而非 Q 的 softmax，所以這只是作者的設計理由，頁面稱非已驗證的保證。
Thm. 3.4（gap-expanding）：對足夠大的 α_k，E_{π_β}[Q̂^k] − E_{μ_k}[Q̂^k] > E_{π_β}[Q^k] − E_{μ_k}[Q^k]。學到的 Q 比真實 Q 更拉大資料內外動作的期望差距，使 π^k 被拉向資料分佈，隱含避開 OOD 動作。頁面指出論文附錄的符號有誤（Thm. 3.4 證明的正負號），本頁採重算版本。
- 段落：「作者認為這個條件是把策略學習率設為 3e-5」
- 信心：medium（Thm. 3.3 條件與學習率）；high（Thm. 3.4 陳述）

**LO10**：ζ 由兩項組成：第一項 2(C_{r,δ}/(1−γ)+γR_maxC_{T,δ}/(1−γ)²)·E_{s∼d^{π*}}[√|A|/√|D(s)|·√(D_CQL+1)]，是經驗 MDP M̂ 與真實 M 不同（取樣誤差）造成的損失；第二項是 −(J(π*,M̂)−J(π̂β,M̂))，其下界為 α/(1−γ)·E[D_CQL]，是 CQL 在經驗 MDP 中的改進。
ζ 為負代表 π* 真的優於 π̂β（J(π*,M)≥J(π̂β,M)+|ζ|）；ζ>0 時只保證不比行為策略差超過 ζ。改進是相對經驗行為策略，不是相對最優策略。
- 數值（頁面自訂常數，只為說明）：第一項 2.0、α=1、γ=0.9、E[D_CQL]=0.3，則第二項 ≥3.0，ζ ≤ −1.0；資料量 4 倍時 ζ ≤ −2.0。
- 段落：「ζ 可以是負的」
- 信心：high

## 乙、beginner 易卡住處（最多 5 點）

1. 「逐點下界」與「期望下界」混淆：只有 Eq. 1（Thm. 3.1）是逐點；實際用的 Eq. 2 只保證 E_π[Q̂]≤V^π。
2. 符號重疊：D 同時是資料集、|D(s,a)| 計數、D_CQL；π̂β 與 π_β 常混用。
3. 「任何 α>0 都給下界」只在表格式且無取樣誤差時成立，有取樣誤差需超過門檻，且 π=π̂β 時無解。
4. 「本頁推導」與論文結論不同：χ² 的名稱、C3 的 α_δ、C4 的 τ 機制、Thm. 3.4 符號都非論文原文；C 系列數字是「推定」的自訂例子。
5. 方向容易反：τ 小 → α 大；哪些動作被抬高由 μ 與 π̂β 的比較決定，而不是由 Q 大小決定。
