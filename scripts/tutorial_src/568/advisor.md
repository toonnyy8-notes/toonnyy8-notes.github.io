## 1. 論證的 10 個步驟

**步驟 1｜問題設定（§2）**
- 假設：離線資料集 D 取樣自 d^{π_β}(s)π_β(a|s)；|r| ≤ R_max；不能再與環境互動。
- 內容：一般 actor-critic 的 Bellman 目標值用 a' ∼ π^k 取樣，但 Q 只在 π_β 的動作上訓練過，這叫 action distribution shift。π 又被訓練成最大化 Q，所以會偏向 Q 值錯誤偏高的 OOD 動作。
- 論文明確寫：Q 的訓練沒有 state distribution shift（backup 從不查詢資料外的狀態），但策略在測試時可能有。
- 這一步沒有證明任何東西，只是動機。

**步驟 2｜式 1：只加「壓低」項，得到逐點下界（§3.1，定理 3.1）**
- 式 1：Q̂^{k+1} ← argmin_Q α·E_{s∼D, a∼μ(a|s)}[Q(s,a)] + ½·E_{s,a∼D}[(Q(s,a) − B̂^π Q̂^k(s,a))²]。
- 假設：表格式（每個迭代都能精確表示）；supp μ ⊂ supp π̂_β；推導中另外假設 π̂_β(a|s) > 0 對所有 a。
- 證明：Q̂^π(s,a) ≤ Q^π(s,a) − α[(I−γP^π)^{-1}(μ/π̂_β)](s,a) + [(I−γP^π)^{-1} C_{r,T,δ}R_max/((1−γ)√|D|)](s,a)，對所有 s∈D 與 a，機率 ≥ 1−δ。α 夠大時 Q̂^π ≤ Q^π 逐點成立；B̂^π = B^π 時任何 α > 0 都成立。

**步驟 3｜式 2：再加「資料上抬高」項，下界變緊但只對 V 成立（§3.1，定理 3.2）**
- 式 2：把式 1 的第一項改成 α·(E_{s∼D,a∼μ}[Q] − E_{s∼D,a∼π̂_β}[Q])。
- 假設：μ = π（被評估的策略）；表格式。
- 證明：V̂^π(s) ≤ V^π(s) − α[(I−γP^π)^{-1} E_π[π/π̂_β − 1]](s) + [(I−γP^π)^{-1} C_{r,T,δ}R_max/((1−γ)√|D|)](s)，∀s∈D。
- 同時說明：Q̂^π 不再是逐點下界（π̂_β 機率高的動作可能被高估）。

**步驟 4｜為什麼抬高項一定要用 π̂_β（附錄 D.2，定理 D.3）**
- 把抬高項的分佈換成任意 ν（式 19，ν-CQL）。
- 證明：若要對「所有」π 都保證下界，只有 ν = π_β 可以。ν ≠ π_β 時可以找到一個 π 讓懲罰項為負。
- 這是「最壞情況的 π」意義下的必要性，不是對每個固定 π 的必要性。

**步驟 5｜從策略評估變成策略學習：CQL(R) 家族（§3.2，式 3、式 4，附錄 A）**
- 不想對每個策略迭代都做完整評估，所以讓 μ 自己去「追」目前 Q 的最大值：min_Q max_μ α(E_μ[Q] − E_{π̂_β}[Q]) + ½ Bellman 誤差 + R(μ)。
- R(μ) = −D_KL(μ, ρ) 時 μ(a|s) ∝ ρ(a|s)·exp(Q(s,a))。
- ρ = Unif → CQL(H)，式 4：min_Q α·E_{s∼D}[log Σ_a exp(Q(s,a)) − E_{a∼π̂_β}[Q(s,a)]] + ½·E[(Q − B̂^{π_k} Q̂^k)²]。
- ρ = π̂^{k−1}（前一個策略）→ CQL(ρ)，式 7。
- 這一步是「定義」，不是定理。

**步驟 6｜策略會變動時下界還在嗎（定理 3.3）**
- 假設：無取樣誤差；π_{Q̂^k}(a|s) ∝ exp(Q̂^k(s,a))；D_TV(π̂^{k+1}, π_{Q̂^k}) ≤ ε（策略相對 Q 變得慢）。
- 證明：若 E_{π_{Q̂^k}}[π_{Q̂^k}/π̂_β − 1] ≥ max_{a: π̂_β(a|s)>0}(π_{Q̂^k}(a|s)/π̂_β(a|s))·ε，則 V̂^{k+1}(s) ≤ V^{k+1}(s)。
- 論文把這個定理當成「策略學習率要小」的依據（§4：策略學習率 3e-5，“as dictated by Theorem 3.3”）。

**步驟 7｜gap-expanding（定理 3.4，附錄 B）**
- 假設：α_k 夠大；無取樣誤差版先證，再補取樣誤差。
- 證明：E_{π_β}[Q̂^k] − E_{μ_k}[Q̂^k] > E_{π_β}[Q^k] − E_{μ_k}[Q^k]，∀s。意思是學到的 Q 把「資料內動作」與「μ 下動作」的期望值差距拉得比真實 Q 更大。
- 附錄 B 圖 2 是實驗佐證（hopper-expert、hopper-medium，CQL 對 BEAR）。

**步驟 8｜CQL 最佳化的是什麼目標（定理 3.5 = 引理 D.3.1）**
- 假設：Q̂^π 是式 2 的不動點。
- 證明：π* = argmax_π E_{s∼ρ(s)}[V̂^π(s)] 等價於 π* ← argmax_π J(π, M̂) − α·(1/(1−γ))·E_{s∼d^π_{M̂}(s)}[D_CQL(π, π̂_β)(s)]（式 5），其中 D_CQL(π, π_β)(s) := Σ_a π(a|s)·(π(a|s)/π_β(a|s) − 1)。M̂ 是資料集轉移構成的經驗 MDP。

**步驟 9｜安全策略改進（定理 3.6 = 定理 D.4）**
- 假設：附錄 D.3 的集中性假設 D.1；π* 最佳化式 5。
- 證明：J(π*, M) ≥ J(π̂_β, M) − ζ，機率 1−δ，ζ 見式 6（下面 2.5 節）。
- ζ 的第一項是取樣誤差造成的損失，第二項是 CQL 在經驗 MDP 中帶來的改進。

**步驟 10｜實作與實驗（§4、§6、附錄 F、G）**
- 連續控制：建在 SAC 上，用 CQL(H)，α 用 Lagrange 對偶梯度自動調（式 30）。離散控制：建在 QR-DQN 上，α 固定。
- 實驗宣稱：D4RL Gym（表 1）、AntMaze/Adroit/Kitchen（表 2）、Atari（圖 1、表 3）、下界驗證（表 4）、消融（表 5–7）。
- 函數近似的理論延伸在附錄 D.1（定理 D.1 線性、定理 D.2 NTK）。論文 §7 自己承認深度網路的嚴格分析留給未來。

## 2. 老師必須算對的 5 個推導

### 2.1 式 1 → 式 11 → 定理 3.1（逐點下界）

條件：表格式；π̂_β(a|s) > 0；每一輪對 Q 精確最小化。

把式 1 對單一格 Q(s,a) 寫開 〔顧問推導：論文只寫「令導數為 0」〕：
- 目標中含 Q(s,a) 的部分 = α·d(s)·μ(a|s)·Q(s,a) + ½·d(s)·π̂_β(a|s)·(Q(s,a) − B̂^π Q̂^k(s,a))²
- 對 Q(s,a) 微分設為 0：α·μ(a|s) + π̂_β(a|s)·(Q(s,a) − B̂^π Q̂^k(s,a)) = 0

得到式 11：
- Q̂^{k+1}(s,a) = B̂^π Q̂^k(s,a) − α·μ(a|s)/π̂_β(a|s)

因為 μ ≥ 0、α > 0、π̂_β > 0，所以 Q̂^{k+1} ≤ B̂^π Q̂^k。

加入取樣誤差（附錄 C、D.3）：B̂^π Q − B^π Q ≤ C_{r,T,δ}R_max/((1−γ)√|D(s,a)|)，所以（式 12）
- Q̂^{k+1}(s,a) ≤ B^π Q̂^k(s,a) − α·μ(a|s)/π̂_β(a|s) + C_{r,T,δ}R_max/((1−γ)√|D(s,a)|)

求不動點：B^π Q = R + γP^π Q，所以
- Q̂^π ≤ (I−γP^π)^{-1}[R − α·μ/π̂_β + C_{r,T,δ}R_max/((1−γ)√|D|)]
- = Q^π − α(I−γP^π)^{-1}[μ/π̂_β] + (I−γP^π)^{-1}[C_{r,T,δ}R_max/((1−γ)√|D|)]

關鍵事實：(I−γP^π)^{-1} 的每個元素都非負，所以「每步都少一點」可以累積成「不動點也少」。

保證下界的 α（附錄 C）：α ≥ max_{s,a}[C_{r,T,δ}R_max/((1−γ)√|D(s,a)|)] · max_{s,a}[(μ(a|s)/π̂_β(a|s))^{-1}]。

〔顧問推導〕要提醒的兩點：
- π̂_β(a|s) 出現在分母，是因為 Bellman 誤差項用資料密度加權，而懲罰項用 μ 加權。資料越少的動作，同樣的 α 壓得越低。
- 若 μ 在 π̂_β = 0 的動作上有質量，表格式下那一格只有 α·μ·Q 一項，最小值是 −∞。所以定理要求 supp μ ⊂ supp π̂_β。

### 2.2 式 2 → 式 13、14 → D_CQL ≥ 0 → 定理 3.2

條件：表格式；先假設 B̂^π = B^π 且 π̂_β = π_β；μ = π。

對式 2 逐格微分（同 2.1，多一項 −α·π_β(a|s)）得式 13：
- Q̂^{k+1}(s,a) = B^π Q̂^k(s,a) − α[μ(a|s)/π_β(a|s) − 1]

逐點下界失效的原因：μ(a|s) < π_β(a|s) 的動作，括號是負的，等於「加」了一個正量 α(1 − μ/π_β)。

對 a ∼ π 取期望得式 14：
- V̂^{k+1}(s) = B^π V̂^k(s) − α·E_{a∼π}[μ(a|s)/π_β(a|s) − 1]

令 μ = π，懲罰量是 D_CQL(s) = Σ_a π(a|s)[π(a|s)/π_β(a|s) − 1]。論文的推導（附錄 C）：
- D_CQL(s) = Σ_a (π − π_β + π_β)[π/π_β − 1]
- = Σ_a (π − π_β)·(π − π_β)/π_β + Σ_a π_β·[π/π_β − 1]
- = Σ_a (π(a|s) − π_β(a|s))²/π_β(a|s) + 0   （因為 Σ_a π = Σ_a π_β = 1）
- ≥ 0，且等於 0 若且唯若 π = π_β。

不動點：
- V̂^π(s) = V^π(s) − α[(I−γP^π)^{-1} E_π[π/π_β − 1]](s)

加取樣誤差後就是定理 3.2 的式子。α 門檻（主文）：α > (C_{r,T}R_max/(1−γ))·max_{s∈D}(1/√|D(s)|)·[Σ_a π(a|s)(π(a|s)/π̂_β(a|s) − 1)]^{-1}。

〔顧問推導〕
- D_CQL(s) = Σ_a π²/π_β − 1，這正是 π 對 π_β 的卡方散度 χ²(π‖π_β)。論文沒有用這個名字，但附錄 D.4 用到 D_CQL(s) = Σ_a π(a|s)²/π̂_β(a|s) − 1。
- 數值檢查：π_β = (0.5, 0.5)，π = (0.9, 0.1)。動作 1：π/π_β − 1 = 0.8，Q 被降 0.8α。動作 2：π/π_β − 1 = −0.8，Q 被升 0.8α。π 下的期望懲罰 = 0.9×0.8 − 0.1×0.8 = 0.64；用平方式算 = 0.16/0.5 + 0.16/0.5 = 0.64。一致。
- 「更緊」的精確量：式 1 取 μ = π 時每步懲罰是 α·E_π[π/π_β] = α(D_CQL + 1)，式 2 是 α·D_CQL。差是常數 α，累積後 V 的下界正好差 α·(I−γP^π)^{-1}·1 = α/(1−γ)（無取樣誤差時）。
- π = π̂_β 的狀態 D_CQL = 0，上面門檻中的 [·]^{-1} 是無限大。也就是有取樣誤差時，評估行為策略本身沒有任何 α 能保證下界。論文沒有討論這個邊界情形。

### 2.3 CQL(R) → CQL(H) 的 log-sum-exp（式 3 → 式 4，附錄 A）

條件：對固定的 Q 與固定的狀態 s，解內層 max_μ；μ 是機率分佈。

問題：max_μ E_{x∼μ}[f(x)] + H(μ)，s.t. Σ_x μ(x) = 1，μ(x) ≥ 0。論文直接給答案 μ*(x) = (1/Z)exp(f(x))。

中間步驟 〔顧問推導〕：
- Lagrangian：Σ_x μ(x)f(x) − Σ_x μ(x)log μ(x) + λ(Σ_x μ(x) − 1)
- 對 μ(x) 微分：f(x) − log μ(x) − 1 + λ = 0 → μ*(x) ∝ exp(f(x))，Z = Σ_x exp(f(x))
- 代回：Σ_x μ*(x)f(x) − Σ_x μ*(x)(f(x) − log Z) = log Z = log Σ_x exp(f(x))

所以 max_μ {E_μ[Q] + H(μ)} = log Σ_a exp(Q(s,a))，這就是式 4 第一項。

KL 版本：R(μ) = −D_KL(μ, ρ) 時 μ*(x) = (1/Z)ρ(x)exp(f(x))。
- 〔顧問推導〕代回的值是 log Σ_x ρ(x)exp(f(x))。ρ = Unif 時等於 log Σ_a exp(Q) − log|A|，常數不影響梯度，所以與 H 版本等價。
- 論文的式 7 寫的是 α·E_{s}[E_{a∼ρ}[Q(s,a)·exp(Q(s,a))/Z] − E_{a∼π_β}[Q(s,a)]] + ½ Bellman 誤差，並註明「modulo some normalization terms」。式 7 的第一項是 E_{μ*}[Q]，不是完整代回後的 log E_ρ[exp Q]。不要把式 7 講成「精確代入」。

### 2.4 gap-expanding（定理 3.4）與定理 3.3 的拆解

**定理 3.4**，條件：表格式，先無取樣誤差。一步更新：
- Q̂^{k+1}(s,a) = B^{π_k} Q̂^k(s,a) − α_k·(μ_k(a|s) − π_β(a|s))/π_β(a|s)

兩個期望：
- 在 μ_k 下：懲罰 = α_k·Σ_a μ_k·(μ_k − π_β)/π_β = α_k·Δ̂^k，Δ̂^k ≥ 0（同 2.2 的平方式）。
- 在 π_β 下：懲罰 = α_k·Σ_a π_β·(μ_k − π_β)/π_β = α_k·Σ_a(μ_k − π_β) = 0。

〔顧問推導〕所以
- E_{π_β}[Q̂^{k+1}] − E_{μ_k}[Q̂^{k+1}] = E_{π_β}[B^{π_k}Q̂^k] − E_{μ_k}[B^{π_k}Q̂^k] + α_k·Δ̂^k
- 真實迭代的差距是 (π_β − μ_k)^T B^{π_k}Q^k。
- 因此 gap-expanding 成立的條件是 α_k·Δ̂^k > (μ_k − π_β)^T[B^{π_k}Q̂^k − B^{π_k}Q^k](s,·)，即 α_k > max((μ_k − π_β)^T[B^{π_k}Q̂^k − Q^{k+1}](s,·)/Δ̂^k, 0)。

注意：論文附錄 C 印出來的式子是「… − α_k·Δ̂^k」，最後的條件分子是 (π_β − μ_k)^T[B^{π_k}Q̂^k − Q^k]。〔顧問推導〕照式 13 的符號重算，α_k·Δ̂^k 前面應是正號，分子的符號也相反。定理的結論（α_k 夠大就成立）不受影響，但教學時不要逐字抄論文那幾行的正負號。論文另外給的寬鬆界：用 D_TV(π_β, μ_k)·R_max/(1−γ) 取代分子；有取樣誤差時 α_k 再加 D_TV(π̂_β, μ_k)·2·C_{r,T,δ}R_max/(1−γ)。

**定理 3.3**，論文的拆解（附錄 C）：
- E_{π̂^{k+1}}[Q̂^{k+1}] = E_{π̂^{k+1}}[B^π Q̂^k] − E_{π̂^{k+1}}[π_{Q̂^k}/π̂_β − 1]
- = E_{π̂^{k+1}}[B^π Q̂^k] − E_{π_{Q̂^k}}[π_{Q̂^k}/π̂_β − 1]（項 (a)，低估量）+ Σ_a(π_{Q̂^k}(a|s) − π̂^{k+1}(a|s))·π_{Q̂^k}(a|s)/π̂_β(a|s)（項 (b)）
- (b) ≤ D_TV(π_{Q̂^k}, π̂^{k+1})·max_a π_{Q̂^k}(a|s)/π̂_β(a|s)。要求 (a) ≥ (b) 的上界，就是定理的條件。

〔顧問推導〕
- 論文這幾行省略了 α。補上後兩邊都乘 α，所以定理 3.3 的條件裡沒有 α：α 不能幫忙滿足這個條件，只有 ε 小才行。
- (b) 的上界在標準定義 D_TV = ½Σ|p − q| 下仍成立：Σ(p−q)r = Σ(p−q)(r − c)，取 c 為 r 的最大最小值中點，得 ≤ D_TV·(max r − min r) ≤ D_TV·max r（因 r ≥ 0）。
- 這裡 μ = π_{Q̂^k} ∝ exp(Q̂^k) 是 CQL(H) 的內層最佳解。論文用 Q̂^k 的 softmax，而內層 max 其實是對「正在最佳化的 Q」取的；這一點論文沒有說明。

### 2.5 定理 3.5 與 3.6（安全策略改進）

**定理 3.5**（引理 D.3.1），論文的證明只有一句：Q̂^π 是經驗 MDP M̂ 中、獎勵改成 r(s,a) − α[π(a|s)/π̂_β(a|s) − 1] 的 Bellman 不動點。
- 〔顧問推導〕這由式 13 直接讀出。對 π 取期望後每步獎勵扣 α·D_CQL(s)，折扣累積就是 α·(1/(1−γ))·E_{s∼d^π_{M̂}}[D_CQL(π, π̂_β)(s)]，其中 d^π 是歸一化的折扣狀態分佈，所以有 1/(1−γ)。
- 注意懲罰的獎勵依賴 π 本身，所以這不是一個固定獎勵的普通 MDP。

**引理 D.4.1**：對任意 π，
- |J(π, M̂) − J(π, M)| ≤ (C_{r,δ}/(1−γ) + γR_max C_{T,δ}/(1−γ)²)·E_{s∼d^π_{M̂}(s)}[(√|A|/√|D(s)|)·√(D_CQL(π, π̂_β)(s) + 1)]

關鍵中間步驟：
- 獎勵部分：|D(s,a)| = |D(s)|·π̂_β(a|s)，所以 Σ_a π(a|s)·C_{r,δ}/√|D(s,a)| = (C_{r,δ}/√|D(s)|)·Σ_a π(a|s)/√π̂_β(a|s)。
- 轉移部分：用 Achiam et al. [1] 的 d^π_M − d^π_{M̂} = γḠΔd^π_{M̂} 類型恆等式，得到同樣的 Σ_a π/√π̂_β 因子。
- 令 α(s,a) := π(a|s)/√π̂_β(a|s)（論文在這裡重用了 α 這個字母，與 CQL 的 α 無關）。D_CQL(s) + 1 = Σ_a α(s,a)²，而 (Σ_a α(s,a))² ≤ |A|·(D_CQL(s) + 1)（Cauchy–Schwarz）。這就是 √|A| 與 √(D_CQL + 1) 的來源。

**定理 D.4 / 3.6** 的組合：
1. π* 最佳化式 5，且 D_CQL(π̂_β, π̂_β) = 0，所以 J(π*, M̂) − α(1/(1−γ))E[D_CQL(π*, π̂_β)] ≥ J(π̂_β, M̂)。（論文證明中這一行漏寫 1/(1−γ)，式 26、27 有。）
2. 對 π* 與 π̂_β 各用一次引理 D.4.1。因 √(D_CQL(π*, π̂_β) + 1) ≥ √(D_CQL(π̂_β, π̂_β) + 1)，π̂_β 的誤差項被 π* 的誤差項逐點蓋住，所以出現係數 2。
3. 結果（式 27）：J(π*, M) ≥ J(π̂_β, M) − 2(C_{r,δ}/(1−γ) + γR_max C_{T,δ}/(1−γ)²)·E_{s∼d^{π*}_{M̂}}[(√|A|/√|D(s)|)·√(D_CQL(π*, π̂_β)(s) + 1)] + α(1/(1−γ))E_{s∼d^{π*}_{M̂}}[D_CQL(π*, π̂_β)(s)]。

式 6 把最後一項寫成 −(J(π*, M̂) − J(π̂_β, M̂))，並標註它 ≥ α(1/(1−γ))E[D_CQL]。

要講對的地方：
- ζ 可以是負的（第二項大於第一項時），那才是真的「改進」。ζ > 0 時定理只保證「不會比行為策略差超過 ζ」。
- 改進是相對 π̂_β（經驗行為策略），不是相對最優策略。
- |D(s)| 大時第一項小，小的 α 就夠。

## 3. 常見誤讀與論文自身的不一致

### 3.1 從摘要或圖表看起來對、但論文沒有證明的說法

1. **「CQL 學到 Q 函數的下界」**。只有式 1 給逐點下界（定理 3.1）。實際用的式 2／式 4 只保證 E_π[Q̂] ≤ V^π（定理 3.2），而且論文明說 Q̂ 可能在 π̂_β 機率高的動作上被高估。§7 的 “lower bounds on the Q-function” 是寬鬆說法。
2. **「任何 α > 0 都給下界」**。只在 B̂^π = B^π（無取樣誤差）且表格式時成立。有取樣誤差或函數近似時要 α 超過門檻。
3. **「理論涵蓋實際演算法」**。定理 3.1 要求 supp μ ⊂ supp π̂_β；CQL(H) 的 μ ∝ exp(Q) 是全支撐，連續動作實作還從 Unif(a) 取樣。定理 3.2 要求 μ = π；實作中 μ 是 Q 的 softmax，π 是另外訓練的 SAC 策略，由定理 3.3 的「慢變」條件銜接。定理 3.3、3.4 在主文是無取樣誤差版。定理 D.2 靠 NTK 線性化假設，且每輪只走一步梯度。
4. **「下界對所有狀態成立」**。定理 3.1、3.2 是 ∀s∈D。定理 D.1（線性）更弱：只對 d^{π_β}(s) 下的期望成立，不是逐狀態。
5. **「2–5 倍」**。摘要與 §7 寫 2-5x；§6 Gym 段落寫「sometimes as much as 2-3x」；Adroit 段落寫 2-9x；Atari 寫 36x 與 6x。這些倍數都來自特定任務。論文自己說單一策略資料集上 CQL 只是「roughly matches or exceeds … by a small margin」。

## 4. 哪些能在瀏覽器現場示範

### 可以（封閉式或小型數值計算）

1. **單狀態 bandit 的式 11 與式 13**（γ = 0）。Q̂(a) = r(a) − α·μ(a)/π_β(a) 對 Q̂(a) = r(a) − α[μ(a)/π_β(a) − 1]。滑桿：π_β、π、α。同時顯示逐動作的 Q̂ − Q 與 E_π[Q̂] − V。可直接看到式 2 有的動作被抬高、但 π 下的期望仍低。用 2.2 的數值例當預設值。
2. **D_CQL 的恆等式**。Σ_a π(π/π_β − 1) 與 Σ_a (π − π_β)²/π_β 兩種算法並排，拖動 π 看它們永遠相等且 ≥ 0，π = π_β 時為 0。
3. **小型表格 MDP 的不動點**（例如 3 狀態 2 動作）。用式 11／式 13 迭代或直接解 (I−γP^π)^{-1}。驗證 V̂^π = V^π − α(I−γP^π)^{-1}D_CQL，以及式 1 與式 2 的 V 差 α/(1−γ)〔顧問推導，見 2.2〕。MDP 的數字要自己設，論文沒有給例子，必須標明是教學用的自訂例子。
4. **log-sum-exp 是 soft-max**。給幾個 Q 值，顯示 μ* = softmax(Q)、E_{μ*}[Q] + H(μ*) 與 log Σ exp(Q) 相等；再顯示 max_a Q ≤ log Σ exp(Q) ≤ max_a Q + log|A|〔顧問推導：標準不等式〕。
5. **bandit 上的 CQL(H) 不動點**。〔顧問推導〕γ = 0 時式 4 的駐點條件是 Q(a) = r(a) − α[softmax(Q)(a)/π_β(a) − 1]，是隱式方程；目標對 Q 是凸的，用梯度下降幾十步就收斂。可示範「π_β 很少選的動作被壓得最低」。
6. **gap-expanding 的一步**。E_{π_β}[懲罰] = 0 與 E_μ[懲罰] = α·Δ̂ ≥ 0 並排，差距增加 α·Δ̂。
7. **定理 D.3 的必要性**。固定 π_β，讓使用者選 ν；程式算 π* = ½ν + ½π_β（式 22）與懲罰值。〔顧問推導〕代入式 23 得懲罰 = ¼(1 − Σ_a ν²/π_β) = −¼χ²(ν‖π_β) ≤ 0，ν ≠ π_β 時嚴格為負，下界被破壞。
8. **取樣誤差與 α 的關係**。bandit 加隨機獎勵，用 n 個樣本估 r̄，重複多次，畫 Q̂ > Q 的比例對 α 與 n 的圖。只能定性呈現「樣本越多，所需 α 越小」與 1/√n 的趨勢；C_{r,T,δ} 的數值論文沒有給，不能宣稱重現門檻。
9. **Lagrange α（式 30）**。在 bandit 上對 α 做對偶梯度上升：差距 > τ 時 α 上升，< τ 時 α 降到 0。可示範 τ 太小時 α 爆大。只是機制示意。
10. **定理 3.6 的 ζ 兩項拉鋸**。給定常數後畫第一項（∝ 1/√|D(s)|）與第二項（∝ α·D_CQL）隨 |D(s)| 與 α 的變化。常數要自訂並標明。

### 不可以

- **表 1、表 2（D4RL）、表 3 與圖 1（Atari）**：需要 MuJoCo／Atari 模擬器、百萬筆資料、1M 梯度步的深度網路訓練。只能引用數字。
- **表 4（下界的實驗驗證）與圖 2（Δ̂^k 曲線）**：依賴神經網路的泛化誤差。OOD 動作被高估在論文中是函數近似造成的現象，表格式玩具不會自然出現；附錄 B 也說這個行為在沒有函數近似時不存在。可以用線性特徵的小例子「人為」造出高估，但那不是論文的結果，必須標明。
- **定理 D.2（NTK）**：無限寬度極限下的線性化，沒有可在瀏覽器驗證的有限計算；而且定理敘述本身缺條件式。
- **表 5–7 的消融**：同樣需要完整訓練。

## 5. 初學者的先備知識（教學順序）

1. 機率基礎：期望值、條件分佈、兩個分佈的比值 π/π_β、分佈的支撐（support）。
2. MDP：狀態、動作、轉移 T(s'|s,a)、獎勵、折扣 γ、策略 π(a|s)、折扣回報。
3. V^π 與 Q^π 的定義，V^π(s) = E_{a∼π}[Q^π(s,a)]。這是「逐點下界」對「期望下界」區別的基礎。
4. Bellman 算子 B^π Q = r + γP^π Q 與 B*；不動點；矩陣形式 Q^π = (I−γP^π)^{-1}r；(I−γP^π)^{-1} = Σ_t γ^t (P^π)^t 所以元素非負。
5. 策略評估與策略改進交替；Q-learning 與 actor-critic 的差別；SAC 與 DQN 只需知道是兩個現成基底。
6. 用平方 Bellman 誤差訓練 Q；表格式下對每一格微分設 0 的作法。這是式 11、13 的來源。
7. 離線 RL 與線上 RL 的差別；行為策略；OOD 動作；為什麼 bootstrapping 加上最大化會造成高估。
8. 經驗 Bellman 算子與取樣誤差；計數 |D(s,a)|；1/√n 型的集中不等式（只需直覺）。
9. 下界與「保守」的意思；為什麼低估比高估安全。
10. 熵、KL 散度、帶限制最佳化的 Lagrange 乘子；log-sum-exp 是 max 的平滑版本；softmax／Boltzmann 分佈。
11. 卡方型散度 Σ(π − π_β)²/π_β（論文不叫這個名字，但 D_CQL 就是它）；total variation 距離。
12. 重要性取樣（只為了理解連續動作下 log-sum-exp 的估計）。
13. （進階，可略）安全策略改進的概念、經驗 MDP M̂；線性函數近似與投影；NTK。
14. 讀實驗前：D4RL 正規化分數的意義、資料集類型（random／medium／expert／mixed／medium-expert／random-expert）、BC、BEAR、BRAC 是什麼類型的 baseline（策略限制法）。
