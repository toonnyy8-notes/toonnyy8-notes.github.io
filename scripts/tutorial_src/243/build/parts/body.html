    Titans：在測試時學習記憶

    這篇論文把長期記憶做成一個在測試時以梯度下降更新的 MLP，再與注意力、持久記憶組成三種架構。

    測試時＝模型訓練完成、部署後處理新序列的時候；此時記憶模組的權重仍在更新。

    Ali Behrouz、Peilin Zhong、Vahab Mirrokni（Google Research，2024）〈Titans: Learning to Memorize at Test Time〉。本頁依 arXiv v1。

    持久記憶（S6） 注意力視窗（S7） 長期記憶（S2–S5）
    01 · 記憶是網路

    長期記憶是一個小型神經網路。每讀到一個新 token，它就做一步梯度下降，讓這個 token 的索引向量（key）能取回對應的內容向量（value）；部署後處理新序列時也照做。

    02 · 驚訝度

    梯度越大，表示新 token 與已記住的內容越不同。作者稱之為驚訝度，並加上動量（延續過去的驚訝度）與遺忘閘（衰減舊內容）。

    03 · 三種架構

    Titans 把這個記憶與注意力、持久記憶組合成三種架構。760M 參數時，三者在 Wikipedia 文字上的 perplexity（困惑度，越低越好）為 18.61–19.93，Transformer++ 為 25.21。

    01 · 寫入與讀取

    序列模型都有寫入與讀取兩個步驟

    注意力（attention）的輸入是 $N$ 個 token 向量，輸出是同樣 $N$ 個向量。第 $i$ 個輸出是前面各 token 內容的加權平均，權重由 token 之間的相似度決定；softmax 把一列分數轉成總和為 1 的正權重。

    每個 token 經三個投影矩陣得到三個向量：query（我要找什麼）、key（我可以被什麼找到）、value（被找到時交出的內容）。第 $i$ 個 token 的 query 與第 $j$ 個 token 的 key 做內積，決定第 $i$ 個輸出給第 $j$ 個 token 多少權重。論文寫成（Sec. 2.1）：

    $$Q=xW_Q,\ K=xW_K,\ V=xW_V,\qquad y_i=\sum_{j=1}^{i}\frac{\exp(Q_i^\top K_j/\sqrt{d_{in}})\,V_j}{\sum_{\ell=1}^{i}\exp(Q_i^\top K_\ell/\sqrt{d_{in}})}$$
    Eq. 1–2

    第 $i$ 個輸出要與前面全部 $i$ 個 token 比較，整段序列的成本與長度 $N$ 的平方成正比，因此實務上只能處理固定長度的視窗。線性注意力（linear attention）把 softmax 換成可分解的核函數；核取單位矩陣時（RetNet），可以寫成遞迴（Eq. 4–5）：

    $$\mathcal M_t=\mathcal M_{t-1}+K_t^\top V_t,\qquad y_t=Q_t\mathcal M_t$$
    Eq. 4–5
    線性注意力的一般形式（Eq. 3）

    把 softmax 換成核函數 $\phi$，並要求 $\phi(x,y)=\phi(x)\phi(y)$：

    $$y_i=\sum_{j=1}^{i}\frac{\phi(Q_i)^\top\phi(K_j)}{\sum_{\ell=1}^{i}\phi(Q_i)^\top\phi(K_\ell)}V_j=\frac{\phi(Q_i)^\top\sum_{j=1}^{i}\phi(K_j)V_j}{\phi(Q_i)^\top\sum_{\ell=1}^{i}\phi(K_\ell)}$$
    Eq. 3

    兩個累加和在每一步都可以沿用上一步的結果，所以吞吐量較高；核取單位矩陣即得 Eq. 4–5。

    線性注意力的記憶 $\mathcal M_t$ 是一個固定大小的矩陣：每讀一個 token，把 $K_t^\top V_t$ 加進去，這是寫入；輸出時用 $Q_t$ 乘上它，這是讀取。整段歷史被壓縮進固定大小的矩陣，每一步的成本與序列長度無關。作者把一般的遞迴模型寫成兩個函數（Eq. 6–7）：

    $$\mathcal M_t=f(\mathcal M_{t-1},x_t)\ \ (\text{寫入}),\qquad y_t=g(\mathcal M_t,x_t)\ \ (\text{讀取})$$
    Eq. 6–7

    原文 Eq. 7 下方一句寫成「f is the read and g is the write」，與方程式旁的標籤相反。本頁依方程式標籤：$f$ 是寫入，$g$ 是讀取。

    從這個角度看，Transformer 的記憶是持續變長的 key／value 快取：它把每個 token 的 key 與 value 直接附加到記憶、不壓縮，所以讀取精確，但成本隨長度成長。作者的觀察是，Eq. 4 的寫入只做加法，長上下文會使固定大小的記憶溢出（memory overflow）。既有的改進分成兩個方向：加入遺忘閘（GLA、LRU、Griffin、xLSTM、Mamba2），或改進寫入方式（delta rule：寫入前先移除該 key 的舊值，例如 DeltaNet、Gated DeltaNet）。

    02 · 驚訝度

    記憶以梯度學習 key 到 value 的對應

    作者認為，直接訓練一個網路記住訓練資料會限制泛化、帶來隱私問題，而且測試資料可能在訓練分布之外。因此需要一個在測試時學習如何記住與遺忘的線上模型。作者把訓練長期記憶視為線上學習：把 $x_1,\dots,x_{t-1}$ 壓縮進 $\mathcal M_t$ 的參數。最簡單的寫入是一步梯度下降（Sec. 3.1）：

    $$\mathcal M_t=\mathcal M_{t-1}-\theta_t\underbrace{\nabla\ell(\mathcal M_{t-1};x_t)}_{\text{Surprise}}$$
    Eq. 8

    論文把這個梯度稱為驚訝度（surprise）。要注意它是對什麼求梯度：原文文字寫「its gradient with respect to the input」，但 Eq. 8 用這個梯度更新 $\mathcal M$ 的參數，所以它必須是損失對記憶參數的梯度。兩者不同，更新式只能用前者。梯度越大，表示 $x_t$ 與過去的資料（記憶已存的內容）差異越大。作者以神經心理學文獻為動機：違反預期的事件比較容易被記住。

    損失 $\ell$ 是聯想記憶（associative memory）損失。每個 token 投影出 key 與 value，記憶要學會從 key 取回 value（Eq. 11–12）：

    $$k_t=x_tW_K,\quad v_t=x_tW_V,\qquad \ell(\mathcal M_{t-1};x_t)=\|\mathcal M_{t-1}(k_t)-v_t\|_2^2$$
    Eq. 11–12

    因此 Eq. 8 的驚訝度就是聯想記憶損失 $\ell(\mathcal M_{t-1};x_t)$ 對記憶參數的梯度。這裡有兩層迴圈。內層迴圈最佳化記憶 $\mathcal M$ 的權重，以 $\|\mathcal M_{t-1}(k_t)-v_t\|_2^2$ 在測試時逐 token 更新；外層迴圈最佳化整個架構的其他參數，包括 $W_K,W_V$。在內層損失中，$W_K,W_V$ 是固定的超參數；作者以 meta-learning 類比這個結構。

    檢查理解

    Eq. 8 的驚訝度是什麼？是對什麼求梯度？

    聯想記憶損失 $\ell(\mathcal M_{t-1};x_t)$ 的梯度，對記憶參數求梯度（更新式需要它）；梯度越大表示輸入與過去的資料差異越大（Eq. 8）。

    內層迴圈與外層迴圈各更新哪些參數？

    內層：記憶 $\mathcal M$ 的權重，以 $\|\mathcal M_{t-1}(k_t)-v_t\|_2^2$ 在測試時更新；外層：整個架構的其他參數（含 $W_K,W_V$，在內層損失中是超參數）（Eq. 11–12）。

    03 · 動量與遺忘

    動量延續驚訝度，遺忘閘清除舊內容

    3a　動量

    作者指出 Eq. 8 的一個問題：一次很大的驚訝之後，梯度可能變得很小，使更新停在平坦區域，錯過後續的資訊。因此加入過去的驚訝度（Sec. 3.1）：

    $$\begin{aligned}\mathcal M_t&=\mathcal M_{t-1}+S_t,\\ S_t&=\eta_t\underbrace{S_{t-1}}_{\text{past}}-\theta_t\underbrace{\nabla\ell(\mathcal M_{t-1};x_t)}_{\text{momentary}}\end{aligned}$$
    Eq. 9–10

    這個形式與帶動量的梯度下降相同，作者稱 $S_t$ 為跨序列長度的驚訝度記憶：$S_t=\eta_tS_{t-1}-\theta_t\nabla\ell$ 讓驚訝度延續到後續的 token。$\eta_t$ 與 $\theta_t$ 都依資料而定：$\eta_t\to0$ 時忽略上一次驚訝（例如語境改變），$\eta_t\to1$ 時完全納入上一次驚訝（token 與最近的過去高度相關）；$\theta_t$ 是當下驚訝度的權重，也就是學習率。論文沒有寫出三個係數如何由 $x_t$ 計算，只說它們依 token 而定、在外層迴圈學習；本頁元件用常數。常數 $\eta$ 下，持續同方向的梯度會累積成 $\theta/(1-\eta)$ 倍的步長，這一點在 C1 中很重要。

    3b　遺忘

    記憶的容量有限，長序列中需要清除不再需要的內容。作者加入遺忘閘 $\alpha_t\in[0,1]$（Sec. 3.1）：

    $$\mathcal M_t=(1-\alpha_t)\mathcal M_{t-1}+S_t,\qquad S_t=\eta_tS_{t-1}-\theta_t\nabla\ell(\mathcal M_{t-1};x_t)$$
    Eq. 13–14

    $\alpha_t\to0$ 時更新不影響過去的內容；$\alpha_t\to1$ 時清空整個記憶。作者指出遺忘閘等同 weight decay，並與現代 RNN 的閘控機制密切相關（Mamba2、LRU）。

    本頁推導取線性記憶 $\mathcal M_t=W_t$、損失取 $\tfrac12\|\cdot\|^2$（與 App. C 相同），把 Eq. 13–14 展開到每一個 token：$e_t=\mathcal M_{t-1}k_t-v_t$，$g_t=e_tk_t^\top$，$S_t=\eta S_{t-1}-\theta g_t$，$\mathcal M_t=(1-\alpha)\mathcal M_{t-1}+S_t$。$\|k_t\|=1$ 時驚訝度大小 $\|g_t\|_F=\|e_t\|$（$\|\cdot\|_F$ 為 Frobenius 範數）。下面的 C1 就是這個演算法。

    檢查理解

    為什麼要加入過去的驚訝度 $S_{t-1}$？$\eta_t\to0$ 代表什麼？

    大驚訝之後梯度可能變小，使更新停在平坦區域而錯過後續資訊；$S_t=\eta_tS_{t-1}-\theta_t\nabla\ell$ 讓驚訝度延續；$\eta_t\to0$ 忽略上一次驚訝（例如語境改變）（Eq. 9–10）。

    Eq. 13 中 $\alpha_t\to0$ 與 $\alpha_t\to1$ 各代表什麼？它等同什麼？

    $\alpha_t\to0$ 不影響過去的內容；$\alpha_t\to1$ 清空記憶；等同 weight decay，與現代 RNN 的閘控相關（Eq. 13–14）。

    在 C1 預設情境（seed 11）中，動量與遺忘各帶來什麼可觀察的效果？為什麼要和「θ = 0.75、η = 0」比較？

    動量使驚訝度下降後 $\|S_t\|$ 仍延續（$\|S_{40}\|$：η = 0.6 為 0.152，η = 0 為 0.092）。$E_B(64)$ 由 0.025（η = 0）降到 0.008（η = 0.6），但常數 η 的有效步長是 θ/(1−η) = 0.75，θ = 0.75、η = 0 也降到 0.011；seed 11–30 中位數 0.0087 對 0.0083，所以誤差下降大多來自步長放大。遺忘（θ = 0.3、η = 0.6）使 $E_A(64)$ 變大（α = 0：0.387；0.02：0.457；0.1：0.582），代價是保留較少。

    04 · 深層記憶

    深層記憶能存下非線性的對應

    Q1 問記憶的結構。作者的論點（Sec. 3.1）：以矩陣 $\mathcal M=W\in\mathbb R^{d_{in}\times d_{in}}$ 為記憶，等價於最佳化 $\|W_{t-1}k_t-v_t\|_2^2$，這是線上線性迴歸；它的最佳解假設歷史資料中 key 與 value 的依賴關係是線性的。至少兩層的 MLP 比線性模型更有表達力（Hornik et al. 1989），所以作者把記憶設計成 $L_{\mathcal M}\ge1$ 層的 MLP，$L_{\mathcal M}=1$ 即矩陣記憶。

    Q3 問讀取方式。讀取是不更新權重的前向傳遞（Eq. 15）：

    $$q_t=x_tW_Q,\qquad y_t=\mathcal M^*(q_t)$$
    Eq. 15

    05 · chunk 平行化

    把序列切成 chunk 就能用矩陣乘法訓練

    逐 token 更新必須依序做 $N$ 步，無法充分利用 GPU／TPU 的矩陣運算。作者沿用 TTT 的做法（Sec. 3.2）：把序列切成大小 $b\ge1$ 的 chunk，chunk 內所有梯度都在 chunk 起點的記憶 $\mathcal M_{t'}$ 上計算，等同 mini-batch 梯度下降。先看不含動量的情形：

    $$\begin{aligned}\mathcal M_t&=(1-\alpha_t)\mathcal M_{t-1}-\theta_t\nabla\ell(\mathcal M_{t-1};x_t)\\&=\beta_t\mathcal M_0-\sum_{i=1}^{t}\theta_i\frac{\beta_t}{\beta_i}\nabla\ell(\mathcal M_{t'};x_i)\end{aligned}$$
    Eq. 16

    其中 $\beta_i=\prod_{j=1}^{i}(1-\alpha_j)$。論文把 $t'$ 印成 $t-\mathrm{mod}(t,b)$，但下一句說第一個 chunk 的 $t=b$、所以 $t'=0$；照公式 $t=b$ 時 $t'=b$，而且 $b=1$ 時梯度會在更新後的 $\mathcal M_t$ 上計算。本頁依論文文字，把 $t'$ 讀成 chunk 的起點 $t'=t-1-\mathrm{mod}(t-1,b)$本頁推導。在這個讀法下，$b=1$ 時 $\mathcal M_{t'}=\mathcal M_{t-1}$，與逐 token 更新完全相同。另外，第二個等號只在單一 chunk 內成立：跨 chunk 時，第 $i$ 項的梯度點是 $i$ 所在 chunk 的起點，不是同一個 $\mathcal M_{t'}$，這也是論文只寫第一個 chunk 的原因。

    對線性記憶 $\mathcal M_t=W_t$，第一個 chunk 內的梯度加權和可以寫成一次矩陣乘法（Eq. 17）。論文的寫法把 key 與 value 都寫成 $x$，並省略 $\|\cdot\|^2$ 求導的係數 2。一般形式如下（損失取 $\tfrac12\|\cdot\|^2$，$K=[k_1\cdots k_b]$、$V=[v_1\cdots v_b]$ 為行向量排成的矩陣，$c_i=\theta_i\beta_b/\beta_i$）本頁推導：

    $$\sum_{i=1}^{b}c_i\nabla\ell(W_0;x_i)=(W_0K-V)\,\mathrm{diag}(c)\,K^\top$$
    Eq. 17（一般形式）

    每個 chunk 只需存自己的係數。動量也能平行（Eq. 18）：

    $$S_t=\eta_tS_{t-1}-\theta_t u_t,\qquad u_t=\nabla\ell(\mathcal M_{t'};x_t)$$
    Eq. 18

    所有 $u_t$ 都在 $\mathcal M_{t'}$ 上計算，可以同時算出；Eq. 18 因此是以 $u_t$ 為輸入、$\eta_t$ 為轉移值的線性遞迴，可以用平行 associative scan 計算。associative scan 的意思是本頁推導：$S_t=\eta_tS_{t-1}+x_t$ 這種線性遞迴的每一步都可寫成一對 $(\eta_t,x_t)$；兩個相鄰步驟可以先合併成一步 $(\eta_2\eta_1,\ \eta_2x_1+x_2)$，而且合併的順序不影響結果。因此可以像比賽淘汰表一樣兩兩合併，$N$ 步只需約 $\log_2N$ 輪平行運算。

    把動量與遺忘一起寫成矩陣乘法（常數 $\alpha,\eta,\theta$，chunk 內有 $n$ 個 token，索引 $l,m=1,\dots,n$，約定 $0^0=1$）本頁推導：

    $$\begin{aligned}\mathcal M_{\text{end}}&=(1-\alpha)^n\mathcal M_{t'}+c_S\,S_{t'}-\theta\,E\,\mathrm{diag}(w)\,K^\top,\\ S_{\text{end}}&=\eta^nS_{t'}+E\,\mathrm{diag}(q)\,K^\top\end{aligned}$$
    本頁推導

    其中 $E=\mathcal M_{t'}K-V$，$w_l=\sum_{m=l}^{n}(1-\alpha)^{n-m}\eta^{m-l}$，$c_S=\sum_{m=1}^{n}(1-\alpha)^{n-m}\eta^{m}$，$q_l=-\theta\eta^{n-l}$。$\eta=0$ 時 $w_l=(1-\alpha)^{n-l}=\beta_n/\beta_l$，$q_l$ 只剩 $l=n$ 一項，回到 Eq. 16–17。

    數值上要注意本頁推導：Eq. 16 的 $\beta_t/\beta_i$ 若照字面先算 $\beta$ 再相除，$\alpha_j=1$ 時 $\beta_i=0$ 會得到 0/0，$\alpha$ 接近 1 時連乘會下溢；應直接以 $\prod_{j=i+1}^{t}(1-\alpha_j)$ 計算比值。實驗中 $\alpha,\theta,\eta$ 依 token 而定；論文 v1 沒有寫實驗用的 chunk 大小 $b$。

    進階：chunk 內參數為常數時

    若 $\alpha,\theta,\eta$ 在一個 chunk 內為常數，Eq. 17 的 $\Theta$ 只需一個純量，Eq. 18 變成線性非時變系統（LTI），可以用全域卷積計算（Sec. 3.2 末段）。作者把依 chunk 而定的參數留作未來工作。

    06 · 持久記憶

    持久記憶是放在序列開頭的可學習參數

    長期記憶是情境記憶：它的內容完全由輸入決定。作者認為還需要一組可學習、但不依賴輸入的參數，用來儲存任務本身的知識。做法是把 $N_p$ 個可學習向量接在序列前面（Sec. 3.3）：

    $$x_{new}=[p_1\ p_2\ \cdots\ p_{N_p}]\ \|\ x$$
    Eq. 19

    作者給三個動機：

    1. 記憶觀點：掌握一個任務需要記住「如何做」這個任務；持久記憶用來儲存任務知識，這部分不依賴當下的輸入。
    2. 前饋網路觀點：Sukhbaatar et al.（2019）指出，把 FFN 的 ReLU 換成 Softmax，會得到類似注意力、但權重不依賴資料的形式（Eq. 20）。持久記憶放在序列開頭，會產生不依賴資料的注意力權重。
    3. 技術觀點：因果遮罩的注意力偏向序列最前面的 token；在開頭放可學習參數可以重新分配注意力權重，緩解因果注意力偏向開頭 token 的現象（Han et al. 2024；Xiao et al. 2024）。
    $$FFN(x)=W_V\,\mathrm{Softmax}(W_Kx)$$
    Eq. 20

    測試時持久記憶的參數固定、不更新，只有長期記憶在測試時持續學習（Sec. 4.1）。在下一節的三種架構中，持久記憶都接在序列開頭，但進入注意力的方式不同。

    檢查理解

    07 · 三種架構

    Titans 以三種方式結合記憶與注意力

    作者把注意力解讀為短期記憶：依賴關係精確，但視窗有限；神經記憶則是長期記憶。Sec. 4 回答 Q4，給出三種組合方式。

    MAC：記憶作為上下文

    MAC（Memory as a Context）把序列切成長度 $C$ 的片段 $S^{(i)}$。處理一個片段時，先用片段的 query 從記憶讀出歷史資訊 $h_t=\mathcal M^*_{t-1}(q_t)$，把持久記憶與 $h_t$ 接在片段前，做片段內注意力，再以注意力輸出 $y_t$ 更新記憶：

    $$\begin{aligned}h_t&=\mathcal M^*_{t-1}(q_t),\quad q_t=S^{(t)}W_Q\\ \tilde S^{(t)}&=[p_1\cdots p_{N_p}]\ \|\ h_t\ \|\ S^{(t)},\quad y_t=\mathrm{Attn}(\tilde S^{(t)})\\ \mathcal M_t&=\mathcal M_{t-1}(y_t),\quad o_t=y_t\otimes\mathcal M^*_t(y_t)\end{aligned}$$
    Eq. 21–25

    片段內是完整因果注意力（Fig. 3a）；Eq. 24 表示以 $y_t$ 經前向傳遞更新記憶。作者列出三個優點：注意力同時看到歷史與當前，可以決定是否需要長期記憶的資訊；注意力幫助記憶只存有用的資訊；測試時持久記憶固定、注意力權重做 in-context learning、長期記憶持續學習。

    MAG：記憶作為閘控分支

    MAG（Memory as Gating）不切片段。一支以輸入更新記憶，另一支用帶前綴的滑動視窗注意力 SW-Attn$^*$，兩支以非線性閘控 $\otimes$ 結合（Sec. 4.2）：

    $$\tilde x=[p_1\cdots p_{N_p}]\ \|\ x,\qquad y=\text{SW-Attn}^*(\tilde x),\qquad o=y\otimes\mathcal M(\tilde x)$$
    Eq. 26–28

    $\mathcal M(\tilde x)$ 是對序列遞迴後記憶的輸出。實驗中以可學習的向量權重分別正規化 $y$ 與 $\mathcal M(\tilde x)$，再接非線性 $\sigma(\cdot)$；論文沒有寫 $\sigma$ 的形式。作者稱滑動視窗注意力為精確的短期記憶，神經記憶為逐漸淡去的記憶（fading memory）。

    MAL：記憶作為一層

    MAL（Memory as a Layer）在記憶層之後接滑動視窗注意力（Sec. 4.3）：

    $$\tilde x=[p_1\cdots p_{N_p}]\ \|\ x,\qquad y=\mathcal M(\tilde x),\qquad o=\text{SW-Attn}(y)$$
    Eq. 29–31

    Eq. 31 是不帶前綴的 SW-Attn，Eq. 27 是帶前綴的 SW-Attn$^*$；依方程式，MAL 的持久記憶只能經由記憶層進入注意力。文獻中常見的混合模型都是這種逐層堆疊；作者指出其缺點是模型能力受限於每一層，無法利用注意力與記憶的互補。把 LMM 單獨當作序列模型（沒有注意力）是 MAL 的特例，論文記為 Titans (LMM)。

    LMM 推廣了 DeltaNet、Longhorn 與 TTT

    App. C 取線性記憶 $\mathcal M_t=W_t$、損失 $\tfrac12\|\mathcal M_tk_t-v_t\|_2^2$，把 LMM 寫成（Eq. 32–33，轉置依本頁「行向量 key、$\mathcal M k$」慣例統一）：

    $$\mathcal M_t=\mathrm{diag}(1-\alpha_t)\mathcal M_{t-1}+S_t,\qquad S_t=\mathrm{diag}(\eta_t)S_{t-1}-\mathrm{diag}(\theta_t)(\mathcal M_{t-1}k_t-v_t)k_t^\top$$
    Eq. 32–33

    原文 Eq. 32 右邊寫成 $\mathcal M_t$，應為 $\mathcal M_{t-1}$。DeltaNet 可以視為最佳化 $\tfrac12\|S_tk_t-v_t\|_2^2$ 的線上學習（Eq. 34）：

    $$S_{t+1}=S_t-\theta_t\nabla L=S_t\big(I-\theta_tk_tk_t^\top\big)+\theta_tv_tk_t^\top$$
    Eq. 34

    Gated DeltaNet 是 Eq. 34 再加 weight decay。論文寫，令 $\eta_t=0$ 時兩者等價（App. C）。本頁能從論文自己的方程式驗證的是本頁推導：Eq. 13–14 取 $\eta=0$ 得 $\mathcal M_t=\mathcal M_{t-1}\big((1-\alpha_t)I-\theta_tk_tk_t^\top\big)+\theta_tv_tk_t^\top$；再取 $\alpha_t=0$ 即 Eq. 34，也就是 η = 0、α = 0 時即 DeltaNet。本論文沒有寫出 Gated DeltaNet 的遞迴式，所以本頁只能說：上式與 Gated DeltaNet 的更新規則形式相近，細節（衰減是否也作用在修正項）需查原論文。

    作者列出 LMM 推廣 Gated DeltaNet 的三點：(1) 動量規則，同時考慮過去與當下的驚訝度；(2) 深層記憶，Gated DeltaNet 需要閉式遞迴，只能用矩陣記憶；(3) 非線性遞迴：chunk 之間非線性、chunk 內線性。作者說 RWKV-7 也用同樣的形式與損失。

    Longhorn 以隱式線上學習推得（Eq. 35），但缺少遺忘閘：

    $$S_{t+1}=S_t\big(I-\delta_tk_tk_t^\top\big)+\delta_tv_tk_t^\top,\qquad \delta_t=\frac{\theta_t}{1+\theta_tk_tk_t^\top}$$
    Eq. 35

    TTT layer 與 LMM 有三個差異：TTT 沒有遺忘機制；TTT 只用當下驚訝度，沒有動量；TTT 允許深層記憶，但沒有以實驗評估深層記憶的利弊。作者宣稱 LMM 是第一個使用動量更新規則的線性遞迴模型。App. A.1 把線性遞迴模型分成三代：第一代是資料無關的衰減，第二代加入閘控，第三代以線上學習或 delta rule 更新。App. A 另稱 Titans (MAC) 是 RMT 的推廣，以神經記憶取代小型向量記憶。

    架構細節見 S7 的 Sec. 4.4 清單。以下是閱讀與復現時容易出錯的地方：

    1. 把驚訝度當成對輸入的梯度：更新式需要損失對記憶參數的梯度（S2）。
    2. 把 Eq. 7 下方的 read／write 文字當真：$f$ 是寫入、$g$ 是讀取（S1）。
    3. 忘記 chunk 內的梯度都在 $\mathcal M_{t'}$ 計算：$b>1$ 時結果與逐 token 更新不同，$b=1$ 才相同（S5、C3）。
    4. 以 $\beta_t/\beta_i$ 相除計算衰減權重：$\alpha=1$ 時得到 0/0，應直接連乘（S5）。
    5. Eq. 17 的 $(W_0x_t-x_t)x_t^\top$ 是 key = value = $x$ 的簡寫；一般情形是 $(W_0k_t-v_t)k_t^\top$，係數 2 取決於損失是否乘 ½（S5）。
    6. MAC 與 MAG／MAL 的注意力範圍不同：MAC 是片段內完整因果注意力＋記憶 token＋持久記憶；MAG 是帶前綴的 SWA；MAL 是不帶前綴的 SWA（S7、C4）。
    7. Eq. 32 右邊的 $\mathcal M_t$ 應為 $\mathcal M_{t-1}$（S8）。
    8. 論文 v1 未說明：chunk 大小、記憶 MLP 寬度、$\eta_t,\theta_t,\alpha_t$ 的參數化、片段長度 $C$、視窗大小、$N_p$、$N_l$、閘控非線性 $\sigma$ 的形式。復現時這些都要自行決定。
    9. 照字面使用 Eq. 16 的 $t'=t-\mathrm{mod}(t,b)$：$t=b$ 時得到 $b$ 而非 0，$b=1$ 時梯度會在更新後的 $\mathcal M_t$ 上計算；應取 chunk 起點 $t'=t-1-\mathrm{mod}(t-1,b)$（S5）。
