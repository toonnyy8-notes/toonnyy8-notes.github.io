 Titans：在測試時學習記憶

 這篇論文把長期記憶做成一個在測試時以梯度下降更新的 MLP，再與注意力、持久記憶組成三種架構。

 測試時＝模型訓練完成、部署後處理新序列的時候；此時記憶模組的權重仍在更新。

 Ali Behrouz、Peilin Zhong、Vahab Mirrokni（Google Research，2024）〈Titans: Learning to Memorize at Test Time〉。本頁依 arXiv v1。

 持久記憶（S6）
 注意力視窗（S7）
 長期記憶（S2–S5）

 01 · 記憶是網路長期記憶是一個小型神經網路。每讀到一個新 token，它就做一步梯度下降，讓這個 token 的索引向量（key）能取回對應的內容向量（value）；部署後處理新序列時也照做。

 02 · 驚訝度梯度越大，表示新 token 與已記住的內容越不同。作者稱之為驚訝度，並加上動量（延續過去的驚訝度）與遺忘閘（衰減舊內容）。

 03 · 三種架構Titans 把這個記憶與注意力、持久記憶組合成三種架構。760M 參數時，三者在 Wikipedia 文字上的 perplexity（困惑度，越低越好）為 18.61–19.93，Transformer++ 為 25.21。

 01 · 寫入與讀取

 序列模型都有寫入與讀取兩個步驟

 注意力（attention）的輸入是 N $N$ 個 token 向量，輸出是同樣 N $N$ 個向量。第 i $i$ 個輸出是前面各 token 內容的加權平均，權重由 token 之間的相似度決定；softmax 把一列分數轉成總和為 1 的正權重。

 每個 token 經三個投影矩陣得到三個向量：query（我要找什麼）、key（我可以被什麼找到）、value（被找到時交出的內容）。第 i $i$ 個 token 的 query 與第 j $j$ 個 token 的 key 做內積，決定第 i $i$ 個輸出給第 j $j$ 個 token 多少權重。論文寫成（Sec. 2.1）：

 Q=xWQ, K=xWK, V=xWV,yi=∑j=1iexp⁡(Qi⊤Kj/din) Vj∑ℓ=1iexp⁡(Qi⊤Kℓ/din) $Q=xW_Q,\ K=xW_K,\ V=xW_V,\qquad y_i=\sum_{j=1}^{i}\frac{\exp(Q_i^\top K_j/\sqrt{d_{in}})\,V_j}{\sum_{\ell=1}^{i}\exp(Q_i^\top K_\ell/\sqrt{d_{in}})}$ ​, K=xWK​, V=xWV​,yi​=j=1∑i​∑ℓ=1i​exp(Qi⊤​Kℓ​/din​​)exp(Qi⊤​Kj​/din​​)Vj​​
Eq. 1–2

 第 i $i$ 個輸出要與前面全部 i $i$ 個 token 比較，整段序列的成本與長度 N $N$ 的平方成正比，因此實務上只能處理固定長度的視窗。線性注意力（linear attention）把 softmax 換成可分解的核函數；核取單位矩陣時（RetNet），可以寫成遞迴（Eq. 4–5）：

 Mt=Mt−1+Kt⊤Vt,yt=QtMt $\mathcal M_t=\mathcal M_{t-1}+K_t^\top V_t,\qquad y_t=Q_t\mathcal M_t$ ​=Mt−1​+Kt⊤​Vt​,yt​=Qt​Mt​
Eq. 4–5

 線性注意力的一般形式（Eq. 3）

 把 softmax 換成核函數 ϕ $\phi$ ，並要求 ϕ(x,y)=ϕ(x)ϕ(y) $\phi(x,y)=\phi(x)\phi(y)$ ：

 yi=∑j=1iϕ(Qi)⊤ϕ(Kj)∑ℓ=1iϕ(Qi)⊤ϕ(Kℓ)Vj=ϕ(Qi)⊤∑j=1iϕ(Kj)Vjϕ(Qi)⊤∑ℓ=1iϕ(Kℓ) $y_i=\sum_{j=1}^{i}\frac{\phi(Q_i)^\top\phi(K_j)}{\sum_{\ell=1}^{i}\phi(Q_i)^\top\phi(K_\ell)}V_j=\frac{\phi(Q_i)^\top\sum_{j=1}^{i}\phi(K_j)V_j}{\phi(Q_i)^\top\sum_{\ell=1}^{i}\phi(K_\ell)}$ ​=j=1∑i​∑ℓ=1i​ϕ(Qi​)⊤ϕ(Kℓ​)ϕ(Qi​)⊤ϕ(Kj​)​Vj​=ϕ(Qi​)⊤∑ℓ=1i​ϕ(Kℓ​)ϕ(Qi​)⊤∑j=1i​ϕ(Kj​)Vj​​
Eq. 3

 兩個累加和在每一步都可以沿用上一步的結果，所以吞吐量較高；核取單位矩陣即得 Eq. 4–5。

 線性注意力的記憶 Mt $\mathcal M_t$ ​ 是一個固定大小的矩陣：每讀一個 token，把 Kt⊤Vt $K_t^\top V_t$ ⊤​Vt​ 加進去，這是寫入；輸出時用 Qt $Q_t$ ​ 乘上它，這是讀取。整段歷史被壓縮進固定大小的矩陣，每一步的成本與序列長度無關。作者把一般的遞迴模型寫成兩個函數（Eq. 6–7）：

 Mt=f(Mt−1,xt)  (寫入),yt=g(Mt,xt)  (讀取) $\mathcal M_t=f(\mathcal M_{t-1},x_t)\ \ (\text{寫入}),\qquad y_t=g(\mathcal M_t,x_t)\ \ (\text{讀取})$ ​=f(Mt−1​,xt​)  (寫入),yt​=g(Mt​,xt​)  (讀取)
Eq. 6–7

 原文 Eq. 7 下方一句寫成「f is the read and g is the write」，與方程式旁的標籤相反。本頁依方程式標籤：f $f$ 是寫入，g $g$ 是讀取。

 從這個角度看，Transformer 的記憶是持續變長的 key／value 快取：它把每個 token 的 key 與 value 直接附加到記憶、不壓縮，所以讀取精確，但成本隨長度成長。作者的觀察是，Eq. 4 的寫入只做加法，長上下文會使固定大小的記憶溢出（memory overflow）。既有的改進分成兩個方向：加入遺忘閘（GLA、LRU、Griffin、xLSTM、Mamba2），或改進寫入方式（delta rule：寫入前先移除該 key 的舊值，例如 DeltaNet、Gated DeltaNet）。

 02 · 驚訝度

 記憶以梯度學習 key 到 value 的對應

 作者認為，直接訓練一個網路記住訓練資料會限制泛化、帶來隱私問題，而且測試資料可能在訓練分布之外。因此需要一個在測試時學習如何記住與遺忘的線上模型。作者把訓練長期記憶視為線上學習：把 x1,…,xt−1 $x_1,\dots,x_{t-1}$ ​,…,xt−1​ 壓縮進 Mt $\mathcal M_t$ ​ 的參數。最簡單的寫入是一步梯度下降（Sec. 3.1）：

 Mt=Mt−1−θt∇ℓ(Mt−1;xt)⏟Surprise $\mathcal M_t=\mathcal M_{t-1}-\theta_t\underbrace{\nabla\ell(\mathcal M_{t-1};x_t)}_{\text{Surprise}}$ ​=Mt−1​−θt​Surprise∇ℓ(Mt−1​;xt​)​​
Eq. 8

 論文把這個梯度稱為驚訝度（surprise）。要注意它是對什麼求梯度：原文文字寫「its gradient with respect to the input」，但 Eq. 8 用這個梯度更新 M $\mathcal M$ 的參數，所以它必須是損失對記憶參數的梯度。兩者不同，更新式只能用前者。梯度越大，表示 xt $x_t$ ​ 與過去的資料（記憶已存的內容）差異越大。作者以神經心理學文獻為動機：違反預期的事件比較容易被記住。

 損失 ℓ $\ell$ 是聯想記憶（associative memory）損失。每個 token 投影出 key 與 value，記憶要學會從 key 取回 value（Eq. 11–12）：

 kt=xtWK,vt=xtWV,ℓ(Mt−1;xt)=∥Mt−1(kt)−vt∥22 $k_t=x_tW_K,\quad v_t=x_tW_V,\qquad \ell(\mathcal M_{t-1};x_t)=\|\mathcal M_{t-1}(k_t)-v_t\|_2^2$ ​=xt​WK​,vt​=xt​WV​,ℓ(Mt−1​;xt​)=∥Mt−1​(kt​)−vt​∥22​
Eq. 11–12

 因此 Eq. 8 的驚訝度就是聯想記憶損失 ℓ(Mt−1;xt) $\ell(\mathcal M_{t-1};x_t)$ ​;xt​) 對記憶參數的梯度。這裡有兩層迴圈。內層迴圈最佳化記憶 M $\mathcal M$ 的權重，以 ∥Mt−1(kt)−vt∥22 $\|\mathcal M_{t-1}(k_t)-v_t\|_2^2$ ​(kt​)−vt​∥22​ 在測試時逐 token 更新；外層迴圈最佳化整個架構的其他參數，包括 WK,WV $W_K,W_V$ ​,WV​。在內層損失中，WK,WV $W_K,W_V$ ​,WV​ 是固定的超參數；作者以 meta-learning 類比這個結構。

 03 · 動量與遺忘

 動量延續驚訝度，遺忘閘清除舊內容

 3a　動量

 作者指出 Eq. 8 的一個問題：一次很大的驚訝之後，梯度可能變得很小，使更新停在平坦區域，錯過後續的資訊。因此加入過去的驚訝度（Sec. 3.1）：

 Mt=Mt−1+St,St=ηtSt−1⏟past−θt∇ℓ(Mt−1;xt)⏟momentary $\begin{aligned}\mathcal M_t&=\mathcal M_{t-1}+S_t,\\ S_t&=\eta_t\underbrace{S_{t-1}}_{\text{past}}-\theta_t\underbrace{\nabla\ell(\mathcal M_{t-1};x_t)}_{\text{momentary}}\end{aligned}$ ​St​​=Mt−1​+St​,=ηt​pastSt−1​​​−θt​momentary∇ℓ(Mt−1​;xt​)​​​
Eq. 9–10

 這個形式與帶動量的梯度下降相同，作者稱 St $S_t$ ​ 為跨序列長度的驚訝度記憶：St=ηtSt−1−θt∇ℓ $S_t=\eta_tS_{t-1}-\theta_t\nabla\ell$ ​=ηt​St−1​−θt​∇ℓ 讓驚訝度延續到後續的 token。ηt $\eta_t$ ​ 與 θt $\theta_t$ ​ 都依資料而定：ηt→0 $\eta_t\to0$ ​→0 時忽略上一次驚訝（例如語境改變），ηt→1 $\eta_t\to1$ ​→1 時完全納入上一次驚訝（token 與最近的過去高度相關）；θt $\theta_t$ ​ 是當下驚訝度的權重，也就是學習率。論文沒有寫出三個係數如何由 xt $x_t$ ​ 計算，只說它們依 token 而定、在外層迴圈學習；本頁元件用常數。常數 η $\eta$ 下，持續同方向的梯度會累積成 θ/(1−η) $\theta/(1-\eta)$ 倍的步長，這一點在 C1 中很重要。

 3b　遺忘

 記憶的容量有限，長序列中需要清除不再需要的內容。作者加入遺忘閘 αt∈[0,1] $\alpha_t\in[0,1]$ ​∈[0,1]（Sec. 3.1）：

 Mt=(1−αt)Mt−1+St,St=ηtSt−1−θt∇ℓ(Mt−1;xt) $\mathcal M_t=(1-\alpha_t)\mathcal M_{t-1}+S_t,\qquad S_t=\eta_tS_{t-1}-\theta_t\nabla\ell(\mathcal M_{t-1};x_t)$ ​=(1−αt​)Mt−1​+St​,St​=ηt​St−1​−θt​∇ℓ(Mt−1​;xt​)
Eq. 13–14

 MAG（Memory as Gating）不切片段。一支以輸入更新記憶，另一支用帶前綴的滑動視窗注意力 SW-Attn∗ $^*$ ，兩支以非線性閘控 ⊗ $\otimes$ 結合（Sec. 4.2）：

 x~=[p1⋯pNp] ∥ x,y=SW-Attn∗(x~),o=y⊗M(x~) $\tilde x=[p_1\cdots p_{N_p}]\ \|\ x,\qquad y=\text{SW-Attn}^*(\tilde x),\qquad o=y\otimes\mathcal M(\tilde x)$ =[p1​⋯pNp​​] ∥ x,y=SW-Attn∗(x~),o=y⊗M(x~)
Eq. 26–28

 M(x~) $\mathcal M(\tilde x)$ ) 是對序列遞迴後記憶的輸出。實驗中以可學習的向量權重分別正規化 y $y$ 與 M(x~) $\mathcal M(\tilde x)$ )，再接非線性 σ(⋅) $\sigma(\cdot)$ ；論文沒有寫 σ $\sigma$ 的形式。作者稱滑動視窗注意力為精確的短期記憶，神經記憶為逐漸淡去的記憶（fading memory）。

 MAL：記憶作為一層

 MAL（Memory as a Layer）在記憶層之後接滑動視窗注意力（Sec. 4.3）：

 x~=[p1⋯pNp] ∥ x,y=M(x~),o=SW-Attn(y) $\tilde x=[p_1\cdots p_{N_p}]\ \|\ x,\qquad y=\mathcal M(\tilde x),\qquad o=\text{SW-Attn}(y)$ =[p1​⋯pNp​​] ∥ x,y=M(x~),o=SW-Attn(y)
Eq. 29–31

 Eq. 31 是不帶前綴的 SW-Attn，Eq. 27 是帶前綴的 SW-Attn∗ $^*$ ；依方程式，MAL 的持久記憶只能經由記憶層進入注意力。文獻中常見的混合模型都是這種逐層堆疊；作者指出其缺點是模型能力受限於每一層，無法利用注意力與記憶的互補。把 LMM 單獨當作序列模型（沒有注意力）是 MAL 的特例，論文記為 Titans (LMM)。
