 Value Forcing：在每個 noise level 對齊回報分佈

 回報（return）是之後所有獎勵的折扣和。Flow matching 是一種生成模型：它學一個速度場，把 τ = 0 的高斯分佈逐步轉換成 τ = 1 的資料分佈，τ 稱為 noise level。Value Forcing 用它表示回報分佈，並在每個 τ 都要求 Bellman 一致性，方法是在 Bellman 方程中加一項高斯修正。論文據此提出兩個演算法：VF（explicit：另外有策略，從候選動作中挑 Q 最大者）與 IVF（implicit：不學策略，只用資料動作加權學 V）。

 Chongyi Zheng、Zhiyuan Zhou、Qiyang Li、Benjamin Eysenbach、Sergey Levine（2026）〈Value Forcing: Aligning Return Distributions at All Noise Levels〉

 01 · 問題γ 是折扣因子，N $N$ 是獨立標準高斯。乾淨的 Bellman 方程 Z=r+γZ′ $Z=r+\gamma Z'$ 在 τ = 0 不成立：兩側都應是標準高斯，但 γZ′ $\gamma Z'$ 的變異數只有 γ2 $\gamma^2$ 。Value Forcing 補上 (1−τ)1−γ2 N $(1-\tau)\sqrt{1-\gamma^2}\,N$ ​N。

 02 · 理論對每個 noise level，新算子都是係數 γ 的 contraction（每套用一次，兩個分佈的距離至少縮小為 γ 倍），因此每一層都有唯一不動點（Remark 1）。

 03 · 結果VF 是本文的 explicit 版本，IVF 是 implicit 版本。20 個 OGBench 任務、10% 資料：VF 總平均成功率 48%，最佳 explicit 基線 43%；IVF 43%，最佳 implicit 基線 27%（Table 2）。

 01 · 分布式 RL

 分布式 RL 把整個回報分佈當成 TD 目標

 強化學習的問題寫成無限期馬可夫決策過程 M=(S,A,p,r,ρ,γ) $\mathcal M=(\mathcal S,\mathcal A,p,r,\rho,\gamma)$ ：代理人在狀態 s $s$ 選動作 a $a$ ，得到確定且有界的獎勵 r(s,a)∈[rmin⁡,rmax⁡] $r(s,a)\in[r_{\min},r_{\max}]$ ​,rmax​]，環境依轉移分佈 p(s′∣s,a) $p(s'\mid s,a)$ ∣s,a) 進到下一個狀態 s′ $s'$ ；ρ $\rho$ 是初始狀態分佈，γ∈[0,1) $\gamma\in[0,1)$ 是折扣因子（Sec. 3）。t $t$ 表示 RL 的時間步。策略 π(a∣s) $\pi(a\mid s)$ 決定每個狀態下選哪個動作。本文處理 offline RL：只有一個由行為策略（behavior policy）πβ $\pi_\beta$ ​ 收集的固定資料集 D={(s,a,r,s′)} $\mathcal D=\{(s,a,r,s')\}$ )}，目標是學一個最大化 Eπ[∑tγtr(st,at)] $\mathbb E_\pi[\sum_t\gamma^tr(s_t,a_t)]$ ​[∑t​γtr(st​,at​)] 的策略。

 回報隨機變數定義為 Zπ(s,a)=∑t≥0γtr(St,At) $Z^\pi(s,a)=\sum_{t\ge0}\gamma^tr(S_t,A_t)$ (s,a)=∑t≥0​γtr(St​,At​)，其中 (St,At) $(S_t,A_t)$ ​,At​) 是第 t $t$ 步的狀態與動作隨機變數；它的期望是 Q 函數 Qπ(s,a)=E[Zπ(s,a)] $Q^\pi(s,a)=\mathbb E[Z^\pi(s,a)]$ (s,a)=E[Zπ(s,a)]。時間差分（temporal difference, TD）學習用「一步獎勵加上自己對下一步的估計」當回歸目標。作者的出發點是：每筆轉移只提供一個即時獎勵，沒有真實的期望回報，所以監督是有限而間接的；TD 用自己的估計當目標，可能有偏，資料少時沒有修正的機會（Sec. 1）。

 分布式 RL（distributional RL）改學整個回報分佈，而不只學期望。論文的例子：一個動作以相同機率得到 −1 與 +1，另一個動作恆得 0，兩者期望相同，分佈不同；學會區分它們可以更有效地使用資料（Sec. 1）。回報分佈滿足分布式 Bellman 方程（Eq. 1）：

 02 · Flow matching

 Flow matching 用速度場把高斯分佈逐步轉換成回報分佈

 03 · 先前方法

 先前方法只在部分 noise level 施加正確的一致性

 用 flow matching 表示回報分佈時，可以要求 Bellman 一致性的地方不只 τ = 1。作者把先前方法依「在哪個 noise level 施加一致性」分成三類（Sec. 1–2，App. D.2，Table 1）。

 先看 τ = 0 為什麼特別。所有 flow 在 τ = 0 的分佈都是初始雜訊，也就是標準高斯；所以 Z(s,a,0) $Z(s,a,0)$ 與 Z(S′,A′,0) $Z(S',A',0)$ ,A′,0) 都是 N(0,1) $\mathcal N(0,1)$ 。但 γZ(S′,A′,0) $\gamma Z(S',A',0)$ ,A′,0) 的變異數是 γ2<1 $\gamma^2<1$ <1，因此 r+γZ(S′,A′,0) $r+\gamma Z(S',A',0)$ ,A′,0) 不可能是標準高斯：乾淨的 Bellman 方程在 τ = 0 無法成立。

 只在終點：FlowCritic 以下一步的乾淨回報樣本 z1 $z^1$ 組成 TD 目標 y=r+γz1 $y=r+\gamma z^1$ ，再用 Eq. 3 擬合（D.2 的 Eq. 25），所以只在終點 τ = 1 施加 Bellman 一致性，不在中間層施加。DFC、Dual-Flow RL 同屬這一類；FlowIQN 另外用分位數對齊的耦合。

 每一層用乾淨方程：Value Flows（以及 EVOR）直接以速度場當 TD 目標，在所有 noise level「天真地」（naïvely）套用乾淨的 Bellman 方程；論文稱這在 τ = 0 給出不正確的監督。

 沿耦合路徑：PCBF 讓兩條 flow 路徑共用同一個起點雜訊 z0 $z^0$ ，沿這對耦合路徑套用 Bellman 算子；論文指出，因為耦合，邊際路徑本身缺乏 Bellman 一致性。

 F1三類方法施加 Bellman 一致性的位置

 實心圓：施加 Bellman 一致性的位置；×：論文稱不正確的位置（τ = 0）。PCBF 沿共用起點雜訊的耦合路徑施加，邊際不一致，不畫在此圖。

 11 · 回報估計

 在 4 個狀態上，VF 的回報分佈比先前 flow 方法準

 兩個名詞。SARSA：bootstrap 時用資料中實際的下一個動作，所以評估的是收集資料的策略。Oracle：直接以 Eq. 3 擬合同一批軌跡的實際折扣回報，不做 bootstrap，代表 bootstrapping 以外的誤差（函數近似、最佳化、有限樣本等）。

 流程（Sec. 6.1、D.4）：每個 OGBench domain 取一個狀態，執行固定的起始 action chunk，再依資料收集策略收集 1000 條訓練軌跡與 1000 條評估軌跡。各方法以 SARSA 在訓練軌跡上訓練 100K 步，抽 5000 個回報樣本，與 1000 個評估回報計算 1-Wasserstein 距離。

 結果（Fig. 2）：VF 在 4 個狀態都低於 FlowCritic、Value Flows、PCBF 三個先前方法。相對 PCBF，VF 的平均 1-Wasserstein 距離在 puzzle-4x4 降低 81%（22 對 118），在 humanoidmaze-giant 降低 89%（13 對 122）；只在 cube-triple 與 puzzle-4x4 接近 Oracle（115 對 92、22 對 20）。cube-quadruple 上 VF 179 對 Oracle 57，與 PCBF 184 接近；humanoidmaze-giant 上 VF 13 低於 Oracle 25，所以 Oracle 不是下界。圖說稱先前方法偏移並集中成窄峰；Fig. 7 的路徑圖顯示 VF 在 τ ≈ 0.25 就展開路徑，基線在 τ ≈ 0.9 才集中。

 這個實驗能說明的是：在這 4 個狀態上，VF 的回報分佈較接近評估回報。不能說明的是：只有 4 個狀態；沒有任何消融單獨拿掉高斯修正項，所以不能證明修正項是改善的原因（論文對 Value Flows 的用語是 “offering an explanation”）。本頁解讀Fig. 2 的回報軸（約 −800 到 −200）是未縮放的回報單位，而訓練時獎勵乘了 (1−γ) $(1-\gamma)$ ；論文沒有說明換算。
