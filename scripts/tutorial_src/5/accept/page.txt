 dLLM 的平行度：DTC、critical window 與三種腐蝕過程的分離

 這篇論文用 forward pass 次數比較 masked、uniform、Gaussian 三種 diffusion language model，證明 uniform 與 Gaussian 的步數可隨 DTC 縮放，並在一個分佈族上證明三者的平行度有差距。

 Sitan Chen、Liye Wang（2026）〈Parallelism, critical windows, and separations among diffusion language models〉

 masked
寬 ∝ 1/d

 uniform
寬 ∝ 1/√d

 Gaussian
寬 ∝ 1/√d

 ← noise 低noise 高 →

 01 · 一次 forward pass模型一次 forward pass 對所有位置同時給出「這個位置原本是什麼」的機率。平行取樣把這些機率當成互相獨立來抽，每一步的誤差等於被忽略的位置間相關性。

 02 · 步數與複雜度uniform 與 Gaussian diffusion 的步數可以只隨分佈的內在複雜度（dual total correlation）成長，與 masked diffusion 先前的結果相同。

 03 · 分離在一個隨機碼本分佈上，模型夠準時 uniform 與 Gaussian 約 √d 次 forward pass 就夠（相差 log 因子）；masked diffusion 則存在誤差很小的模型，使任何取樣方法至少需要約 d 次（相差 log 因子）。論文把差距歸因於「資訊突然出現的 noise 範圍」在 masked 中窄得多。

 01 · 三種腐蝕過程

 三種腐蝕過程把序列變成噪聲

 一筆資料是長度 d $d$ 的序列 X0=(X0,1,…,X0,d) $X_0=(X_{0,1},\dots,X_{0,d})$ ​=(X0,1​,…,X0,d​)，每個位置取自字母表 Σ=[S]={1,…,S} $\Sigma=[S]=\{1,\dots,S\}$ ，S $S$ 是字母表大小，序列空間是 X=Σd $\mathcal X=\Sigma^d$ 。資料分佈記為 q $q$ ，X0∼q $X_0\sim q$ ​∼q。diffusion language model（dLLM）先定義一個前向腐蝕過程：noise level t≥0 $t\ge0$ 越大，序列被破壞得越多；t $t$ 時刻的帶噪樣本記為 Xt $X_t$ ​，它的分佈記為 qt $q_t$ ​。生成時方向相反，從 t $t$ 很大的噪聲出發，逐步把 t $t$ 降回 0。本文比較的三種過程都對每個位置獨立作用（Sec. 2.1–2.3）：

 uniform：每個 token 以機率 1−e−t $1-e^{-t}$ 重抽，從 Σ $\Sigma$ 均勻抽一個符號（可能抽回原符號）。單座標 kernel 為 KtU(⋅∣z)=αt1[z=⋅]+βt $K^U_t(\cdot\mid z)=\alpha_t\mathbb 1[z=\cdot]+\beta_t$ U​(⋅∣z)=αt​1[z=⋅]+βt​，其中 αt=e−t $\alpha_t=e^{-t}$ ​=e−t 是保留機率，βt=(1−e−t)/S $\beta_t=(1-e^{-t})/S$ ​=(1−e−t)/S 是每個符號分到的均勻質量。

 masked：每個 token 以機率 1−e−t $1-e^{-t}$ 變成遮罩符號 ⋆ $\star$ ，kernel 為 KtM(⋅∣z)=αt1[z=⋅]+(1−αt)1[⋆=⋅] $K^M_t(\cdot\mid z)=\alpha_t\mathbb 1[z=\cdot]+(1-\alpha_t)\mathbb 1[\star=\cdot]$ M​(⋅∣z)=αt​1[z=⋅]+(1−αt​)1[⋆=⋅]。

 02 · score oracle

 一次 forward pass 回傳所有位置的 posterior marginal

 取樣器每一步都要知道：給定目前的帶噪序列，每個位置原本是什麼。座標 i $i$ 的 posterior marginal 是條件分佈 law((X0)i∣Xt=z) $\mathrm{law}((X_0)_i\mid X_t=z)$ ​)i​∣Xt​=z)，也就是只看第 i $i$ 個位置、對其他位置取邊際後的後驗分佈。論文把一次 forward pass 形式化為一次 score oracle query：對任意 (t,z) $(t,z)$ ，一次回傳所有座標的 posterior marginal law((X0)i∣Xt=z) $\mathrm{law}((X_0)_i\mid X_t=z)$ ​)i​∣Xt​=z)；masked 只回傳未揭露座標 i∉I $i\notin I$ I 的 marginal，I $I$ 是目前已揭露（沒有被遮住）的座標集合（Sec. 1 Framework）。一個取樣演算法用了多少次 query，稱為它的 query complexity，對應實際的 forward pass 次數。

 三種過程的 score st $s_t$ ​ 都可以換算成 posterior marginal。uniform 的 score 是 likelihood ratio st(y)[i,a]=qt(yi←a)/qt(y) $s_t(y)[i,a]=q_t(y^{i\leftarrow a})/q_t(y)$ ​(y)[i,a]=qt​(yi←a)/qt​(y)（把 y $y$ 的第 i $i$ 個位置換成 a $a$ 後的機率比），由 Lemma 2.1 的兩個仿射映射換算；Gaussian 的 score 是 ∇log⁡qt $\nabla\log q_t$ ​，由 Tweedie 公式 E[X0∣Xt=x]=etx+etσt2st(x) $\mathbb E[X_0\mid X_t=x]=e^tx+e^t\sigma_t^2s_t(x)$ ​∣Xt​=x]=etx+etσt2​st​(x) 換算（Lemma 2.4）；masked 的 score 是 st(y)[i,a]=αt1−αtqi∣I(a∣yI) $s_t(y)[i,a]=\frac{\alpha_t}{1-\alpha_t}q_{i\mid I}(a\mid y_I)$ ​(y)[i,a]=1−αt​αt​​qi∣I​(a∣yI​)，i∉I $i\notin I$ I（Lemma 2.6）。

 masked 的情形有一個細節。係數 αt1−αt $\frac{\alpha_t}{1-\alpha_t}$ ​αt​​ 依賴 t $t$ ，但 posterior marginal qi∣I(a∣yI) $q_{i\mid I}(a\mid y_I)$ ​(a∣yI​) 只依賴已揭露的部分 yI $y_I$ ​，不依賴 t $t$ 。對估計的 score，論文假設估計的 marginal q^i∣I $\hat q_{i\mid I}$ ​i∣I​ 也不依賴 t $t$ （Sec. 2.3），因此 masked 的 oracle 只依賴 partial assignment (I,xI) $(I,x_I)$ ​)。masked 自然的 noise level 是已揭露座標數 m=∣I∣ $m=|I|$ ：它可以從 Xt $X_t$ ​ 直接數出來，也是取樣器實際控制的量。另外，masked 的 oracle 誤差只在 consistent（與至少一個資料點相容）的 partial assignment 上計算；在 inconsistent 的 assignment 上，oracle 可以任意回答（Lemma 2.8）。第 09 章的下界會用到這一點。

 上界與下界的意思不同：上界分析一個特定的演算法，說它用多少次 query 就能達到目標精度；下界排除所有只透過這個 oracle 取得資訊的演算法（Sec. 1）。作為基準，不利用資料結構時，uniform diffusion 以 uniformization 可在 O(d) $O(d)$ 次 query 內做到零離散化誤差（Chen 與 Ying 2024，見研究筆記）。平行生成的目標是 o(d) $o(d)$ ：query 數的成長比序列長度慢。

 10 · 適用範圍

 結論的適用範圍與常見誤讀

 可以推論的。在隨機碼本分佈上，存在每 level 誤差 ≤η=d−Θ(1) $\le\eta=d^{-\Theta(1)}$ 的 worst-case oracle，使 masked 對常數比例的 (k,C) $(k,C)$ 需要 Ω~(d) $\tilde\Omega(d)$ (d) 次 query；uniform 在精度足夠（≤e−BΛ $\le e^{-B\Lambda}$ ）的 oracle 下 O~(d) $\tilde O(\sqrt d)$ (d​) 次即可（Gaussian 同）。兩者相比，masked 至少多 Ω~(d) $\tilde\Omega(\sqrt d)$ (d​) 倍，但兩邊的 oracle 類別與誤差要求不同；論文主張原因是窗寬。

 不可以推論的。masked 對 exact oracle 或訓練出的網路一定慢（下界只說存在一個 worst-case 近似 oracle）；分離來自 commitment，即「masked 不能修改已確定的 token」（論文主張分離來自窗寬，但沒有證明 commitment 在一般情形下無關）；uniform／Gaussian 普遍較好（Result 1 三者打平；Sec. 9 明說不應解讀為推崇某一範式）。
