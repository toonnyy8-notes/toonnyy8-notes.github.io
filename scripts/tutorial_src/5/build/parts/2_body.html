    dLLM 的平行度：DTC、critical window 與三種腐蝕過程的分離

    這篇論文用 forward pass 次數比較 masked、uniform、Gaussian 三種 diffusion language model，證明 uniform 與 Gaussian 的步數可隨 DTC 縮放，並在一個分佈族上證明三者的平行度有差距。

    01 · 一次 forward pass

    模型一次 forward pass 對所有位置同時給出「這個位置原本是什麼」的機率。平行取樣把這些機率當成互相獨立來抽，每一步的誤差等於被忽略的位置間相關性。

    02 · 步數與複雜度

    uniform 與 Gaussian diffusion 的步數可以只隨分佈的內在複雜度（dual total correlation）成長，與 masked diffusion 先前的結果相同。

    03 · 分離

    在一個隨機碼本分佈上，模型夠準時 uniform 與 Gaussian 約 √d 次 forward pass 就夠（相差 log 因子）；masked diffusion 則存在誤差很小的模型，使任何取樣方法至少需要約 d 次（相差 log 因子）。論文把差距歸因於「資訊突然出現的 noise 範圍」在 masked 中窄得多。

    01 · 三種腐蝕過程

    三種腐蝕過程把序列變成噪聲

    一筆資料是長度 $d$ 的序列 $X_0=(X_{0,1},\dots,X_{0,d})$，每個位置取自字母表 $\Sigma=[S]=\{1,\dots,S\}$，$S$ 是字母表大小，序列空間是 $\mathcal X=\Sigma^d$。資料分佈記為 $q$，$X_0\sim q$。diffusion language model（dLLM）先定義一個前向腐蝕過程：noise level $t\ge0$ 越大，序列被破壞得越多；$t$ 時刻的帶噪樣本記為 $X_t$，它的分佈記為 $q_t$。生成時方向相反，從 $t$ 很大的噪聲出發，逐步把 $t$ 降回 0。本文比較的三種過程都對每個位置獨立作用（Sec. 2.1–2.3）：

    • uniform：每個 token 以機率 $1-e^{-t}$ 重抽，從 $\Sigma$ 均勻抽一個符號（可能抽回原符號）。單座標 kernel 為 $K^U_t(\cdot\mid z)=\alpha_t\mathbb 1[z=\cdot]+\beta_t$，其中 $\alpha_t=e^{-t}$ 是保留機率，$\beta_t=(1-e^{-t})/S$ 是每個符號分到的均勻質量。
    • masked：每個 token 以機率 $1-e^{-t}$ 變成遮罩符號 $\star$，kernel 為 $K^M_t(\cdot\mid z)=\alpha_t\mathbb 1[z=\cdot]+(1-\alpha_t)\mathbb 1[\star=\cdot]$。
    • Gaussian：先把每個 token 寫成長度 $S$ 的 one-hot 向量，再跑 Ornstein–Uhlenbeck 過程：one-hot 後 $X_t=e^{-t}X_0+\sigma_tG$，$\sigma_t=\sqrt{1-e^{-2t}}$，$G$ 是標準高斯向量。

    uniform 與 masked 在 $t$ 時刻動到一個位置的機率相同，都是 $1-e^{-t}$。差別在於：masked 動到的位置一律變成 $\star$，取樣器看得出哪些位置被遮住；uniform 動到的位置重抽後只有 $(S-1)/S$ 的機率真的改變，取樣器看不出哪些位置被動過，整體改變比例是 $(S-1)\beta_t$，二元字母表（$S=2$）時就是 $\beta_t$。論文也指出，autoregressive 模型可以視為腐蝕過程為「由右至左逐一 erasure」的特例（Sec. 1）。

    02 · score oracle

    一次 forward pass 回傳所有位置的 posterior marginal

    取樣器每一步都要知道：給定目前的帶噪序列，每個位置原本是什麼。座標 $i$ 的 posterior marginal 是條件分佈 $\mathrm{law}((X_0)_i\mid X_t=z)$，也就是只看第 $i$ 個位置、對其他位置取邊際後的後驗分佈。論文把一次 forward pass 形式化為一次 score oracle query：對任意 $(t,z)$，一次回傳所有座標的 posterior marginal $\mathrm{law}((X_0)_i\mid X_t=z)$；masked 只回傳未揭露座標 $i\notin I$ 的 marginal，$I$ 是目前已揭露（沒有被遮住）的座標集合（Sec. 1 Framework）。一個取樣演算法用了多少次 query，稱為它的 query complexity，對應實際的 forward pass 次數。

    三種過程的 score $s_t$ 都可以換算成 posterior marginal。uniform 的 score 是 likelihood ratio $s_t(y)[i,a]=q_t(y^{i\leftarrow a})/q_t(y)$（把 $y$ 的第 $i$ 個位置換成 $a$ 後的機率比），由 Lemma 2.1 的兩個仿射映射換算；Gaussian 的 score 是 $\nabla\log q_t$，由 Tweedie 公式 $\mathbb E[X_0\mid X_t=x]=e^tx+e^t\sigma_t^2s_t(x)$ 換算（Lemma 2.4）；masked 的 score 是 $s_t(y)[i,a]=\frac{\alpha_t}{1-\alpha_t}q_{i\mid I}(a\mid y_I)$，$i\notin I$（Lemma 2.6）。

    masked 的情形有一個細節。係數 $\frac{\alpha_t}{1-\alpha_t}$ 依賴 $t$，但 posterior marginal $q_{i\mid I}(a\mid y_I)$ 只依賴已揭露的部分 $y_I$，不依賴 $t$。對估計的 score，論文假設估計的 marginal $\hat q_{i\mid I}$ 也不依賴 $t$（Sec. 2.3），因此 masked 的 oracle 只依賴 partial assignment $(I,x_I)$。masked 自然的 noise level 是已揭露座標數 $m=|I|$：它可以從 $X_t$ 直接數出來，也是取樣器實際控制的量。另外，masked 的 oracle 誤差只在 consistent（與至少一個資料點相容）的 partial assignment 上計算；在 inconsistent 的 assignment 上，oracle 可以任意回答（Lemma 2.8）。第 09 章的下界會用到這一點。

    上界與下界的意思不同：上界分析一個特定的演算法，說它用多少次 query 就能達到目標精度；下界排除所有只透過這個 oracle 取得資訊的演算法（Sec. 1）。作為基準，不利用資料結構時，uniform diffusion 以 uniformization 可在 $O(d)$ 次 query 內做到零離散化誤差（Chen 與 Ying 2024，見研究筆記）。平行生成的目標是 $o(d)$：query 數的成長比序列長度慢。

    本文把一次 forward pass 形式化成什麼？masked 的 oracle 輸入與 $t$ 有關嗎？

    03 · 條件相關

    平行更新丟掉的是條件相關

    先複習三個量（log 一律為自然對數，單位 nats）。entropy $H(X)=-\sum_xp(x)\log p(x)$ 是隨機變數的不確定度。KL divergence $\mathrm{KL}(p\|p')=\sum_xp(x)\log\frac{p(x)}{p'(x)}$ 衡量用 $p'$ 近似 $p$ 的代價，非負，且只在 $p=p'$ 時為 0。條件熵 $H(X\mid Y)=H(X,Y)-H(Y)$ 是知道 $Y$ 之後剩下的不確定度。

    論文用兩個量衡量「位置之間相關多少」（Def 2.9）：

    $$\mathrm{TC}(X)=\sum_{i=1}^dH(X_i)-H(X),\qquad \mathrm{DTC}(X)=H(X)-\sum_{i=1}^dH(X_i\mid X_{-i})$$
    Def 2.9

    total correlation（TC）等於 $\mathrm{KL}\big(\mathrm{law}(X)\,\|\,\prod_i\mathrm{law}(X_i)\big)$，即把聯合分佈換成各位置邊際的乘積會損失多少。dual total correlation（DTC）中的 $H(X_i\mid X_{-i})$ 是看到其他所有位置後第 $i$ 個位置剩下的不確定度，$X_{-i}$ 表示除了第 $i$ 個以外的所有座標。兩者都在各位置獨立時為 0。以 $d=3$ 個 bit 為例本頁推導（由 Def 2.9 直接代入）：

    • 複製（三個 bit 完全相同，全 0 或全 1 各半）：$H(X)=\log2$，每個 $H(X_i)=\log2$，所以 $\mathrm{TC}=3\log2-\log2=2\log2$；每個 $H(X_i\mid X_{-i})=0$，所以 $\mathrm{DTC}=\log2$。
    • 偶同位（parity，均勻分佈在含偶數個 1 的 4 個字串上）：$H(X)=2\log2$，$H(X_i)=\log2$，所以 $\mathrm{TC}=3\log2-2\log2=\log2$；另外兩個 bit 決定第三個，$H(X_i\mid X_{-i})=0$，所以 $\mathrm{DTC}=2\log2-3\cdot0=2\log2$。

    推廣到一般 $d$ 個 bit：複製分佈的 $\mathrm{TC}=(d-1)\log2$、$\mathrm{DTC}=\log2$；偶同位分佈的 $\mathrm{TC}=\log2$、$\mathrm{DTC}=(d-1)\log2$。同一個分佈的兩個量可以差很多，Result 1 用的是 DTC。條件版本 $\mathrm{TC}(X\mid Y)$、$\mathrm{DTC}(X\mid Y)$ 把每個 entropy 換成給定 $Y$ 的條件熵。

    取樣器在時間格點 $t_0\lt t_1\lt\dots\lt t_M$ 上由高往低走。每一步從噪聲較多的 $t$ 退到噪聲較少的 $s=t-h$，$h\gt0$ 是步長。平行更新使用 product reverse kernel：給定 $X_t=y$，各座標獨立地從 posterior marginal $P[(X_s)_i=\cdot\mid X_t=y]$ 抽樣（Eq. 12）。真正的 reverse kernel 是聯合分佈 $\mathrm{law}(X_s\mid X_t=y)$，用 posterior marginal 的乘積取代 joint 時，一步的 KL 誤差依 TC 的定義恰好等於條件 total correlation $\mathrm{TC}(X_s\mid X_t)$。這就是平行更新的代價：被丟掉的是給定 $X_t$ 之後，各位置之間仍然存在的相關。

    整條路徑的誤差由 KL 的 chain rule 與 data processing inequality 拆開（Lemma 3.8 的證明）。實際的分解是：路徑 KL = 初始化 $\mathrm{KL}(q_{t_M}\|\mathrm{Unif})$ + 各步 TC $\sum_j\mathrm{TC}(X_{t_j}\mid X_{t_{j+1}})$ + 各步 score 誤差（每步 $\le c\,\varepsilon_{\rm unif}$，精確寫法是 $c_{t_j}(t_{j+1}-t_j)\,\varepsilon_{\rm unif}(t_{j+1})$，Lemma 3.7）+ 末端 $H(q_{t_0})-H(q)$（Lemma 3.9）。初始化項來自從均勻分佈起跑，末端項來自停在 $t_0\gt0$ 而不是 0，$\varepsilon_{\rm unif}$ 是 score 的估計誤差。Lemma 3.8 的敘述是這個分解的上界：各步 TC 換成 $c_{t_j}(t_{j+1}-t_j)\cdot$DTC 落差，即 $c_{t_j}(t_{j+1}-t_j)\big(\mathrm{DTC}(q_{t_j})-\mathrm{DTC}(q_{t_{j+1}})\big)$，換的方法是下一章的 reverse DPI。

    這個替換要用到 DTC 的一個恆等式（Lemma 2.10）。若 $B$ 由 $A$ 經獨立的逐座標 channel 得到，則

    $$\mathrm{DTC}(A)-\mathrm{DTC}(B)=\mathrm{DTC}(A\mid B)+\sum_iI(B_i;A_{-i}\mid B_{-i})$$
    Lemma 2.10

    $I(\cdot\,;\cdot\mid\cdot)$ 是條件 mutual information，非負，所以 $\sum_iI(B_i;A_{-i}\mid B_{-i})\le\mathrm{DTC}(A)-\mathrm{DTC}(B)$（Eq. 2）。前向過程正是逐座標 channel，取 $A=X_s$、$B=X_t$ 得到一個推論：$\mathrm{DTC}(q_t)$ 對 $t$ 單調不增。

    證明要點：Lemma 2.10

    三個等式（Eq. 3 之後）：(1) channel 是 product，所以 $H(A)-H(B)-H(A\mid B)=-H(B\mid A)=-\sum_iH(B_i\mid A_i)$；(2) $B_i$ 只依賴 $A_i$，所以 $H(A_i\mid A_{-i},B)=H(A_i\mid A_{-i},B_i)$；(3) 同理 $H(B_i\mid A_{-i})=H(B_i\mid A_{-i},B_{-i})$。把 $\mathrm{DTC}(A)-\mathrm{DTC}(B)-\mathrm{DTC}(A\mid B)$ 依定義展開，用這三式逐項整理，剩下的就是 $\sum_iI(B_i;A_{-i}\mid B_{-i})$。

    檢查理解

    $d$ 個完全相同的 bit 與 $d$ 個 bit 的偶同位分佈，TC、DTC 各是多少？

    複製：TC $=(d-1)\log2$、DTC $=\log2$；同位：TC $=\log2$、DTC $=(d-1)\log2$（本頁推導，由 Def 2.9）。

    用 posterior marginal 的乘積取代 joint 時，一步的 KL 誤差等於什麼？總誤差由哪些項組成？

    等於條件 total correlation $\mathrm{TC}(X_s\mid X_t)$。路徑 KL = 初始化 $\mathrm{KL}(q_{t_M}\|\mathrm{Unif})$ + 各步 TC + 各步 score 誤差（每步 $\le c\,\varepsilon_{\rm unif}$，Lemma 3.7）+ 末端 $H(q_{t_0})-H(q)$（Lemma 3.9）。Lemma 3.8 是它的上界：各步 TC 換成 $c_{t_j}(t_{j+1}-t_j)\cdot$DTC 落差。

    04 · reverse DPI

    reverse DPI 把單步誤差換成 DTC 的下降量

    data processing inequality（DPI）說：兩個分佈經過同一個 channel $K$ 之後，KL 不會變大，$\mathrm{KL}(pK\|p'K)\le\mathrm{KL}(p\|p')$。reverse DPI 是反方向的不等式：如果 channel 只加少量噪聲，KL 也不會縮小太多，$\mathrm{KL}(pK\|p'K)\ge c\cdot\mathrm{KL}(p\|p')$，$c\gt0$。論文用兩個事實得到 uniform 的版本（Sec. 3.1）：

    1. Prop 3.3：加噪後每個符號至少有質量 $\beta_s$，即 $P[(X_s)_i=a\mid(X_t)_{-i}=y_{-i}]\ge\beta_s$。
    2. Lemma 3.4（單 token reverse DPI）：若 $p,p'$ 每個符號質量 $\ge c/S$，則 $\mathrm{KL}(pK^U_t\|p'K^U_t)\ge\mathrm{KL}(p\|p')\cdot\frac{e^{-2t}c}{1-e^{-t}+e^{-t}c}$。
    證明要點：Lemma 3.4

    KL 可以寫成 $\mathrm{KL}(p\|p')=\sum_a(p_a-p'_a)^2\int_0^1\frac{1-\theta}{p'_a+\theta(p_a-p'_a)}d\theta$（Eq. 4）。經過 $K^U_t$ 後，差 $p_a-p'_a$ 乘上 $e^{-t}$，所以分子乘上 $e^{-2t}$；分母中的機率在每個符號質量 $\ge c/S$ 的條件下，最多放大 $e^{-t}+(1-e^{-t})/c$ 倍。兩者相除得到 Lemma 3.4 的係數。

    Cor 3.5 把兩者接起來。以 $(X_t)_{-i}$ 為條件，有 Markov 鏈 $(X_s)_{i+1:d}-(X_s)_i-(X_t)_i$；取 $c=1-e^{-s}$、noise 量為 $h$，經 chain rule（Eq. 9）整理得到

    $$I\big((X_s)_{i+1:d};(X_s)_i\mid X_t\big)\le\frac{e^{2h}-1}{1-e^{-s}}\;I\big((X_s)_{i+1:d};(X_t)_i\mid(X_t)_{-i}\big)$$
    Eq. 10
    兩個引數邊際化（不出現）條件（已知）

    把 $\mathrm{TC}(X_s\mid X_t)=\sum_{i=1}^{d-1}I((X_s)_i;(X_s)_{i+1:d}\mid X_t)$ 逐項套用 Cor 3.5，再把 $(X_s)_{i+1:d}$ 放大成 $(X_s)_{-i}$，最後用 Lemma 2.10 的 Eq. 2（$A=X_s$、$B=X_t$），得到 Lemma 3.2：

    $$\mathrm{TC}(X_s\mid X_t)\le c_s(h)\big(\mathrm{DTC}(q_s)-\mathrm{DTC}(q_t)\big),\qquad c_s(h)=\frac{e^{2h}-1}{1-e^{-s}}$$
    Lemma 3.2

    所以 Lemma 3.2 靠兩個事實證明：Prop 3.3（加噪後每個符號質量 $\ge\beta_s$）與 Lemma 3.4（單 token reverse DPI），再用 Lemma 2.10 的 Eq. 2 把 mutual information 的和換成 DTC 落差。係數的行為：$h\ll s$ 時 $c_s(h)\approx2h/(1-e^{-s})$，步長越小係數越小；$s$ 很小時分母 $1-e^{-s}$ 趨近 0，所以在低 noise 端必須用很小的步長。

    05 · telescoping

    幾何步長讓各步的 DTC 落差成為逐項抵消的和（telescoping sum）

    Result 1 的目標：給定目標精度 $\varepsilon\gt0$，要求 $\mathrm{KL}(q\|\hat q)\le\varepsilon$，$\hat q$ 是取樣器的輸出分佈。若每一步的係數 $c_{t_j}(t_{j+1}-t_j)$ 都不超過同一個常數，Lemma 3.8 的離散化項就是這個常數乘上 $\sum_j\big(\mathrm{DTC}(q_{t_j})-\mathrm{DTC}(q_{t_{j+1}})\big)$。這個和的相鄰項互相抵消（telescoping sum），只剩 $\mathrm{DTC}(q_{t_0})-\mathrm{DTC}(q_{t_M})\le\mathrm{DTC}(q)$，因為 $\mathrm{DTC}(q_t)$ 對 $t$ 不增。

    Thm 3.1 的排程使用 uniform 排程變數 $u=e^t-1$：$u_0=e^{\delta_U}-1$、$u_{j+1}=\min((1+a_U)u_j,U)$、$t_j=\log(1+u_j)$，也就是 $u=e^t-1$ 每步乘 $1+a_U$。$a_U$ 是步長參數；$\delta_U$ 是末端時間（取樣停在 $t_0=\delta_U$），與第 07 章的失敗機率 $\delta$ 是不同的量；$U=e^{T_U}-1$ 對應起始時間 $T_U$。這個排程使每步係數 $c\le3a_U$。排程的形狀是：$t$ 小時 $t_{j+1}\approx(1+a_U)t_j$（幾何），$t$ 大時 $t_{j+1}-t_j\approx\log(1+a_U)$（等距）（Fig. 6）。

    推導：為什麼每步係數 ≤ 3a_U

    由排程得 $e^{t_{j+1}-t_j}=\frac{1+u_{j+1}}{1+u_j}\le1+a_U\frac{u_j}{1+u_j}=1+a_U(1-e^{-t_j})=:1+x_j$。代入 $c_s(h)$（$s=t_j$、$h=t_{j+1}-t_j$）：$c_{t_j}(t_{j+1}-t_j)\le\frac{(1+x_j)^2-1}{1-e^{-t_j}}=\frac{x_j(2+x_j)}{1-e^{-t_j}}=(2+x_j)a_U\le3a_U$。最後一步只需要 $x_j\le1$，所以 C3 允許 $a_U$ 到 1（論文取 $a_U\le1/12$）。

    誤差帳（Thm 3.1 證明）：

    • 離散化：各步 DTC 落差 telescoping 相加 $\le\mathrm{DTC}(q)$，所以總離散化誤差 $\le3a_U\,\mathrm{DTC}(q)\le\varepsilon/4$。
    • 初始化：$\mathrm{KL}(q_{T_U}\|\mathrm{Unif})\le e^{-T_U}d\log S\le\varepsilon/4$（Lemma 3.10）。
    • 末端：$H(q_{\delta_U})-H(q)\le d\delta_U\log(eS/\delta_U)\le\varepsilon/8$（Lemma 3.11）。
    • score：$3a_UN_U\varepsilon_{\rm unif}$，$N_U$ 是步數。

    參數取 $a_U=\varepsilon/(12\max\{\overline{\mathrm{DTC}},\varepsilon\})$、$L_U=\log(16edS/\varepsilon)$、$\delta_U=\varepsilon/(16dL_U)$、$T_U=\log(4d\log S/\varepsilon)$；步數 $N_U\le1+\log(U/u_0)/\log(1+a_U)$，其中 $\log(U/u_0)\lesssim L_U$、$1/\log(1+a_U)\le2/a_U$。結論是 Thm 3.1：$\mathrm{KL}(q\|\hat q)\le\varepsilon+O(\varepsilon_{\rm unif}\log(dS/\varepsilon))$，query 數為 $O\big((1+\overline{\mathrm{DTC}}/\varepsilon)\log(edS/\varepsilon)\big)$。設定 $a_U$ 需已知一個上界 $\overline{\mathrm{DTC}}\ge\mathrm{DTC}(q)$（informal 的 Thm 1.1 沒有寫出這個條件）。這追平了先前只對 masked diffusion 成立的 DTC 縮放 [CCL26, LZ25]。

    從目標誤差 $\varepsilon$ 推出 query 數，分兩步。第一步，選步長：離散化項必須落在預算 $\varepsilon/4$ 以內。因為 $\mathrm{DTC}(q)\le\overline{\mathrm{DTC}}\le\max\{\overline{\mathrm{DTC}},\varepsilon\}$，取 $a_U=\varepsilon/(12\max\{\overline{\mathrm{DTC}},\varepsilon\})$ 就得到 $3a_U\mathrm{DTC}(q)\le3\varepsilon/12=\varepsilon/4$；分母的 $\max$ 使 $\overline{\mathrm{DTC}}$ 很小時 $a_U$ 也不超過 $1/12$。初始化 $\varepsilon/4$、末端 $\varepsilon/8$ 加上離散化 $\varepsilon/4$，合計小於 $\varepsilon$。第二步，數步數：每一步 query 一次 oracle，所以 query 數就是步數 $N_U$。$N_U\le1+\frac{2}{a_U}\log(U/u_0)=1+\frac{24\max\{\overline{\mathrm{DTC}},\varepsilon\}}{\varepsilon}\cdot O(L_U)$。又因為 $\max\{\overline{\mathrm{DTC}},\varepsilon\}/\varepsilon\le1+\overline{\mathrm{DTC}}/\varepsilon$、$L_U=O(\log(edS/\varepsilon))$，得到 $N_U=O\big((1+\overline{\mathrm{DTC}}/\varepsilon)\log(edS/\varepsilon)\big)$。所以步數與 $\overline{\mathrm{DTC}}/\varepsilon$ 成正比，維度只透過 log 因子出現。

    06 · 隨機碼本

    困難分佈是隨機碼本上的均勻分佈

    Result 2 在一個特定的分佈族上比較三種過程（Sec. 5、Def 5.1）。字母表取 $\Sigma=\{\pm1\}$（$S=2$，$\beta_t=(1-e^{-t})/2$）。碼本 $C$ 是 $\{\pm1\}^d$ 上均勻隨機的 $M$ 元子集，$M=\lceil e^{\kappa d}\rceil$，$\kappa\in[\kappa_-,\kappa_+]\subset(0,\log2)$ 稱為碼率；資料分佈是碼本上的均勻分佈 $q^C=\mathrm{Unif}(C)$。取樣器知道區間 $[\kappa_-,\kappa_+]$，不知道 $\kappa$，也不知道 $C$。下界額外把 $\kappa$ 限制在格點 $\{(k/d)\log2\}$ 上，此時 $M=2^k$。

    臨界時間由「每座標保留的資訊量等於碼率」決定。一個均勻的 bit $V$ 經 uniform 腐蝕後，與原 bit 的 mutual information 是 $I_{\rm unif}(t)=\log2-h_2(\beta_t)$，其中 $h_2(p)=-p\log p-(1-p)\log(1-p)$ 是 binary entropy；經 Gaussian 腐蝕後是 $I_{\rm gauss}(t)=I(V;e^{-t}V+\sigma_tG)$。兩者都是一個 bit 經腐蝕後保留的資訊。臨界時間定義為

    $$d\,I_{\rm unif}(t^\star_{\rm unif})=\log M,\qquad d\,I_{\rm gauss}(t^\star_{\rm gauss})=\log M$$
    Eq. 22

    即 $d\,I(t^\star)=\log M$（Eq. 22）。masked 沒有連續的時間 $t$，腐蝕程度由已揭露的座標數 $m$ 表示：$m$ 個座標露出原值，其餘 $d-m$ 個被遮住。一個露出的座標保留整個 bit 的資訊 $\log2$，被遮住的座標保留 0，所以總資訊是 $m\log2$。令它等於 $\log M=k\log2$（格點上 $M=2^k$），得到 masked 的臨界點：已揭露座標數 $m=k$。$m\lt k$ 時，與已揭露值一致的碼字約有 $1+2^{k-m}$ 個，無法判斷是哪一個；$m\gt k$ 時通常只剩原碼字。從 random coding 的角度看：每座標資訊量 $I\lt\kappa$ 時，帶噪樣本附近仍有很多碼字，無法判斷是哪一個；$I\gt\kappa$ 時只剩原碼字。$\kappa=0.2$ 時本頁推導$\beta^\star=0.1948$、$t^\star_{\rm unif}=0.4937$、$t^\star_{\rm gauss}=0.5521$、masked $m^\star/d=\kappa/\log2=0.2885$（C4 的小圖可以改 $\kappa$）。上界演算法的所有 query 時間都落在 $I_0=[\tau_-/2,\tau_++1]$（Eq. 23）。

    論文陳述這個分佈族的 $\mathrm{DTC}=\Theta(d)$（Sec. 1.2，沒有附證明），所以 Thm 3.1/4.1 在這裡只給 $\tilde O(d/\varepsilon)$；Result 2 的演算法利用分佈的結構，超過 DTC 界。直覺本頁推導：$H=\log M\approx\kappa d$；$H(X_i\mid X_{-i})\ne0$ 需要某個碼字翻一位後仍在 $C$ 中，機率約 $M/2^d$，是指數小的量，所以 $\mathrm{DTC}\approx\kappa d$。

    07 · critical window

    critical window 在 masked 寬 1/d，在 uniform 與 Gaussian 寬 1/√d

    先定義 Result 2 的精度符號。目標是對至少 $1-\delta$ 比例的碼本 $C$ 有 $\mathrm{TV}(\hat q^C,q^C)\le\varepsilon$；這裡 $\varepsilon$ 是 total variation（TV）距離 $\frac12\sum_x|p(x)-p'(x)|$ 的目標精度，$\delta\in(0,1/4)$ 是失敗機率，即保證不成立的碼本所佔比例（Thm 6.1）。對數因子 $\Lambda=\log(Cd/(\varepsilon\delta))$（Eq. 24），這裡的 $C$ 是只依賴 $[\kappa_-,\kappa_+]$ 的常數，不是碼本。$A\gt0$ 是 Prop 6.4 證明中選定、只依賴 $[\kappa_-,\kappa_+]$ 的常數，論文沒有給數值。

    critical window 是 noise 範圍中資訊突然出現的區間：在窗的高 noise 一側，帶噪樣本幾乎不含碼字的資訊；在低 noise 一側，已經可以解出原碼字。三個命題給出窗寬：

    • Uniform（Prop 6.4）：$w=A\sqrt{\Lambda/d}$（Eq. 26）。$t\ge t^\star_{\rm unif}+w$ 時 $\mathbb E_C\,\mathrm{TV}(q^C_t,\mathrm{Unif})\le e^{-K\Lambda}$；$t\le t^\star_{\rm unif}-w$ 時 Bayes 最佳解碼錯誤率 $\mathbb E_C\,\mathrm{err}^U_C(t)\le e^{-K\Lambda}$。條件是 $d\ge d_{K,A}$、$\log d\le\Lambda\le c_{K,A}d$，期望是對 $C$ 取的。
    • Gaussian（Prop 7.4）：結構相同，窗寬同樣是 $w=A\sqrt{\Lambda/d}$；information density 是 $d$ 個獨立項之和，以 $d\,I_{\rm gauss}(t)$ 為中心，偏離 $v$ 的機率 $\le2e^{-cv^2/d}$（Eq. 59）。
    • Masked（Prop 8.6）：$|C|=2^k$；$m\le k-\ell$ 時 $\mathbb E_C\,\mathrm{TV}(\mathrm{law}(X_{0,I}),\mathrm{Unif})\le2^{-\ell/2}$，$m\ge k+\ell$ 時 $\mathbb E_C\,\mathrm{err}^M_C(m)\le2^{-\ell}$。窗在 $m$ 上寬 $2\ell$；$\eta=d^{-\Theta(1)}$ 時 $\ell=O(\log d)$，佔全範圍的 $O(\log d/d)$（$\ell$ 與 $\eta$ 在第 09 章定義）。

    總結：masked 的 critical window 佔 noise 範圍的 $O(\log d/d)$（Prop 8.6，$\eta=d^{-\Theta(1)}$ 時 $\ell=O(\log d)$）；uniform／Gaussian 的窗寬 $w=A\sqrt{\Lambda/d}$，在 $\varepsilon$ 為常數、$\delta=d^{-\Theta(1)}$ 時為 $O(\sqrt{\log d/d})$（Prop 6.4、7.4，需 $\log d\le\Lambda\le cd$）。

    08 · 上界演算法

    上界演算法先找窗、再在窗內取樣、最後一步解碼

    取樣器不知道 $\kappa$，所以不知道窗在哪裡。Thm 6.1 的演算法分成三個階段（Sec. 6.2–6.3）：找窗、窗內取樣、一步解碼。

    09 · 下界

    worst-case oracle 使 masked 取樣器必須搜尋窗的位置

    masked 的下界要證明：存在一個誤差很小的 oracle，使任何演算法都需要很多次 query（Sec. 8）。先在碼本上放一個 prior：$k\sim\mathrm{Unif}(\mathcal K^M_d)$，$\mathcal K^M_d=\{k\in\mathbb Z:\kappa_-\le k\log2/d\le\kappa_+\}$，$|\mathcal K^M_d|\ge c_1d$；給定 $k$，$C$ 是均勻隨機的 $2^k$ 元子集。$\eta$ 是每個 level 允許的 oracle 誤差，$\rho$ 是失敗參數，窗半寬為 $\ell=\lceil\log_2(Cd/(\eta\rho^2))\rceil$（Eq. 96，這個 $C$ 是常數，不是碼本）。

    第一步（Lemma 8.2）。永遠回傳均勻 marginal 的 oracle $\mathcal O_0$ 滿足 $\mathbb E_C\,\varepsilon_{\rm mask}(\mathcal O_0;q^C,m)\le2^{m-k}$。直覺：揭露 $m$ 個座標後，與揭露值一致的碼字平均約有 $2^{k-m}$ 個，它們在未揭露座標上的值近似均勻，所以均勻回答的 KL 誤差約為 $1/2^{k-m}$。這是對 $C$ 取期望的敘述，對個別的 $C$ 不一定成立。因此定義：$C$ 是 good，若 $\varepsilon_{\rm mask}(\mathcal O_0;q^C,m)\le\eta$ 對每個 $0\le m\le k-\ell$ 都成立（Eq. 98）。對單一 level 用 Markov 不等式，$\mathbb P_C[\varepsilon_{\rm mask}(\mathcal O_0;q^C,m)\gt\eta]\le2^{m-k}/\eta$；再對 $m=0,\dots,k-\ell$ 做 union bound，等比級數給出

    $$\mathbb P_C[\,C\text{ not good}\,]\le\frac1\eta\sum_{m=0}^{k-\ell}2^{m-k}\le\frac{2^{1-\ell}}{\eta}$$
    Eq. 99

    所以 $C$ 是 good 的機率 $\ge1-2^{1-\ell}/\eta$。$\ell$ 取得夠大（Eq. 96），這個機率就接近 1。

    第二步（Def 8.3）。對 good $C$ 定義 worst-case oracle $\mathcal O_{k,C}$：$m\le k-\ell$ 一律回傳均勻（不論 consistent 與否）；$m\gt k-\ell$ 時 consistent assignment 回傳真實 marginal、inconsistent 回傳均勻。它是合法的 oracle，因為誤差只在 consistent assignment 上計算（Lemma 2.8），而 $m\le k-\ell$ 的 level 上均勻回答的誤差已由 good $C$ 控制在 $\eta$ 以內；Prop 8.4 因此得到每個 level 的誤差 $\le\eta$（Eq. 97）。

    第三步（Prop 8.5，coupling）。演算法對 $\mathcal O_0$ 的查詢序列只由演算法內部的隨機性決定，與 $k,C$ 無關。把同一個演算法分別接上 $\mathcal O_0$ 與 $\mathcal O_{k,C}$，兩次執行收到的回答出現差異（機率記為 $p_{\rm diff}$）只可能因為三件事，分別對應 Eq. 100 的三項：

    1. $m$ 落在窗內。某次 query 的已揭露座標數 $m$ 與 $k$ 相距不超過 $\ell$（$|m-k|\le\ell$）。在這個範圍，$\mathcal O_{k,C}$ 對 consistent assignment 回傳真實 marginal，與均勻不同。查詢序列與 $k$ 無關，而 $k$ 在 $|\mathcal K^M_d|$ 個值中均勻，所以每次 query 落入的機率 $\le(2\ell+1)/|\mathcal K^M_d|$，$Q$ 次合計 $\le(2\ell+1)Q/|\mathcal K^M_d|$（第一項）。
    2. $C$ 不是 good。此時 $\mathcal O_{k,C}$ 不用上面的規則，回答可能不同；機率 $\le2^{1-\ell}/\eta$（Eq. 99，第二項）。
    3. $m\gt k+\ell$ 的 query 碰巧與 $C$ 一致。$m$ 在窗的上方時，$\mathcal O_{k,C}$ 只對 consistent assignment 回傳真實值。演算法的 assignment 與 $C$ 無關，一個固定的 $m$ 座標 assignment 與某個碼字一致的機率 $\le2^k\cdot2^{-m}\le2^{-\ell}$，$Q$ 次合計 $\le Q2^{-\ell}$（第三項）。

    $m\lt k-\ell$ 而且 $C$ 是 good 時，$\mathcal O_{k,C}$ 本來就回傳均勻，與 $\mathcal O_0$ 相同，不會產生差異。三項相加：

    $$\mathbb E\,p_{\rm diff}\le\frac{(2\ell+1)Q}{|\mathcal K^M_d|}+\frac{2^{1-\ell}}{\eta}+Q\,2^{-\ell}$$
    Eq. 100

    結論（Thm 8.1）。從 $p_{\rm diff}$ 到輸出分佈的 TV 有三步。(1) 接上 $\mathcal O_0$ 時，輸出分佈 $\nu$ 與 $k,C$ 無關；用同一份內部隨機性耦合兩次執行，coupling 不等式給出 $\mathrm{TV}(\hat q,\nu)\le p_{\rm diff}(k,C)$，$\hat q$ 是接上 $\mathcal O_{k,C}$ 時的輸出分佈。(2) $q^C$ 只放質量在 $C$ 上，所以 $\mathrm{TV}(\hat q,q^C)\ge1-\hat q(C)\ge1-\nu(C)-p_{\rm diff}$（Eq. 103）。一個與 $C$ 無關的點落在 $C$ 中的機率是 $2^{k-d}$，所以 $\mathbb E_C\,\nu(C)=2^{k-d}$，是指數小的量。(3) 選常數：$|\mathcal K^M_d|=\Theta(d)$，所以 query 預算 $Q\le c\rho^2d/\ell$ 的常數 $c$ 取得夠小時，第一項 $\le\rho^2/4$；Eq. 96 的常數 $C$ 取得夠大時，第二、三項合計 $\le\rho^2/4$；$d$ 夠大時 $\mathbb E_C\,\nu(C)\le\rho^2/4$。合起來 $\mathbb E_{k,C}[\nu(C)+p_{\rm diff}]\le\rho^2$，再用一次 Markov 不等式得 $\mathbb P_{k,C}[\nu(C)+p_{\rm diff}\le\rho]\ge1-\rho$。因此 $Q\le c\rho^2d/\ell$ 時，以機率 $\ge1-\rho$（對 $k,C$）有 $\mathrm{TV}(\hat q,q^C)\ge1-\rho$：取樣器的輸出幾乎完全不在碼本上。$\ell=O(\log d)$（$\eta=d^{-\Theta(1)}$、$\rho$ 為常數），所以任何演算法需要 $\Omega(d/\log d)$ 次 query。成本約等於候選位置數除以窗寬：masked 有 $\Theta(d)$ 個 level，窗寬 $2\ell+1$；沒有落在窗內的查詢，得到的回答與 $\mathcal O_0$ 相同，不帶任何資訊。

    uniform 的下界（Thm A.1）同構：$t^\star_{\rm unif}(k)$ 的候選值取成彼此相距 $\ge10w$（Eq. 108），候選數 $|\mathcal K^U_d|\ge\frac{c_U}A\sqrt{d/\Lambda}$（Eq. 109）；oracle 只在 $|t-t^\star|\lt4w$ 回傳真實 score（Def A.4）；$Q\le c\rho^2\sqrt{d/\Lambda}$ 時失敗（Eq. 111），即 uniform 需要 $\tilde\Omega(\sqrt d)$ 次 query。Gaussian 的 $\tilde\Omega(\sqrt d)$ 下界引用 Xun 與 Price [XP26]，本文沒有重證；依研究筆記，[XP26] 的論證顯示在這個分佈上，連把 $\kappa$ 估計到足夠精度都需要這麼多 query。另一個 masked 下界是 [CCL26] 以 MDS code 構造的 $\Omega(d)$（Sec. 1.3），那是另一個分佈族，與本文的分離無關。

    worst-case oracle 怎麼構造？為什麼它是合法的？為什麼需要 $\Omega(d/\log d)$ 次 query？

    10 · 適用範圍

    結論的適用範圍與常見誤讀

    可以推論的。在隨機碼本分佈上，存在每 level 誤差 $\le\eta=d^{-\Theta(1)}$ 的 worst-case oracle，使 masked 對常數比例的 $(k,C)$ 需要 $\tilde\Omega(d)$ 次 query；uniform 在精度足夠（$\le e^{-B\Lambda}$）的 oracle 下 $\tilde O(\sqrt d)$ 次即可（Gaussian 同）。兩者相比，masked 至少多 $\tilde\Omega(\sqrt d)$ 倍，但兩邊的 oracle 類別與誤差要求不同；論文主張原因是窗寬。

    不可以推論的。masked 對 exact oracle 或訓練出的網路一定慢（下界只說存在一個 worst-case 近似 oracle）；分離來自 commitment，即「masked 不能修改已確定的 token」（論文主張分離來自窗寬，但沒有證明 commitment 在一般情形下無關）；uniform／Gaussian 普遍較好（Result 1 三者打平；Sec. 9 明說不應解讀為推崇某一範式）。

    其他範圍限制（Sec. 9 與全文）：

    • 上界對任何誤差 $\le e^{-B\Lambda}$ 的 oracle 成立；下界是「存在一個 worst-case 近似 oracle」，沒有證明對 exact oracle 或訓練出的網路成立。
    • 結論只對這一個隨機碼本分佈族。masked 的 any-order 生成等優點沒有被分析；Gaussian 只考慮最基本的 one-hot 嵌入。
    • 兩個下界都依賴 prior（演算法不知道 $k$）；論文沒有討論 $\kappa$ 已知的情形。
    • 定理是漸近的（$d\ge d_0$），常數沒有給；Fig. 4 的窗寬不含 log 因子，因為 0.2→0.8 的定義不要求高機率。

    2. 把分離歸因於 commitment。論文主張分離來自窗寬（abstract、Sec. 1.2、Sec. 9）；論文沒有證明 commitment 在一般情形下無關，本頁也不做這個更強的宣稱。
    3. 以為窗窄比較容易。成本來自找窗：窄窗代表窗可能的位置更多。
    4. 把 Result 1 與 Result 2 的取樣器混為一談。前者是「每步所有座標獨立重抽」的通用演算法；後者是找窗、窗內取樣、一步解碼三階段的專用演算法。
    5. uniform 取樣器使用估計 score 時漏掉投影。Sec. 3 用 Bregman projection（Sec. 3.2）；Sec. 6 用 clipping（Eq. 33）；Sec. 4 用 Euclidean projection 到 $\Delta(\Sigma)^d$（Eq. 17）；Sec. 7 clip 到 $[-1,1]$（Eq. 79）。
    6. 把 recovery probability 當成取樣器成功率，或當成找窗統計量 $T_t$。它是 posterior 在正確碼字上的平均質量。
    7. 混用三個 $u$。見第 02 章符號表下方的說明。
    檢查理解

    這個分離能推論出哪些結論、不能推論出哪些結論？

    可以：在隨機碼本分佈上，存在每 level 誤差 $\le\eta=d^{-\Theta(1)}$ 的 worst-case oracle，使 masked 對常數比例的 $(k,C)$ 需要 $\tilde\Omega(d)$ 次 query；uniform 在精度足夠（$\le e^{-B\Lambda}$）的 oracle 下 $\tilde O(\sqrt d)$ 次即可（Gaussian 同）；masked 至少多 $\tilde\Omega(\sqrt d)$ 倍，但 oracle 類別與誤差要求不同；論文主張原因是窗寬。不可以：masked 對 exact oracle 或訓練出的網路一定慢、分離來自 commitment、uniform／Gaussian 普遍較好（Result 1 三者打平；Sec. 9）。
