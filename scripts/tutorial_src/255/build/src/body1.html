No. 255 Reasoning with Sampling
    No. 255 · 互動教學 · arXiv 2510.14901 · 2025

    不訓練，只取樣：從 base model 的冪分佈取樣做推理

    這篇論文只用既有模型自己給的機率挑選回答，不再訓練，單次作答的準確率接近經過強化學習後訓練的模型（後文說明）。

    Aayush Karan、Yilun Du（2025）〈Reasoning with Sampling: Your Base Model is Smarter Than You Think〉

    01 · 取樣目標

    base model 指作為取樣對象、不再訓練的既有語言模型，它對每條回答序列 x 給出機率 p(x)。本文的取樣目標是 p(x)α（α 是大於 1 的冪次，論文用 4），它使機率較高的回答得到更大的相對權重。

    02 · 和低溫取樣不同

    常用的低溫取樣在每一步把下一個 token 的機率取 α 次方再重新正規化。這和對整條序列的機率取 α 次方得到的分佈不同（03a 節用一個兩 token 的例子說明）。

    03 · 反覆重取

    直接從 p(x)α 取樣需要對所有可能序列加總，無法計算。作者改為反覆執行：隨機選一個位置，從該位置重新生成到目前區塊結尾，再依新舊序列的機率比值決定是否接受。這個方法的名稱、準確率與計算成本在後文說明。

    01a · 序列機率與溫度

    語言模型逐 token 給出序列的機率

    語言模型（LLM）把文字切成 token，詞彙表 $\mathcal X$ 是所有 token 的集合。一條序列寫成 $x_{0:T}=(x_0,x_1,\dots,x_T)$，$T$ 是最後一個位置的索引；$x_{\lt t}$ 表示位置 $t$ 之前的前綴，$x_{>t}$ 表示位置 $t$ 之後的後綴（§3）。模型在每個位置給出下一個 token 的條件分佈 $p(x_t\mid x_{\lt t})$，稱為 next-token 分佈。

    序列機率如何由 next-token 分佈得到：整條序列的機率等於各位置條件機率的連乘，$p(x_{0:T})=\prod_{t=0}^{T}p(x_t\mid x_{\lt t})$（式 1）。逐 token 取樣就是從這個聯合分佈取樣。一條序列的 $p$ 值稱為它的 likelihood，取對數後的和稱為 log-likelihood；長序列的機率連乘可能低於浮點數下限，實作時一律用 log-likelihood 相加。低溫取樣做什麼：低溫取樣在每一步把 next-token 機率 $p(x_t\mid x_{\lt t})$ 取 $\alpha$ 次方再正規化，對應的溫度是 $\tau=1/\alpha$（式 3）；$\tau$ 越小，每一步的分佈越集中在機率最高的 token。

    $$p(x_{0:T})=\prod_{t=0}^{T}p(x_t\mid x_{\lt t}),\qquad p_{\text{temp}}(x_t\mid x_{\lt t})=\frac{p(x_t\mid x_{\lt t})^\alpha}{\sum_{x'_t\in\mathcal X}p(x'_t\mid x_{\lt t})^\alpha}$$
    式 (1)(3)

    本文的 base model 指作為取樣對象、不再訓練的既有模型。實驗用的 Qwen2.5-Math-7B 與 Qwen2.5-7B 是預訓練模型；Phi-3.5-mini-instruct 是 instruct 版，已經過後訓練（Abdin 2024），論文沒有說明細節，但仍稱它為 base model。

    $p$
    base model 的序列分佈；$p(x_t\mid x_{\lt t})$ 是 next-token 分佈。
    $\alpha$、$\tau$
    冪次（$\alpha>1$，主實驗 4.0）、溫度（低溫取樣用 $\tau=1/\alpha$）。
    $p_{\text{temp}}$、$p_{\text{pow}}$

    $F(x_{\le t})$
    未來修正項（03b 節，本頁推導）。

    檢查理解

    序列機率如何由 next-token 分佈得到？低溫取樣做什麼？

    $p(x_{0:T})=\prod_t p(x_t\mid x_{\lt t})$（式 1）；低溫取樣每步把 $p(x_t\mid x_{\lt t})$ 取 $\alpha$ 次方再正規化，溫度 $\tau=1/\alpha$（式 3）。

    01b · RL 與銳化假說

    RL 後訓練與分佈銳化假說

    RL 後訓練用強化學習繼續訓練語言模型：模型生成回答，自動驗證器（例如比對數學題的最終答案）給出獎勵，再依獎勵更新參數。這類方法稱為 RLVR（reinforcement learning with verifiable rewards）。GRPO（Group Relative Policy Optimization）是其中常用的一種演算法，它對同一題取樣一組回答，以組內標準化後的獎勵作為更新權重；本頁不需要它的數學細節，只把它當作比較基準。

    近期文獻問：RL 後訓練學到的是 base model 原本不會產生的推理方式，還是只把 base model 的分佈變得更集中（§1）？後者稱為分佈銳化（distribution sharpening）假說。支持後者的觀察有兩項：RL 後模型的輸出集中在 base model 的高 likelihood 區域（Yue 2025）；以多次作答評分時，作答次數多時 base model 的分數較高（He 2025、Song 2025；這個多次作答指標稱為 pass@k，08 節定義）。

    作者的推論是：如果 RL 後訓練只是銳化，那麼應該能直接寫出一個「銳化後」的目標分佈，從 base model 取樣而不必訓練。這是動機與假說，本文沒有證明 RL 只做銳化。

    延伸閱讀：RLVR 與 GRPO：本文要對照的 RL 基準、分布銳化之爭：RL 後訓練是否只讓 base model 變尖

    02 · 冪分佈

    冪分佈把高機率序列的相對權重放大

    作者選擇的目標是冪分佈（power distribution）$p^\alpha$：每條序列的權重是 $p(x)^\alpha$，再對所有序列正規化（§4.1）。Eq. 2 說什麼：若 $p(x)>p(x')$，則 $p(x)^\alpha/p(x')^\alpha>p(x)/p(x')$，也就是高 likelihood 序列相對於低 likelihood 序列的權重比上升。本頁把「相對權重比依 Eq. 2 上升」稱為銳化。這個不等式需要 $\alpha>1$；論文寫的範圍是 $\alpha\in[1,\infty]$，但在 $\alpha=1$ 時兩邊相等，嚴格不等號不成立。

    $$p(x)>p(x')\ \Longrightarrow\ \frac{p(x)^\alpha}{p(x')^\alpha}>\frac{p(x)}{p(x')}$$
    式 (2)

    論文勘誤 E1 · 式 (2)

    論文寫 $\alpha\in[1,\infty]$；$\alpha=1$ 時兩邊相等，依嚴格不等號應為 $\alpha>1$。

    pp⁴（正規化後）

    混合參數為本頁示範值 示範值；論文 Fig. 2 未給參數。$p(y)=0.6\,\mathcal N(-1,0.6^2)+0.4\,\mathcal N(1.5,0.4^2)$。取 4 次方後，較高的峰占了大部分質量。

    $p^\alpha$ 的未正規化值可以直接由 base model 算出：算出 log-likelihood 再乘以 $\alpha$。困難在正規化：要從 $p^\alpha$ 取樣，需要對所有可能序列加總 $p(x)^\alpha$，序列數隨長度指數增加，無法計算。05 節處理這個問題。統計物理稱 $p^\alpha$ 為退火（annealed）或回火（tempered）分佈（Neal 1998）。

    延伸閱讀：退火與回火取樣：從統計物理到擴散模型的推論時取樣

    檢查理解

    Eq. 2 說什麼？α 需要什麼條件？

    若 $p(x)>p(x')$，則 $p(x)^\alpha/p(x')^\alpha>p(x)/p(x')$，高 likelihood 序列的相對權重上升；須 $\alpha>1$，論文寫的 $\alpha\in[1,\infty]$ 在 $\alpha=1$ 時兩邊相等。

    03a · 兩 token 的例子

    兩個 token 的例子：低溫與冪分佈給出不同答案

    先固定用詞：本頁說「某取樣法偏好 token a」，意思是 a 在該取樣法下得到較大的相對權重。

    Example 1（§4.1）：詞彙只有 a、b，序列只有兩個 token $(x_0,x_1)$，此處 $x_0$ 是第一個生成的 token。四條序列的機率是 $p(aa)=0.00$、$p(ab)=0.40$、$p(ba)=0.25$、$p(bb)=0.25$，所以第一個 token 的邊際權重是 $p(x_0=a)=0.40$、$p(x_0=b)=0.50$。取 $\alpha=2.0$。

    冪分佈先對每條完整序列取平方再相加：a 開頭得到 $0.00^2+0.40^2=0.160$，b 開頭得到 $0.25^2+0.25^2=0.125$，所以冪分佈的 a 權重較大。低溫取樣先把同一開頭的序列機率相加，再取平方：a 得到 $(0.00+0.40)^2=0.160$，b 得到 $(0.25+0.25)^2=0.250$，所以低溫的 b 權重較大。α=2 時兩種取樣對 a、b 的權重因此是：冪分佈 0.160 對 0.125（a 的權重較大），低溫 0.160 對 0.250（b 的權重較大）。

    原因是兩個開頭的未來不同：a 之後只有一條未來 ab，機率 0.40；b 之後有兩條未來 ba、bb，各只有 0.25。低溫取樣把 b 的兩條未來先加總成 0.50，冪分佈則對每條未來分別取平方，兩條 0.25 的平方和小於一條 0.40 的平方。

    例子有什麼瑕疵：四個機率總和是 0.90，不是 1。因為兩種取樣都只比較相對權重，大小關係不受影響。正規化後（本頁推導），冪分佈 $P(x_0=a)=0.160/0.285=0.561$，低溫 $0.160/0.410=0.390$。冪分佈給 a 較大權重的條件是 $0.4^\alpha>2\cdot0.25^\alpha$，即 $\alpha>\ln2/\ln1.6\approx1.475$（本頁推導，利用 $p(aa)=0$ 與 $p(ba)=p(bb)$）。總和為 1 的版本 $p(ab)=0.45$、$p(ba)=p(bb)=0.275$ 得到相同的結論，翻轉點為 1.407。

    03b · 次方的和與和的次方

    一般情形：冪分佈是次方的和，低溫是和的次方

    Prop. 1 說低溫取樣不是從 $p^\alpha$ 取樣（§4.1）。固定前綴 $x_{\lt t}$，冪分佈的 next-token 條件分佈要把所有可能的後綴加總（式 4）；低溫取樣則可用條件機率的定義（論文稱為 Bayes rule，式 5）改寫成式 6。忽略正規化後，兩者的 next-token 相對權重各是：

    $$p_{\text{pow}}(x_t\mid x_{\lt t})\propto\sum_{x_{>t}}p(x_0,\dots,x_t,\dots,x_T)^\alpha$$
    式 (7)
    $$p_{\text{temp}}(x_t\mid x_{\lt t})\propto\Big(\sum_{x_{>t}}p(x_0,\dots,x_t,\dots,x_T)\Big)^\alpha$$
    式 (8)

    冪分佈的權重是「次方的和」（式 7），低溫的權重是「和的次方」（式 8）。把聯合機率拆成 $p(x_{\lt t})\,p(x_t\mid x_{\lt t})\,p(x_{>t}\mid x_{\le t})$，前綴項對所有候選 token 相同，可以得到（本頁推導）：冪分佈 = 低溫權重 × $F(x_{\le t})$，其中 $F(x_{\le t})=\sum_{x_{>t}}p(x_{>t}\mid x_{\le t})^\alpha$。$\alpha>1$ 時 $0\lt F\le1$，而且 $F=1$ 若且唯若選了 $x_t$ 之後只剩一條未來；未來分散到越多條路徑，$F$ 越小。低溫取樣等於把每個候選 token 的 $F$ 都當成 1。

    $$p_{\text{pow}}(x_t\mid x_{\lt t})\propto p(x_t\mid x_{\lt t})^\alpha\cdot F(x_{\le t}),\qquad F(x_{\le t})=\sum_{x_{>t}}p(x_{>t}\mid x_{\le t})^\alpha$$
    本頁推導

    用 Example 1 回驗：a 之後只有 ab，$F(a)=1^2=1$；b 之後 ba、bb 各占一半，$F(b)=0.5^2+0.5^2=0.5$。所以冪分佈 a 的權重是 $0.4^2\times1=0.160$，b 是 $0.5^2\times0.5=0.125$，與 03a 節的計算相同。

    兩者何時相同：$\alpha=1$；各候選 token 的 $F$ 相同；或位於最後一個位置 $t=T$（沒有未來，$F\equiv1$）。總結：冪分佈 ∝ $\sum_{x_{>t}}p(x_{0:T})^\alpha$（次方的和，式 7），低溫 ∝ $(\sum_{x_{>t}}p(x_{0:T}))^\alpha$（和的次方，式 8），冪分佈 = 低溫權重 × $F(x_{\le t})=\sum_{x_{>t}}p(x_{>t}\mid x_{\le t})^\alpha$（本頁推導），在 $\alpha=1$、各 token 的 $F$ 相同或 $t=T$ 時兩者相同。

    論文勘誤 E3 · Prop. 1 的證明

    對一般 $p$ 而言 Prop. 1 成立；但證明中「條件分佈在每個時間步都不同」在 $t=T$ 不成立（兩者相同），$\alpha=1$ 或確定性的 $p$ 時命題本身也不成立。

    檢查理解

    兩者的 next-token 相對權重各是什麼？何時相同？

    冪分佈 ∝ $\sum_{x_{>t}}p(x_{0:T})^\alpha$（次方的和，式 7）；低溫 ∝ $(\sum_{x_{>t}}p(x_{0:T}))^\alpha$（和的次方，式 8）；冪分佈 = 低溫權重 × $F(x_{\le t})$（本頁推導）；$\alpha=1$、各 token 的 $F$ 相同或 $t=T$ 時相同。
