# 255 Goldfish 驗收答案（僅依 page.txt）

**LO1**
- 答：序列機率是各位置 next-token 條件機率的連乘，$p(x_{0:T})=\prod_{t=0}^{T}p(x_t\mid x_{<t})$（式 1）；實作時改用 log-likelihood 相加，避免浮點數下限。低溫取樣在每一步把 next-token 機率取 $\alpha$ 次方再正規化，對應 $\tau=1/\alpha$（式 3），$\tau$ 越小分佈越集中。
- 段落：「低溫取樣在每一步把 next-token 機率」
- 信心：high

**LO2**
- 答：Eq. 2 說若 $p(x)>p(x')$，則 $p(x)^\alpha/p(x')^\alpha>p(x)/p(x')$，高 likelihood 序列的相對權重比上升，本頁稱為「銳化」。不等式需要 $\alpha>1$；α=1 時兩邊相等。頁面另將論文的 α∈[1,∞] 列為勘誤 E1。
- 段落：「這個不等式需要 α>1」
- 信心：high

**LO3**
- 答：α=2 時，冪分佈權重 a 0.160 對 b 0.125（a 較大）；低溫權重 a 0.160 對 b 0.250（b 較大）。例子的瑕疵是四個機率總和為 0.90 而非 1（勘誤 E2），但排序結論不受影響。
- 段落：「四個機率總和是 0.90，不是 1」
- 信心：high

**LO4**
- 答：冪分佈的 next-token 權重是「次方的和」$\sum_{x_{>t}}p(x_{0:T})^\alpha$（式 7）；低溫是「和的次方」$(\sum_{x_{>t}}p(x_{0:T}))^\alpha$（式 8）。兩者相差 $F(x_{\le t})$。相同條件：α=1、各候選 token 的 F 相同，或位於最後位置 t=T。
- 段落：「兩者何時相同：α=1」
- 信心：high

**LO5**
- 答：條件是 $\varepsilon'/N^{1-1/\alpha}<\varepsilon<\varepsilon'$（式 14），並需 $\varepsilon>\varepsilon'/N$（式 15），且需 N>1、α>1。頁面例子 ε=0.4、ε′=0.5、N=2、α=2 的下界為 0.354，落在區間內。這只說明「一條未來 vs N 條均勻未來」極端模型下的權重大小，沒有證明所選答案較正確。
- 段落：「沒有證明這樣選出的答案較正確」
- 信心：high

**LO6**
- 答：不能直接從 $p^\alpha$ 取樣，因為正規化要對所有序列求和，不可計算。MH 的接受率只用 $p^\alpha$ 的比值，正規化常數相消；細緻平衡（detailed balance）使 $p^\alpha$ 成為平穩分佈。收斂需要提議分佈不可約與非週期（Def. 1，引用 Neal 1993，論文未證明）。頁面另指出還需要提議對支撐內序列給正機率，且雙向提議機率同時為正。
- 段落：「論文要求提議分佈不可約」；「的正規化要對所有序列求和，不可計算」
- 信心：high

**LO7**
- 答：提議為同一 base model、未截斷、$\tau=1/\alpha$ 時，接受率化成 $A=\min\{1,\prod_{t=m}^{L}Z_t(x'_{<t})/Z_t(x_{<t})\}$，其中 $Z_t=\sum_v p(v\mid x_{<t})^\alpha$。$Z_t$ 越大，該步分佈越集中。只重取區塊最後一個 token 時 A=1，必接受。
- 段落：「接受率化成（本頁推導）比值」
- 信心：high

**LO8**
- 答：每階段先用 $p_{\text{prop}}$ 延伸 B 個 token（第 3 行），再跑 $N_{\text{MCMC}}$ 次隨機位置重取的 MH（第 4–9 行），目標為 $\pi_{k+1}\propto p(x_{0:(k+1)B})^\alpha$。第 7 行的接受率應寫 $\pi_{k+1}$，原文寫成 $\pi_k$（勘誤 E4）。第 10 行的「fix the new prefix」只是下一階段的初始化，前綴並未凍結，因為第 5 行的 m 從 1 起抽。
- 段落：「第 7 行的接受率卻寫」；「第 10 行不凍結前綴」
- 信心：high

**LO9**
- 答：論文報告的成本倍數是 $N_{\text{MCMC}}T/(4B)=10\times679/(4\times192)=8.84$ 倍。照 Eq. 12 精確求和：K=4，$10\times96\times(1+2+3+4)=9600$ 個 token，約 14.14 倍；把最後區塊截到 679 並加上初始化後，約 13.5–14.5 倍。近似式對應 $(T/B)^2/2$，用平均長度代入會低估平均成本。
- 段落：「10×679/(4×192)=8.84」；「10×96×(1+2+3+4)=9600」
- 信心：high

**LO10**
- 答：Power sampling 低於 GRPO 的格有 4 個：Qwen2.5-Math-7B 與 Qwen2.5-7B 在 MATH500（0.748 對 0.785、0.706 對 0.740）與 GPQA（0.389 對 0.399、0.318 對 0.354）。Phi-3.5 在這兩欄較高；HumanEval 與 AlpacaEval 三個模型都高於 GRPO。相對 base 的差值：9 個推理格中 8 格「低溫−base」占「power−base」的 62%–77%，例外是 Phi-3.5 GPQA（22%）。這是數字分解而非因果，論文沒有消融也沒有誤差棒。AlpacaEval 不適用此比例。
- 段落：「只有 Phi-3.5 在這兩欄較高」；「8 格的「低溫 − base」占」
- 信心：high

**LO11**
- 答：內文說 k>1 時 power sampling 高於 GRPO，大 k 時與 base 收斂。圖說的過度宣稱是「strictly better than both GRPO and the base model」：k=1 時依 Table 1，GRPO 0.785 高於 power 0.748；圖說同時寫大 k 時與 base 相同，所以對 base 也不是嚴格較高（勘誤 E5）。頁面沒有讀出 Fig. 5 的數值。

## 初學者可能卡住的地方

1. 符號很多（$x_{<t}$、$x_{>t}$、ε、ε′、N、F、$Z_t$、$\pi_k$），分散在各節與符號表中，容易混淆。
2. 「次方的和 vs 和的次方」與 F(x≤t) 的推導標為「本頁推導」，不是論文結論，初學者難以分辨哪些是論文的、哪些是頁面自行推的。
3. MH、平穩分佈、細緻平衡只給一行式子，收斂條件需要讀者自行補充。
4. Algorithm 1 的索引（$\pi_k$ 對 $\pi_{k+1}$）與「不凍結前綴」容易誤讀，且勘誤 E4 在行內。
5. 成本數字 8.84 倍（論文近似式）與 14.14 倍（式 12 精確和）差距大；T 是平均長度還是上限（3072）也需要對照清楚。
