 不訓練，只取樣：從 base model 的冪分佈取樣做推理

 這篇論文只用既有模型自己給的機率挑選回答，不再訓練，單次作答的準確率接近經過強化學習後訓練的模型（後文說明）。

 Aayush Karan、Yilun Du（2025）〈Reasoning with Sampling: Your Base Model is Smarter Than You Think〉

 01 · 取樣目標base model 指作為取樣對象、不再訓練的既有語言模型，它對每條回答序列 x 給出機率 p(x)。本文的取樣目標是 p(x)α（α 是大於 1 的冪次，論文用 4），它使機率較高的回答得到更大的相對權重。

 02 · 和低溫取樣不同常用的低溫取樣在每一步把下一個 token 的機率取 α 次方再重新正規化。這和對整條序列的機率取 α 次方得到的分佈不同（03a 節用一個兩 token 的例子說明）。

 03 · 反覆重取直接從 p(x)α 取樣需要對所有可能序列加總，無法計算。作者改為反覆執行：隨機選一個位置，從該位置重新生成到目前區塊結尾，再依新舊序列的機率比值決定是否接受。這個方法的名稱、準確率與計算成本在後文說明。

 01b · RL 與銳化假說

 RL 後訓練與分佈銳化假說

 RL 後訓練用強化學習繼續訓練語言模型：模型生成回答，自動驗證器（例如比對數學題的最終答案）給出獎勵，再依獎勵更新參數。這類方法稱為 RLVR（reinforcement learning with verifiable rewards）。GRPO（Group Relative Policy Optimization）是其中常用的一種演算法，它對同一題取樣一組回答，以組內標準化後的獎勵作為更新權重；本頁不需要它的數學細節，只把它當作比較基準。

 近期文獻問：RL 後訓練學到的是 base model 原本不會產生的推理方式，還是只把 base model 的分佈變得更集中（§1）？後者稱為分佈銳化（distribution sharpening）假說。支持後者的觀察有兩項：RL 後模型的輸出集中在 base model 的高 likelihood 區域（Yue 2025）；以多次作答評分時，作答次數多時 base model 的分數較高（He 2025、Song 2025；這個多次作答指標稱為 pass@k，08 節定義）。

 作者的推論是：如果 RL 後訓練只是銳化，那麼應該能直接寫出一個「銳化後」的目標分佈，從 base model 取樣而不必訓練。這是動機與假說，本文沒有證明 RL 只做銳化。

 03a · 兩 token 的例子

 兩個 token 的例子：低溫與冪分佈給出不同答案

 先固定用詞：本頁說「某取樣法偏好 token a」，意思是 a 在該取樣法下得到較大的相對權重。

 04 · Prop. 3

 冪分佈給「未來路徑少但機率高」的 token 較大權重

 05a · Metropolis-Hastings

 Metropolis-Hastings 只需要未正規化的權重

 為何不能直接從 pα $p^\alpha$ 取樣：pα $p^\alpha$ 的正規化要對所有序列求和，不可計算（§4.2）。作者改用 Markov chain Monte Carlo（MCMC）中的 Metropolis-Hastings（MH）。Markov chain 是一串狀態 x0,x1,… $x^0,x^1,\dots$ ,x1,…，下一個狀態只依目前狀態隨機產生；若鏈走得夠久，狀態出現的頻率會趨近某個固定分佈，稱為平穩分佈。MH 的設計使平穩分佈正好是目標 pα $p^\alpha$ 。

 每一步，MH 用提議分佈（proposal distribution）q(x∣xi) $q(x\mid x^i)$ ) 從目前狀態 xi $x^i$ 產生候選 x $x$ ，以下列機率接受（xi+1=x $x^{i+1}=x$ =x），否則留在原地（xi+1=xi $x^{i+1}=x^i$ =xi）：

 A(x,xi)=min⁡{1, pα(x) q(xi∣x)pα(xi) q(x∣xi)} $A(x,x^i)=\min\Big\{1,\ \frac{p^\alpha(x)\,q(x^i\mid x)}{p^\alpha(x^i)\,q(x\mid x^i)}\Big\}$ )=min{1, pα(xi)q(x∣xi)pα(x)q(xi∣x)​}
式 (9)

 MH 為何可行：MH 接受率式 9 只用 pα $p^\alpha$ 的比值，正規化常數在分子分母相消。平穩分佈成立的理由可以寫成一行（本頁推導）：pα(x) q(x′∣x) A(x′,x)=min⁡{pα(x)q(x′∣x), pα(x′)q(x∣x′)} $p^\alpha(x)\,q(x'\mid x)\,A(x',x)=\min\{p^\alpha(x)q(x'\mid x),\,p^\alpha(x')q(x\mid x')\}$ (x)q(x′∣x)A(x′,x)=min{pα(x)q(x′∣x),pα(x′)q(x∣x′)}，這個式子對 x $x$ 、x′ $x'$ 對稱（detailed balance），所以 pα $p^\alpha$ 是平穩分佈。

 收斂需要什麼：論文要求提議分佈不可約（irreducible，能到達 pα $p^\alpha$ 有質量的任何集合）且非週期（aperiodic）（Def. 1），收斂結果引用 Neal 1993，論文沒有證明。實際上還需要兩個論文略過的條件（本頁推導）：提議對 pα $p^\alpha$ 支撐內的序列給正機率，且雙向提議機率同時為正（q(x′∣x)>0 $q(x'\mid x)>0$ ∣x)>0 若且唯若 q(x∣x′)>0 $q(x\mid x')>0$ )>0），否則式 9 的比值沒有定義；非週期則來自拒絕時留在原地的自環。τ=1/α $\tau=1/\alpha$ 的全詞彙取樣滿足這些條件，greedy、top-k、top-p 等截斷取樣不一定滿足。

 量測結果（單次執行、無誤差棒）

 Power sampling 在哪些格低於 GRPO：兩個 Qwen 模型在 MATH500（0.748 對 0.785、0.706 對 0.740）與 GPQA（0.389 對 0.399、0.318 對 0.354）都低於 GRPO；只有 Phi-3.5 在這兩欄較高。HumanEval 與 AlpacaEval 高於 GRPO，三個模型皆然。

 表中相對 base 的差值有多少比例低溫取樣列也有（本頁推導）：9 個推理格（3 個模型 × MATH500、HumanEval、GPQA）中，8 格的「低溫 − base」占「power − base」的 62%–77%（例外 Phi-3.5 GPQA 22%）。例如 Qwen2.5-Math 的 MATH500，base 到低溫增加 0.194，低溫到 power 再增加 0.058。這是表中數字的分解，不是因果歸因：power sampling 的提議本身就是 τ=1/α $\tau=1/\alpha$ 的取樣器，論文沒有做消融，也沒有誤差棒。GPQA 只有 198 題，差值只有數題：Qwen2.5-Math 為 base 55、低溫 70、power 77、GRPO 79 題；Qwen2.5-7B 為 55、60、63、70 題，也就是 power − base 8 題對低溫 − base 5 題；Phi-3.5 為 54、58、72、71 題。AlpacaEval 不適用這個比例：Qwen2.5-7B 的低溫（5.29）低於 base（7.05），Phi-3.5 的低溫（18.15）高於 power（17.65）。Base 與 Low-temperature 列用的溫度論文沒有寫（推測分別為 1 與 1/α $1/\alpha$ ）。論文的「+25.2%」「+51.9%」「+59.8%」是百分點差；+59.8 是對 Phi-3.5 的 GRPO 算的，而該 GRPO 的 HumanEval（0.134）低於 base（0.213）。

 作者認為：在 RL 的訓練領域 MATH500 上與 GRPO「on par」，在領域外的任務可以高於 GRPO，AlpacaEval 的結果顯示方法可推廣到無法自動驗證的領域（§5.2）。

 Likelihood、confidence 與長度（Fig. 4，Qwen2.5-Math-7B，MATH500）

 論文沒有給 Fig. 4 的數值，以下只轉述，兩項分開。Log-likelihood（依長度平均，相對於 base model）：GRPO 的回答 "heavily concentrated at the highest likelihood peak"；power sampling 位於較高 likelihood 的區域，但 "maintains noticeable spread"。Confidence（式 13，每步 next-token 分佈的平均負熵，值 ≤ 0，越接近 0 表示每步越集中）：power sampling 與 GRPO 位於 "similarly high confidence regions"。平均回答長度：base 600、GRPO 671、power sampling 679 個 token；作者認為這是取樣過程「自然出現」的。

 pass@k（Fig. 5、App. A.2）

 pass@k 的定義：每題取 k 個樣本，只要至少一個正確就算解出。Fig. 5 內文說什麼：k>1 時 power sampling 高於 GRPO，大 k 時與 base 收斂（"supersedes that of the base model until finally converging"）。圖說的哪句話過度宣稱：圖說的「strictly better than both GRPO and the base model」不成立：k=1 時依 Table 1 GRPO 0.785 高於 0.748，且同一圖說寫大 k 時與 base 相同（"our pass rate at high k matches the base model"）。Fig. 5 的數值本頁沒有讀出，論文也沒有說明 Fig. 5 的 k=1 與 Table 1 是否同一設定。

 論文勘誤 E5 · Fig. 5 圖說
圖說寫 power sampling「strictly better than both GRPO and the base model」。k=1 時依 Table 1 是 GRPO 較高（0.785 對 0.748）；同一圖說又寫大 k 時與 base 相同，所以對 base 也不是嚴格較高。

 作者判斷（App. A.2，無數值）：k>1 時 power sampling "near universally better performance than both GRPO and the base model"；HumanEval 的 pass@k 用 α=1.67 $\alpha=1.67$ ，因為 "this temperature exhibits slightly better results at earlier k"；HumanEval 上 GRPO "exhibits better pass@k than the base model until k = 16"，作者猜測原因是程式題可以有多個正確解。
