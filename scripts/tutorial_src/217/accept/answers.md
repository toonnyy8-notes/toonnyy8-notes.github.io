# 217 Goldfish 驗收：LO1–LO12 作答

僅依 page.txt 作答，未使用頁面以外的知識。

**LO1**
- 答：論文認為像素空間模型浪費最大，因為潛空間模型先用 VAE 移除大部分低階空間冗餘，像素空間模型沒有這一步，每個區塊都要處理這些冗餘。MiniT2I-B/16 在 512² 解析度、patch 大小 16 下，為 32×32 的格，共 N=1024 個 patch token。
- 段落：「以 512² 解析度、patch 大小 16 計算」
- 信心：high

**LO2**
- 答：Fig. 2 從三個方向量冗餘。空間上，依完成影像的梯度能量排序，最細節的 15% patch 占一半細節（前一半占 88%）。時間上，把 N=1024 匯集成 R=256 組時，中段區塊的 EV 隨影像成形上升，依內容分組全程高於等大方格。深度上，EV 由第一塊的 61% 升到中段約 75%，再往最後一塊下降。
- 段落：「最細節的 15% patch 占一半細節」
- 信心：high

**LO3**
- 答：EV 的 1 表示匯集後的 token 完整攜帶原本的表示；0 表示匯集後不比一個常數好。EV 量的是區塊激活的線性餘裕，不是輸出影像的品質。R=256 時約 26% 無法回收，論文以此說明要保留全解析度的末段區塊（coda）與可學習的 WRITE。
- 段落：「這 26% 是 RTI 保留全解析度」
- 信心：high

**LO4**
- 答：四個要求是連通、大小隨內容、位置、匯總。Feat Sim 失去連通與位置；Latent Array 失去分組（因而失去連通）與位置；Token Skip 失去匯總；三者都失去大小隨內容。
- 段落：「四個要求是連通、大小隨內容、位置、匯總」
- 信心：high

**LO5**
- 答：Hilbert 曲線上相鄰位置在格中一定相鄰，所以任一連續段都占據一塊相連區域。raster 在行尾斷開，Morton（Z）在二元方格邊界以對角跳躍連接。
- 段落：「曲線上相鄰位置在格中一定相鄰」
- 信心：high

**LO6**
- 答：RTI 先算曲線上相鄰 patch 的特徵距離 $d_j$（Eq. 1），在最大的 R−1 個距離處切開（Eq. 2），相鄰切點之間的 R 段即為區域。此規則無參數，成本 O(N)（掃一次加線性時間選擇）。每個去噪步都從當前狀態 $x_t$ 重算。
- 段落：「這條規則沒有參數，成本是」
- 信心：high

**LO7**
- 答：區域 token 由兩部分組成：區域內 softmax 權重 $\alpha_j$ 的加權平均（評分為 $w^\top h_j$，全模型只有一個 $w$），加上尺寸嵌入 $e_{\text{size}}[\lfloor\log_2|c|\rfloor]$（Eq. 3）。
- 段落：「區域 token 由兩部分組成」
- 信心：high

**LO8**
- 答：區域 token 的位置取其 patch 的 RoPE 單位相量平均。波長長於區域範圍的分量仍接近長度 1，短波長的分量縮向 0，所以區域越大，位置越粗（低通效果）。
- 段落：「區域 token 的位置取其 patch 旋轉位置嵌入」
- 信心：high

**LO9**
- 答：Eq. 4 為 $h_j^{(s_1+1)}=h_j^{(s_0)}+g([h_j^{(s_0)}\Vert z'_c-z_c])$。每個 patch 以自己的 $g$ 產生更新，同區域的 patch 可各自特化；天真廣播則是每個 patch 都加上同一個 $z'_c-z_c$。coda 仍能逐像素輸出，因為這個形式是一條繞過核心的跳接：每個 patch 保留進核心前的特徵，核心只當作修正量接收，核心從未看過個別 patch。
- 段落：「核心從未看過個別 patch」
- 信心：high

**LO10**
- 答：訓練時主幹凍結，只更新 rank-32 的 LoRA 與 READ/WRITE（恆等初始化）。每一步從 {64, 128, 256, 512} 隨機抽一個 $R$，所以訓練完成後才設定預算。未見過的 96、192、384 落在同一條品質曲線上。
- 段落：「未見過的 96、192、384 落在同一條品質曲線上」
- 信心：high

**LO11**
- 答：B/16 速度在約 2.5× 飽和，因為前段（prelude）、末段（coda）與文字串流都不縮短，R 低於約 192 後再減少預算只降品質、不再加速。1.8 s/張的比較是 L/16（附錄 B.3）：dense 每步 288 ms，RTI（R=256）每步 112 ms；同樣 1.8 s 內 dense 只能跑 6 步、RTI 跑 16 步，GenEval 為 65.9 對 82.7。超過約 5 s 後，增加步數較划算。
- 段落：「B/16 速度在約 2.5× 飽和」
- 信心：high

**LO12**
- 答：B/16 在 R=256 時速度 2.15×、GenEval 84.7（dense 87.2）；在 R=512 時速度 1.84×、GenEval 87.8，超過 dense。同預算（以 RTI R=256 為基準）下三個基準的代價是：Token Skip 少 2.4 GenEval（但速度僅 1.19×，不是同預算比較）、Feat Sim 少 4.2、Latent Array 少 39.0。
- 段落：「主結果：B/16 在 R=256」
- 信心：high

## 頁面未提供或信心偏低

- LO 無完全缺漏。唯一缺口：頁面未提供 $g$ 的層數與寬度，也未提供 $e_{\text{size}}$ 的維度（Sec. 9、Sec. 14）。這不影響 LO9 與 LO7 的答案，但影響「怎麼實作」。
- LO3 的「匯集後不比一個常數好」信心 high，但頁面對「為何 EV 不等於品質」只有一句，信心 medium 以下的說法不要用在教學上。
- LO5 的「任一連續段連通」與「對齊段三者都連通」兩句在頁面中需要自行區分，已依頁面寫出。

## 初學者可能卡住的地方

1. 連通性的範圍：頁面一方面說 Hilbert 任一連續段都連通，另一方面說只有不對齊的段才會在 raster、Morton 斷開；後者標為「本頁推導」。初學者容易不知道哪句是論文原文。
2. EV 與品質的差別：EV 0.74 不是「74% 品質」，頁面要到 Sec. 2 結尾才說清楚；讀者容易把 EV 當成生成品質。
3. 預算 R 與 token 數：R 是區域（即核心中的 token）數，不是 patch 數；R=512 時核心只看 512 個 token，但 1024 個 patch 仍在 READ/WRITE 兩端存在。頁面沒有把這兩個數字並排說清楚。
4. B/16 與 L/16 混用：2.5× 飽和、1.8 s 的 6 步對 16 步、288 ms 與 112 ms，都屬於 L/16 或 B/16 的不同情境，頁面沒有在每個數字旁標主幹，容易張冠李戴。
5. 公式符號密集：Eq. 3、Eq. 4、成本模型 $\rho$ 中的 $\eta$、$\nu$、$\tau$ 只在局部定義，且 $\tau\approx0.073$ 是「本頁推導」而非論文數字，初學者不易分辨。
