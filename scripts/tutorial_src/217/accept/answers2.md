# 驗收作答：LO5、LO9

## LO5

**問題**：為什麼 Hilbert 序列的任一連續段都是連通區域？raster 與 Morton 何處斷開？

**答案**：
- Hilbert 曲線恰好走過 $2^k\times2^k$ 格的每一格一次。任一連續段都是連通區域，原因是曲線上相鄰位置在格中一定相鄰；因此任何一段連續位置都占據影像中一塊相連的區域，大小任意，不一定是正方形。
- 更強的性質：每個二元方格（dyadic cell，quadtree 會產生的正方形）恰好是 Hilbert 序列上的一段連續位置。所以任何 quadtree 分割都能用切割 Hilbert 序列表達，切割還能表達 quadtree 做不到的分割。
- raster 在行尾斷開；Morton（Z）順序在二元方格邊界以對角跳躍連接。
- 長度為 $2^m$、從對齊位置開始的段，三種順序都連通（本頁推導）；斷裂只出現在不對齊的段。RTI 的切點可落在任何位置，所以順序的連通性在自適應切割下才重要。
- 數值例（$q=8$、段長 $L=8$、起點 $p=4$）：Hilbert 為 1 塊（一塊相連的 2×4 區域），Morton 為 2 塊，raster 為 2 塊。連通比例：Hilbert 1.000、Morton 0.561、raster 0.140。把 $p$ 改成 0（對齊）時三者都連通。
- 在 $32\times32$ 格上：Hilbert 的連通比例恆為 1；raster 在 $L=16$ 時只有約 54% 的段連通，Morton 約 51%。
- 連通性的效益（凍結模型，$R=256$、依內容切割）：retained 依序 Hilbert 0.735、Morton 0.720、raster 0.697；每個 patch 到組中心的距離分別為 1.49、1.73、3.85 格。Morton 與 Hilbert 只差 0.015。

**passage used**：「原因是曲線上相鄰位置在格中一定相鄰」
**confidence**：高

## LO9

**問題**：Eq. 4 與「把 $z'_c-z_c$ 加到每個 patch」有何不同？為何 coda 仍能逐像素輸出？

**答案**：
- Eq. 4：$h_j^{(s_1+1)}=h_j^{(s_0)}+g\big([\,h_j^{(s_0)}\,\Vert\,z'_{c(j)}-z_{c(j)}\,]\big)$。
- 天真廣播是把同一個 $z'_c-z_c$ 原樣加到區域內每個 patch，同一區域的 patch 會一起移動。Eq. 4 中每個 patch 以 $g$ 讀入自己的特徵 $h_j^{(s_0)}$ 與區域差 $z'_c-z_c$，產生自己的更新，因此同一區域的 patch 可以各自特化，而不是一起移動。
- Eq. 4 同時是一條繞過核心的跳接：每個 patch 保留進核心之前的特徵，把核心的工作當作修正量接收。核心從未看過個別 patch，所以末段（coda，$s_1$ 之後的區塊）仍能產生逐像素的輸出。
- 對照：末段要把特徵轉回逐像素輸出，若共享的區域更新使輸出模糊，因此末段保持全解析度。
- 消融：把整個可學習的 READ/WRITE 換成平均匯集與廣播寫回，GenEval 下降 7.2（Fig. 8b）。
- 初始化：READ 與 WRITE 都初始化為恆等，訓練從凍結模型的行為出發。論文未給出 $g$ 的層數與寬度，也未給出 $e_{\text{size}}$ 的維度。

**passage used**：「核心從未看過個別 patch」
**confidence**：中高（機制與 7.2 的數字明確；$g$ 的結構論文未寫，只能描述到「以 $g$ 映射」）
