 RTI：把影像 patch 排成一條線，在內容變化最大處切開

 這篇論文把預訓練像素擴散模型中段的 patch token 換成數量可調的區域 token，一個模型可在 64–512 個 token 的範圍內任選。

 Eduard Zamfir、Christian Reisswig、Zongwei Wu、Yongqin Xian、Radu Timofte（2026）〈Elastic Token Compression for Pixel-Space Diffusion Transformers〉

 8×8 格上的 Hilbert 曲線；三個切點把它分成四段，每段都是相連的一塊。

 01 · 重複的計算自然影像的細節集中在少數小方塊（patch）。在已訓練好的像素擴散模型裡，中間幾層對平坦區域的計算大多是重複的。

 02 · 一條線上的切割RTI 把所有小方塊排成一條不斷線的路徑，在相鄰內容變化最大的地方切開，每一段合成一個 token。

 03 · 一個模型、多種預算同一個模型可在 64–512 個 token 之間任選：B/16 用 512 個時，速度 1.84 倍、GenEval 87.8（原模型 1024 個、87.2）。

 01 · 背景

 擴散 Transformer 對每個 patch 分配相同計算量

 本節符號N $N$ ：patch token 數；xt $x_t$ ​：取樣過程中的狀態；x^ $\hat x$ ：網路預測的乾淨影像。

 擴散 Transformer（diffusion transformer，DiT）把影像切成規則的小方格，每一格稱為一個 patch，攤平成一個向量後當作一個 token。網路由一串區塊（block）串接而成，每個區塊包含一層注意力（attention）與一層 MLP。生成一張影像時，模型從純噪聲出發，反覆執行整個網路；執行一次稱為一個取樣步，一個取樣步等於整個網路的一次前向計算，本文的設定要跑 100 步（Sec. 4.1）。

 每個區塊的成本取決於 token 數 n $n$ ：注意力要比較每一對 token，成本約與 n2 $n^2$ 成正比；線性層對每個 token 各算一次，成本與 n $n$ 成正比。DiT 對每個 patch、在每個區塊、每個取樣步都分配相同的計算量，不論該 patch 是一片藍天還是一叢樹葉（Sec. 1）。

 本文的基礎模型是 MiniT2I-B/16：一個像素空間（JiT 系列）的文字到影像 DiT，主幹有 17 個區塊，影像 token 與凍結的 FLAN-T5 文字 token 並行。它以 rectified flow 訓練：狀態 xt $x_t$ ​ 在噪聲與乾淨影像之間內插，網路直接預測乾淨影像 x^ $\hat x$ ，而不是預測噪聲（Sec. 3.1）。RTI 只縮短影像 token 的序列，文字串流永遠保持全長。

 論文指出浪費在像素空間模型最大：潛空間模型由 VAE 先把影像壓成較小的潛變數，移除了大部分低階空間冗餘；像素空間模型沒有 VAE 先移除低階空間冗餘，每個區塊都要處理這些冗餘（Sec. 1）。以 512² 解析度、patch 大小 16 計算，一張影像是 32×32 的格，共 N=1024 $N=1024$ 個 patch token（Sec. 3.1），這就是 RTI 要縮短的序列。

 冗餘的形狀決定壓縮必須保留的四個性質

 本節符號pj $p_j$ ​：patch j $j$ 在格上的座標；wrj $w_{rj}$ ​：patch j $j$ 屬於第 r $r$ 組的權重（和為 1）；pr $p_r$ ​：組中心；spread：組內 patch 到中心的平均距離。

 本節比較三個既有的縮減方法，論文把它們都放進同一個介面重新實作（App. A）：

 04 · 核心區段

 RTI 只壓縮中段核心

 本節符號s0 $s_0$ ​、s1 $s_1$ ​：核心第一與最後一個區塊（含兩端點；B/16 為 3 與 13）。

 RTI 沿用 recurrent-depth Transformer（Geiping et al. 2025）的前段（prelude）／核心（core）／末段（coda）結構：中段一串連續區塊 [s0,s1] $[s_0,s_1]$ ​,s1​] 是核心。READ 在 s0 $s_0$ ​ 之前把 N $N$ 個 patch token 匯集成 R≪N $R\ll N$ 個區域 token，核心的每個區塊只處理這段短序列，WRITE 在 s1 $s_1$ ​ 之後把結果散回 N $N$ 個 patch；核心以外的區塊維持全解析度（Sec. 3.2）。B/16 的核心是 17 塊中的 [3,13] $[3,13]$ ，前後各留三塊。

 05 · Hilbert 順序

 Hilbert 曲線把二維分組變成一維切割

 本節符號q $q$ ：格邊長；π $\pi$ ：曲線誘導的順序，π(j) $\pi(j)$ 是第 j $j$ 個位置的 patch；連續段（run）：順序上一段連續的位置。

 四個要求中的連通與位置，都可由同一個排列 patch 的方式取得。Hilbert 曲線（Hilbert 1891）恰好走過 2k×2k $2^k\times2^k$ ×2k 格的每一格一次。Hilbert 序列的任一連續段都是連通區域，原因是曲線上相鄰位置在格中一定相鄰；所以任何一段連續位置都占據影像中一塊相連的區域，大小任意、不一定是正方形。更強的性質是：每個二元方格（dyadic cell，quadtree 會產生的那種正方形）恰好是 Hilbert 序列上的一段連續位置，所以任何 quadtree 分割都能用切割 Hilbert 序列表達，切割還能表達 quadtree 做不到的分割。其他順序沒有這個性質：raster 在行尾斷開，Morton（Z）順序在二元方格邊界以對角跳躍連接（Sec. 3.1、App. B.4）。

 於是二維的分組問題變成一維的切割問題：只要決定在序列的哪些位置切開。和 quadtree 相比，quadtree 也能隨內容調整大小，但每個區域綁定一個二元正方形，而且每張影像、每個取樣步都要建一棵樹；切 Hilbert 序列保留了隨內容調整大小，去掉了這兩個缺點（Sec. 3.3）。點雲 Transformer（Point Transformer V3）也用這條曲線，但只用來排列注意力的序列；本文用它定義分組本身（Sec. 2）。

 下面的元件比較三種順序。注意：長度為 2m $2^m$ 、從對齊位置開始的段，在三種順序下都連通（raster 的對齊段是一整行或一行的一段）〔本頁推導〕；斷裂只出現在不對齊的段。RTI 的切點可以落在任何位置，所以順序的連通性在自適應切割下才重要。

 06 · 切割規則

 在特徵變化最大的地方切割

 本節符號hj(s0)∈Rd $h_j^{(s_0)}\in\mathbb R^d$ (s0​)​∈Rd：進入核心時 patch j $j$ 的特徵；dj $d_j$ ​：曲線上相鄰兩 patch 的特徵距離；C $C$ ：切點集合。

 08 · 位置

 區域 token 的位置是相量的平均

 本節符號ω $\omega$ ：RoPE 的一個頻率；eiωp $e^{i\omega p}$ ：位置 p $p$ 在該頻率的單位相量；∣m(ω)∣ $|m(\omega)|$ ：區域內相量平均的長度。

 預訓練主幹用旋轉位置嵌入（rotary position embedding，RoPE）。對一個頻率 ω $\omega$ ，位置 p $p$ 對應旋轉角 ωp $\omega p$ ，也就是單位圓上的一個相量 eiωp $e^{i\omega p}$ ；注意力只看兩個 token 的旋轉角之差。模型用許多個頻率，高頻率的角度隨位置轉得快，低頻率轉得慢。

 數值例：取 ω=1 $\omega=1$ ，相鄰兩個位置 0 與 1 的旋轉角是 0 與 1 弧度，兩個相量的平均長度是 ∣cos⁡(1/2)∣=0.878 $|\cos(1/2)|=0.878$ ；取 ω=0.01 $\omega=0.01$ ，兩個角度幾乎相同，平均長度是 0.99999。平均後，角度轉得快（波長短）的分量變小，角度轉得慢（波長長）的分量幾乎不變；這種「保留長波長、削弱短波長」的效果稱為低通。

 區域 token 的位置取其 patch 旋轉位置嵌入（單位相量）的平均；波長長於區域範圍的分量仍接近長度 1，波長較短的分量縮向 0，所以位置依區域大小變粗（Sec. 3.4）。論文的說法是：單一 patch 的位置精確，大區域的位置粗略，這正適合代表一塊面積而不是一個點的 token。

 〔本頁推導〕一列長 L $L$ 、相鄰間隔 1 的直線區域，頻率 ω $\omega$ 的平均相量長度是 ∣sin⁡(ωL/2)Lsin⁡(ω/2)∣ $\left|\dfrac{\sin(\omega L/2)}{L\sin(\omega/2)}\right|$ ​Lsin(ω/2)sin(ωL/2)​​（等比級數求和）；L=1 $L=1$ 時為 1，ωL≪1 $\omega L\ll1$ 時接近 1。這個公式只適用於直線段（旁瓣與 ω>π $\omega>\pi$ 的混疊除外）；RTI 的區域是二維的 Hilbert 段，下面的元件直接數值求和。

 基準為何失敗

 Token Skip 保留的表示只有 RTI 分組的三分之一；它的稠密那一半核心每次都全量計算，使速度上限低於約 1.3×。Feat Sim 的 patch 離組中心 5.2 格（RTI 0.5），R=64 $R=64$ 時差距達 13.8 GenEval，在 R=256 $R=256$ 時兩個主幹的每個偏好分數都落後。Latent Array 訓練 40K 步後，一個潛變數的讀取注意力仍覆蓋 11.4 格（最大 12.2）；作者指出 Perceiver-IO 與 RIN 是為從頭訓練設計的（Sec. 4.2）。

 消融

 把切點改成沿同一順序等距放置（順序、預算與介面不變），R=128 $R=128$ 時 GenEval 下降 2.7，預算越大下降越少，因為 R=256 $R=256$ 時一區只有 4 個 patch，等距切點已接近自適應切點。換成平均與廣播下降 7.2。換成 latent array 則掉到 Latent Array 基準（Fig. 8b）。

 分割跟著影像成形

 以 x^ $\hat x$ 的梯度能量作為細節、1 個 patch 為細區域、16 個以上為粗區域：兩者在最吵的步驟攜帶相同的細節，隨影像成形拉開到約 6 倍；R=256 $R=256$ 、取樣中段時細緻度與細節的相關為 +0.58（Sec. 4.4、App. C.3）。切割只讀進入核心的特徵，從不讀細節量，所以這個對齊是模型自己做到的。區域大小的熵在 R=512 $R=512$ 時低、R=64 $R=64$ 時高；預算決定大小的範圍，影像決定細區域放在哪裡。

 分布指標與其他任務

 FID（MJHQ-30K，L/16）：RTI 比 Feat Sim 好 8.6（R=512 $R=512$ ）與 13.3（R=256 $R=256$ ），RTI 的 R=256 $R=256$ 還低於 Feat Sim 的 R=512 $R=512$ 。FID 是 RTI 在一半 token 時唯一沒追上 dense 的指標：R=512 $R=512$ 時高 2.4；作者的結論是壓縮先損失分布保真度，後損失組合準確率（App. B.1）。類別條件 ImageNet-256（JiT）：R=130 $R=130$ 時 B/16 的 FID 為 6.23，Feat Sim 為 15.99；R=64 $R=64$ 用 62% 的 token 計算量得 16.69，Token Skip 用 71% 得 19.11；L/16 在 R=193 $R=193$ （88% 計算量）得 2.42，公開的 dense 為 2.36（App. B.2）。

 順序消融（App. B.4）：R=256 $R=256$ 時三種順序的差異在噪聲內；預算越小越依局部性排序。R=64 $R=64$ 時 raster 比 Hilbert 低 0.268 PickScore 與 0.154 ImageReward，Morton 介於其間（0.153、0.083）。GenEval 上 raster 在 R=128 $R=128$ 與 64 低 3.2 與 4.6（遠超 ±1.6 的波動），Morton 維持參考值；作者的解讀是行尾斷裂傷害構圖，對角跳躍只損失知覺品質。
