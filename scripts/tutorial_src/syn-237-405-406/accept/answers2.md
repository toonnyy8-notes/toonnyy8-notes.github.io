## LO4

**段落**：「這個結果不能說明 ES 的效果」；「所以 c = σ^α 回到 Thm 5.1」（指 Thm B.1 對應）

## LO5

**答**：
- 換算結果（**本頁推導**，論文沒有寫）：DDPM-IP 的貝氏最佳網路（訓練損失的最小值），經標準取樣器換算成分數後，等於資料在噪聲標準差 σ_t√(1+γ²) 下的精確分數：
  - ε*_IP(y,t) = −σ_t ∇log p̃_t(y)，其中 p̃_t = law(√ᾱ_t x0 + σ_t√(1+γ²) z)。
  - γ = 0.1 時，噪聲水準為原本的 1.005 倍。頁面以 Monte Carlo（兩點資料、3×10⁷ 樣本）驗證，與推導一致（差小於 0.002）。
- 由此的推論（本頁推導）：靠近流形時，精確分數主要是指向流形的法向分量；IP 的最佳網路把法向分量乘上 1/(1+γ²) = 0.9901，切向分量幾乎不變。σ → 0 時 p̃_t 趨近 p_data。
- **為什麼解釋不了 IP 的改善**（頁面推導）：DDPM-y 的最佳網路與 IP 只差 √(1+γ²) 倍（0.5%），但 No. 405 Tab. 7（CIFAR10，100 步）中 DDPM 為 3.37、DDPM-y 為 3.90、DDPM-IP 為 2.70。DDPM-y 比 DDPM 差，因此 IP 的改善來自有限網路的訓練行為，而不是最佳網路的性質；本頁的等式只描述最佳網路。
- 論文自己的歸因（**論文**，No. 405 Sec. 5.2、5.4）：作者把 IP 的效果歸因於讓預測函數變平滑的正則化。

**段落**：「所以 IP 的改善來自有限網路的訓練行為」；「兩者只差一個 √(1+γ²) 倍（0.5%）」（頁面原文以 1+γ² 表示）

**信心**：高（0.9）。等式與數字明確；歸因區分為論文寫的內容。

## LO6

**答**：
- 相同處：兩者定義相同，都是 x̂0 − x0 的標準差（頁面詮釋，本頁詮釋）。
- 相異處：
  - ν_t（No. 405 Sec. 5.3）：沿取樣軌跡**實測**的 x̂0 預測誤差 e_t = x̂0 − x0，近似 N(0, ν_t² I)；兩個資料集的 ν_t 平均為 0.20 與 0.19（**論文**）。作者以 [0, E_t ν_t] = [0, 0.2] 作為 γ 的搜尋範圍，稱它「covering the last half of the sampling trajectory」，最後取 γ = 0.1；並寫道原則上可設 γ_t = ν_t 來模仿實際預測誤差（**論文**）。

  - 來源不同：前者實測，後者是未給數值的建模參數（頁面詮釋）。
- 使 IP 與 No. 406 單步取樣變異數一致的 γ（**本頁推導**，論文沒有寫）：γ = c_{1,t+1} e_{t+1} / σ_t，其中 c_{1,t+1} = √ᾱ_t β_{t+1}/(1 − ᾱ_{t+1})。推導來自把 IP 的訓練輸入變異數 σ_t²(1+γ²)（No. 405 Eq. 7）與 No. 406 Eq. 9 多出的變異數 (c_{1,t+1} e_{t+1})² 設為相等。

**段落**：「來源不同：前者沿取樣軌跡實測」；「γ=c1,t+1 et+1/σt」（頁面以 LaTeX 呈現之式）

**信心**：中高（0.8）。定義與 γ 式清楚；數值區段依推定假設，已依頁面標示。
