# Goldfish 驗收作答（僅依頁面文字）

**LO1**
- 答：ε 誤差 η 對應分數誤差 η/σt（σ 每小 10 倍，同樣的 ε 誤差對應的分數誤差大約大 10 倍）。x0 誤差 e 對應分數誤差 √ᾱt·e/σt²（σ 每小 10 倍，大約大 100 倍）。237 Thm 4.1 換成 x0 誤差：集中到流形需 o(1)，還原 p_data 需 o(σ²)。頁面例子：σ = 0.100、x0 誤差 0.20 時分數誤差為 19.9。
- 段落：「x0 誤差 o(1) 足以集中到流形」
- 信心：high

**LO2**
- 答：E_σ 量的是生成分佈 π_σ 的分數與真實分數在有界區域 K 上的最大差距（L∞(K)），只看 σ → 0 的極限。405 Tab. 1 量的是從真實帶噪樣本 x_t 出發跑 t 步反向過程後的 FID（ImageNet 32×32，100 步 0.983，1,000 步 3.544）。406 的 δ_t 量的是多步取樣狀態的變異數 V_t 與訓練變異數 σt² 的差，即 (√V_t − σt)²。
- 為什麼 237 不能直接描述曝光偏差：237 不追蹤取樣軌跡上的誤差累積，只假設知道最終生成分佈的誤差；曝光偏差描述的正是軌跡上的過程（x̂_t 偏離 x_t），而 237 的定理沒有描述這個機制。頁面說曝光偏差可看成產生「最終分佈誤差」的一種機制，但不能直接用 237 的定理來描述它。
- 段落：「不追蹤取樣軌跡上的誤差累積」
- 信心：high

**LO3**
- 答：σ = 0.1、α = 1、λ = 1.017 時，TS 乘數 σ^α = 0.1（只乘無條件分數，改的是 Predictor–Corrector 的校正步，CFG 引導項不變）；ES 乘數 1/λ = 0.9833（改的是預測步平均中的 ε，噪聲項不變）。兩者相等的位置 σ* = λ^(−1/α)，α = 1 時為 0.9833，對應 cosine 排程（推定）中 t ≥ 883 的最吵階段。比 σ* 小的地方，TS 縮得比 ES 多，σ = 0.1 時相差 10 倍。
- 段落：「兩者相等的位置是 σ∗=λ−1/α」
- 信心：high

**LO4**
- 答：在精確分數、梯度場、Langevin 跑到平穩、σ → 0 下：乘常數 1/λ 的平穩分佈收斂到 p_vol^(1/λ)（流形上資料密度的 1/λ 次方）；乘 σ^α 的平穩分佈收斂到流形上的均勻分佈（237 Thm 5.1）。
- 這能說明 ES 的效果嗎：不能。ES 是有限步反向過程中的 ε 縮放，不是跑到平穩的 Langevin 動態；常數乘數在 Thm 4.1 的誤差度量下是 Θ(σ^−2) 的誤差，不在 Thm 4.1 的充分條件內，樣本仍集中是因為它是梯度場。頁面也說 237 的理論不預測 ES 的 FID 改善。
- 段落：「這個結果不能說明 ES 的效果」
- 信心：high

**LO5**
- 答：DDPM-IP 的貝氏最佳網路經標準取樣器換算後，等於資料在噪聲標準差 σt√(1+γ²) 下的精確分數，即 ε*_IP = −σt ∇log p̃t，p̃t = law(√ᾱt x0 + σt√(1+γ²) z)。頁面中 γ = 0.1 時這個噪聲水準是原本的 1.005 倍。
- 為什麼解釋不了 IP 的改善：DDPM-y 的最佳網路與 IP 只差 √(1+γ²) 倍（0.5%），但 Tab. 7 中 DDPM-y（3.90）比 DDPM（3.37）差，IP 為 2.70。所以 IP 的改善來自有限網路的訓練行為，不是最佳網路的性質；這個等式只描述最佳網路。
- 段落：「這個等式解釋不了 IP 的改善」
- 信心：high

**LO6**
- 答：ν_t 與 e_t 的定義相同，都是 x̂0 − x0 的標準差。不同之處在來源：ν_t 是 405 沿取樣軌跡實測的值（兩個資料集平均 0.20 與 0.19）；e_t 是 406 Eq. 7 的建模參數，論文沒有報數值。
- 使 IP 與 406 單步取樣變異數一致的 γ：γ = c_{1,t+1}·e_{t+1} / σt（c_{1,t+1} = √ᾱt·β_{t+1}/(1 − ᾱ_{t+1})）。頁面強調它不是 γ_t = ν_t，因為 γ 在 x_t 空間相對於 σt，ν_t 在 x0 空間，單位不同。
- 段落：「兩者相等的條件是」
- 信心：high（定義與單位）；medium（γ 公式的具體取值，頁面只給推導，且多步版數值是推定值）

**LO7**
- 答：論文自己寫的關係只有一條：只有 No. 406 引用 No. 405（406 Sec. 3.4 把 DDPM-IP 列為以資料增強降低曝光偏差的方法）。另外 406 Table 3 列出 ADM-IP 100 步 best FID 2.38，但頁面指出這個數字不在 405 的任何表中（405 的 CIFAR10 ADM-IP 為 2.70 等），且 406 沒寫 γ 與權重來源。其餘關係（如 R1、R2、R3）都是本頁建立。
- 段落：「只有 No. 406 引用 No. 405」
- 信心：high

**LO8**
- 答：237 的理論不能解釋 405／406 的以下部分：有限步與離散化（Limitations d）、取樣軌跡上的累積（a）、實際訓練控制的是 L² 誤差而非 L∞（b）、FID 的改善；也不預測 λ = 1.017 或 γ = 0.1 這些值。
- 段落：「No. 237 的理論不能解釋」
- 信心：high

## 初學者可能卡住的地方

1. **三種「誤差」與三種單位**：分數、ε、x0 三個單位加上 η、e、ν_t、e_t 等符號很密，頁面沒有一張表把所有符號並列對照，初學者容易把 e_t 與 ν_t 當成同一個量。
2. **o(·) 與充分條件**：頁面寫「o(σ^−2) 足以集中到流形」，但沒有解釋 o(·) 的意思，也沒有先說明「充分」與「必要」的差別，容易把它讀成必要條件或讀成 ε 誤差可到 σ^−2。
3. **TS、ES、IP 作用在哪一步**：TS 在校正步乘分數，ES 在預測步除 ε，IP 在訓練時改輸入。ES 是「除以 λ」，TS 是「乘 σ^α」，方向與對象都不同，初學者很容易混。
4. **γ 符號重複使用**：IP 的擾動強度 γ、多步累積的 γ_M、單步 γ_1、以及 σt√(1+γ²) 都用 γ，頁面只在各章節處標註，沒有統一說明。
5. **平穩分佈與 p^c 的推導**：「乘常數 c 的平穩分佈為 p^c」與 p_vol^c 的推導主要放在進階區塊，正文只給結論；加上「本頁推導」「本頁詮釋」「推定」的標示，初學者不易分辨哪些結論有論文依據。
