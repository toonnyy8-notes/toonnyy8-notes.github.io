# 326 設計文件審查：教學法與建置就緒度

1. P0｜C2「評審來源：三個下拉選單…另有滑桿 f…p、TPR、q、π0、η」。概念未教就放元件：策略梯度、期望獎勵、sigmoid 參數化 θ、學習率都沒有任何章節的內文教過；LO6 的內文放在「C2 後一段」，元件在概念之前。初學者只懂機率與神經網路，會直接面對 8 個控制項。修正：S4 在 C2 前先寫 3 段內文：策略輸出機率 π、期望獎勵比較、梯度上升為何使 π 往較高獎勵移動（定義 r_att、f、Δ）；控制項分兩層，預設只露出 f 與 π0，其餘收進「進階參數」。
2. P1｜符號衝突：S1 的 $q$＝題目，C2 的 $q$＝評審對答錯回答的 YES 機率；$J$ 在 S1 是評審函式，在 C2 是 $J_t$ 平均獎勵；$R$ 與 $r_{att}$ 混用。修正：C2 改用 $\mathrm{FPR}_{att}$ 或 $y$ 代替 $q$，$J_t$ 改名 $\bar R_t$。
3. P1｜C2「Δ=0：π 不變」「f=r_att 時梯度恰為 0」。r_att=0.4×0.95+0.6×0.10 浮點不精確，滑桿 f=0.440 可能得 ±1e-17，條件文字誤判。修正：|Δ|<5e-4 視為 0，與顯示精度一致。
4. P1｜C2/C4/C5 動態 `aria-label`「role=img 與動態 aria-label」＋「每影格 10 步重畫」。影格更新會洪水式更新 label/live region。修正：動畫期間不更新，結束後一次更新；重播以 rAF 並在輸入拖動時取消前一個動畫。
5. P1｜C1「10 列（key）× 12 欄（評審）」，≥600px 時單欄 680px 內 12 欄約 50px，評審名（Qwen2.5-72B、General-Verifier）放不下，規格未給欄頭縮寫、旋轉或水平捲動；600–1024px 是否用 1080px 加寬版也未說明。修正：欄頭用 NAMES 代號＋圖例，或熱圖外包 `overflow-x:auto` 並固定 key 欄 sticky。
6. P1｜C1「未選者淡化 opacity .3」＋每格印數值。淡化後文字對比必低於 4.5:1，且「底色深於 0.55 時文字改 --bg」在深色模式與 color-mix 疊色下未驗證。修正：淡化只作用於底色，文字保持；在 light/dark 各算一次臨界對比並寫回規格。
7. P1｜C4「x 軸平方根刻度」＋12 點。M7 0.1、M32 0.8、MS 1.1 在 358px 寬、平方根刻度下僅相距約 7px，點與標籤重疊，點擊目標遠小於 44px；「Master-RM 為實心菱形」與「專用獎勵模型為圓」互相衝突（Master-RM 也是專用獎勵模型）。修正：點擊以 `<select>` 為主、圖點不作唯一入口；形狀改為三類互斥並附圖例；平方根刻度要在內文以一句字面說明原因（0–10 之間資料密集）。
8. P1｜C4「Pareto 前緣」。LO 沒有涵蓋，內文大綱只有「百分點說明、R2 註記」，術語未教；「y 範圍為最小值 −5% 到最大值 +5%」未說明是值的 5% 還是範圍的 5%。修正：S6 內文加一句字面定義（沒有任何評審 FPR 更低且準確度更高），並明定 ±5% 為 (max−min) 的 5%。
9. P1｜C5：「評審分段按鈕（CoT：Q72、Q7、L70、L8；NQ：Q72、Q7）」。切換比較方式時，若目前選 L70 或 L8，NQ 模式無此選項，行為未定義。修正：切換時回到 Q72；也寫明 NQ 的 Overall 為〔本頁推導〕標註。另「點選資料集列展開」須用 `<button aria-expanded>`，否則鍵盤不可用。
10. P1｜窄螢幕寬內容：$L_{SFT}$、S1 的 $J$ 式、Table 14 全表（13 列）、Table 2 摘錄（8 列×4 欄）、Table 11、Table 10/6 提示 `<pre>`。390px 規格只談圖版，未談式子與表格。修正：統一 `overflow-x:auto` 容器，KaTeX display 加 `overflow-x:auto`，`<pre>` 用 `white-space:pre-wrap`。
11. P1｜S3 過密：FPR 定義、題數換算、Overall 定義、LLaMA3-8B 論文不一致註記、C1、Table 1 重點、LO4 擠在 400–500 字。不一致註記對初學者是干擾。修正：註記移進可收合 `<details>`；S3 拆為「怎麼量」「讀結果」兩小節。
12. P2｜動態 DOM 與 KaTeX：C2 讀數含 $\Delta$、π、$r_{att}$，規格寫成純文字但未說明；若用 KaTeX 重繪動態 DOM 要在每次更新後 `renderMathInElement`，SVG `<text>` 內無法使用 KaTeX。修正：明定動態讀數與 SVG 標籤一律用 Unicode（π、Δ、κ），KaTeX 只用於靜態內文。
13. P2｜字面風格：Hero 標題「一個 token 騙過 LLM 評審」、S3 標題「十二個評審都會被騙」、「被騙」「拿到正確判決」帶擬人；「字面比對者／自行解題者」雖屬作者假設仍是擬人。「master key」「偽陽性」未以字面定義，而 positive＝評審輸出 YES 並非自明。修正：標題改「評審對不含解答的回答判 YES」；偽陽性首次出現時寫「錯誤回答被判 YES 的比例」；master key 加「（論文用語，指…）」。S4 標題「偽陽性會讓 RLVR 訓練崩潰」是因果過度宣稱，論文只有一次崩潰觀察，改「一次 RLVR 崩潰中，策略輸出空洞開頭語，評審多半判 YES」。
14. P2｜前向引用：C2 預設可選 Master-RM（S5 才教），底部註記提到 Master-RM；S4 Table 13 摘要出現 REINFORCE、reward normalization、KL，未教；S5 的 $L_{SFT}$、SFT、log P 預設讀者懂交叉熵。修正：C2 預設列出但註明「Master-RM 於第 05 節說明」，或預設選單只放通用評審；Table 13 摘要保留但術語以括號短注。
