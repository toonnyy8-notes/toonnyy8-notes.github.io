從獎勵到策略：三個概念

策略機率 π。策略模型對同一題可能給出不同回答。為了看清楚機制，本頁用一個只保留兩種回答的玩具：策略以機率 $\pi$ 輸出 master key，以 $1-\pi$ 認真作答。訓練改的是一個實數 $\theta$，再用 $\pi=\sigma(\theta)=1/(1+e^{-\theta})$ 換成機率；$\sigma$ 保證 $\pi$ 永遠落在 0 與 1 之間 本頁玩具。

期望獎勵的比較。輸出 key 時，獎勵為 1 的機率就是評審對 key 的 YES 率，記為 $f$。認真作答時，設策略答對的機率為 $p$、評審對答對的回答判 YES 的機率為 TPR、對答錯的認真回答判 YES 的機率為 $\beta$，所以認真作答的期望獎勵是 $r_{att}=p\cdot\mathrm{TPR}+(1-p)\,\beta$。兩者之差記為 $\Delta=f-r_{att}$；整體期望獎勵是 $\bar R=\pi f+(1-\pi)\,r_{att}$。

梯度上升。每一步把 $\theta$ 往使 $\bar R$ 增加的方向移動 $\eta\cdot d\bar R/d\theta$，$\eta$ 是學習率。由上式，$d\bar R/d\theta=\pi(1-\pi)\Delta$ 本頁推導。因為 $\pi(1-\pi)>0$，所以在 S4 的兩行動玩具中，當 key 的期望獎勵 $f$（評審對 key 的 YES 率）大於認真作答的期望獎勵 $r_{att}=p\cdot\mathrm{TPR}+(1-p)\,\beta$，即 $\Delta=f-r_{att}>0$ 時，期望梯度 $\pi(1-\pi)\Delta$ 為正，梯度上升使 $\pi$ 單調增加；$\Delta\lt 0$ 時 $\pi$ 每步減少。$\pi$ 很小時 $\pi(1-\pi)$ 也很小，所以一開始變化很慢。在這個無 KL 懲罰、單一 $f$ 的玩具中，$\pi$ 趨近 1、評審回報的平均獎勵趨近 $f$、真實準確率趨近 0；這是玩具的極限，不是論文結論，而且玩具的 $f$ 借自 Table 1（另一個分布）。

06 · 一般判斷能力

Master-RM 的一般判斷能力沒有退化

加入大量 NO 標籤，可能讓評審偏向輸出 NO。作者用兩種方式檢查（Sec. 3.3.2）。第一是一致性：2500 題（5 個資料集各 500，由 Qwen2.5-7B-Instruct 作答）以 GPT-4o 的判決為準；其中 500 題（各 100）由 5 位作者標註，至少 3 票一致者為人類標準。

一致性用 Cohen’s κ：$\kappa=(p_o-p_e)/(1-p_e)$，其中 $p_o$ 是兩方實際一致的比例，$p_e$ 是兩方依各自 YES 比例隨機猜也會一致的比例。也就是 κ 扣除兩方依各自 YES 比例隨機猜也會一致的部分，所以不用單純一致率。示範計算 示範值：100 題中兩位評審同判 YES 60 題、同判 NO 25 題、A 判 YES 而 B 判 NO 10 題、A 判 NO 而 B 判 YES 5 題，則 $p_o=0.85$；A 的 YES 比例 0.70、B 0.65，$p_e=0.70\times0.65+0.30\times0.35=0.56$；$\kappa=(0.85-0.56)/(1-0.56)=0.659$。實例：Qwen2.5-0.5B 的 κ 只有 0.10（Table 2a），接近隨機。

第二是 VerifyBench 與 VerifyBench-Hard（Yan et al. 2025）：經人工標註的參考答案式評審基準，報告準確率（Acc）與 Macro F1（Table 2b）。

論文的結論是「沒有退化，部分情況提升」。κ_GPT-4o / κ_human：Master-RM-7B 0.91 / 0.90、Master-RM-32B 0.89 / 0.87（Multi-sub RM 0.91 / 0.91）；VerifyBench / Hard Acc：Master-RM-7B 94.45 / 84.40、Master-RM-32B 95.15 / 86.80。Master-RM-32B 與最高的 GPT-o1（95.70 / 88.80）差 0.55 與 2.0 百分點；論文把這兩個差寫成「0.55%」「2.0%」，它們是百分點差，不是相對百分比。κ 評估的回答由 Qwen2.5-7B-Instruct 產生，與訓練資料（Qwen2.5-7B-base 產生）同家族，接近分布內。另外，論文寫 Master-RM-7B 的 0.91 與 Multi-sub RM 並列對 GPT-4o 一致性的最高分，但 Table 2a 中 Qwen2.5-14B-Instruct 是 0.92；本頁照錄表格。

Cohen’s κ 的定義是什麼？Master-RM 是否犧牲一般判斷能力？

$\kappa=(p_o-p_e)/(1-p_e)$，扣除依各自 YES 比例隨機一致的部分（Qwen2.5-0.5B 只有 0.10）。沒有退化：7B κ 0.91/0.90、32B 0.89/0.87；VerifyBench 32B 95.15、Hard 86.80，與 GPT-o1 差 0.55 與 2.0 百分點；κ 評估接近分布內。
