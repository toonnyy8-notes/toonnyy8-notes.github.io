    條件記憶：用查表補上 MoE 之外的另一條稀疏軸

    這篇論文在 Transformer 中加入以 N-gram 雜湊查表的記憶模組 Engram，並研究總參數固定時，記憶與專家該如何分配。

    MoE 與「稀疏」的定義見 01、02 節。

    Xin Cheng、Rui Tian 等（北京大學、DeepSeek-AI）〈Conditional Memory via Scalable Lookup: A New Axis of Sparsity for Large Language Models〉

    01 · 查表

    Engram 把目前 token 與前一、兩個 token 組成的片段當作鍵，直接在大型嵌入表中查出一個向量。不論表多大，每個 token 只查固定幾格。

    02 · 分配

    總參數與每個 token 的計算量都固定時，把約 20%–25% 的閒置參數從專家移到記憶，驗證集上的損失（越低越好）最小。

    03 · 規模

    27B 模型加入記憶後各類測驗都進步，一般推理題進步最多。100B 參數的表放在 CPU 記憶體，推論速度只下降不到 3%。

    01 · 計算與查表

    語言模型同時需要計算與查表

    作者把語言建模分成兩種性質不同的子任務（Sec. 1）。第一種是組合推理：依上下文把多個資訊組合起來，需要深層、動態的計算。第二種是知識檢索：文本中有相當比例是局部、靜態、刻板的片段，例如具名實體（“Alexander the Great”）與固定片語（“By the way”）。這類片段只依賴前面少數幾個 token，經典的 N-gram 模型就能以查表的方式低成本捕捉。

    問題在於標準 Transformer 沒有查表的基本運算。局部靜態模式原本可以查表解決，Transformer 卻只能用前幾層的多層注意力與 FFN 逐步「算出」它們，等於用序列深度重建一張靜態查找表。作者引用的例子是 Table 3。這張表是外部例子，轉載自 Ghandeharioun et al.     據此，作者提出與「條件計算」互補的另一條稀疏軸：條件記憶（conditional memory）。條件記憶指依輸入內容直接查出一段儲存的參數，而不是經由多層計算重建它。本文以 Engram 模組實作條件記憶：用目前位置結尾的 2-gram、3-gram 當作鍵，在大型嵌入表中以 O(1) 查出向量，再依目前的隱藏狀態調節後加回模型（Sec. 2）。下一節先說明條件計算（MoE）如何讓參數變多而計算量不變，條件記憶沿用同一個預算框架。

    02 · 參數預算

    MoE 用路由增加參數而不增加每個 token 的計算量

    MoE（Mixture-of-Experts）把 Transformer 每層的 FFN 換成多個並列的「專家」FFN。每層有一個路由器（router），依目前 token 的隱藏狀態為它打分，只選分數最高的 top-$k_{\text{act}}$ 個專家計算，其餘專家對這個 token 不做任何運算。DeepSeekMoE 另有共享專家，每個 token 都會經過。本文的 MoE-27B 有 2 個共享專家與 72 個路由專家，每個 token 選 top-6。這種依輸入選擇部分參數的做法稱為條件計算（Shazeer et al. 2017 提出稀疏閘控 MoE，見研究筆記）。

    為了比較不同架構，作者定義三種參數量（Sec. 3.1）：

    • $P_{\text{tot}}$：總可訓練參數，不含詞嵌入與 LM head。
    • $P_{\text{act}}$：每個 token 實際啟用的參數，決定每個 token 的計算量（FLOPs）。
    • $P_{\text{sparse}}=P_{\text{tot}}-P_{\text{act}}$：未啟用的參數。它增加模型容量，但不增加每個 token 的 FLOPs。

    以 Table 1 為例，MoE-27B 的總參數為 26.7B，每個 token 啟用 3.8B，大部分參數屬於 $P_{\text{sparse}}$。MoE 增加 $P_{\text{tot}}$ 而不增加 FLOPs 的方式是：未被路由器選中的專家參數不參與該 token 的計算。Engram 的方式是：嵌入表可以非常大，但每個 token 只取固定數量的槽（每個階數、每個雜湊頭各一列），所以增加槽數只增加 $P_{\text{tot}}$，不增加 $P_{\text{act}}$。兩者都把參數放進 $P_{\text{sparse}}$，差別在選擇的依據。

    03 · tokenizer 壓縮

    先把語意相同的 token 合併

    N-gram 是連續 $n$ 個 token 組成的片段；N-gram 嵌入是為每個 N-gram 配置一個可學向量，使用時依片段直接取出，屬於 O(1) 的查表，不需要經過任何矩陣乘法。Engram 在查表之前先處理 tokenizer 的一個特性：子詞 tokenizer 為了能把 ID 無損地還原成原文，常給語意相同的字串不同 ID，例如 Apple 與 ␣apple（␣ 表示前導空白）。若直接用原始 ID 組成 N-gram，同一個片語會被拆成多個互不相干的鍵。

    作者因此預先計算一個滿射 $\mathcal P:V\to V'$（Sec. 2.2）：依正規化後的文字（NFKC、轉小寫等）把語意相同的原始 ID 合併成同一個標準 ID，$x'_t=\mathcal P(x_t)$。對 128k 的 tokenizer，有效詞表縮小 23%（App. C 的 Table 6 寫 23.43%）。官方示範程式的正規化順序是 NFKC → NFD → 去除重音 → 小寫 → 連續空白改為單一空格 → 去頭尾空白；去頭尾空白使 ␣apple 與 apple 合併。

    04 · 多頭雜湊

    多個雜湊頭把 N-gram 映到嵌入表

    Engram 沿用 Tito Svenstrup et al. (2017) 的雜湊嵌入（Hash Embeddings，見研究筆記）。對每個階數 $n$，模型準備 $K$ 個雜湊頭；第 $k$ 個頭有自己的雜湊函數 $\varphi_{n,k}$ 與嵌入表 $\mathbf E_{n,k}$，表的列數 $M_{n,k}$ 取質數（Sec. 2.2）：

    $$z_{t,n,k}\triangleq\varphi_{n,k}(g_{t,n}),\qquad \mathbf e_{t,n,k}=\mathbf E_{n,k}[z_{t,n,k}]$$
    Eq. 1
    $$\mathbf e_t\triangleq\big\Vert_{n=2}^{N}\big\Vert_{k=1}^{K}\,\mathbf e_{t,n,k}$$
    Eq. 2

    $z_{t,n,k}$ 是雜湊得到的列索引，$\mathbf e_{t,n,k}$ 是查出的向量，$\Vert$ 表示串接。所有頭的向量串接成記憶向量 $\mathbf e_t\in\mathbb R^{d_{\text{mem}}}$，Engram-27B 的 $d_{\text{mem}}=1280$、$K=8$。$n\in\{2,3\}$ 共 16 個頭，所以每列是 $1280/16=80$ 維推定。論文只寫 $\varphi_{n,k}$ 是輕量的乘法–XOR 雜湊。官方示範程式的寫法是：每層抽 $N$ 個奇數乘數 $m_0,\dots,m_{N-1}$，計算 $\text{mix}=(x'_t m_0)\oplus(x'_{t-1}m_1)\oplus\cdots$（$\oplus$ 為逐位元 XOR，共 $n$ 項），第 $k$ 頭的索引為 $\text{mix}\bmod M_{n,k}$；$M_{n,k}$ 是從設定的表大小往上找、彼此不重複的質數示範程式。

    表的單位推定：Table 5 的 Engram Vocab Size 2,262,400（27B）解讀為每頭列數，等於 129,280 × 17.5。Engram 參數 $=2\text{ 層}\times2\text{ 階}\times8\text{ 頭}\times2{,}262{,}400\times80=5.79$B，與論文的 5.7B 一致；40B 的 7,239,680 列給 18.53B，論文寫 18.5B。

    碰撞：多頭降低「無法區分」的機率

    雜湊會讓不同的 $n$-gram 落在同一格（碰撞）。以下是本頁的近似分析本頁推導。設表中共有 $U$ 個不同的 $n$-gram，單一頭有 $M_{n,k}$ 格（下文簡寫為 $M$）；$U$ 是讀者假設的值，論文沒有給出。某個 $n$-gram 在一個頭上與至少一個其他 $n$-gram 同格的機率為

    $$p_1=1-\left(1-\tfrac1M\right)^{U-1}$$
    本頁推導

    若各頭近似獨立，$K$ 個頭都與別人同格（沒有任何一個無碰撞的頭）的機率為 $p_1^K$。例：$U=10^6$ 個不同 2-gram、每頭 $M=2{,}262{,}400$ 格時，$p_1\approx0.357$，單頭約三分之一的 2-gram 會與別人共用一格；8 個頭都與別人同格的機率 $p_1^8\approx2.65\times10^{-4}$，約 $2.7\times10^{-4}$。只要還有一個無碰撞的頭，串接後的 $\mathbf e_t$ 就與其他 $n$-gram 不同。

    「與某一個 $n$-gram 在 $K$ 頭全部同格」比上述機率更罕見，但示範程式的 $K$ 個頭共用同一個 mix，只是模數不同。由中國餘數定理，兩個 $n$-gram 在 $K$ 頭全部同格，若且唯若兩者的 mix 對 $\prod_k M_{n,k}$ 同餘；$K=8$ 時這個乘積約 $10^{51}$，遠大於 mix 的範圍 $R\approx2^{48}$推定，所以全部同格只在 mix 完全相同時發生。全部同格的期望個數因此寫成 $E_{\text{full}}\approx(U-1)/\min(M^K,R)$：$U=10^6$ 時獨立模型給 $10^{-44.8}$，mix 下限給 $10^{-8.45}$；$U=10^9$ 時下限約 $3.6\times10^{-6}$，比獨立模型高約 36 個數量級。這個值仍然很小，但不能說「8 個頭的組合必然唯一」。正式模型的雜湊細節論文沒有寫，$R$ 只依示範程式推定。

    05 · 閘門

    閘門 α 依隱藏狀態縮放記憶向量

    雜湊查出的 $\mathbf e_t$ 只由輸入 token 決定，不看更遠的上下文，也會受碰撞與多義影響。Engram 因此以注意力為藍本，用目前的隱藏狀態 $\mathbf h_t$ 當 Query，記憶 $\mathbf e_t$ 同時產生 Key 與 Value（Sec. 2.3）。$\mathbf h_t$ 已經過前面的注意力層，彙整了整個前綴的上下文。

    式中的 RMSNorm 把向量除以其元素的均方根，再乘以可學的增益：$\mathrm{RMSNorm}(\mathbf y)=\mathbf y/\sqrt{\tfrac1d\sum_i y_i^2}$（再逐元素乘以增益）。作者對 Query、Key 都做 RMSNorm，目的是讓梯度穩定。

    $$\mathbf k_t=\mathbf W_K\mathbf e_t,\qquad \mathbf v_t=\mathbf W_V\mathbf e_t$$
    Eq. 3
    $$s_t=\frac{\mathrm{RMSNorm}(\mathbf h_t)^\top\mathrm{RMSNorm}(\mathbf k_t)}{\sqrt d}$$
    Eq. 4
    $$\alpha_t=\sigma(s_t),\qquad \tilde{\mathbf v}_t=\alpha_t\cdot\mathbf v_t$$
    Eq. 4

    合起來寫，閘門為 $\alpha_t=\sigma\big(\mathrm{RMSNorm}(\mathbf h_t)^\top\mathrm{RMSNorm}(\mathbf k_t)/\sqrt d\big)$，$\sigma$ 是 sigmoid，$\alpha_t\in(0,1)$ 是一個純量，乘在整個 Value 向量上。作者的解釋：若查出的記憶與目前上下文矛盾，$\alpha_t$ 趨近 0，該位置的記憶向量幾乎不加入殘差流。

    引數的範圍本頁推導：假設 RMSNorm 增益為 1 並忽略 eps，正規化後的向量長度恰為 $\sqrt d$，所以 sigmoid 的引數等於 $\sqrt d\cos\theta$，$\theta$ 是 $\mathbf h_t$ 與 $\mathbf k_t$ 的夾角。在這個假設下，$d=2560$ 時引數的範圍是 $\pm50.6$，只有 $|\cos\theta|<5/\sqrt{2560}=0.099$ 時 $|s|<5$，閘門幾乎只取 0 或 1。論文的 RMSNorm 增益是可學的，實際範圍隨增益改變，$\pm50.6$ 只是增益為 1 時的值。下圖以 $s=\gamma\sqrt d\cos\theta$ 表示，$\gamma$ 代表學到的增益對引數的整體縮放（本頁簡化）。示範程式在 sigmoid 前多做一步帶號平方根 $s\mapsto\mathrm{sign}(s)\sqrt{|s|}$，論文 Eq. 4 沒有這一步；下圖提供切換，不宣稱哪一個是正式模型的實作。

    06 · 短卷積

    短卷積擴大讀取範圍，殘差連接保留未經卷積的輸入

    閘門只看單一位置。作者在閘門之後加一層短卷積，擴大感受野並增加非線性（Sec. 2.3）。把所有位置的 $\tilde{\mathbf v}_t$ 排成矩陣 $\tilde{\mathbf V}$：

    $$\mathbf Y=\mathrm{SiLU}\big(\mathrm{Conv1D}(\mathrm{RMSNorm}(\tilde{\mathbf V}))\big)+\tilde{\mathbf V}$$
    Eq. 5

    Conv1D 是深度（depthwise）因果卷積：每個維度各自卷積、只讀目前與之前的位置；核大小 $w=4$，擴張率（dilation） $\delta$ 等於最大 N-gram 階數 $N=3$，激活函數為 SiLU，最後加上殘差 $\tilde{\mathbf V}$。結果以殘差方式融合進主幹：$\mathbf H^{(\ell)}\leftarrow\mathbf H^{(\ell)}+\mathbf Y$，之後接標準的 Attention 與 MoE。Engram 只插在部分層，Engram-27B 是第 2 與第 15 層。

    卷積參數初始化為 0。訓練開始時 $\mathrm{Conv1D}(\cdot)=0$，而 $\mathrm{SiLU}(0)=0$，所以 $\mathbf Y=\tilde{\mathbf V}$：零初始化使模組一開始只是把閘門後的記憶加回殘差流，作者稱之為「strictly preserve the identity mapping」（Sec. 4.1）。

    讀取範圍本頁推導：卷積在位置 $t$ 讀取 $t,\ t-\delta,\ t-2\delta,\ t-3\delta$ 四個位置的 $\tilde{\mathbf v}$。依 Eq. 2，每個位置的查表內容同時包含結尾於該處的 2-gram 與 3-gram，3-gram 的視窗涵蓋了 2-gram 的視窗。$\delta=N=3$ 時，四個 3-gram 視窗剛好首尾相接、不重疊，查表內容涵蓋連續 $wN=12$ 個位置；$\delta=1$ 時視窗重疊，只涵蓋 $N+w-1=6$ 個。位置靠近句首時，部分位置落在句首以前，由 pad 補齊：下圖預設的 $t=9$ 涵蓋 10 個句內 token 加 2 個 pad。這裡只計算查表內容的來源；閘門 $\alpha_{t'}$ 依賴 $\mathbf h_{t'}$，而 $\mathbf h_{t'}$ 經注意力看過整個前綴。

    07 · 多分支

    多分支主幹共用記憶、各自計算閘門

    本文的主幹採 mHC（Manifold-Constrained Hyper-Connections）：殘差流不是一條向量，而是擴成 $M=4$ 條平行分支，各層以可學的連接權重混合這些分支（Sec. 2.4）。Engram 要為每條分支產生輸入，作者的做法是：

    $$s_t^{(m)}=\frac{\mathrm{RMSNorm}(\mathbf h_t^{(m)})^\top\mathrm{RMSNorm}(\mathbf W_K^{(m)}\mathbf e_t)}{\sqrt d}$$
    Eq. 6
    $$\alpha_t^{(m)}=\sigma\big(s_t^{(m)}\big),\qquad \mathbf u_t^{(m)}=\alpha_t^{(m)}\cdot(\mathbf W_V\mathbf e_t)$$
    Eq. 6

    參數共享方式：一張嵌入表與一個 $\mathbf W_V$ 由 $M$ 條分支共享，每條分支只有自己的 $\mathbf W_K^{(m)}$。這樣閘門可以依分支的隱藏狀態 $\mathbf h_t^{(m)}$ 而不同，同時一個 $\mathbf W_V$ 與 $M$ 個 $\mathbf W_K^{(m)}$ 可以融合成一次稠密的 FP8 矩陣乘法，保留分支專屬閘門而不增加多次小矩陣乘法的開銷。Engram-27B 有 2 個 Engram 層 × 4 條分支，所以每個 token 共有 8 個閘門純量（Sec. 6.5 註腳 2）。消融中的「w/o multi branch」保留 mHC 主幹，但改為在 pre-mapping 後的 $\mathbf H_{pre}$ 上做單一融合（Sec. 6.2）。

    08 · 稀疏度分配

    固定預算下記憶與專家的分配呈 U 形

    有了兩種稀疏模組，作者提出稀疏度分配（Sparsity Allocation）問題：固定 $P_{\text{tot}}$ 與 $P_{\text{act}}$（等參數、等 FLOPs），未啟用的參數該如何分給 MoE 專家與 Engram？以 $\rho$ 表示未啟用參數分給 MoE 專家的比例（Sec. 3.1）：

    $$P^{(\text{sparse})}_{\text{MoE}}=\rho\,P_{\text{sparse}},\qquad P_{\text{Engram}}=(1-\rho)\,P_{\text{sparse}}$$
    Eq. 7

    $\rho=1$ 是純 MoE。實驗只調整路由專家數與 Engram 槽數，其餘不變。作者用兩個計算預算（稀疏比 $P_{\text{tot}}/P_{\text{act}}\approx10$）：$C=2\times10^{20}$ FLOPs，$P_{\text{tot}}\approx5.7$B、$P_{\text{act}}=568$M、基準 106 個專家；$C=6\times10^{20}$ FLOPs，$P_{\text{tot}}\approx9.9$B、$P_{\text{act}}=993$M、基準 99 個專家。

        10 · 有效深度

        Engram 讓淺層提早完成特徵組合

        作者的假設是：模型有了明確的查表能力後，前幾層不必再組合局部特徵，效果相當於增加深度（Sec. 6.1）。兩個工具用來檢驗這個假設。

        LogitLens 把每一層的隱藏狀態直接接到最終的 LM head，得到一個「提前輸出」的分布，再計算它與最終輸出分布的 KL 散度（衡量兩個機率分布差異的量，越小越接近）。結果：兩個 Engram 模型各層的 KL 都系統性地較小，差距在淺層最明顯（Fig. 4a），表示淺層較早完成特徵組合，較早接近最終預測。

        CKA（Centered Kernel Alignment）衡量兩組表示的相似度，值在 0 到 1 之間。作者對 Few-NERD 具名實體的最後一個 token，計算 Engram 模型第 $j$ 層與 MoE 模型各層的 CKA，再以軟對齊指標 $a_j$ 找出「Engram 第 $j$ 層最像 MoE 的第幾層」。觀察到 $a_j>j$：Engram-27B 第 5 層約對應 MoE 第 12 層（Fig. 4b–c）。也就是 Engram 的淺層表示相當於 MoE 較深層的表示。作者的結論：Engram 在功能上相當於增加有效深度。

        補充：HSIC 與 Eq. 8–9

        CKA 以 HSIC（Hilbert-Schmidt 獨立性準則）定義，使用線性核 $K=XX^\top$、$L=YY^\top$，並以 minibatch 無偏估計計算：

        $$\mathrm{CKA}(K,L)=\frac{\mathrm{HSIC}(K,L)}{\sqrt{\mathrm{HSIC}(K,K)\,\mathrm{HSIC}(L,L)}}$$
        Eq. 8

        軟對齊指標取與 Engram 第 $j$ 層最相似的 top-5 個 MoE 層 $I_j$，以相似度 $S_{i,j}$ 加權平均層號：

        $$a_j=\frac{\sum_{i\in I_j}S_{i,j}\,i}{\sum_{i\in I_j}S_{i,j}}$$
        Eq. 9

        閘門在哪裡打開

        Fig. 7 把 Engram-27B 的閘門 $\alpha_t$ 畫成熱度圖（Sec. 6.5）。閘門在完成局部靜態模式的 token 上啟動：英文例如 “Alexander the Great”、“the Milky Way” 等多 token 具名實體，以及 “By the way”、“Princess of Wales” 等固定片語；中文例如「四大发明」「张仲景」。因為查的是後綴 N-gram（$N=3$），高啟動落在片語的最後一個 token。下方以 token 帶重繪 Fig. 7 的兩個英文句，只標出論文文字點名的片語與其最後一個 token，不標閘門數值。Fig. 7 只顯示 8 個閘門中與語意模式最相關的那一個。

        11 · 消融

        移除元件與關閉記憶時的變化

        元件消融（Sec. 6.2，Fig. 5）在較小的設定上進行：12 層 3B MoE（0.56B 啟用）、訓練 100B token，基準驗證損失 1.808。參考配置是 1.6B Engram、{2,3}-gram、插在第 2 與第 6 層，損失 1.768（降低 0.04）。從參考配置逐一移除元件，影響最大的三項是分支專屬融合、情境感知閘門與 tokenizer 壓縮；Fig. 5 沒有給出數值，本頁不排三者的先後。移除短卷積只稍微變差。在固定 1.6B 下加入 4-gram 稍差，作者推測它稀釋了較常見的 2/3-gram 的容量，不排除記憶更大時有益。

        敏感度分析（Sec. 6.3，Fig. 6）在推論時把 Engram 的輸出完全關掉、主幹不變，觀察各類任務還保留多少表現。事實知識類受影響最大，只保留 29%–44%（TriviaQA 29%）；閱讀理解類保留 81%–93%（C3 93%）。這表示事實知識大量依賴 Engram 查出的記憶，而閱讀理解主要依賴主幹對上下文的計算。作者提醒，這種事後消融造成訓練與推論不一致，所以只分析兩端的任務。

        檢查理解

        LogitLens 與 CKA 各顯示什麼？關掉 Engram 時哪類任務受影響最大？

        LogitLens：淺層 KL 較小；CKA：$a_j>j$，Engram-27B 第 5 層約對應 MoE 第 12 層；事實知識只保留 29%–44%，閱讀理解保留 81%–93%（Sec. 6.1、6.3）。

        12 · 預取

        確定性位址讓查表可以預取

        MoE 的路由依賴執行時的隱藏狀態，模型要算到該層才知道選哪些專家。Engram 的索引只由輸入 token ID 決定，在執行該層之前就已知道要讀哪些列（Sec. 2.5）。這種確定性位址帶來兩個系統面的好處：

        • 訓練：嵌入表以模型平行切分到各 GPU，前向用 All-to-All 收集被用到的列，反向把梯度分派回去；總記憶容量隨 GPU 數線性增加。
        • 推論：嵌入表放在主機記憶體，經 PCIe 非同步預取，與前面層的計算重疊（Fig. 2b）。插得越深，可以遮住傳輸延遲的計算時間越長。

        研究筆記整理的 PKM 等記憶層以學到的 key 比對隱藏狀態來選列，位址同樣要到執行時才知道；Engram 的位址由雜湊直接決定，所以可以預取。這是筆記的整理，論文沒有逐項比較。N-gram 的存取服從 Zipf 分布，少數模式佔大多數存取，所以常用的列可放在 HBM 或 DRAM，長尾放在 NVMe SSD（多層快取）。

        插入層的取捨：建模偏好早插入。12 層 3B MoE 上把單一模組由第 1 層掃到第 12 層，第 2 層最佳（Val Loss 1.770），越深越差；同樣 1.6B 拆成兩個模組放在第 2、6 層更好（1.768）（Sec. 6.2）。插得越早，查表結果越早進入殘差流，主幹花在重建局部模式上的層數越少；但越早的 $\mathbf h_t$ 上下文越少、各分支差異越小，閘門越不精確。系統面則偏好晚插入，留給預取更多計算時間。Engram-27B 用第 2、15 層同時滿足兩者。

        Table 4 量測了代價（Sec. 6.4）：nano-vLLM、H800、512 條序列，把 100B 參數的 Engram 放在第二個 block、整張表放在主機 DRAM，與第一個 block 的計算重疊。4B-Dense 的吞吐量由 9,031.62 降到 8,858.28 tok/s（−1.92%，本頁推導），8B-Dense 由 6,315.52 降到 6,140.02 tok/s（−2.78%，論文寫 2.8%）。100B 表放主機記憶體，吞吐量最多只降 2.8%。每步的通訊量隨啟用的槽數增加，與表的總大小無關。這組實驗強制所有查表都走 PCIe、沒有使用快取，作者稱之為保守基準。

        研究脈絡

        論文 §7 把源頭追溯到 Shannon 的 N-gram 語言模型。之後 FastText 以子詞 N-gram 嵌入表示詞，Hash Embeddings 用多個雜湊函數降低嵌入表的大小與碰撞，這是 Eq. 1 所沿用的做法。另一條線是 MoE：稀疏閘控 MoE、Switch Transformer 與 DeepSeekMoE 讓條件計算成為大型模型的標準做法。參數式記憶（PKM、PEER）在層內放大型 key-value 儲存，以學到的 key 選列；FFN 被解讀為鍵值記憶，說明模型會用計算重建靜態知識；REALM 等檢索增強方法則使用非參數的外部記憶。N-Grammer、OverEncoding 與 SCONE 把 N-gram 嵌入擴大到語言模型，但放在輸入層，也沒有在嚴格等參數、等 FLOPs 下驗證。本文把 N-gram 查表移到中間層，並以稀疏度分配把它與 MoE 放在同一個預算下比較。每張卡片連到對應的研究筆記。
