# Goldfish 驗收答案（僅依頁面文字）

**LO1**
- 答：兩種子任務是「組合推理」（依上下文組合資訊，需要深層、動態計算）與「知識檢索」（局部、靜態、刻板的片段，如具名實體、固定片語）。標準 Transformer 沒有查表的基本運算，只能用前幾層的注意力與 FFN 逐步「算出」這些靜態模式，等於用序列深度重建一張靜態查找表。
- 段落：「標準 Transformer 沒有查表的基本運算」
- 信心：高

**LO2**
- 答：$P_{\text{tot}}$ 是總可訓練參數（不含詞嵌入與 LM head）；$P_{\text{act}}$ 是每個 token 實際啟用的參數，決定 FLOPs；$P_{\text{sparse}}=P_{\text{tot}}-P_{\text{act}}$ 是未啟用參數。MoE 由路由器只選 top-$k_{\text{act}}$（本文為 6）個專家，未被選中的專家不參與計算，所以增加專家數只增加 $P_{\text{tot}}$。Engram 的嵌入表可以很大，但每個 token 只取固定數量的槽（每個階數、每個雜湊頭各一列），所以增加槽數只增加 $P_{\text{tot}}$。
- 段落：「未被路由器選中的專家參數不參與該 token 的計算」
- 信心：高

**LO3**
- 答：$\mathcal P$ 是 tokenizer 壓縮的滿射 $V\to V'$，依正規化後的文字（NFKC、轉小寫等）把語意相同的原始 ID 合併成同一個標準 ID，即 $x'_t=\mathcal P(x_t)$。對 128k tokenizer，有效詞表縮小 23%（論文附錄 Table 6 寫 23.43%）。
- 段落：「有效詞表縮小 23%」
- 信心：高

**LO4**
- 答：單頭碰撞機率 $p_1=1-\left(1-\tfrac1M\right)^{U-1}\approx0.357$（頁面寫 0.357256）。8 個頭都與別人同格的機率 $p_1^8\approx2.65\times10^{-4}$（約 $2.7\times10^{-4}$）。前提是各頭近似獨立，且 $U$ 是頁面的假設值，論文沒有給出。
- 段落：「p1≈0.357」
- 信心：高（數字）；中（套用到真實模型，頁面已標為本頁推導）

**LO5**
- 答：Eq. 4 為 $s_t=\dfrac{\mathrm{RMSNorm}(\mathbf h_t)^\top\mathrm{RMSNorm}(\mathbf k_t)}{\sqrt d}$，閘門 $\alpha_t=\sigma(s_t)$。假設增益為 1、忽略 eps，$s_t=\sqrt d\cos\theta$，$d=2560$ 時 $\sqrt d\approx50.6$，所以引數範圍是 $\pm50.6$。只有 $|\cos\theta|<0.099$ 時 $|s|<5$，閘門幾乎只取 0 或 1。論文的增益是可學的，實際範圍隨之改變。
- 段落：「引數的範圍本頁推導」
- 信心：高（數字，依頁面假設）

**LO6**
- 答：Eq. 5 為 $\mathbf Y=\mathrm{SiLU}(\mathrm{Conv1D}(\mathrm{RMSNorm}(\tilde{\mathbf V})))+\tilde{\mathbf V}$，深度因果卷積，核大小 $w=4$，擴張率 $\delta=N=3$，最後加殘差。$w=4,\delta=3$ 時，查表內容涵蓋連續 $wN=12$ 個位置（四個 3-gram 視窗首尾相接、不重疊）。零初始化時 Conv1D 輸出為 0，SiLU(0)=0，所以 $\mathbf Y=\tilde{\mathbf V}$，模組一開始只是把閘門後的記憶加回殘差流，作者稱為「strictly preserve the identity mapping」。
- 段落：「零初始化使模組一開始只是把閘門後的記憶加回殘差流」
- 信心：高

**LO7**
- 答：一張嵌入表與一個 $\mathbf W_V$ 由 $M=4$ 條分支共享，每條分支只有自己的 $\mathbf W_K^{(m)}$。這樣閘門可依各分支的隱藏狀態而不同，同時 $\mathbf W_V$ 與 $M$ 個 $\mathbf W_K^{(m)}$ 可融合成一次稠密的 FP8 矩陣乘法，避免多次小矩陣乘法的開銷。Engram-27B 有 2 個 Engram 層 × 4 條分支，所以每個 token 共 8 個閘門純量。
- 段落：「Engram-27B 有 2 個 Engram 層 × 4 條分支」
- 信心：高

**LO8**
- 答：$\rho$ 是未啟用參數中分給 MoE 專家的比例（Eq. 7）：$P_{\text{MoE}}=\rho P_{\text{sparse}}$，$P_{\text{Engram}}=(1-\rho)P_{\text{sparse}}$；$\rho=1$ 是純 MoE。驗證損失對 $\rho$ 呈 U 形，最佳點約 $\rho\approx75\%$–$80\%$，即把約 20%–25% 的稀疏預算給 Engram。兩端的解釋：$\rho\to100\%$ 時缺少靜態模式的專用記憶，模型只能用深度與計算重建；$\rho\to0\%$ 時失去條件計算，記憶無法取代需要動態計算的部分。具體數字：6e20 預算下損失 1.7248（ρ=100%）降到 1.7109（ρ≈80%）。頁面正文寫「10B 預算」，圖說寫 6e20 FLOPs（9.9B），是同一組實驗。
- 段落：「最佳 ρ≈75% –80%」
- 信心：高

**LO9**
- 答：兩者等參數、等 FLOPs：總參數同為 26.7B，啟用參數同為 3.8B，同樣 262B token；只把路由專家由 72 減到 55，空出的參數給 5.7B 的 Engram（$\rho=74.3\%$）。增益最大的是一般推理：BBH +5.0、ARC-Challenge +3.7、DROP +3.3；知識類 MMLU +3.0、CMMLU +4.0；程式與數學的增益與知識類相當，沒有更大。
- 段落：「BBH +5.0」
- 信心：高

**LO10**
- 答：Engram 的長文脈能力隨預訓練進度提升，若只對齊步數，無法分辨增益來自架構還是來自較低的預訓練損失，所以要對齊預訓練損失。結果：Engram 46k 步（損失 1.63）對 MoE-27B 50k 步（損失 1.63），Multi-Query NIAH 97.0 對 84.2，VT 87.2 對 77.0。頁面也說明並非所有指標都勝出（例如 S、CWE 略低），所以只能寫「幾乎所有指標」。
- 段落：「Multi-Query NIAH 97.0 vs 84.2」
- 信心：高

**LO11**
- 答：LogitLens 把每層隱藏狀態接到 LM head，計算與最終輸出分布的 KL 散度；Engram 模型各層 KL 都較小，淺層差距最明顯，代表淺層較早接近最終預測。CKA 衡量表示相似度；Engram-27B 第 5 層約對應 MoE 第 12 層（$a_j>j$），結論是 Engram 功能上相當於增加有效深度。關掉 Engram（推論時）後，事實知識類受影響最大，只保留 29%–44%（TriviaQA 29%）；閱讀理解類保留 81%–93%（C3 93%）。
- 段落：「只保留 29%–44%」
- 信心：高

**LO12**
- 答：Engram 的索引只由輸入 token ID 決定，在執行該層前就已知道要讀哪些列，可以預取；MoE 的路由依賴執行時的隱藏狀態，要算到該層才知道。100B 表放主機記憶體時，Table 4 的量測是 8B-Dense 吞吐量由 6,315.52 降到 6,140.02 tok/s（−2.8%），4B-Dense 由 9,031.62 降到 8,858.28（約 −1.9%）；該實驗為不使用快取的保守基準。插入層要在建模與預取之間取捨：建模偏好早插入，單一模組在 3B MoE 上以第 2 層最佳（Val Loss 1.770），越深越差；系統面則偏好晚插入，留給預取更多計算時間。Engram-27B 用第 2、15 層。
- 段落：「第 2 層最佳（Val Loss 1.770）」
- 信心：高（數字）；中（4B 的 −1.9% 百分比在頁面上有「本頁推導」與論文量測兩種標示）

## 初學者可能卡住的地方

1. **三個 P 符號**：$P_{\text{tot}}$、$P_{\text{act}}$、$P_{\text{sparse}}$ 是參數量；$\mathcal P$ 是 tokenizer 的映射函數。頁面沒有在第一次出現時提醒兩者無關。
2. **「每列 80 維」與「dmem=1280」**：1280 是串接後的記憶向量維度（16 個頭）；80 維是頁面自己推定的每列維度，論文沒有寫。
3. **閘門範圍 ±50.6 的前提**：這個數字只在增益為 1 時成立，論文增益可學。頁面的互動示範還使用論文 Eq. 4 沒有的「帶號平方根」，初學者容易把示範當成論文公式。
4. **ρ 的數字不一致**：正文說「10B 預算」，圖說寫 6e20 FLOPs（9.9B）；Engram-27B 的 ρ 有時寫 74.3%、頁面推導為 74.24%，最佳區間寫 75%–80%，都容易混淆。
5. **層編號與碰撞假設**：論文寫第 2、15 層，示範程式用 [1, 15]（0 起算），頁面說兩者起算方式未說明。碰撞機率依賴讀者假設的 $U$，論文沒有給數值，初學者可能誤以為是論文結果。
