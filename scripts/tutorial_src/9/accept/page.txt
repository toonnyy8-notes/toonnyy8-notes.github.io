 Lafa：把預訓練語言模型改成 block 內平行生成的連續 flow

 這篇論文讓 block 之間照 AR 順序、block 內的 token 從噪聲經連續的逐步變換（flow）一起生成，並用同一個模型的 AR 預測驗證一步草稿。

 01 · 生成方式文字切成長度固定的 block：block 之間照 AR 順序生成，block 內的 token 從高斯噪聲出發，經過連續的逐步變換（解一個常微分方程）一起變成詞嵌入。

 02 · 訓練方式模型不從零訓練：把預訓練的 AR 模型（Qwen2.5 0.5B／7B、Qwen3 8B）改成同時做 AR 預測與 block 去噪，訓練資料少於 300 億 tokens。

 01 · Block-AR 分解

 Block 之間自迴歸，block 內平行

 自迴歸（autoregressive，AR）語言模型給定前文，輸出下一個 token 的機率分布。greedy decoding 每一步取機率最大的 token，接到前文後再做下一次 forward，所以一次 forward 只產生一個 token。為了不重算前文，實作上把已處理位置的 key/value 存起來，稱為 KV cache；只要這些位置的表示不隨後續輸入改變，KV cache 就能一直重用。

 Lafa 保留這個結構，只把平行放進固定長度的 block。記 prefix（已知文字）為 c∈VN $c\in V^N$ 、續寫為 y∈VM $y\in V^M$ ，block 大小為 B $B$ （假設 B∣M $B\mid M$ ）。論文把續寫的機率寫成 block 的連乘（Sec. 2.1）：

 p(y∣c)=∏r=0M/B−1p(yrB+1:(r+1)B∣c, y≤rB) $p(y\mid c)=\prod_{r=0}^{M/B-1}p\big(y_{rB+1:(r+1)B}\mid c,\,y_{\le rB}\big)$ ∏M/B−1​p(yrB+1:(r+1)B​∣c,y≤rB​)
Eq. 1

 這是機率的連鎖律，沒有任何近似。block 之間仍照 AR 順序：第 r $r$ 個 block 以 prefix 與前面所有 block 為條件。平行只發生在 block 內，B $B$ 個 token 一起生成。因為 block 之間維持 causal，前面的 token 與它們的表示不會因為後面的 block 改變，所以 prefix 的 KV cache 可以沿用。同樣的分解也用在 block-autoregressive 模型 [22] 與 block discrete diffusion [23]。

 剩下的問題是 block 內的 B $B$ 個 token 怎麼一起生成。Lafa 的做法是在詞嵌入空間中從高斯噪聲出發，解一個常微分方程（第 02 節）。

 c₁τ = 1c₂τ = 1c₃τ = 1y₁τ = 1y₂τ = 1y₃τ = 1τ¹ 0.50τ² 0.50τ³ 0.50

 第一個 block（y₁–y₃）生成後併入 prefix，第二個 block 的三個位置再一起生成。這裡三個位置共用同一個時間 0.5（同步）。

 11 · 研究脈絡

 研究脈絡

 Lafa 接在幾條線的交會點上：AR 的平行解碼（blockwise parallel decoding、Medusa、multi-token prediction）先提出「一次預測多個 token 再驗證」；flow matching 與 CDCD 把連續擴散帶到類別資料，CDCD 也提出 loss-aware time warping；block diffusion 把 block 內去噪與 block 間因果結合；AR 轉擴散的工作（Dream、Efficient-DLM，筆記另列 From Next-Token to Next-Block 與 WeDLM）從預訓練 AR 模型出發；flow map 與 two-time denoiser 讓少步生成成為可能；同期的 ELF 也在詞嵌入空間做 flow。Lafa 把這些放進同一個從 AR 調整而來的模型。每張卡片連到對應的研究筆記。
