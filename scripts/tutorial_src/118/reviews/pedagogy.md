# 118 設計審查：教學法與建置就緒度

1. **P1｜S0 Hero 圖**「判別式 RM 0.999」與「GenRM-CoT 0.0015」。問題：兩個名詞要到 S2、S5 才教，卻先成為視覺主角。另外 0.999 與 0.0015 分別貼著軸的兩端，不會重疊，「沿用 238 頁分層演算法」用不到。需要處理的是端點標籤被裁切。修正：hero 標籤加「詳見 02／05」，並改寫成端點避讓（靠 0 的標籤向右展開、靠 1 的向左展開），不再寫分層。

2. **P1｜S1 末尾符號表**列出 z_t、γ、λ、K、I_CoT、r_θ。問題：這些符號到 S2–S5 才教，符號表成為提前出現的未定義符號。修正：符號表分欄為「本章用到」與「後續章節」，後者標註章節，或每章各放一張小表。

3. **P1｜R10「S2 先給 softmax 一段」**。問題：S2 大綱只列 Eq. 1–2 與 Eq. 3，沒有 softmax、logit、sigmoid、BCE 的定義段落。C2 直接使用這些詞。修正：在 S2 大綱明列「softmax／logit／sigmoid／BCE」一段，並定義 $z_{cls}$。

4. **P1｜C1 先於 Φ、N(μ,1)**。問題：C1 假設常態分數、積分與次序統計，只具備基本機率的讀者看不懂「最大值勝過」。修正：S1 在 C1 之前用一段文字定義「正確解分數偏高的程度 μ」，並說明 μ 與 RM accuracy 的對應；積分公式放進可收合的「計算方式」。

5. **P1｜C3 難度跳躍且內建假設自相矛盾**。圖版寫「Yes 機率取 0 或 1」，但 Eq. 7 平均的是機率；而且同時引入 q_e、q_h、h、K、同分隨機選取，共四個旋鈕。問題：初學者容易把「票數」讀成 Eq. 7，這正是 S9 錯誤 4。修正：預設隱藏 h、q_h，先只顯示 q_e 與 K；加一行「此處以 0/1 近似，Eq. 7 實際平均連續機率」；「困難解答」改名「系統性判錯的解答」。

6. **P1｜S5 過密**。問題：Eq. 6、Eq. 7、Fig. 3 下半、Fig. 2、C3、LO6、LO7 全放在 500–600 字內。修正：拆成 05a 生成理由（Eq. 6＋Fig. 2）與 05b 平均（Eq. 7＋C3），或字數上限提高到 700 並加小標。

7. **P1｜S4 提到 DPO 隱式獎勵、錯誤外推、表徵退化**。問題：DPO 只在 S2 被定義一句，這裡的比較沒有鋪陳。修正：移到 S10，或刪掉這段並只留連結。

8. **P1｜KaTeX 長式在 390px**。問題：Eq. 3、5、6、7 是 display math，6.4 只處理表格與 `<pre>` 的水平捲動，沒有處理公式。修正：`.katex-display{overflow-x:auto;max-width:100%}`，並在 selfTest 檢查含 `.katex-display` 的頁面 `scrollWidth <= innerWidth`。靜態 `figGenRM()` 的 SVG 內文字一律用 `<text>`，不放 KaTeX。

9. **P1｜深色模式色彩**。問題：`--c-pos`、`--c-neg` 只「沿用」淺色值（#3F6E8C／#6B7A3A），SVG 的斜線 pattern 與密度曲線的深色版沒有定義。修正：補深色 token（例如 #8DB4D3／#A9BC7C 互換），pattern 的 stroke 用 `var(--ink-2)`。

10. **P1｜C1 快取鍵與滑桿浮點**。問題：快取 key 取 μ 的字串，步長 0.1 累加會得到 "0.30000000000000004"，快取失效；p 的夾限 [0.01,0.99] 與滑桿範圍 [0.05,0.95] 不一致。修正：滑桿用整數步（μ×10、p×20），key＝`mu10`，並說明夾限的用途或刪除。

11. **P2｜C2 梯度箭頭**「箭頭方向表示梯度下降會把 logit 往哪裡推」。問題：數值正負（梯度）與箭頭方向（負梯度）相反，讀者容易搞混。修正：讀數寫成「更新方向：z_Y ↑」並用文字「上升／下降」，數值欄標明是 ∂L/∂z。

12. **P2｜C4 自訂模式**。問題：沒有規定使用者改動預設組的分數時是否自動切成「自訂」；8 列 radiogroup 的鍵盤操作（方向鍵、Tab 順序）未寫；全部同分、某答案沒有任何候選的顯示未寫。修正：任何編輯即切到「自訂」；每列一個 `radiogroup` 並說明方向鍵；空答案在小表列為 0。

13. **P2｜C3 RM accuracy 在 K=32 比 K=16 低**（0.8018 < 0.8066）。問題：預設參數下曲線不單調，可能被讀成錯誤。修正：C3 下方明寫「RM accuracy 在 h>0 時於 K≥16 後略降，來自平手半對的計算與有限 K」，或於 selfTest 以此值驗證。

14. **P2｜文字風格**。「天真做法」「常見錯誤」「讀者應觀察到」；檢查題 summary 為問句型。問題：「天真」帶評價，與字面風格有落差。修正：「天真做法」改「只依最終 Yes/No 過濾的做法」；檢查題的題幹保留問句，但 `<summary>` 固定寫「檢查理解」。

15. **P2｜學習目標與元件、本文的對應**。問題：LO5、LO6、LO8 沒有互動元件（LO5 的 λ 與 LO8 的過濾可用小型靜態表替代，可接受）；LO12 為超參數背誦，沒有學習價值。修正：把 LO12 改成「說出訓練 GenRM 需要哪些資料，以及哪三項設定與判別式 RM 不同」，超參數表留作參考，不列入驗收。
