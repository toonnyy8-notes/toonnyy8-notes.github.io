 注意力匯聚在注意力層裡形成原生 MoE

 語言模型的注意力常集中在第一個 token。這篇論文說明，這個現象等於替每個注意力 head 的輸出乘上一個 0 到 1 的係數，並提出讓各 head 係數較平均的訓練損失。以下術語從第 01 節開始定義。

 Zizhuo Fu、Wenxuan Zeng、Runsheng Wang、Meng Li（2026）〈Attention Sink Forges Native MoE in Attention Layers: Sink-Aware Training to Address Head Collapse〉

 每根長條是一個 head 的平均係數，示意資料。

 01 · 第一個 token在 Vanilla 注意力的語言模型中（Fig. 2），大部分注意力常放在第一個 token 上，而這個 token 送出的向量長度接近 0，所以這些注意力幾乎不改變輸出。

 02 · 一個係數沒放到第一個 token 的比例是一個 0 到 1 的係數，乘在每個注意力 head 的輸出上，作用像開關；多個 head 各配一個係數，結構與專家混合模型（Mixture-of-Experts）相同。

 03 · 一個損失多數 head 的平均係數偏低，只有少數 head 偏高。作者加入一個懲罰各 head 平均係數差異的損失，在 0.6B 到 8B 的模型上提高平均分數。

 01 · Attention sink

 Softmax 的總和限制產生 attention sink

 先說明注意力（attention）的計算。Transformer 的每一層把每個 token 的表示經過三個線性映射，得到 query 向量 q $q$ 、key 向量 k $k$ 與 value 向量 v $v$ ，長度都是 head 維度 dh $d_h$ ​。token t $t$ 對 token j $j$ 的匹配程度用 logit 表示：zt,j=qt⊤kj/dh $z_{t,j}=q_t^\top k_j/\sqrt{d_h}$ ​=qt⊤​kj​/dh​​。語言模型使用 causal mask，token t $t$ 只能看到位置 j=0,1,…,t $j=0,1,\dots,t$ 的 token。softmax 把這些 logit 轉成非負、總和為 1 的注意力權重 At,j $A_{t,j}$ ​，輸出是 value 的加權和。一層有 Nh $N_h$ ​ 個 head，每個 head 有自己的三個映射，各自算出輸出後經輸出矩陣 WO $W_O$ ​ 相加。對第 l $l$ 層第 h $h$ 個 head（Sec. 2.1）：

 At,jl,h=Softmax(qtl,h⊤kjl,hdh),Otl,h=∑j=0tAt,jl,h vjl,h $A^{l,h}_{t,j}=\mathrm{Softmax}\Big(\frac{q_t^{l,h\top}k_j^{l,h}}{\sqrt{d_h}}\Big),\qquad O_t^{l,h}=\sum_{j=0}^{t}A^{l,h}_{t,j}\,v_j^{l,h}$ l,h​=Softmax(dh​​qtl,h⊤​kjl,h​​),Otl,h​=j=0∑t​At,jl,h​vjl,h​
Sec. 2.1

 本頁會反覆用到 log-sum-exp（LSE）：LSE({ai})=log⁡∑ieai $\mathrm{LSE}(\{a_i\})=\log\sum_i e^{a_i}$ ​})=log∑i​eai​（App. B.1）。softmax 可以寫成 At,j=ezt,j−LSE $A_{t,j}=e^{z_{t,j}-\mathrm{LSE}}$ ​=ezt,j​−LSE，其中 LSE 對同一個 query 的所有 logit 計算。

 StreamingLLM（Xiao et al., 2023）發現，大型語言模型常把很高的注意力權重放在第一個 token 上，而且與這個 token 的語意無關。這個現象稱為注意力匯聚（attention sink）。它已被用在 KV cache 最佳化、長脈絡生成、head 剪枝與量化等方向（Sec. 1）。

 論文說明的成因如下（Sec. 2.1）。softmax 強迫注意力權重總和為 1。當一個 head 只需要分配一部分注意力，或完全不需要注意任何 token 時，剩下的權重仍然必須分到某處；模型把它分到第一個 token（論文用 absorb 一詞）。第一個 token 的語意內容少，它的 value 向量接近 0（Gu et al., 2024；Guo et al., 2024），所以分到它的權重滿足「總和為 1」的限制，卻不影響輸出。簡言之：attention sink 是 LLM 把大量注意力權重放在第一個 token、與語意無關的現象；softmax 強迫權重和為 1，head 不需要完整分配時，剩下的權重分到 value 接近 0 的第一個 token。

 既然問題出在「總和為 1」，解法有兩類：修改 softmax，或在輸出端加上門控。下一節介紹這兩類的代表。

 02 · 兩種機制

 兩種機制消除 attention sink

 Sink Attention（GPT-OSS 採用；Fig. 1 另列 DeepSeek-V4）在 softmax 的分母加上一個可學習的參數 sink（Sec. 2.2）：

 03 · Value drain

 第一個 token 的 value 接近 0

 Vanilla Attention 能把第一個 token 當成 sink，前提是它的 value 向量接近 0，這個現象稱為 value 歸零現象（value drain；Guo et al., 2024；Gu et al., 2024）。Fig. 2 顯示 Qwen2.5-7B、Qwen3-8B、Qwen3-14B、LLaMA-2-7B、LLaMA-3.1-8B、LLaMA-2-13B 六個模型中，第一個 token 的 value ℓ2 $\ell_2$ ​ 範數都遠小於位置 1 到 16 的 token。

 作者的解釋是：第一個 token 收到大量權重，把它的 value 設成接近 0，這些權重才不影響輸出。Sink Attention 的 sink 參數沒有 value，貢獻恰為 0。兩者採用同一個原則：把多出來的權重分到 value 為 0（或接近 0）的成分。

 以下把這種「收到多出來的權重、value 為 0 或接近 0」的成分稱為 sink 成分，它收到的權重記為 At,sink $A_{t,\text{sink}}$ ​。Vanilla Attention 中 sink 成分是第一個 token，所以 At,sink=At,0 $A_{t,\text{sink}}=A_{t,0}$ ​=At,0​；Sink Attention 的合成 sink 在第 04 節介紹。

 App. A 用介入實驗檢查這個解釋：在 KV cache 生成後把第一個 token 的 value 歸零。設定一是所有 head 都歸零（All）；設定二只對「sink 比例」高的 head 歸零。head 級 sink 比例定義為（Eq. 9，Gu et al., 2024）

 04a · 隱式門控

 Sink 的權重是一個隱式門控

 Sink Attention：恰好成立

 在 Sink Attention 中，真實 token j=0,…,t $j=0,\dots,t$ 與合成 sink 共用同一個分母（App. B.3）。把只含真實 token 的分母記為 Dt,tok=∑m=0tezt,m $D_{t,\text{tok}}=\sum_{m=0}^t e^{z_{t,m}}$ ​=∑m=0t​ezt,m​，含 sink 的分母為 Dt,all=Dt,tok+esink $D_{t,\text{all}}=D_{t,\text{tok}}+e^{\mathrm{sink}}$ ​=Dt,tok​+esink。合成 sink 的權重是 At,sink=esink/Dt,all $A_{t,\text{sink}}=e^{\mathrm{sink}}/D_{t,\text{all}}$ ​=esink/Dt,all​，它沒有 value，對輸出的貢獻恰為 0。

 05 · 原生 MoE

 多個 head 與門控構成原生 MoE

 專家混合模型（Mixture-of-Experts，MoE）有兩個要素：彼此獨立的專家模組，以及決定各專家貢獻多少的路由機制（Shazeer et al., 2017；Fedus et al., 2021）。注意力層正好具備這兩者：多個 head 是獨立的專家，sink 形成的門控 G=1−Asink $G=1-A_{\text{sink}}$ ​ 是路由器。所以論文說 attention sink 在注意力層裡形成原生 MoE（Sec. 3.1）。作者指出，隱式門控與 Gated Attention 的兩個核心設計一致：(1) head 專屬，每個 head 有自己的 sink 權重，門控彼此獨立；(2) 有 sigmoid 形式，而 Qiu et al. (2025b) 的實驗發現 sigmoid 是門控的最佳選擇。差別只在 Gated Attention 的門控由一個獨立的投影 Wθ $W_\theta$ ​ 算出（顯式），Vanilla 與 Sink 的門控藏在 softmax 裡（隱式）。

 Sec. 6.2 討論了這個觀點的限制。標點等 token 也可能成為局部 sink（Yu et al., 2024），但它們常匯集前文資訊，不一定只收權重而不貢獻輸出（原文 pure attention dumps；Chen et al., 2024）；第一個 token 在 causal mask 下語意有限，較可靠（Barbero et al., 2025）。更一般的隱式門控可寫成

Sec. 6.2

 Sl,h $S^{l,h}$ 是 sink 類成分的集合，Eq. 4 是 S $S$ 只含一個成分的特例。DeepSeek-V4 的 sink 參數沒有收下全部多出來的權重，第一個 token 仍有大量權重，這時 Asink $A_{\text{sink}}$ ​ 應同時計入兩者；實務上可用「高注意力權重 + 低 value 範數」找出這類成分。Gated Attention 也可能另外形成隱式門控（若某些 token 收到多出來的權重且 value 小），所以一個 head 的啟用程度可能由多個門控共同決定。

 06 · Query／key 幾何

 第一個 token 當 sink 會限制 query 與 key 的分布

 先前研究已知 attention sink 的負面效應：造成極端的激活離群值，使量化困難；降低模型表達能力；而消除 sink 能提升長脈絡表現（Sec. 3.2 引用）。這些研究沒有解釋為什麼。作者用 Fig. 3 回答：取 LongBench 的 2k 個 token，把 query 與 key 向量做 PCA 投影到二維。PCA（主成分分析）找出資料變異最大的兩個正交方向，把高維向量投影到這兩個方向上畫成平面圖。

 Vanilla Attention 的模型（Fig. 3(a)(b)，(c) 為示意圖）呈現兩極結構：為了維持第一個 token 的高權重，後續 token 的 query 聚在 k0 $k_0$ ​ 附近，key 被推離 k0 $k_0$ ​。query 只能在很窄的角度範圍內變化，key 的有效維度也受限，點積的相對差異被壓縮，softmax 區分候選 token 的精度下降；在長脈絡中這會產生注意力雜訊（Liu et al., 2023），降低模型取回相關資訊的能力。

 07 · Head collapse

 只有少數 head 有貢獻：head collapse

 先前研究發現只有固定一小部分 head 真正參與生成。DuoAttention（Xiao et al., 2024）顯示重要的 head 在不同資料集間一致；Sandoval-Segura et al. (2025) 與 Sok et al. (2026) 把超過 25% 的 head 歸零，模型準確率仍然維持（Sec. 4.1）。從原生 MoE 的角度看，這就是 MoE 的專家崩塌（expert collapse）：模型反覆依賴少數幾個專家。作者稱之為 head 崩塌（head collapse）。

 10 · 實作

 12 · 機制假說

 有效的門控是 head collapse 的前提

 Sec. 6.1 用 Fig. 9 追蹤三個訓練診斷：value drain（第一個 token value 的 ℓ2 $\ell_2$ ​ 範數除以其他 value 的平均範數）、attention sink（sink 成分的平均權重）、Head Load Imbalance CV。論文據此提出一個假說（hypothesis）：Value Drain → Attention Sink → Implicit Gating → Head Collapse。

 Value Drain
Attention Sink
Implicit Gating
Head Collapse

 這條鏈（Value Drain → Attention Sink → Implicit Gating → Head Collapse）解釋了三種機制不同的崩塌型態。Gated Attention 的門控從訓練一開始就是顯式的，不需要先建立 sink，所以崩塌可以直接發生，與標準 MoE 的專家崩塌相同，這對應 Fig. 5 中最早、最嚴重的不平衡。Sink Attention 的 sink 沒有 value，模型不需要先壓低某個真實 token 的 value；sink 一取得權重，隱式門控 G=1−Asink $G=1-A_{\text{sink}}$ ​ 就形成，崩塌隨之出現，介於兩者之間。Vanilla Attention 要走完整條鏈：先發展 value drain，讓第一個 token 可以收下多出來的權重而不改變輸出；由此產生的 attention sink 再形成 Eq. 4 的隱式門控；門控生效之後，崩塌才變得明顯。三者不必嚴格分階段，可以在最佳化中共同演化；論文強調的重點是：有效的門控是崩塌的前提。
