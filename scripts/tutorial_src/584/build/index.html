    注意力匯聚在注意力層裡形成原生 MoE

    語言模型的注意力常集中在第一個 token。這篇論文說明，這個現象等於替每個注意力 head 的輸出乘上一個 0 到 1 的係數，並提出讓各 head 係數較平均的訓練損失。以下術語從第 01 節開始定義。

    Zizhuo Fu、Wenxuan Zeng、Runsheng Wang、Meng Li（2026）〈Attention Sink Forges Native MoE in Attention Layers: Sink-Aware Training to Address Head Collapse〉

    01 · 第一個 token

    在 Vanilla 注意力的語言模型中（Fig. 2），大部分注意力常放在第一個 token 上，而這個 token 送出的向量長度接近 0，所以這些注意力幾乎不改變輸出。

    02 · 一個係數

    沒放到第一個 token 的比例是一個 0 到 1 的係數，乘在每個注意力 head 的輸出上，作用像開關；多個 head 各配一個係數，結構與專家混合模型（Mixture-of-Experts）相同。

    03 · 一個損失

    多數 head 的平均係數偏低，只有少數 head 偏高。作者加入一個懲罰各 head 平均係數差異的損失，在 0.6B 到 8B 的模型上提高平均分數。

    01 · Attention sink

    Softmax 的總和限制產生 attention sink

    先說明注意力（attention）的計算。Transformer 的每一層把每個 token 的表示經過三個線性映射，得到 query 向量 $q$、key 向量 $k$ 與 value 向量 $v$，長度都是 head 維度 $d_h$。token $t$ 對 token $j$ 的匹配程度用 logit 表示：$z_{t,j}=q_t^\top k_j/\sqrt{d_h}$。語言模型使用 causal mask，token $t$ 只能看到位置 $j=0,1,\dots,t$ 的 token。softmax 把這些 logit 轉成非負、總和為 1 的注意力權重 $A_{t,j}$，輸出是 value 的加權和。一層有 $N_h$ 個 head，每個 head 有自己的三個映射，各自算出輸出後經輸出矩陣 $W_O$ 相加。對第 $l$ 層第 $h$ 個 head（Sec. 2.1）：

    $$A^{l,h}_{t,j}=\mathrm{Softmax}\Big(\frac{q_t^{l,h\top}k_j^{l,h}}{\sqrt{d_h}}\Big),\qquad O_t^{l,h}=\sum_{j=0}^{t}A^{l,h}_{t,j}\,v_j^{l,h}$$
    Sec. 2.1

    本頁會反覆用到 log-sum-exp（LSE）：$\mathrm{LSE}(\{a_i\})=\log\sum_i e^{a_i}$（App. B.1）。softmax 可以寫成 $A_{t,j}=e^{z_{t,j}-\mathrm{LSE}}$，其中 LSE 對同一個 query 的所有 logit 計算。

    StreamingLLM（Xiao et al., 2023）發現，大型語言模型常把很高的注意力權重放在第一個 token 上，而且與這個 token 的語意無關。這個現象稱為注意力匯聚（attention sink）。它已被用在 KV cache 最佳化、長脈絡生成、head 剪枝與量化等方向（Sec. 1）。

    論文說明的成因如下（Sec. 2.1）。softmax 強迫注意力權重總和為 1。當一個 head 只需要分配一部分注意力，或完全不需要注意任何 token 時，剩下的權重仍然必須分到某處；模型把它分到第一個 token（論文用 absorb 一詞）。第一個 token 的語意內容少，它的 value 向量接近 0（Gu et al., 2024；Guo et al., 2024），所以分到它的權重滿足「總和為 1」的限制，卻不影響輸出。簡言之：attention sink 是 LLM 把大量注意力權重放在第一個 token、與語意無關的現象；softmax 強迫權重和為 1，head 不需要完整分配時，剩下的權重分到 value 接近 0 的第一個 token。

    既然問題出在「總和為 1」，解法有兩類：修改 softmax，或在輸出端加上門控。下一節介紹這兩類的代表。

    02 · 兩種機制

    兩種機制消除 attention sink

    Sink Attention（GPT-OSS 採用；Fig. 1 另列 DeepSeek-V4）在 softmax 的分母加上一個可學習的參數 sink（Sec. 2.2）：

    $$\mathrm{Softmax}_{\text{sink}}(x)_i=\frac{\exp(x_i)}{\sum_j\exp(x_j)+\exp(\mathrm{sink})}$$
    Eq. 1

    這放寬了「總和為 1」的限制：真實 token 的權重總和可以小於 1，差額落在一個沒有 value 的合成 sink 上，取代 Vanilla Attention 中的第一個 token。

    Gated Attention（Qwen3-Next 採用；Fig. 1 另列 Qwen3.5、3.6）有兩個設計：每個 head 專屬的門控，以及 sigmoid 激活。第 $h$ 個 head 的門控與層輸出為：

    $$\begin{gathered}G_t^{l,h}=\sigma\big(x_t^lW_\theta^{l,h}\big),\quad W_\theta^{l,h}\in\mathbb R^{d_{\text{model}}\times1}\\ O_t^l=\sum_{h=1}^{H}G_t^{l,h}\cdot O_t^{l,h}W_O^{l,h}\end{gathered}$$
    Eq. 2

    $x_t^l$ 是該層輸入，$W_O^{l,h}$ 是 head $h$ 的輸出投影。總結兩者的改動：Sink Attention 在 softmax 分母加 $\exp(\mathrm{sink})$，sink 為可學習參數、沒有 value（Eq. 1）；Gated Attention 把每個 head 的輸出乘上 $G=\sigma(xW_\theta)$，$W_\theta\in\mathbb R^{d_{\text{model}}\times1}$（Eq. 2）。Sec. 2.2 寫道，這個 head 專屬的門控在注意力層引入 MoE 結構，使 head 稀疏使用並消除 sink。下圖重繪 Fig. 1：論文把 Vanilla 與 Sink Attention 歸為「隱式門控」，把 Gated Attention 歸為「顯式門控」，原因在第 04 節說明。

    檢查理解

    Sink Attention 與 Gated Attention 各改了什麼？

    Sink：softmax 分母加 $\exp(\mathrm{sink})$，sink 為可學習參數、沒有 value（Eq. 1，GPT-OSS）；Gated：每個 head 輸出乘上 $G=\sigma(xW_\theta)$，$W_\theta\in\mathbb R^{d_{\text{model}}\times1}$（Eq. 2，Qwen3-Next）。

    03 · Value drain

    第一個 token 的 value 接近 0

    Vanilla Attention 能把第一個 token 當成 sink，前提是它的 value 向量接近 0，這個現象稱為 value 歸零現象（value drain；Guo et al., 2024；Gu et al., 2024）。Fig. 2 顯示 Qwen2.5-7B、Qwen3-8B、Qwen3-14B、LLaMA-2-7B、LLaMA-3.1-8B、LLaMA-2-13B 六個模型中，第一個 token 的 value $\ell_2$ 範數都遠小於位置 1 到 16 的 token。

    作者的解釋是：第一個 token 收到大量權重，把它的 value 設成接近 0，這些權重才不影響輸出。Sink Attention 的 sink 參數沒有 value，貢獻恰為 0。兩者採用同一個原則：把多出來的權重分到 value 為 0（或接近 0）的成分。

    以下把這種「收到多出來的權重、value 為 0 或接近 0」的成分稱為 sink 成分，它收到的權重記為 $A_{t,\text{sink}}$。Vanilla Attention 中 sink 成分是第一個 token，所以 $A_{t,\text{sink}}=A_{t,0}$；Sink Attention 的合成 sink 在第 04 節介紹。

    App. A 用介入實驗檢查這個解釋：在 KV cache 生成後把第一個 token 的 value 歸零。設定一是所有 head 都歸零（All）；設定二只對「sink 比例」高的 head 歸零。head 級 sink 比例定義為（Eq. 9，Gu et al., 2024）

    $$\alpha^{l,h}_{\text{sink}}=\frac1T\sum_{i=0}^{T-1}A^{l,h}_{i,\text{sink}}$$
    Eq. 9

    選擇性設定只歸零 $\alpha_{\text{sink}}>\tau$ 的 head，$\tau=0.75$。Table 3 的九項基準平均如下。

    04a · 隱式門控

    Sink 的權重是一個隱式門控

    Sink Attention：恰好成立

    在 Sink Attention 中，真實 token $j=0,\dots,t$ 與合成 sink 共用同一個分母（App. B.3）。把只含真實 token 的分母記為 $D_{t,\text{tok}}=\sum_{m=0}^t e^{z_{t,m}}$，含 sink 的分母為 $D_{t,\text{all}}=D_{t,\text{tok}}+e^{\mathrm{sink}}$。合成 sink 的權重是 $A_{t,\text{sink}}=e^{\mathrm{sink}}/D_{t,\text{all}}$，它沒有 value，對輸出的貢獻恰為 0。

    每個真實 token 的權重可以拆成兩個因子：$A_{t,j}=\dfrac{e^{z_{t,j}}}{D_{t,\text{tok}}}\cdot\dfrac{D_{t,\text{tok}}}{D_{t,\text{all}}}$（Eq. 19–20）。第一個因子是只在真實 token 上正規化的權重 $\tilde A_{t,j}$（總和為 1），第二個因子等於 $1-A_{t,\text{sink}}$。所以輸出為：

    $$O_t^{l,h}=\sum_{j\ne\text{sink}}A_{t,j}v_j=(1-A_{t,\text{sink}})\cdot\sum_{j\ne\text{sink}}\tilde A_{t,j}v_j,\qquad \tilde A_{t,j}=\frac{A_{t,j}}{1-A_{t,\text{sink}}}$$
    Eq. 3、21

    右邊是「一個正常的注意力輸出」乘上一個介於 0 與 1 之間的數。這個數就是門控值（Sec. 3.1）：

    $$G_t^{l,h}=1-A^{l,h}_{t,\text{sink}}$$
    Eq. 4

    它還有 sigmoid 形式。令 $\mathrm{LSE}_{t,\text{tok}}=\log D_{t,\text{tok}}$，則 $1-A_{t,\text{sink}}=\dfrac{D_{t,\text{tok}}}{D_{t,\text{tok}}+e^{\mathrm{sink}}}=\sigma\big(\mathrm{LSE}_{t,\text{tok}}-\mathrm{sink}\big)$（Eq. 22–23）。Sink Attention 沒有任何近似：合成 sink 的 value 恰為 0，所以 Eq. 3 是恆等式。

    04b · 隱式門控

    Vanilla Attention：在 $v_0\approx0$ 時近似成立

    Vanilla Attention 的 sink 成分是第一個 token（App. B.2）。令 $D_t=\sum_{m=0}^te^{z_{t,m}}$、$D_{t,\neg0}=\sum_{m=1}^te^{z_{t,m}}$。同樣的拆法給出 $A_{t,j}=\tilde A_{t,j}\cdot D_{t,\neg0}/D_t$，而 $D_{t,\neg0}/D_t=1-A_{t,0}$。差別在於第一個 token 有真實的 value $v_0$，必須假設 $v_0\approx0$ 才能丟掉 $A_{t,0}v_0$：

    $$O_t\approx\sum_{j=1}^tA_{t,j}v_j=(1-A_{t,0})\cdot\sum_{j=1}^t\tilde A_{t,j}v_j$$
    Eq. 10、14

    這個等式的誤差恰為 $A_{t,0}v_0$，所以 value drain（第 03 節）是 Vanilla 的隱式門控成立的條件。sigmoid 形式為 $1-A_{t,0}=\dfrac{D_{t,\neg0}}{D_{t,\neg0}+e^{z_{t,0}}}=\sigma\big(\mathrm{LSE}_{t,\neg0}-z_{t,0}\big)$，其中 $z_{t,0}=q_t^\top k_0/\sqrt{d_h}$（Eq. 15–16）。

    整理兩種機制：輸出都寫成 $O=(1-A_{\text{sink}})\sum\tilde A v$，$\tilde A=A/(1-A_{\text{sink}})$，門控 $G=1-A_{\text{sink}}$（Eq. 3–4）；Sink Attention 的 sigmoid 形式為 $G=\sigma(\mathrm{LSE}_{\text{tok}}-\mathrm{sink})$（Eq. 23），Vanilla 為 $G=\sigma(\mathrm{LSE}_{\neg0}-q^\top k_0/\sqrt{d_h})$（Eq. 16）；Vanilla 依賴 $v_0\approx0$，誤差為 $A_0v_0$，Sink 恰好成立。

    由 Eq. 16 取反函數，Vanilla 要讓門控等於 $G$，第一個 token 的 logit 必須比其他 token 的 LSE 高出 $z_{t,0}-\mathrm{LSE}_{t,\neg0}=\ln\frac{1-G}{G}$本頁推導（例：$G=0.1$ 需要高出 $\ln9\approx2.197$）。這是與第 06 節幾何描述相容的必要條件；Sec. 3.2 的幾何是定性的觀察，不是由此式推出。

    App. B.2 逐行推導

    由 $A_{t,j}=e^{z_{t,j}}/D_t$，對 $j\ge1$ 在分子分母同乘 $D_{t,\neg0}$：

    $$A_{t,j}=\frac{e^{z_{t,j}}}{D_{t,\neg0}}\cdot\frac{D_{t,\neg0}}{D_t}=\tilde A_{t,j}\cdot\frac{D_{t,\neg0}}{D_t}$$
    Eq. 12–13
    $$\frac{D_{t,\neg0}}{D_t}=1-\frac{e^{z_{t,0}}}{D_t}=1-A_{t,0},\qquad 1-A_{t,0}=\frac{1}{1+\exp\big(z_{t,0}-\log D_{t,\neg0}\big)}=\sigma\big(\mathrm{LSE}_{t,\neg0}-z_{t,0}\big)$$
    Eq. 15–16

    05 · 原生 MoE

    多個 head 與門控構成原生 MoE

    專家混合模型（Mixture-of-Experts，MoE）有兩個要素：彼此獨立的專家模組，以及決定各專家貢獻多少的路由機制（Shazeer et al., 2017；Fedus et al., 2021）。注意力層正好具備這兩者：多個 head 是獨立的專家，sink 形成的門控 $G=1-A_{\text{sink}}$ 是路由器。所以論文說 attention sink 在注意力層裡形成原生 MoE（Sec. 3.1）。作者指出，隱式門控與 Gated Attention 的兩個核心設計一致：(1) head 專屬，每個 head 有自己的 sink 權重，門控彼此獨立；(2) 有 sigmoid 形式，而 Qiu et al. (2025b) 的實驗發現 sigmoid 是門控的最佳選擇。差別只在 Gated Attention 的門控由一個獨立的投影 $W_\theta$ 算出（顯式），Vanilla 與 Sink 的門控藏在 softmax 裡（隱式）。

    Sec. 6.2 討論了這個觀點的限制。標點等 token 也可能成為局部 sink（Yu et al., 2024），但它們常匯集前文資訊，不一定只收權重而不貢獻輸出（原文 pure attention dumps；Chen et al., 2024）；第一個 token 在 causal mask 下語意有限，較可靠（Barbero et al., 2025）。更一般的隱式門控可寫成

    $$G_t^{l,h}=1-\sum_{j\in S^{l,h}}A^{l,h}_{t,j}$$
    Sec. 6.2

    $S^{l,h}$ 是 sink 類成分的集合，Eq. 4 是 $S$ 只含一個成分的特例。DeepSeek-V4 的 sink 參數沒有收下全部多出來的權重，第一個 token 仍有大量權重，這時 $A_{\text{sink}}$ 應同時計入兩者；實務上可用「高注意力權重 + 低 value 範數」找出這類成分。Gated Attention 也可能另外形成隱式門控（若某些 token 收到多出來的權重且 value 小），所以一個 head 的啟用程度可能由多個門控共同決定。

    注意力層中誰是專家、誰是路由器？隱式門控與 Gated Attention 共有哪兩個設計？

    head 是專家，sink 形成的門控是路由；head 專屬、有 sigmoid 形式（Sec. 3.1）。

    06 · Query／key 幾何

    第一個 token 當 sink 會限制 query 與 key 的分布

    先前研究已知 attention sink 的負面效應：造成極端的激活離群值，使量化困難；降低模型表達能力；而消除 sink 能提升長脈絡表現（Sec. 3.2 引用）。這些研究沒有解釋為什麼。作者用 Fig. 3 回答：取 LongBench 的 2k 個 token，把 query 與 key 向量做 PCA 投影到二維。PCA（主成分分析）找出資料變異最大的兩個正交方向，把高維向量投影到這兩個方向上畫成平面圖。

    Vanilla Attention 的模型（Fig. 3(a)(b)，(c) 為示意圖）呈現兩極結構：為了維持第一個 token 的高權重，後續 token 的 query 聚在 $k_0$ 附近，key 被推離 $k_0$。query 只能在很窄的角度範圍內變化，key 的有效維度也受限，點積的相對差異被壓縮，softmax 區分候選 token 的精度下降；在長脈絡中這會產生注意力雜訊（Liu et al., 2023），降低模型取回相關資訊的能力。

    Sink Attention 與 Gated Attention 的模型（Fig. 3(d)(e)，(f) 為示意圖）中，$k_0$ 不再占據特殊位置，query 與 key 分散分布，沒有明顯的兩極化。softmax 可以用完整的表示能力區分 token，這對長脈絡特別有利。

    07 · Head collapse

    只有少數 head 有貢獻：head collapse

    先前研究發現只有固定一小部分 head 真正參與生成。DuoAttention（Xiao et al., 2024）顯示重要的 head 在不同資料集間一致；Sandoval-Segura et al. (2025) 與 Sok et al. (2026) 把超過 25% 的 head 歸零，模型準確率仍然維持（Sec. 4.1）。從原生 MoE 的角度看，這就是 MoE 的專家崩塌（expert collapse）：模型反覆依賴少數幾個專家。作者稱之為 head 崩塌（head collapse）。

    門控值提供了量化每個 head 貢獻的方法。head $h$ 在第 $l$ 層的重要度定義為一個 batch 中所有 token 的平均門控值：

    $$\mathrm{Imp}^{l,h}=\frac{1}{|\mathcal T|}\sum_{(i,t)\in\mathcal T}G^{l,h}_{i,t}$$
    Eq. 5

    $\mathcal T$ 是 batch 中所有 token（$i$ 為樣本、$t$ 為位置）。Gated Attention 用 Eq. 2 的門控，Vanilla 與 Sink 用 Eq. 4。每個門控值都在 0 與 1 之間，所以 $\mathrm{Imp}\in[0,1]$本頁推導；Vanilla 在 $t=0$ 時只有一個 token，$A_{0,0}=1$、$G=0$，論文沒有說明是否排除 $t=0$。各層的不平衡用變異係數（coefficient of variation，CV）衡量，再對層平均：

    $$\text{Head Imbalance}=\frac1{N_L}\sum_{l=1}^{N_L}\mathrm{CV}\big(\{\mathrm{Imp}^{l,h}\}_{h=1}^{N_h}\big),\qquad \mathrm{CV}(\cdot)=\frac{\mathrm{std}(\cdot)}{\mathrm{mean}(\cdot)}$$
    Eq. 6

    總結兩個定義：$\mathrm{Imp}$ 是所有 token 上門控值 $G$ 的平均（Eq. 5）；Head Imbalance 是各層 CV 的平均，CV = std/mean（Eq. 6）。手算一例：一層有 4 個 head，$\mathrm{Imp}=(0.9,0.1,0.1,0.1)$。平均 mean = 0.3，母體標準差 std $=\sqrt{(0.6^2+3\times0.2^2)/4}=\sqrt{0.12}=0.3464$，所以 CV = 0.3464 / 0.3 = 1.1547（母體 std）。論文沒有說明 std 用母體（除以 $N$）或樣本（除以 $N-1$）版本，本頁一律用母體版本。

    Fig. 4（LLaMA-3.1-8B、GPT-OSS-20B、Qwen3-Next-80B-A3B）與 App. C（以 GSM8K 的 500 個樣本計算；Fig. 10 的六個 GPT-OSS 與 LLaMA 模型、Fig. 11 的十個 Qwen2.5／Qwen3 模型，共 16 個）都顯示：三種機制都有少數高重要度 head 與許多低重要度 head。App. C 另指出模型越大，崩塌越嚴重。Qwen3-Next 使用逐元素（element-wise）門控，論文先在每個 head 內對維度平均，再套用 Eq. 5。

    Fig. 5 追蹤從頭訓練時的 Head Imbalance：Sec. 4.1 概括為不平衡在早期上升、最後停在較高水準，Sec. 5.2 再細分（第 11 節）。作者認為某些 head 在早期占優勢後得到較多的更新（原文 attract disproportionate updates）。崩塌有三個後果（Sec. 4.1）：有效參數量低於名目參數量；不平衡妨礙模型學習多樣、專門化的表示；崩塌的 head 在訓練與推論時仍消耗運算。

    檢查理解

    $\mathrm{Imp}$ 與 Head Imbalance 如何定義？$\mathrm{Imp}=(0.9,0.1,0.1,0.1)$ 的 CV？

    $\mathrm{Imp}$＝所有 token 上 $G$ 的平均（Eq. 5）；Head Imbalance＝各層 CV 的平均，CV＝std/mean（Eq. 6）；例：mean 0.3、std 0.3464、CV 1.1547（母體 std）。

    08 · 輔助損失

    輔助損失懲罰各層重要度的變異係數

    從頭訓練的模型，作者借用 MoE 的負載平衡做法（Shazeer et al., 2017；Fedus et al., 2021），直接最小化各層重要度的 CV（Sec. 4.2）：

    $$\mathcal L_{\text{aux}}=\lambda\sum_{l=1}^{N_L}N_h\Big[\mathrm{CV}\big(\{\mathrm{Imp}^{l,h}\}_{h=1}^{N_h}\big)\Big]^2,\qquad \mathcal L=\mathcal L_{\text{base}}+\mathcal L_{\text{aux}}$$
    Eq. 7

    $\mathcal L_{\text{base}}$ 是一般的語言模型損失。Eq. 7 即 $\mathcal L_{\text{aux}}=\lambda\sum_lN_h[\mathrm{CV}]^2$，從頭訓練時 $\lambda=10^{-4}$（Sec. 5.1）。CV 不隨所有 head 同乘一個倍數而改變，所以這個損失只要求各 head 相對一致，不規定它們的平均水準。用母體 std 時，$N\cdot\mathrm{CV}^2=\sum_h(x_h/\mu-1)^2$本頁推導，$x_h$ 是 head $h$ 的重要度、$\mu$ 是平均；第 07 節的例子 $(0.9,0.1,0.1,0.1)$ 得到 $N\cdot\mathrm{CV}^2=2^2+3\times(2/3)^2=5.333$。也就是說，Eq. 7 的 $N_h$ 把每個 head 相對平均的偏差平方加總起來。

    推導：恆等式與梯度

    記 $S=\sum_i(x_i-\mu)^2$，母體 $\mathrm{std}^2=S/N$，所以 $N\cdot\mathrm{CV}^2=N\cdot\frac{S/N}{\mu^2}=\frac{S}{\mu^2}=\sum_i\big(\frac{x_i}{\mu}-1\big)^2$。對 $x_h$ 微分（$\partial\mu/\partial x_h=1/N$，$\partial S/\partial x_h=2(x_h-\mu)$）：

    $$\frac{\partial(N\mathrm{CV}^2)}{\partial x_h}=\frac{2(x_h-\mu)}{\mu^2}-\frac{2S}{N\mu^3}$$
    本頁推導

    第一項把高於平均的 head 往下推、低於平均的往上推；第二項對所有 head 相同且為負，在梯度下降中使所有 head 一起增加。兩項合起來滿足 $\sum_hx_h\,\partial(N\mathrm{CV}^2)/\partial x_h=0$，這是縮放不變的代數形式。

    第 09 節會說明微調時的另一種版本，C2 先把它一起算出來，所以這裡先定義兩個名詞：每層重要度最高的 $m$ 個 head 稱為共享 head（shared heads），其餘稱為路由 head（routed heads）；微調版的損失只對 routed heads 計算 CV（Eq. 8）：$\mathcal L_{\text{aux}}=\lambda\sum_l(N_h-m)[\mathrm{CV}(\{\mathrm{Imp}^{l,h}:h\notin\mathcal T_m^l\})]^2$，$\mathcal T_m^l$ 是第 $l$ 層 top-$m$ head 的集合。為什麼微調時要這樣分，在第 09 節說明。

    09 · 微調

    微調時保留 shared heads，只平衡 routed heads

    直接用 Eq. 7 微調已訓練好的模型，會出現作者稱為 head 釘住效應（head pinning effect）的現象（Sec. 4.2、App. D）。Fig. 12 中圖顯示，Qwen3-8B 用 Eq. 7 微調一個 epoch 後，幾乎所有 head 都有一致的高重要度。CV 確實變小了，但這不是期望的平衡。作者的解釋：預訓練時崩塌出的主導 head 對生成已不可或缺，降低它們會傷害表現，所以它們的門控在微調中幾乎不變（原文 resist change）；損失要求一致時，其餘 head 的門控升高到與主導 head 相近。簡言之，head pinning 是：主導 head 的門控幾乎不變（原文 resist change），其餘 head 的門控升高到與之相近，結果幾乎所有 head 都變高。對策借鑑 DeepSeekMoE 的共享專家與路由專家（Dai et al., 2024）。每層 top-$m$ 個最重要的 head 為 shared heads，不放進損失，保留已學到的行為；只對其餘 routed heads 計算 $(N_h-m)[\mathrm{CV}]^2$，微調時 $\lambda=10^{-2}$（Sec. 5.1）。令 $\mathcal T_m^l=\arg\mathrm{top}_m\{\mathrm{Imp}^{l,h}\}_{h=1}^{N_h}$：

    $$\mathcal L_{\text{aux}}=\lambda\sum_{l=1}^{N_L}(N_h-m)\Big[\mathrm{CV}\big(\{\mathrm{Imp}^{l,h}:h\notin\mathcal T_m^l\}\big)\Big]^2$$
    Eq. 8

    Fig. 12 右圖：用 Eq. 8 微調後，routed heads 之間較平均，shared heads 維持高啟用。論文沒有給 $m$ 的值，也沒有說明 $\mathcal T_m^l$ 是在微調前選定，還是每個 batch 重選。

    下面的玩具模型只示範一件事：固定幾個高重要度 head 時，以 Eq. 7 最小化 CV 的梯度下降會讓其餘 head 一起升高，方向與 App. D 的描述相同。主導 head 的「幾乎不變」在這裡以凍結表示，所以 pinning 的結果直接來自這個設定，玩具模型不證明論文的因果解釋。

    10 · 實作

    門控值可由 Flash Attention 的 LSE 算出

    $G=1-A_{\text{sink}}$ 需要注意力權重，但 Flash Attention 等融合 kernel 不輸出注意力權重；改用 eager 模式取出權重會犧牲效率（Sec. 4.2）。作者改用 kernel 在前向計算中本來就算好的 LSE。

    • Vanilla：$G=\sigma\big(\mathrm{LSE}_{\neg0}-q_t^\top k_0/\sqrt{d_h}\big)$。呼叫 out, lse = torch.ops.aten._scaled_dot_product_flash_attention(q, k, v)，由回傳的 LSE 與第一個 token 的 query-key 乘積算出 $G$，不需實體化完整的權重矩陣。
    • Sink：現有做法（Agarwal et al., 2025）用非融合運算，顯著降低效率。作者改為對所有 token 跑標準 Flash Attention，再乘上 $G=\sigma(\mathrm{LSE}-\mathrm{sink})$，LSE 由 kernel 取得；同一個 $G$ 直接供輔助損失使用。

    整理：作者用 kernel 回傳的 LSE 得到門控：Sink 為 $\sigma(\mathrm{LSE}-\mathrm{sink})$ 並乘到標準 Flash 輸出，Vanilla 為 $\sigma(\mathrm{LSE}_{\neg0}-q^\top k_0/\sqrt{d_h})$；額外訓練延遲小於 2%（Sec. 5.1）。

    標準 Flash Attention 對真實 token 正規化，它的輸出就是 $\sum_j\tilde A_{t,j}v_j$；由 Eq. 21，$O_t=\sigma(\mathrm{LSE}_{\text{tok}}-\mathrm{sink})\cdot\text{FlashOut}$ 是 Sink Attention 的精確輸出本頁推導。Vanilla 的 Flash 輸出本身就是完整輸出，$G$ 只用於重要度與輔助損失，不可再乘到輸出上。

    數值上要注意一點本頁推導。kernel 回傳的 LSE 含第一個 token，論文沒有說明 $\mathrm{LSE}_{\neg0}$ 如何取得。只用 kernel 的 LSE，可得 $G=1-e^{z_{t,0}-\mathrm{LSE}}$，寫成 -expm1(z0 - lse)；先推回 $\mathrm{LSE}_{\neg0}=\mathrm{LSE}+\log(-\mathrm{expm1}(z_{t,0}-\mathrm{LSE}))$ 再代入 sigmoid，數學與精度都相同。由含第一個 token 的 LSE 相減，在 $A_0\to1$ 時發生相消：LSE 本身已四捨五入，結果的相對精度流失。若能另外對 $j\ge1$ 計算 $\mathrm{LSE}_{\neg0}$，就沒有這個問題。對 $\mathrm{Imp}$ 而言，這個絕對誤差小於 $10^{-16}$，可以忽略。

    本節重點：Flash Attention 等融合 kernel 不輸出注意力權重，eager 模式太慢；作者用 kernel 回傳的 LSE 得到門控，Sink 為 $\sigma(\mathrm{LSE}-\mathrm{sink})$ 並乘到標準 Flash 輸出，Vanilla 為 $\sigma(\mathrm{LSE}_{\neg0}-q^\top k_0/\sqrt{d_h})$，額外訓練延遲小於 2%。kernel 的 LSE 含第一個 token，論文未說明 $\mathrm{LSE}_{\neg0}$ 如何取得；由含第一個 token 的 LSE 相減，在 $A_0\to1$ 時相消（本頁推導）。

    背景（FlashAttention 的標準做法，不是本論文內容）：kernel 把 token 分成區塊依序處理，維護目前的最大值 $m$ 與以 $m$ 縮放的指數和 $\ell$；遇到更大的 logit 時把舊的和乘上 $e^{m-m'}$ 再加上新區塊，最後 $\mathrm{LSE}=m+\ln\ell$。直接加總 $e^{z}$ 在 logit 大於約 709.78 時會超出 float64 的範圍。

    12 · 機制假說

    有效的門控是 head collapse 的前提

    Sec. 6.1 用 Fig. 9 追蹤三個訓練診斷：value drain（第一個 token value 的 $\ell_2$ 範數除以其他 value 的平均範數）、attention sink（sink 成分的平均權重）、Head Load Imbalance CV。論文據此提出一個假說（hypothesis）：Value Drain → Attention Sink → Implicit Gating → Head Collapse。

    1. Value Drain
    2. Attention Sink
    3. Implicit Gating
    4. Head Collapse

    這條鏈（Value Drain → Attention Sink → Implicit Gating → Head Collapse）解釋了三種機制不同的崩塌型態。Gated Attention 的門控從訓練一開始就是顯式的，不需要先建立 sink，所以崩塌可以直接發生，與標準 MoE 的專家崩塌相同，這對應 Fig. 5 中最早、最嚴重的不平衡。Sink Attention 的 sink 沒有 value，模型不需要先壓低某個真實 token 的 value；sink 一取得權重，隱式門控 $G=1-A_{\text{sink}}$ 就形成，崩塌隨之出現，介於兩者之間。Vanilla Attention 要走完整條鏈：先發展 value drain，讓第一個 token 可以收下多出來的權重而不改變輸出；由此產生的 attention sink 再形成 Eq. 4 的隱式門控；門控生效之後，崩塌才變得明顯。三者不必嚴格分階段，可以在最佳化中共同演化；論文強調的重點是：有效的門控是崩塌的前提。

    檢查理解

    Sec. 6.1 的假說鏈為何？為何 Gated Attention 最早崩塌？

    Value Drain → Attention Sink → Implicit Gating → Head Collapse；Gated 的門控一開始就是顯式的，不需先建立 sink，所以崩塌直接發生（Sec. 6.1、Fig. 5）。

    研究脈絡

    這條脈絡從 Transformer 的 softmax 注意力開始；StreamingLLM 提出 attention sink 並用於串流推論；後續研究探討 sink 的成因（value drain、over-mixing、massive activation）；另一批研究修改 softmax 或加上門控來消除 sink；MoE 端則有專家崩塌與負載平衡的研究。本論文把兩條線接起來：sink 是隱式門控，head collapse 是專家崩塌。每張卡片連到對應的研究筆記。
