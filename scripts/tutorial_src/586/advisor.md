## 2. 必須講對的推導（5 個）

### D1. Thm 3.1（附錄 B）

1. 只擾動 W_ij：z_i' = Σ_k (W_ik + δ_kj ΔW_ij) h_k = z_i + ΔW_ij h_j（式 12）。所以 Δz_i = h_j ΔW_ij，其餘 Δz_k = 0。**這一步是精確的**（線性層）。
2. 把 f 看成 z^(l) 的函數 F：F(z+Δz) = F(z) + (∂F/∂z)Δz + O(∥Δz∥²)（式 13）。丟掉高階項：Δf ≈ Σ_k J_k Δz_k（式 14）。**唯一的近似在這裡。**
3. 和式只剩 k=i：Δf ≈ J_i·(ΔW_ij·h_j)（式 15）。
4. ΔW_ij·h_j 是純量，所以 ∥Δf∥₂ ≈ ∥J_i∥₂·\|ΔW_ij\|·\|h_j\|（式 16）。**這一步也是精確的。**

成立條件：F 在 z 可微；\|ΔW_ij h_j\| 夠小；h 是「該輸入下」的活化（分數依賴輸入）。定理本身沒有用到活化函數的形式——GELU/SiLU 的非線性全部藏在 J_i 裡。

〔顧問推導〕可手算的玩具例（已用程式驗算）：f(x) = V·GELU(Wx)，W = [[1, −2],[0.5, 3]]，x = (1, 0.5)，V = [[1,2],[0,−1],[2,0]]。
- z = (0, 2)；GELU'(0) = 0.5，GELU'(2) = 1.08523。
- J_1 = V[:,1]·0.5 = (0.5, 0, 1)，∥J_1∥ = 1.11803；J_2 = V[:,2]·1.08523 = (2.17046, −1.08523, 0)，∥J_2∥ = 2.42665。
- S = [[1.11803, 1.11803],[1.21333, 3.63998]]。注意 \|W_12\| = 2 是 \|W_11\| = 1 的兩倍，但因 \|x_2\| = 0.5，兩者分數相同。
- 一階預測 vs 真實 ∥Δf∥：ΔW_11 = 0.01 → 0.01118 vs 0.01127；0.1 → 0.11180 vs 0.12071；1.0 → 1.11803 vs 1.88130；**−1.0（把 W_11 歸零，即 \|ΔW\| = \|W\|）→ 1.11803 vs 0.35476**。最後一列說明：S_ij 不是「把權重拿掉」的真實位移，一階近似在 \|ΔW\| = \|W\| 這個尺度已經不準。

### D2. Cor 3.2（附錄 C）

1. 全微分：Δf ≈ Σ_l Σ_{i,j} (∂f/∂W_ij) ΔW_ij（式 18）。
2. 鏈鎖律：∂f/∂W_ij = (∂f/∂z_i)(∂z_i/∂W_ij) = J_i·h_j（式 19）。
3. 代入：Δf ≈ Σ (J_i h_j) ΔW_ij（式 20）。
4. 三角不等式：∥Σ_x∥ ≤ Σ∥x∥ ⇒ ∥Δf∥₂ ⪅ Σ ∥J_i∥₂·\|h_j\|·\|ΔW_ij\|（式 21–22）。

要講對的三點：
- 「⪅」＝先 ≈（Taylor）再 ≤（三角不等式）。它是**一階位移**的上界，不是真位移的嚴格上界。
- 三角不等式把各項的方向抵消全部丟掉，所以上界可以很鬆。〔顧問推導〕n 個互相正交、大小相同的項，真實範數隨 √n 成長，上界隨 n 成長。
- 上界裡是 \|ΔW_ij\|。附錄 C 最後說「S_ij 的總和是總位移的理論上界」，這只有在 \|ΔW_ij\| ≤ \|W_ij\| 時才成立〔顧問推導〕；剪枝（ΔW = −W）滿足，微調不保證。附錄 C 的標題本身就叫 "Multi-layer and Multi-weight **Pruning**"。

### D3. 式(4)：Hutchinson 式估計

令 a = J_i ∈ R^{d_final}，X = ξᵀa = Σ_k ξ_k a_k。因為 ∂(ξᵀf)/∂z_i = ξᵀJ_i：

E[X²] = Σ_k a_k² E[ξ_k²] + Σ_{k≠m} a_k a_m E[ξ_k ξ_m] = Σ_k a_k² = ∥J_i∥₂²。

條件：ξ_k 獨立、E[ξ_k] = 0、ξ_k² = 1。論文只寫結論（式 4、式 24），中間這一行是〔顧問推導〕。

要講對的點：
- 省成本的原因：純量 ξᵀf 做一次反向傳播，就得到所有層、所有節點 i 的 ξᵀJ_i（向量–Jacobian 乘積）。顯式建 Jacobian 需要 d_final 次反向傳播（§3.2 "Computational Complexity"）。
- 被估的是 (JᵀJ) 的對角元素 ∥J_i∥²，不是 trace；論文稱它為 "Hutchinson Trace Estimator" 是借名。〔顧問推導〕
- 估的是**平方**。R 個樣本平均後開根號，對 ∥J_i∥₂ 是偏低的有偏估計（Jensen）。〔顧問推導〕
- 單次樣本的變異數：Var[X²] = 2(∥a∥₂⁴ − Σ_k a_k⁴)〔顧問推導；用 E[X⁴] = 3∥a∥⁴ − 2Σa_k⁴〕。a 只有一個非零分量時變異數為 0。驗算：a = (3,4) → E[X²] = 25，Var = 576 = 2(625 − 337)。

### D4. Thm D.1：√(1/2)·∥J_i∥₂ ≤ E\|ξᵀJ_i\| ≤ ∥J_i∥₂

- 上界：√· 是凹函數，Jensen 給 E\|X\| = E√(X²) ≤ √E[X²] = ∥J_i∥₂（式 25）。
- 下界：Khintchine 不等式 p=1，常數 √(1/2)（式 26；論文引 Khintchine 1923、Haagerup 1981，不自己證）。
- 兩邊同乘 \|ΔW_ij\|·\|h_j\| 得式(23)/(27)。

〔顧問推導〕兩個界都能取到：a = (1,1) 時 E\|X\| = (2+0+0+2)/4 = 1 = ∥a∥/√2（下界取等）；a 只有一個非零分量時 E\|X\| = ∥a∥（上界取等）。a = (3,4)：E\|X\| = (7+1+1+7)/4 = 4，比值 0.8。分量很多且分散時，由中央極限定理比值趨近 √(2/π) ≈ 0.798。

要講對的點：
- "L1-norm surrogate" 的 L1 指的是**一階絕對動差 E\|ξᵀJ_i\|**，不是向量 1-範數 ∥J_i∥₁。附錄 D 中間那句 "Given that ∥J_i∥₂ ≤ ∥J_i∥₁" 與證明無關。
- 夾擠只保證常數倍等價。論文說可「不失去相對排序」；〔顧問推導〕兩個節點的 ∥J∥₂ 若相差不到 √2 倍，兩種估計量的排序可以相反，所以排序保持並未被證明。
- 動機是數值的：FP16/BF16 下平方小梯度會下溢成 0（附錄 D "Numerical Stability near Zero"）。〔顧問推導〕BF16 的指數範圍與 FP32 相同，下溢風險主要在 FP16；論文把兩者並列。

### D5. 遮罩、更新式與指標

- 式(7)：M_ij = 1 若 S̄_ij 落在該層最低的 ρ 比例，否則 0。M=1 表示**更新**。ρ=0.1 ⇒ 凍結 90%、更新最不重要的 10%。
- 式(8)：θ* = θ − λ·(M ⊙ ∂L/∂θ)。
- 式(9)：Avg = (A_up + A_down)/2；H = 2·A_up·A_down/(A_up + A_down)。A_up 是 6 個上游基準（TextVQA、OKVQA、OCRVQA、MMB、MMB(CN)、GQA）的算術平均。
- 驗算範例（Table 1，NVILA、COCO、Dowser）：A_up = (69.3+48.6+68.8+77.7+50.8+60.7)/6 = 62.65〔顧問推導，表中未列〕；A_down = 135.5；Avg = 99.1 ✓；H = 2·62.65·135.5/198.15 = 85.7 ✓。
- 我用程式重算了 Tables 1、2、6、7、12 的所有 Avg／H，除第 3 節列出的一處外全部吻合。

## 3. 常見誤讀、內部不一致、未明說之處

### 3.1 從摘要／圖看起來對、但論文沒有顯示的事

1. **「凍結少數關鍵參數」** — 相反。主實驗 ρ=0.1：凍結 90%，只更新分數最低的 10%（式 7、Fig.2 圖說）。
2. **「大部分效果來自重要性分數」** — 在主表使用的 ρ=0.1，隨機遮罩已拿到絕大部分效果。全層微調、ρ=0.1 的 H-score（Tables 8/9）：NVILA ImageNet-R 隨機 68.0±0.8 vs 本法 69.7；NVILA COCO 85.2±0.1 vs 85.7；LLaVA ImageNet-R 67.6±0.1 vs 68.5；LLaVA COCO 79.1±0.2 vs 79.3。附錄 H 自己也說低 ρ 時差距較小。分數的作用在 ρ 大時才明顯（NVILA ImageNet-R ρ=0.5：55.0±0.8 vs 62.7）。本法只有單次執行，沒有標準差。
3. **「不損失預訓練知識」**（貢獻第 2 點 "without loss of pretrained knowledge"）— Table 2 LLaVA ImageNet-R：OKVQA 58.0 → 48.4、GQA 62.0 → 56.5。Table 1 NVILA ImageNet-R：TextVQA 70.8 → 64.4。同一格 Grafting 的上游保留更好（57.7/55.8/65.7/64.6/58.8/61.4），只是下游 67.3 很差。Dowser 贏的是平衡（H-score），不是每一欄。
4. **「各方法下游表現相近，差別在上游」**（§4.2 原話）— 在 captioning 不成立。Table 1 NVILA COCO：Dowser 135.5 vs Full-FT 98.5；Flickr30k 96.0 vs 64.3。Table 2 LLaVA COCO：123.6 vs 100.0。只更新 10% 參數的下游分數反而大幅高於全微調，論文沒有解釋；H-score 的領先有一大部分來自這裡。
5. **「H-score 是兩個準確率的調和平均」** — captioning 的 A_down 是 CIDEr，可以超過 100（135.5），與 0–100 的準確率混在一起算。
6. **「Jacobian 項主要幫助保住上游」** — Table 12（LLaVA、COCO、20 層）ρ=0.1：去掉 ∥J_i∥₂ 後 A_up 58.4 → 有 J 59.1（+0.7），COCO CIDEr 116.0 → 123.6（+7.6）。H 的 +2.2 主要來自下游。而且去掉 J 的 Wanda 式分數（H 77.7）已高於 Table 2 的 SPIDER（75.2）與 Tailor（75.8）。
7. **「對 ρ 不敏感、不需調參」**（§4.2）— Table 8 全層微調 LLaVA ImageNet-R 的 A_up：ρ=0.1 為 55.8、0.25 為 48.2、0.5 為 27.9、0.9 為 10.2（Full-FT 9.4；zero-shot 為 61.0，見 Table 6）。「到 0.25 都穩定」是寬鬆的說法。
8. **「對學習率穩定」**（附錄 G）— Table 7 Dowser 的 ImageNet-R H-score：lr 1×10⁻⁴ 為 61.4、2×10⁻⁵ 為 69.7、5×10⁻⁶ 為 71.1。在 5×10⁻⁶ 時與 SPIDER 的差距縮小到 COCO 82.4 vs 81.5、ImageNet-R 71.1 vs 69.6；此時 Full-FT 的 ImageNet-R H 是 66.2，高於主表 lr 下的 SPIDER（62.8）。所有方法都在最小 lr 最好，主表 lr 對任何方法都不是最佳。Table 7 的 Grafting 只有 2×10⁻⁵ 一列，未說明原因。
9. **「data-free ＝ 與真實資料算出的分數相同」** — Table 5/10 最佳（R=8, N=64）Spearman 0.891±0.003、Hamming 0.050±0.002。〔顧問推導〕若兩個遮罩都剛好取 10%，Hamming 距離 = 2×0.1×(1−重疊率)，0.050 對應重疊率 75%，即選出的集合有四分之一不同。
10. **「text-only 探測與含影像探測幾乎相同」**（附錄 J "almost identical"）— Table 11（R=8, N=64）Hamming 0.081±0.001、Spearman 0.882±0.002，比「合成 vs 真實」的 0.050 還差。而且對照組的影像是用 ImageNet 通道均值／標準差取樣的高斯雜訊，不是真實影像。主實驗的探測完全不含影像。
11. **「R 越大越好」** — Table 10 中 N 的影響大於 R：N=64 時 R=2/4/8 的 Spearman 是 0.886/0.885/0.891。Table 11 中 R=8, N=4（0.844）還略低於 R=2, N=4（0.846）。
12. **「定理證明了凍結高分參數能防止遺忘」** — 定理只說給定 ΔW 時一階輸出位移多大。它沒說微調時 ΔW 會多大（式 3 用 \|W\| 代替），也沒把 ∥Δf∥ 連到上游準確率。

## 4. 哪些能在瀏覽器即時示範

### 可以（小型閉式或玩具計算）

1. **Thm 3.1 的一階近似與失效點**：2 層 MLP f = V·GELU(Wx)（D1 的玩具例，數字已驗算）。滑桿調 ΔW_ij，並排顯示真實 ∥Δf∥ 與預測 ∥J_i∥·\|ΔW\|·\|h_j\|。J_i = V[:,i]·GELU'(z_i) 是閉式。ΔW 小時兩線重合，ΔW = −W 時分開（1.118 vs 0.355）。
2. **為什麼只看權重大小不夠**：同一個例子把 z_i 推到很負（GELU' ≈ 0），大權重的分數趨近 0；或把 x_j 調成 0。可切換「只用 \|W\|」「\|W\|·\|h\|（Wanda 式）」「完整 S」三種排序看遮罩變化。這是示意，不是論文的實驗。
3. **式(4) Hutchinson 估計**：對小向量 a 抽 R 個 ±1 向量，畫 (ξᵀa)² 的平均隨 R 收斂到 ∥a∥²。d ≤ 10 時可列舉全部 2^d 個符號向量，顯示期望值精確相等。
4. **Thm D.1 的夾擠**：使用者拖動 a 的分量，列舉算 E\|ξᵀa\|/∥a∥₂，顯示它永遠在 [0.7071, 1]；a = (1,1) 觸底、單一非零分量觸頂。
5. **Cor 3.2 上界的鬆緊**：玩具網路同時擾動多個權重，比較真實 ∥Δf∥、一階 ∥ΣJ_i h_j ΔW_ij∥、三角不等式上界三個數。
6. **式(7)(8) 遮罩與稀疏更新**：小矩陣的 S 熱圖，滑桿調 ρ，顯示哪些格 M=1；做幾步遮罩梯度下降看凍結的格不動。
7. **式(9) H-score 計算器**：輸入 A_up、A_down 得 Avg 與 H。可重現 Table 1 的 99.1/85.7，也可示範 Avg 與 H 何時分歧（IconQA zero-shot：A_down = 0.1 時 Avg 31.2、H 0.2）。
8. **Hamming 距離的尺度**〔顧問推導〕：兩個密度 ρ 的遮罩，距離 = 2ρ(1−重疊率)，上限 2ρ。可讓讀者看到 0.050 對應多少重疊。需註明這是顧問推導，且論文的隨機基準 0.226 與此不符。

### 不行（只能以論文表格數字靜態呈現，並標明來源）

## 5. 初學者先備知識（教學順序）

1. MLLM 的組成：視覺編碼器＋連接模組＋語言解碼器；「只微調解碼器最後 L 層」是什麼意思（L 從輸出端往輸入端數，Fig.3 圖說）。
2. 上游／下游、zero-shot、災難性遺忘的定義（§1、§2.1）。
3. 評估指標：準確率／EM、CIDEr（可超過 100）、算術平均與調和平均的差別（式 9）。
4. 線性層 z = W h：pre-activation z 與 activation h 的區別；W_ij 連接輸入 j 到輸出 i。
5. 活化函數 GELU／SiLU；homogeneous 的意思（ReLU 滿足 φ(αz) = αφ(z)，α>0；GELU 不滿足），以及為什麼這讓「權重大小＝重要性」失效（§3.1 首段的動機）。
6. 偏導數、鏈鎖律、Jacobian 矩陣與它的「一行」J_i；反向傳播算的是向量–Jacobian 乘積。
7. 一階 Taylor 展開與它何時不準。
8. L2 範數、純量可提出範數、三角不等式。
9. 期望值、Rademacher 隨機變數、Monte Carlo 平均、無偏估計；Jensen 不等式（凹函數版）；Khintchine 不等式只需知道結論。
10. 剪枝式重要性分數的前身：純大小、Wanda（\|W\|·活化）；本法多乘一個輸出敏感度。
11. 二元遮罩、百分位、Hadamard 乘積、遮罩梯度下降（式 7、8）。
12. 讀實驗用：標準差、t 檢定與 p 值、Spearman 等級相關、Hamming 距離。
