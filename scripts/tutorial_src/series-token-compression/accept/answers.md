# Goldfish 驗收答題（僅依 page.txt）

**LO1**
- 答：一個 block 的 FLOPs 為 C(L)=24Ld²+4L²d（m=4）。d=768、L=1024 時，注意力二次項占 18.2%（公式 L/(6d+L)）。token 減半，block 成本約減半。
- 段落：「token 減半，block 成本約減半」
- 信心：high

**LO2**
- 答：每個方法都要在八個軸上選擇：A 縮減什麼、B 如何分組、C 在網路哪裡縮減、D 如何還原、E 如何訓練、F 預算由誰決定、G 合併後位置怎麼表示、H 擴散特有問題。
- 段落：「每個方法都必須在八個設計軸上做選擇」
- 信心：high

**LO3**
- 答：shorten（每 k 個相鄰 token 合成一個）→ 中段只在短序列上運算 → upsample 加殘差 → 全長層。兩端全長、只有中段變短。分組是固定步幅，每 k 個相鄰 token 一組，不看內容。
- 段落：「分組完全固定，與內容無關」
- 信心：high

**LO4**
- 答：ToMe 每層把 token 交替分成 A、B 兩集合，每個 A 連到最相似的 B（key 餘弦），保留最相似的 r 條邊，依大小加權平均合併。加 log s 是 proportional attention，本頁推導為「等於把該 key 複製 s 份」。分類不需還原，因為只用 CLS token 的輸出，被合併的 token 不必回原位。
- 段落：「分類只用 CLS token 的輸出」
- 信心：high（log s 的恆等式為頁面推導，組內差異大時不一定更接近原注意力）

**LO5**
- 答：ToMeSD 的 unmerge 直接複製，x'₁=x'₂=x*₁,₂（Eq. 1）。交替分割使 dst 形成規則欄位，等於沿列方向減半解析度，因此改為每個 2×2 隨機挑一個 dst。固定隨機性是為了讓 CFG 的條件與無條件分支以相同方式配置 dst，兩分支才一致。ToDo 只對 K、V 下採樣、保留全部 query，輸出仍全長，所以不需要 unmerge。
- 段落：「輸出仍是全長，所以不需要 unmerge」
- 信心：high

**LO6**
- 答：只縮中段（3＋11＋3）、不計文字時，加速上限為 17/6=2.83×。RTI B/16 在 R=256（κ=0.25）實測 2.15×，約在 2.5× 飽和。ToDo 式只縮 K/V 的注意力項；1024 token 時二次項只占 18%，在「K/V 投影仍全長」的假設下 κ=0.25 只有 1.16×（此為頁面推導，非論文數字）。
- 段落：「17/6=2.83×」、「只有 1.16×」
- 信心：high（2.83×、2.15×）；medium（1.16× 依賴頁面假設）

**LO7**
- 答：學得路由（MoD、DiffCR）屬於跳過（刪除）：未選中的 token 沿殘差流繞過 block，不被總結。RTI 在凍結 MiniT2I 上重實作的 Token Skip：GenEval 82.3，只有 1.19× 加速，比 RTI（2.15×）低 2.4 點。作者指出 Token Skip 的 576 個 token 不是同一預算、速度也慢得多，所以 2.4 點低估了差距。
- 段落：「GenEval 82.3，只有 1.19× 加速」
- 信心：high

**LO8**
- 答：JiT 用大 patch（16、32）控制 token 數；HDiT 用固定 2×2 Pixel-UnShuffle 合併的沙漏結構。兩者都與內容無關。H-Net 以相鄰向量的餘弦算邊界機率 pt=½(1−cos(qt,kt−1))，pt≥0.5 的位置為邊界。壓縮比由 ratio loss 控制（目標 N_H），只控制平均比例，個別序列的切塊數可多可少。
- 段落：「pt≥0.5 的位置就是邊界」
- 信心：high

**LO9**
- 答：Hilbert 上相鄰序號必為格點鄰居，所以切出的每段連續區間都連通。RTI 每張精確 R 個區域；HiT 的門檻法群組數由內容決定，只有批次平均受壓縮損失約束。相似度分組（Feat Sim）在 RTI 的代價：群組散布 5.16 格（RTI 為 0.49 格），GenEval 低 4.2 點（R=256）。
- 段落：「散布 5.16 格」
- 信心：high

**LO10**
- 答：廣播的最小誤差是目標在組內的變異 Σ_c Σ_{j∈c}‖y_j−ȳ_c‖²（頁面推導，組平均為最佳）。殘差寫回保留每個 patch 的核心前特徵，據此個別化更新（RTI Eq. 4）。只改還原的消融是 HiT 的硬查表：每個 token 只取自己群組的結果，FID 由 6.61 惡化為 7.97。RTI 的 −7.2 同時改了池化與還原，不能只歸因於還原。
- 段落：「由 6.61 惡化為 7.97」
- 信心：high

**LO11**
- 答：
  - RTI：目的為推論加速（凍結骨幹＋LoRA）；分組為無參數 Hilbert 連續區域；預算為每張精確 R 個（彈性）；位置為區域內平均 RoPE 相量。
  - HiT：目的為品質與訓練效率（從頭訓練）；分組為學得親和度＋平均連結，可非局部；預算為批次平均、單張可變；位置為 compact 層預設不加 RoPE。
- 段落：「推論加速（凍結骨幹＋LoRA）」、「品質與訓練效率」
- 信心：high

**LO12**
- 答：RTI 的對照是凍結骨幹上免學習的相似度分組，骨幹依賴 RoPE；HiT 的對照是形狀固定的空間配對（本身連續），且 HiT 的軟池化讓每個 token 都貢獻給每個群。兩篇都沒有在同一設定下比較「內容自適應且連續」與「學得且非局部」兩種分組。
- 段落：「不能直接比較」
- 信心：high

## 初學者可能卡住的地方

1. **八個軸與 A–H、S 節號的跳讀**：軸與符號分散在 S03、S05、S10 等節，讀者需要頻繁回頭對照。
2. **softmax、餘弦、key/query 未在先備中定義**：ToMe 的配對、log s 的恆等式與 H-Net 的 pt 公式都依賴這些詞，先備只定義了 RoPE 與 LoRA。
3. **Amdahl 定律與 17/6 的計算**：頁面只點名「Amdahl 定律」，沒有說明 17 個 block 與 6 個全長 block 如何得到 17/6。
4. **Hilbert 曲線與「連通」**：只有一張 8×8 圖與一句「相鄰序號必為鄰居」，初學者不一定能推出為何每段都連通；平均連結與 dendrogram 也只給名詞。
5. **「軟混合」、「投影 skip」、「ratio loss」**：第 6 期與還原節中出現，但沒有在頁內定義，只能靠名稱猜測。
