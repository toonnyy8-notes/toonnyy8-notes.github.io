 Transformer 的 token 縮減與解析度還原

 從 ViT 的 token 合併到像素擴散的 RTI 與 HiT，七期研究在八個設計軸上的選擇。

 起點論文：〈Elastic Token Compression for Pixel-Space Diffusion Transformers〉（RTI，2026）與〈Hierarchical Diffusion Transformer for End-to-End Image Generation〉（HiT，2026）

 第 0 期2020–21第 1 期2021–22第 2 期2023–24第 3 期2022–25第 4 期2023–25第 5 期2023–25第 6 期2026

 01 · 成本Transformer 每層的計算量大約與 token 數成正比；擴散模型每一步、每一層都對每個 patch 付相同的計算。

 02 · 取捨七期研究的差別在於：哪些 token 合成一組、在網路哪裡合、合完之後怎麼回到每個 patch。

 03 · 兩個端點RTI 把相鄰且相似的 patch 合成連續區域，用來加速現成模型；HiT 讓模型自己學分組、允許相隔很遠的 patch 同組，從頭訓練以提升品質。

 01 · 先備

 先備：擴散 Transformer 與評估指標

 本頁假設讀者知道 Transformer 的注意力（attention）：一張影像先切成固定大小的方塊（patch），每個 patch 變成一個向量，稱為 token；每一層讓所有 token 兩兩計算注意力，再各自通過一個 MLP。以下只定義後文會用到的詞。

 擴散模型與 DiT。擴散模型從純噪聲出發，反覆用一個網路把噪聲一步步去除，得到影像。以 Transformer 作為這個去噪網路的模型稱為 DiT（Diffusion Transformer）。本頁採用 RTI 與 JiT 的時間方向：取樣狀態寫成 xt=t x+(1−t) ε $x_t=t\,x+(1-t)\,\varepsilon$ ​=tx+(1−t)ε，其中 x $x$ 是乾淨影像、ε $\varepsilon$ 是標準高斯噪聲；t=1 $t=1$ 時是乾淨影像，t=0 $t=0$ 時是純噪聲。生成時從 t=0 $t=0$ 走到 t=1 $t=1$ ，每一個取樣步（sampling step）都要把整個網路跑一次。

 x-prediction。網路直接輸出它對乾淨影像 x $x$ 的預測，稱為 x-prediction。JiT 與 RTI 所改造的 MiniT2I 都屬於這一類。因為要對每個 patch 都輸出一個預測，擴散模型的輸出是稠密的。

 注意力的三個詞。每個 token 經三個線性投影得到 query、key、value：query 是「要找什麼」，key 是「我有什麼」，value 是「被取走的內容」；一個 token 的輸出是所有 value 的加權平均，權重由它的 query 與各 key 的內積決定。softmax 把一組數 zi $z_i$ ​ 轉成總和為 1 的正權重 ezi/∑kezk $e^{z_i}/\sum_k e^{z_k}$ ​/∑k​ezk​。兩個向量的餘弦相似度是它們夾角的餘弦 a⊤b/(∥a∥∥b∥) $a^\top b/(\lVert a\rVert\lVert b\rVert)$ b/(∥a∥∥b∥)，介於 −1 與 1，越接近 1 表示方向越像。

 CFG。Classifier-free guidance：每一步分別跑一次有條件（例如給文字）與無條件的預測，再把兩者的差放大後相加。所以一步其實要跑兩個分支。

 latent 與 pixel-space。latent 擴散先用一個另外訓練的 VAE 把影像壓成較小的格點，再在那個空間生成；pixel-space（像素空間）擴散直接在像素上生成，不需要 VAE。

 評估指標。FID 衡量生成影像與真實影像的分布距離，越低越好；GenEval 衡量文字到影像模型是否畫對物件、數量、顏色與位置，是正確率，越高越好。牆鐘時間（wall-clock time）是實際花費的秒數，FLOPs 是浮點運算次數；兩者不一定成正比。

 LoRA 與 RoPE。LoRA 凍結原本的權重，只訓練一個低秩的增量。RoPE（rotary position embedding）以一組不同頻率的旋轉相量 eiωp $e^{i\omega p}$ 表示位置 p $p$ ，注意力只看兩個 token 的相位差。

 02 · 成本

 token 數決定 Transformer 的成本

 考慮一個標準 Transformer block，序列長度（token 數）為 L $L$ 、模型寬度為 d $d$ 、MLP 的隱藏寬度為 m⋅d $m\cdot d$ （擴張比 m $m$ ）。把一次乘加計為 2 次運算，前向 FLOPs 由三部分組成：QKV 與輸出投影 8Ld2 $8Ld^2$ ；MLP 4mLd2 $4mLd^2$ ；注意力分數 QK⊤ $QK^\top$ 與加權 AV $AV$ 共 4L2d $4L^2d$ d。

本頁推導

 一個 block 的 FLOPs 在 m=4 $m=4$ 時是 C(L)=24Ld2+4L2d $C(L)=24Ld^2+4L^2d$ +4L2d。其中注意力的二次項占總成本的比例是 4L2d/(24Ld2+4L2d)=L/(6d+L) $4L^2d/(24Ld^2+4L^2d)=L/(6d+L)$ d/(24Ld2+4L2d)=L/(6d+L)；取 d=768 $d=768$ 、L=1024 $L=1024$ ，二次項只占 18.2%（L=256 $L=256$ 為 5.3%，L=4096 $L=4096$ 為 47.1%，L=16384 $L=16384$ 為 78.1%）。所以在 DiT 常見的 256–1024 個 token 下，成本大約與 token 數成正比：token 減半，block 成本約減半；注意力的二次項要到數千個 token 以上才成為主項。本頁推導這也與 ToMeSD、ToDo 在大圖上加速最多一致（ToDo 摘要：一般尺寸至多 2×，2048×2048 至多 4.5× 以上僅摘要）；ToMeSD 作者對小圖加速較少的解釋是「擴散模型不是瓶頸」（ToMeSD Sec. 5）。

 第二點：牆鐘時間可能比 FLOPs 下降得更快。RTI App. A（Fig. 10）在 RTX 4090、batch 4 下量測，每個預算的實際時間都低於解析 FLOPs 曲線，作者歸因於這些長度下的注意力受記憶體頻寬限制。

 pixel-space 模型的 token 特別多。JiT（Li 與 He，2025）以 patch 16 處理 256² 影像，得到 16×16 = 256 個 token；RTI 改造的文字到影像模型 MiniT2I-B/16 在 512²、patch 16 下有 32×32 = 1024 個 token（RTI Sec. 3.1）。RTI 的說法是：latent 模型在 VAE 中「一次付清」低階空間冗餘，pixel-space 模型則在每個 block 都付一次（RTI Sec. 1）。HiT 的出發點不同：一個 patch 一個 token 貫穿整個骨幹，不鼓勵模型在較粗的層級上總結內容，所以 HiT 把分組當作提升品質與訓練效率的手段，而不只是加速（HiT Sec. 1）。

 本節重點：一個 block 的 FLOPs 是 C(L)=24Ld2+4L2d $C(L)=24Ld^2+4L^2d$ +4L2d（m=4 $m=4$ ）；d=768 $d=768$ 、L=1024 $L=1024$ 時注意力二次項比例 L/(6d+L)=18.2% $L/(6d+L)=18.2\%$ ；在 256–1024 個 token 下成本約與 token 數成正比，token 減半成本約減半；二次項要到數千個 token 以上才成為主項。

 03 · 設計軸

 每個方法都在八個設計軸上做選擇

 要減少 token，每個方法都必須在八個設計軸上做選擇：縮減什麼（A）、如何分組（B）、在網路哪裡縮減（C）、如何還原成每個 patch 一個輸出（D）、如何訓練（E）、預算由誰決定（F）、合併後的位置怎麼表示（G），以及擴散特有的問題（H）。後文以 A–H 代號引用這些軸；各軸裡的術語在第一次用到的章節才定義。

 04 · 第 0 期（2020–2021）

 第 0 期：沙漏結構讓中段在短序列上運算

 第 0 期2020–21第 1 期2021–22第 2 期2023–24第 3 期2022–25第 4 期2023–25第 5 期2023–25第 6 期2026

 最早的問題來自語言模型：長序列讓 Transformer 太貴，但語言建模需要每個 token 都有輸出，所以縮短之後還得還原。Funnel-Transformer（2020）逐步把隱藏序列壓短，把省下的 FLOPs 用來加深或加寬模型；需要逐 token 輸出時，再以解碼器從短序列還原僅摘要。

 Hourglass（Nawrot 等人，2021）的結構是：shorten（以縮短係數 k $k$ 把相鄰 token 合成一個）→ 中段 Transformer 只在短序列上運算 → upsample 並加上殘差 → 全長的 Transformer 層，所以兩端保持全長、只有中段變短。在自回歸設定下，縮短前要先把序列右移 k−1 $k-1$ 個 token，避免偷看未來（Sec. 2）。它的分組是固定步幅，與內容無關：每 k $k$ 個相鄰 token 一組，不看那些 token 是什麼。

 Hourglass 也比較了三種上採樣（Sec. 2.3）：直接重複（無法區分組內位置）、線性上採樣（每個組內位置一個投影）、以及注意力上採樣 x=U(x,x′)+Attention(Q=U(x,x′),K=V=x′) $x=U(x,x')+\mathrm{Attention}(Q=U(x,x'),K=V=x')$ )+Attention(Q=U(x,x′),K=V=x′)，其中 U(x,x′)=x+LinearUpsampling(x′) $U(x,x')=x+\mathrm{LinearUpsampling}(x')$ )=x+LinearUpsampling(x′)。這個結構在 ImageNet32 影像生成達到 3.741 bits/dim（Sec. 3.4）。

 同期的 Perceiver IO（2021）走另一條路：以固定數量的 latent 向量經 cross-attention 讀入任意長度的輸入，在 latent 上運算，再以輸出查詢讀出，成本對輸入輸出長度呈線性僅摘要。它不做空間分組；RTI 在凍結骨幹上重實作的 Latent Array 基線同時失去了分組、連續與位置（RTI Sec. 4.2）。

 這一期證明「中段在短序列上運算、兩端保持全長」可行。限制是分組完全固定，與內容無關。

 05 · 第 1 期（2021–2022）

 第 1 期：ViT 分類以剪枝與合併減少 token

 第 0 期2020–21第 1 期2021–22第 2 期2023–24第 3 期2022–25第 4 期2023–25第 5 期2023–25第 6 期2026

 Vision Transformer（ViT）對每個 patch 等量計算，背景 patch 也一樣。DynamicViT（2021）用一個預測模組估計每個 token 的重要性並剪掉不重要的 token；剪去 66% 的 token 時 FLOPs 降低 31%–37%，精度下降 0.5% 以內僅摘要。剪枝的缺點是被剪掉的資訊就消失了。

 ToMe（Token Merging，Bolya 等人，2022）改成合併。它在每個 block 中執行二部軟配對（bipartite soft matching）：ToMe 每層把 token 交替分成 A、B 兩個集合（程式碼中 A 取偶數索引、B 取奇數索引），每個 A 連一條邊到 B 中最相似的 token（以 key 的餘弦相似度衡量），保留最相似的 r $r$ 條邊，把相連的 token 依大小加權平均合併，最後把兩個集合串回去（Sec. 3）。所以每層減少 r $r$ 個 token，而且全部可以平行計算，不需要迭代的分群演算法。

 合併後，一個 token 可能代表好幾個原始 patch；記它代表的 patch 數為 s $s$ （token 大小）。若不處理，兩個相同的 key 合成一個後，在 softmax 中的權重就變小了。ToMe 的 proportional attention（Eq. 1）在注意力 logit 上加 log⁡s $\log s$ ：

 A=softmax ⁣(QK⊤d+log⁡s) $A=\mathrm{softmax}\!\Big(\frac{QK^\top}{\sqrt d}+\log s\Big)$ ​QK⊤​+logs)
ToMe Eq. 1

 本頁推導因為 e q⋅k/d+log⁡s=s e q⋅k/d $e^{\,q\cdot k/\sqrt d+\log s}=s\,e^{\,q\cdot k/\sqrt d}$ ​+logs=seq⋅k/d​，加 log⁡s $\log s$ 等於把該 key（以及它的 value）複製 s $s$ 份。下一節的 C1 會數值驗證這個恆等式。

 ToMe 能直接用在現成模型、不需要訓練：ViT-L@512 與 ViT-H@518 吞吐量提高 2×，精度下降 0.2–0.3%僅摘要。它在分類中不需要還原：分類只用 CLS token 的輸出，被合併的 token 不必回到原本的位置。這也是它的限制：把同樣的做法搬到需要每個 patch 都有輸出的擴散模型時，沒有還原機制；而且它只依外觀分組，不顧空間位置。

 本節重點：ToMe 每層把 token 交替分成 A、B 兩個集合，每個 A 連到最相似的 B（key 的餘弦相似度），保留最相似的 r $r$ 條邊，依大小加權平均合併；proportional attention 加 log⁡s $\log s$ ，等於把該 key 複製 s $s$ 份；分類只用 CLS token 的輸出，被合併的 token 不必回到原位置，所以不需要還原。

 06 · 第 2 期（2023–2024）

 第 2 期：擴散的稠密輸出需要把合併還原

 第 0 期2020–21第 1 期2021–22第 2 期2023–24第 3 期2022–25第 4 期2023–25第 5 期2023–25第 6 期2026

 擴散模型要對每個 token 預測，CFG 每步要跑兩個分支，而且同一張圖在幾十個取樣步中重複計算。以下把被併入別人的 token 稱為 src，接收的 token 稱為 dst；把合併結果送回原本每個位置的動作稱為 unmerge。

 ToMeSD（Bolya 與 Hoffman，2023）在每個元件（self-attention、cross-attention、MLP）之前合併、之後 unmerge。它的 unmerge 是直接複製：若 x1,2∗=(x1+x2)/2 $x^*_{1,2}=(x_1+x_2)/2$ ∗​=(x1​+x2​)/2，則 x1′=x2′=x1,2∗ $x'_1=x'_2=x^*_{1,2}$ ′​=x2′​=x1,2∗​（Sec. 3.1，Eq. 1）。ToMeSD 的 unmerge 把合併結果複製回所有來源位置，同一組的 token 因此完全相同。它也改以比例 r% $r\%$ 取代固定個數。

 分割方式（Sec. 4.1）：ToMe 的交替分割使 dst 形成規則的欄位，等於沿列方向把解析度減半。ToMeSD 因此改用隨機 2×2 dst——每個 2×2 區域隨機挑一個 dst——並且在整個 batch 固定隨機性，讓 CFG 的條件與無條件分支以相同方式配置 dst，兩個分支才一致。設計實驗顯示只對 self-attention 合併最划算（Tab. 3）。ToMeSD 在 SD v1.5、512² 上的結果（Tab. 4）：基線 FID 33.12、每張 3.09 秒；r=50% $r=50\%$ 時 FID 33.02、每張 1.65 s/im；r=60% $r=60\%$ 時 FID 33.37、1.52 s/im。

 ToDo（2024）換一個假設：空間相鄰的 token 本來就相似，所以用最近鄰下採樣 D(⋅) $D(\cdot)$ 取代相似度配對，成本 O(n) $O(n)$ （Sec. 2.2）。更重要的是它只對 key、value 下採樣，保留全部 query：

 Attention(Q,K,V)=softmax ⁣(Q D(K)⊤dk)D(V) $\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\!\Big(\frac{Q\,D(K)^\top}{\sqrt{d_k}}\Big)D(V)$ ​​QD(K)⊤​)D(V)

 免訓練方法的比例要手調，而且與層、時間步無關。這一期的代表做法是讓模型學「哪些 token 要算」。Mixture-of-Depths（MoD，2024，語言模型）在每層放一個 router，選出 top-k $k$ 個 token 進入注意力與 MLP，其餘 token 沿殘差流直接跳過這一層。DiffCR（2024）把同樣的想法用在 DiT：每層一個 router 預測 token 重要性，並讓每層、每個時間步的壓縮比例也可微地學出來；在 PixArt-Σ 上品質與未壓縮模型相當，同時省下 20.68% 延遲與 8.33% 記憶體（Sec. 4）。

 學得路由（MoD、DiffCR）屬於跳過，也就是刪除：未被選中的 token 沿殘差流繞過 block，不被總結，它們的資訊不參與這一層的計算。RTI 在凍結的 MiniT2I 上重實作了這類方法（Token Skip）：GenEval 82.3，只有 1.19× 加速，比 RTI（2.15×）低 2.4 點；作者指出 Token Skip 的 576 個 token 不是同一種預算，而它的速度又慢得多，所以 2.4 點低估了差距（Tab. 1、Sec. 4.2）。

 其他同類方法只列出：DyDiT 依時間步調整寬度並跳過不必要的空間位置，DiT-XL FLOPs 降低 51%、加速 1.73×；FlexiDiT 把預訓練 DiT 轉為多預算模型；Sparse Guidance 以 token 稀疏度作為引導訊號僅摘要。架構層級的 RIN 以一組 latent 承擔全域注意力，U-ViT 以長 skip 連接淺層與深層僅摘要。它們在 S14 的對照表中各占一列。

 比較分組規則需要量測。記 patch j $j$ 所屬的組為 c(j) $c(j)$ ，組內特徵平均為 hˉc(j) $\bar h_{c(j)}$ c(j)​，全部 patch 的平均為 hˉ $\bar h$ 。RTI 用保留變異 EV（App. C.1，Eq. 5）衡量「用組平均代表每個 patch」後還剩多少資訊：

 EV = 1 表示組平均完整攜帶原本的特徵，EV = 0 表示不比一個常數好。另外兩個量測看位置：spread 是每個 patch 到其組中心的平均距離（單位為格；本頁對全部 patch 平均，RTI Tab. 4 對每組平均）；連通組比例是在格子上相連成一塊的組所占的比例。

 分組規則也決定預算型態（軸 F）。RTI 每張精確 R $R$ 個區域；固定網格與 ToMe 式合併也是每張固定個數。門檻法則不同：HiT 的群組數由門檻與內容決定，只有整個批次的平均保留比例受壓縮損失約束（Eq. 4，目標 ρ=1/r $\rho=1/r$ ），門檻 τ $\tau$ 在訓練前以 1,024 個雜訊樣本校準後凍結（Sec. 4.1）。所以 HiT 單張影像、單個時間步的群組數可以多於或少於目標。

 RTI 量到相似度分組的代價：以 ToMe 式相似度分組（Feat Sim）在同一介面中取代 Hilbert 區域，Feat Sim 的群組散布 5.16 格，RTI 只有 0.49 格（Tab. 4，R=256 $R=256$ ），GenEval 低 4.2 點（Sec. 4.2）。RTI 的結論是失去連續性就失去位置。

 冗餘也隨時間步改變：RTI 的探測顯示取樣進行時（影像逐漸成形）保留比例上升（Fig. 2b），DiffCR 學到的壓縮比在雜訊大的時間步較高。下方的玩具只用乾淨影像，不模擬時間步。

 12 · 還原

 還原方式決定同一組內能否各自更新

 縮短的核心只為每一組產生一個結果，但擴散模型要對每個 patch 輸出（軸 D）。進入縮短段之前每個 patch 的特徵稱為核心前特徵，記為 hj $h_j$ ​。前面各期出現過五種還原：不需要（分類）、複製回來源（ToMeSD 的 unmerge，也稱廣播，broadcast）、殘差寫回、skip connection（U-ViT、HDiT 的 lerp、HiT 的投影 skip），以及 Hourglass 的注意力上採樣。

 本頁推導廣播只能讓同組共用一個更新：同一組的 patch 拿到同一個值。若第 j $j$ 個 patch 的理想輸出是 yj $y_j$ ​，同組共用一個值時，最好的選擇是組平均 yˉc $\bar y_{c}$ ​c​，最小誤差就是目標在組內的變異 ∑c∑j∈c∥yj−yˉc∥2 $\sum_c\sum_{j\in c}\lVert y_j-\bar y_c\rVert^2$ ​∑j∈c​∥yj​−yˉ​c​∥2。殘差寫回則保留每個 patch 的核心前特徵，並據此個別化更新。RTI 的 WRITE（Eq. 4）是

 hjout=hjin+g([ hjin ∥ zc(j)′−zc(j) ]) $h_j^{\text{out}}=h_j^{\text{in}}+g\big([\,h_j^{\text{in}}\,\Vert\,z'_{c(j)}-z_{c(j)}\,]\big)$ out​=hjin​+g([hjin​∥zc(j)′​−zc(j)​])
RTI Eq. 4

 其中 hin $h^{\text{in}}$ 、hout $h^{\text{out}}$ 是核心前、後的特徵（論文以層索引 s0 $s_0$ ​、s1+1 $s_1+1$ ​+1 表示），zc $z_c$ ​、zc′ $z'_c$ ′​ 是區域 token 進、出核心時的值，g $g$ 是小型可學映射：每個 patch 以自己的特徵與區域的變化量產生自己的更新。HiT 則以同一組軟權重把核心處理後的群組特徵混回每個 token（軟混合：每個 token 得到所有群組結果的加權平均，權重是它對各群組的軟指派），再加上一個投影 skip（把核心前的特徵乘上一個可學的線性投影後直接加回，HiT 初始化為恆等）。

 哪個消融只改還原？HiT 只改讀回方式的消融：把軟混合換成硬查表（每個 token 只取自己所屬群組的結果），FID 由 6.61 惡化為 7.97（Tab. 3）。RTI 以平均池化＋廣播取代整個 READ/WRITE，GenEval 低 7.2（Sec. 4.3），但這同時改變了池化與還原，不能只歸因於還原。

 13 · RTI 與 HiT

 RTI 與 HiT 在八個設計軸上的選擇對照

 RTI 的目的是推論加速：凍結骨幹＋LoRA 加速，只訓練 rank-32 的 LoRA 與 READ/WRITE（B/16 可訓練參數 16.3M，5.9%）；分組是無參數的 Hilbert 連續區域；預算是每張精確 R $R$ 個，訓練時每步自 {64, 128, 256, 512} 隨機抽 R $R$ ，所以一個 checkpoint 支援任意預算（彈性），連未見過的預算也能用；位置以區域內 patch 的平均 RoPE 相量表示。結果（Tab. 1，512²）：B/16 稠密 GenEval 87.2，RTI R=512 $R=512$ 為 87.8（1.84×）、R=256 $R=256$ 為 84.7（2.15×）；L/16 在 R=256 $R=256$ 為 86.3（2.59×）。

 HiT 的目的是品質與訓練效率：從頭訓練求品質；分組用學得親和度＋平均連結、可非局部；預算是批次平均、單張可變；compact 層預設不加 RoPE。結果：ImageNet-256 上 HiT-XL/16 在 600 epochs 達到 FID 1.48（Tab. 1），FID ≈ 2.16 時訓練計算比 JiT-H/16 少 2.4×（Fig. 1d）；文字到影像 512² 五項平均 65.93，MiniT2I-B/16 為 64.64，名目 GFLOPs 139.4 對 201.6（乘加計 1、以目標群組數計，Tab. 2、Sec. 4.1）。學得分組優於固定空間配對（FID 6.61 對 7.11，Tab. 7）。

 開放問題與延伸閱讀

 分組必須空間連續嗎？

 −4.2RTI：相似度分組（Feat Sim）比 Hilbert 區域低的 GenEval 點數，散布 5.16 格對 0.49 格

 6.61 / 7.11HiT：學得分組對固定空間配對的 FID

 這兩個結果看起來指向不同方向，但不能直接比較。RTI 的對照是凍結骨幹上的免學習相似度分組，骨幹依賴 RoPE；HiT 的對照是形狀固定的空間配對（第一階段水平、第二階段垂直，本身連續），而且 HiT 的軟池化讓每個 token 都能貢獻給每個群。兩篇都沒有在同一設定下比較「內容自適應且連續」與「學得且非局部」兩種分組。

 精確預算與內容自適應預算的結合：RTI 的 R $R$ 由使用者決定；H-Net、DC-DiT、HiT 只控制平均。

 文字流壓縮：RTI 的加速上限部分來自文字流全長。

 合併 token 的位置表示仍無定論：HiT 各位置變體的差距小。

 與步數縮減的關係：RTI App. B.3（Fig. 7，MiniT2I-L/16、R=256 $R=256$ ）中，每張影像低於約 3 秒時 token 壓縮優於減少步數（1.8 秒：少步稠密 GenEval 65.9、RTI 82.7），高於約 5 秒時相反（11.2 秒：稠密 87.6、RTI 86.3）。

 HiT 的平均連結在 N $N$ 增大時的實際成本未報告；它的 GFLOPs 是以目標群組數計的名目值，實際成本隨每張影像與時間步的群組數改變（HiT Sec. 4.1）。
