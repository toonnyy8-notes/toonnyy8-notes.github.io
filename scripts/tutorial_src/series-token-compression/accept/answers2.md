# 作答（僅依 page.txt）

## LO1

**問題**：一個 block 的 FLOPs 怎麼寫？$d=768$、$L=1024$ 時注意力二次項占多少？token 減半時成本約如何變化？

**答案**：
- 序列長度（token 數）為 $L$、模型寬度為 $d$、MLP 擴張比為 $m$。一次乘加計為 2 次運算，前向 FLOPs 由三部分組成：QKV 與輸出投影 $8Ld^2$、MLP $4mLd^2$、注意力分數與加權 $4L^2d$。
- 合併為 $C(L)=(8+4m)\,L\,d^2+4L^2d$；$m=4$ 時為 $C(L)=24Ld^2+4L^2d$。
- 注意力二次項占比為 $4L^2d/(24Ld^2+4L^2d)=L/(6d+L)$。取 $d=768$、$L=1024$，二次項只占 18.2%（線性項占 81.8%）。對照：$L=256$ 為 5.3%，$L=4096$ 為 47.1%，$L=16384$ 為 78.1%。
- 在 DiT 常見的 256–1024 個 token 下，成本大約與 token 數成正比：token 減半，block 成本約減半；注意力二次項要到數千個 token 以上才成為主項。
- 補充（頁面所述）：RTI App. A（Fig. 10）在 RTX 4090、batch 4 下量測，實際牆鐘時間都低於解析 FLOPs 曲線，作者歸因於這些長度下注意力受記憶體頻寬限制，即牆鐘時間可能比 FLOPs 下降得更快。

**依據段落**：「token 減半，block 成本約減半」

**信心**：高

## LO5

**問題**：ToMeSD 如何還原？為什麼改用隨機 2×2 dst，且要固定隨機性？ToDo 為何不需要 unmerge？

**答案**：
- ToMeSD 的還原（unmerge）是直接複製：若合併結果為 $x^*_{1,2}=(x_1+x_2)/2$，則還原後 $x'_1=x'_2=x^*_{1,2}$（Sec. 3.1，Eq. 1）。也就是把合併結果複製回所有來源位置，同一組的 token 完全相同。
- 改用隨機 2×2 dst 的原因：ToMe 的交替分割使 dst 形成規則的欄位，等於沿列方向把解析度減半。ToMeSD 因此改為每個 2×2 區域隨機挑一個 dst（Sec. 4.1）。
- 固定隨機性的原因：在整個 batch 固定隨機性，讓 CFG 的條件與無條件兩個分支以相同方式配置 dst，兩個分支才一致。
- 設計實驗顯示只對 self-attention 合併最划算（Tab. 3）。
- 結果（SD v1.5、512²，Tab. 4）：基線 FID 33.12、每張 3.09 秒；$r=50\%$ 時 FID 33.02、1.65 s/im；$r=60\%$ 時 FID 33.37、1.52 s/im。ToMeSD 也改以比例 $r\%$ 取代固定個數。

**ToDo 不需要 unmerge**：ToDo 只對 K、V 下採樣，保留全部 query，公式為 $\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\!\Big(\frac{Q\,D(K)^\top}{\sqrt{d_k}}\Big)D(V)$（Sec. 2.2）。每個 query 仍各自得到一個輸出，輸出仍是全長，所以不需要 unmerge。ToDo 的 $D(\cdot)$ 為最近鄰下採樣，成本 $O(n)$；合併比例 0.75、0.89 指被移除的比例，等於 2×、3× 下採樣（Sec. 3）。

**依據段落**：「ToDo 只對 K、V 下採樣、保留全部 query」

**信心**：高

## 判定（對照 design.md 學習目標表的參考答案）

- **LO1：correct。** 參考答案的 $C(L)=24Ld^2+4L^2d$（$m=4$）、二次項比例 $L/(6d+L)=18.2\%$、256–1024 token 下近似正比、減半約減半、數千 token 才成主項，本作答全部包含。
- **LO5：correct。** 參考答案的 unmerge 複製回所有來源位置、交替分割改為每 2×2 隨機一個 dst 並固定隨機性使 CFG 兩分支一致、ToDo 只下採樣 K/V 且輸出全長、ToMeSD $r=50\%$ FID 33.02（基線 33.12）與 1.65 對 3.09 s/im，本作答全部包含。
