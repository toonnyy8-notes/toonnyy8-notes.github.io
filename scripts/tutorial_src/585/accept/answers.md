# 585 HiT 驗收作答（Goldfish，僅依 page.txt）

**LO1** 作者認為像素空間 Transformer 落後潛空間模型的部分原因，是骨幹「從頭到尾每個 patch 保留一個 token」，沒有鼓勵形成「把相關內容在逐漸變粗的層級彙整」的視覺階層。規則 patch 網格也讓每個等大區域得到相同數量的 token，不管內容多寡。
- 段落：「從頭到尾每個 patch 保留一個 token」
- 信心：high

**LO2** ImageNet 256 的 HiT-B/16（18 區塊）token 數為 256→128→64→128→256。layout 3/3/6/3/3 的五個數字依序是：全解析度編碼器區塊數 3、中間編碼器 3、精簡核心 6、中間解碼器 3、全解析度解碼器 3。這組數字只適用 ImageNet 256。
- 段落：「3/3/6/3/3 的五個數字依序是」
- 信心：high

**LO3** 先對 token 特徵做兩個學到的投影並正規化為單位向量 q、k，然後 S_ij = ½(q_i·k_j + q_j·k_i)，取平均使矩陣對稱。群組間親和度 s(U,V) 是所有成員配對 S_ij 的平均。平均連結法每次合併 s 最高的兩群，只保留分數 ≥ τ 的合併。範例：角度 10°、22°、150° 時 S12=0.9781、S13=−0.7660、S23=−0.6157；第二次合併分數為 (−0.7660−0.6157)/2 = −0.6909。τ=0.8 時只保留 {1,2} 與 {3}。
- 段落：「S12=0.9781」「We retain merges with affinity at least τ」
- 信心：high

**LO4** 親和度只由特徵投影 q、k 計算，不含位置，所以分組是在雙向影像特徵上做的。不像 H-Net 沿序列切相鄰區塊，HiT 的不相連 patch 可以同組。例：Fig. 1 兩根香蕉的 patch 同組；Fig. 4c 分開的車身標記也同組。玩具例子中 token 1 與 2 隔著 token 3，仍可同組。
- 段落：「親和度只由特徵投影 q,k 計算，不含位置」
- 信心：high

**LO5** 硬群組 G_g 算出 e_ig = (1/|G_g|) Σ_{j∈G_g} S_ij，再 A_ig = softmax_g(e_ig / T_r)，T_r = 0.05。池化矩陣 P_ig = A_ig / Σ_j A_jg，群組 token z_g = Σ_i P_ig h_i。也就是說，群組 token 是「所有輸入 token」的加權平均，不只是硬群組成員的平均。硬群組只決定有哪些群組與 e_ig；每個 token 都依 A 對每個群組有貢獻。
- 段落：「群組 token 是所有輸入 token 的加權平均」
- 信心：high

**LO6** 解組重用分組前的同一組軟權重 A：r_i = Σ_g A_ig z̃_g，再加上跳接 H·W^T（W 初始為單位矩陣）。整段是 H̃ = A·M(Z) + H·W^T，其中 Z = P^T H。反向傳播時硬分割視為常數，梯度經由軟池化與解組的權重 A 傳回產生 q、k 的投影。
- 段落：「梯度經由軟池化與解組權重 A 傳到產生 q,k 的投影」
- 信心：high

**LO7** Table 3（HiT-B/16，80 epoch，FID 越低越好）：
- 只在硬群組內池化、均勻軟混合解組：FID 10.32
- 只在硬群組內池化、學到的軟混合解組：FID 10.16
- 所有 token 池化、硬查表解組：FID 7.97
- 預設（所有 token 池化、軟解組）：FID 6.61

信心：high

**LO8** Eq. 4：L_comp = 1 + (f_h − ρ)(f_s − ρ) / (ρ(1−ρ))。f_h 是實際保留比例（計數，視為常數）；f_s 是可微估計。當 f_h > ρ（群組太多）時，∂L/∂f_s = (f_h−ρ)/(ρ(1−ρ)) > 0，梯度下降會降低 f_s，也就是使合併分數上升、產生更多合併。f_h < ρ 時方向相反；f_h = ρ 時損失恆為 1、梯度為 0。
- 段落：「梯度下降降低 fs，也就是使合併分數上升、產生更多合併」
- 信心：high

**LO9** f_h = Σ_b K_b / Σ_b N_b，f_s = Σ_b K̃_b / Σ_b N_b，其中 K̃_b = N_b − Σ_m sig((s_{b,m} − τ)/T_b)，T_b = 0.1，分子分母跨批次與裝置加總。損失只約束批次平均保留比例，所以每張影像的群組數可以不同，且隨內容與擴散時間改變。門檻 τ 在訓練前用 1,024 個固定帶噪樣本校準，之後固定。
- 段落：「損失只約束平均比例，所以每張影像的群組數可以不同」
- 信心：high

**LO10** 2×4 與 4×2 的核心都是 32 token：2×4（256→128→32）FID 6.89；4×2（256→64→32）FID 9.54。預設 2×2（256→128→64）為 6.61。作者結論：適度、漸進的壓縮較好，保留較多 token 做中間處理有益。
- 段落：「適度、漸進的壓縮較好」
- 信心：high

**LO11** 群組引導在 CFG 之外，改的是分組門檻：條件分支用較細的分組 r_c ≥ 1，無條件分支用較粗的 r_u ≤ 1，只改門檻、不增加網路評估。ImageNet 設定：w = 2.6（引導區間 [0.1, 1]）、r_c = (1.2, 1)、t ≥ 0.85 時 r_u = (0.5, 1)、否則 (1, 1)；時間網格偏移 k = 1.7，只用於 600 epoch 端點。
- 段落：「條件分支用較細的分組 rc≥1，無條件分支用較粗的分組 ru≤1」
- 信心：high

**LO12** ImageNet 256：HiT-XL/16 在 600 epoch FID 1.48（280 epoch 為 1.87）；JiT-H/16 在 600 epoch 為 1.86。在 FID ≈ 2.16 時，HiT 比 JiT 少用 2.4 倍訓練計算、2.3 倍更新次數（Fig. 1）。文字到影像：HiT-B/16 五項基準平均 65.93，高於 MiniT2I 的 64.64，GFLOPs 139.4 對 201.6（少約 31%）。
- 段落：「HiT-XL/16 在 600 epoch 達到 FID 1.48」
- 信心：high

## 初學者可能卡住的地方

1. **符號多**：q、k、h、S、A、P、e、z 之間的關係散在 Sec. 03–04；A（列正規化）與 P（行正規化）容易混。
2. **合併樹與 τ**：「保留分數 ≥ τ 的合併」與「最高分數低於 τ 時停止」的等價性依賴「本頁推導」的可約性證明，沒有直觀說明。
3. **梯度方向**：f_s 越低反而產生越多合併，方向與直覺相反；加上 f_h 視為常數、sig 平滑化，Eq. 4 到 Eq. 11 的鏈式關係需要多次跳轉。
4. **r 的三種用法**：壓縮比 r（第 06 章）、群組數倍率 r（第 09 章）、以及 Eq. 10 中的 r，頁面有提醒但仍容易混淆。
5. **GFLOPs 與實際成本**：Table 4 的 GFLOPs 是以目標群組數計算的名目值，並非實際成本；第 07 章的推定 22.3 GFLOPs 與論文值是另一層估計。
