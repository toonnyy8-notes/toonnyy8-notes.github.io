    01 · 分組

    HiT 把特徵相近的 patch token 合併成一個群組 token；相距很遠的 patch 也能同組。

    02 · 預算

    群組數不固定：訓練只要求每一個分組階段在整個批次上平均保留一半的 token（兩階段後為四分之一），每張圖、每個噪聲程度可以不同。

    03 · 結果

    在 ImageNet 256 的影像品質指標 FID（越低越好）上達到 1.48；達到同樣品質時，比沒有分組的像素空間基準模型 JiT 少用 2.4 倍訓練計算（Fig. 1，FID ≈ 2.16）。

    01 · 出發點

    像素空間模型每個 patch 都保留一個 token

    影像生成的擴散模型有兩條路線。潛空間（latent space）擴散先用另外訓練的編碼器把影像壓成精簡的特徵，再在那個特徵空間學習生成；編碼器提供了由像素到精簡表示的階層，但這個階層是在生成訓練之外決定的。像素空間（pixel space）擴散直接在像素上生成，一個階段端到端訓練，不需要另外的視覺編碼器，但品質與訓練效率仍落後於領先的潛空間模型（Sec. 1）。

    常見的像素空間 Transformer 把影像切成固定大小的 patch（例如 16×16 像素），每個 patch 經線性投影成一個 token。ImageNet 256×256 的影像因此有 $16\times16=256$ 個 token，而且每一層都處理同樣的 256 個。

    作者的假設是：像素空間 Transformer 落後潛空間模型的部分原因，在於骨幹從頭到尾每個 patch 保留一個 token，沒有鼓勵模型形成「把相關內容在逐漸變粗的層級彙整」的視覺階層（Abstract、Sec. 1）。規則的 patch 網格給每個等大區域相同數量的 token，不管區域內容多寡；作者因此主張讓模型自己學「哪些資訊可以共用一個表示、要用幾個表示」，而不是用固定的空間切割決定。

    背景：x-prediction 與訓練損失

    HiT 沿用 JiT（Li 與 He，〈Back to Basics〉）的像素空間設定。帶噪影像寫成 $x_t=t\,x+(1-t)\,\epsilon$，其中 $x$ 是乾淨影像、$\epsilon$ 是標準高斯噪聲；$t=1$ 是乾淨影像，$t=0$ 是純噪聲。網路 $f_\theta$ 直接輸出乾淨影像（x-prediction），損失寫成（App. A.3）：

    $$\mathcal L_{\text{diff}}=\mathbb E\left[\frac{\mathrm{MSE}\big(f_\theta(x_t,t,c),x\big)}{\max(1-t,\,a_{\min})^2}\right],\quad a_{\min}=0.05$$
    Eq. 12

    分母把乾淨影像的誤差換算成速度的誤差（論文稱為 velocity loss），$a_{\min}=0.05$ 避免 $t\to1$ 時除以 0。$c$ 是條件（類別或文字）。

    作者認為像素空間 Transformer 落後潛空間模型的部分原因是什麼？

    骨幹從頭到尾每個 patch 保留一個 token，沒有鼓勵把相關內容在逐漸變粗的層級彙整的視覺階層（Abstract、Sec. 1）。

    02 · 骨幹

    骨幹由編碼器、精簡核心與解碼器遞迴組成

    HiT 把 Transformer 區塊排成巢狀的三段：編碼器、精簡網路與解碼器（Sec. 3.1、Fig. 2）。Transformer 區塊本身不改變 token 數與特徵寬度；token 數只在兩種新運算中改變。分組（grouping）把多個 token 合併成較少的群組 token；解組（ungrouping）把群組 token 的特徵送回原來的 token 位置。解組之後，再把分組前的特徵經線性投影加回來，稱為跳接（skip connection）。有 $J$ 層分組時，token 數依序為

    $$N\to K_1\to\cdots\to K_J\to\cdots\to K_1\to N$$
    Eq. 1
    帶噪影像 → 線性 patch 投影
    Transformer × 3 · 256 token
    ↓ 分組
    Transformer × 3 · 128 token
    ↓ 分組
    Transformer × 6 · 64 token
    ↓ 解組 ＋ 跳接（來自 128 token 段）
    Transformer × 3 · 128 token
    ↓ 解組 ＋ 跳接（來自 256 token 段）
    Transformer × 3 · 256 token
    預測 head → 乾淨影像

    依 Fig. 2 重繪。寬度表示目標 token 數；特徵寬度 $d$ 各段相同。

    ImageNet 256 的 HiT-B/16 骨幹以 18 個區塊、兩次 2× 分組為參考設定（Sec. 4.5）。論文用五個數字描述區塊分配，例如 3/3/6/3/3。ImageNet 256 的 HiT-B/16（18 區塊）目標平均 token 數依序是 256→128→64→128→256；layout 3/3/6/3/3 的五個數字依序是全解析度編碼器、中間編碼器、精簡核心、中間解碼器、全解析度解碼器的區塊數（Eq. 1、Sec. 4.5、Table 4）。這組數字只適用於 ImageNet 256；文字到影像的設定見第 08 章。

    條件資訊以 token 的形式加入：8 個類別 token 與 1 個時間 token 從第一個區塊開始參與注意力，但不參與分組與解組，也不計入壓縮預算與跳接（App. A.4）。

    以「區塊數 × token 數」粗估線性運算量本頁推導：3/3/6/3/3 為 $3\cdot256+3\cdot128+6\cdot64+3\cdot128+3\cdot256=2688$，18 個區塊都不分組則為 $18\cdot256=4608$。第 07 章的元件給出完整的推定成本。

    03 · 親和度

    親和度與平均連結法決定硬群組

    分組要先決定「哪些 token 屬於同一群」。在分組階段 $\ell$，令 $H\in\mathbb R^{N\times d}$ 為前面 Transformer 區塊輸出的 token 特徵，第 $i$ 列為 $h_i$。作者學兩個線性投影，並把投影結果正規化為長度 1，得到 $q_i$ 與 $k_i$。兩個單位向量的內積 $q_i^\top k_j$ 等於夾角的餘弦（cosine similarity），範圍是 $[-1,1]$：方向相同為 1，相反為 −1。

    $$S_{ij}=\tfrac12\big(q_i^\top k_j+q_j^\top k_i\big)$$
    Eq. 2

    因為 $q\ne k$，$q_i^\top k_j$ 一般不等於 $q_j^\top k_i$；Eq. 2 取兩者平均，讓親和度矩陣 $S$ 對稱。兩個群組 $U,V$ 之間的親和度定義為所有成員配對的平均（App. A.1）：

    $$s(U,V)=\frac{1}{|U|\,|V|}\sum_{i\in U}\sum_{j\in V}S_{ij}$$
    Eq. 8

    平均連結法（average linkage）是一種由下而上的階層式分群：從每個 token 自成一群開始，每一步合併 $s(U,V)$ 最高的兩群，直到只剩一群，得到一棵合併樹（共 $N-1$ 次合併）。把合併樹畫成樹狀圖時，縱軸是每次合併的分數。

    三個 token 的例子：若三個單位向量的角度是 10°、22°、150°，則 $S_{12}=0.9781$、$S_{13}=-0.7660$、$S_{23}=-0.6157$。第一次合併分數最高的 {1,2}（0.9781）；第二次合併 {1,2} 與 {3}，分數是 $(-0.7660-0.6157)/2=-0.6909$。門檻 $\tau=0.8$ 時只保留第一次合併，得到兩個群組 {1,2} 與 {3}。

    $S_{ij}$ 的算法是 $S_{ij}=\tfrac12(q_i^\top k_j+q_j^\top k_i)$，其中 $q,k$ 為單位向量；平均連結法反覆合併平均親和度最高的兩群，並保留分數 $\ge\tau$ 的合併（Eq. 2、Eq. 8、Sec. 3.2，原文為「We retain merges with affinity at least τ」），保留下來的合併形成 $K$ 個硬群組 $G_1,\dots,G_K$。在精確的平均連結法下，合併分數沿合併順序不增，所以「保留分數 $\ge\tau$ 的合併」等於「最高分數低於 $\tau$ 時停止」本頁推導。

    空間上不相連的 patch 能在同一群組，原因是親和度只由特徵投影 $q,k$ 計算，不含位置；HiT 在雙向的影像特徵上分組，不像 H-Net 沿因果序列切出相鄰的區塊（Sec. 2、Sec. 3.2）。Fig. 1 中兩根香蕉的 patch 屬於同一群組，Fig. 4c 中分開的車身標記也屬於同一群組。

    門檻 $\tau$ 在訓練前校準後固定（第 06 章）。即使 $\tau$ 固定，每一個去噪步驟的特徵不同，群組成員與群組數也跟著改變（Sec. 3.2）。

    為什麼合併分數不增〔本頁推導〕

    平均連結法滿足可約性（reducibility）：若 $U,V$ 是目前分數最高的一對，合併後的新群組 $U\cup V$ 對任何其他群組 $W$ 的分數 $s(U\cup V,W)=\frac{|U|s(U,W)+|V|s(V,W)}{|U|+|V|}$ 是兩個不大於 $s(U,V)$ 的數的加權平均，所以下一次合併的分數不會超過這一次。本頁的驗算腳本對 200 組隨機輸入確認合併分數不增。

    與 ToMe、H-Net 的差異

    ToMe 與 ToMeSD 依相似度合併 token，但每層合併的數量或比例是預先設定的；HiT 的群組數由門檻與壓縮預算決定（Sec. 2）。H-Net 與 BLT 在序列上形成長度可變的區塊，但區塊沿序列連續；HiT 用親和度分組，不相鄰的位置也能同組（Sec. 2）。

    檢查理解

    $S_{ij}$ 怎麼算？平均連結法保留哪些合併？

    $S_{ij}=\tfrac12(q_i^\top k_j+q_j^\top k_i)$，$q,k$ 為單位向量；反覆合併平均親和度最高的兩群，保留分數 $\ge\tau$ 的合併（Eq. 2、8、Sec. 3.2）。〔本頁推導，假設精確的平均連結法〕合併分數不增，所以等於最高分低於 $\tau$ 時停止。

    為什麼空間上不相連的 patch 能在同一群組？

    親和度只由特徵投影 $q,k$ 計算，不含位置；HiT 在雙向影像特徵上分組，不像 H-Net 沿因果序列切塊（Sec. 2、3.2）。

    04 · 軟權重

    每個群組 token 由所有輸入 token 加權平均而成

    硬分組是離散的：一個 token 屬於某一群就是 1，否則是 0。這種指派沒有梯度，訓練時無法調整產生 $q,k$ 的投影（Sec. 3.2）。作者因此另外算一組連續的軟權重，用來建立群組 token。

    對 token $i$ 與硬群組 $G_g$，先算 $i$ 對該群成員的平均親和度 $e_{ig}$，再對所有群組做 softmax。softmax 的溫度 $T_r$ 越小，最大的 $e_{ig}$ 分到的權重越接近 1：

    $$e_{ig}=\frac{1}{|G_g|}\sum_{j\in G_g}S_{ij},\qquad A_{ig}=\frac{\exp(e_{ig}/T_r)}{\sum_{g'=1}^{K}\exp(e_{ig'}/T_r)}$$
    Eq. 9

    $A\in\mathbb R^{N\times K}$ 的每一列和為 1，描述一個 token 與各群組的關聯。把 $A$ 的每一行（column）除以該行總和，得到池化矩陣 $P$，第 $g$ 個群組 token 是所有輸入特徵的加權平均：

    $$P_{ig}=\frac{A_{ig}}{\sum_jA_{jg}},\qquad z_g=\sum_{i=1}^{N}P_{ig}\,h_i=\frac{\sum_{i=1}^{N}A_{ig}h_i}{\sum_{i=1}^{N}A_{ig}}$$
    Eq. 6、App. A.1

    軟權重與池化的定義如下：$A_{ig}=\mathrm{softmax}_g(e_{ig}/T_r)$，$e_{ig}$ 是 token $i$ 對 $G_g$ 成員的平均親和度；$P_{ig}=A_{ig}/\sum_jA_{jg}$；群組 token 是所有輸入 token 的加權平均，而不只是硬群組成員的平均（Eq. 6、Eq. 9、App. A.1）。硬群組只決定「有哪些群組」與每個群組的 $e_{ig}$；每個 token 都依 $A$ 對每個群組有貢獻。論文的 $T_r=0.05$ 很小，權重比 $A_{ig}/A_{ig'}=\exp((e_{ig}-e_{ig'})/T_r)$ 在親和度差 0.1 時約為 $e^2\approx7.4$ 倍本頁推導。

    05 · 解組

    解組重用同一組軟權重並加上跳接

    精簡網路 $M$（更深一層的區塊）處理群組 token 後，輸出第 $g$ 個群組的特徵 $\tilde z_g$。解組把這些特徵依分組前算好的同一組軟權重 $A$ 混合回每個 token 位置，輸出記為 $\mathbf r_i$（Eq. 7）：

    $$\mathbf r_i=\sum_{g=1}^{K}A_{ig}\,\tilde z_g$$
    Eq. 7

    再加上分組前的特徵經跳接投影 $W_\ell$（$d\times d$，初始化為單位矩陣）後的結果。整個階段用矩陣寫成：

    $$Z=P^\top H,\qquad \tilde H=A\,M(Z)+H\,W_\ell^\top$$
    Eq. 3

    解組的做法是 $\mathbf r_i=\sum_gA_{ig}\tilde z_g$，即 $\tilde H=AM(Z)+HW_\ell^\top$：重用 $A$ 軟混合，並加上初始化為單位矩陣的跳接；反向傳播時硬分割視為常數，梯度經由軟池化與解組權重 $A$ 傳到產生 $q,k$ 的投影（Eq. 3、Eq. 7、Sec. 3.2）。解組恢復了 token 的位置，但不能反轉有損的池化（App. A.1）。

    跳接投影不一定改善品質：App. B.2 的 12 區塊 adaLN 模型中，直接相加 $R+H$ 的 FID 為 11.65，優於預設投影跳接的 12.27（Table 10）。作者保留投影，理由是它是簡單的融合規則，允許轉換編碼器特徵，同時保留重建特徵的直接路徑。

    作者比較了四種組合（Table 3，HiT-B/16，80 epoch，FID 越低越好）。只在硬群組內池化時，FID 為 10.32（均勻權重）與 10.16（學到的權重）；對所有 token 池化但用硬查表解組（$\mathbf r_i=\tilde z_{g(i)}$，$g(i)$ 為 token $i$ 的硬群組）時為 7.97；預設的「所有 token 池化＋軟解組」為 6.61。作者的結論是：在聚合與讀回兩個方向都跨越硬群組邊界交換資訊較好。

    06 · 壓縮預算

    壓縮損失只約束批次平均的保留比例

    HiT 不規定每張影像要有幾個群組，而是規定整個批次平均保留多少比例（Sec. 3.3）。在分組階段 $\ell$，令 $r\gt1$ 為目標壓縮比，$\rho=1/r$ 為目標保留比例；預設每階段 $r=2$，$\rho=1/2$。批次中第 $b$ 個樣本進入此階段時有 $N_b$ 個 token，產生 $K_b$ 個硬群組。實際保留比例 $f_h$ 是所有樣本的群組數總和除以 token 數總和，分子分母都在整個批次與所有裝置上加總（App. A.3）。

    $f_h$ 是計數，沒有梯度。作者用 sigmoid $\operatorname{sig}(x)=1/(1+e^{-x})$ 把每次合併「分數是否 $\ge\tau$」的 0/1 判斷換成 0 到 1 之間的平滑值，得到可微的群組數估計 $\tilde K_b$；$s_{b,m}$ 是第 $b$ 個樣本完整合併樹第 $m$ 次合併的平均親和度，溫度 $T_b$ 越小越接近 0/1（App. A.2）：

    $$\tilde K_b=N_b-\sum_{m=1}^{N_b-1}\operatorname{sig}\!\Big(\frac{s_{b,m}-\tau}{T_b}\Big),\qquad f_h=\frac{\sum_bK_b}{\sum_bN_b},\qquad f_s=\frac{\sum_b\tilde K_b}{\sum_bN_b}$$
    Eq. 11

    壓縮損失沿用 H-Net 的比例損失（ratio loss），論文把它寫成：

    $$\mathcal L^{(\ell)}_{\text{comp}}=1+\frac{(f_h-\rho)(f_s-\rho)}{\rho(1-\rho)}$$
    Eq. 4
    H-Net 的原始寫法（Eq. 10）與兩式相等〔本頁推導〕
    $$\mathcal L^{(\ell)}_{\text{comp}}=\frac{r}{r-1}\big[(r-1)f_hf_s+(1-f_h)(1-f_s)\big]$$
    Eq. 10

    代入 $r=1/\rho$，Eq. 4 與 Eq. 10 都化成 $\big[f_hf_s+\rho(1-f_h-f_s)\big]/\big(\rho(1-\rho)\big)$。下方元件同時顯示兩式的值。

    $f_h$ 在反向傳播時視為常數，梯度只經由 $f_s$ 傳到合併分數 $s_{b,m}$；合併樹的形狀固定，但合併親和度可微（App. A.2）。對 $f_s$ 微分得到 $\partial\mathcal L^{(\ell)}_{\text{comp}}/\partial f_s=(f_h-\rho)/(\rho(1-\rho))$本頁推導。

    壓縮損失是 $1+(f_h-\rho)(f_s-\rho)/(\rho(1-\rho))$；當 $f_h\gt\rho$（群組太多），對 $f_s$ 的梯度 $(f_h-\rho)/(\rho(1-\rho))\gt0$，梯度下降降低 $f_s$，也就是使合併分數上升、產生更多合併；$f_h$ 視為常數（Eq. 4、Sec. 3.3）。$f_h\lt\rho$ 時方向相反；$f_h=\rho$ 時損失恆為 1、梯度為 0。若 $f_h=f_s=f$，損失為 $1+(f-\rho)^2/(\rho(1-\rho))\ge1$本頁推導。

    批次層級預算的算法是 $f_h=\sum_bK_b/\sum_bN_b$、$f_s=\sum_b\tilde K_b/\sum_bN_b$，其中 $\tilde K_b=N_b-\sum_m\operatorname{sig}((s_{b,m}-\tau)/T_b)$，分子分母跨批次與裝置加總；損失只約束平均比例，所以每張影像的群組數可以不同，論文的說法是群組數「隨影像內容與擴散時間改變」（Eq. 11、Sec. 3.3）。第二個分組階段的 $N_b$ 是第一階段實際產生的群組數（App. A.2）。

    各階段的損失相加後乘上權重 $\lambda$，與去噪損失一起訓練：

    $$\mathcal L=\mathcal L_{\text{diff}}+\lambda\sum_\ell\mathcal L^{(\ell)}_{\text{comp}},\qquad\lambda=0.01$$
    Eq. 5

    門檻 $\tau$ 在訓練前校準：在 1,024 個固定的帶噪訓練樣本上，由外層到內層依序調整各階段的 $\tau$，使總壓縮比符合目標，之後在訓練與一般取樣時固定（App. A.3）。App. B.3 掃描 $\lambda\in\{0.005,0.01,0.02,0.03\}$，FID 依序為 12.30、12.27、12.07、12.33（12 區塊 adaLN 模型，Table 11），作者結論是生成品質對 $\lambda$ 不敏感。

    檢查理解

    Eq. 4 是什麼？$f_h\gt\rho$ 時梯度下降如何改變 $f_s$？

    $1+(f_h-\rho)(f_s-\rho)/(\rho(1-\rho))$；對 $f_s$ 的梯度為 $(f_h-\rho)/(\rho(1-\rho))\gt0$，梯度下降降低 $f_s$（使合併分數上升，更多合併）；$f_h$ 視為常數（Eq. 4、Sec. 3.3）。

    08 · 學到的群組

    學到的群組對應物件、部位與字詞

    訓練時沒有任何分割標註，但 HiT-B/16 在 $t=0.75$ 的群組會沿著物件區域或物件部位分開，也會把重複的背景結構（例如樹葉）收進同一群組；分開的車身標記可以屬於同一群組（Sec. 4.4、Fig. 4）。第二階段在第一階段的群組上再分組，每個第一階段群組在硬指派下有一個第二階段的上層群組（App. D.2、Fig. 8）。同一張影像、同一份噪聲，改變 $t$ 時群組成員與群組數都會改變（App. D.3、Fig. 9）。本頁不重繪這些影像；請參考論文圖與專案頁。

    文字到影像的共同分組

    文字到影像沿用 MiniT2I：凍結的 FLAN-T5-Large 文字編碼器（序列長度 256）加上學到的投影與兩個純文字前置區塊；外層的影像與文字各有自己的投影與 MLP，以聯合注意力互動（App. A.5）。Table 2 的 HiT-B/16 解析度為 512×512、patch 16，影像有 32×32 = 1024 個 patch token。

    $$N_b=N_{\text{img}}+\sum_j m_{bj}$$
    Eq. 13

    其中 $m_{bj}$ 是字幕的有效遮罩（含有效的特殊 token）。padding 不進入合併樹、池化與預算；時間 token 繞過分組；字幕被丟棄的樣本只有影像進入分組。一個群組可以只含影像、只含文字或兩者都有，所以精簡階段用共享的區塊。論文的可視化（App. D.5）用 $(P_1P_2)_{\text{img},g}$ 畫出一個字幕 token 所屬群組在影像上的池化權重，用 $((A_1A_2)(P_1P_2)^\top)[i,:]$ 的字幕部分畫出一個影像 patch 與各字詞的連結；Fig. 1 中「banana」的 patch 對字詞「banana」有高權重，「boy」所在群組的池化權重集中在男孩的臉與上半身。

    09 · 群組引導

    群組引導以分組容量的差作為引導訊號

    分類器自由引導（classifier-free guidance，CFG）在每一步算兩次網路：有條件與無條件（類別被丟棄）的預測，再把兩者的差放大。HiT 在推論時還可以調整門檻，改變群組數。群組數倍率 $r=(r_1,r_2)$ 表示各階段的目標平均群組數是預設值的幾倍（這裡的 $r$ 與第 06 章的壓縮比無關）；群組數對每個輸入仍是自適應的（App. A.6）。

    直接增加群組數給出更細的表示，但骨幹是在壓縮表示上訓練的，改變操作區間可能讓預測變差。作者受 Sparse Guidance 啟發，把「容量差」也放進引導方向。令 $v_c^{(r)}(x_t,t)$ 為條件 $c$、群組數倍率 $r$ 時網路預測的速度，$v_\varnothing^{(r)}$ 為無條件預測，引導強度 $w$（論文寫 $s$）：

    $$\hat v_t=v_\varnothing^{(r_u(t))}(x_t,t)+w\Big(v_c^{(r_c(t))}(x_t,t)-v_\varnothing^{(r_u(t))}(x_t,t)\Big),\qquad r_c(t)\ge1\ge r_u(t)$$
    Eq. 14

    兩個倍率都設為 1 時就是標準 CFG。群組引導只改門檻，不改權重、軟池化與讀回，也不需要 CFG 以外的網路評估。ImageNet 的 FID 1.48 結果使用 $w=2.6$（引導區間 $[0.1,1]$，區間外只用條件預測）、$r_c=(1.2,1)$，以及在接近乾淨影像的一端額外壓縮無條件分支（App. A.6）：

    $$r_u(t)=\begin{cases}(1,1),&t\lt0.85\\(0.5,1),&t\ge0.85\end{cases}$$
    Eq. 15

    JiT 用 $[0,1]$ 上均勻的 50 步 Heun 加最後一步 Euler。這個 HiT 結果保留解算器與步數，只把時間網格往噪聲多的一端偏移：

    $$\sigma=1-t,\qquad\sigma'=\frac{k\sigma}{1+(k-1)\sigma},\qquad t'=1-\sigma',\qquad k=1.7$$
    Eq. 16

    這裡的 $\sigma$ 是噪聲程度 $1-t$。Eq. 14–15 中的 $t$ 是偏移後網格上的時間 $t'$。偏移只用在 600 epoch 的端點；Fig. 1 收斂曲線的其他點用均勻網格（App. A.6）。映射固定兩端（$t=0\mapsto0$、$t=1\mapsto1$），$k\gt1$ 時內部各點 $t'\lt t$本頁推導。

    群組引導比 CFG 多改的是分組：條件分支用較細的分組 $r_c\ge1$，無條件分支用較粗的分組 $r_u\le1$，只改門檻、不增加網路評估。ImageNet 設定為 $w=2.6$（區間 $[0.1,1]$）、$r_c=(1.2,1)$、$t\ge0.85$ 時 $r_u=(0.5,1)$、否則 $(1,1)$，時間偏移 $k=1.7$ 僅用於 600 epoch 端點（Eq. 14–16）。

    檢查理解

    群組引導比 CFG 多改了什麼？ImageNet 設定為何？

    條件分支用較細的分組 $r_c\ge1$、無條件分支用較粗的 $r_u\le1$，只改門檻、不增加網路評估；ImageNet $w=2.6$（論文 $s$，區間 $[0.1,1]$）、$r_c=(1.2,1)$、$t\ge0.85$ 時 $r_u=(0.5,1)$ 否則 $(1,1)$；時間偏移 $k=1.7$（僅 600 epoch 端點）（Eq. 14–16）。

    延伸閱讀：Group guidance：以分組容量差作為引導、學到的路由與動態 DiT（系列筆記，含 Sparse Guidance）、擴散模型的分類器引導

    10 · 結果

    HiT-XL/16 在 ImageNet 256 達到 FID 1.48

    FID（Fréchet Inception Distance）比較生成影像與真實影像在 Inception 特徵空間的分布距離，越低越好；論文用 50,000 張生成影像計算。HiT 在 ImageNet 256 與文字到影像的關鍵數字如下：HiT-XL/16 在 600 epoch 達到 FID 1.48，在 280 epoch 為 1.87，而 JiT-H/16 在 600 epoch 為 1.86；在 FID ≈ 2.16 時，HiT 比 JiT 少用 2.4 倍訓練計算、2.3 倍更新次數；文字到影像的 HiT-B/16 五項基準平均 65.93，高於 MiniT2I 的 64.64，GFLOPs 少 31%（Table 1、Table 2、Fig. 1）。摘要另寫「約 40% 的累積訓練 FLOPs」。

    HiT-XL/16 也低於使用 DINOv2 外部監督的像素空間模型 PixNerd-XL/16（2.15）、PixelGen-XL/16（1.83）與 PixelDiT-XL/16（1.61），並接近潛空間的 REPA SiT-XL/2（1.42）。在 80 epoch、CFG 2.9 的同參數量比較中，HiT 在三個規模都以較少的 forward FLOPs 得到較低的 FID（Table 8）。

    11 · 實作

    實作設定與常見錯誤

    訓練與評估設定（Sec. 4.1、App. A.3–A.4）
    項目設定
    分組每階段 2×、兩階段；$T_r=0.05$、$T_b=0.1$、$\lambda=0.01$（各階段損失之和）
    門檻訓練前在 1,024 個固定帶噪樣本上由外到內依序校準，之後固定
    最佳化AdamW，β = (0.9, 0.95)，weight decay 0，global batch 1,024；ImageNet 遵循 JiT 配方
    文字到影像學習率5,000 步內由 10⁻⁶ 升到 4×10⁻⁴ 後固定；EMA 0.99995
    骨幹RMSNorm、QK 正規化、SwiGLU；單一線性 patch 投影；去掉 adaLN，8 個類別 token＋1 個時間 token
    位置編碼全解析度影像 RoPE；條件 token 用恆等旋轉；精簡階段不加 RoPE
    ImageNet 消融評估HiT-B/16、80 epoch、EMA 0.9999、CFG 2.9（區間 (0.1, 1.0)）、50 步 Heun＋最後一步 Euler、FID-50k
    GFLOPs以目標群組數計算的名目值

    常見錯誤

    1. 只在硬群組內池化：FID 10.16–10.32，遠差於對所有 token 加權的 6.61（Table 3）。
    2. 解組用硬查表：7.97 對 6.61；解組要重用分組前的 $A$ 做軟混合。
    3. 每張影像固定群組數：壓縮損失只約束批次的平均保留比例，個別影像的群組數可以不同（Sec. 3.3）。
    4. 只在單一裝置上算比例：$f_h,f_s$ 的分子分母要先跨裝置加總再算損失；梯度累積時對各次 forward 的損失取平均（App. A.3）。
    5. 讓梯度經過 $f_h$ 或合併樹的形狀：$f_h$ 與硬分割視為常數，只有 $f_s$ 與軟權重可微。
    6. 第二階段的分母用固定的 $N/2$：要用第一階段實際產生的群組數（App. A.2）。
    7. 條件 token 或 padding 參與分組：類別／時間 token 與 padding 繞過分組與預算（App. A.4–A.5）。
    8. 把 GFLOPs 當成實際成本：論文報告的是以目標群組數計算的名目值（Sec. 4.1）。
    9. 在訓練中更新門檻：基準門檻訓練前校準後固定；群組引導另用個別校準的推論門檻（App. A.3、A.6）。
    10. 忽略 $T_r=0.05$ 很小：$A$ 接近硬指派，只有平均親和度接近的群組才分到可見的權重。
    12 · 與 RTI 比較

    與 RTI／HiT 的異同

    同一批教學中的 RTI（No. 217，〈Elastic Token Compression for Pixel-Space Diffusion Transformers〉）也在像素空間擴散 Transformer 中合併 token，但目的與做法不同。下表只列兩篇論文各自寫明的事實；RTI 的細節見其互動教學。

    HiT 與 RTI 的比較（RTI 事實取自其摘要與 Sec. 3）
    面向HiT（本文）RTI（No. 217）
    訓練方式從頭端到端訓練，分組與去噪一起學改造預訓練的像素空間文字到影像模型，微調介面
    群組形狀由特徵親和度決定，可以不相連沿 Hilbert 曲線切成連續區段，區域必相連
    群組數批次層級壓縮損失決定平均，個別樣本自適應區域數 R 在微調時隨機抽取，一個 checkpoint 服務多種預算
    位置精簡階段預設不加 RoPE每個區域 token 帶位置（patch rotary embedding 的平均）
    解組重用軟權重 A 混合回所有位置把區域 token 的變化寫回其 patch
    主要目的生成品質與訓練效率推論加速（摘要：與 dense 品質相當時 2.0 倍速度）
