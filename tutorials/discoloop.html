DiscoLoop

Dis · Discrete 離散詞嵌入co · Continuous 連續隱藏狀態Loop · 迴圈

迴圈 Transformer 在兩圈之間交接時，同時傳遞連續隱藏狀態與離散詞嵌入，讓模型不寫出中間步驟也能把兩條事實接起來。

這篇論文找出迴圈 Transformer 做兩步推理時仍會出錯的原因：第一圈其實已經算出中間答案，但交給第二圈的向量和該答案的詞嵌入方向差很多。作者據此設計了 DiscoLoop。

Hengyu Fu*、Tianyu Guo*、Zixuan Wang*、Hanlin Zhu*、Jason D. Lee、Jiantao Jiao、Stuart Russell、Song Mei
UC Berkeley · Princeton University　* 共同第一作者

論文的四步論證

步驟 1一般 Transformer 存錯深度事實只存在前面幾層，第二步要用時已在後面幾層。 步驟 2迴圈解決存放，但不夠同一組層用兩次，ID 71.1%，OOD 只有 8.3%。 步驟 3找到原因：方向不對Bob 可被讀出（機率 1.000），但與 W[Bob] 的餘弦只有約 0.3。 步驟 4DiscoLoop 把修正做進架構交接時加入按機率加權的詞嵌入，可以一起訓練。
01 · 任務

兩步推理：把兩條記住的事實接起來

假設模型在訓練時讀過兩條事實：「Alice 的兒子是 Bob」和「Bob 的妻子是 Carol」。現在問它：「Alice 的兒子的妻子是誰？」正確答案是 Carol。要得到答案，必須先用第一條事實找到 Bob，再用第二條事實從 Bob 找到 Carol。

這種題目叫做兩步推理（two-hop reasoning）。中間的 Bob 叫做橋接實體（bridge entity）。

大型語言模型可以先把中間步驟寫出來，例如先輸出「Alice 的兒子是 Bob」，再輸出答案。這種做法叫。這篇論文研究的是另一種情況：模型不寫出 Bob，必須在一次內完成兩步，直接輸出 Carol。

用符號寫下來

論文把知識寫成一張圖 G = (E, R, F)：E 是實體（人名），R 是關係（兒子、妻子⋯⋯），F 是所有成立的事實。每條事實是一個三元組 (a, r₁, b)。

推論規則（論文式 1）(a, r1, b) ∈ F且(b, r2, c) ∈ F⇒問題 (a, r1, r2) 的答案是 c

在符號資料集中，每個實體和每個關係各自是一個 。原子事實寫成 3 個 token：<a> <r₁> <b>；兩步問題寫成 4 個 token：<a> <r₁> <r₂> <c>。模型要預測最後一個 token。事實必須存在模型的參數裡，並且在內部組合。

03 · 問題一

一般 Transformer 把事實存在「錯的深度」

由很多層疊成，每一層有自己的參數，資訊從第 1 層往上傳到最後一層。研究發現，一般 Transformer 做兩步推理時會分工：前面幾層找出 Bob，後面幾層再查「Bob 的妻子」。

問題在於「Bob 的妻子是 Carol」是怎麼學到的。訓練時它以原子事實 <Bob> <妻子> <Carol> 出現，Bob 直接寫在輸入裡，模型在前面幾層就能查完，所以這條事實被存進前面幾層的參數。做兩步推理時，Bob 要等前面幾層算完才出現，查第二條事實的工作落在後面幾層，而後面幾層沒有存這條事實。

論文稱這個現象為深度局部儲存問題（depth-local storage problem）：事實只存在特定深度，在另一個深度就用不到。

迴圈 Transformer：同一組層用兩次

迴圈 Transformer（Looped Transformer）把同一個模組 fθ 重複套用 K 次。兩次用的是同一組參數，所以第一圈查得到的事實，第二圈也查得到。

原始迴圈 Transformer（論文式 2），本文 K = 2H(0) = W[x],H(k+1) = fθ(H(k)),ℓ = H(K)W⊤

W 是嵌入矩陣，每一列是一個 token 的。這裡輸入和輸出共用 W：輸入時用 W[x] 把 token 換成向量；輸出時用 HW⊤ 算出每個 token 的分數（logits），這一步叫 。H 是，每個輸入位置各有一個向量。

作者在訓練完成後分兩個階段讀出答案：Stage 1 是只跑第一圈就送進 LM head，Stage 2 是跑完兩圈。

  • Stage 1 的原子事實準確率是 100%：一圈就足以記住所有事實。

04 · 問題二

Bob 已經算出來了，但向量的方向不對

既然迴圈已經解決存放位置的問題，為什麼 OOD 還是只有 8.3%？作者檢查第一圈結束時、位於 r₁ 位置的隱藏狀態 H(1)1。這是模型應該已經算出 Bob 的位置。

檢查一：能不能讀出 Bob？使用 ，把這個隱藏狀態直接送進 LM head，看它此時會預測什麼。結果 Bob 的機率是 1.000，ID 和 OOD 都一樣。第二圈開始之前，Bob 已經可以被正確讀出。

檢查二：方向是否接近 Bob 的詞嵌入？計算這個隱藏狀態和 W[Bob] 的。結果只有 0.327（ID）和 0.266（OOD），換算成夾角大約是 71° 和 75°。

拖曳藍色箭頭的端點（或聚焦後用方向鍵）。分數只取決於箭頭在橫軸上的分量，縱軸的分量幾乎不影響任何 token 的分數，卻會讓餘弦變小。真實模型的向量有數百維，與所有詞嵌入都接近垂直的方向非常多；這張二維圖只保留其中一個方向來說明。圖中的機率是示意，論文量到的 P(Bob) 是 1.000。

為什麼方向重要？訓練原子事實 <Bob> <妻子> <Carol> 時，Bob 是以詞嵌入 W[Bob] 的形式進入模型的。模型學會的是「收到 W[Bob] 時，查出 Bob 的事實」。第二圈收到的卻是一個和 W[Bob] 夾角約 71° 的向量，裡面混有其他成分，查詢就容易失敗。作者的描述是：第二圈收到的是一個有雜訊的連續混合向量，而不是乾淨的離散詞嵌入。

為什麼 OOD 比 ID 更低？圖 B 的實體在訓練中從來沒有出現在橋接位置，沒有任何訓練訊號讓它們在第一圈的輸出靠近自己的詞嵌入。

05 · 驗證

一個不用重新訓練的實驗：把向量往 W[Bob] 推

如果問題真的出在方向，那麼把第一圈的輸出往 W[Bob] 推一些，第二圈就應該查得到事實。作者只在 r₁ 這一個位置、只在兩圈之間做以下替換，模型參數完全不動，其他計算也不變：

免訓練重新對齊（論文式 3）bmax = argmax(WH(1)1);H(1)1 ← (1 − α) H(1)1 + α · Norm(W[bmax])α ∈ [0, 1]

bmax 是 LM head 分數最高的 token，也就是 Bob。α = 0 代表不修改；α = 1 代表整個換成正規化後的詞嵌入。

只把交接的向量往詞嵌入推一點（α = 0.1），OOD 就由 8.3% 升到 25.9%；α 接近 0.5 時，ID 與 OOD 都接近 100%。OOD 提升超過十倍。

結論迴圈解決了存放問題，但留下了表示問題（representation bottleneck）：第二圈收到的向量和它熟悉的詞嵌入不一致。這個實驗只改動交接處，所以它說明「表示不一致」是主要原因之一；它沒有證明這是唯一原因。

這個修正不能直接拿來訓練，原因有兩個：它用 argmax 硬選一個 token，argmax 不能求梯度；而且它需要事先知道橋接實體在哪個位置。DiscoLoop 就是為了解決這兩點而設計的。

06 · 方法

DiscoLoop：在交接處加上一條離散詞嵌入通道

DiscoLoop 在每一次「不是最後一圈」的交接時做兩件事：完整保留連續隱藏狀態，再加上一個由模型自己的預測機率算出來的詞嵌入。這個詞嵌入是所有 token 詞嵌入的加權平均，權重就是 LM head 的預測機率，所以叫「軟」詞嵌入。

DiscoLoop 遞迴（論文式 4），k = 0, …, K−1H(k+1) = fθ(H̃(k)),H̃(k+1) = H(k+1) + α(k) ⊙ RMSNorm(Φ(H(k+1))),H̃(0) = W[x]
先解碼再編碼的運算 Φ（論文式 5）Φ(h) = Σv pv(h) W[v],pv(h) = exp((Wh)v / τ) ⁄ Σv′ exp((Wh)v′ / τ)

五個 token 的分數固定為 Bob 3.0、Carol 1.6、Finley 1.0、Dave 0.6、Erin 0.2（示意值）。τ 越小，機率越集中在 Bob，Φ 越接近 W[Bob]（圖中的空心圓）；τ 越大，Φ 越接近所有詞嵌入的平均。藍色 h 是連續隱藏狀態，深色 h̃ = h + α · RMSNorm(Φ) 是送進下一圈的向量。這裡 RMSNorm 以「調整成單位長度」來畫。

閘門 α 的兩種設定

  • 固定：所有位置使用同一個值 α*。符號資料實驗使用 α* = 1、τ = 1。
  • 可學習：αt = σ(⟨wα, Φ(Ht)⟩ + bα)，依照每個位置解碼出的內容決定加入多少。只多出 d + 1 個參數，所有圈與所有位置共用。自然語言資料實驗使用這個版本。
  • 最後一圈 α = 0：最終答案直接由 H(K) 經 LM head 讀出，不加入離散通道。
  • 實作上，Φ 只用機率最高的 128 個 token 計算（top-k = 128）。作者表示這已涵蓋幾乎所有不可忽略的機率。

07 · 結果

實驗結果：符號資料、自然語言、三步推理與預訓練

主要比較三種模型：DiscoLoop；原始迴圈 Transformer（同一個 fθ，只差在沒有離散通道）；非迴圈 Transformer（K 份不共用參數的 fθ，計算量相同、參數較多）。預訓練實驗另外加入 PonderLM。

訓練損失：前期原始迴圈較低；約 130 億 token 之後 DiscoLoop 反超並維持領先，後期差距最大約 0.01。

訓練過程：Stage-1 準確率先掉下來，測試準確率才上升

作者在訓練中持續讀取「只跑第一圈」時對兩步訓練題的準確率。這個數字高，代表模型在單一圈裡直接背下兩步答案。這是一種捷徑，對 OOD 沒有幫助。這個數字降到接近 0，代表組合被推到第二圈進行。

結果顯示，Stage-1 準確率下降的時間點，正好是測試準確率開始上升的時間點。DiscoLoop 的下降更早、更快，測試準確率也更早上升、最後更高。作者的解釋是：離散通道提供了更乾淨的訊號，讓模型更快走向「用迴圈組合」的解法。

    08 · 限制

    這篇論文還沒有回答的問題

    • 長度泛化沒有測試：用最多 k 步訓練的模型，能不能處理更多步，論文沒有實驗。
    • 預訓練規模中等：受限於計算資源，只做到 440M 參數，更大規模還需要驗證。
    • 作者提出的下一步：用持續預訓練（continual pretraining）把這套迴圈方法套到更大的、已經預訓練好的模型上。
    • 預訓練的分數差距不大：平均分數差 1.2 分，最大單項差 2.5 分，而且 LAMBADA 上 PonderLM 較高。
