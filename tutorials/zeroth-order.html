不用反向傳播，
模型也能學會嗎？

零階最佳化（zeroth-order, ZO）只看損失值，不算梯度。它從 1952 年的有限差分出發，2023 年讓大型語言模型以推論等級的記憶體完成微調，2026 年 10 月第一次在 Transformer 預訓練上追近反向傳播。這篇導讀從直覺一路走到 Dust 與 Noise 的最新紀錄。

01動機

反向傳播很強，但它有兩個前提

整條計算必須可微，而且要把中間的激活值全部存下來。任何一個前提不成立，就得換個辦法回答「參數該往哪裡走」。目前有四股力量推著大家研究零階方法，成熟度各不相同。

記憶體

不必保存激活值與梯度。MeZO 在一張 A100 80GB 上就能訓練 30B 模型，同樣預算用反向傳播只到 2.7B。

已在微調實現

不可微與黑盒

準確率、F1、量化模型、外部程式、只開放 API 的模型，都只回傳一個數字。只要能算分數，就能用零階方法。

部分實現

硬體與平行化

只有前向就沒有 backward 鎖。只會跑推論的晶片、類比或 neuromorphic 硬體，以及沒有 bubble 的深度方向 pipeline 都受惠。

仍是願景

苦澀教訓

Q Labs 主張可微性是低算力時代的歸納偏誤。算力夠多時，以搜尋為核心的通用學習法會勝出，就像 AlphaGo Zero。

押注中

代價也很清楚。每一次前向只帶回一個純量，卻要拿來猜一個 d 維的方向。所以零階方法的估計變異數會隨維度成長，需要的步數是一階方法的數十倍，也特別敏感。例如 MeZO 在 SST-2 上，有 prompt 模板時準確率是 89.6，拿掉模板只剩 51.9。

目前的進度：記憶體這條已經在微調上兌現。不可微目標與硬體兩條大多還停在願景，Noise 的紀錄全都跑在完全可微的標準 GPT 上。苦澀教訓則是 Q Labs 的押注，證據目前只到 37.7M 到 243M 參數。

02直覺

蒙著眼下山：往兩邊各踩一步

站在看不見的山坡上，你不知道坡度，但可以沿某個方向往前試踩一步、再往後試踩一步，比較哪邊比較低。把高度差除以步長，就得到這個方向上的坡度。

ĝ = f(θ + σu) − f(θ − σu)2σ · u,   u ~ 𝒩(0, I) 兩次前向、一個隨機方向 u。期望值等於（平滑後的）梯度；單次很吵，平均 K 次就會收斂。這就是 SPSA 與 Gaussian smoothing 的核心。

在二維裡，抽幾個方向平均一下就很準了。問題是一個 Transformer 有幾千萬到幾千億個參數。方向的維度一變大，同樣的抽樣次數就猜不準了。下一章來量化這件事。

03理論

維度的詛咒，以及三條繞路

每次評估只帶回一個數字。要猜的方向有 d 維，大約就需要 d 次評估才猜得準。把 K 個方向平均後，估計與真實梯度的夾角餘弦大約是：

cos(K) ≈ 1√(1 + d / K) K = d 時 cos ≈ 0.71；要到 0.9 需要 K ≈ 4.3d。Ghadimi & Lan（2013）與 Duchi 等人（2015）的結果都指出：最壞情況下，零階方法的查詢複雜度比一階方法多一個與 d 相關的因子。

一個 512×512 的權重矩陣就有 262,144 維。要讓估計方向的 cos 達到 0.9，大約要 110 萬次評估，這還只是一層。所以「零階方法不能訓練大網路」曾經是共識。過去十年的進展，可以看成三條把有效維度 d 變小的路。

Dust 論文把自己的估計量和 backprop 梯度的夾角配適成 cos(K) = cmax / √(1 + c/K)，各種層的誤差都低於 0.06。這和上面的經典公式形式完全相同：c 就是有效維度，Dust 的貢獻是把 c 壓到族群負擔得起的範圍；cmax 小於 1，反映 token 之間互相干擾造成的上限。

04歷程

從 1952 到 2026 年 10 月

七十年的時間線可以分成四段：經典理論打底、2023 年 MeZO 打開微調、2024 到 2026 年的子空間與演化策略擴展，以及 2026 年秋天 Dust 與 Noise 把戰場推到預訓練。

    05Dust · Q Labs · 2026 年 10 月

    把雜訊從權重搬到激活值

    權重空間的演化策略（例如 EGGROLL）每個族群成員都要一份擾動過的權重，各自跑一次前向，成本跟族群大小成正比。Dust 改成擾動每層的輸出，而且每個 token 各自一份雜訊，一次前向就評估幾千個成員。

    Attention 內部的 Q、K、V 與 gate 另外擾動，用「和 attention 輸出估計誤差的對齊程度」計分。只有 2L 個殘差混合純量還是用權重空間 ES。為了省計算，Dust 快取乾淨前向的激活值，擾動第 l 個 block 時只重跑 l 之後；LM head 直接在快取的 logits 上擾動；不同層類型分開跑，各自有自己的 σ。

    論文的主要結果

    對 backprop（SGD）：100k 與 1M tokens 下，Dust 用幾百到一千個 draws 就低於 backprop。20M tokens 的 power-law 外推極限是 4.431（95% 區間 3.89 到 4.58），backprop 是 4.633。作者自己說這個配適約束很鬆。

    對 EGGROLL：EGGROLL 用 16k draws 仍追不上 Dust 的 64 draws，這是實測。外推的效率差距是 10³ 到 10⁴ 倍。

    改用 Adam：1M tokens 的外推極限 5.248 對 backprop 5.361；但 Noise 的實測顯示 Dust + Adam 仍落後 backprop + Adam。前者是外推，後者是實測，讀的時候要分清楚。

    作者自己承認的限制：計算效率還差好幾個數量級，才可能成為實用的替代方案；20M 的結果是外推的；超參數部分針對預算調過；大多數實驗用 SGD；為什麼 Dust 有時候比 backprop 好（可能是隱式探索曲率）還不清楚。

    07技術地圖

    Noise 的進步來自四種東西

    真正的躍進不是更好的隨機估計量，而是換掉要估計的目標：接受一點偏差，換來零變異的精確量測。這和微調世界裡子空間零階方法的邏輯一致。

    估計量降變異

    • 正交 Hadamard draws每個 token 的 draws 取正負號翻轉的 Hadamard 行，K 個 draw 精確還原 K 個方向。
    • 座標差分 head每個 token 的損失只取決於自己的 logits，一次對全部 logit 做中央差分，沒有取樣變異。
    • 只抖動活著的單元relu 輸出為 0 的單元 credit 必為 0，不浪費 draw。
    • Associative credit memory用過去的估計擬合 ridge regression，當 control variate。期望不變，變異下降。
    • Exact valuesattention 對 value 是線性的，直接用解析解。

    10M track 1：4.167 → 3.991

    換估計目標

    • Boost每個子層只負責降低共享 head 直接讀它後面那段殘差流的損失，像 logit lens 加上 gradient boosting。
    • Cut把 attention 輸出固定在乾淨值，每個 token 成為獨立實驗；重跑時 MLP 只保留貢獻最大的單元。
    • Identity-path credit只在最上層量一次 credit，沿殘差路徑（只經過線性的混合純量）傳給每個 block。
    • Own queries、first hop、future-token probes用額外的前向實驗補回 Cut 損失的跨 token credit。

    10M track 1：3.991 → 3.707，越過 backprop + Adam

    最佳化器與排程

    • ANVIL II移植自 modded-nanogpt PR #360 的 Muon 系最佳化器，快慢雙 momentum 與 quintic cascade，對雜訊方向較不敏感。
    • End merge保留 9 條權重 EMA，訓練結束後對每個參數各挑最好的合併方式，用保留的訓練序列評分。
    • Drift Leap、structured start提早停再沿權重漂移跳一步；把 block 1 的 heads 初始化成 lag-1 RoPE heads。

    10M track 2：13.1 s 之後多數紀錄來自排程

    系統工程

    • KernelTriton 與 Pallas 融合 kernel、moment kernel、torch.compile max-autotune、CUDA graphs。
    • 分散JAX 移植、token 分片到各 GPU、非同步 all-to-all、bf16 傳輸、通訊與計算重疊。

    PR #44：每個 Cut row 從 0.51 秒降到 0.050 秒，每項改動都檢查 cos ≥ 0.9998

    08規則邊界

    這些紀錄還算零階嗎？算一半。

    Noise 禁止任何 autograd 與手寫 backward。每個誤差訊號都要用前向對損失量出來，量到之後最多只能再穿過一次非線性部件。穿過線性映射不計次數，但訊號不能一個 block 接一個 block 串回去。

    所以這些方法的源頭確實是前向量到的損失差（零階 oracle），但 credit 會經過線性映射的轉置往下傳，再做一次精確的局部非線性步驟。數學上等於「backprop 只穿過線性部分，非線性部分用有限差分取代」，是一種混合式的局部學習。

    好處是有效、變異低。代價是：一旦網路含有真正不可微、或線性結構未知的部件，這些技巧就不見得能用。這也是 Noise 規則用「精神」判定的原因。比較準確的稱呼是 measured-credit local learning，不要和 MeZO 那種純黑盒零階方法混為一談。

    09實驗堆疊

    動手重現需要什麼

    微調和預訓練是兩套很不一樣的堆疊。微調看任務準確率與記憶體，預訓練看固定預算下的驗證損失與時間。

    五個常見陷阱

    一定要用 prompt 模板

    ZO-Bench 顯示，拿掉模板後零階方法在 SST-2 和 RTE 上分別掉約 10% 和 8%，一階方法幾乎不受影響。

    最佳化器狀態會吃掉記憶體優勢

    在 OPT-13B 上，ZO-SGD 需要 64GB，ZO-Adam 需要 158GB，比 backprop 的 FO-SGD（148GB）還多。

    比較要對齊成本

    零階方法常需要多數十倍的步數。用相同前向次數、wall-clock 或峰值記憶體比較，才是公平的。Noise 目前沒有 FLOPs 對等的賽道，issue #43 提議新增。

    單一 seed 的雜訊比你想的大

    PR #25 用 5 個 seed 跑出 4.163 ± 0.016，這個標準差跟某些紀錄之間的差距同一量級。節點之間的計時也有約 6% 的差異。

    Backprop 基準調得多好，決定了結論

    PR #25 的作者重現不出 README 的 3.769，自己調的 backprop 跑完 10M 是 3.952。spicylemonade 的 boost-cut repo 報告同設定 backprop 3.706 ± 0.009，Boost → Cut 3.935 ± 0.012。社群各方的 backprop 數字介於 3.706 與 3.952。

    10現況比較

    零階方法今天走到哪裡

    在「記憶體與系統」這一維，零階方法明確勝出。在「每單位計算換到多少精度」這一維，它仍然輸給反向傳播。

    面向微調 · MeZO 系預訓練 · Dust / NoiseBackprop
    記憶體約等於推論，最多省 12 倍Dust 要快取乾淨前向；Noise 的方法仍需保存激活值激活值、梯度與最佳化器狀態
    品質OPT-13B 上 11 個任務有 7 個追平或勝過完整微調；困難任務落後 5–6%37.7M：社群方法 3.409，略優於 Adam 的 3.419，輸給 ANVIL II 的 3.340；原版 Dust 3.767基準
    計算效率步數多數十倍，每步只要 2 次前向Dust 需要多個數量級的計算；尚無 FLOPs 對等比較最有效率
    規模證據最大 66B（微調）；ZO2 在 18GB GPU 上微調 OPT-175BDust 論文 243M；Noise 37.7M兆參數
    不可微目標可以，直接最佳化準確率或 F1原版 Dust 可以；Noise 的混合方法部分依賴線性結構需要代理目標
    理論有效秩解釋cos(K) 經驗律，沒有收斂理論完備

    給工程師的建議：GPU 記憶體夠跑 backprop + LoRA，就繼續用。只有在記憶體只夠推論、硬體只支援前向、需要聯邦或端側訓練、或目標不可微時，才改用零階方法，並搭配 LoRA 或子空間版本。Dust 與 Noise 目前是研究題目，不是生產級的預訓練方案，作者自己也這麼說。

    11未來趨勢

    接下來值得盯的六件事

    Q Labs 自己的評估很誠實：大多數紀錄只是在前一筆上精修，並且針對這一個設定調校。可擴展的進步要靠更有創意的方法。

    規模

    放大到 250M 參數以上

    Noise 已從 10M 擴到 30M tokens，並預告會繼續提高門檻。Cut、identity path 這類針對單一設定調校的技巧，能不能在更深的模型上撐住，是下一個關鍵。

    最佳化器

    與估計量共同設計

    ANVIL II 這類正交化最佳化器特別適合雜訊估計。微調端的 ZO-Muon、StructZO 得出同樣結論。預期會出現專為有偏、低秩 credit 設計的最佳化器。

    架構 · Track 3

    讓前向實驗更乾淨的模型

    PR #45 的 quarter-turn context tap 是第一個訊號。更強的殘差解耦、更好量 credit 的 attention，都可能出現。

    硬體

    低精度、類比與 neuromorphic

    EGGROLL 已在整數 RNN 上做預訓練，也有人用低秩 ES 從頭訓練 spiking 網路，QScheduler 在 INT8 NPU 上做端側訓練。這是最可能先落地的地方。

    不可微

    外部程式與迴圈計算

    Dust 作者點名兩個方向：迴圈內有外部程式的網路，以及 BPTT 難以訓練的 looped transformer。這是零階方法相對 backprop 有本質優勢的地方，目前還沒有任何實驗。

    理論

    補上缺口

    需要 attention 耦合下 per-token node perturbation 的偏差與變異分析、Boost 與 Cut 這類換目標方法的收斂保證，以及解釋為什麼大族群的 Dust 有時反而比 backprop 好。

    12讀數字

    看到「快 4,000 倍」時，先問三件事

    這個領域變化很快，頭條數字往往省略了比較條件。

    1

    哪一個賽制？

    4,000× 是已封存的 10M 賽制：1 h 46 min 降到 1.6 s。現行 30M 賽制的對應進步是 1 h 43 min 降到 8 min 20 s。

    2

    目標損失多少？

    10M speedrun 的目標是 4.2，比 backprop + Adam 能達到的 3.769 寬鬆很多。目標越寬鬆，越容易跑出驚人的倍數。

    3

    跟哪一個 backprop 比？

    3.409 對 Adam 的 3.419 算贏；對 ANVIL II 的 3.340 就輸了。而且 3.409 是社群疊出來的方法，不是原版 Dust。

    其他要記得的限制

    • Noise 所有官方紀錄都只用 seed 0。
    • 規模很小：Noise 固定 37.7M 參數、30M tokens；Dust 最大 243M 參數，訓練最多 20M tokens。
    • Dust 的 10³–10⁴ 倍效率、20M 的 4.431 極限、Adam 下的 5.248 極限，都是 power-law 外推值。
    • 沒有經過同儕審查：Dust 是 Q Labs 的網頁論文，Noise 紀錄是 GitHub PR，PR #45 尚未合併。截至本文，還沒有正式論文引用 Dust 或 Noise。
    • 多個 PR 標示由程式助手協作產生；boost-cut 的論文草稿也標明由 LLM 撰寫、仍在審查中。
