No. 9 Lafa：block 內平行生成的連續 flow 語言模型
    No. 9 · 互動教學 · arXiv 2610.28559

    Lafa：把預訓練語言模型改成 block 內平行生成的連續 flow

    這篇論文讓 block 之間照 AR 順序、block 內的 token 從噪聲經連續的逐步變換（flow）一起生成，並用同一個模型的 AR 預測驗證一步草稿。

    Arnav Chavan、Chanhyuk Lee、Udbhav Bamba、Jaehoon Yoo、Seunghoon Hong、Aditi Raghunathan、Jinwoo Kim（2026）〈Large Flow Language Models〉

    左：乾淨的 prefix（實線框，時間固定為 1）。右：一個 block 的三個位置（虛線框），灰階越深表示 τ 越接近 1，也就是越接近乾淨的詞嵌入；下方數字是各位置的 τ（示意值）。prefix 取自論文 Fig. 2。

    01 · 生成方式

    文字切成長度固定的 block：block 之間照 AR 順序生成，block 內的 token 從高斯噪聲出發，經過連續的逐步變換（解一個常微分方程）一起變成詞嵌入。

    02 · 訓練方式

    模型不從零訓練：把預訓練的 AR 模型（Qwen2.5 0.5B／7B、Qwen3 8B）改成同時做 AR 預測與 block 去噪，訓練資料少於 300 億 tokens。

    03 · 最快的模式

    最快的模式是 flow 一步寫草稿、同一個模型的 AR 預測逐字驗證。輸出與 greedy AR（每步取機率最大的 token）相同，7B 每秒產生的 token 數（吞吐量）是 AR 的 2.54 倍。

    01 · Block-AR 分解

    Block 之間自迴歸，block 內平行

    自迴歸（autoregressive，AR）語言模型給定前文，輸出下一個 token 的機率分布。greedy decoding 每一步取機率最大的 token，接到前文後再做下一次 forward，所以一次 forward 只產生一個 token。為了不重算前文，實作上把已處理位置的 key/value 存起來，稱為 KV cache；只要這些位置的表示不隨後續輸入改變，KV cache 就能一直重用。

    Lafa 保留這個結構，只把平行放進固定長度的 block。記 prefix（已知文字）為 $c\in V^N$、續寫為 $y\in V^M$，block 大小為 $B$（假設 $B\mid M$）。論文把續寫的機率寫成 block 的連乘（Sec. 2.1）：

    $$p(y\mid c)=\prod_{r=0}^{M/B-1}p\big(y_{rB+1:(r+1)B}\mid c,\,y_{\le rB}\big)$$
    Eq. 1

    這是機率的連鎖律，沒有任何近似。block 之間仍照 AR 順序：第 $r$ 個 block 以 prefix 與前面所有 block 為條件。平行只發生在 block 內，$B$ 個 token 一起生成。因為 block 之間維持 causal，前面的 token 與它們的表示不會因為後面的 block 改變，所以 prefix 的 KV cache 可以沿用。同樣的分解也用在 block-autoregressive 模型 [22] 與 block discrete diffusion [23]。

    剩下的問題是 block 內的 $B$ 個 token 怎麼一起生成。Lafa 的做法是在詞嵌入空間中從高斯噪聲出發，解一個常微分方程（第 02 節）。

    第一個 block（y₁–y₃）生成後併入 prefix，第二個 block 的三個位置再一起生成。這裡三個位置共用同一個時間 0.5（同步）。

    02 · 嵌入空間的 flow

    每個 block 的嵌入從高斯噪聲經 ODE 積分到資料的嵌入

    Lafa 不直接在離散的 token 上生成，而是在詞嵌入空間生成。一個 block 的乾淨資料是 $B$ 個 token 的嵌入疊成的矩陣 $x_1:=(\E_{y_1},\dots,\E_{y_B})^\top\in\mathbb R^{B\times d}$。直接前作 Flow Map Language Models [13] 用長度 $\lvert V\rvert$ 的 one-hot 向量；改用維度 $d$ 的嵌入是設計選擇，論文寫這是為了讓訓練更可擴展（"making training more scalable"）。

    Flow matching [24, 25] 的做法：從噪聲 $x_0\sim\mathcal N(0,\sigma^2I)$ 到資料 $x_1$ 定義一條內插 $I_t$。標準形式是 $I_t=(1-t)x_0+tx_1$，$t=0$ 為噪聲、$t=1$ 為資料，所有 token 共用同一個 $t$。速度場定義為內插速度的條件期望 $b_t(x)=\Ex[\dot I_t\mid I_t=x]$。從 $x_0$ 沿下面的常微分方程（ODE）積分到 $t=1$，終點的分布就是資料分布：

    $$\dot x_t=b_t(x_t;c),\quad x_0\sim p_0,\quad x_t\sim p_t(\cdot\mid c)$$
    Eq. 3

    Lafa 讓 block 內每個位置有自己的時間。逐位置時間（tokenwise time）是函數 $\tau:[0,1]\to[0,1]^B$，位置 $i$ 在 base time $t$ 的進度是 $\tau^i(t)$。內插改寫成：

    $$I_t^i:=(1-\tau^i(t))\,x_0^i+\tau^i(t)\,x_1^i,\quad i\in[B]$$
    Eq. 2

    $\tau$ 要滿足的條件：每個分量 $\tau^i$ 可微且遞增，$\tau(0)=0$、$\tau(1)=1$（Sec. 2.1）。App. A.2 的證明另要求 $\tau^i\in C^1$，且 $t<1$ 時 $\dot\tau^i>0$，也就是嚴格遞增。若 $i<j$ 時 $\tau^i(t)>\tau^j(t)$，較前的位置比較接近資料，會先被還原。速度場 $b_t(\cdot;c)$ 的存在引用 [27]，論文不另外證明。

    論文的動機（Sec. 2.1）：「To introduce a left-to-right bias within each block to match the inherent directionality of text [19], we use tokenwise time [26–30], allowing earlier positions to progress faster.」先例 [26–30] 包含 Learning When to Denoise、Token Time Continuous Diffusion、AR-Diffusion；相近的想法還有 Diffusion Forcing。要注意：動機是由左到右，但 $\tau$ 的實際形狀是訓練中由 loss 學出來的（第 05 節），論文沒有把 $\tau^i>\tau^j$ 設成約束。

    03 · Denoiser 與速度

    預測 token 機率就能得到速度

    $\hat D$ 是 transformer 的輸出，第 04 節說明怎麼由 AR 模型改成；本節先把它當成給定的函式。C1 用玩具的精確 $D$（由高斯似然算出的後驗），不是神經網路。

    理想的 block denoiser 是：給定 prefix 與整個 block 的目前狀態 $x$，位置 $i$ 的 token 的後驗分布，是長度 $\lvert V\rvert$ 的機率向量：

    $$D_t(x;c)^i:=p(y_i=\cdot\mid c,\,I_t=x)\in\Delta^{\lvert V\rvert-1}$$
    Eq. 4

    論文證明速度可以完全由它換算（Prop. A.1）：

    $$b_t(x;c)^i=\frac{\dot\tau^i(t)}{1-\tau^i(t)}\big(D_t(x;c)^i\E-x^i\big),\quad t\in[0,1)$$
    Eq. 5

    推導的關鍵有兩步。第一，由 Eq. 2 解出噪聲 $x_0^i=(I_t^i-\tau^ix_1^i)/(1-\tau^i)$，得到 $x_1^i-x_0^i=(x_1^i-I_t^i)/(1-\tau^i)$，所以內插的速度 $\dot I_t^i=\dot\tau^i(x_1^i-x_0^i)$ 只依賴乾淨嵌入與目前狀態。第二，$x_1^i=\E_{y_i}$，所以取條件期望時 $\Ex[x_1^i\mid c,I_t=x]=\sum_v p(y_i=v\mid c,I_t=x)\E_v=D_t(x;c)^i\E$。機率向量乘上嵌入矩陣就是期望嵌入：例如 $D^i$ 在兩個 token 上各有 0.5 時，$D^i\E=\tfrac12(\E_{v_1}+\E_{v_2})$。分母 $1-\tau^i$ 在 $t\to1$ 時趨近 0，所以命題限定 $t\in[0,1)$。

    完整推導（Prop. A.1）
    1. 對 Eq. 2 微分：$\dot I_t^i=\dot\tau^i(t)(x_1^i-x_0^i)$（Eq. 11）。
    2. 由 Eq. 2 解出 $x_0^i=(I_t^i-\tau^ix_1^i)/(1-\tau^i)$，所以 $x_1^i-x_0^i=(x_1^i-I_t^i)/(1-\tau^i)$。
    3. 取條件期望 $b_t(x;c)=\Ex[\dot I_t\mid c,I_t=x]$：$b^i=\frac{\dot\tau^i}{1-\tau^i}\big(\Ex[x_1^i\mid c,I_t=x]-x^i\big)$。
    4. $x_1^i=\E_{y_i}$，所以 $\Ex[x_1^i\mid c,I_t=x]=\sum_v p(y_i=v\mid c,I_t=x)\E_v=D_t(x;c)^i\E$（Eq. 12），代回即 Eq. 5。

    這個式子有三個重點。條件是整個 block 的 $x$，所以位置 $i$ 的速度透過 $D$ 依賴其他位置；但只需要每個位置的邊際後驗，不需要聯合分布；係數只用該位置自己的 $\tau^i$。

    生成時在 base time 網格 $t_k=k/K$ 上走 $K$ 步，$p_k:=\hat D_{t_k}(\hat x_{t_k};c)$ 是第 $k$ 步的 denoiser 輸出：

    $$\begin{gathered}\hat x^i_{t_{k+1}}=\hat x^i_{t_k}+\frac{\tau^i(t_{k+1})-\tau^i(t_k)}{1-\tau^i(t_k)}\big(p^i_k\E-\hat x^i_{t_k}\big)\\ \hat y_i=\arg\max(p^i_{K-1})\end{gathered}$$
    Eq. 8

    生成的 token 是最後一次 denoiser 預測的 argmax，不是把 $\hat x_1$ 找最近的嵌入。〔本頁推導〕Eq. 8 是 tokenwise time 上的精確步：假設 denoiser 輸出在這一步內不變，ODE 的解正好是 Eq. 8。它不是 base time 的 Euler 步 $x+\Delta t\,b_t$。最後一步 $\tau=1$，$\hat x=p\E$，不會碰到 $1/(1-\tau)$ 的發散。

    推導：Eq. 8 是常數 denoiser 下的精確解〔本頁推導〕

    把 Eq. 8 改寫為 $\hat x_{k+1}=\frac{1-\tau_{k+1}}{1-\tau_k}\hat x_k+\frac{\tau_{k+1}-\tau_k}{1-\tau_k}p_k\E$。若在 $[t_k,t_{k+1}]$ 內 $D\equiv p_k$，Eq. 5 的 ODE 對 $\tau$ 寫成 $\frac{dx}{d\tau}=\frac{p_k\E-x}{1-\tau}$，解為 $x(\tau)=p_k\E+(x_k-p_k\E)\frac{1-\tau}{1-\tau_k}$，代入 $\tau_{k+1}$ 即上式。它與 Eq. 7 同形；論文在 Eq. 9 前也說 flow map 是把 $\hat D_{t_k}$ 換成 $\hat\delta_{t_k,t_{k+1}}$。

    $K=1$ 時，因為 $\tau^i(0)=0$、$\tau^i(1)=1$，Eq. 8 退化成一次 denoiser 計算（Eq. 10）：$p^i=\hat D_0(\hat x_0;c)^i$，$\hat x_1^i=p^i\E$，$\hat y_i=\arg\max p^i$。

    〔本頁推導〕$t=0$ 時 $I_0=x_0$ 是純噪聲，與 $y$ 獨立，所以理想的 $D_0(x_0;c)^i=p(y_i\mid c)$：各位置獨立的邊際，噪聲不帶任何資訊。各位置分別取 argmax，可能組出聯合機率為 0 的序列。論文的說法是「One-step drafts can be inconsistent across positions」（Sec. 2.3）。下面的玩具中，prefix 固定時 $p(\text{hot dog})=0.4$、$p(\text{ice cream})=0.3$、$p(\text{sour cream})=0.3$。位置 1 的邊際 argmax 是 hot（0.4），位置 2 的邊際 argmax 是 cream（0.3 + 0.3 = 0.6），所以一步得到機率為 0 的「hot cream」。步數增加後，後面的步驟看得到已部分成形的另一個位置，樣本落在有支撐的組合，頻率也接近先驗。

    04 · 從 AR 模型調整

    預訓練 AR 模型改成 block denoiser

    作者不從零訓練，而是把預訓練 AR transformer $f$（Qwen2.5 0.5B／7B Instruct、Qwen3 8B Base）改成 block denoiser。輸入是嵌入後的 prefix $c$ 接上 noisy block $x$。Sec. 2.2 有四個改動：

    1. Tokenwise time conditioning。每個位置以 adaLN [31]（依時間縮放與平移每層的特徵）接收自己的時間：prefix 恆為時間 1（無噪聲），block 位置 $i$ 為 $\tau^i(t)$。adaLN 初始化為恆等，所以剛加入時間條件時，模型的計算與預訓練模型相同。加上時間條件的模型記為 $f_t(x;c)$。
    2. Block-bidirectional attention（Fig. 3）。block 內雙向；block 位置可看整個 prefix；prefix 維持 causal，且看不到 noisy block [32, 33]。雙向優於 causal（Table 3：38.0 vs 32.7）。
    3. 共享且受約束的嵌入。見下一段。
    4. 平行訓練（Fig. 4、Alg. 1）。見 C2 之後的段落。

    前兩點合起來：prefix 以 adaLN 固定在時間 1、attention causal 且不看 noisy block，所以 prefix 的 K/V（key 與 value）與 block 狀態 $(x,t)$ 無關，可以跨 denoising 步與後續 block 重用。prefix 的輸出也保留 AR 角色：$f_t(x;c)_i$ 預測 $c_{i+1}$（$i<N$），$i=N$ 時預測 $y_1$，記為 $f(c)_i$，也就是 AR 預測 $f(c)$。

    05 · 學出 tokenwise time

    Tokenwise time 是 loss 的反累積分布

    tokenwise time 的形狀由 loss 決定（Sec. 2.2、App. B.1），靈感來自 CDCD [12] 的 loss-aware time warping，差別是每個位置分開做。記 $\ell^i(\tau)>0$ 為位置 $i$ 在 tokenwise time $\tau$ 的期望 denoising CE：

    $$\tau^i(t):=F_i^{-1}(t),\qquad F_i(\tau):=\frac{\int_0^\tau\ell^i(r)\,dr}{\int_0^1\ell^i(r)\,dr}$$
    Eq. 22

    $\tau^i=F_i^{-1}$，$F_i$ 是 $\ell^i$ 的正規化累積分布。論文寫「$\dot\tau^i\propto1/\ell^i(\tau^i)$ is small where the loss is high」：loss 高處 $\tau$ 的增加率小，所以訓練時均勻取樣的 $t$ 與推論時均勻的 $t$ 網格，都集中在最難的噪聲程度。〔本頁推導〕對 $F_i(\tau^i(t))=t$ 微分得 $\dot\tau^i(t)=\big(\int_0^1\ell^i\big)/\ell^i(\tau^i(t))$；等價地說，$t\sim U[0,1]$ 時 $\tau^i(t)$ 的密度正比於 $\ell^i$。$\ell^i>0$ 保證 $F_i$ 嚴格遞增、$\tau^i(0)=0$、$\tau^i(1)=1$。

    $\ell^i$ 的估計方式（Alg. 2）：矩陣 $L\in\mathbb R^{B\times M_{\text{bin}}}$，$M_{\text{bin}}=200$ 個等寬格，均勻初始化；每 $S=100$ 個訓練步做四次無梯度 forward，每個 noisy block 各自獨立抽均勻時間，再以 EMA 更新：

    $$L_{i,m}\leftarrow\beta L_{i,m}+(1-\beta)\bar L_{i,m},\qquad\beta=0.99$$
    Eq. 23

    $\bar L_{i,m}$ 是這一輪落在位置 $i$、第 $m$ 格的 denoising CE 平均；沒被訪問的格保留原值。$F_i$ 取正規化列 $L_{i,:}$ 的分段線性 CDF。論文說明各 block 獨立抽時間的理由：「This independent uniform estimation prevents the learned sampling distribution from starving low-probability regions」（App. B.1）。另外，Alg. 2 的虛擬碼用同步內插 $(1-t)x_0+tx_1$ 估計 $\ell^i$，論文沒有說明為何不用訓練時的非同步內插。

    結果：學到的時間「generally satisfy $\tau^i(t)>\tau^j(t)$ for $i<j$」（Fig. 5，Lafa 7B，16 個位置）。由左到右的順序是學出來的，不是人工設定；論文沒有給出機制解釋，也沒有 Fig. 5 的數值。消融中同步時間 36.2、非同步 38.0（Table 3）。

    07 · Flow map

    Flow map 把多步積分換成一次跳躍

    Flow decoding 每個 block 要做多次 denoiser 計算；第 03 節的玩具顯示，一步 denoiser 只能給出各位置的邊際。Flow map $X_{s,t}$ 直接把時間 $s$ 的狀態送到時間 $t$ [38]。作者把 Flow Map Language Models [13] 的 simplex 值 two-time denoiser 推廣到詞嵌入上的非同步 flow：

    $$X_{s,t}(x;c)^i:=\frac{1-\tau^i(t)}{1-\tau^i(s)}x^i+\frac{\tau^i(t)-\tau^i(s)}{1-\tau^i(s)}\,\delta_{s,t}(x;c)^i\E,\qquad 0\le s<t\le1$$
    Eq. 7

    $\delta_{s,t}(x;c)^i$ 是 two-time denoiser：輸出一個機率向量，經 $\E$ 後與 $x$ 內插。它與 Eq. 8 同形，只是把一步內不變的 $p_k$ 換成 $\delta$。用字面說：$\delta$ 是沿路 denoiser 預測的加權平均，越接近終點權重越大。

    設定與假設（App. A.2）：$c$、$\E$、$\tau$ 固定；$\tau^i\in C^1$，$t<1$ 時 $\dot\tau^i>0$；ODE 解唯一；denoiser 對時間連續可微；在 $0\le s\le t<1$ 上討論，$t=1$ 以極限理解。在這些假設下，Prop. A.2 說：學到的 $\delta$ 經 Eq. 7 等於真正的 flow map，若且唯若它滿足兩個條件：

    • diagonal：$\delta_{s,s}=\hat D_s$，時間不動時，two-time denoiser 就是一般的 denoiser。
    • semigroup：對 $s<u<t$，從 $s$ 跳到 $t$ 等於先跳到 $u$ 再跳到 $t$ 的組合：
    $$\begin{aligned}\delta_{s,t}^i&=\gamma^i\delta^i_{s,u}+(1-\gamma^i)\,\delta_{u,t}(X_{s,u})^i\\ \gamma^i&=\frac{(1-\tau^i_t)(\tau^i_u-\tau^i_s)}{(1-\tau^i_u)(\tau^i_t-\tau^i_s)}\end{aligned}$$
    Eq. 16

    這裡 $\tau^i_t$ 是 $\tau^i(t)$ 的簡寫。$0\le\gamma^i\le1$，所以組合仍是機率向量。反方向也成立：任何滿足 diagonal 與 semigroup 的 $\delta$，經 Eq. 7 得到的就是真正的 flow map（$X_{s,s}=\mathrm{Id}$、切線條件、semigroup [38]）。

    〔本頁推導〕為什麼一步 flow map 能保留位置間關聯：$t\to1$ 時 $Z_{s,t}\to\infty$、$\gamma^i\to0$，權重集中在軌跡終點，所以 $\delta_{0,1}(x_0)$ 是沿整條軌跡的加權平均、權重集中在終點，等於 ODE 終點 token 的 one-hot；$X_{0,1}(x_0)$ 一步就得到與多步積分相同的聯合結果。對照第 03 節，$\hat D_0$ 只是各位置的邊際，所以一步 denoiser 不能保留位置間關聯。以上是對理想的 teacher $\delta$；學到的 $\hat\delta$ 仍有差距（Table 5：7B 一步 flow map 49.0，多步 flow 75.9）。

    08 · 自我推測解碼

    自我推測解碼用 AR 驗證一步草稿

    自我推測解碼（self-speculative decoding）用同一個模型做兩件事。草稿：一步 Euler（Eq. 10）產生 $B$ 個 token $\hat y_{1:B}$，不用 prefix guidance。驗證：commit 與 greedy AR 預測一致的最長草稿前綴；第一個 token 不一致時改 commit $\arg\max f(c)_N$。第一個 token 可以免費驗證（與已有的 AR 預測比）。其餘位置的接受長度是：

    $$a=\max\{\,j\in[B]:\ \hat y_{i+1}=\arg\max f(c\oplus\hat y)_{N+i}\ \ \forall\,1\le i<j\,\}$$
    Eq. 28

    $j=1$ 的條件是空的，所以 $a\ge1$：每次至少 commit 一個 token。

    為什麼輸出等於 greedy AR〔本頁推導：補上歸納步驟，論文只陳述結論〕：被接受的 $\hat y_{i+1}$ 等於以 $c\oplus\hat y_{1:i}$ 為 prefix 的 greedy AR 預測；prefix 為 causal，$f(c\oplus\hat y)_{N+i}$ 只依賴 $c\oplus\hat y_{1:i}$；而 $\hat y_{1:i}$ 已歸納地等於 greedy AR 輸出。所以被接受的 token 都等於以已接受前綴為條件的 greedy AR 預測，2.54× 的品質就是該 checkpoint 的 greedy AR 品質，flow 只當草稿器。這是邏輯上的等價；數值上取決於實作，例如 bfloat16 下 fused forward 與逐字 forward 的 batch 形狀不同，logits 可能有微小差異並影響同值處理。論文原話為「matches greedy AR decoding」。

    Fused forward（Alg. 4、Fig. 9）讓驗證與下一份草稿在同一次 forward 完成。輸入是乾淨 prefix $c\oplus\hat y$（時間 1）加上 $B$ 個噪聲 block $z^{(1)},\dots,z^{(B)}\in\mathbb R^{B\times d}$（時間 0，各自 $\sim\mathcal N(0,\sigma^2I)$）。$c\oplus\hat y$ 內 causal；$z^{(j)}$ 看 $c\oplus\hat y_{1:j}$、block 內雙向、block 之間互不可見。驗證得到 $a$ 後，取 $z^{(a)}$ 的輸出當下一份草稿（計算上等同 $D_0(z^{(a)};c\oplus\hat y_{1:a})$），並沿用 $f(c\oplus\hat y)_{1:N+a}$ 與 KV cache。第一個 token 被修正時只需一個噪聲 block。

    〔本頁推導〕每次 fused forward commit $1\le a\le B$ 個 token；新處理的位置數為 $B+B^2$（修正時 $1+B$），$B=16$ 時 272。本頁推測這是 TPF 4.9 只換到 2.54× TPS 的原因之一；論文沒有這個計數，只寫「forward-pass costs differ」。

    速度以 TPF 衡量（Eq. 29）：$\text{TPF}=\sum_jT_j/\sum_jF_j$，$T_j$ 為 commit 的 token 數，$F_j$ 為 fused forward 次數加 1 次初始草稿（不含 prompt prefill）。AR 的 TPF 定義為 1。

    背景（Sec. 4）：「Many parallel decoders predict tokens independently within an update, which can degrade」品質，部分方法以 AR 驗證草稿緩解。Lafa 也用 AR 驗證，差別在草稿來自同一模型的 flow。替代方案（App. C.3）是 confidence thresholding：接受信心 $\ge\lambda$ 的最長前綴，同樣 $a\ge1$；論文以 self-speculation 為預設，理由是它不需調門檻、低門檻時不退化。

    多步 flow 追上 AR，速度來自自我推測

    模型與資料：0.5B、7B 由 Qwen2.5 Instruct 調整；8B 用 Qwen3 8B Base（論文寫其 Instruct 版再訓練會退步）。訓練資料為 Dolci-Instruct-SFT。Sec. 3 寫訓練 5–15 epochs（9–27B tokens）；Table 4 對三個尺度都寫 5 epochs、約 9B tokens。論文沒有說明兩者的關係。合起來訓練用 9–27B tokens（<30B），論文寫這比 Dream、LLaDA、Efficient-DLM 的報告預算（reported budgets）少至少 18 倍（"at least 18× fewer"）。0.5B 做消融、7B 是主結果、8B 用來對比更多基準。

    常見錯誤

    1. 把 2.54× 當成 flow 生成的速度：它來自自我推測解碼，輸出等於 greedy AR。純 flow decoding 在 $B=4$、32–64 步時，0.5B 接近（38.1、38.5 vs 38.6）、7B 超過（75.2、75.9 vs 73.9）AR SFT（Table 5）。
    2. 用「最近的嵌入」把 $\hat x_1$ 轉回 token：Eq. 8 取最後一次 denoiser 預測的 argmax。
    3. 讓 prefix 看到 noisy block，或給 prefix 1 以外的時間：prefix 的 KV 會隨 $(x,t)$ 改變，cache 失效，AR 預測也不再是 $f(c)$。
    4. 不固定嵌入 norm：norm 相對固定的 $\sigma$ 膨脹，有效 corruption 下降（Table 3）。
    5. 把 Eq. 8 寫成 base time 的 Euler $x+\Delta t\,b_t$：Eq. 8 用 $\tau$ 的增量，最後一步落在 $p\E$，不會碰到 $1/(1-\tau)$ 的發散。
    6. 推論沿用訓練的 $\sigma$：Table 4 訓練 4.0、flow decoding 推論 0.1，論文未解釋差異；自我推測草稿的 $\sigma$ 未寫明（Alg. 4 只寫「scale $\sigma$」）。
    7. 在自我推測草稿加 prefix guidance：論文的草稿不用 guidance；flow decoding 才用 $g=8$。
    8. 以為 tokenwise time 用訓練時的非同步內插估計：Alg. 2 的虛擬碼用同步內插估 $\ell^i$（論文未說明理由）。

    論文未說明的細節：flow map 蒸餾的 $(s,u,t)$ 分布與訓練量；不含 prefix 的 $D_t(x;\varnothing)$ 如何訓練；輸出 head 是否與 $\E$ 綁定（tied）。

    11 · 研究脈絡

    研究脈絡

    Lafa 接在幾條線的交會點上：AR 的平行解碼（blockwise parallel decoding、Medusa、multi-token prediction）先提出「一次預測多個 token 再驗證」；flow matching 與 CDCD 把連續擴散帶到類別資料，CDCD 也提出 loss-aware time warping；block diffusion 把 block 內去噪與 block 間因果結合；AR 轉擴散的工作（Dream、Efficient-DLM，筆記另列 From Next-Token to Next-Block 與 WeDLM）從預訓練 AR 模型出發；flow map 與 two-time denoiser 讓少步生成成為可能；同期的 ELF 也在詞嵌入空間做 flow。Lafa 把這些放進同一個從 AR 調整而來的模型。每張卡片連到對應的研究筆記。
