No. 255 Reasoning with Sampling
    No. 255 · 互動教學 · arXiv 2510.14901 · 2025

    不訓練，只取樣：從 base model 的冪分佈取樣做推理

    這篇論文只用既有模型自己給的機率挑選回答，不再訓練，單次作答的準確率接近經過強化學習後訓練的模型（後文說明）。

    Aayush Karan、Yilun Du（2025）〈Reasoning with Sampling: Your Base Model is Smarter Than You Think〉

    01 · 取樣目標

    base model 指作為取樣對象、不再訓練的既有語言模型，它對每條回答序列 x 給出機率 p(x)。本文的取樣目標是 p(x)α（α 是大於 1 的冪次，論文用 4），它使機率較高的回答得到更大的相對權重。

    02 · 和低溫取樣不同

    常用的低溫取樣在每一步把下一個 token 的機率取 α 次方再重新正規化。這和對整條序列的機率取 α 次方得到的分佈不同（03a 節用一個兩 token 的例子說明）。

    03 · 反覆重取

    直接從 p(x)α 取樣需要對所有可能序列加總，無法計算。作者改為反覆執行：隨機選一個位置，從該位置重新生成到目前區塊結尾，再依新舊序列的機率比值決定是否接受。這個方法的名稱、準確率與計算成本在後文說明。

    01a · 序列機率與溫度

    語言模型逐 token 給出序列的機率

    語言模型（LLM）把文字切成 token，詞彙表 $\mathcal X$ 是所有 token 的集合。一條序列寫成 $x_{0:T}=(x_0,x_1,\dots,x_T)$，$T$ 是最後一個位置的索引；$x_{\lt t}$ 表示位置 $t$ 之前的前綴，$x_{>t}$ 表示位置 $t$ 之後的後綴（§3）。模型在每個位置給出下一個 token 的條件分佈 $p(x_t\mid x_{\lt t})$，稱為 next-token 分佈。

    序列機率如何由 next-token 分佈得到：整條序列的機率等於各位置條件機率的連乘，$p(x_{0:T})=\prod_{t=0}^{T}p(x_t\mid x_{\lt t})$（式 1）。逐 token 取樣就是從這個聯合分佈取樣。一條序列的 $p$ 值稱為它的 likelihood，取對數後的和稱為 log-likelihood；長序列的機率連乘可能低於浮點數下限，實作時一律用 log-likelihood 相加。低溫取樣做什麼：低溫取樣在每一步把 next-token 機率 $p(x_t\mid x_{\lt t})$ 取 $\alpha$ 次方再正規化，對應的溫度是 $\tau=1/\alpha$（式 3）；$\tau$ 越小，每一步的分佈越集中在機率最高的 token。

    $$p(x_{0:T})=\prod_{t=0}^{T}p(x_t\mid x_{\lt t}),\qquad p_{\text{temp}}(x_t\mid x_{\lt t})=\frac{p(x_t\mid x_{\lt t})^\alpha}{\sum_{x'_t\in\mathcal X}p(x'_t\mid x_{\lt t})^\alpha}$$
    式 (1)(3)

    本文的 base model 指作為取樣對象、不再訓練的既有模型。實驗用的 Qwen2.5-Math-7B 與 Qwen2.5-7B 是預訓練模型；Phi-3.5-mini-instruct 是 instruct 版，已經過後訓練（Abdin 2024），論文沒有說明細節，但仍稱它為 base model。

    檢查理解

    序列機率如何由 next-token 分佈得到？低溫取樣做什麼？

    $p(x_{0:T})=\prod_t p(x_t\mid x_{\lt t})$（式 1）；低溫取樣每步把 $p(x_t\mid x_{\lt t})$ 取 $\alpha$ 次方再正規化，溫度 $\tau=1/\alpha$（式 3）。

    01b · RL 與銳化假說

    RL 後訓練與分佈銳化假說

    RL 後訓練用強化學習繼續訓練語言模型：模型生成回答，自動驗證器（例如比對數學題的最終答案）給出獎勵，再依獎勵更新參數。這類方法稱為 RLVR（reinforcement learning with verifiable rewards）。GRPO（Group Relative Policy Optimization）是其中常用的一種演算法，它對同一題取樣一組回答，以組內標準化後的獎勵作為更新權重；本頁不需要它的數學細節，只把它當作比較基準。

    近期文獻問：RL 後訓練學到的是 base model 原本不會產生的推理方式，還是只把 base model 的分佈變得更集中（§1）？後者稱為分佈銳化（distribution sharpening）假說。支持後者的觀察有兩項：RL 後模型的輸出集中在 base model 的高 likelihood 區域（Yue 2025）；以多次作答評分時，作答次數多時 base model 的分數較高（He 2025、Song 2025；這個多次作答指標稱為 pass@k，08 節定義）。

    作者的推論是：如果 RL 後訓練只是銳化，那麼應該能直接寫出一個「銳化後」的目標分佈，從 base model 取樣而不必訓練。這是動機與假說，本文沒有證明 RL 只做銳化。

    延伸閱讀：RLVR 與 GRPO：本文要對照的 RL 基準、分布銳化之爭：RL 後訓練是否只讓 base model 變尖

    02 · 冪分佈

    冪分佈把高機率序列的相對權重放大

    作者選擇的目標是冪分佈（power distribution）$p^\alpha$：每條序列的權重是 $p(x)^\alpha$，再對所有序列正規化（§4.1）。Eq. 2 說什麼：若 $p(x)>p(x')$，則 $p(x)^\alpha/p(x')^\alpha>p(x)/p(x')$，也就是高 likelihood 序列相對於低 likelihood 序列的權重比上升。本頁把「相對權重比依 Eq. 2 上升」稱為銳化。這個不等式需要 $\alpha>1$；論文寫的範圍是 $\alpha\in[1,\infty]$，但在 $\alpha=1$ 時兩邊相等，嚴格不等號不成立。

    $$p(x)>p(x')\ \Longrightarrow\ \frac{p(x)^\alpha}{p(x')^\alpha}>\frac{p(x)}{p(x')}$$
    式 (2)

    論文勘誤 E1 · 式 (2)

    論文寫 $\alpha\in[1,\infty]$；$\alpha=1$ 時兩邊相等，依嚴格不等號應為 $\alpha>1$。

    pp⁴（正規化後）

    混合參數為本頁示範值 示範值；論文 Fig. 2 未給參數。$p(y)=0.6\,\mathcal N(-1,0.6^2)+0.4\,\mathcal N(1.5,0.4^2)$。取 4 次方後，較高的峰占了大部分質量。

    $p^\alpha$ 的未正規化值可以直接由 base model 算出：算出 log-likelihood 再乘以 $\alpha$。困難在正規化：要從 $p^\alpha$ 取樣，需要對所有可能序列加總 $p(x)^\alpha$，序列數隨長度指數增加，無法計算。05 節處理這個問題。統計物理稱 $p^\alpha$ 為退火（annealed）或回火（tempered）分佈（Neal 1998）。

    延伸閱讀：退火與回火取樣：從統計物理到擴散模型的推論時取樣

    檢查理解

    Eq. 2 說什麼？α 需要什麼條件？

    若 $p(x)>p(x')$，則 $p(x)^\alpha/p(x')^\alpha>p(x)/p(x')$，高 likelihood 序列的相對權重上升；須 $\alpha>1$，論文寫的 $\alpha\in[1,\infty]$ 在 $\alpha=1$ 時兩邊相等。

    03a · 兩 token 的例子

    兩個 token 的例子：低溫與冪分佈給出不同答案

    先固定用詞：本頁說「某取樣法偏好 token a」，意思是 a 在該取樣法下得到較大的相對權重。

    Example 1（§4.1）：詞彙只有 a、b，序列只有兩個 token $(x_0,x_1)$，此處 $x_0$ 是第一個生成的 token。四條序列的機率是 $p(aa)=0.00$、$p(ab)=0.40$、$p(ba)=0.25$、$p(bb)=0.25$，所以第一個 token 的邊際權重是 $p(x_0=a)=0.40$、$p(x_0=b)=0.50$。取 $\alpha=2.0$。

    冪分佈先對每條完整序列取平方再相加：a 開頭得到 $0.00^2+0.40^2=0.160$，b 開頭得到 $0.25^2+0.25^2=0.125$，所以冪分佈的 a 權重較大。低溫取樣先把同一開頭的序列機率相加，再取平方：a 得到 $(0.00+0.40)^2=0.160$，b 得到 $(0.25+0.25)^2=0.250$，所以低溫的 b 權重較大。α=2 時兩種取樣對 a、b 的權重因此是：冪分佈 0.160 對 0.125（a 的權重較大），低溫 0.160 對 0.250（b 的權重較大）。

    原因是兩個開頭的未來不同：a 之後只有一條未來 ab，機率 0.40；b 之後有兩條未來 ba、bb，各只有 0.25。低溫取樣把 b 的兩條未來先加總成 0.50，冪分佈則對每條未來分別取平方，兩條 0.25 的平方和小於一條 0.40 的平方。

    例子有什麼瑕疵：四個機率總和是 0.90，不是 1。因為兩種取樣都只比較相對權重，大小關係不受影響。正規化後（本頁推導），冪分佈 $P(x_0=a)=0.160/0.285=0.561$，低溫 $0.160/0.410=0.390$。冪分佈給 a 較大權重的條件是 $0.4^\alpha>2\cdot0.25^\alpha$，即 $\alpha>\ln2/\ln1.6\approx1.475$（本頁推導，利用 $p(aa)=0$ 與 $p(ba)=p(bb)$）。總和為 1 的版本 $p(ab)=0.45$、$p(ba)=p(bb)=0.275$ 得到相同的結論，翻轉點為 1.407。

    論文勘誤 E2 · Example 1

    四個機率 0.00、0.40、0.25、0.25 的總和是 0.90，不是 1。排序結論不受影響。

    03b · 次方的和與和的次方

    一般情形：冪分佈是次方的和，低溫是和的次方

    Prop. 1 說低溫取樣不是從 $p^\alpha$ 取樣（§4.1）。固定前綴 $x_{\lt t}$，冪分佈的 next-token 條件分佈要把所有可能的後綴加總（式 4）；低溫取樣則可用條件機率的定義（論文稱為 Bayes rule，式 5）改寫成式 6。忽略正規化後，兩者的 next-token 相對權重各是：

    $$p_{\text{pow}}(x_t\mid x_{\lt t})\propto\sum_{x_{>t}}p(x_0,\dots,x_t,\dots,x_T)^\alpha$$
    式 (7)
    $$p_{\text{temp}}(x_t\mid x_{\lt t})\propto\Big(\sum_{x_{>t}}p(x_0,\dots,x_t,\dots,x_T)\Big)^\alpha$$
    式 (8)

    冪分佈的權重是「次方的和」（式 7），低溫的權重是「和的次方」（式 8）。把聯合機率拆成 $p(x_{\lt t})\,p(x_t\mid x_{\lt t})\,p(x_{>t}\mid x_{\le t})$，前綴項對所有候選 token 相同，可以得到（本頁推導）：冪分佈 = 低溫權重 × $F(x_{\le t})$，其中 $F(x_{\le t})=\sum_{x_{>t}}p(x_{>t}\mid x_{\le t})^\alpha$。$\alpha>1$ 時 $0\lt F\le1$，而且 $F=1$ 若且唯若選了 $x_t$ 之後只剩一條未來；未來分散到越多條路徑，$F$ 越小。低溫取樣等於把每個候選 token 的 $F$ 都當成 1。

    $$p_{\text{pow}}(x_t\mid x_{\lt t})\propto p(x_t\mid x_{\lt t})^\alpha\cdot F(x_{\le t}),\qquad F(x_{\le t})=\sum_{x_{>t}}p(x_{>t}\mid x_{\le t})^\alpha$$
    本頁推導

    用 Example 1 回驗：a 之後只有 ab，$F(a)=1^2=1$；b 之後 ba、bb 各占一半，$F(b)=0.5^2+0.5^2=0.5$。所以冪分佈 a 的權重是 $0.4^2\times1=0.160$，b 是 $0.5^2\times0.5=0.125$，與 03a 節的計算相同。

    兩者何時相同：$\alpha=1$；各候選 token 的 $F$ 相同；或位於最後一個位置 $t=T$（沒有未來，$F\equiv1$）。總結：冪分佈 ∝ $\sum_{x_{>t}}p(x_{0:T})^\alpha$（次方的和，式 7），低溫 ∝ $(\sum_{x_{>t}}p(x_{0:T}))^\alpha$（和的次方，式 8），冪分佈 = 低溫權重 × $F(x_{\le t})=\sum_{x_{>t}}p(x_{>t}\mid x_{\le t})^\alpha$（本頁推導），在 $\alpha=1$、各 token 的 $F$ 相同或 $t=T$ 時兩者相同。

    論文勘誤 E3 · Prop. 1 的證明

    對一般 $p$ 而言 Prop. 1 成立；但證明中「條件分佈在每個時間步都不同」在 $t=T$ 不成立（兩者相同），$\alpha=1$ 或確定性的 $p$ 時命題本身也不成立。

    延伸閱讀：冪次分布 p^α 與低溫取樣為何不同

    檢查理解

    兩者的 next-token 相對權重各是什麼？何時相同？

    冪分佈 ∝ $\sum_{x_{>t}}p(x_{0:T})^\alpha$（次方的和，式 7）；低溫 ∝ $(\sum_{x_{>t}}p(x_{0:T}))^\alpha$（和的次方，式 8）；冪分佈 = 低溫權重 × $F(x_{\le t})$（本頁推導）；$\alpha=1$、各 token 的 $F$ 相同或 $t=T$ 時相同。

    04 · Prop. 3

    冪分佈給「未來路徑少但機率高」的 token 較大權重

    Obs. 1（§4.1）把 Example 1 推廣成一句話：冪分佈偏好未來路徑少、但每條未來機率高的 token；低溫取樣偏好未來路徑多、但每條未來機率低的 token。App. A.1 用一個極端的簡化模型把它寫成 Prop. 3。

    固定前綴，token $x_t$ 的邊際權重是它所有未來的機率和（Def. 2）。正向 pivotal token 把全部權重 $\varepsilon$ 放在一條未來上（Def. 3）；負向 pivotal token 把權重 $\varepsilon'$ 平均分到 $N$ 條未來，每條 $\varepsilon'/N$（Def. 4）。代入式 7 與式 8：冪分佈給兩者的權重是 $\varepsilon^\alpha$ 對 $N(\varepsilon'/N)^\alpha=\varepsilon'^\alpha/N^{\alpha-1}$；低溫給兩者的權重是 $\varepsilon^\alpha$ 對 $\varepsilon'^\alpha$。

    先用 Example 1 代入：a 是正向 token（$\varepsilon=0.4$），b 是負向 token（$\varepsilon'=0.5$，$N=2$），$\alpha=2$。下界 $\varepsilon'/N^{1-1/\alpha}=0.5/\sqrt2=0.354$，而 $0.354\lt0.4\lt0.5$。一般情形就是下式。

    $$\frac{\varepsilon'}{N^{1-1/\alpha}}\lt\varepsilon\lt\varepsilon',\qquad \frac{\varepsilon'}{N^{1-1/\alpha}}>\frac{\varepsilon'}{N}$$
    式 (14)(15)

    在什麼條件下冪分佈給正向 pivotal token 較大權重，而低溫給負向 pivotal token 較大權重：當 $\varepsilon'/N^{1-1/\alpha}\lt\varepsilon\lt\varepsilon'$（式 14）。右半 $\varepsilon\lt\varepsilon'$ 使低溫給 $x'_t$ 較大權重；左半等價於 $\varepsilon^\alpha>\varepsilon'^\alpha/N^{\alpha-1}$，使冪分佈給 $x_t$ 較大權重。再由式 15，$\varepsilon>\varepsilon'/N$，也就是正向 token 的未來 likelihood 高於負向任一條未來。這需要 $N>1$ 且 $\alpha>1$（本頁推導），否則區間為空。這證明了什麼：Prop. 3 只在「一條未來 vs N 條均勻未來」的極端模型下比較權重大小，沒有證明這樣選出的答案較正確。

    作者認為：這種權重差異對推理有用。少數 token 會決定答案對錯（pivotal token 或 critical window，Li 2025、Abdin 2024）；選到錯的 token 時，所有後續序列的 likelihood 都較低。作者稱冪分佈內含 "an implicit bias towards planning for future high likelihood tokens"（§4.1，作者用語）。

    05a · Metropolis-Hastings

    Metropolis-Hastings 只需要未正規化的權重

    為何不能直接從 $p^\alpha$ 取樣：$p^\alpha$ 的正規化要對所有序列求和，不可計算（§4.2）。作者改用 Markov chain Monte Carlo（MCMC）中的 Metropolis-Hastings（MH）。Markov chain 是一串狀態 $x^0,x^1,\dots$，下一個狀態只依目前狀態隨機產生；若鏈走得夠久，狀態出現的頻率會趨近某個固定分佈，稱為平穩分佈。MH 的設計使平穩分佈正好是目標 $p^\alpha$。

    每一步，MH 用提議分佈（proposal distribution）$q(x\mid x^i)$ 從目前狀態 $x^i$ 產生候選 $x$，以下列機率接受（$x^{i+1}=x$），否則留在原地（$x^{i+1}=x^i$）：

    $$A(x,x^i)=\min\Big\{1,\ \frac{p^\alpha(x)\,q(x^i\mid x)}{p^\alpha(x^i)\,q(x\mid x^i)}\Big\}$$
    式 (9)

    MH 為何可行：MH 接受率式 9 只用 $p^\alpha$ 的比值，正規化常數在分子分母相消。平穩分佈成立的理由可以寫成一行（本頁推導）：$p^\alpha(x)\,q(x'\mid x)\,A(x',x)=\min\{p^\alpha(x)q(x'\mid x),\,p^\alpha(x')q(x\mid x')\}$，這個式子對 $x$、$x'$ 對稱（detailed balance），所以 $p^\alpha$ 是平穩分佈。

    收斂需要什麼：論文要求提議分佈不可約（irreducible，能到達 $p^\alpha$ 有質量的任何集合）且非週期（aperiodic）（Def. 1），收斂結果引用 Neal 1993，論文沒有證明。實際上還需要兩個論文略過的條件（本頁推導）：提議對 $p^\alpha$ 支撐內的序列給正機率，且雙向提議機率同時為正（$q(x'\mid x)>0$ 若且唯若 $q(x\mid x')>0$），否則式 9 的比值沒有定義；非週期則來自拒絕時留在原地的自環。$\tau=1/\alpha$ 的全詞彙取樣滿足這些條件，greedy、top-k、top-p 等截斷取樣不一定滿足。

    延伸閱讀：Metropolis-Hastings 與自回歸 LLM 上的 MCMC 前作

    檢查理解

    為何不能直接從 $p^\alpha$ 取樣？MH 為何可行？收斂需要什麼？

    正規化要對所有序列求和，不可計算；MH 接受率式 9 只用 $p^\alpha$ 的比值，正規化常數相消；提議分佈須不可約且非週期（Def. 1，引用 Neal 1993），實際上還需提議對 $p^\alpha$ 支撐內的序列給正機率、且雙向提議機率同時為正（本頁推導）。

    05b · 隨機重取與 Z_t

    隨機位置重取與接受率的化簡

    作者用的提議是隨機重取（random resampling，Fig. 3）：均勻選一個位置，保留它之前的前綴，用提議 LLM $p_{\text{prop}}$ 從該位置重新生成。在 06 節的 Algorithm 1 中，重新生成到目前區塊的結尾 $L$ 為止。設重取起點為 $m$，新舊序列在 $m$ 之前相同，前綴的機率與選位置的機率 $1/L$ 在比值中相消，式 9 的比值變成（本頁推導）：

    $$\frac{p^\alpha(x')\,q(x\mid x')}{p^\alpha(x)\,q(x'\mid x)}=\prod_{t=m}^{L}\frac{p(x'_t\mid x'_{\lt t})^\alpha/p_{\text{prop}}(x'_t\mid x'_{\lt t})}{p(x_t\mid x_{\lt t})^\alpha/p_{\text{prop}}(x_t\mid x_{\lt t})}$$
    本頁推導

    論文在推理任務中用的提議是同一個 base model 配溫度 $1/\alpha$，即 $p_{\text{prop}}(v\mid x_{\lt t})=p(v\mid x_{\lt t})^\alpha/Z_t(x_{\lt t})$，其中 $Z_t(x_{\lt t})=\sum_v p(v\mid x_{\lt t})^\alpha$ 是低溫分佈的正規化常數。代入後每個 token 自己的 $p^\alpha$ 全部相消。提議為同一 base model、未截斷、$\tau=1/\alpha$ 時，接受率化成（本頁推導）比值 $=\prod_{t=m}^{L}Z_t(x'_{\lt t})/Z_t(x_{\lt t})$，$Z_t=\sum_v p(v\mid x_{\lt t})^\alpha$；$Z_t$ 越大，表示該步的 next-token 分佈越集中。

    $$A=\min\Big\{1,\ \prod_{t=m}^{L}\frac{Z_t(x'_{\lt t})}{Z_t(x_{\lt t})}\Big\}$$
    本頁推導

    兩個推論。(a) 只重取區塊最後一個 token 時比值為 1 必接受：$m=L$ 時唯一的一項 $Z_L$ 只依前綴，而前綴相同。(b) 因共同前綴上的 $Z_t$ 在比值中相消，同一對新舊序列不論 $m$ 落在共同前綴的哪裡，比值都相同。這和 03b 節的 $F$ 是同一件事：低溫提議乘上 $Z$ 的修正，就得到冪分佈。化簡只在提議與目標用同一模型、未截斷（無 top-k、top-p）且溫度正好是 $1/\alpha$ 時成立；截斷提議（top-k、top-p）或 AlpacaEval 的 $\tau=0.5$ 不適用。論文沒有說明提議是否截斷。

    06 · Algorithm 1

    Algorithm 1 逐區塊執行 MH

    直接在整條長度上做 MH，每一步都要重新生成很長的序列；MCMC 還可能有指數級的混合時間（mixing time，鏈要走多少步才接近目標分佈），壞的初始化與高維狀態空間都會使它變長（§4.3）。作者利用自回歸結構，定義一串逐步變長的中間目標：

    $$\varnothing\to p(x_{0:B})^\alpha\to p(x_{0:2B})^\alpha\to\cdots\to p(x_{0:T})^\alpha,\qquad \pi_k(x_{0:kB})\propto p(x_{0:kB})^\alpha$$

    Alg. 1 每一階段做什麼：每階段先用 $p_{\text{prop}}$ 延伸 $B$ 個 token，再跑 $N_{\text{MCMC}}$ 步隨機位置重取 MH（重取到目前區塊結尾），目標是 $\pi_{k+1}\propto p(x_{0:(k+1)B})^\alpha$。第 7 行與第 10 行要注意什麼：第 7 行寫 $\pi_k$ 是索引錯誤，應為 $\pi_{k+1}$；第 10 行不凍結前綴，因為第 5 行的 $m$ 從 1 起抽，較早的 token 在後面的階段仍可能被重取。Output 一行寫輸出服從 $p^\alpha$，但只有 $N_{\text{MCMC}}\to\infty$ 時輸出才是 $p^\alpha$；論文沒有 mixing 診斷，§5.3 自己說步數越少離目標越遠。中間目標 $\pi_k$ 是「前綴機率的 $\alpha$ 次方」，不是 $p^\alpha$ 在前綴上的邊際（03b 節的同一個差別，發生在區塊層級，本頁推導）；最後一個階段的目標是完整的 $p^\alpha$，所以漸近正確，有限步數下則是偏差來源。B 決定區塊數；下方 C3 中，輸出與 $p^\alpha$ 的 TV 隨 $N_{\text{MCMC}}$ 下降，但不同 B 之間沒有一致的大小順序。論文只說較大的 B 需要較大的 $N_{\text{MCMC}}$（§4.3）。

    為了看見「有限步數時離 $p^\alpha$ 多遠」，C3 用總變差距離（TV）比較兩個分佈：$\mathrm{TV}(P,Q)=\tfrac12\sum_x\lvert P(x)-Q(x)\rvert$，也就是兩個分佈差異的總量，0 表示相同、1 表示完全不重疊。C3 的模型小到可以列舉全部序列，所以它不是抽樣估計，而是把 Algorithm 1 的轉移機率精確地逐步相乘，得到輸出分佈本身。

    07 · 成本

    成本與生成長度的平方成正比

    取樣 $\pi_k$ 時，每一步平均重取 $kB/2$ 個 token，每階段 $N_{\text{MCMC}}$ 步。對所有階段求和，期望生成的 token 數是（§4.3）：

    $$E_{\text{tokens}}=N_{\text{MCMC}}\sum_{k=1}^{\lceil T/B\rceil}\frac{kB}{2}\approx\frac{N_{\text{MCMC}}T^2}{4B}$$
    式 (12)

    論文報告的成本倍數是多少：除以一般推論的 $T$ 個 token，倍數是 $N_{\text{MCMC}}T/(4B)=10\times679/(4\times192)=8.84$ 倍（§5.3；$T=679$ 是 MATH500 上的平均生成長度）。精確照式 12 的和算呢（本頁推導）：$K=\lceil T/B\rceil=4$，精確求和為 $10\times96\times(1+2+3+4)=9600$ token，是 14.14 倍；把最後一個區塊截到 679 個 token，得 9155 token，是 13.48 倍；再加上每個區塊初始化延伸的約 $T$ 個 token，是 14.48 倍，所以約 13.5–14.5 倍。差異來自近似式相當於 $(T/B)^2/2=6.26$，而 $K=4$ 時精確和用 $K(K+1)/2=10$。成本與 $T^2$ 成正比，用平均長度代入會低估平均成本，因為 $E[T^2]\ge E[T]^2$；$T=3072$（上限）時近似式給出 40 倍。

    作者認為：假設每題 8 個 rollout、資料集一樣大，power sampling 的推論成本約等於 GRPO 訓練一個 epoch；實際 GRPO 一個 epoch 通常更貴（16 個 rollout、訓練集大於 MATH500）。本頁補充：GRPO 是一次性的訓練成本，power sampling 每次查詢都要付；MH 的步驟是循序的，論文沒有報告延遲。

    圖說寫 power sampling「strictly better than both GRPO and the base model」。k=1 時依 Table 1 是 GRPO 較高（0.785 對 0.748）；同一圖說又寫大 k 時與 base 相同，所以對 base 也不是嚴格較高。

    作者判斷（App. A.2，無數值）：k>1 時 power sampling "near universally better performance than both GRPO and the base model"；HumanEval 的 pass@k 用 $\alpha=1.67$，因為 "this temperature exhibits slightly better results at earlier k"；HumanEval 上 GRPO "exhibits better pass@k than the base model until k = 16"，作者猜測原因是程式題可以有多個正確解。

    超參數（Fig. 6）

    $\alpha=4.0$ 最好，$\alpha\ge2.0$ 之後大致穩定（MATH500，§5.3）。$N_{\text{MCMC}}$ 增加到 10 之前準確率穩定上升，超過 10 大致持平（not plotted）；2 到 10 步的差「不超過 3–4%」，0 到 2 步的跳升卻寫成「substantial (3–4%)」，同一個數字一處說小、一處說大。α 的掃描用 MATH500（測試集）；$N_{\text{MCMC}}$ 掃描的圖說只寫 "Qwen models"，沒有寫基準。

    檢查理解

    Power sampling 在哪些格低於 GRPO？表中相對 base 的差值有多少比例低溫取樣列也有？

    兩個 Qwen 模型在 MATH500（0.748 對 0.785、0.706 對 0.740）與 GPQA（0.389 對 0.399、0.318 對 0.354）都低於 GRPO；9 個推理格中 8 格的比例為 62%–77%（例外 Phi-3.5 GPQA 22%），這是分解不是因果，GPQA 的差只有數題；HumanEval 與 AlpacaEval 高於 GRPO。

    10 · 研究脈絡

    研究脈絡

    本文接在五條脈絡之後。RLHF 與 GRPO、DeepSeek-R1 等 RLVR 工作確立了以 RL 後訓練提升推理的做法；Yue 2025、He 2025、Song 2025 提出「RL 只是銳化」的觀察；另一批工作改用模型內部訊號（confidence、自我熵、甚至隨機獎勵）當作獎勵；twisted SMC 與 QUEST 等工作在 LLM 上做 MCMC／SMC 取樣；擴散模型領域則以退火分佈 $p^\alpha$ 提升樣本品質。本文把目標分佈完全交給 base model 自己的 likelihood。每張卡片連到對應的研究筆記。
