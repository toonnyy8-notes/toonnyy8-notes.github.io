No. 260 用自我蒸餾做強化學習：以加入回饋後的同一模型分布作為逐 token 訓練目標
    No. 260 · 互動教學 · arXiv 2601.20802

    用自我蒸餾做強化學習：以加入回饋後的同一模型分布作為逐 token 訓練目標

    SDPO 把同一個模型在提示中加入回饋後的下一個 token 分布當作目標，蒸餾回不看回饋的模型，得到逐 token 的訓練訊號。

    Jonas Hübotter、Frederike Lübeck、Lejs Behric、Anton Baumann 等（2026）〈Reinforcement Learning via Self-Distillation〉

    〔示意〕本頁構造的數值，不是論文數據以 Fig. 4 的題目為背景：回答 return list(range(1, n + 1))，回饋「Don't include n.」

    GRPO：同組 8 次嘗試中 3 次成功，這次失敗，所以每個 token 的優勢都是 0 − 3/8 = −0.375。SDPO：每個 token 各有一個值。

    01 · 文字回饋

    一般的強化學習訓練中，模型每次嘗試只得到一個分數；程式環境其實還會回傳錯誤訊息。本文把這些文字回饋直接變成訓練訊號。

    02 · 自己當教師

    教師就是模型自己：把錯誤訊息放進提示，重新計算原回答每個 token 的機率。在論文的例子中，機率明顯下降的 token 正好是錯誤所在；這是一個例子，不是保證。

    03 · 一個結果

    在 LiveCodeBench v6 上，Qwen3-8B 以 SDPO 訓練達到 48.8%，GRPO 為 41.2%。

    01 · RLVR 與 RLRF

    純量獎勵只含一個數字，文字回饋還帶有環境狀態

    語言模型可以看成一個策略（policy）：給定問題 $x$，逐 token 產生回答 $y=(y_1,\dots,y_{|y|})$，

    $$\pi_\theta(y\mid x)=\prod_{t=1}^{|y|}\pi_\theta(y_t\mid x,y_{\lt t})$$

    $\theta$ 是模型參數，$y_{\lt t}$ 是第 $t$ 個 token 之前的前綴。對一題取樣一次完整回答稱為一個 rollout。強化學習依環境對 rollout 的評價調整 $\theta$，讓評價高的回答更常出現。

    目前多數做法屬於 RLVR（reinforcement learning with verifiable rewards，以可驗證獎勵做強化學習）：取樣 $y\sim\pi_\theta(\cdot\mid x)$ 後，環境只回傳一個純量獎勵 $r\in\mathbb R$，常為二元，例如程式題的單元測試全部通過得 1、否則得 0。許多環境其實能回傳更多資訊：執行錯誤、未通過的測試、LLM 評審的文字意見。論文把這個設定稱為 RLRF（reinforcement learning with rich feedback，以豐富回饋做強化學習）：環境回傳 token 化的回饋 $f$，可同時包含獎勵與環境狀態的觀察（Sec. 1）。

    作者的主張是：RLVR 的主要限制不在 RL 本身，而在資訊量。純量獎勵只含一個數字，告訴模型「錯了」，卻沒有把環境狀態（例如錯誤訊息）傳回模型，模型無從得知錯在哪裡（Sec. 1；Fig. 2 的說明文字稱之為 information bottleneck）。從經典 RL 的角度看，這些環境是部分可觀測的（POMDP），RLVR 丟掉了觀察通道（App. C）。

    02 · GRPO

    GRPO 用群組平均估計優勢

    $\nabla\log\pi$ 是什麼。模型在一個位置對每個候選 token 輸出分數（logit）$z$，經 softmax 得機率 $\pi$。$\nabla_z\log\pi(\hat y)=e_{\hat y}-\pi$：讓被選 token 的分數上升、其他依機率下降。數值例：三個候選 $\pi=(0.5,0.3,0.2)$，選第 1 個，方向是 $(+0.5,-0.3,-0.2)$。乘上優勢 $A$：$A>0$ 時沿此方向走（提高這個 token 的機率），$A\lt 0$ 時反向走。

    訓練目標是期望獎勵 $J(\theta)=\mathbb E_{x,\,y\sim\pi_\theta}[r]$。策略梯度把它的梯度寫成

    $$\nabla J(\theta)=\mathbb E\Big[\sum_t A_t\,\nabla_\theta\log\pi_\theta(y_t\mid x,y_{\lt t})\Big]$$

    優勢 $A$ 表示這個動作比平均好多少：比平均好就提高它的機率，比平均差就降低。GRPO（Group Relative Policy Optimization）不另外訓練價值網路，而是對每題取樣 $G$ 個 rollout，以群組平均當基準（Sec. 2.1）：

    $$A^{\mathrm{GRPO}}_{i,t}:=r_i-\mathrm{mean}\{r_i\}_{i=1}^{G}$$
    Sec. 2.1

    本文的 GRPO 優勢不除以標準差（footnote 3，沿用 Liu et al. 2025b）。它有三個性質：(1) 優勢只施加在實際取樣的 token $y_{i,t}$ 上；(2) 同一 rollout 內所有位置的優勢相同，與 $t$ 無關；(3) 一組 $G$ 個 rollout 的獎勵全部相同（全對或全錯）時，所有優勢為 0，這一題沒有梯度，學習停止（Sec. 1）。例如 $G=8$ 中 2 個通過：$\bar r=0.25$，通過者的優勢是 +0.75，失敗者是 −0.25，總和為 0。

    〔本頁推導〕若每個 rollout 獨立、成功機率都是 $p$，一組優勢全為 0 的機率是 $(1-p)^G+p^G$。$G=8$、$p=0.1$ 時為 $0.9^8+0.1^8=0.4305$；每批 32 題（Table 12 的 question batch size）中，期望約 $32\times0.4305=13.8$ 題沒有梯度。$p=0.5$ 時只有 0.0078。這是獨立、同機率的簡化；實際上各 rollout 的成功率隨題目與訓練改變。

    要得到逐 token 的稠密監督，一個辦法是從更強的教師蒸餾。但線上學習的目標是超越現有模型，通常沒有更強的教師（Sec. 1）。本文的做法是讓模型自己在看到回饋後擔任教師（下一章）。

    04 · 損失

    SDPO 的損失是學生到自我教師的逐 token KL

    KL 散度 $\mathrm{KL}(p\|q)=\sum_i p(i)\log\frac{p(i)}{q(i)}$ 衡量分布 $p$ 與 $q$ 的差距：$p=q$ 時為 0，否則為正。例：$p=(0.5,0.5)$、$q=(0.9,0.1)$ 時，$\mathrm{KL}(p\|q)=0.5\log\frac{0.5}{0.9}+0.5\log\frac{0.5}{0.1}=0.511$。

    SDPO 在學生自己取樣的回答 $y$ 上，對每個位置 $t$ 計算學生與教師下一個 token 分布的 KL，再加總成損失：

    $$\mathcal L_{\mathrm{SDPO}}(\theta):=\sum_t \mathrm{KL}\Big(\pi_\theta(\cdot\mid x,y_{\lt t})\,\Big\|\,\mathrm{stopgrad}\big(\pi_\theta(\cdot\mid x,f,y_{\lt t})\big)\Big)$$
    Eq. 1

    學生分布放在 KL 的第一個位置，所以期望是對學生分布取的（reverse KL 方向）。stopgrad 表示計算梯度時把教師分布當作常數：梯度只流入學生的計算路徑，不流入教師。教師與學生共用參數，若不加 stopgrad，最小化 KL 也會把教師分布拉向學生分布，訓練訊號就不再反映回饋 $f$（Sec. 2）。

    05 · 梯度

    KL 的梯度就是以自我教師打分的策略梯度

    Prop. 2.1 把 Eq. 1 的梯度寫成策略梯度的形式（$\hat y_t$ 是位置 $t$ 上任一候選 token）：

    $$\nabla\mathcal L_{\mathrm{SDPO}}(\theta)=\mathbb E_{y\sim\pi_\theta(\cdot\mid x)}\Big[\sum_{t=1}^{|y|}\mathbb E_{\hat y_t\sim\pi_\theta(\cdot\mid x,y_{\lt t})}\Big[\log\frac{\pi_\theta(\hat y_t\mid x,y_{\lt t})}{\pi_\theta(\hat y_t\mid x,f,y_{\lt t})}\,\nabla_\theta\log\pi_\theta(\hat y_t\mid x,y_{\lt t})\Big]\Big]$$
    Eq. 2

    梯度下降沿負梯度方向走，所以最小化 Eq. 1 等於以下面這個優勢做策略梯度（Sec. 2.1）：

    $$A^{\mathrm{SDPO}}_{i,t}(\hat y_{i,t})=\log\frac{\pi_\theta(\hat y_{i,t}\mid x,f_i,y_{i,\lt t})}{\pi_\theta(\hat y_{i,t}\mid x,y_{i,\lt t})}$$
    Sec. 2.1

    讀法：教師與學生對候選 token $\hat y$ 的機率完全一致時，優勢為 0；教師較看好的 token（教師機率大於學生）優勢為正，訓練會提高它的機率；教師較不看好的 token 優勢為負。03 章 C2 的 log(q/π) 就是這個優勢在取樣 token 上的值。實作上，只要把既有 RLVR 管線中的 GRPO 優勢換成 $A^{\mathrm{SDPO}}$ 即可（Sec. 2.1）。這個優勢形式只對 reverse KL（Eq. 1 的 $\mathrm{KL}(\pi\|q)$）證明過（Prop. 2.1）；改用 forward KL 或 Jensen–Shannon 散度時，論文沒有證明優勢仍是這個 log 比值。

    與 GRPO 相比有兩點差異（Sec. 2.1）：(1) 回饋從 1 位元（通過／失敗）擴展到任意 token 序列；(2) 優勢變成稠密的 logit 層級：每個位置的每個候選 token 各有一個值，而不是整個 rollout 共用一個數字。

    推導：Prop. 2.1 的證明要點（App. B.1）

    固定位置 $t$，記 $\pi(\hat y)=\pi_\theta(\hat y\mid x,y_{\lt t})$、$A(\hat y)=\log\frac{q(\hat y)}{\pi(\hat y)}$。則 $\mathrm{KL}(\pi\|q)=-\sum_{\hat y}\pi(\hat y)A(\hat y)$。對 $\theta$ 微分並用乘積法則得兩項：$-\sum\nabla\pi\cdot A$ 與 $-\sum\pi\,\nabla A$。教師被 stopgrad，所以 $\nabla A=-\nabla\log\pi$，第二項成為 $\sum\pi\nabla\log\pi=\sum\nabla\pi=\nabla 1=0$。剩下 $-\sum\nabla\pi\cdot A=-\mathbb E_\pi[A\,\nabla\log\pi]$，即 Eq. 2。

    推導：KL 本身扮演 baseline〔本頁推導〕

    把單一位置的學生 logits $z$ 當自由參數，代入 $\nabla_z\log\pi(\hat y)=e_{\hat y}-\pi$：$-\partial\mathcal L/\partial z_k=\pi_k\big(A_k-\mathbb E_\pi[A]\big)$，且 $\mathbb E_\pi[A]=-\mathrm{KL}(\pi\|q)$。也就是說，優勢減去的基準值正好是負的 KL。06 章 C3 在數值上顯示這個等式。

    推導：序列層級的估計式（App. A.1，Eq. 5–8）

    App. A.1 指出：Eq. 5 的逐 token 估計式（假設產生 $y$ 的取樣分布固定）就是 Prop. 2.1。若改用整條序列的 KL（Eq. 7），梯度會多一項 $\mathbb E\big[\sum_t\mathrm{KL}_t\,\nabla\log\Pi_\theta(s_t)\big]$（Eq. 8，Amini et al. 2025），反映取樣分布本身也隨 $\theta$ 改變。作者試過這一項，「沒有可量測的增益」。

    推導：SDPO 與最大熵 RL（App. C.1）

    最大熵 RL $\arg\max\,\mathbb E\big[\sum_t r(y_t\mid x,y_{\lt t})\big]+\lambda_{\mathrm{ent}}H[\pi_\theta]$（Eq. 17）等價於最小化 $\sum_t\mathrm{KL}(\pi_\theta\|\pi^\star)$（Eq. 19）。取隱含獎勵 $r=\log q(y_t\mid x,f,y_{\lt t})$、$\lambda_{\mathrm{ent}}=1$ 即得 Eq. 1。作者據此稱 SDPO 為以回顧模型隱含構造稠密獎勵的最大熵 RL，並連到逆強化學習。

    檢查理解

    SDPO 的優勢是什麼？何時為 0、為正、為負？和 GRPO 差在哪兩點？

    $A^{\mathrm{SDPO}}=\log\frac{\pi_\theta(\hat y\mid x,f,y_{\lt t})}{\pi_\theta(\hat y\mid x,y_{\lt t})}$；學生與教師完全一致時為 0，教師較看好為正、較不看好為負；回饋從 1 位元擴展到任意 token 序列，優勢變成稠密的 logit 層級；此形式只對 reverse KL 證明（Prop. 2.1、Sec. 2.1）。

    06 · top-K 近似

    top-K 近似讓 logit 蒸餾放得進記憶體

    SDPO 唯一額外的計算是教師的 log 機率。這一步可以平行化，遠快於逐 token 的序列生成。Fig. 5（micro batch size 2）中，每個訓練步的時間增加 +17.1%（無程式環境）與 +5.8%（含程式環境）。Fig. 14 的虛擬碼：

    logprobs_student = compute_log_prob(batch) # T × V teacher_batch = reprompt(batch, teacher_context) logprobs_teacher = compute_log_prob(teacher_batch).detach() # stopgrad per_token_loss = divergence(logprobs_student, logprobs_teacher) loss = aggregate(per_token_loss, mode="token-mean")

    divergence 可以是三種散度之一（$\pi$ 為學生、$q$ 為教師）：

    • reverse KL：$\mathrm{KL}(\pi\|q)$，即 Eq. 1；
    • forward KL：$\mathrm{KL}(q\|\pi)$；
    • Jensen–Shannon：$\tfrac12\mathrm{KL}(\pi\|m)+\tfrac12\mathrm{KL}(q\|m)$，$m=\tfrac{\pi+q}{2}$。論文只寫「symmetric Jensen–Shannon」，混合比例 1/2 為本頁採用；論文也沒有給 JS 的優勢形式。

    記憶體。完整的 KL 需要同時保留學生與教師在整個詞彙表上的 logits。Eq. 11 只對學生機率最高的 $K$ 個 token 計算 KL 項，其餘 token 合併成一個「尾」類別：

    $$\mathcal L\approx\sum_t\Big[\sum_{\hat y\in\mathrm{top}_K(\pi)}\pi(\hat y)\log\frac{\pi(\hat y)}{q(\hat y)}+\Big(1-\sum_{\mathrm{top}_K}\pi\Big)\log\frac{1-\sum_{\mathrm{top}_K}\pi}{1-\sum_{\mathrm{top}_K}q}\Big]$$
    Eq. 11

    top-K 依學生選。作者指出 $K=100$ 時幾乎沒有記憶體負擔，且保留大部分資訊（Sec. 2.2）；Table 12 中 Sec. 3 用 $K=100$，Sec. 4–5 用 $K=20$。Eq. 11 等於把非 top-K 的 token 合併成一個類別之後的精確 KL，因此近似值 ≤ 精確值，尾部所有 token 的 $q/\pi$ 比值皆相同時兩者相等〔本頁推導〕。尾項不能省：省略它就不再是兩個機率分布之間的 KL。每個 rollout 因此有 $|y|\cdot(K+1)$ 個不同的優勢值（Sec. 4.2）。

    推導：為什麼近似值不會超過精確值〔本頁推導〕

    log-sum 不等式：對非負的 $a_i,b_i$，$\sum_i a_i\log\frac{a_i}{b_i}\ge\big(\sum_i a_i\big)\log\frac{\sum_i a_i}{\sum_i b_i}$，等號成立若且唯若 $a_i/b_i$ 全部相同。取 $a_i=\pi(\hat y_i)$、$b_i=q(\hat y_i)$ 為所有非 top-K 的 token：左邊是精確 KL 中尾部各項之和，右邊是 Eq. 11 的尾項。top-K 部分兩者相同，所以近似值 ≤ 精確值；尾部各 token 的 $\pi/q$（等價地 $q/\pi$）比值相同時相等。

    離策略。GRPO 基準用 Eq. 12：PPO 截斷、截斷重要性取樣 TIS（truncated importance sampling，以截斷後的機率比修正取樣分布與訓練分布的差異）、clip-higher、固定長度正規化。SDPO 推廣成 Eq. 13 的 logit 層級損失：對每個候選 token 以舊策略 $\pi_{\theta_{\mathrm{old}}}$ 的機率加權；實驗中 TIS 施加在 token 層級，而不是 logit 層級（App. A.4）。

    下面的 C3 把 Eq. 1 縮小到一個位置：學生是 C2 第 9 格（ +）的分布，教師固定，看梯度下降如何把學生拉向教師。

    07 · 穩定性

    正規化教師讓自舉保持穩定

    教師與學生共用參數，所以教師會隨訓練改變。這可以帶來自舉（bootstrapping）：學生進步，教師跟著進步；也可能讓訓練不穩定。作者提出兩個修正（Sec. 2.3）：(1) 正規化教師；(2) 改用對稱的 Jensen–Shannon 散度（Agarwal et al. 2024 在外部教師的線上蒸餾中也觀察到較穩定）。

    信任域教師。限制教師與初始教師 $q_{\theta_{\mathrm{ref}}}$ 的距離：

    $$\sum_t\mathrm{KL}\big(q\,\|\,q_{\theta_{\mathrm{ref}}}\big)\le\epsilon$$
    Eq. 9

    閉式解（Prop. B.1）是初始教師與目前教師在 log 空間的加權平均：

    $$q^*(y_t\mid x,f,y_{\lt t})\propto\exp\big((1-\alpha)\log q_{\theta_{\mathrm{ref}}}(y_t\mid x,f,y_{\lt t})+\alpha\log q_\theta(y_t\mid x,f,y_{\lt t})\big)$$
    Eq. 10、16

    這裡 $\alpha=1/\lambda_L$，$\lambda_L$ 是約束的 Lagrange 乘子（寫成 $\lambda_L$，與 Eq. 3 的混合權重 $\lambda$ 無關）。$q_{\theta_{\mathrm{ref}}}$ 是初始教師，所以 $q^*$ 永遠以固定比例 $1-\alpha$ 錨定在初始教師上。App. B.2 末提到 Chen et al. (2025c) 以初始學生 $\pi_{\theta_{\mathrm{ref}}}$ 當參考，作者觀察到效果不如 $q_{\theta_{\mathrm{ref}}}$。

    EMA 教師。教師參數 $\theta'$ 是學生參數的指數移動平均：$\theta'\leftarrow(1-\alpha)\theta'+\alpha\theta$。兩者的取捨：EMA 需要額外的 GPU 記憶體存放 $\theta'$，但沒有執行時間開銷；信任域要多算一次 $q_{\theta_{\mathrm{ref}}}$ 的 log 機率，但若 $\theta_{\mathrm{ref}}$ 本來就因 KL 正規化而保留在記憶體中，就不需要額外記憶體。

    〔本頁推導〕從 $\theta'_0=\theta_0$ 開始，經過 $n$ 次 EMA 更新後，初始參數在 $\theta'$ 中的權重是 $(1-\alpha)^n$：$\alpha=0.01$、$n=80$ 為 0.4475，$\alpha=0.05$、$n=80$ 為 0.0165。論文沒有說 EMA 是每個優化步還是每批生成更新一次；Sec. 4 的 question batch 32、mini batch 1（Table 12）表示一個訓練步最多有 32 次優化步，若每個優化步都更新，訓練步數與 $n$ 就不相同（第 80 個訓練步時 $n$ 可達 2560）。

    逐 logit 的信用分配與兩種回饋各有貢獻

    信用分配粒度（Sec. 4.2，Fig. 10 左）。論文比較三種 SDPO：

    11 · 測試時

    測試時自我蒸餾加速找到第一個解

    測試時（test time）面對單一難題，可以在同一題上反覆嘗試。Def. 5.1 把發現時間定義為第一次得到獎勵 1 的嘗試序號，並定義

    $$\mathrm{discovery@}k:=P(\text{發現時間}\le k)$$
    Eq. 4

    對固定模型做獨立取樣（best-of-k）時，discovery@k 等於 pass@k，也就是 $1-(1-p)^k$，$p$ 是單次成功率。

    作者的論證（Sec. 5、footnote 9，沒有實驗量測）：在單一題目上做 RLVR 不會勝過 best-of-k，因為二元獎勵在第一次成功之前全為 0，沒有訊號。SDPO 每次嘗試都得到回饋，可以在找到解之前就修正；而且它把上下文 $c=(y_k,f_k)$ 壓縮進權重：把 $\pi_\theta(\cdot\mid x,c)$ 蒸餾成 $\pi_{\theta'}(\cdot\mid x)$（Fig. 12），因此不受上下文長度限制。

    13 · 研究脈絡

    研究脈絡

    SDPO 接在幾條路線的交會處：策略梯度與 PPO 提供優化框架，GRPO 與 RLVR 把它用在語言模型的推理上；知識蒸餾與線上蒸餾提供逐 token 的監督形式，但需要更強的教師；情境蒸餾與自我蒸餾讓同一個模型帶著額外上下文擔任教師。本文把額外上下文換成環境回饋，並證明蒸餾的梯度就是一種策略梯度。每張卡片連到對應的研究筆記，總覽見 SDPO 的研究脈絡總覽。

    14 · 限制與延伸

    限制與延伸閱讀

    SDPO 依賴模型的上下文學習能力：弱模型的自我教師可能無法從回饋找出錯誤，表現不如 GRPO。它也依賴回饋品質：沒有資訊或誤導的回饋無法帶來學習。在小模型、短生成的設定下，額外的教師 log 機率計算佔訓練時間的比例較大。作者列出的未來方向是長時程與代理環境、大規模多任務訓練、沒有驗證器的文字回饋任務，以及系統性研究推理行為的差異，例如模板的影響（Sec. 7）。
